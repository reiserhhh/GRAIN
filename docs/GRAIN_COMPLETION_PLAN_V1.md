## 0. 老板先读：什么叫这次真正做完

我们不再以“写出下一条公式”为目标，而是交付一个有完整说明、可从新文本开始、
能被别人重建的研究系统：**作者材料→条件与表达配置→查询相关证据→固定数学读数→
相对群体的位置/变化→与独立心理或行为信息相接的解释**。

它包括 GRAIN 测量基础、LLM 推论机制、独立数学实现三条线。
现有成果已经提供若干有效接口；剩下的工作是把它们组成完整实例，并判定哪些
连接成立、哪些不成立、失败具体发生在哪一层。

“完美”不能被诚实地承诺成“从此不可能有未知机制”。本计划采用可验收的更强约束：
**每个已知必要问题有负责人、依赖、输入、输出、成功条件、失败出口；
没有未归属的必需拼图，也不通过改名或缩小问题把失败计成成功。**
如果某项关键假说失败，项目可以形成完整的否定性结论，但不能说终极目标已实现。
如果必要观测缺失，必须在开跑前或对应门口明确请求，不允许跑完再说“还差一个实验”。

## 1. 不再漂移的目标与边界

### 1.1 三条必须分别交付的线

| 线 | 必須回答 | 具体终点 |
|---|---|---|
| A：GRAIN 测量基础 | 什么被计分，和条件/机会/时间/参照是什么关系？ | 一套可复建的观察、组织、汇总、校准、误差及解释协议 |
| B：查询推论机制 | 固定模型怎样把同一材料变成不同查询的判断？ | 有输入及干预契约的计算机制，在冻结范围内解释已登记现象 |
| C：独立人格/状态推论 | 哪些有用计算可以不经 LLM 推理完成？ | 新文本冷启动的固定程序及多效标结果；严格无 Transformer 路线单独裁决 |

### 1.2 本阶段不是哪些项目

不是马上制作新临床量表、确立诊断 cut-off、验证治疗效用或宣称跨文化常模通用。
不是证明所有人格/情绪都能从任意短文本恢复，也不要求每一个 Big5/MBTI 因子高相关。
不是证明人脑运行同一个 Transformer，或强制实现唯一、全维、零误差的世界模型。

这些边界来自用户此前反复确认的“基础方法论研究”目标，不是看到失败后的降级。
但是，**只做文本分类、只模仿模型、只在缓存上精确复算**，都不足以替代 A–C。
“大量文本获得与作者相关的心理推论”仍是应用方向；当前必须交付至少一个完整的
真实作者连接实例及其可拓展制作流程，不能以理论文档代替所有实证连接。

### 1.3 三种最终状态，不可混报

- `OBJECTIVE_ACHIEVED`：下列 C01–C06 必需成果达到审核后冻结的规则，WP00–11 全部验收。
- `NEGATIVE_RESULT_CLOSED`：完整尝试给出了具体反例/失败范围，研究包可结束，但相关积极假说未实现。
- `REQUIRES_NEW_INPUT`：缺少必要独立观测、授权或可运行输入。计划不能标为全部完成，也不自动重新开 loop。

可有部分成果独立达到第一种状态；整个项目只有全部必需项满足，才可整体用第一种状态。
资源到限、所有脚本跑完、表格填满、代数残差归零，都不是额外的成功状态。

## 2. 先冻结需要解释的现象

这些是待解释目标，不是说所有现象已经跨总体确证。现有证据范围保留在系统回顾中。

| ID | 现象 | 一个合格解释必须做到 |
|---|---|---|
| P01 | 条件/主题选择可携带作者差异，整体删除会损失信息 | 同时表示可用机会、选择与条件内表达，而非一律残差化 |
| P02 | 静态、动态、共享及残差结构不总能旋转成稳定单轴 | 允许分布式配置与坐标等价，给可计分的不变量 |
| P03 | 同材料换查询会改变证据选择和读取方向 | 区分选择、方向、输出基线，并给可区分的干预预测 |
| P04 | 上下文改变会影响未改变 token 的读取 | 表示交互项；不能只加和静态 token 权重 |
| P05 | GRAIN 矩有用，但同 GRAIN 观察值下仍可有原生作用 | 给输入充分性条件/反例，定位缺在非线性组合还是配置 |
| P06 | 局部函数拟合好，真人效标关联未必同样好 | 同时测模型功能和独立效标，保留其不一致 |
| P07 | 不同查询共享一部分路径，仍有方向特定部分 | 共享/私有/抵消可由同一个机制族表示，而不强制独立因子 |
| P08 | 单次记录中的变化、作者平均和群体关系并不等价 | 使用实际时钟与测量层级，分别定义和计算 |
| P09 | 合成可控世界可成功，真实域未必运输 | 分离机制存在、输入支持、统计运输与心理效度 |
| P10 | 系统分数需要稳定解释，但 LLM 渲染不应改变计分 | 数值、材料地址、候选含义与独立编码可分别复核 |

每个 P 的输出必须至少有：来源、竞争解释、区分实验、成立范围及失败去向。
不因某机制解释 P03 很好，就默认它解释了 P01、P06 或 P08。

### 3.2 应当统一的计算图，而不是假装已有万能公式

定义记录 `X_{u,t}`、机会 `O_{u,t}`、查询 `q`，观察协议 `v`。
以下是**待实现的统一接口规格**，不声称现有所有脚本已经采用：

\[
X_{u,t}\xrightarrow{\mathcal O_v}(H,G,C,T),\quad
\mathcal A_u=\mathcal A(H,G,C,T),\quad
z_{u,q}=f_q\{\mathcal A_u,\Phi_q(H,G)\},\quad
m_{u,q}=\mathcal C_{q,P_0}(z_{u,q}).
\]

`H` 依赖哪个编码器必须写明；`G` 是观察坐标，不等于心理真值；
`C` 保留条件与机会；`T` 分清文本顺序、真实时间和模型深度。
最后接外部通道 `Y^(self/other/state/behavior)`，不能写成默认相等的同一变量。

对固定模型端点 `F_q`，沿声明的连续向量路径：

\[
F_q(H_1)-F_q(H_0)=\int_0^1 DF_q(\gamma(s))[\gamma'(s)]ds.
\]

对可学习替身要求 `Df_q` 真的是 `f_q` 的导数，不能另拟合后拼接。
分解余项必须有来源：表示压缩、计算近似、域支持、效标方法差异或未识别机制。
显式保留余项是诚实记账；只有量化/约束其来源，才是新增机制解释。

若多层近似可在相应支持上给出误差 `e_i` 和后续 Lipschitz 界 `L_j`，
由逐层替换可得到形式误差界 `sum_i e_i prod_{j>i} L_j`。
WP03 必须检验这些前提能否成立；没有可用 `L_j` 时报告实测端点误差，
不将形式界当作已获得的全局保证。

### 3.3 四个需要明确回答的哲学问题

| 问题 | 本计划的处理 |
|---|---|
| 可计算就等于心理真实存在吗？ | 不等于；计算对象先成立，心理含义由独立连接支持，目标不被退化为纯文本分析 |
| 两个公式都能解释相同数据，必须选唯一真相吗？ | 先报告观测/干预等价类；只有新增可区分观测才继续选择，不能凭美感定因果 |
| 误差能否随着样本无限增大而为零？ | 估计误差、观测误差、条件内变异、模型遗漏分开；无额外假设不混同其极限 |
| 把已知人格词作为查询是否循环？ | 查询是研究先验；方向构造与外部效标必须拆分，命名后的验证不能回灌选择最优结果 |

**验收：** 10个现象全覆盖，所有 headline 数字有地址；同人AUC、结构r、功能r、人格r无混用。
**成本/失败出口：** 3–5小时；无法追溯的数字不作终局证据，保留历史注释。

### WP02：识别测量对象、选择机制与竞争解释

**问题/依赖：** 作者、机会、表达、查询、编码器与效标之间，哪些边可识别？依赖 WP01。
**动作：** 绘制有类型的观测/干预图；写出选择与条件响应的区别、被试/AI角色、
群体/个人内差异、误差类型、旋转等价。对每个关键边给至少一个替代生成机制。
只按实际交叉设计估计方差分量；不得为形式完整拟合不可识别的 full G-study。
**输出：** `IDENTIFICATION_AND_SCOPE.md`、`alternatives.csv`，每边对应最小所需观测。
**验收：** 31条边全有状态与后续包；无“代数恒等式→人格因果”“群体→个人内”隐含跳跃。
缺少观测的参数必须明确只能估计组合或等价类，不能任意固定为0。
**成本/失败出口：** 4–6小时；理论不能唯一分离时交付识别边界，积极唯一性命题判失败。

### WP03：统一形式理论与已知真机制的玩具世界

**问题/依赖：** 同一组公式能否再现 P01–P10 中可模拟部分？依赖 WP02。
**动作：** 写6个标准命题及推导：条件/选择分解、固定参照变换、矩核充分性边界、
值/导数一致性与积分、层间复合误差、层级/方法误差不等价。
构造有限机制库：共同潜源、互相作用、机会选择、状态脉冲、纯方法差异、
共享/私有/抵消路径、同矩异响应、不可识别的等价模型。
复用M3/M4的事件核→作者配置→群内/群间关系→构成加权见证，
特别保留“同群误差约化不推出全社会随机误差为零”的反例。
**输出：** `FORMAL_SPECIFICATION.md`、`synthetic_witnesses.json`、合成测试与反例报告。
**验收：** 每个命题列假设/证明/反例；已知真机制至少包含阳性与阴性。
double 精度恒等式残差拟定 ≤1e-8×尺度，数值有限差分相对误差 ≤1e-3（退化尺度另报绝对值）。
模拟恢复参数只在可识别情形评价；等价情形正确输出等价类，不要求虚假的唯一恢复。
**成本/失败出口：** 1–2天，CPU≤2小时；证明失败修定义，不能以大量模拟代替证明。

### WP04：决定联合表示究竟要保留什么

**问题/依赖：** 现有 GRAIN 分数内部缺的是交互还是 token 配置？依赖 WP03。
**动作：** 将尚未执行的 NEXT91 纳入此包：线性矩→全二次 GRAIN 模式→精确同G cell 上限→cell 内配置。
同时检查移动 G/重新分词时的额外导数，不把固定 G 局部结论外推整个观察管线。
只有两个可部署候选：非线性局部矩；保留 token/局部配对的查询条件集合读出。
精确cell只作描述上限，单例率/有效rank必须报告，不据标签改cell定义。
**输出：** `INPUT_SUFFICIENCY_REPORT.md`、固定输入schema、候选保留/淘汰理由。
**验收：** 可见作用、残余作用、能量与对齐分别报告；覆盖 P05，选定一个主接口和一个失败备选。
若两者不足，必须定位剩余输入类型，不能宣称四因子完全充分或无限增加 K。
**成本/失败出口：** 0.5–1天，首先复用缓存；新增神经计算预算为0。

### WP05：把局部机制接回完整原生判断

**问题/依赖：** 选择、读取方向、交互、基线能否解释完整端点变化？依赖 WP04。
**动作：** 采用固定教师版本；同时保留“静态池化”“仅选择变化”“选择+方向+交互”三个机制候选。
使用合法的同材料干预：角色/指代绑定、证据位置/顺序、上下文及查询；
向量干预与可读文本修改分别登记。量化原生端点和路径积分，而非只看教师局部内积。
记忆/摘要压缩使用同源证据对照；对用户persona反向路径想法，以一个固定小对照
检验共享方向，不预设赋予AI人格与推断真人特质是互逆过程。
**输出：** `NATIVE_MECHANISM_REPORT.md`、干预库、可执行原生/抽取机制接口。
**验收：** P03/P04/P07 有能区分竞争模型的结果；完整函数和有限变化都有误差表。
任意切换基线或query输出单位都需要版本；固定梯度见证不冒充部署选择器。
**成本/失败出口：** 1–2天；新GPU≤4小时。先做不超过24个现有可用作者的完整单元，
作者名单由输入条件选定，不按结果筛选；发现方向后冻结，再由WP08评价独立连接。
若全机制不优于简单模型，采用简单模型，不以“更深”作为保留理由。

### WP06：同时落实两条独立构造路线

**问题/依赖：** 新文本如何产生必需的证据坐标，而非借用现成H16？依赖 WP05。
**路线A：** 从文本重构必要中间表示，再用冻结读出；必须记录重构坐标与功能的不同误差。
**路线B：** 直接预测目标证据、选择/交互及读出，不重建整个隐藏状态。
两者都设置 D1（冻结轻量编码器）和 D0（静态token/字符/显式局部数学特征）版本，
开发时可以源教师教学，部署时不能偷偷调用它。冻结一类线性与一类小型非线性读者，
不进行新的大规模模型选秀；不因为某库可用就展开额外家族。
具体候选规格：D0采用源固定word/char特征、静态token表示及位置/局部配对统计；
D1采用冻结E5局部表示与同样的地址/配对统计。A预测WP04确定的必要证据坐标，
B直接学习分数与同材料修改响应。线性读者为Ridge；非线性优先复用既有可微核读者，
只在其输入契约不适用时用一个小型MLP替换，不同时扩展多个新家族。
候选最多为2路线×2依赖级别×2函数族；超参数仅源内分组CV，固定三档正则，
不得用外部Y决定输入、权重或模型。多查询联合求解可减少重复成本。

教学目标采用同一个函数的值与有限响应，而不是分别拟合两个不一致的头：

\[
\mathcal L=\frac1n\sum_i\frac{(f(x_i)-F(X_i))^2}{\sigma_F^2}
+\lambda\frac1m\sum_{(i,j)}
\frac{\{[f(x_j)-f(x_i)]-[F(X_j)-F(X_i)]\}^2}{\sigma_{\Delta F}^2}.
\]

尺度只由源材料确定，近零尺度使用明确的退化分支；差分与值并非独立观测。
导数比较仅在输入变换及其切向映射已定义时进行，不把字符离散修改直接等同H16梯度。
这给出有限可执行构造；不声称该损失本身能确保心理有效性或发现唯一机制。
**输出：** `INDEPENDENT_ROUTES_REPORT.md`、每条路线的 `input_dependencies.json`、模型与源固定校准。
**验收：** A/B都有结果；冷启动前不能读目标作者隐藏缓存或人格标签。
函数值、导数/有限变化、人类关联分开计分；选模只用开发资料的预定目标，不用最终Y。
**成本/失败出口：** 2–3天；CPU≤8小时、GPU≤8小时，不做LoRA/大模型训练。
D0失败则保留D1实用成果，但严格独立目标判未实现；不得更改D0定义逃避结论。

### WP07：端到端冷启动与统一误差预算

**问题/依赖：** 一个外部执行者只给新文本能否跑通？依赖 WP06。
**动作：** 在隔离缓存目录运行同一固定程序；断开API；记录所有模型加载与文件访问。
比较原始文本→观察→表示→读出→分数的逐层与完整误差，验证数值变化可追溯。
**输出：** `END_TO_END_REPORT.md`、`run_manifest.json`、冷启动命令、时间/内存/依赖表。
**验收：** 无训练集混入评价作者；源参照固定；不同同批陪伴样本不改变个体分数；
全程符合申报D0/D1级别。总误差不能只靠带自由参数的余项配平。
下节数值门槛在Claude审查后冻结，再做评价。
验收材料至少包括合法独立作者文本、同作者已有不同视图、无证据/角色混入的失败输入，
各自预先确定输出规则。故障注入针对接口正确性，不再生成一套无边界安全测试矩阵。
**成本/失败出口：** 0.5–1天；全端点复核只运行冻结候选。
失败需明确在输入获取、表示、函数或校准哪层，不能退回报告局部r作为完成。

### WP08：九人格查询与状态/关系因子的全图

**问题/依赖：** 抽取计算能保留哪些真实作者信息？依赖 WP07；WP00的权限先决条件必须满足。
**动作：** Big5五项、MBTI E/N/F/J四个正向编码全报告；
在允许的源样本做作者分组交叉拟合，bridge按冻结模型评价，不用于选择头或权重。
已有 MEPS 白名单中有分数的关系/状态因子逐一列入；pre/mid/post只与真实相应窗口相接。
分别比较G、路径、G+路径、常数/词汇/简单表示基线；嵌套损失比较固定读者族。
效标为探索材料则写探索，反复暴露的样本不改称新验证集。
**输出：** `ALL_CRITERIA_REPORT.md`、`criterion_matrix.csv`、桥接关系表、缺失/不可估计清单。
**验收：** 所有预先存在的白名单因子都有估计或具体缺失理由；无只报最佳因子；
人格水平、文内变化、真实时段变化分别估计。个体关联与关系矩阵相似单独报。
若全部心理连接消失，C05失败；若仅部分存在，冻结该范围，不制造万能测量主张。
**成本/失败出口：** 1–2天，主要缓存CPU；MEPS零外部API、零训练。
存在独立评价样本不足时，提前提交最小新增数据规格，不循环挖旧数据冒充确认。

### WP09：参照、机会、文本量、来源与语言的制作规则

**问题/依赖：** 换资料时要重建什么、可直接保留什么？依赖 WP07，可与WP08顺序交错但不共享选模信息。
**动作：** 仅冻结公式/观察器，分别在PANDORA、Essays、X及可用MEPS材料检查
输入支持、参照分布、文本量、格式/角色、实际时钟和机会匹配。
明确三种场景：同公式同参数、同公式源内再校准、需新观察协议。
缺少同人跨域或多语言匹配时，只报告可计算性和结构变化，不制造测量等价。
继承M4的自动适用性路由失败：支持统计仅是元数据，不用coverage阈值预测算法收益；
新场景采用设计许可与B0/候选敏感性比较，不重启旧路由调参。
**输出：** `TRANSPORT_AND_REFERENCE_REPORT.md`、适用性矩阵、`BUILD_ON_NEW_CORPUS.md`。
**验收：** 每个数据源有可复建结论或明确不支持项；低支持输入返回说明而非错误常模。
至少定义一个 state 型与一个较稳定分布型制作范例，不要求现在完成临床常模。
**成本/失败出口：** 1天；跨源新编码GPU≤2小时。没有对应标签就不跑伪外部准确度表。

### WP10：将固定计算翻译为可复核解释

**问题/依赖：** 解释如何有心理研究价值而不循环自证？依赖WP08/09。
**动作：** 冻结数字证据包：作者范围、参照、材料地址、时间、方向、量级、候选意义、替代解释。
独立行为/关系编码先于查看模型分数；渲染器只读取获准证据。
精神动力/TA/依恋等只在既有公开rubric与授权材料上做辅助解释，不临时发明诊断真值。
不强求每个数学维度可命名；多维配置允许描述成条件化模式。
**输出：** `INTERPRETATION_CONTRACT.md`、盲编码/数字渲染两个独立prompt、人工可读示例。
**验收：** 100%数值/引用地址通过程序核对；无新诊断标签；删去依据后相应断言必须删去。
一致性只比较事先定义的原子判断，报告分歧；相似作者解释安定性不能靠输出同一句话实现。
**成本/失败出口：** 0.5–1天；最多24个合法去标识或合成证据包、3次重复；
私有MEPS不发API。无可用独立编码则交付接口，解释效度不标成立。

### WP11：独立复建、论文与最终裁决

**问题/依赖：** 另一个研究者能否不依赖我们口头说明做出同一系统？依赖WP00–10。
**动作：** Claude先只读方法审查；经用户允许后，在干净环境重建关键代表结果。
核对6个命题、10个现象、31条边、数据/模型许可证与公私边界；
生成从0制作说明、理论论文中日英三语一致版、主张/证据/限制表、版本化发行清单。
**输出：** `FINAL_DECISION.md`、`REPRODUCTION_GUIDE.md`、固定模型/常模/输入schema、论文审查包。
**验收：** 无必需TODO、无未归属边、关键复算可从公开合成材料运行；
受限数据提供合法获取/本地引用方法，不公开原文、用户ID、心理问卷或密钥。

**成本/失败出口：** 2–3天；一轮主要修正+一轮复查。严重新缺口回到对应WP，不新增无界子项目。

## 6. 评价规则：先定用途，不再拿一个r管所有东西

以下是**提交审核的建议门槛**，不是已经预注册的结论。Claude应检查它们是否服务于
用户目标、是否可由数据支持；用户批准后在WP00冻结，之后不能因结果修改。

| 对象 | 主量 | 建议裁决方式 |
|---|---|---|
| 代数/代码一致性 | 尺度化残差、数值梯度误差 | WP03规则；float32原生模型另用重复测量的数值误差底线，不套double门槛 |
| 新文本对固定教师的读出 | MAE/RMSE、以开发集SD归一的NRMSE、r、偏差 | 工程候选主门槛：分数NRMSE≤.25、有限变化NRMSE≤.35；与简单基线配对报告。阈值仅表示替身精度，不表示心理有效性 |
| 作用机制 | 干预响应、选择/方向/交互的增量、符号与幅度 | 高于数值底线的效应方向与幅度均报告；不以符号全对替代幅度，也不要求所有人敏感度不同 |
| 人格联系 | trait-wise r/rho、MBTI AUC/balanced accuracy、校准 | 全9项；正向效应CI、BH q与效应量一起报。无需r>.5；不将不显著自动写成等价 |
| 独立实现保留人类关系 | 相对冻结D1/原生参考的配对Δr/ΔAUC | 拟定可接受损失边界为Δr=-.03、ΔAUC=-.02；单侧95%下界超过边界且原有关联仍可检出，才声称保留。不是把任意小数都判材料差距 |
| G与路径的条件贡献 | 同折 held-out loss(G)−loss(G+path)，反方向同算 | 函数族与训练预算相同；允许冗余/抵消/无增量。用它选择组合形式，不强制相加 |
| 状态变化 | 与真实匹配时点状态的个人内关联、误差、变化区间 | 按人聚类；无时点对应只能评静态关系，不要求每天重复同题 |
| 结构关系 | 关系矩阵元素r、误差及配对bootstrap | 完整关系矩阵整体重算，不能把20个元素当20名独立被试 |
| 可复建/可解释 | 冷启动成功、固定参照、地址和数字一致性 | 确定性计分在同版本内可重现；解释精确引用，不改变分数 |

**样本与不确定性。** 折、种子、token不是额外被试。以作者为bootstrap/置乱单位；
相谈重复观测按作者成组，时间分析额外保留块结构。缺失不填0，常数分数相关不填成功。
有独立保留集才进行一次冻结评价；如果所有可用数据均已用于探索，
作者分组OOF只称交叉验证探索，不伪称最终独立确认。

若非劣效CI太宽，提前按开发集方差和预定精度目标估计所需新增作者数，
不能看到评价结果后无限补样本到通过。新资料授权属于显式请求，而非无界研究许可。

## 7. 在脑中模拟失败：每个结局提前有出口

| 情形 | 能学到什么 | 固定动作与结束边界 |
|---|---|---|
| GRAIN二次组合解释余项 | 当前分数交互有用 | WP04选非线性矩，WP06检验新文本；不继续找更多factor直到出高分 |
| 同G内部配置主导 | G分数不足以作为完整输入 | 保留token配对候选；GRAIN继续承担条件/参照，不宣称理论无用 |
| cell全是单例 | 精确cell上限平凡 | 不用该上限作发现；按预定局部配置候选继续，不改阈值追结果 |
| 梯度作用好但有限修改失败 | 局部性/路径支持是断点 | WP05修一次完整机制；仍失败则限制机制支持范围并记C02部分失败 |
| 模型拟合好但外部联系消失 | 教师利用方式和人类效标不一致 | 保留机制发现，C05不通过；不得继续仅钻教师精度 |
| D1有效而D0失败 | 编码计算仍不可省 | 报D1成果和D0限制；严格终极目标未实现，不更名D1为D0 |

| 两个机制始终观测等价 | 当前可识别对象是等价类 | 保留等价类和未来可区分观测，不循环寻找“唯一轴” |
| 解释稳定但依据不对 | 一致性不等于有效性 | 禁止该断言，修rubric一次；无独立编码不声称解释有效 |
| 样本身份/AI代写/泄漏改变结果 | 核心输入对象错误 | 优先修WP00/观察层；重新冻结受影响评价，不复用污染headline |
| 新差异很小、无主线决策影响 | 无需继续耗算力 | 冻结结果表结束此包；不是统计学证明效应为0 |
