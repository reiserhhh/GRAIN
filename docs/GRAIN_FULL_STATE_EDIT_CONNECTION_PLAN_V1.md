## 1. 要发现什么

同一个文本编辑，使N与确认的局部响应共同变化，却与其余作用部分抵消。
把其余上下文状态和末查询状态同时纳入实际四格干预，判断这是：
上下文主作用、查询主作用、二者组合，还是删文后的布局变化。
成功是找到可重复计算的自然响应构造，并定位哪种操作使查询关系出现或抵消。
不设人格r门槛，不把任一剩余项定义成噪声，不要求单一方向吞掉所有机制。

## 3. 自然删文长度改变：先做诚实的状态对齐

执行前接口核对：S1删文会重新编号Excerpt标题。因此A按**正文的原评论来源**
和**脚手架的可见编号/角色**分别绑定，后缀按固定查询角色绑定。每个运输位置
仍须token ID和字符区间完全相同；不做语义近邻匹配、不丢掉token。标题状态
可以来自原序列同显示编号位置，故A不一定单调；该历史重新分配明确归入Gamma，
Gamma不解释成纯删除或纯位置作用。此规则在读取新响应前固定。

记原始下游读出为s_full，编辑后为s_edit。记录原始H与编辑后的H'，用评论边界
和完整token ID序列，建立**保留token的确定性对应P**。不得用向量最近邻或
可调相似度匹配。预检实际发现换行会与前一标点合并成不同token。因此固定如下
规则：能精确对应的token运输原状态；重分词的脚手架/正文边界token保留编辑后
状态，在四格中均固定并单列数量；正文内部不匹配则停止，不能用此规则掩盖。
定义H0=P H+J H'，J只选择这些明确的边界位置，P与J互补，覆盖全部编辑位置。
此修正在新神经采集前完成，未删token、未改任何原生提示。

下游统一使用编辑后的长度、mask和位置规则L'。令F_L'为固定模型的后缀计算，
把状态分为所有非末位R与末查询位置Q：

    f00 = F_L'(H0_R, H0_Q)
    f10 = F_L'(H'_R, H0_Q)
    f01 = F_L'(H0_R, H'_Q)
    f11 = F_L'(H'_R, H'_Q) = s_edit
    Gamma = f00 - s_full

R包括其余提示、查询前缀、正文等，不冒称纯正文或纯语义。Gamma是操作性
重基准项，包含对齐/位置/上下文删除及边界重分词的影响，不是已独立识别的
“纯位置效应”。末查询token必须有精确的原末位对应，不使用J填补。
重放f11与原生编辑输出、原H在原布局与s_full，必须在同次运行核对。

## 4. 可测试的有限构造

    R_main = f10-f00
    Q_main = f01-f00
    I_RQ = f11-f10-f01+f00
    Delta = Gamma + R_main + Q_main + I_RQ.

进一步对称分配：

    Phi_R = [(f10-f00)+(f11-f01)]/2
    Phi_Q = [(f01-f00)+(f11-f10)]/2
    Delta = Gamma + Phi_R + Phi_Q.

I_RQ单报，不能再加进最后一式。分解依赖声明的干预与对齐，但每项都有实际
反事实端点；比把Delta−M统称黑箱更具体。此设计不混用S1原布局patch与L'下
的f01，也不把代数重建叫留出预测成功。

对三个查询同时计算有符号分量、跨作者协方差、分量交叉项、参照/评估差异，
检查N/确认的负交叉关系主要落在哪里。随后只选一个已观测作用继续数学近似：
上下文主作用、交互或重基准；不要同时开三条精度优化队列。
