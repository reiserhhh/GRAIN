# 条件分布、联合读取与输出映射

2026-09-10。接续[条件函数](GRAIN_CONDITIONAL_FUNCTION_LOGIC_V1.md)；对应NEXT17-23。
这是GRAIN表达测量与查询功能之间的计算接口，不是新的人格因子命名。

## 1. 把三种非线性分开

对固定条件c、布局l和查询q，候选程序写为：

    u = sum_j Phi_q(h_j; c,l)
    z = rho_q(u; c,l)
    s = S_q(z).

Phi是局部表示，rho是联合读取，S是答案空间上的输出映射。当前核函数使Phi
非线性，但rho仍是线性Ridge；因此“已经用了非线性核特征”不等于拥有非线性
联合读取。另一头，S的softmax即便遇到可加的z也会产生非加和的s。

这个区分有明确先例。[Deep Sets（Zaheer等，2017）](https://papers.nips.cc/paper/2017/file/f22e4747da1aa27e363d86d40ff442fe-Paper.pdf)
采用rho(sum Phi)，且可加入条件变量。其可表示性定理有定义域和集合大小条件，
不保证我们固定32方向足够。带位置的文本可用(状态,位置)作输入；对这些配对
的枚举不变，不等于把真实文本时间/展示顺序删除。
[Szabo等（2016）](https://www.jmlr.org/papers/v17/14-510.html)进一步研究从分布
嵌入到结果的回归。文本token并非独立同分布采样，不直接套用其统计收敛界。

## 2. 当前线性聚合的精确限制

固定评论均值、位置、训练尺度及其它条件后，令评论j恢复其原配置产生特征
增量u_j。当前分布差满足u_{i,j}=u_i+u_j；如果rho为线性，则：

    rho(u_i+u_j)-rho(u_i)-rho(u_j)+rho(0)=0.

无论Phi有多少谐波、多少单token高阶矩，这个混合差始终为0。增加局部表示
能力不能自动补齐集合层交互。反过来，若实际混合差小，线性汇总仍可能是
很有价值的近似，并不是因模型内部复杂就必须使用复杂读出。

两个评论均值保持位移d_i、d_j作用在不同状态位置。设G为固定后缀某个连续
标量输出，H0为背景，则：

    I_ij = G(H0+d_i+d_j)-G(H0+d_i)-G(H0+d_j)+G(H0)
         = integral_0^1 integral_0^1
             d_i^T Hessian G(H0+a*d_i+b*d_j) d_j da db.

后式需要路径邻域二阶光滑等常规条件；本轮用四个真实端点测前式，不以近似
Hessian代替观测。它是条件积分混合作用，不是全文通用固定耦合矩阵。

## 3. 内部混合作用与最终评分曲率精确分账

记录四端点候选logits z0、zi、zj、zij。共同logit平移不改变条件概率，因此
先投影掉全1方向，再比较内部向量作用。定义z_add=zi+zj-z0：

    I_score = S(zij)-S(zi)-S(zj)+S(z0)
            = [S(zij)-S(z_add)]
              + [S(z_add)-S(zi)-S(zj)+S(z0)].

第一项是超出可加logits的评分差，第二项是同一S造成的曲率。它们可以抵消，
不能把RMS之比称作独立方差份额。即使第一项为0，也不意味着全部内部向量
交互为0：某些方向可能被S抵消，所以同时保留中心化logit交互范数。

[Zhang与Nanda（2024）](https://arxiv.org/abs/2309.16042)和
[Heimersheim与Nanda（2024）](https://arxiv.org/html/2404.15255v1)讨论了patching
指标、参考及方向对解释的影响。本轮把这个建议落实成数值恒等式，而非只在
报告末尾加一句“可能受softmax影响”。

## 4. 条件也可能是上游信息的载体

块16的正文、模板和查询状态，都经历过前缀上下文化。将正文改成各评论均值
只作用于这些位置，不会抹去已流入其它位置的配置信息。于是：

    B = F(C(E),x0) = F(M_native,R_native,x0; layout).

其中M为正文均值，R为非正文的非P/Q状态。R的字面模板即使完全相同，数值
状态仍可能不同。不能把B的作者关联全部归给“平均词义”，也不能把R全叫噪声。
NEXT18以固定参考M0/R0、目标布局不变的四格，将B分成参考、正文、保留状态
及交互。参考只从旧四位参考作者取得，效标主表排除他们。

这些是独立操作坐标，不是自然统计独立变量。恢复两评论时，其原状态已经
包含上游跨评论信息；本轮检验的是剩余后缀的联合读取，而非所有层、所有
人类理解过程的完整交互。给定边界后，这仍是一个可直接开发的机制对象。

## 5. 与群体作者测量如何相接

GRAIN保持固定群体参照、条件选择、表达配置及真实时钟的测量对象。查询
读出另外给出各配置对指定判断的功能权重。两者可用同一作者材料连接：

    原文 -> 条件/位置/配置表示 -> 局部特征 + 联合读取 -> 查询评分
                     |                         |
                群体参照位置                人类效标联系

研究任务因此分层：测得一个作用，找其输入载体，构造可迁移读法，再观察与
作者外部指标的关系；不把任一层的拟合成功替换所有层的成功。
当前数值函数仍依赖原LLM隐藏状态，轻量输入提取是后继接口，不被本文略去。

对固定背景，全部评论子集作用可作Mobius分解：

    m(T)=sum_{U subset T}(-1)^(|T|-|U|) V(U),
    V(S)=sum_{T subset S} m(T).

这是有限集合的精确恒等式。十二评论的完整表有4096格；本轮只测预设相邻/
远隔两对，不声称已识别全部高阶项，也不为形式上的“全量”启动4096格队列。
实际下一函数的复杂度由已测作用决定，而不是由能写多少项决定。

## 6. 共享函数的几何不能只按矩阵范数定义

NEXT19/20已构造对称张量读法与R参照矩阵，见
[第十二轮报告](../reports/grain_vector_mechanisms/JOINT_CARRIER_READOUT_LOGIC_REPORT_V1.md)。
N两读法相对零交互降低约23%-26%混合logit误差，但训练对类型均值也很强；
相邻个体强度部分可读，远隔不改善。T/F完整参照矩阵误差/零=.854，原R作用
与自评的联系未被完整保留。不能用可写公式或低误差自动替代作者关联。

八个参照路径矩阵的共同均值占欧氏能量91.18%，仍不能推断共同函数保留
91.18%的实际作用。令g_u=vec(G_u)、d_u=vec(Ru-R0)，则：

    Phi_R(u) = g_ref^T d_u + (g_u-g_ref)^T d_u + integration_error.

即使||g_u-g_ref||很小，第二项相对总作用也可能很大。例如g_ref=(1,0)、
g_u-g_ref=(0,epsilon)、d=(0,1)，共同读法给0，而实际全部作用是epsilon。
绝对误差仍遵守Cauchy-Schwarz界；小绝对差异与完全遗漏个体差异并不矛盾。

对固定矩阵误差v，真正的平方作用损失是：

    E[(v^T d)^2] = v^T C_d v,    C_d=E[d d^T].

这里C_d是未中心化二阶矩，不是悄悄删除平均位移后的协方差。若矩阵差也随
作者变化，则须保留E[v_u^T d_u d_u^T v_u]，不能把相关的两者均值相乘。
因此参数空间的SVD能量最优，不自动等于源材料上作用预测最优。

进一步，对共同读法g的平方损失L(g)=E[(Phi_R-g^T d)^2]，正规方程是：

    C_d g = E[d Phi_R].

平均梯度g_ref=E[g_u]一般不满足它；需要额外的独立性/权重条件。用固定
参照状态作有限样本的作用加权校准是一个新的可检验连接，而不是声称矩阵
平均已经有最优性。参数量高于参照人数时应保留低维可识别支持和显式正则，
不能从四个参照人物恢复任意136x1536矩阵。

以平均梯度为先验中心，一个明确定义的下一候选为：

    g = g_ref + D^T (D D^T + n*lambda*s^2 I)^(-1) (phi-D g_ref)
    s^2 = trace(D D^T)/n.

D的行仅是参照作者位移；phi仅是模型实测作用，不是人格标签。修正局限于
已观察位移张成的空间，其正交补保留g_ref；这给出明确的可识别性与失效边界。
此候选已由NEXT21执行，见下节；下文保留其支持边界，不升级为全域最优。

## 7. 已测校准与位移相关的曲率

[第十三轮](../reports/grain_vector_mechanisms/ACTION_GEOMETRY_LOGIC_REPORT_V1.md)
完成上述唯一候选：相同20人作用误差/零从.853553降到.813729，相对下降
4.67%，配对区间跨零。其余作者的ridge软参照支持均值仅.009129：

    support(d)=d^T D^T(DD^T+eta I)^(-1)D d / (d^T d), eta=n*lambda*s^2.

eta>0时它在[0,1]内，是正则投影的作用范围描述，不是人格可解释率。
修正只在row(D)内；n=4给出的有效自由度约2.912，不能凭208896维输入宣称
辨认了同样多的独立作用。这个先验中心化最小二乘是
[Scholkopf等（2001）biased regularization](https://alex.smola.org/papers/2001/SchHerSmo01.pdf)
的有限维实例，不作为GRAIN原创定理。

现在把每个人的积分矩阵进一步拆开。定义J_u为固定M0/R0/x0和目标布局L_u
处对R的梯度；H0u/H1u分别为M0/M_u条件下沿R0到R_u的积分梯度，则：

    G_u = .5*(H0u+H1u)
        = J_u + (H0u-J_u) + .5*(H1u-H0u).

对每项减去参照均值并与本人位移d_u收缩，分别得到布局起点、R路径、正文
条件三项的偏差作用。本轮RMS=.002606/.014656/.000223。这里布局固定的是
各作者自己的计算布局，不是所有人的布局相同；后两项则有明确的同布局
路径对照。分项相关且会抵消，不能按矩阵范数或RMS直接分配独立心理份额。

如果F在该R线段上二阶连续可微，积分梯度项又有精确形式：

    Phi_R(u) = J_u^T d_u + Curv_u + .5*(H1u-H0u)^T d_u,
    Curv_u = integral_0^1 (1-t)
             d_u^T Hessian_R F(M0,R0+t*d_u,x0;L_u) d_u dt.

它来自梯度的微积分基本定理再交换三角区域积分，并不需要假设全局二次
函数。本轮已经用一阶梯度积分量化Curv_u；尚未直接估计整张Hessian。
存储的路径积分有NEXT20记录的数值误差，端点总账保留该误差而非强制归零。

一个明确的下一对象不再是固定g，而是**给定条件、随着d变化的响应函数**。
例如局部近似J(L)^T d + .5*d^T H(L)d，或对可识别投影的非线性读法；是否
需要它、其曲率是否共享，必须由实际路径作用决定，不能只因写得出H而引入
高维自由参数。原共享线性程序仍是已测基线和可用的一阶部分。

数学反例测试说明：精确零均值的d_u可有非零均值二次作用，而任意共同齐次
线性读法平均都为零。当前真实d_u只是浮点近零均值、第四奇异值非零，故
不能据此声称任意系数的线性拟合在数学上绝对不可能；极小方向上的巨系数
拟合与稳定支持内的可用读法不是同一个命题。实测分项而非该极限独自支持
本轮的路径曲率方向。

## 8. 输出方向的线性操作与非线性统计不可混同

对固定训练方向v、中心化混合logits m，定义a=v^T m、r=m-av。因为v单位化：

    ||m||^2=a^2+||r||^2,
    ||m-m_hat||^2=(a-a_hat)^2+||r-r_hat||^2.

NEXT22中相邻共同方向在训练折间cosine=.982，评估能量62.93%沿此方向。
bag/position幅度的折内相关为.501/.363，证明有超出折间共同均值的可读
变化。远隔的明显负pooled相关大部分属于折间均值分量，不应写成逐人反向。

最终S映射的解析梯度为p*(values-S(z))。本次真实内部作用的Taylor余项RMS
仅为实际RMS的约.36%/.09%，因此最后评分曲率不是这两对缺失读法的首要
修复点；精确S仍保留，不据局部小余项宣布它处处线性。

固定核Ridge对输出矩阵Y是线性算子A，故(A Y)v=A(Yv)。单独再拟合同一
投影目标不会比投影原预测更好，除非改变输入、惩罚或训练规则。相反：

    E[||m||^2 | x] = ||E[m | x]||^2 + trace Cov(m | x).

此式在条件二阶矩存在时成立。能量与条件均值向量不同，可以给下一步发现
一个新的可计算对象；其中条件协方差相对于当前输入x，不能直接叫不可约
心理噪声。当前尚未由本轮识别它，也不将其存在当作人格效度。

完整模型、条件B、局部作用以及轻量输入之间的依赖见
[全输入契约](GRAIN_CONDITIONAL_INPUT_DEPENDENCIES_V1.md)。
