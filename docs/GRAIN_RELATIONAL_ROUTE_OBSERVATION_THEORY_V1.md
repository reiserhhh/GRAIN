# GRAIN：关系信息的载体、运算与作者测量

2026-10-09。HM74/HM75实际结果后的理论推进。
本文不把群平均、有限展开、激活干预或Jensen差当成新数学定理。

## 1. 精确复制答案不能识别机制

给定g∈{-1,+1}，令正文载体B=g、查询载体S=g。三个读者：

    R_body(B,S)=B
    R_suffix(B,S)=S
    R_redundant(B,S)=B+S-B²S

在全部自然输入上都输出g，教师保真可以同时为100%。但只平均正文后，
第一读者归属作用消失，第二、第三保留；只平均查询后反之；同时平均后
三者均消失。第三读者与前两者还有不同的联合操作余项。

所以提高同一自然支持上的预测精度，并不一般增加机制可识别性。新信息
来自能区分候选实现的操作，而不是进一步压低已经相同的自然答案误差。
这些玩具读者是可检查的反例，不是声称真人或LLM恰好使用这些函数。

可以把这个问题写成观察算子的识别边界。令自然输入的支持为M，

    O_M(R) = R|_M
    R1 ~_M R2  iff  O_M(R1)=O_M(R2)

自然答案只确定这个等价类，不确定类中的内部实现。在上述例子中M是
B=S=g的对角集合；R_body-R_suffix=B-S在M上恒为零，因此再增加同一
支持上的样本、把答案拟合到任意精度，都不能区分两条路线。

增加声明的干预集合P后，观察对象变为

    O_(M,P)(R) = {R(PH): H in M, P in P}

它可以细分原来的等价类。只将B平均到0就把三个读者中的正文读者与
另两者分开；再平均S可分开查询读者，联合余项则保留冗余实现的差别。
这是有限设计的可识别性论证，不等于任意模型已被唯一识别。实验中仍须
说明干预触及什么、哪些变量不变，以及未自然出现的切口值怎样被读取。

## 2. 对同一证据建立载体与操作两层

固定x/y内容和g归属，切口表示H_z=(B_z,S_z)，实际目标读取为

    F_q(z)=R_q(B_z,S_z)

B是完整查询之前的状态，S是已读过证据的完整查询后缀。它们不是两份
互相独立的新证据；S可已经携带B在更早层的运算结果。不可把两侧作用相加
当信息量或心理成分百分比，也不能把查询载体存在误读为信息来自prompt。

两个固定操作：

    P_B H_z=(average_g B_z,S_z)
    P_S H_z=(B_z,average_g S_z)
    P_B P_S=P_S P_B

平均只沿已声明的g反事实，保留x/y内容与状态的g-even部分。是有限C2群
投影，不是以“相似部分就是噪声”为前提的降噪算法。

即使状态操作交换，F_q、F_q∘P_B和F_q∘P_S的输出效应也可以相互调节：

    I_q=F_q-F_q∘P_B-F_q∘P_S+F_q∘P_B P_S

I_q是联合操作的有限四角差，不是自动成立的Lie交换子、唯一路径或新因子。
输出可以通过未删的主效应/其它交互/正文内容及上层非线性形成新的组合。

## 3. 两侧归属平均的零是控制，不是新发现

在固定x/y下，g伙伴的token长度、位置、完整后缀和上层因果mask相同。
同时平均两侧后完整切口完全一致，因此上层确定性读取必须给相同输出。
其g-odd输出系数为零是操作定义的直接后果。

真正要研究的是：只平均一侧时的作用，以及查询已去yg/xyg后，正文归属
平均相对等范数随机扰动的额外作用。它们区分哪种保留输入参与了读取。
如果正文归属平均不改变输出，仍可能依赖正文x/y内容；不能宣称无需正文。
如果查询平均仍有作用，也不能忽略正文向查询更早层传输的历史。

## 4. 保留状态均值不等于保留观察均值

沿一对归属伙伴，记H0=(H+ +H-)/2、d=(H+ -H-)/2。定义

    J_q(x,y)=[R_q(H0+d)+R_q(H0-d)]/2-R_q(H0)

J_q量化先读后平均与先平均后读的差；现有有限表就能计算，不需要更好的
回归器。若采用理想实数C²读者，其精确表达为

    J_q = 1/2 * integral_-1^1 (1-|t|) dᵀ Hessian(R_q)(H0+td) d dt

这是标准一元Taylor积分恒等式。实际浮点模型本轮不读取Hessian，不能把
该表达声称为已测得的神经曲率或人格因子。有限差可以保留为真实观察对象。
常量读取、均值、主效应都应单独保存；组平均不是免费去掉无用成分。

## 5. 接回作者而不是停在模型内部

对声明证据单位上的作者组成P_u(z)，固定查询观察律：

    m_u,K=E_Pu[chi_K]
    Theta_u,q=sum_K m_u,K*c_K[F_q]
    Delta_u,q(P)=sum_K m_u,K*c_K[F_q-F_q∘P]

在固定参照P_ref下，相对作者位置及操作后变化分别用m_u-m_ref替代m_u。
这使“哪种关系被读取”与“一个人的证据如何组成”能在同一公式连接。

共同读者R_q、作者文本分布P_u、个人条件响应B_u不是同一变量。P_u含
选择、机会供给、报告与场景；不能仅凭组成差异就称其为心理偏好。
需要保留GRAIN的选择/条件/状态分层，不能把多目标读者分数取代整套测量。

## 6. 主线增量与下一层

HM74已经发现显式查询yg参与，而去同名xyg后功能交互大幅保留。HM75
3234实际干预及异式复算完成：只平均正文归属，目标优势RMS保留95.66%；
只平均查询归属，只剩4.85%。后缀已删yg/xyg再平均正文归属时，输出xyg
仍保留原删除臂的96.98%中心化logit RMS，score为100.80%。这不是人格r。

理想精确算术下，B_even在每个固定x/y背景中不随g变；S_low的固定后缀
相对坐标保留g/xg，不保留yg/xyg。跨x/y正文可变长度，不把B强写成同维
字符展开。上层操作须保留该背景的实际长度、位置与因果mask。因此归属
变动可通过后缀保留g/xg进入，与x/y内容及信息机会共同产生yg/xyg输出。
实际float32存在小舍入残留，未估计全上层误差界。
这一结果将测量对象推进为来源/目标/条件索引的关系操作，而非强制寻找
一根同名交互向量；不唯一识别所有上层计算或把共用读者当个人响应Bu。
结果决定下一次独立计量的对象是静态sector、条件化操作，还是两者组合。

从有限机制走向无LLM新文本计分，还必须使事件资格/归属操作不依赖待测
文本的完整反事实八格，并检验跨材料运输。不能以当前已知表上的精确代数
重建替代这一要求。自然作者与心理意义及原18/100/44范围继续保持开放。

## 6a. 观测工具升级的主线准入条件

精度工作只有在改变以下至少一个决策时才进入下一有限包：

1. 两种候选机制目前因工具误差不可区分，升级后有预定的区分操作。
2. 现有读数混合了作者/他人、事件/复述或条件/状态，修正会改变计量对象。
3. 冻结操作从来源材料移到新材料后失效，修正能解释运输条件而不是仅救分。

这三个条件也要列出有限停止点。达到区分下一机制决策所需的读数后，应
转回证据单位、目标操作及作者组成的理论构造，不追求观察误差归零。
教师保真、语义解析准确率、真实人格预测效果和机制识别分别报告；前两者
不能代替后两者。工具已有成熟实现时先复用，不以重新发现成熟算法当创新。
