## 1. Distinguish the object from its observation

Let x be one fixed article, z its retained task message, o a new choice
opportunity, and pi the option order. The native object in this experiment is

    q_z,o,pi(x) = R(x,z,o,pi).

It is a frozen local model's choice probability, not the article author's true
trait or observed human action. The article's original production task/style
g, the now-intervened history z, and the new opportunity o are different
variables. The source g blocks stay fixed when z changes. The system/style
message also stays fixed. Some z/body pairs are genre-incompatible and are
explicit counterfactual histories, not naturally occurring writer events.

Replacing the prior message also changes its token length and downstream token
positions. This finite intervention does not isolate semantic task meaning
from generic history, position or genre-compatibility effects. A joint response
here is a property of the registered history manipulation, not proof of a
uniquely semantic or personality-specific internal mechanism.

The GRAIN representation v = Phi(x) is unchanged by the registered intervention.
Thus a nonzero response difference at the same v is not an embedding precision
defect. It is a distinction in the observation arguments.

Importantly, this does not rule out a stable latent author attribute theta:

    R(x,z,o,pi) = G(theta(x),z,o,pi)

can have strong interactions even when theta(x) itself is invariant. Observed
response dependence, latent attribute change and psychological interpretation
must not be conflated. HM167 does not identify theta or the function G.

## 2. Three mechanisms, not three optimized predictors

For a registered low/high article pair, denote old log odds by a_-/a_+ and
common-task log odds by b_-/b_+. Define

    s = [(b_- - a_-) + (b_+ - a_+)]/2,
    I = [(b_+ - b_-) - (a_+ - a_-)]/4.

Body sufficiency requires b=a at this support. A shared-offset account permits
b=a+s while I=0. A body-context interaction has I nonzero. These are statements
about the finite observed response law, not exhaustive neural mechanisms.

The binary link sigma may change a probability gap under a shared log-odds
offset. The signed account is

    gap(sigma(b))-gap(sigma(a))
      = gap(sigma(a+s))-gap(sigma(a))
        + gap(sigma(b))-gap(sigma(a+s)).

The first term is the offset/link contribution; the second is the joint
remainder. Neither is an independently identified causal mediation fraction.
Both signs and both option orders remain in the finite analysis.

## 3. A representation fiber obstruction

If an unchanged article receives q0 and q1 under two registered histories, one
body-only output f(Phi(x)) cannot equal both unless q0=q1. For equally weighted
histories, its smallest pointwise squared discrepancy is

    min_f [(f-q0)^2+(f-q1)^2]/2 = (q1-q0)^2/4.

This is elementary conditional-variance geometry, not a new theorem. It is a
descriptive obstruction to reproducing both protocol outputs with one body-only
readout. It does not establish an irreducible personality error, limit latent
trait scoring, or justify optimizing that discrepancy to zero. A richer body
representation still has the same input at both histories; an indexed observer
is a different construction from making the encoder more precise.

## 4. Executable source-supported functions

Use only actual source responses and fixed article vectors. For each z/o/pi,

    C_z = Cov_source(Y_z,Phi),
    T_z(v) = <C_z,v-mu_source>.

There is no persona-label orientation, inverse covariance, application-answer
fit or fitted probability calibration. This is a cross-moment witness, not an
identified conditional expectation or a probability estimator.

For the same source reference and fixed production blocks g,

    C_z = sum_g p_g Cov(Y_z,Phi | g)
          + Cov_g(E[Y_z | g],E[Phi | g]).

The within and between terms are both retained. Their opposition is a source
composition property, not a reason to discard context or choose the better
component after observing results. With source features/reference unchanged,

    C_1-C_0 = Cov_source(Y_1-Y_0,Phi),
    T_1(v)-T_0(v) = <C_1-C_0,v-mu_source>.

HM167 constructs original9/common9/delta3 fixed algebraic accounts. All108 cold
article readings were sealed before the new application outputs. These21 arms
are an accounting family, not a hyperparameter search or21 independent trials.

A coefficient difference alone is not evidence of body-context interaction.
For example, a shared log-odds offset s_g within each production block can
change the between term when blocks have different feature means. Probability
cross-moments can also change through sigma alone. The native paired log-odds
interaction must therefore be read separately from the vector witness change.

## 5. Relation to the measurement mainline

The positive construction is an observation-law-indexed numeric function
family on the SAME article IDs. The next scientific decision depends on whether
the context effect is an offset, interaction, or both, and whether the source
delta function has a signed correspondence on new article responses. Better
cosine alone is not the promotion criterion.

If a common-task function transports poorly, do not rescue it by changing
prompts, reference cohorts, signs, ranks or source components. Keep the failure
and determine which variable/interaction the current observation interface
does not describe. Stable person attribution and human behavioral meaning are
separate remaining constructions. Model histories do not supply them by name.

## 6. Existing mathematics and inspiration

- Song et al. (2009), Sections3-4, defines conditional distribution operators
  indexed by conditioning arguments. Cross-covariance is not automatically a
  conditional-mean operator; inverse/range assumptions matter. HM167 uses only
  finite cross-moments and does not inherit its conditional-mean guarantees.
  https://alex.smola.org/papers/2009/SonHuaSmoetal09.pdf
- Geiger et al. (2025v4), Section2.4, permits graded causal abstraction but
  distinguishes state correspondence from faithful mechanism transformation.
  A prior-message intervention here is not a unique identified neural circuit.
  https://arxiv.org/html/2301.04709v4
- Gilg et al. (2026v3) already studies persona-dependent preferences, context
  components and probe/steering distinctions. The general discovery that a
  context changes preferences or that a vector predicts choice is not novel.
  https://arxiv.org/html/2605.13339v3
- OpenAI/math adc7f124, Thorp manuscript section05, fixes an array before
  changing conditional reveal laws and treats repeated labels separately.
  This is design inspiration for separating evidence and observation law.
  Its independent line permutations, density bounds and spectral assumptions
  have not been established for GRAIN; no theorem has been transferred.

The candidate contribution is the tested same-event GRAIN construction and
its measurement implications, not the discovery of covariance, sigmoid
curvature, conditional variance, or conditional observation laws themselves.

## 8. The construction left open

An observation family T_z(v) is different from a transferable response action

    A_(z0->z1,o,pi)(x) = R(x,z1,o,pi)-R(x,z0,o,pi).

The starting messages differ across source discovery and application writing
tasks;the common destination alone does not make these identical transitions.
Production condition,starting observation context,destination and new opportunity
must retain separate identities before estimating a common action. The current
delta covariance is an observed finite difference,not an identified operator
acting on arbitrary latent person states. Do not tune it into a universal rule.
