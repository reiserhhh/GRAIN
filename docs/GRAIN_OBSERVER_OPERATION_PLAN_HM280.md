## Mechanism decision, not an accuracy experiment

The model's archived generative self-description and the SOURCE criterion
function are different observations. HM255 already tried binary item judgments
on OTHER evidence and A/C; repeating that alone is not a new method. This
packet adds a controlled OPERATION contrast on SAME actual events: judging
the author's usual behavior versus behavior expressed by this sample.

Two competing operational explanations are considered:

1. Both contracts use the same sample-expression evidence; their difference is
   only a context-independent item offset. Their two-event joint departures
   must then be equal, even if their absolute endorsement levels differ.
2. The requested object changes evidence integration. Their joint departures
   differ on unchanged comments/items, and the SOURCE-qualified contacts can
   differ without changing geometry, labels, weights or signs.

The contrast can reject only the specified offset explanation, not all generic
prompt effects. It does not prove the usual-author contract really measures
human trait, or the sample contract human state. Those are requested objects.
No favorable sign or larger accuracy is an acceptance criterion. The new useful
interface binds the same evidence to two explicit measuring operations and
exports their final hidden states and fixed binary output covector.
