# 真实作者文本中的条件预测联系

2026-10-13，HM257。本文件先固定数学解释，观测结果另列。
方案见 `GRAIN_AUTHOR_PREDICTIVE_LINK_PLAN_HM257.md`。
这是一项新增的同事件观察接口，不是新的条件概率定理。

## 1. 为什么不是再磨一个预测器

HM256 表明，在给定 persona 时生成文本与读文本判断 persona，并不自动
对应同一个联合概率模型。这里不再请求模型给出作者的性格答案，而是
保留实际作者写出的下一段文字，计算这段文字在不同倾向描述下的概率。

只有普通的“本人上下文让下一段更可预测”，仍可能只是熟悉内容、语域或
写作习惯。新的问题是：这个上下文作用是否随所观察的目标而变化？
GRAIN 的来源目标场与这些概率作用绑定到同一评论，分别计算，不能把
其中一个的结果拿来拟合另一个，再宣布得到相同心理意义。

## 2. 有地址的观察单位

一个单位包含作者 u、上下文事件 a、完整目标事件 b、来源窗口、真实时间、
情境类别、上下文观察方式 m 和假设 h。把某个评论用于两个相反方向，不会
增加作者样本数。本人、陌生人和 token 逆序的上下文也不是三个新作者。

本轮使用 24 位历史公共作者；每人从前两个评论窗取一个完整同粗条件评论
对，保留两个方向。陌生上下文采用固定长度/粗条件约束和 E5 最小匹配；
0 个陌生上下文与本人处于完全相同 subreddit。因此这是粗条件比较，
不是对主题、场景或所有作者背景的完全控制。匹配还可能同时匹配作者信号。

原文不掩蔽、不截断；48 个本人评论连同陌生上下文共 92 个实际评论。
计分使用完整目标的原生 token，而不是重新生成的答案或32token文章开头。
输入模板和神经模型属于观察仪器；它们不是已识别的人类语言生成过程。

## 3. 明确计算的目标与上下文交互

令 b=(x_1,...,x_T)，在冻结输入序列化下定义

\[
\ell_h(b\mid a)=\sum_{t=1}^{T}\log p_\theta(x_t\mid h,a,x_{<t}).
\]

每个目标 q 有一对预先规定的行为倾向描述 H_q/L_q。
不使用人格名称词作为输出选项，也不搜寻表现最佳的描述。

\[
L_q(b\mid a)=\ell_{H_q}(b\mid a)-\ell_{L_q}(b\mid a),
\]

\[
T_q(b;a,f)=L_q(b\mid a)-L_q(b\mid f).
\]

f 是匹配的陌生上下文。另保留

\[
O_q=L_q(b\mid a)-L_q(b\mid\operatorname{reverse}(a)),\quad
K_q=L_q(b\mid a)-L_q(b\mid\varnothing).
\]

这是目标条件与上下文条件的有限混合差分。若

\[
\ell_h(b\mid a)=U(b,a)+V_h(b),
\]

则 T_q 恒为0，即使中性条件下本人上下文有很大的预测增益。
因此非零 T 排除这个严格可加、目标无关的上下文机制。
它不排除目标描述与文法、内容、token 位置共同交互等更宽的机制。
高/低描述长度本身也可能不同，不能把 T 直接称为纯人格作用。

逆序保留本人 token 多重集合；非零 O 排除纯词袋的上下文作用。
逆序并非自然文本，也可能破坏文法。reset 改变上下文长度与绝对位置，
故 K 不是独立识别的“记忆信息量”。所有这些因素保留在观察合同中。

## 4. 实际向量运算，不是抽象相似度替代

给定位置 t，输出词汇 covector 为 W_{x_t}，冻结头部偏置为 b_{x_t}。
令 h_{q+,m,t}/h_{q-,m,t} 为相应条件前向得到的最后层状态，则

\[
T_q=\sum_t W_{x_t}^{\mathsf T}
\left(h_{q+,own,t}-h_{q-,own,t}-h_{q+,foreign,t}+h_{q-,foreign,t}\right)
-\sum_t\Delta_q\Delta_m\log Z_t.
\]

偏置在四角差中抵消；Z_t 是全词汇 logsumexp 的指数归一化项。
第二项不是噪声，可能削弱或反转第一项，必须连同 signed 交叉项保留。
每个实际 token 的 W 不同；因此不是一条对全部文本固定的人格轴。
这里测的是完整条件前向差，不是已定位的单个注意力头或因果中介。

已有观测后的加减、收缩和逐 token 计分可以由不加载 torch 的独立 CLI
执行。获取 h 和全词汇归一化仍需要冻结神经模型；不能说已完全脱离 LLM。

## 5. 与 GRAIN 的接点

同一实际评论已有冻结 E5 表征和 GRAIN15 坐标。来源386作者与当前24位
目标标定作者不重叠；历史表征发现仍有17位重叠，不冒称全新的盲锁箱。
沿用八个条件/坐标单元的来源场

\[
W_q(c,s)=\psi_q(c,s)-\pi_q,
\quad \mu_q(c)=E_R[W_q(c,s)\mid c].
\]

保留 W=mu+(W-mu)，不把条件选择删为噪声。两份本人评论的平均场
与双向 T 的平均在作者层形成完整5x5 signed 接触矩阵；同时保存15坐标
的全部接触。它们是来源概率对比单位乘模型 nats，非心理相关 r 或 AUC。

这里将“来源支持的目标意义”和“模型条件作用”放在同一证据地址上比较。
同名正接触是这个具体接口的正面联系，负接触是接口差异；任何一个都不能
单独被提升为人类人格效度。双向平均只描述两种观察方式，不消除时间作用。

## 6. 成熟数学与本轮新增内容

- [PICLe (2024), Sec3.1](https://arxiv.org/html/2405.02501v2)：已有 persona
  似然比和示例选择；这里没有实现其 LoRA/PersonaSFT，也没有选择最佳例子。
- [Nini et al. (2024), Algorithm1/Sec4](https://arxiv.org/html/2403.08462v1)：
  作者/参考总体模型的逐 token 似然比已有研究。其司法语法掩蔽目标不同，
  不能照搬为本项目删除内容的准则。
- [Huang, Murakami & Grieve (2025)](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0327081)：
  作者语言模型和相对逐 token 证据已有研究；内容词的具体用法可以有作者
  信息，词类频率与单次 token 用法不等价。这里不训练每作者模型。
- [OpenAI/math 三态通道 foundations](https://github.com/openai/math/blob/adc7f1241b42e322a6451854ab7e4b4c146bf78a/preprints/The-exact-reconstruction-threshold-for-the-three-state-symmetric-channel-September-25-2026/build/sections/02-foundations.tex)：
  217-232行的退化序需要与目标输入无关的 Markov 核；166-215行的枝组合
  需要条件独立。这些条件在 persona 条件上下文编辑中不成立，不移植其
  Jensen 信息序、树重构阈值或“去噪保证”。有用的是显式声明观察律的思想。

新增的是本项目可执行的真实评论、目标条件、本人/匹配陌生上下文、逐 token
向量账户与 GRAIN 来源场的共同接口。条件概率和混合差分本身并非首创。
它是否推进主线，由实际目标交互及其来源联系判断，不由准确率或测试数判断。

## 7. 实测与后续决定

全部528批/2112条件序列已一次完成，797.402866模型秒；一次额外原生前向
兼容检查同样计入唯一1600秒上限。所有单位保留，没有新生成、答案拟合或重跑。
典型本人/陌生人目标交互的逐方向RMS为 .5280--1.2462 nats，明显大于
原生读数差3.3379e-5。本人 token 逆序的目标交互也存在，RMS .5357--1.7992。
中性条件本人预测增益均值为3.904659/.610176 nats，分别19/24、16/24为正。
因此严格目标无关的可加上下文解释不足；不能仅以中性增益代替目标作用。

本人/陌生人交互与同名来源场的全部作者层接触为：

| 目标 | full | 条件选择 choice | 条件内 within |
|---|---:|---:|---:|
| E | +.0106694 | +.0053054 | +.0053640 |
| N | +.0012252 | +.0001418 | +.0010834 |
| A | -.0021585 | +.0006195 | -.0027780 |
| C | -.0005510 | -.0000040 | -.0005470 |
| O | +.0026899 | +.0034617 | -.0007719 |

单位是来源概率对比乘模型nats，不是r、人格方差份额或显著性。
full=choice+within 是精确 signed 账户，误差5.20e-18。
O 的总体同向联系由选择部分承担，条件内联系反向；两部分不能合称噪声。
E/N两部分同向。A/C反向保留，不能把3/5正解释成五目标有效量表。

预设双向平均之外的完整方向描述另封印，属于结果后分析：
E/N/O在两个方向均为正；A均为负；C为-.0012513/+.0001493。
不同比较合同的同名接触（E/N/A/C/O顺序）则为

    own - reversed: -.0087807,+.0029131,+.0012785,+.0003604,-.0051578
    own - reset:    -.0164635,+.0004572,+.0006498,+.0093235,-.0096979

不能把存在向量作用、某项总量很大或另一比较更好当作同一测量意义。
四个固定位置区间的逐 token 账户也保存，存在相反区间，不能以总量猜测
一条统一路径。它们是描述，不是重新命名因子或优化窗口。

全词汇归一化使本人/陌生人交互的10个目标×方向均值中的6个改变了
selected-logit项原有方向。例如正向A为 .254170-.364476=-.110306。
所以“观察词的向量对齐”与“这个词相对其它词更可预测”不可混用。
这个 softmax 原理已知；此次补上真实同作者事件上的完整实测账户。

720个冷端四角、675个来源接触及所有stored selected-head向量复核通过；
head误差4.55e-6，cold/direct差3.31e-5，来源接触误差6.94e-18。
这是同agent异式审计，不是第三方盲复现。28项focused测试与6个Python
lint/format通过，旧SWIG警告保留。所有科学seal/旧输入不变。

下一步保留这条新观察接口，优先解释E/N的选择及条件内联系，与O的
选择联系为何不同；比较同一来源目标在不同观察合同下由谁承担，而不是
调概率、prompt、层/head或八单元参数来获得更多正对角。仍然需要识别
作者背景、内容、文法及不同描述长度的竞争解释；不能由本轮直接命名
神经“人格轴”、宣称已定位注意力头或提高真人人格预测准确率。
当前工具误差足够小，下一实验必须增加机制辨别能力，不增加精度网格。
