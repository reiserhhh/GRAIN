## Construction question

Can actual observed future choices orient a reusable GRAIN article function,
without fitting persona labels or consulting application answers? This is
different from improving activation-patching fidelity. The output is a signed
response witness, NOT a calibrated probability or an identified human trait.

HM165 contains 21 source pairs with all16 neutral-policy article-response
observations,42 articles. Eligibility depends only on capture completeness,
not response magnitude. They are a nonrandom E-only prefix: diary/email in all
three writing styles, opinion only neutral. Source N and the full source remain
missing. Use this exact available support openly, not as a completed HM165 source.

All54 development/evaluation pairs are addressed prospectively: both targets,
all styles/seeds, advice/review/neighbor.108 articles x4 opportunities x2 option
orders =864 observations. Only neutral current policy is needed to test article
evidence. We do NOT spend on the irrelevant high/low current-policy corners.
These are previously generated controlled texts followed by new local-model
choices, not new humans, continuous original sessions, or human temporal events.
Seeds are generation replicates. Refusals and generation truncations stay.

## Distinguishable explanations and decisions

1. Source response functions retain article-specific response structure in new
   writing tasks. Matched source functions should align with new pair response
   differences, including the within-source task/style component, beyond the
   fixed conditional relinking comparators. This enables anonymous response
   scoring rather than merely reading the assigned persona label.
2. Source functions primarily encode old task/style composition. Between-block
   functions will dominate while within-block functions do not transport. Keep
   both; change the construction to condition-qualified evidence, not deletion
   of condition means or a precision/regularization rescue.
3. A function may transport only the balanced-order response, only order
   susceptibility, or neither. Preserve even AND odd. Do not equate the odd
   part with noise or choose the favorable probability/log-odds view afterward.

All cells and source-link comparators are reported. Direction/cosine are
descriptive mechanism accounts, not independent-person significance. A negative
result is informative; no automatic refit, embedding switch, kernel/rank/grid.

## Frozen finite construction

Use HM165's same article IDs and625 affine-tensor GRAIN features. For source
article i define Y_i[m,c,o] from native neutral-policy q/log-odds, m in the two
registered observation channels. Current persona high/low is NEVER an input.

    C = mean_i (Y_i-Ybar) tensor (Phi_i-Phibar)
    C = C_within + C_between
    C_within = sum_g sum_i_in_g (Y_i-Ybar_g) tensor
               (Phi_i-Phibar_g) / n
    C_between = sum_g n_g (Ybar_g-Ybar) tensor (Phibar_g-Phibar) / n
    T[m,c,o](v) = C[m,c,o] dot (v-Phibar)

g is source writing task x writing style. Keep total, within, between, and
the additive-view projection of total in the SAME source units. The latter is
an ablation, not a new feature fit. No inverse, normalized-to-zero objective,
probability calibration, source-label fit, target-answer fit or tuning occurs.
Five predeclared cyclic response relinks (shifts1..5 within every6-article
source block) preserve each block's entire response-profile multiset. They
are comparators, not five independent trials or a valid exhaustive p-value.

Cold scorer receives numeric Phi and the sealed source program ONLY. A
standalone CLI produces all108 application readings before native outcomes.
Source/task/style/axis/seed metadata are used only in source construction and
later grouping, not as application scorer features.

    T_even=(T_o0+T_o1)/2; T_odd=(T_o0-T_o1)/2

Apply the same transformation separately to actual q and log odds. Do not
replace mean(q) by sigmoid(mean(log odds)). All16 opportunity cross-readings
(source function c -> actual response d) are retained as matched/mismatched
accounts; no cherry-picked endpoint promotion. Different units are not called
psychological fractions.

freezes all source functions; cold seals vector-only outputs; collect then
performs exactly864 new native choices at most. Full input-token equality
against every old captured input is forbidden. Batch32,480 model seconds

uses alternative pairwise covariance, explicit contractions and raw-logit tanh
accounts. Focused tests check decomposition, relinking, metadata-independent
scoring and the distinction between a witness and conditional expectation.

Acceptance means a frozen numeric response-construction interface plus an
honest new-response test, not a positive accuracy threshold. Scientific answers
and scope completion are separate. Original human validity/mainline18/100/44
