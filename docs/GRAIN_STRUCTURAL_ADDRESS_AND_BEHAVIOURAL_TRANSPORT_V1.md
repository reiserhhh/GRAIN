## The attempted interface

For a declared record endpoint e, the frozen pretrained observer produces a
block15 state h_e and block17 value carrier v_e. A source-fitted PLS program
decodes two structural indices; existing six-target covectors read the value:

    b(h) = ((h-center)/scale) C + beta
    i_hat(e) = nearest_legal_grid(b(h_e))
    s[e,q] = sum_head v[e,kv(head)] dot d[q,head]
    A[i,e] = 1{i_hat(e)=i} / count[i]
    S[i,q] = sum_e A[i,e] s[e,q]

Empty cells are unobserved, not zero. A is defined only on its observed rows.
Roster/field indices are not real-world identity, psychological constructs or
unknown-document event IDs. The cold scorer uses NumPy and numeric inputs, but
its upstream h/v and target d depend on a pretrained language model. It is not
a fully LLM-independent psychological instrument.

## Necessary invariance for this particular pure-address module

The desired address stays fixed when a person's action changes but its declared
actor and condition do not. Write B=diag(1/scale) C, so b(h)=h B+constant.
Then exactly

    b(h + delta_h) - b(h) = delta_h B.

A pure-address linear program would need the relevant fixed-address content
variations to lie in ker(B), or at least remain inside the same rounding cell.
This is elementary affine algebra, not an original invariant-subspace theorem.
It does NOT require behavioural scores to be invariant: their change is often
the desired measurement. Nor does it imply every representation admits a
content/address direct-sum decomposition.

In24 matched assignment pairs, the declared roles and record slots stay fixed
while the first two people's action assignments change. Routing changes for
36/144 record pairs. Even48 records belonging to an unchanged third person
change5 assigned cells; their entity-coordinate RMS displacement is .108744.
Contextual displacement can therefore enter this adopted address program.
These interventions also change wording lengths/context, so this does not
identify one unique cause or a new psychological process.
