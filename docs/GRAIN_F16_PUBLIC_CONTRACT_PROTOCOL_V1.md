# F16-R03 public construction and transport contract

Frozen before the new public-interface application run, 2026-09-24.
This extends, rather than rewrites, the archived F16 numeric and text bundles.
Original F12/F16 protocols and 44+6 requirements remain authoritative.

## Construction and scoring

Support T1/T2/T3 for both numeric and controlled-text observations. A public
construction consumes a hash-pinned, already source-fitted bundle plus a brief.
It compiles a target-specific contract and packages the existing numerical law;
it does not claim to refit sources or constitute another independent builder.
The original source fit/reference construction stays in the source archive.

Required public fields include target_id, one of the original seven object
classes, invalidating_result, formula_version, observed_role, unit, frozen
reference_mu/sigma, source_hash, reader_hash, world_contract, scorer_code_hash,
support_rule, error_model, explanation_rule, time/condition/observation contracts.
Numeric and text readouts must never be interchanged because their target names
match. The public T3 class is predictive_state; retain the historical internal
future_response label in its immutable payload and disclose the mapping.

Derive these fields from a checked engine and payload, not free user labels.
Text reader identity covers material bytes/readouts, channel draws, alphabet,
qualification rate and reader-law version. Dynamic cached reader_hash must also
match its original material/channel digest. Numeric reader hashes retain the
original contracts. Confirm finite positive norms, complete model components,
source reference count and exact known target/plan. Reference scores must not
depend on the application batch. Cold loading checks an externally supplied
bundle digest, its nested payload digest, current code manifest and metadata.

Public requests contain only a matching observation contract and the engine's
allowed observed-data envelope. No targettruth/labels/parameters may be added.
Scoring uses bundle+request only; no source/app path is opened in cold inference.
Unknown engines, target substitutions, time-unit changes, wrong reader/source,
latent input fields and corrupted bytes fail closed, without value repair.

## Finite acceptance run

Three original seeds. Re-export all six numeric/text target routes from frozen
source bundles, with no new fitting. For text routes run all 200 application
authors per seed and target through separate cold processes, compare all engine
score fields to archived cold objects within1e-10. T2/T3 share authors and base
payload, not independent samples. Numeric target routes: first and last archived
application IDs per seed, full source/person integration. This is adapter
regression, not a new numerical calibration/accuracy experiment; preserve the
earlier full numeric evaluations rather than rerunning them for a new table.

For each route/seed check the first author alone, with a second author, and with
an extreme outsider; keep original IDs, then rename the same records to check
that identity is not a feature. Add negative cases for contract and payload
fields. Evaluate numeric current/future with the explicit-cutoff adapter,
including tail-missing and empty histories at the same requested time. Reuse
archived checks for unaffected original mathematics; do not claim second-agent
reconstruction. Save exact inputs, outputs, hashes, rejections and code snapshot.

## Matched transport remains required, not supplied by export

Next execute original F12 transforms (identity, global affine, conditional
affine, prescribed nonlinear), population shift and independent pilot100 split
60 fit/40 validate. Separate source/pilot/application, preserve missing anchors,
condition DIF and nonmonotone inverse failures. Apply calibration at the
declared observation or target level, never silently interchange them.

Text probabilities are not Gaussian response values. A transport at continuous
reader-output level must precede alphabet thresholding; if it occurs after
information is discarded, mathematical invertibility is not guaranteed. Freeze
the implementation and exact observation law before application scoring. Report
calibration uncertainty explicitly and compare original/matched/oracle mapping.
This paragraph is a required next design, not a completed text transport claim.

No new neural/API calls, training, private raw/MEPS data, remote runs, lockbox,
commit/push. Public schema closure alone does not close F16 or the full goal.
