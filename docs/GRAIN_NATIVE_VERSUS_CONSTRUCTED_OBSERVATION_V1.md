## Encoded evidence, observation and composition

For four designed corners a=(s,o), let J_V=(1/4)sum_a so V_a on the same current
token support. The constructed observer F_q(K,V) uses source-contrast d_q and
reference q. The native observation N_q also uses the full question, upstream
context, residual routes, later blocks, candidate logits and declared response
conversion. An algebraic product identity for F is not an identity for N.

The actual value intervention keeps all unselected inputs fixed and replaces
V_a by V_a-so J_V. Define, retaining all four characters,

    A_(q,j)(c) = (1/4) sum_a chi_j(a) [N_q(V_a;c)-N_q(V_a-so J_V;c)].
    a_(N,q,j)(c) = A_(q,j)(c) + a_(N_removed,q,j)(c).

This equality is an observation decomposition, not unique causal mediation.
It supports a finite current-value-to-native connection when actual effects
are distinguishable from the declared controls. Redundant routes and all
remaining native response are retained, not labelled noise.

For any supplied positive law P over actual corners, intervention changes the
author composition by sum_j m_j(P) A_(q,j), with m_j(P)=sum_a P(a)chi_j(a).
For P+/-=(1+/-0.5so)/4, the contrast change is exactly A_(q,joint). This is not
an empirical personality score: the supplied P is a designed evidence law.
An other-person-only report is not positive evidence about the target; forcing
a model to issue a digit does not repair missing target evidence.
