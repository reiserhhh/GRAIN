# 同一文本的局部势函数与完整判断：NEXT60

2026-09-11。数学构造与有限实证已完成；整体逻辑 goal 继续 ACTIVE。
本轮的 scalar potential 是可微标量函数，不是假定心理能量或物理守恒律。

## 1. 两条路线在相同 token 地址相交

GRAIN 提供文本的可测变化方向 D_f，查询读法提供同一 H16 上的梯度 g_q。
两者通过 tau_qf = sum_t <g_qt, D_ft> 相交。不是先给因子命名再编心理解释，
而是检验同一处表达变化是否沿查询函数发生作用。

NEXT59 已表明旧均值输入看不见的重要部分是 token 间配置。NEXT60 实际
开发了保留这些地址的统一函数，评分和导数不再分开拟合成互不兼容的程序。

令 U 为源梯度密度的 rank8 正交基，S=diag(s_z)，
z_t=S^-1(U^T h_t-mu)，p_t 为固定三阶 Legendre 位置描述。候选为：

    Lhat_q(H) = b + a^T mean_t(z_t) + beta^T z_last
                + mean_t phi_q(z_t,p_t)
    phi_q(v) = sum_m c_m exp(-||v-l_m||^2 / (2 bandwidth^2)).

所有 U/mu/S/l_m/bandwidth/系数均来自另外的源作者。当前作者只提供 H16、
固定位置与 GRAIN 方向。源4逐人用其余3人构造，新8用全部源4；24上下文、
2查询、4方向。新8是未参与这次拟合的旧暴露材料，不是新独立样本。

匹配对照将最后一项换成 phi_q(mean(z),mean(p))。参数数目、源目标、惩罚
相同；本轮在这一 rank8/源参照下只比较非线性与聚合的先后。

## 2. 同一个函数如何同时给出分数与路径作用

    Khat_t = T * dLhat/dz_t = a + partial_z phi_q(z_t,p_t)
    ghat_t = U S^-1 Khat_t / T
    tauhat_qf = sum_t <ghat_t, D_ft>.

列向量写法对应代码行向量 `(Khat / s_z) @ U.T / T`。
原生教师在归一化坐标中的目标密度为 `K=T*(g @ U)*s_z`，不是除以 s_z。
末 token 的导数另为 `U S^-1 beta`；本轮 BODY 方向不移动末 token。
有限差分覆盖两部分，真实缓存192次 BODY 方向验算最大误差3.07e-10。

令 D_alloc,t=D_t-mean(D)。均值项 a 的作用严格抵消：

    tauhat_alloc = mean_t <U S^-1 partial_z phi_q(z_t,p_t), D_alloc,t>.

这是局部读取权重与文本配置的同地址配对。均值后非线性对零均值 D 的
导数严格为0；均值前非线性一般不为0。无需语言化推理即可在冻结向量上
计算此作用。不过 h_t 仍由神经前缀产生，本文没有宣称无编码器的生文本推论。

## 3. 数据支持了哪一层

新8的候选配置作用与原生配置作用：N r=.486409，确认寻求 r=.086785，
对应 SSE/zero=.952090/.992433；查询差值 r=.571306、SSE/zero=.924365。
候选因此确实读到了原均值函数无法读取的一部分方向。响应幅度仅为原生
配置 RMS 的约4.76%/2.84%，不能用较高局部相关遮盖幅度不足。

完整 L 的新8 r=.533976/.546934，SSE/sourceconstant=.782701/.744320，
两者都保留了实用的原模型判断关系；对照也有 r=.540951/.543761。故完整
评分关系不是“非线性前置”单独带来的突破，也不是新的真人量表相关。
完整 tau 误差比对照低6.66%/2.13%，但 SSE/zero 仍1.152543/1.181391。
本轮开发保留，整体替代未晋级，不能把一项完整评分成功当作全部路径成功。

源 U 内原生梯度投影在新8的 tau r=.851014/.808190，说明该固定子空间
仍含可用的局部作用。它使用当前原生梯度，是评价用容量诊断，不能部署。
正交投影对完整梯度的最小二乘意义成立，不保证每个 D 上的作用误差最小；
其查询差值 SSE/zero=1.222081 正好提醒：每查询的好结果不会自动继承到差值。

## 4. 下一条逻辑缺口不是缺一张更大精度表

所有源拟合的梯度密度标准化误差仍大于1，连源数据的密度场也没有读好。
可能是标量势函数的导数字典不够表达，也可能是评分约束、梯度目标和系数
惩罚争夺同一组系数。仅凭新8误差不能区分二者。

NEXT61将固定全部输入、基底、字典，直接分解源目标在导数字典列空间内外
的部分，再检查保持原评分不变的参数方向还能改进多少梯度。先计算能不能
表达、如何争夺，才决定改函数结构或改训练准则；不搜 rank/bandwidth/alpha。

## 5. 与前人及用户设想的连接

[Deep Sets](https://papers.nips.cc/paper/6931-deep-sets.pdf) 把逐元素变换与聚合
区分开，并允许条件信息。本轮是带位置/查询的有限核实现，不借其定理宣称
64个中心能表示所有集合函数，更不是把文本真的当成没有次序的词袋。

[Sobolev Training](https://arxiv.org/abs/1706.04859) 为同时利用函数值和导数
教学提供先例；[GDML](https://arxiv.org/abs/1611.04678) 展示可积梯度域学习的
价值。本轮直接参数化标量再求导，不是原 GDML Hessian-kernel 模型的复现。

GRAIN 同材料的测量与向量路径现在有了可执行的共同地址接口。将来做精神
分析/交流分析辅助解释时，可以引用该处的文本、变化方向与查询作用，而
不能仅从相关方向推出“这是某种防御/自我状态”。候选编码、证据定位与人工
解释仍是应用层；本轮未用新心理名词替换尚未闭合的读取机制。
