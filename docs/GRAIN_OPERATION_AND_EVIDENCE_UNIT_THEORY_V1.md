## Observed separation

For a fixed source vector d, let A_e(d)=D(B_e,C_e+d)-D(B_e,C_e), with e denoting
the complete receiver evidence and its contextualized query state at block16.
Source-oriented mean score action is .568316 on own relevant behaviour,
.491861 on other-person reports, .307412 on unrelated behaviour and .354862
on roster-only text. Random controls are .017622/.023169/.004946/.003157.
Candidate high-versus-low log-odds also retain large control effects.

Thus the tested operation has substantial portable directional action and
context modulation. Its action does not require directly stated, relevant
behaviour of the queried person. This is not evidence for an arbitrary-vector
effect, and not a rejection of the observed transfer.

Possible sources include answer-token steering, semantic judgement steering,
injected source evidence and a context-dependent mixture. A fixed vector
addition is not identified as a reusable evidence-reading procedure merely
because it agrees with natural ownership swaps in familiar materials.

## Measurement interface

An evidence unit E keeps reporter, actor, event, modality, condition, content,
and history separate. The measurement chain is:

    raw/vector observation -> E and purpose-specific qualification
        -> contextual observation operation -> declared observation unit
        -> conditional/reference-aware author aggregation

Qualification is not defined by a large activation norm, output score or
successful steering. A report about another actor may inform reporter choice,
context or state without counting that action as the reporter's own action.
Keep all context; do not delete every third-party report as noise. Missing
direct evidence remains missing, rather than a manufactured neutral/high/low
score. These are bookkeeping and estimand requirements, not a new theorem.

## Answer recoding as a mechanism contrast

Let kappa=+1 mean digit0=low/digit9=high and kappa=-1 mean digit9=low/digit0=high.
For the native digit distribution p, y_raw=sum(k*p_k)/9 and
y_sem=(1-kappa)/2+kappa*y_raw. With L_raw=log mass(5..9)-log mass(0..4),
L_sem=kappa*L_raw. These are exact readout-coordinate identities.

The next experiment keeps all evidence/actors/trait questions fixed and changes
only two instruction digits. It compares operations extracted under each code
and transported into both receiver codes. If conceptual action persists under
recoding, raw digit action should reverse; if raw digit action persists, decoded
conceptual action reverses. Mixed or code-conditioned outcomes are retained.

Native compliance with the inverse code is measured separately. A failure to
read the recoding is not evidence that a vector represents a concept or lacks
one. No layer/head/strength search is justified by an ambiguous result.

The finite answer reversal forms C2 at the declared output coordinate. It does
not prove an orthogonal representation, group-equivariance or a unique semantic
subspace in the hidden state. Cross-code token-slot interventions intentionally
change the two digit-cue slots and must be labelled as such, not same-token
transport. Even/odd output contrasts are descriptive, not personality factors.
