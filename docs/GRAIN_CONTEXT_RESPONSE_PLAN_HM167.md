## Competing mechanisms, with different observations

1. Body sufficiency: fixed-body responses and high-low gaps are invariant to
   prior task. Both source function differences and application gap changes
   vanish up to numerical measurement error.
2. Shared offset: context changes log odds equally for high/low articles in a
   pair, so log-odds gap stays fixed. Probability gaps can change from the
   sigmoid link alone. Do not misidentify link curvature as body-context action.
3. Joint response: context changes the log-odds gap itself. A body-only universal
   function cannot reproduce both registered histories at the same Phi(X).
   Keep the context-qualified family; do not delete Z or optimize reconstruction.

All targets, roles, styles, opportunities, signs, probability/log-odds and order
fields are retained. No arbitrary significance threshold creates a new trait.
Current numerical forward differences are checked against independent raw-logit
accounts, not reduced by refitting. Source and application answers are separate.

## Fixed mathematics

Let a(x)=ell_original(x), b(x)=ell_common(x). Per high/low pair,

    I_ell = [b(high)-b(low)-a(high)+a(low)]/4.

The average offset is s=mean_x[b(x)-a(x)] over these two bodies. Define

    gap_change_q = gap(sigmoid(a+s))-gap(sigmoid(a))
                   +gap(sigmoid(b))-gap(sigmoid(a+s)).

The first term is the described offset/link contribution, the second is the
remaining joint response. This is a signed finite account, not a unique causal
mediation estimand or a psychological-information percentage. The two-context
body-only mean-square floor mean_x[(q_common-q_original)^2]/4 is a descriptive
observation-fiber obstruction, NOT a predictor optimization objective.

For the same source features and origin, construct

    C_common - C_original = Cov_source(Y_common-Y_original,Phi),
    T_common(v)-T_original(v) = <C_common-C_original,v-mu>.

Each C keeps its within+between decomposition using the SAME historical body
task/style blocks. A historical block is not the now-common retained user task.
Cold outputs include original9/common9/delta full+within+between3:21 fixed arms,
not21 tuned predictors. No inverse, calibration, embedding update or label fit.
