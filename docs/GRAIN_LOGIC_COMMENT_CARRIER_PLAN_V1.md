2026-09-10. Ordered discovery on the already exposed M11/M15/M16 panel.
Not retrospective preregistration, new questionnaire fitting, or a production change.

## Decision and existing coverage

NEXT16's fixed-condition kernel reader adds token features before a linear head.
Before adding a nonlinear distribution-level head, measure an actual mixed
comment action. M15 is E-configuration by P/Q, M19 reflects all body tokens,
S6 changes selected sets without an anchored independent-comment quartet, and
M24 changes query coordinates. None supplies the requested comment quartet.
M12/M13 read conditional anchors from aggregate features; neither separates
retained body means from non-body contextual states inside the suffix.

## NEXT17: conditional joint action, including output-link curvature

Start from C(E), with each comment replaced by its own mean and P/Q fixed.
F0,Fi,Fj,Fij restore no comment, i, j, or both. Other10 comments stay collapsed.
I=Fij-Fi-Fj+F0. This is a background-specific mixed finite difference; it need
not have the same value around the fully native background.

Record the entire candidate-logit vector z for every endpoint. Remove its
common scalar shift before measuring logit interaction. With S(z) the native
conditional softmax score and z_add=zi+zj-z0, distinguish exactly:

    I = [S(zij)-S(z_add)] + [S(z_add)-S(zi)-S(zj)+S(z0)].

The first term is departure from additive candidate logits; the second is
curvature of the output link. A nonzero probability interaction alone does not
justify a new internal coupling mechanism. For smooth functions the mixed
difference is also the double integral of the directional mixed derivative;
we measure endpoints, not an untested Hessian reconstruction.

Report both pairs/query, RMS/mean/SD, paired intervals, centered-logit interaction,
sign changes, and source-criterion links. No universal materiality threshold:
compare size to pair action and actual replay error, then state what was found.

## NEXT18: T/F conditional-mean carrier quartet

At C(E) with P/Q fixed, partition body comment means M versus remaining
non-body E states R. Do not call R noise: it includes contextualized template
and boundary positions. Keep target token count, mask, positions and P/Q fixed.

Create a fixed reference from the four pre-existing T/F M16 reference authors,
view0, without outcomes. Body means are averaged by comment ordinal. For R,
split into13 gaps (before each of12 bodies, plus the final pre-question gap).
Interpolate each donor gap on normalized position into the target gap, then
average the four donors. This is a declared numerical role reference, NOT
exact token-ID patching or a claim these hybrid states are natural prompts.
No target state values enter its reference; target layout does.

Measure b11=native M/native R (old M15 B), b10=native M/reference R,
b01=reference M/native R, b00=reference M/reference R.
Decompose baseline/body/non-body/interaction and symmetric allocations. b00
may still vary with target layout; it is not assumed constant. Record edit norm,
candidate mass, saturation and interpolation coverage. Primary description of
reference-external source links uses20 non-reference authors; all24 secondary.
Compare b11 with old view0 B, not the previous three-view mean headline.

## Verification, outputs, and next branch

Pure numerical tests: additive versus interacting functions, additive logits
with nonlinear score interaction, mixed derivative identity, body/non-body/PQ
partition, deterministic role reference independent of target values, mean and
untouched-state preservation. Replay old f10/f00 for all48 authors (2e-6),
two exact duplicate calls, hash sources and models, no fresh text tokenization.
Publish only aggregate tables under reports/grain_vector_mechanisms; all author
IDs, logits, states, models, Y and joins remain in ignored results.

If logit joint action exists, develop a parity-preserving nonlinear function
of the distribution features using measured joint targets, not more harmonics.
If only link curvature is material, retain additive latent actions and model
the output link instead. If retained R matters, add its declared conditional
carrier to the next input contract; do not force all evidence into body means.

References informing the design:
- [Sundararajan et al.2020](https://proceedings.mlr.press/v119/sundararajan20a.html):
  distinguish component attribution from interaction allocation. Our local
  quartet is not the full Shapley-Taylor procedure.
- [Zhang and Nanda2024](https://arxiv.org/abs/2309.16042): patch metrics and
  corruption choices can change localization; retain score and logit accounts.
- [Heimersheim and Nanda2024](https://arxiv.org/html/2404.15255v1): patch direction
  and reference determine the question. Numerical hybrid-state interventions
  are not silently interpreted as natural-text or human causal effects.
