on public HM79/HM81 source observations, not another reader-fidelity fit.

## Question and decisions

Which declared author evidence contrasts are retained by a frozen observation
dictionary? Can condition selection and condition-dependent evidence differ
while pooled observations stay identical? Does an invertible per-event reading
change preserve those contrasts after a fixed moment summary?

The decision is whether to preserve condition-indexed observations and use a
target-specific observable/lost account rather than maximizing teacher accuracy.
Do not promote a winning feature arm, add product degrees, or optimize a rank.

## Mathematical construction

For any two author laws supported on R, f=(p_u-p_v)/R. Decompose
f=E_R[f|c]+(f-E_R[f|c]); their squared reference norms add. No condition
component is deleted.

For a registered Markov channel K, f_out=E_R[f|Y]. Input norm equals output
norm plus the joint reference expectation of (f(X)-f_out(Y))^2. Shared
invertible re-addressing preserves the norm, while a lossy channel can erase
a particular author contrast. This is standard information geometry.

For fixed source observation columns B, use the source-weighted SVD projection
Pi_B onto centered span(B) in L2(R). Machine tolerance is
100*max(shape)*eps*smax, never selected by application outcomes. Report
f=Pi_B f+(I-Pi_B)f and target contrasts
<f,t>=<Pi_B f,Pi_B t>+<(I-Pi_B)f,(I-Pi_B)t>.
This is a finite MOMENT account, not all information in individual continuous
readings or a learned density estimator for new unrestricted texts.

Compile t_vis=Pi_B t on source only, preserving lost t separately. An application
author score is E_author[t_vis]. The cold process receives only compiled source
functions and sampled event addresses, never author-generating coefficients or
full application probability tables. A source matrix inverse is not an
application inverse. Exact semantic behavior labels are supplied by design.

## Exact channel controls

Four-state (c,x) support: identity, invertible re-addressing, forget c, forget x,
and x-flip probability .2 with c retained. Test c*x contrast: identity/re-address
retain all; forgetting either erases it; flip retains .36 of squared norm.
These are mathematical controls, not empirical GRAIN or quantum claims.
