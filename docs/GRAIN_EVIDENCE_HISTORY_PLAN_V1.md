# M02：相关事件与修订历史的个人函数更新

2026-09-13。执行前冻结。本包完成尚缺的累积接口，不重做已交付的修订/重复小见证。

## 新增机制与旧结果

已有`resolve_revisions`可取最新明确版本，`profile_fit`可事件加权；旧证据状态理论已
证明同分数不决定下一更新。缺口是共同依赖、撤回/更正、摘要状态进入同一个人函数。
继承高斯条件矩/Schur创新、来源注记和修订与新事件的区分，不声称发明这些数学。

输入是已限定主体/条件的事件读数及**观察到的**关系：新事件、独立复述、精确副本、
明确更正、撤回、带来源摘要。更正只替代明示的旧主张，不判定其真实可信性；
同一内容在新事件出现反向反应不属于更正。开放文本身份发现仍归M01。

## 实验

1. 复用M04/M05的72公开原文、冻结NLI+乘积观察器和冷运行数值，无新神经调用。
2. 3固定种子，每种192独立来源作者，从文本读数学习个人水平/斜率均值与5个二阶
   方差分量：个人水平、响应、共同事件块、事件、复述读者。非负矩匹配，固定底限。
   来源不读取任何生成隐参数；模型为线性工作矩，不是二元事件的精确高斯后验。
3. 每种256新应用作者，两套配对措辞世界；8块×3事件×2报告。块内事件通过一次
   共享抽样或各自独立抽样产生依赖；块内条件相同，块间独立。参数/事件由生成器
   保存于评估专用truth，不由应用阶段读取。
4. 固定记录流包含副本、同事件独立复述、新事件、原记录误报及显式更正、撤回、
   来源摘要。比较版本/相关性完整模型、仅事件平均但忽略跨事件依赖、全部行独立。
5. 每次更新保存水平、有限变化、未见z=.5条件、工作方差、来源借力与实际核权重。
   更正/撤回重建活跃证据账；新增观察使用Schur创新并与全量条件矩交叉验证。
6. 摘要两层：只存当前数值和协方差的摘要保留当前答案，但对定向更正和相关新增
   事件会丢掉必要状态；数值证据/依赖附录完整的摘要可精确重播，不冒称固定大小压缩。
7. 同分数/同当前方差、不同依赖或来源历史的更新见证；非独立复制新增信息应为0。
   更正不增加已发生事件数量；撤回降低可用信息，后验不确定性允许增加。
8. 自然关系台账只核已有地址与缺失的跨评论事件/更正链字段，不生成真人行为真值。

## 数学与验收

单作者工作模型 `y=X beta + e`，来源给`m,V,R`。观测总矩为`K=X V X'+R`。
新增相关记录的剩余观测方差为`S=K_new-new-K_new-old K_old^-1 K_old-new`，
只用条件创新更新。精确副本若S=0且创新为0，贡献为0；冲突副本必须报错。
更正/撤回不是追加另一独立似然，应从带版本来源图重新构造活动X/y/R。

报告所有固定臂、种子与阶段，不以更低MSE单独决定正确证据含义；无语义提示、
prior强度、方差/块数调参网格。有限验收是更新规则/信息量、摘要反例、文本读数
应用与数式重播，而非开放自然事件链接或心理真值已解决。MEPS不读、不拟合。
