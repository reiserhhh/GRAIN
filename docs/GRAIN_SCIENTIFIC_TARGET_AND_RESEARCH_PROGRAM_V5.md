## 1. 先确定要发现什么

### 1.1 长期目标

**建立一种从开放语言中构造心理测量的基础方法：解释个人的心理差异如何经由
表达机会、情境选择、条件反应及状态变化表现出来；据此发现有效证据、构造
计分与解释规则，并指导研究者在新的情境中制作测量。**

所指对象是人格倾向、行为倾向和当次状态，不是只有Big5，也不是只识别作者。
目标不是在当前资料上立即完成临床量表，而是得到别人可以使用和发展的构造
原则。通用的是推理与制作程序；不同环境可以有不同证据、参数、构念和参照。

GRAIN本身仍是待发展的方法。切片、因子、4W、动态分解、向量路径接口都允许
修订、替换或重新组合。既有成果作为证据和竞争方案保留，不升格为不可更改的
公理。不能因为现有缓存只支持某种运算，就把科学终点缩成那种运算。

### 1.2 这阶段要争取的实质性新增能力

**找到可学习、与真人心理或行为效标相关的“个人对情境的响应结构”，并利用
它预先判断：改变哪类文本证据或表达机会，会改善对目标属性的测量；同时保留
个人选择和反应方式中的真实信息，而不是靠消掉差异取得表面稳定。**

具体例子：相同平均表达水平的人，面对不同情境可能有不同的响应曲线；不同
平均水平的人也可能只是被观察的机会不同。我们希望方法能区分这两种情况，
指出需要哪种证据，并据此构造新的测量，而非只给两个相似度或两个Big5分数。

这不是已经确认的新颖性声明。候选贡献有三层：

| 层次 | 要新增什么 | 什么不够 |
|---|---|---|
| 经验发现 | 有心理关联的响应结构及其可重复的条件变化规律 | 只有作者识别或LLM评分一致 |
| 方法贡献 | 从文本学习证据与条件表示，并据此选择有用观察、保留交互和校准比较 | 给现有聚合器再接一个回归头 |
| 数学贡献 | 对明确模型推导可识别目标、表示误差和设计改变的关系；必要时提出扩展 | 把条件期望、矩阵分解或核方法改名为新公式 |

其中前两层是主攻目标；是否需要、能否得到新的数学定理，由具体缺口决定。
不是每个基础理论论文都要首创全部数学，也不能用漂亮公式替代心理内容。

### 1.3 明确退出的旧终点

- 不以“GRAIN与向量路径成功接通”作为研究结束。
- 不以“做完所有工作包、两名agent同意”作为科学突破。
- 不以“所有情境同一系数、所有人格都可预测”定义通用性。
- 不以强制低维、强制相同分数、强制消除交互定义测量成功。
- 不以顶刊接收作可保证的验收项；目标是可检验的新增知识与能力。

## 2. 文献使我们改了什么

本轮不是给现版寻找理论背书。以下近邻直接限制了我们可以声称的创新：

| 近邻 | 已覆盖的部分 | GRAIN必须进一步解决的问题 |
|---|---|---|
| [Whole Trait Theory](https://pmc.ncbi.nlm.nih.gov/articles/PMC4472377/)与CAPS | 特质分布、情境化反应、个人反应模式 | 从开放且自选的语言中怎样构造可计分证据，而非重述人格会随情境表现 |
| [选择性作答IRT](https://pubmed.ncbi.nlm.nih.gov/28390145/)及[评分者扩展](https://pubmed.ncbi.nlm.nih.gov/31452553/) | 选择过程、不可忽略缺失、评分者差异 | 不预先把文本变成已知题目得分时，怎样学习证据、明确比较对象 |
| [潜在空间IRT](https://arxiv.org/abs/2007.08719) | 人与题目的交互几何 | 开放表达中哪些交互是目标相关信息，怎样生成和解释证据 |
| [开放式人格测评研究](https://journals.sagepub.com/doi/10.1177/10944281251413746) | 提示设计、叙事证据与人格关联 | 能否得到可预测的构造规律，而不是再次证明好问题比泛问有效 |
| [text](https://github.com/OscarKjell/text)、[LSX](https://github.com/koheiw/LSX)、[SPAR](https://github.com/maifeng/SPAR_measure) | 向量计分、语义轴、种子和检索引导的证据 | 从语义相近走到人的心理差异；选择、条件响应及证据利用要分清 |
| [深度IRT](https://arxiv.org/abs/1905.10957)、[LLM题目生成](https://link.springer.com/article/10.1007/s10869-025-10067-y) | 语义与测量参数结合、构念导向题目制作 | “学习表示＋自动提出问题”本身也不是新颖性 |
| [矩阵可识别性](https://icml.cc/2012/papers/510.pdf)、[主动采样](https://www.jmlr.org/papers/volume18/15-233/15-233.pdf) | 缺失结构、恢复条件、挑选有信息的观察 | 观察值本身由文本表示和诱发方式共同产生时，规则是否仍有效 |

因此，本项目不能把“传统心理测量只会固定题目”当作对手画像。真正需要比较
的是解释性、选择性、交互式测量模型以及已有语义测量工具，而不只是弱线性
baseline。文献档案记录了哪些读了相关方法段，哪些只有摘要，不能混称全文研读。

**尚待查清的新颖性问题**：在学习文本证据的同时，按目标选择观察设计并处理
自选表达，是否已有同等机制与能力？后续必须比较具体公式和实验，而不是只
检索“GRAIN”这个名字。即使数学组件都有先例，新的构造机制与经验规律仍可
形成实质贡献，但要讲清新增在哪里。

## 3. 开放的数学对象，不预先锁死算法

### 3.1 区分人、机会、选择、表达、读出

候选生成模型写为：

\[
C_{ut}\sim\pi(\cdot\mid O_{ut},H_{ut},\theta_u,s_{ut}),\qquad
X_{ut}\sim p(\cdot\mid C_{ut},O_{ut},H_{ut},\theta_u,s_{ut},d),
\]

\[
E_{ut,q}=\phi_{q,\eta}(X_{u,\leq t},O_{u,\leq t},d).
\]

O为可获得的表达机会，C为选择，H为历史，d为记录/诱发设计；theta是待解释的
较稳定个人属性，s是指定时间范围内的状态。它们可以相关，此式不承诺从文本
唯一恢复全部潜变量。E是可计算证据，q可为构念目标或尚未命名的探索问题。

没有机会集合O时，仅估计观察到的构成，不把“发过什么”直接等同于“有机会时
偏好什么”。主题由回复内容推断时可以作为描述性条件，但不能冒充独立操控。
LLM的判断与人的效标另列，不能相互当真值。

### 3.2 主体是响应函数，而非必须找到一条稳定轴

\[
m_{u,q}^{d}(z)=\mathbb E[E_{ut,q}\mid u,Z_{ut}=z,d],\qquad
T_{u,q}^{\nu,d}=\int m_{u,q}^{d}(z)\,d\nu(z).
\]

z可以包含事先记录的条件、明确标注的描述性情境，以及合法的时间/历史索引。
T给出指定参照条件分布下的一个摘要；m的变化方式也是候选对象，不必全部
压缩到T。也可用条件分布或有序路径代替条件均值。

一个有限维、可直接开展机制比较的子模型是：

\[
m_{u,q}^{d}(z)=a_{u,q}+c_q^d(z)
 +\sum_{k=1}^{r} b_{u,qk}f_{qk}^{d}(z)+h_{u,q}^{d}(z).
\]

b描述个人的条件响应；h是当前表示尚未解释的结构，不预先称为噪声。
分解需给中心化、尺度或等价类约定，否则主效应和交互可相互挪动。r不是固定
人格因子数；低秩只是第一可计算子模型。若信号高维或非线性，改用相应对象。

**此处用到的是已有混合模型、功能数据和条件表示思想。** 候选新增在于怎样
从开放文本学习phi、z和有效比较规则，并检验它们提供的心理信息。

### 3.3 不变性只是一个特例，设计变化也可以被解释

若完全可加，个人差异可以不依赖参照条件；若存在真实交互，改变参照会改变
比较结果。后者不是自动失败。固定证据函数后，可研究：

\[
\Delta_{uv}^{\nu_2}-\Delta_{uv}^{\nu_1}
=\int[m_u(z)-m_v(z)]\,d(\nu_2-\nu_1)(z).
\]

这只是积分线性性的恒等式，不是新定理。研究价值在于能否估计右侧并提前
预测改变观察条件后的差异，而不是在看完结果后给变化找解释。

设计d还可能改变说话方式本身。令观察构成为p_u^d，固定phi，有：

\[
S_u(d_2)-S_u(d_1)
=\int m_u^{d_1}\,d(p_u^{d_2}-p_u^{d_1})
+\int(m_u^{d_2}-m_u^{d_1})\,dp_u^{d_2}.
\]

第一项是观察构成变化，第二项是条件响应变化；这是选定基准后的分解，不是
天然唯一的因果分解。无共同支持的部分需要模型假设或新增观察。核、表示或
评分器也改变时，不能把所有差异都归给作者。

### 3.4 两个研讨中实际修正的错误方向

**不能只优化不变性。** phi=常数就能得到完美一致，却没有心理测量信息。
候选证据必须保留构念内容、心理/行为关联或明确的待检验心理假说；匿名证据
可以先发现，但作者识别本身不完成心理解释。

**一个共同问题不等于全部响应可比较。** 对m_u(z)=a_u+b_u z，只在z=0共同
观察能比较截距，不能确定斜率或z=1的排序。需要多少链接观察取决于要估计的
函数、模型类与支持，而非“图连通”一个条件。更不能仅凭连接图识别受到未观测
状态选择影响的目标均值。

## 4. 高等数学各自解决什么

| 工具族 | 对应缺口 | 本轮定位 |
|---|---|---|
| 条件核均值、分布回归 | 比较表达分布而非只平均token；处理人和文本两层样本 | 优先可用实现；参见档案M3-5，不自动带来人格解释 |
| 图、代数几何、矩阵完成 | 哪些响应方向被观察到，新增什么条件能补充目标信息 | 有具体链接问题时启用，不把缺失图统计变成整个主线 |
| 非线性ICA、多视图识别 | 是否存在不同读出/情境共享的潜在来源 | 条件独立、辅助变化等假设可检验时再用，不强装独立人格因子 |
| 功能数据、状态空间、路径核 | 响应曲线、过程状态、顺序和跨变量耦合 | 有相应序列材料时启用；token顺序与真实时间分别建模 |
| 统计决策/实验比较 | 压缩后是否保留指定心理推论所需信息 | 比较目标信息而非重建全部LLM激活；需共同目标空间 |

不是把所有数学塞进一个总公式。先有未解决的可计算问题，再选择工具。
群变换、不变性可研究坐标重标记，但情境变化不一定是应消除的对称变换。
高维、路径或非线性也不自动要求量子解释。

## 5. 如何重建GRAIN，而不是给它加附件

| 当前部件 | 保留什么 | 允许怎样改变 |
|---|---|---|
| 切片与多视图 | 可定位、可比较的局部证据 | token/句段/事件/有序路径/无切片均为候选，不保留强制切法 |
| 因子与作者参照 | 多人共同结构、个体相对位置 | 轴、分布、响应函数、配置和局部几何都可作为测量对象 |
| MCD条件思想 | 条件是前提，选择也有信息 | 从固定残差处理升级为选择与响应的联合表示，避免统一扣除 |
| 动态特征 | 表达变化、耦合、条件响应 | 明确时间单位，必要时以函数或状态空间替换手工flow指标 |
| 向量路径 | 查询如何选取和组合证据的直接线索 | 参与发现phi与观察机会；不只事后给因子贴人格名字 |
| 数字读出与解释 | 固定计分、可追溯证据 | 解释须对应计算和心理关联；LLM可提候选，但不临场改分 |

LLM不必被限制成“只能渲染文字”，也不能升级成“人的心理真值生成器”。发现
阶段可用它寻找证据、对比机制、提出语言变换；计分阶段冻结需要使用的函数。
无生成读出、仍运行神经编码器、完全脱离大模型，是三个不同技术状态。

## 6. 从目标反推小步骤

前置第一阶段为[I0-I4](GRAIN_PREDECESSOR_INTEGRATION_STAGE_V1.md)：方法规格 → 核心参照复现
→ 条件/过程接口 → 共同协议统合 → 剩余研究问题。完成后再按其结论修订下表，
不能以已有文献综述或旧GRAIN实验代替本阶段验收。

以下时间是获准后一次有限研究周期的工程估计，不是整个基础理论完成期限。
每步优先寻找能改变下一步设计的正面结果；不为补齐表格启动长跑。

| ID / 顺序 | 工作与预计时长 | 可验收产物 / 正面发现 | 决策 |
|---|---|---|---|
| G0：贡献规格 | 半天至1天；精读最接近的选择IRT、交互IRT、叙事证据、语义测量和主动设计方法 | 一页目标、逐公式竞争表、一个可区分的新增机制 | 先定需要超越的能力，不默认必须造新定理 |
| G1：机制世界 | 1-2天；主效应、强交互、自选情境、状态驱动四类生成世界，固定/学习证据对比 | 明确真值、oracle界面、恢复曲线与反例；找出何时保留交互和选择确实增加目标信息 | 有正面规律才决定GRAIN重建对象；只靠固定均值也有效则保留简单解 |
| G2：真实证据发现 | 1-2天；在允许开发的作者材料上比较现版证据、语义轴、学习证据和交互表示 | 有地址的证据候选、响应结构、目标关联；发现侧与作者分离的验证侧分开 | 不把匿名作者结构强制命名；也不因不能压成低维就丢弃 |
| G3：构造机制 | 2-3天；为G1/G2发现选择一个实现，比较固定证据、学习证据、联合设计 | 冻结的提取与计分原型、对新条件的事前预测、可说明的增量能力 | 只在这里确认该保留、替换哪些GRAIN部件 |
| G4：链接设计 | 仅在影响G3决策时，1-2天；推导目标需要的支持和少量补充观察 | 模型条件下的链接/采样规则；比较被动、随机与目标引导观察 | 无有限最优性证明时称可行/贪心设计，不称全局最小诱发 |
| G5：局部制作示范 | 2-3天；按同一构造规则制作至少两个不同条件下的候选测量 | 人格/状态/行为目标分别报告；有心理关联、解释和可复建参数 | 同一方法可制作，不自动等于两域同一数字量尺 |
| G6：独立复建与论文 | 2-3天；按规格由未参与设计的执行者复建 | 方法、来源、公式地位、构造示例与限制的完整论文证据链 | 缺口反馈到相关机制，不无限添加防御支线 |

建议投入：机制发现与GRAIN开发约一半，真实心理关联与制作示范约三成，其余
给直接竞争文献、复建和文档。Claude用于有限理论争点，Codex实施与检验，不
默认启动多agent或持续长会话。

### 6.1 G1不是给自己的公式搭一场必胜比赛

先规定潜在人差、选择、状态和表达生成过程，以及什么结果会改变机制判断，
再让不同算法看到相同观测。
至少包含：只有总体水平、强且有意义的交互、只有主题/作者身份线索但无目标
信息、状态同时影响发言选择与语言四种世界。非线性表达和表示损失分别变化。
另设心理属性不变、仅表达机会或测量通道改变的世界，以及预先规定的无结构
世界。比较oracle证据与实际学习证据，区分估计器失败和观测根本没有目标信息。

竞争对象包括：pooled回归/语义轴、常规条件/选择模型、交互模型、GRAIN旧版、
学习证据但不改设计、学习证据并改设计。不是每种都全参数网格；先用最小可
区分设置。任何“动态/残差必然有心理意义”的命题都不放进生成器当既定结论。

### 6.2 G2/G5的数据位置

- PANDORA：开放、自选、多文本的开发与作者分离验证环境，心理标签为有误差
  的外部关联。先核实当前允许使用的人/文/标签划分，不照抄旧样本数字。
- Essays：另一种文本诱发与人群的验证/制作候选；不同人群不当同人跨情境。
- X市场文本：情境限制、选择与过程的机制场景；无心理标签时不宣称人格效度。
- MEPS/AI相谈：严格保持验证用途，不参与fit、选证据、调参或选择理论赢家。
  同人固定/自由材料可做有界检验；已经反复查看的结果不再冒称全新盲测。
- 现有数据支持不到的关键构造步骤，明确写出未来必要资料；不为了填表虚构
  观察或把模拟人当真人。本轮不新招募被试、不扩大数据使用许可。

## 7. 怎样知道目标正在接近，而不是又在绕圈

主报告按“发现了什么机制 -> 它预测什么 -> 它怎样改变测量制作 -> 实际产生
什么心理关联”组织。至少要有以下正面成果中的连贯组合：

1. 一种现有pooled表示容易遗漏、而新构造能检出的目标相关响应结构。
2. 一条提前写出的证据/观察变化预测，在新作者或新条件上得到相应结果。
3. 同一构造规则能形成第二个有意义的局部测量，而非仅把第一套参数复制过去。
4. 计分变化可以追溯到证据及条件，并与心理/行为含义对照，而不是LLM事后故事。

以上是逐级积累的成果，不要求第一次发现就同时达到全部终局标准。可比机会下
的个人响应与当次状态分别检验，不要求被试每日重复相同话题。观察到的响应
规律先称统计结构；有适当干预与识别依据时再讨论人的因果机制。

不设所有构念统一r>.5的行业外阈值，也不把一个小p值当全部贡献。报告效应量、
不确定性和相对强竞争方案的增量；科学重点是新增推论与制作能力。若经典方法
同样解决问题，诚实定位为有效适配，不另造名称宣称全新理论。

**当前完成的是目标修订与候选机制的研究设计。下一步首先执行G0/G1，而不是
恢复旧排行榜、重新训练MBTI或提前宣布理论闭环。**
