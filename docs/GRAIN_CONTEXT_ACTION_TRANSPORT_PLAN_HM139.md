## Fixed source construction

For four corner observations define Gamma(f)=sum(b*c*f(b,c))/4. This is also
the author-account difference for P+/P-=(1+/-0.5*b*c)/4, retaining both margins.
These positive laws are experimental compositions, not new human authors.

Three feature dictionaries: g (15), onehot(real_regime) tensor g (30),
onehot(sham_regime) tensor g (30). Sham: one fixed balanced random split of
24 strata, seed139; a separate balanced application split, seed140. A label
is constant across each four-corner stratum; no target outcome sets a label.

Each source contrast column is scaled by its source RMS; zero columns retain
zero. Use one fixed SVD pseudoinverse, rtol1e-10, minimum norm in that stated
source metric. Fit ALL28 fixed native full-program actor/query/score-logodds
actions. This is source calibration to native observer actions: it IS fitting,
not independent discovery of psychological truth or zero-fit mathematics.
No intercept is identified by four-corner contrasts; the cold event function
has fixed zero intercept, and only declared contrasts are evaluated.

Freeze JSON coefficients before application model reads. The cold scorer
accepts only g, real_context, sham_context. It cannot access body, family,
b/c codes, corner partner, native outputs or an application lookup table.
Also evaluate real coefficients with the context deliberately swapped: a
negative diagnostic, not a fourth fitted model. No clipping or calibration.
