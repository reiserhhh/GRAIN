# GRAIN 机制-前身-缺口矩阵

2026-09-12。范围由本地系统回顾、V8统一理论、4W、V5计划及会话目标建立。
这是研究覆盖图，不是27项均已验证，更不是未来必须同时开27个实验。

来源ID可在[原登记簿](GRAIN_LITERATURE_REGISTER.md)及
[W01-W65补充登记](GRAIN_LITERATURE_REGISTER_WIDE_20260912.md)定位到原文、版本和阅读深度。
“继承”指现成数学/方法可作起点；“适配”指观测与目标不相同；
“新问题候选”指检索后值得研究，未认证首创。

## 需要停止重复发明的八类部件

MEM/BLT式因子发现、sJIVE式共享监督分解、DSEM/ctsem式动态估计、
TextTiling/ACE式分段概念发现、Semantic Measures式语义计分、SIMPA式条目证据匹配、
ECD/AIG式构造流程、longitudinal NLP式群间/个体内分离评价。

“采用”不等于所有源代码直接兼容，也不等于它们在我们的资料上必然有效。
参照实现先于大规模自研；若适用条件不满足，清楚写出缺哪一项，
只为这个差别新增机制。

## 不把覆盖图误读为闭环证书

- 表内每格都有文献入口，不代表每个本地实现已经正确执行该方法。
- 近邻多，减少了部件首创空间，也增加了可站立的理论支撑。
- 本轮没有找到一项可直接涵盖全部目标的已验证成品；这不证明其不存在。
- 下一步要检验的是“三接口同时出现”是否产生已有组合没有的可测规律，
  而非把三个成熟模块串联后默认新颖性成立。
