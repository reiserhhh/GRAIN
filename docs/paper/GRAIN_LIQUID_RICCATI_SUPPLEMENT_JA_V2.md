# GRAIN 理論稿への補遺（第2版）：液態軌跡・制約付き Riccati-Möbius 精密流・対人ダイナミクス

**位置づけ：** 本書は [`GRAIN_THEORY_MANUSCRIPT_JA_V1.md`](GRAIN_THEORY_MANUSCRIPT_JA_V1.md) および
[`GRAIN_MECHANISM_SUPPLEMENT_JA_V1.md`](GRAIN_MECHANISM_SUPPLEMENT_JA_V1.md)
に対する第2版補遺であり、V1 本文と歴史的凍結記録を改変せずに第 3・5・6・8 節を拡張する。
本版では、凍結液態軌跡ツール群、`ConstrainedRiccatiCell` による厳密零次ホールド（ZOH）
Möbius 流、多時点動的集合反転、同伴リポジトリ `project-persona` における Lean 4
形式検証（`58` 定理、公理逸脱なし）、および独立した公開人間コーパス群での検証結果を統合する。
全数値の出典は [`GRAIN_LIQUID_RICCATI_EVIDENCE_PROVENANCE.md`](GRAIN_LIQUID_RICCATI_EVIDENCE_PROVENANCE.md) に記録した。

> **中核的非主張声明。** GRAIN は自然言語に基づく測定系を構築するための基盤分析法であり、
> **パーソナリティ尺度では**なく、臨床診断用具でもなく、構成概念・母集団・臨床妥当性の
> 検証を代替するものでもない。

## S1. 目的と位置

理論稿 V1（式 1–15）および機構補遺 V1 は、文脈を無条件に除去すべきでない理由、
条件選択と条件付き反応の分離、ならびに個人・関係・集団の型区別を定式化した。しかし、
離散切片回帰から連続時間対話および多時点言語流へ拡張するうえで、三つの構造的課題が残されていた。

1. **連続時間半群の破綻と長期初期記憶の消失。** 既存の離散ステップ近似による液態セル
   （`LTCCell`）は、不規則時間間隔（`dt = 0` や区間分割）下で時間分割半群則を満たさず、
   長い空白区間の後に初期の高信号イベントを忘却する。
2. **静的計画における等減衰率の非識別性。** 共有状態と各視点固有状態の自己回帰減衰率が一致する
   領域では、単一ステップの静的集合境界は任意の初期私的オフセットを除去できない。
3. **独白テキストから対人相互作用ダイナミクスへの実証的接続。** 単一コーパス・自己報告のみでは、
   相手反応の喚起（evocation）、対人可塑性（plasticity）、条件付き反応、物語粘性ダイナミクスが
   厳密に分離された他者評価パネルに対してどの程度の独自情報を持つかが未検証であった。

第2版補遺は、凍結・ソース較正済みの枠組みのままこれら三課題を解消し、同時にゼロ結果と
非臨床境界を明示する。

## S2. 継承手法・厳密 Riccati-Möbius 流・Lean 4 形式検証

本リリースは `grain_core.riccati_mobius`（`suica_core/riccati_mobius.py`）および凍結液態
ノード群（`grain_core.liquid_*`）を公開するとともに、同伴リポジトリ `project-persona` 上で
Lean `v4.36.0` + Mathlib `v4.36.0` により検証済みの `58` 定理（7 モジュール、`sorryAx` ゼロ、
依存公理は `propext`・`Classical.choice`・`Quot.sound` のみ；内訳は `RiccatiMobiusFlow.lean` 7、
`DynamicSetInversion.lean` 6、`PersonalityDynamics.lean` 7、`LiquidResearchLoop.lean` 14、
基本 GRAIN 定理 24）と対応付ける。形式証明は仮定下での演繹的正当性を保証するものであり、
人間心理学における経験的妥当性を代替しない。

| 構成要素 / Lean モジュール | 数理メカニズム | 証明済み性質・保証 | 適用範囲と限界 |
|---|---|---|---|
| `ConstrainedRiccatiCell`（`RiccatiMobiusFlow.lean`） | 制約付きスカラー Riccati 微分方程式 $\frac{dx}{dt}=\epsilon(u)(\alpha(u)+\beta(u)x+\gamma(u)x^2)$ を正規化 $2\times 2$ Möbius 行列指数で厳密積分 | 厳密 $[-B, B]$ 不変性、`dt = 0` 恒等写像、時間分割半群整合性、Kogge-Stone 法による結合律 $O(\log T)$ 並列走査一致（誤差 `<= 1e-12`） | 入力区分一定の ZOH モデルであり、純粋な高速減衰チャネル自体は空白保持のためエピソード検索との併用を要する |
| `DualPathwayRiccatiObserver` | イベント間遅延上の収縮 Riccati 高速流と履歴コサイン類似度に基づく低速エピソード検索を結合 | 長時間空白後でも初期顕著発話の影響を保持しつつ、因果マスク規則（`mask_first`）を遵守 | エピソード重みは履歴混合率であり、語変更による将来ゲート介入の因果効果ではない |
| `estimate_cross_view_lag1_rates` と `solve_axis_trajectory_lp`（`DynamicSetInversion.lean`） | クリップ付きの交差モーメント比と HiGHS による軌跡の集合推定 | 指定した遷移率・静的境界・変動幅の下で可能な範囲を返す。空集合は `None` | 推定された分散が正でなければ、そのモーメントから遷移率を決めない。同一履歴の差分法を対照とする。 |
| `stack_transition_contrasts` | 複数時間窓・複数読み手に跨り較正済み遷移差 $A_t - P_{j,t}$ を積層 | 単一ステップが階数不足でも適切条件で共有初期状態 $c_0$ をフルランク復元（誤差 `< 1e-12`） | 事前に独立ソース標本から遷移写像と誤差許容幅が較正されていることを前提とする |
| 五作用素対人ダイナミクス統合（`PersonalityDynamics.lean` / `LiquidResearchLoop.lean`） | 喚起・条件付き反応・対人可塑性・軌跡粘性・課題横断コンセンサスの五作用素で状況内行動を分解 | 動的希薄化補正式、分散分解境界、自己報告と他者評価基準の非等価性を形式化 | 対人行動・他者評価指標は依然として自己報告尺度や臨床診断とは別個の対象である |

## S3. 計算性質・動的集合反転・公開人間コーパス横断検証

### S3.1 連続時間半群不変性と動的集合反転

同伴リポジトリの過去実軌跡アーカイブ（`N = 108`）において、従来型 `ncps LTCCell` は 2 倍時間
細分化で `3.8665e-5` の誤差（対実時間比較中央値 `wall_vs_equal_median = 1.2601e-4` の `30.68%`）
を生じ、長間隔末に初期イベント感度が消失した（`wall_first_at_end_median = 0.0`）。これに対し、
`ConstrainedRiccatiCell` と `DualPathwayRiccatiObserver` は細分化誤差 `1.73e-18`〜`2.52e-18`
（`5.07e-13%`〜`7.33e-13%`）、逐次対 $O(\log T)$ 並列走査最大差 `1.388e-17` を達成し、
二重経路検索により初期発話の末端到達感度 `wall_first_at_end_median = 2.710e-4` を回復した。

合成動的集合反転ベンチマークでは、共有・固有減衰率が異なる条件（`distinct_rates`）で多面体
幅が `4.949` から `0.1070`（`0.0216x`）へ縮小し分岐非交差率が `0/60` から `60/60` に上昇した。
一方、三減衰率が一致する反例（`equal_rates_counterexample`）では幅が `3.8343` へ拡大し
分岐分離 `0/60` に留まり、Lean 4 の非識別定理と整合した。アーカイブ済み実軌跡
（`actual_slopes/paths.npz`、クロスビュー MoM `r_c = (0.165, 0.350, -0.031)`,
`r_p1 = (0.193, 0.150, 0.104)`, `r_p2 = (0.021, -0.015, 0.179)` および全軌跡最大適合分位 `0.90`）
では、`R4_branches` が `216/216` 実行可能で幅比 `0.281x`〜`0.614x`（軸 0・1 で `12/216` および
`4/216` 分岐非交差）、PANDORA 保留セットでも `78..83/96` 実行可能かつ不適合 `13..18` 経路を
適切に棄却した。

## S4. 保持した反例・ゼロ結果・方法論的境界

1. **離散近似における時間細分化ドリフト：** 通常の `LTCCell` は不規則間隔下で `30.68%` の細分化
   不整合を示し、空白区間後に初期イベントを忘却する（`0.0`）。
2. **等減衰率による非識別障壁：** $r_c = r_{p,1} = r_{p,2}$ が成立する場合、動的 LP 境界は縮小せず
   非分離（`3.8343`, `0/60`）に留まる。
3. **有限標本適合較正における不適合棄却：** 適合分位 `0.90` 較正下で PANDORA 保留経路の
   `13..18/96` が不適合棄却された；棄却出力 `None` を強制補間してはならない。
4. **各コホートの正直なゼロ結果：** RealPersonaChat 質問紙相関 `0/252`・無再賦活リフトヌル
   （`-0.0016`）、ESConv 感情緩和ヌル（`p >= 0.309`）、顕在・潜在乖離の領域非共有性はいずれも
   実測された制約として保持する。
5. **コホート間非統合原則：** 4 つの公開コーパスは母集団・課題・出力型が異なるため、単一の潜在
   パーソナリティモデルや臨床スコアへ統合してはならない。

## S5. 追加の反証可能な命題（P12–P15）

- **命題 12（不規則標本化下の半群不変性）。** 正当な連続時間言語読み取り器は、空白区間の分割および
  `dt = 0` 連結のもとで浮動小数点許容差内の出力一致を保たねばならない。細分化により系統的逸脱が
  生じれば反証される。
- **命題 13（動的集合反転の速度分離条件）。** 外力のない厳密なスカラー差分では、等しい速度は未知の初期値に掛かる係数を消す。これは有界区間が狭まるための必要十分条件ではない。静的境界、共有遷移、変動幅による制約の寄与を分け、[同じ履歴を使う差分法](../GRAIN_EVENT_AND_VIEW_INCREMENT.md)と比較する。
- **命題 14（対人喚起・動的勾配と自己報告の非冗長性）。** 自然対話において、話し手が相手に喚起する
  反応と対人適応勾配は、自己報告尺度では捉えられない分離相手パネル印象分散を説明する（`ΔR² > 0`）。
  自己報告集合のみでクロス・パネル動的分散が完全に吸収されれば反証される。
- **命題 15（顕在・潜在乖離の領域固有性と物語順序依存性）。** 顕在・潜在乖離は独立領域間で低い
  相関にとどまり、投射物語アークの妥当性は無作為文順シャッフルに対して保存されない。

**命題13の計算例。** 二時点の構成例では、同一履歴を視点別に処理した区間は [−0.4, 2.0] であった。二つの視点が同じ直前状態を共有するという制約を加えると [0.8, 1.2] となり、ゼロを超えるかという判断が初めて定まる。閾値が4なら判断は変わらない。[実行手順](../GRAIN_EVENT_AND_VIEW_INCREMENT_JA.md)を参照。対話では訂正・本人の応答・後続行動を別々に記録する。既にコード化した7例（支持4、判断保留3）の再読は独立した予測成績ではない。[原資料 §3.5](https://aclanthology.org/2023.paclic-1.85/)によれば、積極性は回答者自身、理解度は相手の発言を理解した程度、関心は話題、満足度は対話全体についての評定である。

## S6. 理論稿 V1 および機構補遺 V1 との関係

本補遺第2版は V1 本文（式 6–15）および機構補遺 V1 の凍結記録を一切書き換えずに、（a）厳密
Möbius 半群と二重経路エピソード検索により連続時間輸送の欠陥を解消し、（b）静的楕円から動的
線形計画多面体へ部分識別理論を拡張し、（c）独立した複数人間コホートにおいて対人ダイナミクス、
条件リフト、多課題コンセンサスと同時にヌル境界および非臨床原則を明確化した。
