## S1. 目的与位置

理论稿 V1（公式 1–15）与机制补编 V1 确立了为何不能无条件剥离情境、为何条件选择与条件内反应必须分账、以及个体/关系/群体三类输出不可混同。但在将 GRAIN 从离散切片回归推广到连续时间对话流与多时点动态表达时，仍有三项核心缺口亟待补全：

1. **连续时间半群失效与长程早发信号遗忘。** 现有通用液态神经网络单元（如 `LTCCell`）依赖有限离散步长近似，在不规则时间间隔（`dt = 0` 或间隔二分）下破坏半群一致性，同时指数衰减会在空窗期抹除早期高信号事件。
2. **静态部分识别中的等衰减率退化障碍。** 当单步转移或共有/私有通道的滞后一阶衰减率重合时，静态双视角区间无法消除任意私有初值偏置。
3. **个人独白与人际交互动力学在真实人群上的分离检验。** 仅凭横断单语料相关无法回答：在严格隔离的他人评价面板上，由对话过程刻画的动态响应、唤起（evocation）、人际可塑性（plasticity）及叙事粘滞动力学，究竟能否提供自陈问卷无法捕捉的行为信息。

第 2 版补编在冻结、来源校准且严格区分推演与实证边界的前提下系统补齐上述三项缺口。

## S2. 继承方法、受约束 Riccati-Möbius 精确流与 Lean 4 形式化验证

## S3. 计算性质、动态集合反演与多语料公开实证发现

### S3.1 连续时间半群不变性与动态多时点集合反演

在 `project-persona` 历史归档的 `N = 108` 条真实动态轨迹上，常规 `ncps LTCCell` 的时间二倍细分误差高达 `3.8665e-5`（占真实时间对比效应 `wall_vs_equal_median = 1.2601e-4` 的 `30.68%`），且长间隔后首帧在终点的保留信号完全坍缩为 `wall_first_at_end_median = 0.0`。相对地，`ConstrainedRiccatiCell` 与 `DualPathwayRiccatiObserver` 的二倍细分误差仅为 `1.73e-18` 至 `2.52e-18`（仅 `5.07e-13%` 至 `7.33e-13%`），顺序滚动与 $O(\log T)$ 并行扫描最大偏差 `1.388e-17`，且双通路情景检索将长间隔后首帧保留灵敏度恢复至 `wall_first_at_end_median = 2.710e-4`。

在合成动态集合反演基准测试中，共有/私有衰减率分离（`distinct_rates`）使隐状态多面体宽度从 `4.949` 收缩至 `0.1070`（`0.0216x`），分支可分率从 `0/60` 跃升至 `60/60`；而三通道等衰减率反例（`equal_rates_counterexample`）的区间仍膨胀至 `3.8343`（`0/60` 可分），精确印证等衰减率不可识别定理。在真实归档斜率轨迹（`actual_slopes/paths.npz`，结合无偏跨视角矩估计 `r_c = (0.165, 0.350, -0.031)`、`r_p1 = (0.193, 0.150, 0.104)`、`r_p2 = (0.021, -0.015, 0.179)` 与全轨迹最大共形分位数 `0.90`）上，`R4_branches` 全部 `216/216` 保持可行且宽度收缩至 `0.281x`–`0.614x`（第 0–1 轴分别实现 `12/216` 与 `4/216` 分支不交），而在留出 PANDORA 路径上可行率为 `78..83/96`（如实拒斥 `13..18` 条模型失配路径）。

### S3.2 严格隔离公开人类语料库上的多群体实证检验

以下检验分别在四套互相独立、绝不跨库合并个体的公开人类数据集上开展，同步报告阳性与零结果：

1. **RealPersonaChat**（`13,583` 段真实双人对话；`138` 名双面板说话人 / `129` 名在严格不交 `117` 对 `116` 伴侣面板上平衡的说话人；`332,677` 条 `dt <= 300s` 真实时间戳）：
   - **跨面板条件响应他评效度与自陈问卷零结果。** 条件化自我反应（`v_given_v`）可跨不交伴侣面板预测 4 项经 200 次置换 FWER 校正仍显著的他人印象：`informativeness r_cross = 0.3545`（`p_FWER = 0.00498`）、`familiarity = 0.3338`（`p_FWER = 0.00498`）、`comprehension = 0.2921`（`p_FWER = 0.0149`）、`interest = 0.2874`（`p_FWER = 0.0249`）。同期 `252` 项自陈问卷指标与动态指标的 BH-FDR 检出率为 `0/252`（`q_BH >= 0.1245`）。
   - **自陈、静态与人际动力学同台对比。** 在综合他人适应评定（`PeerAdj_Composite`）预测中，28 项自陈量表（`S_self28`）留一交叉折外 `r_OOF = -0.0216, R² = -0.0719`；静态行为均值（`B_static5`）`R² = +0.2082`；22 维完整人际动力学（`B_full22`）池化 `r_OOF = +0.5869, R² = +0.3388`（面板内动态净增量 `ΔR²(B_full|B_static) = +0.1306`，主动性 `proactiveness ΔR² = +0.1933`，严格跨不交面板 `r = 0.4031`），并在 `7/7` 项他评目标上以 bootstrap 95% 置信区间稳健优于自陈量表。
   - **唤起、可塑性与跨文字系统不变性。** 伴侣面板劈半下，唤起特征展现高复现性（`evoke_p_log_chars r_AB = 0.7399`、`evoke_p_q_rate = 0.5643`、`evoke_p_v_rate = 0.2781`）；条件依赖人际可塑性斜率亦跨越不同伴侣面板复现（`slope_v_to_p_v = 0.2762`、`slope_q_to_p_q = 0.2343`、`slope_chars_to_p_chars = 0.1806`，且正交于自我监控 `SMS` 与适应均分）；跨日语表记系统的回应承接保持高度同向（`E_katakana <-> E_kanji r = 0.7705`）。
   - **零结果与自评—他评差异的解释边界。** 不交条件下原始情感/认知衔接相关（`0.2479`）在条件提升（lift）下回落至 `0.0628`，无重新激活条件超额提升为零（`r_AB = -0.0016`）。`Self - Peer` 差异得分与低 `v_aff_given_v`（`-0.3665, q_BH = 0.00052`）、高 `deflect_v_to_e_lift`（`+0.2605, q_BH = 0.020`）及高 `evoke_p_q_rate`（`+0.2853, q_BH = 0.0107`）相关；因差值项右侧直接包含 `-Peer`，不可仅凭差值将原因单向归咎于自我盲点。
2. **ESConv**（`1,300` 段情绪支持对话）：`Reflection of feelings` 策略（`v_prob = 0.7156, e_uptake = 0.0701`）可有效区别于 `Restatement or Paraphrasing`（`e_uptake = 0.1531`），但 `v_prob -> seeker_empathy` 仅弱相关（`r = 0.0654, p = 0.0266`），下游 `emotion_relief` 为零结果（`p >= 0.309`）。
3. **PSE-Database v1.0**（`4,570` 名写作者、`26,389` 篇主题投射故事、`27 vs. 27` 严格不交图片集、`N = 1,949`、留出验证 `N = 351`）：权力动机故事弧 `story_arc_pow` 跨独立图片集保持预测（偏相关 `r = +0.0725, p = 0.0059`；留出 `N = 151` 达 `r = +0.2831`），并显著优于 32 次句序置换（`p = 0.0303`）；成就句段粘滞 `sent_visc_ach` 偏相关 `r = +0.0993`（`p = 0.0062`，留出 `N = 80` `r = +0.1411`）；`3×3` 动机形状矩阵（`N = 548`）对齐度 `rho = +0.0531`（`p = 0.0303`）。
4. **Bar-Anan & Nosek (2014)**（`N = 24,015` 多任务受试者）：零自由度多任务内隐共识显著增加外显指标之外的增量效度：`Race -> mrs ΔR² = +0.0442`（`N = 331, 95% CI [+0.0015, +0.0808]`），`Politics -> willVoteDem ΔR² = +0.0266`（`N = 244, 95% CI [+0.0022, +0.0515]`）。同时显隐背离度 `|z_exp - z_imp|` 具有严格域特异性（`Race <-> Politics r = -0.036, p = 0.63`；`Race <-> Self r = -0.081, p = 0.29`），且自尊存在方法双分离（`IAT+ -> rsnbrg r = 0.1374` 对 `AMP+EPT -> _estmDrct r = 0.0814`）。

## S4. 保留的反例、零结果与方法学边界

1. **离散近似的时间细分漂移：** `LTCCell` 在不规则延时下积累高达 `30.68%` 的时间细分误差并在终点完全丢失首轮印迹（`0.0`）。
2. **等衰减率不可识别屏障：** 当共有与私有衰减率相等（`r_c = r_p1 = r_p2`）时，动态 LP 边界无法收敛（宽度 `3.8343`、可分率 `0/60`）。
3. **共形覆盖与无解拒斥：** 共形标定（`0.90`）在 PANDORA 留出集如实拒斥 `13..18/96` 失配路径；必须以 `None` 保留拒斥报告，严禁强行投影。
4. **域内诚实零结果：** RealPersonaChat 问卷—动态相关性检出 `0/252`（`q_BH >= 0.1245`）且无重新激活提升为零（`-0.0016`）；ESConv 过程分离不自动蕴含情绪缓解（`p >= 0.309`）；显隐差异不跨领域泛化。
5. **群体与工具非通用性：** 四套公开数据集相互隔离且分别对应特定人群与文本体裁，不得拼接为同一潜在人格模型或临床筛查分数。

## S5. 新增可证伪命题（P12–P15）

- **命题 12（不规则采样下的半群不变性）。** 合法的连续时间语言读取器必须在任意间隙细分与 `dt = 0` 拼接下保持状态转移在浮点容差内不变。若细分后轨迹发生非数值噪音级的系统偏离，则该读取器被否证。
- **命题 13（动态集合反演的速率分离条件）。** 跨视角多时点线性规划能够严格收紧共同轨迹区间，当且仅当共同转移与私有转移算子在可观测步长上线性可分；等衰减率在结构上不可识别。
- **命题 14（人际唤起、动态斜率与自陈量表非同源）。** 在自然对话中，说话人唤起伴侣的行为变化及其人际适应斜率，能够解释跨不交伴侣评价中不被自陈量表覆盖的增量方差（`ΔR² > 0`）。若自陈组合可完全吸收跨面板动态方差，则本命题被否证。
- **命题 15（显隐背离的域特异性与叙事时序依赖性）。** 显隐分歧在不同态度域间保持低跨区相关，且投射叙事轨迹效标依赖于真实句序而非词袋/句袋随机排列。
