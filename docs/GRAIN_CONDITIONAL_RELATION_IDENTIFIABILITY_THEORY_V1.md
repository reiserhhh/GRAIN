## 1. A perfect transport fit may contain no testable assertion

Let X,Y contain aligned neutral and styled high-minus-low response rows. A
common linear expression map Y=XB exists iff ker(X.T) is a subset of ker(Y.T).
Necessity follows by applying a source relation c.T X=0 to XB. For sufficiency,
define the map c.T X -> c.T Y on the row span;the kernel inclusion makes that
definition well-defined,then extend it to the ambient space. Offsets cancel in
high-minus-low contrasts. This does not imply every text mechanism is linear.

Let Q_X project onto ker(X.T). The observable constraint is Q_X Y=0. If X has
full row rank,then Q_X=0 and ANY Y admits a linear map. If X and Y have full row
rank in the same ambient dimension,an invertible extension also exists. Its
existence is not evidence for a general population transport or a causal path.
It makes no prediction outside the observed row span without added structure.

justified restrictions that make different hypotheses disagree on observations.

author selection P(c|theta,opportunity),conditional expression P(x|c,theta)

One candidate is the conditional predictive likelihood path of a fixed local
