## 1. The Object Is an Action Law, Not Only a Vector

Let H be the four exact post-layer16 property states, c the other receiver
states and their layout, and q the fixed target query. Write

    F_q(H,c) = digit-expectation native score,
    alpha_q(H,c) = d_H F_q(H,c),
    A_q(H,c;delta) = [F_q(H+delta,c)-F_q(H-delta,c)]/2.

At fixed H, the query state and every other receiver state belong to c. The
relative perturbation radius is .01 of the donor property's norm; calculations
use actual float32 endpoints, not intended real-valued displacements. Equal H
means byte-identical arrays; equal delta means identical actual half-deltas.

H itself already encodes donor context. Recombining H with receiver c separates
that encoded context from the unpatched context that modulates its later use.
It does not erase context or claim to isolate a human trait.

## 2. A Necessary Condition for an H-Only Action Law

Suppose F_q(H,c)=f_q(H)+b_q(c). Then alpha_q(H,c)=df_q(H), and symmetric finite
actions depend only on H and delta, regardless of the context-dependent offset.
Consequently different gradients or finite actions at identical H refute this
restricted action law on the observed configurations. A level difference alone
would not do so: F(H,c)=H^2+b(c) changes levels without changing property action.

Conversely, if alpha is context-independent throughout a connected H-domain,
integration gives F_q(H,c)=f_q(H)+b_q(c) on that domain. This converse needs the
whole domain and differentiability; equality on finitely many points is not
enough. Our experiment tests only the necessary condition on48 finite units.

The map pi(H,c)=H suggests the differential-geometric question of whether an
observation descends through a projection. Here c is a finite decoder state and
can have different sequence lengths. We do not construct a principal bundle,
connection curvature or a Lie-group action from it. The proof above is our
elementary action condition, not a borrowed PDE uniqueness theorem.

## 3. A Quantitative Obstruction, Not Another Accuracy Grid

For two receivers with the same H, let a0=A_q(H,c0;delta) and
a1=A_q(H,c1;delta). Every H-only prediction p must satisfy

    [(a0-p)^2+(a1-p)^2]/2
      = (p-(a0+a1)/2)^2 + (a0-a1)^2/4.

The best shared prediction is their mean, and the minimum error is their
conditional variance. The population L2 analogue is

    E[(A-f(H))^2] = E[Var(A|H)] + E[(E[A|H]-f(H))^2].

The finite diagnostic grants a different oracle prediction to each donor cell.
This is at least as permissive as a single compiled H-only model. Its lower
bound is optimistic; it is not a validation-selected model or a prediction
trained on held outcomes. Additional collisions between donor cells could
increase the actual H-only obstruction.

For the equally weighted2x2 donor/receiver product projection, this bound equals
receiver energy plus donor-by-receiver interaction energy. The same identity
holds for vector-valued gradients with squared Euclidean norm. Raw gradients,
moment covectors and task projections have different units and must be kept
separate. The two fixed action directions define a seminorm, not all information.
