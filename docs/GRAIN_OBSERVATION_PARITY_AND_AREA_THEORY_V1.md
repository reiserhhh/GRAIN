## 2. Upstream invariance is an exact obstruction

Let tau exchange the two actions in the fixed event-1/event-2 templates.
For a text observation G, its C2 sectors are

    G_even(T) = (G(T) + G(tau T))/2
    G_odd(T)  = (G(T) - G(tau T))/2.

All 72 unordered exchange pairs have exactly equal sparse whole TF-IDF
vectors. Thus the actual deterministic whole-SVD/factor readouts are equal.
If Phi(T)=Phi(tau T) but F(T)!=F(tau T), no function f(Phi(T)) can reconstruct
that particular distinction. This is a finite, explicit collision argument;
precision, regularization and nonlinear capacity cannot cure it.

Do not generalize this to every embedding or the whole GRAIN framework.
It is a property of the inherited bag-of-1/2-grams instrument and these
templates. Neural contextual means were already sensitive in HM93.
Also do not infer that the target distinction is psychological merely because
its target direction was named after a trait.

## 3. Retaining direction is insufficient after author aggregation

For common event coordinates x_i, the first-order edge observation is

    D(i,j) = x_j - x_i.

It is odd under exchange. For any closed sequence i_0,...,i_T=i_0,

    sum_t D(i_t,i_(t+1)) = 0.

This is telescoping, equivalently the zero integral of an exact graph
1-cochain on a cycle. The assumption of common point coordinates matters:
contextual neural values need not share it. Here the actual frozen lexical
event vectors exchange exactly and the assumption is empirically checked.
HM96 event-step odd maximum is 3.239934, but all 24 matched cycle contrasts
are zero to roundoff. A larger local directional response would not fix this.

## 4. A pair-dependent second-order observation survives

With event coordinates X,Y and the fixed neutral third event Z, define

    A(X,Y;Z) = ((X-Z)(Y-Z)^T - (Y-Z)(X-Z)^T)/2.

Retain its six upper-triangular entries, not one selected coordinate. This is
the signed triangular area of the three-point polygon, a second-level
signature-area construction. It is translation-invariant and exchange-odd.

    A(X,Y;Z) = -A(Y,X;Z).
    A'(RX,RY;RZ) = R A(X,Y;Z) R^T.

For orthogonal R its Frobenius norm is invariant. For general invertible R
the tensor still transforms covariantly but its Euclidean norm is NOT
invariant. Norms depend on the fixed reference metric; psychological meaning
is not produced by a coordinate rotation.

For a balanced author's directed edge law J,

    G_area(u,c) = sum_(i,j) J_u,c(i,j) A_c(i,j).
    V_target(u,c,q) = sum_(i,j) J_u,c(i,j) F_c,q(i,j).

Both observe the SAME directed composition in their own units. On the finite
three-state complete graph there is only one independent divergence-free
cycle direction C. With matched symmetric traffic S and J=S+alpha C,

    G_area = <S,A> + alpha <C,A>,
    V_target = <S,F> + alpha <C,F>.

The common alpha is a designed path coefficient, not a personality latent
variable. Nonzero responses in both instruments identify a common mechanism
object but NOT equal coordinates, a universal score map or shared trait validity.
The one-dimensional cycle restriction makes this a limited construction,
not identification of arbitrary natural high-dimensional paths.
