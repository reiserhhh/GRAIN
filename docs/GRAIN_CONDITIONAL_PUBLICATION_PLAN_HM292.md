## New interface,not known-method replication or accuracy rescue

source conditional mean for next encoded cells. HM171 supplies a static E
criterion link. HM212 source-qualifies native A action. HM291 supplies actual

The new construction measures CURRENT observed conditional publication fields,
not another forecast of later metadata and not another source-author posterior.

SOURCE-author groups. No conditional-mean or random-effects theorem is new.

## Observation and scoring units

Retain all386 SOURCE/120 historical held authors,each two18-comment windows.
Each of17 within-window pairs has the original current8-state address a and
three actual outputs b:log1p next captured span,log1p elapsed cached-record
seconds,and same exact venue. No boundary pair. These are publication/selection/
opportunity observations,not offline action,controlled stimulus response or
emotion. Time windows span months/years,not single clinical conversations.

Compile the reference using only calibration-bank authors,both text views and
equal author/view weights. Let mu/sigma be reference output moments,z=(b-mu)/sigma,
R(a) the reference address law,psi(a)=E_SOURCE[z|a]. Keep every observed address.
For a new observed window,

    P_u(a)=mean_t 1[a_t=a]
    J_u(a,b)=mean_t 1[a_t=a] z_tb
    O_u(a,b)=P_u(a)psi_b(a)
    D_u=J_u-O_u.

Reference J0=R*psi. In the declared finite tensor metric,

    phi_J=(J-J0)/sqrt(R),phi_O=(O-J0)/sqrt(R),phi_D=D/sqrt(R)
    phi_J=phi_O+phi_D.

No component is deleted or called pure personality/noise. When P_u(a)=0,the
joint moment is0 but an individual's conditional mean is UNKNOWN;export the
support mask. D is a weighted deviation,not an identified complete B_u operator.
Fixed two-coordinate/venue-bit addresses do not control all context/semantics.

The cold scorer receives only recorded publication pairs and an immutable
numeric reference. It uses no current-person labels,model judgments or batch
normalization. It measures the supplied window,not predicts an unseen next
window. Upstream vector address extraction remains neural-derived.

## Decisions

* Joint/opportunity criterion contact:existing scales align with observable
  conditional organization,not automatically a private causal response.
* Response contact or author continuity:weighted within-address publication
  deviations are a distinct usable measuring object;name only what is observed.
* Response failure with joint/opportunity success:do not remove opportunity
  to purify personality,or erase the older static/choice links.
* Changing signs/negative controls:retain them,not rescue them through precision,
  new bins,regularization or selective criteria/observations.

Acceptance is complete honest calculation,not guaranteed positive r. Focused
tests:cold author/label boundary,source/app separation,missing support,moment
and covariance reconstruction,unaltered batch reference,source-only criterion
orientation,and a null synthetic source. Scientific outcomes separate from tests.
