# HM186: Condition-expression pairing as an author observation

Frozen before result construction. This packet does not optimize prediction,
reconstruction, rank, heads, kernels, folds, label cuts or weights.

## Scientific decision

HM185 found strong recurrence within the same source authors but no positive
registered cross-author joint profile-mean bank. Inventory HM171/174/176/178/182
and HM81 shows existing source target calibration, joint author observations,
event assembly and conditional choice. The unresolved interface here is
**natural event-condition pairing at fixed vector bags and condition counts**.
HM81's covariance identity is already known; its histories had balanced designed
conditions. This is not a rediscovery of covariance or a new mathematical theorem.

Competing explanations: (1) vector level and condition prevalence suffice for
the current target association; (2) their actual pairing carries a cross-author
target-linked observation; (3) pairing repeats within authors but not between
authors. The new construction reads all three accounts, not only the winner.

## Source and observation family

Reuse the same 386 authorized numeric SOURCE authors and inherited binary E/N/A/C/O
labels, two disjoint original-slot 12-comment views, normalized full1024 E5 and
fixed1024x15 map. Reuse HM185's frozen profile-stratified 203/183 author folds;
no fold selection. Restore HM170's chronological condition array to original
event slots via the inverse `original_units` permutation, and verify coordinates.
Conditions are the old source TOP20 venue bit, not a full topic/situation parser.
Keep all authors including zero mixed-condition opportunity. No raw/private text,
application questionnaire, native answers, new neural calls, API or training.

For n events and binary recorded c:

    mu = mean(h); p = mean(c); m = mean(c h)
    rho = m - p mu = mean((c-p) h)
    opportunity = p(1-p)
    delta = rho/opportunity = mean(h|c=1)-mean(h|c=0), if 0<p<1.

The tuple (p,mu,m,rho,opportunity,delta/support) is retained. Nothing is removed
from h. A zero rho at p=0/1 means no mixed-condition opportunity, not a neutral
person or zero psychological response. Delta is missing there, never imputed0.
It is a conditional observational contrast, not a causal individual B_u.

S_n acts by relinking c to the unchanged h slots. Its average m is p mu; rho is
the pairing-sensitive observation. Simultaneous reordering of c and h preserves
the tuple. Relinking is a numerical relational null, not a generated valid text,
real environmental intervention, or permission to delete invariant information.

## Source construction and frozen comparisons

For each fixed author fold b, view v and target q, construct author-balanced
high-minus-low covectors for mu and rho. These use natural marginal trait groups,
not HM185's uniform32-profile reference or matching other4 labels. Therefore they
are not unique trait effects or a directly comparable accuracy improvement.
Keep E/N/A/C/O, mean/pairing, full/retained/complement spaces and all signed terms.
Report choice prevalence contrasts separately. Normalized delta is an output,
not a selected primary feature or an opportunity-filtered author subgroup.

Primary J is the sum over all five full-E5 rho covectors of cross-author-fold
inner products, averaged over the four view pairings. Report same-view,
different-view and within-fold cross-view products. No coordinate alignment.

Two separately fixed199 reference families:

1. Whole five-bit label profiles shuffled inside each fixed author fold, the
   same reassignment for both text views. Profile counts/dependence retained.
2. Conditions independently relinked within each original author/view, preserving
   its complete vector bag, mu, condition count, p and opportunity exactly.

Upper rank=(1+number reference J>=observed J)/200. Promote this specific shared
pairing bank only if J>0 and both ranks<=.05. Other target/space/kind comparisons
are fully retained, descriptive and unadjusted; no favorable cell selection.
Relinking unchanged mean/choice is by construction, not empirical validation.
Any negative or failed outcome remains; no rescue grid or science rerun.
