## 3. Different events are not automatically independent

Under independent condition-specific draws with fixed conditional means,
E[U] equals the population conditional-displacement outer product. This
expectation is not assumed for natural comments.

More generally, write z_(c,j)=m_c+e_(c,j), with zero-mean errors conditional
on the declared author/condition/count. Let C_cc^neq be the average ordered
cross-event covariance inside condition c, and C_10/C_01 the average
cross-condition covariance matrices. Then the same algebra gives

    E[U] = (m_1-m_0)(m_1-m_0)^T
           + C_11^neq + C_00^neq - C_10 - C_01.

This identifies what is still being observed: conditional displacement PLUS
cross-event dependence. A common occasion, temporal relation or stable
author response may contribute to those terms. They are not garbage merely
because an independence model calls them error. V also retains dispersion
and count dependence; it is not declared pure noise.

Exhaustive toy tests distinguish independent zero-displacement events
(E[M,U,V]=[1,0,1]) from correlated repeated events ([2,2,0]). Other tests
retain a true displacement, negative U, singleton missingness, orthogonal
coordinate covariance and the direct-pair identity. These tests establish
the observation distinction, not synthetic-persona validity.
