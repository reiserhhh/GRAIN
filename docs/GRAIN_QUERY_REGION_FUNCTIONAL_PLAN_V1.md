## 要发现的数学对象

同一查询的P区域token在作者间可逐位对齐；文字不变，但隐藏状态Z_q(x)随
证据而变。当前P的实际作用已经测到。下一步问：这些矩阵变化是否可以通过
参照作者共享的功能矩阵读出，而非每位作者都运行完整后段模型？

设固定末Q0、两个证据状态E0/E1，D=Z1−Z0。前包对称P作用满足：

    Phi_P = .5 * sum_{e=0,1} integral_0^1
            <gradient_Z F(E_e,Z0+tD,Q0), D>_F dt.

这是原函数上的微积分恒等式；候选可运输模型则是：

    predicted Phi_P = <G_ref,q, D>_F.

两者不同。要寻找的是G的共同、token位置特异和查询特异结构，不是只把
上一公式的积分重建r算到更高。每个查询可有自己的矩阵，不强制统一人格轴。

## 最小执行顺序

1. 仅复用4作者的全状态及第二包区域/端点，不读量表、不改提示、不新取正文。
2. 对每query、每作者、两个E条件，在t=0/.5/1采样P梯度，权重不求导；
   记录实际Phi_P与Simpson近似，以及每个token的有符号贡献。
3. 只由既有2参照作者估计G_ref；2评估作者仅使用已缓存D计算输出，不用
   评估梯度参与拟合。报告每人的误差、符号和合并能量误差，不对2个点报r。
4. 同时记录梯度矩阵的可压缩性、均值读出与逐token读出的区别、TF/N/确认
   在共同表示中的共享/专属关系。不同长度的查询先在各自坐标内分析，不因
   同为1536隐维就任意拼接；若要比较token功能需预先声明对齐。

每个人的局部积分可诊断数学构造，跨作者冻结矩阵才回答复用问题。保留所有
查询，不按问卷表现挑N神经元，不事后改变参照划分。
