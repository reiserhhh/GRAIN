## What has been built

The original prefix-dependent equation is now connected to raw text by two
implemented construction routes. Both have been compared under real and
synthetic reader references, on controlled worlds, natural edits and existing
permitted human endpoints. No questionnaire target was used in construction.

~~~text
raw author excerpts + fixed query
    |
    +-- fixed token table, explicit correspondence and input derivatives
    |       -> two projected evidence values -> fixed score                 [B0]
    |
    +-- four extracted contextual blocks
            +-- contextual correspondence + pulled-back derivatives
            |       -> two projected evidence values -> fixed score         [B4]
            |
            +-- early query/end coordinates
                    -> residual-state operator -> P_hat/Q_hat -> score     [A]
                    -> exactly compiled affine reader -> same score        [A1]
    |
    +-- full frozen prefix -> actual P/Q -> fixed function/native controls
~~~

P is the ordered query-region hidden rows; Q is the distinct final input-position
hidden vector, not the attention Q weight matrix. Queries have their own token
coordinates, system instructions, output coding and reader. The fixed-reference
author position is an additional population-relative transformation, not part
of the neural construction reference.

Three distinctions make the framework usable: level reconstruction is not edit
response recovery; either is separate from human psychological association; and
runtime independence is separate from independence of pretrained knowledge.
These are measured distinctions in this packet, not reasons to discard the
positive effects. R_real/R_synth changes reader provenance while B's upstream
chart origins remain the same synthetic texts.

## Remaining mechanism, outside finite execution closure

The next high-value question is how to construct the **conditional derivative**:
why does the same type of evidence edit change different texts by different amounts?
The affine program has constant derivative in early-state coordinates. Adding
more coverage can improve levels without supplying the missing response rule.

A next-stage test should use only separate source-reference authors and fit a
bounded value-and-secant candidate:

~~~text
L = mean_i ||f_hat(x_i)-f_teacher(x_i)||^2
  + lambda mean_(i,j) ||[f_hat(x_j)-f_hat(x_i)]
                       -[f_teacher(x_j)-f_teacher(x_i)]||^2
~~~

Fit one fixed condition-aware model and a value-only comparator, not a human-label
grid. Keep the twelve existing evaluation authors and46 participants outside
construction. Freeze coefficients before repeated exploratory external links.
This follows the value-plus-derivative idea in
[Sobolev Training for Neural Networks](https://arxiv.org/abs/1706.04859);
finite semantic edits are secants, not differentiable text or exact gradients.
It is a proposed subsequent mechanism experiment, not an unrun branch being
counted toward this completed finite packet. Full34-query independence, persona
write/read duality, cross-model transport and new human studies remain pending.
