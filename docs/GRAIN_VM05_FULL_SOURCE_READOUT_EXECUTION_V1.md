## Inputs / outputs

`--views`, `--preflight-dir`, `--parent-dir`, `--prepared-root`, `--vector-dir`,
`--task`, `--site`, `--readout`, `--output-dir`; optional `--arm`,
`--exclude-reference`, `--no-pca`, `--preflight-only`, `--max-seconds`.

Each private result contains supervisor status/log and `fit/` with the source
manifest, cache evidence, feature commitment, source snapshot, target-support

Preflight ends before label conversion and writes no target-support file or head.
