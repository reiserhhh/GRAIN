## Construction before application outcomes

Let P_u(a) be author u's observed frequency of cell a=(c,s), using the SAME
current events as HM170. With U source authors, R(a)=mean_u P_u(a). For trait q,
Y_uq=1{label_uq>source-author median_q}. This is an author outcome, not one
new psychological trial per comment. Source weights preserve one mass/author:

    pi_q = mean_u Y_uq
    J_q(a) = mean_u P_u(a)Y_uq
    psi_q(a) = J_q(a)/R(a)
    rho1_q(a) = J_q(a)/pi_q
    rho0_q(a) = [R(a)-J_q(a)]/[1-pi_q]
    w_q(a) = psi_q(a)-pi_q
           = pi_q(1-pi_q)[rho1_q(a)-rho0_q(a)]/R(a).

This standard Bayes density-contrast identity tells us HOW source outcome
meaning orients a numeric function. It does not identify an innate trait-word
axis or justify multiplying correlated comment likelihoods. Zero source support
stays unsupported; no pseudocounts, smoothing, extrapolation or app fit.

Cold reading theta_uq=sum_a P_u(a)w_q(a) remains a source-observation functional,
not P(author trait high|all comments). Return source-reference difference,
choice and within as in HM170, preserving both. The scorer receives only
existing current event coordinates/conditions/identities, not author labels,
future observations or fitted application parameters.

For the8-cell field, use the standard Z2^3 Walsh basis with bits coordinate0,
coordinate5,condition. All7 nonconstant coefficients are retained. Separate
condition-only mask4, coordinate-only masks1/2/3, and condition-interaction
masks5/6/7; center their author moments at the SAME source reference.
These components are not the same decomposition as choice/within and are NOT
causal psychological pathways or information fractions.
