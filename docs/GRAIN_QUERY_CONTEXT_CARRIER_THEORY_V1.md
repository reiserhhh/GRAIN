# GRAIN：查询文字、上下文化状态与功能载体的区分

2026-09-08。继自然响应构造V1；依据
[两个实际干预包](../reports/grain_vector_mechanisms/FULL_STATE_CONTEXT_CARRIER_REPORT.md)。

后续：提问区功能矩阵包已完成，见[token功能构造理论](GRAIN_TOKEN_FUNCTIONAL_CONSTRUCTION_THEORY_V1.md)。
以下保留形成该包的推导。

## 1. 从相关分账到同输入反事实

上一轮识别到不同查询的有符号协方差抵消，本轮通过实际状态替换看到同输入
内部的相反贡献和边际方向反转。它们是固定模型内的可重放计算，不需要先
证明人格预测精度很高，才能把这些机制作为研究对象。

但仍区分两个层面：上下文和查询区是操作性位置分区，不直接等于人的心理
结构；四个人的机制实例不自动给出总体上的频率。这些边界不抹去实例的存在。

## 2. 为什么相同问题文字可以携带不同作者的信息

固定查询q时，其输入token相同，初始词嵌入也由固定权重决定。但是在因果
Transformer内，后置问题token经过各层计算后可以吸收前面的证据与布局信息：

    Z_q(x)=H^(16)_{P_q}(x),  通常 Z_q(x) != Z_q(x').

“上下文化token”是既有Transformer的基本机制，不是GRAIN新发明。本轮新增的
经验定位是：在这个人格推论任务和声明干预下，P区不只是被动伴随变化，而是
通过状态替换对最终读出产生可观作用；其分配RMS在三个查询中均大于前方E区。

文字不变、状态变、读出随替换改变，构成一个具体的作者输入→查询状态→判断
接口。这里包含上下文/长度/位置等条件，不能仅凭接口存在就叫纯人格语义轴。

## 3. 分层条件不能在代数上偷换

完整状态四格给出：

    Delta = Gamma + Phi_R + Phi_Q,
    Phi_R = .5*[R_effect(Q0)+R_effect(Q1)].

本轮第二包测的是：

    R_effect(Q0) = Phi_E(Q0)+Phi_P(Q0).

因此Phi_E(Q0)+Phi_P(Q0)不能直接替换完整式中的Phi_R。两个Q1下的E/P单独
端点尚未测量；若未来问题需要无条件三块分配，可补齐完整三因子立方体。
目前已足以决定研究P载体，不为凑齐恒等式而自动追加不改变主线选择的调用。

Gamma显式吸收对齐、压缩布局、标题历史和重分词边界的重基准。P运输位置
本轮全部token相同，正文/脚手架边界的少量新token另列；不以向量近邻伪配。
这种可追溯重基准让跨长度比较可计算，同时防止把Gamma任意命名为噪声。

## 4. 下一数学对象不是新的单一人格轴

P由36或62个token组成，每个token为1536维。首先保留矩阵，而不是均值：

    D_q=Z_q(Ex)-Z_q(x),
    response approximation=<G_ref,q,D_q>_F.

查询区的token次序与每个位置的功能敏感度可以不同。若平均会抹去正负抵消，
就保留token级加权；若有稳定低秩结构，再压缩。新公式的目标先是已观测的
Phi_P，不是未经证明将其替换完整Delta，更不是立刻替代外部量表。

真正待发现的是G的可运输条件、共享/专属结构，以及它与作者参照空间的关系。
精确路径积分用于理解原函数，冻结参照矩阵用于测试可复用构造，二者分开。
下一包已固定在[提问区功能矩阵计划](GRAIN_QUERY_REGION_FUNCTIONAL_PLAN_V1.md)。

这保留4W骨架：where限定布局与条件；what是证据及其查询化表示；who存在于
相对作者群体的响应配置；when需另有真实时间/顺序材料。本轮不是时间研究。
实践目标仍是先用固定向量化过程形成证据，再由可解释的数学读出承接判断，
而非让LLM自己生成一段理由后把理由当机制证明。
