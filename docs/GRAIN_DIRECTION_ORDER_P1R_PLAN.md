criteria). Reverse exactly the two named action lines, not content/ownership;
preserve the header, question and output code. No new wording, person or template.

or complementary donor state (192 patches). Compare with all matched original
P1P cases; no room or random-direction rerun since they do not resolve this
confounding question. The absence of new random controls limits any new claim of
order-invariant direction specificity. Person event/trait anchors share prefixes.

per person/criterion (4); original native replay for those4 cells. Save RAW A/B

## Outcomes and interpretation

Paired per-setting native truth/preference, natural and projected shifts,
projected normalized error, complement relative RMS, intended-direction fraction,
projection energy, and original-minus-reversed differences. Preserve absolute RMS
when normalized denominators are small. Use P1P's descriptive .5/.5 bounds without
retuning. Every setting and both criteria reported, not only pooled scores.

If successes follow order, the fixed direction is partly sequence-conditioned;
if they stay with the same setting, order alone is not sufficient explanation
(wording remains confounded with scenario). Mixed changes motivate interaction,
not a universal axis or a new rank search. Exact paired changes support only this
synthetic transformation. Native always-Yes attribution, old code/polarity failures,
one model/trait cue and lack of human validity remain regardless of outcome.

Independently replay text reversal, token/donor alignment, stored projection
