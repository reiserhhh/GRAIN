# 同材料路径如何接上关系模式的辅助解释

2026-09-11。对用户两个补充的定向文献复查；接续已经完成的 NEXT27–28，
不是重新宣称刚建立了同材料接口，也不是启动临床评估系统。

## 1. 现在实际接到哪里

同一评论/词法切片/token 地址上的 GRAIN 配置与查询响应已经分阶段接通：
评论级联合统计、精确跨度分配、GRAIN 方向上的原生局部作用、查询条件下的
选择测度。NEXT74 又从源作者学习这个选择函数，新的材料上选择分布更接近
原模型，但响应幅度仍需发展。简单“按路径越重要就给 GRAIN 越大正权重”
不等于当前有符号协方差/方向作用；后者能保留支持与反向作用。

建议保持四层，而不是直接把词贴成患者特征：

1. **材料层**：同一文本地址、真实说话者、被转述对象和相邻轮。
2. **数值层**：固定 GRAIN 参照和查询函数，输出位置、选择、方向响应。
3. **观察编码层**：依据公开操作定义独立编码可见表达/关系事件。
4. **解释层**：展示证据、候选含义与替代解释；由人复核，不反向改数值。

这里第三层可以不依赖 Big5；行为/关系事件是另一种外部联系。它也不必等价于
传统投映测验。要保留患者与心理师的真正双向交流、患者转述他人这两类不同材料。

## 2. 新增直接先例及方法差异

**AutoPsyC（Hossain 等，CLPsych 2025）**使用141份约90分钟 OPD 访谈，
结合摘要、检索、专门化模型和加权投票识别四类心理动力冲突。Table1 的
weighted F1 为 .78/.81/.59/.58，不是 Big5 相关或真人诊断的泛化准确率。
关键借鉴是：查询有操作定义，局部片段与完整叙事共同保留。我们可先研究某个
关系编码查询如何选择证据，而不复制其临床判定或把标签当无意识动机的真值。
[原文](https://aclanthology.org/2025.clpsych-1.2.pdf)

**Antichi 等（2026）**在单个案例前两次会谈上，用结构化提示进行防御编码，
比较人工和 LLM 的判断。这支持“提出可复核候选”的研究定位；单案例与分歧
也提示我们，模型解释不能反过来当独立标签。本轮复查确认其研究设计，不将其
结果升级为成熟临床编码器。[原文](https://link.springer.com/article/10.1007/s12144-026-09685-3)

**Zamojska 与 Chudziak（PACLIC 2025）**研究 Parent/Adult/Child 代理与记忆检索，
每条件22段模拟工作场景对话。它适合设计条件已知的互动玩具世界；不是从真人
文本验证 CP/NP/A/FC/AC 的逆向分类。公开描述与旧 TEG 代理结果继续分开。
[原文](https://aclanthology.org/2025.paclic-1.55.pdf)

## 3. 最小可接入实验，暂不新增临床数据使用

先做“同材料、两查询、同数值程序”的机制比较，而非拟人化诊断。未来获授权
的连续对话可用三类条件：完整前后轮、孤立该句、保留措辞但换说话者/转述关系。
源训练与独立应用必须保持同一地址契约。观察 GRAIN 位置是否相近、查询选择
与响应是否因关系上下文而改变，再与盲编码的关系事件比较。

固定输出：证据地址、叙事角色、观察描述、数值读数、候选解释、反例/替代解释、
缺失背景、人工审核状态。没有疾病严重度、治疗建议或无意识动机确定性字段。
评估先看证据定位和编码一致性，再看候选构念关系；不能拿解释器看过分数后
生成的标签去“验证”同一分数。既有 `MEPS` 数据本轮未读取或外传。

后续 NEXT75 已完成：源响应坐标改善native-query响应幅度，但与直接教学目标
仍有差异。数值方向、查询选择与解释编码的分层因此继续保留，不能单凭某个
相关升降改变因子的人格名称。见[响应坐标理论](GRAIN_SOURCE_RESPONSE_COORDINATES_THEORY_V1.md)。

NEXT76内容值通道与NEXT77源端点组装均已完成。同一材料的GRAIN方向现在可以
沿源构建的完整局部函数求query响应，应用不再需要当前材料的专属g；H16仍保留。
新8局部分数查询差r=.545-.690，但方向幅度有高估。NEXT78已将两查询差精确
分为共同读法的证据变化与差异读法的共同证据：后者对scalar作者差异重要，
对正文响应却可以反向调制。下一NEXT79尝试上下文条件化的差异读法，而不是
无条件给某类文本更大的正权重。这也保留了关系背景影响解释的数值入口。
这个解释方向保留为已有主线的下游接口，不另开临床训练队列，也不把两套方法
作用提前假定为相加。见[查询差理论](GRAIN_ENDPOINT_QUERY_CONTRAST_THEORY_V1.md)。

NEXT79已完成：上下文加权不能解决有限源reader缺少方向的问题，新8差异reader
向量误差78.60%在源仿射空间外。NEXT80将教“读法怎样随语境移动”，而不是仅
给已有读法重新加权。这为相同文字在不同关系背景下的读法提供新的候选接口，
但本轮未新增关系/临床编码数据，未将数值向量误差解释成人格信息比例。见
[条件reader理论](GRAIN_CONTEXT_DIFFERENTIAL_READER_THEORY_V1.md)。
