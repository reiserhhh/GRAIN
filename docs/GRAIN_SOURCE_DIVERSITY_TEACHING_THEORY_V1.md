# 从源材料覆盖到双查询的可识别读法

2026-09-11，NEXT88/pass77。目标仍是从同一作者材料建立 GRAIN 方向与人格
查询之间可计算的联系。本轮增加不重合源材料，而非调节评价集上的参数。

## 1. 发现：可用作用关系需要被源材料覆盖

相同输入特征、Gaussian核、权重、lambda和上游程序，源4扩大到12后，
兼容作用坐标F02的排序从-.303到+.685，F03从-.755到+.554；对应坐标误差
下降，实际组装K+V误差也从7.2865降到6.9033。因而旧四源上的弱或反向
关系不是“这种GRAIN方向没有信息”的充分依据。新增材料教出了新的函数
变化，而不是创造或重新命名GRAIN因子。

仍然区分有限材料发现与总体定理：当前八评价作者未参与拟合，但已经用于
多轮探索。F01相关提升却未改善误差，scalar排序变差；保留各自结论。
源覆盖改善不是“样本一多所有误差自动归零”。输入压缩、条件依赖和目标
定义都会影响可以学出的函数。

## 2. 为什么查询差变好，某个查询却变差

记两个query的当前证据为p_N,p_C，共同与差异读法为m,d：

\[
\hat s_N=p_N^T(m+d/2),\quad \hat s_C=p_C^T(m-d/2),
\quad \bar p=(p_N+p_C)/2,\quad \Delta p=p_N-p_C.
\]
\[
D=\hat s_N-\hat s_C=\Delta p^Tm+\bar p^Td,
\qquad A=(\hat s_N+\hat s_C)/2=\bar p^Tm+\tfrac14\Delta p^Td.
\]

NEXT87/88对每个作用j只教D_j。其五行R_j=bar(p_j)^T/u_j，最小修正lift
保留ker(R)里的旧baseline分量。若v属于ker(R)，d换成d+v不改变五个D，
但可能通过Delta(p)^T v/4同时移动两个query。**差异观测不确定共同读数。**

这比“共同reader固定导致失败”更精确：固定m也可以通过更多d方向满足
两个绝对目标；若两query证据组成的相应矩阵满行秩，线性方程可以同时解。
现在未学习那些约束，不能把一种最小修正规则的结果当成数学不可能性。
`tests/test_grain_joint_query_identifiability.py`给出四个合成见证：同差异/不同
平均、固定m仍可满足两个目标、双查询lift精确闭合十个作用值、成对误差分解。

还有一个直接平方误差恒等式：令e_A=(e_N+e_C)/2，e_D=e_N-e_C，则
e_N²+e_C²=2e_A²+e_D²/2。只优化e_D没有约束另一项。它是逐材料/逐作用
的代数，不依赖正态分布，也不等价于任何人格量表误差理论。

## 3. 下一接口：先教共同观测，再决定内部表示

每个q保留五个观察向量P_q：一行primal，四行锚定GRAIN total方向。
固定旧单位u与原点r0_q=m0+s_q*d0/2，s_N=+1,s_C=-1：

\[
R_q=\mathrm{diag}(u)^{-1}\widehat P_q,\qquad
R_{qj}=\widehat p_{qj}^T/u_j,
\]
\[
c^*_{qj}=[t_{qj}-\widehat p_{qj}^Tr0_q]/u_j,
\qquad \hat r_q=r_{bq}+R_q^+[\hat c_q-R_q(r_{bq}-r0_q)].
\]

矩阵写法准确为R_q=diag(u)^(-1) P_hat_q。满行秩时逐query/作用误差仍为
u_j(c_hat_qj-c_star_qj)。将十个目标用同一source12核学出，既保留原contrast，
也约束平均和两个绝对query。两个reader的mean/difference可以事后精确
重组；这不是宣称恢复唯一原生m,d。原生向量与有效功能等价类继续分开。
应用时P_hat和GRAIN来自同一材料，不使用当前native reader或目标。

全导数必须包括DR、Dc和baseline导数；四个锚定方向观察值不能偷换为该
对角函数的全导数。新接合保持这一点。H16神经编码依赖也没有被删除。

## 4. 文献如何帮助而不是替代本轮证据

[Grunewalder等，2012](https://arxiv.org/abs/1205.4656)将条件均值嵌入联系到
向量值回归，可借鉴其“学的是给定输入下的函数值”视角。我们当前五维/十维
目标是有限功能坐标，不是完整条件分布嵌入；不能直接套其收敛率。
[Tamas与Csaji，2024](https://jmlr.org/papers/v25/23-0168.html)给出条件核均值
估计的一致性结果。其意义是明确假设与估计对象，而非从source4->12推出
一致性已在本数据成立。
[Shimizu等，2024](https://proceedings.mlr.press/v235/shimizu24a.html)讨论条件
嵌入的表示能力与可扩展性，并结合神经网络。它提醒我们区分输入/表示能力
与样本覆盖；本轮不因此增加新网络或展开调参。
[Donti等，2017](https://arxiv.org/abs/1703.04529)的任务导向学习支持将目标
对准下游用途。NEXT88的直接证据则来自固定配置、相同材料接口下的比较。

## 5. 接回用户的两个补充

同一句/同组文本既有GRAIN群体位置，也有query读取规则。当前最实用的
接合是“这些方向怎样改变这个query的局部读取”，不是分数简单相加。
多源材料可以学习这种作用的方向和大小，F02/F03已出现具体进展。

用于精神动力/交流关系辅助解释时，保留文本地址、说话者、查询对象、方向
作用与独立可见行为编码。两个绝对query的输出尤其重要：一个对比值不能
区分“两种倾向都强”和“两种都弱”。LLM可组织这些证据，但不把自身
生成的解释再拿来充当数值通道的独立真值。本轮未新增临床判定或MEPS读取。
