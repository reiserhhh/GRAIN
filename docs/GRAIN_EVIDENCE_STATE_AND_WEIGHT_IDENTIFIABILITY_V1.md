## 1. 本轮真正补上的连接

研究对象依然是**基于作者证据的人格/状态解释机制**，不是改做通用文本压缩，
也不是现在制作成品量表。本轮把“如何聚合向量”与“如何利用历史更新判断”连接起来：

> 同样的当前分数，可以对应不同的证据积累，因而对同一条新信息产生不同反应。
> 只保留归一化后的一个向量，可能不足以保留推论过程。

这是一个可构造、可证明的可能机制，不是宣称现有 embedding 必然丢失了该信息。
更不能把数学权重直接称为可信度、样本量或人格强度。

## 2. 从固定 attention 运算得到一个有限适用的公式

固定一个 attention head 的 query、key、value 和位置处理。设非证据 token 组为
\(J_0\)，一组证据 token 为 \(J_E\)，其未归一化权重为 \(a_j=\exp(\ell_j)>0\)。
对该 head 的固定线性读出，令 \(v_j\) 是投影后的标量 value，定义

\[
a_0=\sum_{j\in J_0}a_j,\quad m_0=\frac{\sum_{j\in J_0}a_jv_j}{a_0},\qquad
A=\sum_{j\in J_E}a_j,\quad \bar m=\frac{\sum_{j\in J_E}a_jv_j}{A}.
\]

若复制的是**完全相同的 key/value 权重组**，复制 \(k\) 次后精确有

\[
m(k)=\frac{a_0m_0+kA\bar m}{a_0+kA}
     =m_0+\frac{rk}{1+rk}(\bar m-m_0),\qquad r=A/a_0>0.
\]

这里 \(r\) 是权重比，**不是 Pearson r**。实际报告字段使用 `mass_ratio` 或
`ratio`，不能与预测相关混用。若无非证据组，即 \(a_0=0\)，纯内容平均是另一边界，
对正 \(k\) 保持不变；当前参数化不包含该无穷比值。

这是标准 softmax 加权平均的代数，不是 GRAIN 新发明的 attention 定理。
[Vaswani et al., 2017, §3.2](https://arxiv.org/html/1706.03762v7)
Attention-sink 文献证明部分模型会向语义上不重要的初始 token 分配显著权重，
使保留非证据通道值得研究；它没有证明心理判断遵循上式。
[Xiao et al., ICLR 2024](https://arxiv.org/html/2309.17453v4)

**边界：**复制原始文本会改变位置、query、上下文化的 key/value 及后续非线性。
自然空历史也不等同于保持其他节点不变的 \(m_0\)。因此固定 KV 处的公式是精确
恒等式，最终 LLM 分数的同形公式只是待检验的有效模型。非证据组不自动等于
attention sink，也不等于 Bayesian 先验；必须说明 token 的归属标准。

### 2.1 曲线到底能识别什么

对 \(a_0,A\) 同乘任意正数，所有 \(m(k)\) 不变，所以仅凭输出曲线不可能分别
识别两者的绝对值。在非退化且已知两端点时，任意正 \(k\) 给出

\[
\frac{m(k)-m_0}{k[\bar m-m(k)]}=r,
\qquad \operatorname{logit}\left(\frac{m(k)-m_0}{\bar m-m_0}\right)=\log k+\log r.
\]

若端点未知，不能先把最大观察点当作真正渐近值。非退化曲线有三个有效参数；
三个点的拟合不构成有力检验，必须预测未拟合的数量/条件。作为精确世界的必要条件，
四个互异点满足线性分式变换的交比不变性：

\[
\frac{[m_1-m_3][m_2-m_4]}{[m_1-m_4][m_2-m_3]}
=\frac{(k_1-k_3)(k_2-k_4)}{(k_1-k_4)(k_2-k_3)}.
\]

这是标准代数性质，不是新统计检验。近乎平坦/饱和、有噪声的曲线会使分母不稳定，
实测应使用原分数尺度上的拟合及留出预测误差，不直接对这个比值设心理学门槛。
通过交比只支持函数类，不识别内部神经实现；非恒定线性函数也保持交比。

在固定参数下，\(m'(k)=r(\bar m-m_0)/(1+rk)^2\)，
\(m''(k)=-2r^2(\bar m-m_0)/(1+rk)^3\)。增加、下降、曲率方向均由端点差决定；
不应一律寻找“向上饱和”。有限 \(k\) 不能验证无穷极限，平坦也可能是端点相同。

## 3. 从当前分数升级为可更新的证据状态

固定查询与表示后，定义总权重和加权一阶矩：

\[
Z=a_0+\sum_j\alpha_j>0,\qquad
T=a_0v_0+\sum_j\alpha_jv_j,\qquad m=T/Z.
\]

加入已给定权重 \(\alpha\geq0\) 和 value \(v\) 的证据时：

\[
Z'=Z+\alpha,\quad T'=T+\alpha v,\quad
m'=m+\frac{\alpha}{Z+\alpha}(v-m).
\]

标量/向量 value 都成立。这是标准加权均值递推，不能把它命名为新的人格学习定律。
但它给 GRAIN 一个具体候选：**保留分子与分母，而不只保留比值。**

两个状态都输出 \(m=.5\)，但 \(Z=1\) 与 \(Z=9\)；加入相同 \(\alpha=1,v=1\)
后分别为 \(.75\) 与 \(.55\)。因此在允许这种更新的模型族内，当前 \(m\) 不充分，
\((Z,T)\) 则对已规定的加权追加运算闭合。不能据此证明它对任意自然对话或完整
Transformer 都充分。全体权重包括新权重一起缩放时，轨迹依旧不变。

### 3.1 还缺来源状态，不能把重复当独立证据

\((Z,T)\) 也不够判断新输入是否已经见过。构造历史一包含来源 a/b，历史二包含
c/d；四条的权重均为 1，各历史 value 为 1/0。两者都是 \((Z,T)=(2,1)\)。
现在追加 a、value=1：若精确同源复制不再计权，历史一仍为 .5，历史二变成 2/3。

所以要实现这一来源规则，至少还需来源状态 \(\mathcal P\)，或能提供相同判断的
等价表示。**来源账本可能随历史增长，不能提前宣称存在固定维数的无损压缩。**
这里的 exact duplicate 是受控构造；同一作者两次相近表达未必是复制，不同来源
也未必独立。权重需要依赖关系模型，不能用句子数、余弦相近或作者 ID 直接替代。
对重复的助手复述与新的用户证据，尤其应分开。

## 4. 多个心理问题：保留一个可查询的数值对象

固定非负核 \(\kappa(q,b)=\phi(q)^T\phi(b)\geq0\)，\(b_j\) 是经过主体/事件
归属绑定的证据 key，\(q\) 为查询。先把非证据参考也列为一条固定记录。可定义

\[
z=\sum_j\alpha_j\phi(b_j),\quad
M=\sum_j\alpha_j\phi(b_j)v_j^T,\qquad
m(q)=\frac{\phi(q)^TM}{\phi(q)^Tz}.
\]

在分母为正、核与 key/value 固定时，这精确等于逐记录的加权读出；追加只需更新
\(z,M\)。**这是 kernel/linear attention 的标准一阶矩表示，而非新公式首创。**
相关论文明确给出核特征映射与递推实现；本轮借鉴的是可更新记忆的数学形式，不是
迁移其模型性能或训练结果。
[Katharopoulos et al., ICML 2020](https://proceedings.mlr.press/v119/katharopoulos20a.html)

正定核不保证任意一对输入的核值非负；概率式权重解释需要另行满足非负性。固定
低维特征核也不自动精确等于 softmax 的指数点积核。重新计算上下文 key、动态位置
或非线性 value，会突破上述固定矩闭合，需要增加状态或报告近似误差。

这把用户想法落在一个可试的对象上：输入可以经冻结向量化和归属绑定进入
\((\mathcal P,z,M)\)，再按数值查询读出，无需每次生成一段语言推理。
**仍然可能依赖 LLM 预训练知识；没有语言化中间步骤，不等于没有语义知识。**
此外，模型证据状态不是作者本人完整人格。只有在共同参照总体、条件与评分规则下，
稳定可比较且关联心理/行为指标的部分，才有进一步人格解释价值。

## 5. 这一机制究竟能否解释人格相关性的提升

### 5.1 一个重要限制：统一放大不会提高相关或 AUC

设作者证据读出为 \(b_u\)，共同参考输出为 \(m_0\)，最终分数为

\[
S_u=m_0+g_u(b_u-m_0).
\]

若所有作者 \(g_u=g>0\)，\(m_0\) 相同且方差非零，则
\(\operatorname{Corr}(Y,S)=\operatorname{Corr}(Y,b)\)。同样的严格正向仿射变换
保留样本排序，因此保留相同作者与标签上的 AUC、Spearman；绝对误差、校准与
固定阈值判断可以改变。\(g=0\) 时分数常量，Pearson 未定义，不能套结论。

**因此，若新增历史只使每个人统一更相信同一证据，它无法单独解释 Pearson/AUC
提高。** 真正的提高至少涉及不同作者权重的变化、证据内容/归属变化、非统一读出，
或比较协议发生变化。这不是否认历史作用，而是把研究从“输出更强”推进到
“哪些人的哪些证据被如何重新使用”。

### 5.2 作者特异的权重：内容、覆盖与交互

在同一配对作者分布上，记 \(\bar g=E[g]\)、\(\bar b=E[b]\)、\(\bar Y=E[Y]\)。
在共同 \(m_0\) 和有限所需矩条件下，代数展开给出

\[
\begin{aligned}
\operatorname{Cov}(Y,S)={}&\bar g\operatorname{Cov}(Y,b)\\
&+(\bar b-m_0)\operatorname{Cov}(Y,g)\\
&+E[(Y-\bar Y)(g-\bar g)(b-\bar b)].
\end{aligned}
\]

三项分别是加权内容关联、覆盖/权重关联、二者交互的**有符号统计账目**，不是互斥
因果百分比。Pearson 还要除以实际 \(\sigma_Y\sigma_S\)；这不是 AUC 分解。
作者特异 \(m_{0u}\) 会产生额外项，不能把共同基准公式照搬。
仅观察 \(S\) 不足以唯一分开 \(b,g,m_0\)。这张账目只有在其分量已被独立规定、
测得或在可识别模型中估计时才能作实证分析，不能用外部标签选择分解再宣称解释成功。

构造反例：所有作者 \(b_u=1\)、\(m_0=0\)，外部指标 \(Y=\pm1\)，
\(g_u=.5+.2Y\)，则 \(S=g\) 与 \(Y\) 的相关为 1，尽管内容读出没有任何个体差异。
这说明相关可能来自暴露/权重变量，不自动证明内容解释成功；不是当前实测的归因。
如果权重变化来自真实作者的自选 topic/表达机会，它也可能是有效的 Where/choice
证据，不能因此统统删除。应分开报告自由选择目标与固定机会目标。

## 6. 下一实验应如何区分，而不是只画一条饱和曲线

| 有待区分的问题 | 最小比较/观测 | 能支持什么 |
|---|---|---|
| 证据是不是此人的 | 同一词汇、主体/他人归属互换，固定查询 | 绑定敏感性；先于聚合解释 |
| 新信息还是复述 | 同源复制、独立机会、助手复述分开 | 来源依赖敏感性，不把复制当新测量 |
| 只是权重竞争吗 | 数量曲线及未拟合 k；可行时固定 KV 与输入级改动分开 | 有效函数类与内部干预证据分层 |
| 当前分数是否足够 | 匹配当前分数但不同历史，再给同一受控证据 | 更新是否需要额外状态 |
| 小矩状态能替代到哪 | 固定表示/核/来源规则；留作者、留查询、留更新序列 | 有限支持上的输出和更新保真 |
| 外部关联来自哪里 | 完整既定源头包；同作者内容/权重与线索使用账目 | 不用模仿 LLM 代替心理关联 |

有意操纵“独立事件”会改变自然语言材料本身，不能声称同时把所有 token/位置完全
固定。应区分输入级生态比较与局部计算干预，并记录不可避免的变化。相同当前分数
也可能因事后筛选产生偏差；未来优先使用合成可控构造，或仅在 development 内确定
匹配规则并独立验证，不对现有作者结果反复挑选。

这些是下一轮小面板的**可执行机制问题**，不是本轮启动的新增 GPU 任务。现有 direct
缓存只有候选 logits，不能反推出上述全部 key/value、分母或来源账本。先完成
冻结的 source/direct/history 比较；没有这些缓存时应承认缺测，不补造内部解释。

## 7. 理论地位与可复现产物

- 已有理论：softmax 加权平均、线性分式不变性、加权均值递推、kernel moment 记忆、
  仿射相关不变性与协方差展开。不能作为 GRAIN 的首创数学定理。
- 本轮组合：将归属、来源依赖、证据覆盖、可更新矩与外部线索对齐接成作者推论路线。
- 启发式/待检验：用小矩状态近似真实 LLM；将有效权重对应到可解释证据覆盖。
- 尚未证明：它比现有 embedding 更接近真人心理指标；它就是 LLM 实际的推论机制；
  来源依赖与开放语境下存在固定小维度的充分状态。
