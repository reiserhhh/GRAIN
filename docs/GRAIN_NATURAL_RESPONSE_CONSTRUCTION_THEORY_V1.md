## 1. 共通公式不要求共用一个人格方向

用户的原始目标是找到“作者文本经向量运算到特质判断”的可计算联系，包括
小特质，以及不同查询之间共享/专属的路径。现有证据给出的基本单位应是
**查询条件下的响应函数**，而非一根可脱离输入分布解释的欧氏轴。

对文本x、查询q、操作E，定义Delta_q=S_q(Ex)−S_q(x)。在一个声明测点上，
冻结参照读出a_q=g_ref,q^T d_q。自然响应可写为：

    Delta_q = a_q + b_q + t_q + o_q,
    b_q = (g_xq-g_ref,q)^T d_q,
    t_q = M_q-g_xq^T d_q,
    o_q = Delta_q-M_q.

这些是可操作比较得到的分量，不是已经分离出的四种心理实体。
个体差异可以在d_q中，即使g_ref相同；不能把Who缩成梯度的个体残差。

## 2. 共享路径不会保证总分高相关

令z_q=(a_q,b_q,t_q,o_q)。相同条件c内：

    Cov(Delta_q,Delta_r | c)
      = 1^T Cov(z_q,z_r | c) 1.

右侧为16个可正可负的项。单个共享通路与总响应相关的关系，不由该通路
自身的r决定；其它通路的幅度和交叉项也参与。可以出现：

- 局部共享很强，完整响应共享较弱，因为交叉项负向抵消。
- 局部不共享，完整响应共享，因为其余上下文形成共同作用。
- 更稳定的分量拉低某一外部量表相关，因为它对应别的作者属性或条件。

本轮N/确认给出第一种经验实例：局部冻结响应r=.814，完整响应r=.283；
其协方差=.06999−.03391−.06271+.15444。不能把负项、未命名项或
与某一量表低相关的项统统删掉。协方差的抵消是统计事实；计算上的抑制机制
需用具体上下文/查询联合干预特定，而不是由这一式自动推出。

## 3. 查询同时改变取证与读法

对b_rs=g_ref,r^T d_s，在冻结评分单位下，对角差可作两阶对称分配。
本轮读出项与证据项都达到非零可观量级；TF/N与TF/确认的自然差异分别
与不同项联系较明显。保留“证据构造＋查询读出”的两层结构，不强迫单因解释。

函数关系的合适内积是E_c[(g_q^T d_q)(g_r^T d_r)]或中心化版本，
需要指定参照群体、条件和交叉位移分布。g_q与g_r的角度、人的量表相关、
完整自然响应相关，是三个不同但可逐步连接的对象。

## 4. 下一层公式与可发现机制

把全部上下文和末查询状态纳入同一固定布局的四格函数f(R,Q)，则：

    Delta = Gamma + [f10-f00] + [f01-f00]
                  + [f11-f10-f01+f00].

Gamma承担从原文到对齐布局的重基准，不藏入随机误差；其它三项对应上下文、
查询与有限交互。在固定状态空间内，若后缀函数二阶连续可微，令两个状态位移
为d_R、d_Q，则交互等于混合曲率在矩形路径上的累积：

    I_RQ = integral_0^1 integral_0^1
           d_R^T Hessian_RQ F(R0+t*d_R, Q0+s*d_Q) d_Q ds dt.

四格端点可直接测这个积分的总作用，不需要先估计巨大的完整Hessian。
本轮只建立下一实验的可计算对象，没有实测该混合曲率。
先用实际四格端点找到作用，再选需要近似的函数，才符合发现优先。

因此下一阶段由“逐步提升g^Td精度”转向“识别哪种完整状态运算形成Delta”。
它直接服务真实作者文本到特质判断的主线。轻量化继承已成立的T/F路线，
新函数在明确其作用后才成为学生目标；不先重新训练一个总分预测器。

这保留4W骨架：where是声明的编辑/视图与观察布局，what是被查询组织的证据，
who是相对参照作者的响应配置，when需要实际时间/顺序干预。两份S1文本视图
不自动构成时间序列；本包没有用它们宣称人格随时间变化。
