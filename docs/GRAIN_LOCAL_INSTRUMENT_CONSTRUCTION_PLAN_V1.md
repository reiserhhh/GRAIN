# M14：共同制作规格下的个人条件与当次过程实例

2026-09-13，数值运行前冻结。目的不是再换回归头，而是将B1–B7走成可复建的
制作接口：目标/机会/证据 → 来源校准与参照 → 新人采点 → 数式计分与证据解释。

## 两个实例

1. 社交条件轮廓：安静/嘈杂聚会中的自述愉快事件。保留两个条件期望、等权水平
   与半差；不将机会分布当个人偏好，不将它直接命名为外向性。
2. 任务过程：短/长枯燥任务的完成报告，加记录到的伙伴输入及观察轮次。
   分开个人水平、条件/伙伴响应、当前偏移、当前表达、窗口偏移。
   此处“状态”是模型中的当次偏移，不预先断言为情绪。

两例使用已冻结的本地NLI查询读者，但读数校准、人口矩、时间参数、证据预算各自构造。
来源32条公开机制材料/查询，用已实现的条件化仿射标尺恢复事件方向单位；
不使用应用作者标签，不新增提示或分类器救援。条件是实验设计给定，不谎称开放识别。

共同证据记录含author/event/text/scope/condition/time/partner/replicate，
只有设计确认的self_event_report计分。未知范围输出未资格化，不默认填0或中性。
重复事件只算一次；同事件冲突要求修订协议，拒绝猜测。每条保留原文hash与字符地址。
个人轮廓允许事件重排；过程保留时间与条件绑定，不用无序矩取代路径。
这继承M01/M02/M03及M05的“不先抹掉目标需要的关系”的结论。

## 制作模型

共同高斯工作读出形式：θ~(m,Σ)，y=Hθ+e，
C=(Σ^{-1}+H'R^{-1}H)^{-1}，评分目标t给出s=t'm+t'ΣH'(HΣH'+R)^{-1}(y-Hm)。
这是继承的线性最小均方/高斯工作模型，不另称新定理。

个人例θ=(两个条件期望)，m/Σ及事件噪声由独立pilot方法矩学习。
过程例θ=(a,b,c,s_1…s_T)，OU协方差参数由独立pilot REML学习，
新作者每时点不同报告数按事件数量缩放噪声，不把缺失材料当作同样精度。
两个例子均保留来源项、每条证据贡献、模型条件方差及来源bootstrap构造方差。
来源模型缺乏个人证据时不能冒充实测；常模固定在来源，不跟应用批次重中心化。

当前M05的K为可选辅助观察接口，不强行作为以上事件读者的替代品。
本包不新增17块向量提取或将K端点分数和NLI事件单位直接相加。

## 材料和有界实验

- 3种子；每例64模拟pilot、每应用条件64新模拟作者；应用同措辞/留出措辞两条件。
- 个人pilot每条件24独立事件，应用每条件6；过程12轮、每轮2组×8独立事件。
- 已有128条公开文本/NLI margin作为确定性读者缓存；精确文本+query为键，不能用隐标签找分数。
- 过程生成有界AR(1)：s_t=.7s_(t-1)+.3u_t，u_t均匀[-.45,.45]；256轮预热。
  加a∈[-.12,.12], b∈[-.10,.10], c∈[-.08,.08]及给定z/u后，概率仍在[0,1]。
  非Gaussian、Bernoulli事件噪声异方差，故Gaussian区间是工作区间，要实际报告覆盖。
- source/应用作者完全分开；12次作者bootstrap/构造；数值CPU上限240秒。
- 输出真实目标与读者诱导目标分别计算；不能将读者在同措辞中的自洽性称为人类效度。
- 原文冷运行两例第一名留出措辞作者，不读缓存/NLI结果表/模拟真值，最多160新NLI对、180秒。
  同时检查明确重复事件、移除一个条件、范围未知以及时间重排；不扫超参数。
- 自然材料只审既有273事件是否有这些实例所需设计/范围/时钟字段，未知不补造。
  不调用MEPS、不把原自然文本外发、不因不适配而改自然内容。
