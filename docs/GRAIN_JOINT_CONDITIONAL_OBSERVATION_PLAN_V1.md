# M04/M05: 同文本多通道观察到个人条件函数

2026-09-13，冻结于新文本计算前。不是新人格准确率竞赛。

## 唯一新增机制

GRAIN4坐标、既有二次查询矩、组内K查询作用与NLI观察同一事件时，
不是独立重复测量、也不是可直接相加的分数。先学习`o=b(z)+L(z)m+error`，
保留原单位及共同误差，然后构造个人条件矩函数`m_u(z)=a_u+b_u z`。
`m`有三个坐标：担忧事件极性均值、确认行为极性均值、二者极性乘积均值。
第三项为联合分布的一个矩，不是自动命名的新心理特质。

## 材料与分离

- 72公开编写文本：3任务时长×两极性×两极性×6措辞。每篇超过48词，按原GRAIN
  lossless四slice程序计分。两个既有查询operator不重新训练，来源4作者的旧权重固定。
- 32来源标定文本：时长5/45分钟、措辞0–3、全部四极性组合。
- 来源标定冻结后，运行其余40文本：新增35分钟与留出措辞4–5。
- 每篇实际运行前17块+QKV，无suffix/logit/backward；两既有查询为
  `neuroticism`和`confirmation_seeking`，不因此称事件标定等于这两种心理量表。
- NLI固定4对/篇，总288对；没有提示或模型搜索，没有MEPS或人类量表拟合。
- 数字世界3种子×256新模拟作者×2措辞世界；两世界同潜在参数和事件随机数配对。
  每条件32事件，仅条件-1/+1用于作者函数；+.5整条件隐藏，最后才评估。

## 继承的计算

四极性角点给出完整二元联合矩展开：
`E[o|z]=b(z)+L1(z)E[s]+L2(z)E[t]+L12(z)E[st]`。
来源角点与措辞残差估计b/L/R；R使用固定0.1标准化对角收缩，不调参。
对指定通道子集白化R后用SVD解线性标定。保留`resolution=W L`及秩；
秩不足时仅报告可识别投影，不把最低范数当完整三目标恢复。

比较NLI、GRAIN、GRAIN+二次矩、再加K、全部通道。新增K先看条件信息/秩，
再看留出事件/作者误差；不以任何一个最优分数决定采用。
完整R与假定通道独立的diag(R)比较；精确复制一个通道用相同协方差行列，
应不增加信息。已冻结量的可逆单位变换应保持标定后分数不变。

对每位作者：`a=(m(+1)+m(-1))/2`, `b=(m(+1)-m(-1))/2`。
一个向量函数同时保存水平、有限条件差分与未见中间条件预测；比较仅水平、
仅斜率和联合函数。此包不用总体先验替新作者作答，也不再做Gaussian超参数搜索。
经验材料方差经固定W及条件对比线性传播；不称潜在人格精确置信区间。

## 机制判据与输出

1. 同文输入实际重算；新K是否增加条件响应观察，而非仅已有量换单位。
2. 联合读数能否恢复角点/个人条件矩；明确来源匹配与新措辞/新条件偏移。
3. 秩、分辨投影、条件数、量纲变换、重复通道、共同误差一并记录。
4. 回归图谱不新增人类相关表；输出事件地址→通道→标定→个人水平/变化的解释链。
5. 实验可正面交付或以有限反例结案；不为追求漂亮r续跑模板/秩/alpha网格。

作为保留多坐标而非硬相加的参照；本包为有限基底模型，不复制其GP实验。

仅继承统计操作，不因参照计量标准而宣称心理构念效度。
