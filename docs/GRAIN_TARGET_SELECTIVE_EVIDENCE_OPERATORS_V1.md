# GRAIN: Target-Selective Evidence Operators

2026-10-09. HM60 finite finding; not a new mathematical theorem or completed
psychological instrument. Parent goal remains active, original scope open.

## Observation Object

Keep the qualified event archive E, narrative/condition C, and query q separate:

    R_q(E,C) = a target-conditioned observation law
    D[q,c;C] = R_q(E_c_high,C) - R_q(E_c_low,C).

A scalar author score cannot specify this operator. HM60 probes six behavior
contents, two families, six queries and four account regimes using existing raw
observations. It does not reconstruct the entire operator, causal attention path,
or an author's psychological truth.

## Two Different Decompositions

Complete K6,6 node projection removes additive query/content offsets:

    D = G + C_interaction,  B^T vec(C_interaction) = 0.

This graph decomposition is standard. Nonzero interaction can arise in a rank-one
multiplicative matrix, so it is not evidence of multiple latent psychological axes.
The fixed spectral diagnostic retains both parts:

    D = D1 + R,  D1 = s1*u1*v1^T,  <D1,R> = 0.

In pooled isolated behaviors, D1 carries 90.6358% of answer-score energy. R carries
9.3642%, but 58.4083% of the named diagonal-vs-off-diagonal contrast. Both full D
and R have the unique maximum named assignment among 720; D1 is rank3. Log-odds
results retain the pattern (90.1241%/9.8759%, 59.4720%, rank4 for D1).
These are descriptive response-energy and alignment statistics, not personality
information percentages or population p-values.

Full-family response cosine is .9156/.9222 across score/log-odds; the rank-one-tail
family cosine is .5652/.6948. Keep shared effects and family deviations; do not
delete the leading part as noise, name a singular vector as a personality factor,
or claim universal transport from these two controlled families.

## Context and Author Measurement

One fixed gain does not describe every account operator. Relative to the pooled
atom operator, non-proportional score-response energy is 17.4% for alias, 7.6% for
distinct occasions and 21.7% when the added actions belong to B. The last is an
observation/qualification issue, not new A evidence. Balanced contrasts include
opposing actions and text-placement changes, not trait change.

The next mainline object is composition of multiple qualified evidence units into
an author/condition response, including cross-target interactions:

    r_q(E,C) = r_q(empty,C) + sum_e a_q(e,C) + sum_{e<f} k_q(e,f,C) + ...

This is a proposed finite evidence expansion, not an established new law. An event
definition, duplicate/revision treatment, condition and reference population must
be fixed before its terms have measurement meaning. It must retain GRAIN choice,
condition response and state rather than subtracting context indiscriminately.
