# GRAIN 前缀函数的源作者连接 V1

2026-09-08。在完整水平包结束后冻结，不改其公式。

## 为什么现在运行

12名新作者上，P+Q完整水平r为TF .817/N .761/确认 .920，自然变化r为
.886/.681/.717。已从局部作用接上原生整判断。下一决定是：该冻结函数是否
保留既有源样本的人格关联，而不是再优化局部r。没有这一步，就缺整链的解释接口。

## 固定设计

复用S9已冻结的213 Big5-only(N)和64 MBTI-only(TF)，每人原3×12评论，cue-mask。
这些是暴露过的开发源材料，不是新锁箱。先核验与四个图册/两个主参照不重叠。
不换作者、不按标签挑例，不拟合或调校、不读取bridge/MEPS。

同一Qwen/MPS/FP32观察器，只算block0-16前缀（现有早停实现还捕获block17
的QKV线性投影，未执行17的attention输出/MLP，不执行18-27、最终norm/lm_head）。
用已冻结P+Q公式计算P-only/Q-only/P+Q完整分数。无生成、无后缀判断、无新梯度。
所有三视图等权汇总，先锁定预测与哈希，再接既有源Y。保持分数未裁剪。

前缀重放pilot：12作者包前两作者×三查询=6前缀，P/Q与完整采集缓存逐坐标
对照，容差2e-5；禁止后缀/lm_head hook必须零调用。
pilot通过后源包最多831前缀（277×3），总837，计算预算1200秒，逐作者存盘。
首16作者只判断成本/输入错误，不看心理标签、不能按效果删剩余作者。
若资源外推超过预算则保存可续跑结果；不为了填表自动启动第二批。

## 输出与决定

同样本比较原生本地教师、历史源教师、S4固定学生、本次P/Q/PQ读出。
报告teacher fidelity、外部r/AUC、配对作者CI、跨视图相关；N和TF分别解释。
精确分账`Cov(Y,s)=Cov(Y,s_hat)+Cov(Y,s-s_hat)`，不叫人格方差解释比例。

不以“超过原生教师”为入口标准。存在稳定方向的源连接就作为方法实例保留；
来源/样本与先前结果一致才能比较。若遗漏关联，定位它落在何种余项并形成
下一主线问题，不用外部标签改权重。无旧长队列、无Windows新训练、无新API。
