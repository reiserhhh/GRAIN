## Source-only construction and exact controls

Source paired body/query states define e_b,d_b,e_q,d_q and origins m_b,m_q.
Complete numerical spans E_b,D_b must be a direct sum. Fit A from the aligned
even coordinates, with A(e_b-m_b)=e_q-m_q and A D_b=0. No tuned truncation.
Let P_b be the source oblique odd projection, and P_q either source projection.

    b' = b - 2 P_b(b-m_b)
    q' = q - 2 P_q(q-m_q-A(b-m_b))

Application takes only (b,q) for one text. Since A P_b=0, the joint transformation
is S^{-1} diag(I-2P_b,I-2P_q) S, S(x,y)=(x,y-Ax). Its square is identity for
arbitrary joint states. This is a STANDARD conjugate representation, not a new
group theorem. Exact source exchange is a construction control, not discovery.

change that query operation on ANY input. This prederived no-effect arm is a
