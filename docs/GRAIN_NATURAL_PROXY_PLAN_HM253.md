# HM253: natural paired observations and a third-view measurement test

Registered before fitting new source functions or reading new result tables.

## Question and competing mechanisms

HM252 established a finite measurement bridge in a designed world. This packet
asks whether existing PUBLIC PANDORA numerical observations can instantiate a
related linear conditional-moment interface, without fitting any LLM answer.

M1: a common target-linked author component supports the same scoring function
across independent event collections. M2: source moments can be fitted but the
function mainly follows view-specific composition or weak cross-view directions.
M3: cross-view agreement is an author fingerprint without a target link.
Disjoint events do not by themselves establish independent proxy errors. The
experiment distinguishes observable implications, not all latent explanations.

## Measurement coordinates and source construction

For view v define a 32-vector (all means are over its twelve events):

    phi_v = [1, mean(c), mean((1-c)*z), mean(c*z)].

The TOP20 venue bit is the inherited coarse condition, NOT topic or situation.
Its frequency and both conditional vector masses remain. There is no deletion,
condition-centering or missing-condition imputation: a zero mass is an observed
absence, not a claimed conditional response equal to zero.

For each fixed cycle (W,Z,T)=(0,1,2),(1,2,0),(2,0,1), fit on one historical
author fold and score the other, using ALL five targets at once:

    K = mean(phi_Z phi_W^T), m = mean(phi_Z Y^T), K beta = m.
    ordinary beta = argmin ||phi_W beta-Y||^2.

One fixed relative cutoff 1e-12 only declares numerical null directions. Keep
singular values, coefficient norms, equation residuals and out-of-range scores;
do not clip, sign-flip, regularize, tune cutoff, select a cycle or rescue results.
The coordinate and moment operators use source observations only. A cold CLI
reads beta bundles and label-free view arrays, never criteria or LLM answers.

## Third-view observations and prespecified outputs

For both methods and all three cycles retain:

1. Source fitted K beta-m, and UNUSED source instrument moments
   mean(phi_T*(Y-phi_W beta)); latter is not fitted.
2. Held-author moments with Z and T instruments, reported in source-coordinate
   units after dividing each row by its SOURCE RMS. No Hansen J p-value: we have
   not justified its covariance, asymptotics or weak-instrument conditions.
3. Cross-fitted Pearson r, AUC and calibration bias for reading W and T against
   all five historical binary criteria. These are candidate external links,
   not proof of latent personality measurement or new prediction benchmark.
4. Same-author W/T score agreement versus a fixed matched stranger. Match within
   held fold on TOP20-count bands [0..3,4..7,8..11,12] and SOURCE-median length
   bit. Cycle each cell to a different author; singleton is missing, not zero.
5. 199 whole-five-label-profile permutations within each historical fold,
   refitting both source functions without changing features or parameters.
   Report directional ranks and max-absolute five-target adjusted tails per
   cycle/view/method. Do not choose which result to promote from these tables.
6. Coefficient drift between calibration folds and view-specific score drift.
   Fold differences are observed composition/sampling effects, not controlled
   population-prior interventions or psychological information fractions.

Primary construction-use decision: does the paired source rule produce positive
held THIRD-view target links and author agreement beyond the matched stranger?
Report each target separately. If ordinary regression has useful associations
and the bridge does not, KEEP those associations and infer that this particular
proxy/linear law needs a different observation model, not more precision tuning.
No requirement that a real effect exceed r=.5; significance is evidence about
this finite comparison, not a prerequisite for preserving exploratory links.

## Prior art and next decision

This is a new GRAIN construction/use test, not a new IV/GMM theorem. Source:
[Fu and Green, section6.2](https://arxiv.org/html/2505.21909v3),
[Zhang et al., proposition2.3](https://arxiv.org/html/2303.10134v4),
[Hansen1982](https://larspeterhansen.org/wp-content/uploads/2016/11/Hansen-econometrica-GMM.pdf).

its tree conditional-independence/reconstruction theorem is NOT transferred.
HM186 already established cross-view source moments; HM253 adds source-criterion
moment compilation, independent cold scoring and an unused third-view check.
The outcome determines whether to extend this proxy interface or instead build
a condition/occasion-dependent observation law; never repeat a precision grid.
