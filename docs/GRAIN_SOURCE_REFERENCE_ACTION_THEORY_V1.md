## Exact positive-law construction

The two frozen banks contain203/183 SOURCE authors, the full32 E/N/A/C/O
binary profiles, and two12-event full1024 E5 window means. The panel24 and

Write A_b(g,x)>0 for the source profile potential, x0 for control removal,
x1 for selected removal. For source b and destination d set

    a_g = A_d(g,x0) / A_b(g,x0)
    T_(b->d)(g,x) = a_g A_b(g,x)
    eta_g = log[A_d(g,x1)/A_d(g,x0)]
            - log[A_b(g,x1)/A_b(g,x0)].

At x0, T equals the destination potential for EVERY g. Thus it matches the
entire profile posterior, not only five marginals. At x1,

    A_d(g,x1) = T_(b->d)(g,x1) exp(eta_g).

Transport is an anchored diagnostic third law, not a naturally sampled
population or a prediction of an unknown destination instrument. It requires
the two frozen SOURCE banks; the destination labels are historical SOURCE
anchors, never labels of the panel/current user.

For target q let S_q(A)=log(sum_(g:q=1) A_g / sum_(g:q=0) A_g), and D the
selected-minus-control action. Let D_b,D_d,D_T be the three actions. Then

    D_d - D_b = (D_T-D_b) + (D_d-D_T)
              = calibration_action + response_defect.
    response_defect_q = log E_(T,g|q=1)[exp eta_g]
                        - log E_(T,g|q=0)[exp eta_g], evaluated at x1.

The exact expectation identity, not a numerical integration grid, supplies
the finite defect. Squared action accounts require the signed cross term:

    E[(D_d-D_b)^2] = E[calibration^2] + E[defect^2]
                    + 2 E[calibration*defect].

Ratios above1 are possible through cancellation. These are not orthogonal
components, causal mediation paths or psychological-information percentages.

## Conditional cross-ratios and their interpretation

For each hypothetical other-four profile c define

    kappa_q(c) = eta_(1,c) - eta_(0,c).

It is the change, across SOURCE references, of the within-c evidence log-odds
action. Profile-only calibration a_g and point-only density normalizers cancel.
All16 c are returned without asking for the current person's other labels.

If eta_g is constant in g, all full-profile readings transport exactly at
x1, regardless of its magnitude. Conversely, equality of all32 normalized
readings with positive support implies this constancy. All80 edge differences
kappa vanish iff eta is constant: any two five-bit profiles are connected by
successive single-bit flips, along which zero edge differences telescope.
This is elementary connected-graph/log-ratio algebra, not a new group theorem.
The80 coordinates are constrained response contrasts, not80 personality factors.

For only ONE target, zero kappa_q is weaker. An eta depending only on c can
reweight the other profiles and change the marginal q when q associates with
c. Therefore preserve conditional response AND joint-profile routing. This
recovers HM210's established distinction in a SOURCE-reference transport
operation; it does not prove independent target circuits.

## Implication for measurement construction

Current-score alignment and evidence-response alignment are distinct contracts:

    reference instrument = current profile calibration
                           + evidence-response operation
                           + declared observation protocol/support.

This extends the current GRAIN interface, not the number of discovered traits.
For a future text-based measure, matching average/current scores alone cannot
certify that a new utterance will have the same meaning under a new reference.
The transported operation must retain the profile-relative likelihood ratios,
conditional response and routing that produced its target valuation.

Here empirical banks differ beyond the baseline-calibration class on these
fixed observations. That does not identify whether the cause is sparse SOURCE
sampling, author-catalogue fingerprints or a shared condition response. The
next discriminating construction must address that cause, rather than fitting
away source dependence or boosting native agreement. No universal coefficient
or invariant human personality axis follows from this experiment.
