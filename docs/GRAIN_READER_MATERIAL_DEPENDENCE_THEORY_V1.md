# 同材料接合的进一步性质：正文改变证据，也改变读法

2026-09-11。NEXT81/第70轮，主实现4ac4c36。
[实验报告](../reports/grain_vector_mechanisms/READER_MATERIAL_DEPENDENCE_REPORT_V1.md)。

## 1. 输入摘要是否足以确定读法

写完整隐藏材料为 H=(B,C,R)，其中B为BODY，C为两个查询的末位，R保留其它
位置、布局等。固定原模型的端点读头是：

```text
r_q(H) = grad_(post22,last) L_q(H)
d(H) = r_N(H)-r_confirmation(H).
```

若存在足够的条件摘要C使 d(H)=f(C)，则任何固定C的有限面板上d都应相同。
现在固定每个query的完整末位后，实际d仍不同，最佳常向量误差为：

```text
min_a sum_i ||d_i*-a||^2 = sum_i ||d_i*-mean_j d_j*||^2 = .0934308.
```

它保留原始源间离差的67.73%，也是固定末位后的总d能量的10.64%。这是
有限面板上某个**输入契约**的反例：末位摘要没有穷尽可用输入。不是证明
67.73%来自人格，也不是证明残余全是BODY；R仍存在。

进一步在同一固定末位材料中只沿GRAIN正文方向D_if变化：

```text
j_BODY,if = D_(D_if) d(B_i,Cbar,R_i)
          ~ [d(H_i*+eta D_if)-d(H_i*-eta D_if)]/(2 eta).
```

四个方向都测到变化，约54%-64%能量在此前语境扩展空间外。这里存在直接的
BODY到reader链接，不只是作者间相关或因为更换末位而产生的间接变化。
GRAIN方向是固定文本特征调制的向量方向，不自动等价于自然语言编辑。

旧context列和本轮BODY列的基点不同；空间外比例说明已有有限列还不够，
不是说明两者天然属于完全独立、正文专属的普适子空间。

## 2. 一个重要的函数对象区分

原生局部K/V作用是固定端点伴随向量对相应运输切向量的内积：r_q(H)^T Dp_q。
如果研究r本身如何随H改变，测到的是一类混合/曲率信息，不能未经定义就
再加到原L的一阶导数上。应把两种函数明确写开：

```text
Fhat_q(H; A) = rhat_q(A)^T phat_q(H)
partial_H Fhat_q(H; A)[D] at H=A = rhat_q(A)^T Dphat_q(A)[D]

Fdiag_q(H) = Fhat_q(H; H)
D Fdiag_q[D] = rhat_q(H)^T Dphat_q[D] + Drhat_q(H)[D]^T phat_q(H).
```

前者是以当前材料A为锚点的一族局部读法，后者是单一对角标量函数。
它们值相同而导数不同，因为改变的自变量不同。这个差别不是程序bug，也
不是可以忽略的误差：它解释了为什么局部作用图不能不加定义地拼成全局评分。
后续可从局部场发展共同评分，但需要匹配目标，不能借用已验证的局部作用
结果来给对角导数背书。

因此NEXT82先把原先为零的 Dr_BODY 学成可计算的函数，并分别保留：
reader向量、固定证据投影、锚定局部作用、对角标量导数。只有目标相同的量
才做数值精度比较；对角新增项先作为数值函数的性质，不当原模型原作用。

## 3. 对GRAIN理论的新增内容

同材料接口现在有三个不同角色：

1. GRAIN提供可比较的正文变化方向。
2. 查询路径决定这些方向怎样改变被选择和运输的证据。
3. 同样的方向还可以改变下游读取规则本身。

第三项使二者不只是平行评分器或相加特征。作者材料可以调节自己的读取
算子，是一个可研究的向量交互机制。F03在本小面板的共同证据投影同向，
F01/F04幅度更大但方向不统一，说明“变化大小”与“共同心理解释”不能混用。
因子编号、正文作用与外部心理命名继续分开。

## 4. 和已有数学研究对齐

[Elhage等，2021](https://transformer-circuits.pub/2021/framework/)
把注意力的QK选择与OV写入分开研究。本项目沿用这种功能分解思路；这里
新增实验关注的是实际多层后缀的端点梯度怎样随材料改变，不是声称该文已
证明我们的人格路径，也不将小型attention-only模型的结论直接推广。

[Solak等，2002](https://proceedings.neurips.cc/paper/2002/hash/5b8e4fd39d9786228649a8a8bec4e008-Abstract.html)
提出结合函数值与导数观测。本项目下一步用这个思路连接源读头位置和GRAIN
方向变化。明确的数值目标、核与导数比任意拼接独立回归头更适合表达此问题；
有限源样本仍是局部学习，不借文献宣称全球不确定性已解决。
