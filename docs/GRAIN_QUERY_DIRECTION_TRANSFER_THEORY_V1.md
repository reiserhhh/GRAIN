# 查询之间的共享输入与专用读取

2026-09-10，NEXT36。接续[查询残差输入](GRAIN_QUERY_RESIDUAL_INPUT_THEORY_V1.md)。
本轮进一步支持“共用部分＋专用部分”，但这是一种局部模型读取结构，不能
将共用部分的维数直接命名成人格共同因子。

## 1. 把“表示接近”与“可以借用”分开定义

每个源折s内，U_qs为查询q的8×1536正交行基底。几何指标为

    cos(theta_k) = singular_value_k(U_qs U_ps^T),
    overlap(q,p;s) = ||U_qs U_ps^T||_F^2 / 8.

它等于两投影矩阵乘积迹除以8，对基底符号及正交旋转不变。
主角度来自[标准子空间分析](https://doi.org/10.1090/S0025-5718-1973-0348991-3)，
不是新发明的心理距离。相同为1、正交为0；中间值是连续重叠，不据任意
阈值宣布“正好有几个共同因子”。本轮几何是同一源折内跨查询，不是跨折
作者稳定性，也不是量表间相关。

借用则保留接收查询自己的目标、旧输入和输出方向：

    Phi_(q<-p),u = [Phi0_qu, source_standardize(R_u U_ps^T)],
    W_(q<-p) = argmin_W sum_(u in source_s)
        ||A_qu - Phi_(q<-p),u W||_F^2/(3T_u) + .01||W_nonintercept||_F^2,
    Jhat_(q<-p),u = Phi_(q<-p),u W_(q<-p) V_qs / T_u,
    tauhat_(q<-p),uk = <Jhat_(q<-p),u, D_uk>_F.

不借donor的输出V、目标A或系数W。donor与recipient始终使用同一个held
排除集合，变动的只有输入基底。这个不对称实验与对称的几何指标是两件事。

## 3. 为什么同子空间未必同一个拟合程序

本轮固定源坐标逐维标准化。若原标准化设计Z经可逆T变成Z'=ZT，系数需
变为B'=T^-1 B，原各向同性Ridge惩罚在新坐标应为

    lambda ||T B'||_F^2 = lambda tr(B'^T T^T T B').

只有T正交时才仍是同一各向同性惩罚。任意旋转后重新逐维标准化通常让T
不再正交。新玩具测试证明：连惩罚一起变换可精确重放，天真沿用单位惩罚
则有不同预测。实验没有旋转挑参；所有U保留原确定性方向与标准化规则。
本轮可比较的是固定程序之间的借用效果，不是宣称给整个子空间找到了唯一
最优、坐标无关的预测函数。

另一个文献提醒：[Kraemer与Sugiyama的PLS自由度研究](https://arxiv.org/abs/1002.4112)
指出目标参与成分构造后，有效复杂度不只是成分数。故我们只声称两种输入
增加了同样8列，不将其等同于严格相同有效自由度。NEXT35/36也未实现完整
SIMPLS；[de Jong的原始算法](https://doi.org/10.1016/0169-7439(93)85002-X)
作为目标相关降维的先例，不作为本地数据结果的证明。
