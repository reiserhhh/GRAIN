## 1. Three different identities

Let x=(e,n) be a registered assignment at a fixed condition and clause order.
The finite source and application encoders are H_s(x) and H_a(x). This notation
includes all28 blocks' joint K/V at the fixed history addresses, not merely one
averaged sentence embedding. g is a full e or n assignment exchange.

The label-aware source increment d_s(g,x)=H_s(gx)-H_s(x) obeys the exact cocycle

    d_s(g2*g1,x)=d_s(g2,g1*x)+d_s(g1,x).

For an involutive flip it also obeys d_s(g,gx)=-d_s(g,x). These are telescoping
identities for any encoder, not a discovery of a neural group representation.
The operation uses registered x; the present algorithm does not infer an unknown
assignment from arbitrary text. Reapplying the same fixed vector twice without
updating x is NOT the inverse operation.

If R(x)=H_a(x)-H_s(x), the source-complete additive update is

    T_s(g,x)H_a(x)=H_a(x)+d_s(g,x).

Its application-natural defect is

    epsilon_g(x)=T_s(g,x)H_a(x)-H_a(gx)=R(x)-R(gx).

Therefore source cocycle closure does not imply application orbit closure. Exact
full-memory natural transport holds precisely when the context difference is
invariant under the registered exchange. A large constant source/application
difference can be harmless; a smaller assignment-dependent difference can obstruct
transport. This is not the rule "remove all differences". R may contain useful
actor/behavior/condition information and is retained.

## 2. Support and component omissions have different meanings

For fixed time projector P_S and an actually used source component d_used,

    epsilon_(used,S)(x)
      = R(x)-R(gx) -(I-P_S)d_full +P_S(d_used-d_full).

The three terms are context variation, omitted causal support and omitted source
components. Their squared norms do not add: preserve cross terms and cancellations.
Calling any term an information fraction or psychological noise requires a separate
definition, not the existence of this decomposition. Full support is the union
of the causal descendant history positions, not a promise of natural-text transport.

Source H_s(e,n)=H0+eHE+nHN+enHEN is an exact finite Fourier expansion. HE or HEN
can include lexical/positional effects. A relation-only edit is a valid operation,
but not the whole source assignment exchange unless the omitted marginal is zero.
Changing a causal carrier is also not a new independent author event.

## 3. Representation support versus endpoint meaning

For fixed endpoint q/instruction iota/condition c let F_(q,iota,c) read the cache.
The finite source action and natural action are different quantities:

    A_s = F(T_s H_a(x))-F(H_a(x)),
    A_a = F(H_a(gx))-F(H_a(x)).

Their difference is F(H_a(gx)+epsilon)-F(H_a(gx)). If F is continuously
differentiable on the connecting segment, ordinary calculus gives

    A_s-A_a = integral_0^1 grad F(H_a(gx)+t*epsilon) dot epsilon dt.

This identity is explanatory, not an estimated gradient or a unique causal pathway.
Representation defect can be invisible to one endpoint and visible to another.
Conversely a probability response can be suppressed by saturation while log-odds
response remains. Compare multiple frozen endpoints rather than fitting one answer.

For full natural assignment exchange any scalar readout satisfies

    D_g F(gx)=-D_g F(x).

Thus exchange-even action coefficients must vanish. The operation's empirical
failure of this identity is a diagnostic, not something to fix by projecting its
outputs into the odd part. Oddness alone is necessary here, not sufficient to
prove that a cache or a psychological object is natural.

## 4. Place in the author-measurement chain

GRAIN's author comparison still requires a qualified source-supported evidence law
P_u, a defined target operation T_q and a fixed population reference P_ref:

    Theta_uq-Theta_ref,q = integral T_q d(P_u-P_ref).

The current experiment concerns a construction constraint INSIDE T_q. It cannot
replace evidence qualification, identify P_u from fictional actors, or equate
model choice with an observed person's future behavior. In HM160 notation,
psi=P(Y|H,A) is learned from specified observable source events; here F is a model
readout. Their connection must be established by common event/target semantics,
not by both being probabilities. Preserve choice, state, condition, event history
and shared observation error throughout this bridge.

If restored support/components resolve the mismatch, the construction is a joint
natural-evidence operation, not an isolated trait vector. If context variation
remains the obstacle, the next question is which condition-dependent transport
preserves the meaningful relation. Neither branch licenses an accuracy grid.
