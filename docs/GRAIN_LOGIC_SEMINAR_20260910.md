# GRAIN 逻辑接合：理论协作与修正记录

2026-09-10。一名只读 `gpt-5.6-sol / xhigh` 数学协作者与主执行 agent 的
有界研讨。不是新一次 Claude 会话。主 agent 独立复核公式、执行缓存实验。

## 1. 共识：对象不应等同于因子编号

作者对象至少保留固定参照位置、条件分布、路径。查询作用的候选接口是
\(D_q\)，不是“F02 就是 T/F”。若列坐标 \(G'=AG\)，应同时变换
\(D'_q=D_qA^{-1}\)。协向量变换 \(\omega'_q=A^{-T}\omega_q\)，则
\(\omega_q'^T dG'=\omega_q^T dG\)。单轴相关可以重新分布，而共同作用不变。

这是一种标准坐标协变思想，不是新的人格定理。真实缓存 LOG02 已检验固定
函数与变换后的惩罚如何共同搬运；只做旋转等价不是新心理机制发现。
新机制目标是找到可跨作者使用、对特定查询起作用的低维像或分布统计量。

## 2. 研讨中实际修正的承重公式

协作者最初提出 \(\Delta F_q=\int\omega_q(G)^T dG\) 作为统一对象。
主 agent 指出：当前 D 是源样本拟合，而 H 并不能由 G 唯一确定，直接写此式
丢掉了重要余项。协作者确认并给出完整形式：

\[
dR=dH-D_qdG,\quad \omega_q(t)=D_q^T\nabla F_q(H(t)),
\]
\[
\boxed{\Delta F_q=\int\omega_q(t)^TdG(t)
+\int\nabla F_q(H(t))^TdR(t).}
\]

这沿既定平滑联合路径成立，离散文本编辑仍需声明实际选用的状态路径。
第一项是被 D 运输的 GRAIN 通道；第二项是现有 G 没有表示但仍会被查询读取的
作用。D 不被更名为真实 Jacobian。

删除第二项的充分条件是该路径上的查询残差作用积分为0；更强的逐点条件是
\(\nabla F_q^T dR=0\)。若要在任意子路径都删掉它，则需逐点/几乎处处条件，
不能借某条完整路径的抵消。\(dR=0\) 是更强条件。
将 \(\omega\) 写成 G 上单值函数还需同一 G 对应可达 H 的投影梯度一致；
\(H=h(G),D=dh/dG\) 是一个常见充分构造。历史依赖时它只是联合路径上的量。

**这不阻止开发。** 保留“表示通道 + 查询可读余项通道”，可以逐步从余项
中提炼新的分布、条件或路径观察对象，而不要求旧12因子一次包含所有信息。
LOG04 的已知例子中，两项分别为1/3和2/3；删除余项会把完整变化1错算为1/3。

此外，即使坐标已冻结，任意 \(D'=D+A\)、\(dR'=dR-AdG\) 仍给相同总作用。
因此某条通道的“贡献”需要给定拟合准则、源数据和干预支持；加法闭合本身不
识别唯一归因。坐标不唯一与分解不唯一是两个不同问题。

## 3. 另外两个提议如何变成可判别实验

**水平与动态。** 作者常数在差分算子核中，路径响应并不确定作者群体位置。
LOG01 不只重复这个反例，而是在276名真实作者中同时计算层级关系。

**非线性。** 协作者建议检查正负干预偶项，寻找新门控。主 agent 补充：
native p(F) 的 sigmoid 坐标本身产生曲率，必须同时检查 log-odds。
LOG05 因此不是“偶项存在 = 内部门控存在”，而是分别量化输出坐标曲率、
共同方向、作者异质性和剩余 logit 偶项。

**主执行第二轮修正：共同响应也不能被当作无个体信息。** 对一个完全有效的
线性测量轴 \(F(H_u)=x_u=Y_u\)，给所有人相同位移 a 会得到完全相同增量 a。
个体信息位于 x_u，而不是每人的梯度必须不同。因此共同单位响应支持一种
可发展的共享算子形式；是否有心理意义应检验自然位置/变化与效标，而不能
由干预效应的共同能量比例决定。第五个有限反例专门验证这一点。

## 4. 文献依据与下一次真正的发展

- [Sundararajan et al. 2017](https://proceedings.mlr.press/v70/sundararajan17a.html)：路径积分归因与实施不变性；不提供 G 到 H 的映射存在性。
- [Kornblith et al. 2019](https://proceedings.mlr.press/v97/kornblith19a.html)：表示比较需要明确不变性；高维小样本中，任意可逆变换不变量可能退化。
- [Fleeson 2001](https://pubmed.ncbi.nlm.nih.gov/11414368/)：分布参数与个体内波动可以分别有意义；这里文本坐标的分布仍需独立解释。
- [Geiger et al. 2021](https://arxiv.org/abs/2106.02997)：将高层变量与神经状态的对应推进到可检验干预，而非只依赖相关。

下一机制应优先尝试：同级匹配的多统计量接口，以及自然文本变化中的作者特异
作用。不因本轮旋转或余项验算成功就声称完整因果抽象已完成。
