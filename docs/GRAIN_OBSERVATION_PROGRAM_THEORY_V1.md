## Why the program belongs in the measurement object

GRAIN distinguishes a selected event e, a vector observation F and a psychological
observation likelihood ell. Even with the same model and token input, F also
depends on which carriers the question may read and on recursive suffix state:

    y_q = F_{R,q}(e)
    S_{R,q}(P_u) = integral F_{R,q}(e) dP_u(e).

R is the observation program, not a person's condition. An intervention on e
asks what different evidence does; an intervention on R asks what a different
reader does. These can be jointly varied, but should not be conflated.
All text/body states can be unchanged while suffix access changes the output.
This is not just additive measurement noise or a more precise estimate of F.

HM130 already established that different observation functions need not order
author accounts identically. HM131 already established interactions between
history, relay and current access in a qualified-ownership task. HM136 asks the
distinct empirical question of whether later causal/availability diagnosis and
unchanged-fact mixing survive the program difference. It does not re-prove
the general theoretical possibility or discover a new access mechanism.

## Finite contrast without accuracy optimization

For access R in {H,full}, registered binary evidence variables b,c, retain

    I_R = F_R(+,+)-F_R(-,+)-F_R(+,-)+F_R(-,-)
    J = I_full-I_H.

The finite three-way character coefficient is J/8 under +/-1 coordinates.
J is a program-dependent conditional effect, not a failure-to-fit measure.
Actor, nonactor, off-target traits and factual questions remain different slots.
Do not choose a program on the basis of which interaction or fact score is larger.

The scalar softmax counterexample in math_observation_program.py is known math:
H contains one value b in {-1,+1}; an additional carrier has value0 and key
weight1 or3 according to c. H-only output is b; full output b/2 or b/4.
I_H=0 while I_full=-1/2. An apparently informative condition effect can arise
from normalization even when the new value is zero. The actual experiment
does NOT identify normalization as its unique explanation: recursive Q, MLP
and readout also remain free. No intervention percentage is a psychology share.

## Construction consequence, regardless of which result is larger

A reusable GRAIN measurement object must bind encoder, query, access/recursion
program, evidence-account composition and reference population together.
Keeping only a model name and trait label is insufficient to reproduce its
operation. Cold scoring should preserve this binding rather than silently
replace the reader with a higher-fidelity approximation or another access mask.

The psychological likelihood ell(e | theta, design) remains distinct from
F_{R,q}. Fixing R is necessary to identify what was measured, but is not a
way to manufacture a validated likelihood. Author choice, response and state
stay in the evidence account; changing a reader does not delete those signals.
