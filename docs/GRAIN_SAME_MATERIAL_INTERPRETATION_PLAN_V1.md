frozen whole:F01-F04 scores on four lexical slices per eligible comment. Exact
keys are author/view/comment/slice, with source file hashes and lossless lexical
span construction. These slices are not transformer token IDs.

Reconstruct only the existing pooled E5 configuration program within the SAME
five author folds, same seed20260910, same .01 ridge penalty and source scale.
There are45 small fits. The configuration target is the old fixed query function,
not a human questionnaire and not a GRAIN-subtracted residual. Replay every old
OOF configuration score before using its comment weights. Never fit a new Y head.

For comment j with vector h_j, expose psi_qj=w_q^T h_j. Their mean plus the fixed
intercept must equal the old score. This is a compiled functional contribution,
not native attention or a measured causal importance for every token.

Let g_j be the mean of the four frozen slice scores in that exact comment.
On eligible comments only, predefine:

    U = mean(g_j)
    a_j = abs(psi_j-mean(psi))
    W = sum(a_j*g_j)/sum(a_j), uniform fallback if all a_j=0
    D = W-U = Cov(g,a)/mean(a)
    S = Cov(g,psi).

Keep U, W, D, S and one deterministic within-view cyclic weight rotation control.
No temperature, factor, sign or query selection. Preserve the old whole-view
prediction using all12 comments; eligibility restricts only the new co-location
statistics. Record coverage and effective comment count of weights.

Primary outputs: within-author/view centered g-psi links; author-level mean
co-location across the three views; all nine source-criterion links for U/W/D/S
and shifted W; paired W-minus-U and W-minus-shifted association intervals. Whole
authors are the uncertainty unit, not thousands of correlated comments. These
are associations of newly defined statistics, not a new validated predictor.

Question answered: do expression coordinates and query-function evidence select
the same material, and is their co-location itself author-informative? A positive
result supports a functional measurement interface. A negative result still
separates the two sides; it does not justify arbitrary GRAIN relabeling.
