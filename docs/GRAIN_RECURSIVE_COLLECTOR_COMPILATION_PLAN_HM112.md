## Decision and prior inventory

HM111 separates independently encoded events from a recursive current collector.
Existing shared_prefix/context_carrier tools reuse a jointly computed full-prefix
cache and still execute the model suffix. HM110's final-state sum and HM111's
cold integrator do not construct joint states from single-event libraries.
HM80 already tests higher interactions, and HM106 already uses finite character
expansions. We do not claim to invent nonlinearity, third moments, KV caching or
transformer compilation. The new operation must construct an observation from
independent layered carriers, before any joint reference is admitted.

## Input and operation

Capture arm00 for each bank: two all-mid owner anchors plus twelve single-event
low/high records with ownerA. Exactly28 actual prefixes. Hooks save only context
K/V at blocks0--16, rotary coordinates and the neutral current's initial token
embeddings. Current joint states/scores are discarded. All matching context
segments are checked at all17 layers, not merely at the final projection.

Extract P, each of six E slots at three levels, and R for each owner. Positions,
causal support and invisible padding stay fixed at the HM111 layout. Neither
pair nor triple states/scores enter the numeric libraries or cold constructor.

The cold CLI imports no transformers, tokenizer or full-model object. It loads
only the declared frozen safetensors weights and applies current-token linear
maps, RMSNorm, RoPE, GQA, softmax, residual and SiLU-MLP arithmetic. Block l reads
the library's layer-l context, then updates C. Layer17 projects current K/V; the
frozen six-query observer reads those vectors. This is still pretrained neural
arithmetic, not an encoder-free personality formula. Context selection addresses
levels/owner, not observed pair answers.

Run all292 HM111 arm00 configurations plus128 new triple configurations. Two
fixed variants: correct layer-indexed history and broadcasting layer16 history
at every block. The latter is a declared incompatible-layer ablation, not a
minimum-depth theorem or parameter search. Seal all420 constructed states before
opening old pair reference outputs or computing new triple reference outputs.

## New author object

Four declared triples cover all six behavior slots. For each triple, eight
binary configurations and two owners in both banks give128 reference prefixes.
Only ownerA enters author laws. With chi(x)=x1*x2*x3 and integer weights3/7,

    P_plus(x)=(1+0.4*chi(x))/8
    P_minus(x)=(1-0.4*chi(x))/8.

All single and pair marginals agree. Their observation difference is exactly
0.8 times the third character coefficient. Retain every target and sign. This
tests what author composition can be measured beyond marginal/pair summaries;
it is not a population significance or personality-validity test. Both banks
change wording and situations; neither is a pure paraphrase transport test.

## Acceptance, failure and resource boundary

states; all segment invariances; cold input hashes; no transformers/full forward
in cold processes; constant current coordinates; all420 outputs and all128
references; allsix targets/owners retained, qualified laws exclude ownerB.

<=5e-5. They certify arithmetic construction only, not a research accuracy
target. A failure is preserved rather than tuned away. Report triple effects
including zeros; pair-marginal equality and explicit40-event weights verified
by a second calculation. No fitted coefficient or favorable target selection.

jobs get no extra model call to fill an unfinished table. Inputs/outputs/code
