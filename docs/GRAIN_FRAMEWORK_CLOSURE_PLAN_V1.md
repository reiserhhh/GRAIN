## 包1：完整水平与响应连接

冻结原 M7 两参照的积分矩阵 `Gq`，并取同两人的完整原生状态均值 `Zbar,q`、
末位置均值 `hbar,q`、完整原生分数均值 `bq` 及完整上下文末位置梯度均值 `gq`。
P 为相同查询 token × hidden 矩阵，Q 为最后一个 token。固定读出为：

```
vP_q(x) = <Gq, Zq(x)-Zbar,q>_F
vQ_q(x) = <gq, hq(x)-hbar,q>
v_q(x)  = vP_q(x) + vQ_q(x)
s_hat_q(x) = bq + v_q(x)
Delta_hat_q = v_q(edited) - v_q(full)
anchor_hat_q = -v_q(full)
```

P-only/Q-only/P+Q 都报告，不看结果选择主公式。P 梯度来自编辑布局/Q0路径，
Q 梯度来自完整原生上下文，和式是待测近似函数，不是同一全局势的已知梯度。
分数不裁剪，以免掩盖超范围外推。

12作者沿旧 salt/hash 顺序，从原两组剔除M7四人后各取6人，全部为本轮评估。
三查询：TF、neuroticism、confirmation-seeking。view0/E1固定。每单元2完整
前向 + 6后缀：编辑重放、Q0下四个E/P组合、完整布局中的参照P+Q替换。
总预算288前向（72完整、216后缀）、0反向、0训练，20分钟计算预算。
token身份与模型/观察器保持相同，逐单元保存缓存、冻结代码与数据哈希。

完整自然响应精确账本，令四个Q0格子为 f00,f10,f01,f11：

```

E_main = f10-f00; P_main = f01-f00
EP = f11-f10-f01+f00
Q_conditional = s_edit-f11
Delta = Gamma + E_main + P_main + EP + Q_conditional
```

也可把EP平分给E/P，不能分配后再加一次EP。这里Q项条件于E1/P1，不伪装
成全三玩家对称分配。实际锚定响应 `F(Eu,Pbar,Qbar)-s_full` 对比负中心化读出。

目标分别报告局部P、完整水平、自然Delta、锚定响应；水平对固定参照常数，
变化对零，给RMSE、MSE比、作者配对bootstrap、r、散点和有符号协方差账本。
不计算逐人近零Delta分母的覆盖率。P语义/指令/框架贡献为坐标归因，不是
人格信息比例。距离-残差关系检查仿射运输误差，不称为路径无关性的证明。
