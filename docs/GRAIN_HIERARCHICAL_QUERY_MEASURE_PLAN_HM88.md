# HM88: contextual query as a hierarchical observation measure

2026-10-10 JST. New finite numerical intervention on already observed HM87
material, explicitly retrospective. Seal before running this analysis. No new
neural/API/private/training calls, no accuracy fitting or parameter selection.

## Scientific decision

HM87 made query-free body KV numerically readable, but contextual queries change
target selection. Does that change require target-specific adaptation, or a
body-dependent potential shared by six targets? Does it act by redistributing
mass between three events, or selecting different tokens within each event?
The answer determines the next evidence-observer interface, not a better score.

Prior NEXT50 averaged source raw queries, NEXT73 separated selection from key
direction, S12 studied Fisher geometry, HM32/HM75 localized contextual states,
and HM86/87 additively decomposed weighted values. None of those exact
operations holds event probabilities fixed while replacing conditional token
laws on body-only KV. This packet does that; generic exponential tilting,
conditional probability and permutation averaging remain established methods.

## Frozen data and six interventions

Use all 96 forward HM87 body carriers, all six raw contextual queries, all
twelve heads and six query-free source behaviour directions. Reverse-body
captures have no native queries; do not invent them. This is not independent
new-material confirmation, natural author measurement, or a new personality
factor discovery. Body-KV prefix gate failure remains FAIL, unchanged.

For each body/head, logits l0_t come from the frozen neutral query and l1_t
from its native contextual query, both at the recipient's original position.
Set b_t=l1_t-l0_t and fix its irrelevant scalar gauge by token-uniform centering.
The shared field is bbar=mean_t b_t, specific field b_t-bbar. This is a
permutation-invariant mean over this chosen six-query battery, not a universal
psychological common factor. Fields still require observed native queries.

Run exactly six arms: cold, shared_only, specific_only, native, event_only,
within_only. The first four apply exp(bbar), exp(b_t-bbar), exp(b_t), or no
tilt to the same cold token measure. The last two use the exact factorization:

    p1(i) = p0(i) exp(b_i) / Z
    u_G = log E_[p0(i|G)] exp(b_i)
    v_i = b_i-u_G, with E_[p0(i|G)] exp(v_i)=1
    p1(G) = p0(G) exp(u_G) / Z
    p1(i|G) = p0(i|G) exp(v_i).

event_only=p1(G)p0(i|G); within_only=p0(G)p1(i|G).
Keep joint effects rather than calling these output contributions additive.
KL chain rule supplies an exact probability-change account, not a personality
information percentage. Naive centering b-E[b|G] is separately checked because
its exponential normalizer can still change event mass.

## Outputs and stopping rules

Save all body/query/head event masses, between/within KL, naive mass drift;
all six arm projections; all target selectivity and matched/foreign actions;
and synthetic author-law contrasts P+/-=(1+/-0.5yg)/16 (also h=-g subsets).
These are calibrated vector units, not Pearson r or prediction accuracy.
Use native-minus-cold four-corner action components for shared/specific and
event/within, retaining signed interaction. Do not infer final-answer mediation.

Numerical gates: reconstruct native attention/projections, normalize all arms,
preserve event mass under within_only and within law under event_only, validate
KL chain rule, and compare independent direct mixtures for all projections.
Tests must contain pure-between, pure-within, mixed, gauge, query-permutation,
invalid-group and a Jensen counterexample where naive centering moves mass.
Threshold 1e-9, not selected after reading results. Keep failed outputs.

After this packet, choose a shared conditional observer, target-specific
observer, or both according to observed effects. Do not continue grids to make
one win. Constructing the fields without native query forwards is still the
next missing mechanism; this experiment does not claim that construction.
