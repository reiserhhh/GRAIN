## Finite reversal algebra, not a new group theorem

For each field feature H_o(e), o in {+, -},

    H_even = (H_+ + H_-)/2, H_odd = (H_+ - H_-)/2
    H_+ = H_even + H_odd, H_- = H_even - H_odd
    mean_o ||H_o||^2 = ||H_even||^2 + ||H_odd||^2.

This is standard C2/Reynolds decomposition. Even invariance under swapping the
orbit starting point is guaranteed by construction, not an empirical success.
Both components are retained. Odd response belongs to this fixed reader and
material orbit; it is not personal dynamics B_u or an emotional/trait axis.

## Scientific decisions and limits

1. If event-indexed directions preserve same-act changes across wording while
   whole endpoints do not, use event fields as an observation interface and
   keep presentation response separately. This is an object choice, not a new
   trained accuracy score or universal transport theorem.
2. If averaging alone appears better, it is standard Janossy/Reynolds pooling;
   next ask whether event identity is still necessary before adopting it.
3. If no map preserves directions, do not fit another exact finite chart.
   Keep wording-dependent observation laws and investigate semantic relations
   or a different observed unit rather than further source precision.

The actual outcome may be mixed. Compare same-meaning wording, artificial
order and event-label controls at their distinct scope. This packet does not
prove psychological validity, automatic event parsing, causal mediator effects,
independent personality prediction or the original18/100/44 closure.
