## 1. New object and exact decomposition

Two addressed text windows can have a target-related relationship even when
their separate conditional means contain none. Let G be the inherited joint
five-bit target profile. This experiment DECLARES a uniform reference over all
32 profiles and uniform source authors within each profile; it does not infer
that the natural population is balanced or symmetric.

For centered window vectors a,b, profile means a_g,b_g, and residual accounts
r_A=a-a_g,r_B=b-b_g, retain every nonconstant character chi_m of Z2^5:

    T_joint,m = E_ref[chi_m(G) a b']
    T_profile,m = E_ref[chi_m(G) a_G b_G']
    T_pair,m = E_ref[chi_m(G) r_A r_B']
    T_joint,m = T_profile,m + T_pair,m.

The cross terms vanish within each complete empirical profile because its
residual means are zero. This is an accounting identity, not a reason to
delete profile means, conditions, choice, or state. A synthetic example in
the tests has a_g=b_g=0 while the E character controls the sign of a b'.

Independent within-profile permutations of the second window preserve both
profile-conditioned window distributions and their means. The finite
permutation expectation of T_pair is zero. They test the pairing account,
not whether all author-specific language is psychological personality.

## 4. Why the full operator cannot be called the pair signal

The five-target cross-fold contraction decomposes into four signed terms:

    joint-joint = profile-profile + profile-pair + pair-profile + pair-pair
                = 1.621009e-7 + .754087e-7 + 3.132250e-7 + .717989e-7

Thus a positive full contraction is not independent pairing evidence. In
particular, profile-pair and pair-profile cannot be dropped or interpreted
