# GRAIN：条件函数如何连接固定读出与作者测量

2026-09-10。全系统逻辑第九至十一轮，连接 L15/L16/L17/L22/L31。
依据：[本轮实测报告](../reports/grain_vector_mechanisms/SCALAR_CONDITIONAL_LOGIC_REPORT_V1.md)。
本页不是新量表或发布评分器；它说明下一步应构造什么，而非再给残差起名字。

## 1. 现在明确了哪一条逻辑

非仿射余项有两种不同来源：同一输入需要更好的读法，或者输入未保留目标所需
的区别。本轮同时检验两者：七个固定读法没有清楚补回原生目标；旧锚定材料
则给出了第二种来源的直接实例。两者不能仅凭相关系数互相替代。

在固定查询 q、模型和运行条件下，把一个中间层的完整状态分为：

- x=(P,Q)：本实验选定的查询位置状态与最终读取位置状态。
- E：其余边界向量，以及长度、位置、mask 等布局条件。
- F_q(E,x)：完整后缀的原生数值读出；不是人的真实人格值。
- f_q(x)=b_ref+M_q(x)+C_q(x)+Q_q(x)：当前固定仿射近似。

这里 E 不是已经识别的 topic 或心理环境，也不全是“噪声”。P/Q 在自然文本
中也已被 E 的上游信息条件化，二者并非独立变量。GRAIN 的 where/choice
不能直接与 E 画等号；前者是测量设计对象，后者是模型计算分区。

## 2. 输入等价类给出明确的存在性结论

旧 M11 将 P/Q 置为共同 x0，保留每份材料的 E。旧/新参考数组逐项一致。
因此 phi=(f,M,C,Q) 在这组干预上完全相同，而 b_q(E)=F_q(E,x0) 不同。

对于任意只看 phi 的确定函数 g，其输出只能是常数 c；等权有限材料上：

    mean[(b_q(E)-c)^2] = Var[b_q(E)] + (mean[b_q(E)]-c)^2.

右侧第一项是所有这种 g 的最小均方损失。本轮 T/F 与 N 的实测作者均值方差
分别为 .000637639 与 .000131248，非零。所以在这个已测干预域内，不只是
三次多项式，任何只看这些固定分量的函数都无法精确重建原生读数。

这是[输入等价类条件](GRAIN_INPUT_QUOTIENT_AND_TARGET_THEORY_V1.md)的新实例。
它不声称自然材料分布上所有标量近似都失败，也不是人格预测的不可约误差。
自然输入 x(E) 本身可能携带 E 的信息；实验把它固定是为了检验函数结构。

## 3. 从余项发展成条件函数

令 d=x-x0。在给定 E 的线段上，若 F_q 绝对连续且满足链式积分条件，则：

    b_q(E) = F_q(E,x0)
    K_q(E,d) = integral_0^1 grad_x F_q(E,x0+s*d) ds
    F_q(E,x) = b_q(E) + K_q(E,d)^T d.

K 是依赖条件及位移的平均敏感度向量；不能把整个 K 默认当作一个固定线性
算子。对于当前固定仿射函数，写成 f_q(x)=f_q(x0)+J_ref,q^T d，得到：

    F_q(E,x)-f_q(x)
      = [b_q(E)-f_q(x0)] + [K_q(E,d)-J_ref,q]^T d.

现在有两个具体目标：条件起点 b_q(E)，以及沿当前材料位移变化的敏感度。
这不是任意指定两项凑和：第一项已有固定 P/Q 后的原生干预值；第二项由端点
及路径导数定义。恒等式只给出对象定义，尚不等于已获得轻量计算器。

这是微积分的路径积分关系，与
[Sundararajan、Taly 与 Yan（2017）的 Integrated Gradients](https://proceedings.mlr.press/v70/sundararajan17a.html)
同属基线相对的函数归因思路，不作为 GRAIN 独创定理。GRAIN 此处的工作是
对齐同作者、同材料、同观察器的已测条件项、固定函数与人类效标。

实际实现必须保持参考精度：旧干预把 x0 转成 FP32，f(x0) 与存储的理想
b_ref 有约 1.53e-8（T/F）及 2.55e-9（N）的常数差。旧运输账本按 b_ref
定义，新积分式按实际 x0 定义；常数可精确换算，不能暗中混用。

## 4. 分解闭合不等于归因唯一

换参考 x1 时令 h_q(E)=F_q(E,x1)-F_q(E,x0)。则精确地：

    b_1(E) = b_0(E) + h_q(E)
    R_1(E,x) = R_0(E,x) - h_q(E)
    b_1 + R_1 = b_0 + R_0 = F_q(E,x).

总函数不变，两部分的作者协方差可以重新分配。因此“条件项仍含效标联系”
是在已声明参考下的结果，不能宣称找到了唯一、参考无关的人格成分。
这不是删除条件项的理由，而是与 GRAIN 固定参照总体相同的设计要求。

旧 M15 的四格作用表已测得非加性交互：

    I = F(E,x)-F(E,x0)-F(C(E),x)+F(C(E),x0).

C(E) 是评论内均值化，保留布局。先改变 E 再改变 x，与相反顺序，所分配的
两项差额就是 I，总和仍一致。下一步应追踪这个已测交互怎样改变本轮留下的
关联，不能重新宣称“发现了交互”。[Hooker（2007）](https://doi.org/10.1198/106186007X237892)
指出依赖输入的函数分解需要明确权重和支持区域；本项目的锚定分解不是独立
输入 ANOVA，也不能把有符号协方差说成互斥心理方差比例。

## 5. 对全系统的实际更新

| 层 | 保留的功能 | 新增的连接要求 |
|---|---|---|
| GRAIN 表达测量 | 作者相对群体的位置、选择、分布、动态 | 保留条件组成和明确时钟，不能用模型 E 替换自然条件 |
| 查询功能提取 | 固定 f、均值/配置/最终位置贡献 | 不能只压成一个总分再期待任意 g 找回所有条件区别 |
| 条件构造 | 已测 b(E)、配置主效应、奇偶作用、响应积分 | 分别压缩可观测目标，且检验总函数及相互抵消；不重跑旧浅层均值网格 |
| 效标连接 | 同作者技术值与自评的关联 | teacher 拟合、干预重建和效标保留分别记账，不据 Y 选函数 |
| 解释层 | 将有来源的技术关系翻译为可理解说明 | 说明查询、参考、条件和材料单位，不把函数命名当心理效度 |

一个可发展的程序形式是：

    T -> {GRAIN(T), x_hat(T,q), E_summary(T,q)}
      -> b_hat_q(E_summary) + K_hat_q(E_summary,d_hat)^T d_hat
      -> fixed-reference author scores / material responses
      -> separately observed questionnaire or behavior links.

这是接口目标，不是当前已经完全脱离编码器/LLM的部署事实。它将两个原本
独立的逻辑接起来：GRAIN 保留条件下的群体差异，查询路线定义这些差异如何
进入某个明确判断。既不丢掉 E，也不把整个完整模型的所有敏感性照搬为人格。

## 7. 条件分布差作为新的可计算作用候选

NEXT16沿已定位配置项构造了一个具体函数，不再只写出未知K：令每条评论
token投影h_t=c_t+d_t，用训练参照定义theta(c_t,position)与u(d_t)，在固定
随机方向上计算cos/sin特征差，再按反射拆成奇/偶向量Phi_o、Phi_e。

    A_hat(E) = beta_o^T Phi_o(E,C(E)) + beta_e^T Phi_e(E,C(E)).

所有方向、频数、惩罚及四个臂先固定。Phi_o反射变号、Phi_e不变，零位移时
二者均0；正反端点的等权平方损失精确分成奇/偶两部分。均值保留在相位中，
因此“固定均值后研究偏移”并不等于删除均值所含作者信息。

对任意可微phi，phi(C+d)-phi(C)=integral grad(phi)(C+s*d)^T d ds。
有限特征的线性组合作用因而有显式的积分表示。两套奇偶权重允许更一般的
反射分解；其和依然是关于d的明确可微函数，而非宣称复制唯一真实梯度。

实测局部可读：N位置傅里叶的配置作用r=.368，但MSE/零作用=2.657；T/F
非位置傅里叶偶作用r=.471、MSE比=.840。没有普遍胜过同输入三阶对照。
若干T/F作者自评联系反而较高，说明恢复指定作用与保留作者效标可再次分离。
这些函数值得保留为研究坐标，不据最大自评关联选一个替代固定计分系统。

新增输入能力不能自动推出学习成功。更关键的下一连接是：当前按token
相加的分布差，还需不需要跨评论共同作用；以及T/F均值化后保留的B到底由
哪些状态承载。先核对真实交叉端点，再决定是否加入分布层的非线性组合，
不能把每次剩余误差都未经测量地归为“更高阶交互”。
