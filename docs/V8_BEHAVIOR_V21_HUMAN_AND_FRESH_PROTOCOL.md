# V8 Behavior-v2.1 Human and Fresh-Panel Protocol

## Current Boundary

The opened 24-author panel established a technical candidate, not observer
accuracy or psychological validity:

- five-family soft behavior AUC: 0.699 [0.554, 0.798], p=0.0010;
- repetition AUC: 0.669 / 0.683;
- cross-model family macro-F1: 0.771;
- nested 3/6/9/12-comment AUC: 0.589 / 0.639 / 0.679 / 0.699.

Exact-subreddit residualization is retired. Reddit conditions are too sparse
and too author-linked for that estimator: the attempted matched control still
had condition AUC 0.803. The present object is therefore a joint
choice-and-expression profile. It does not yet isolate response under a
shared condition.

No geometry bridge may be reopened until both the human-observer gate and
fresh-author gate pass.

## Frozen Scoring Object

The LLM is an evidence observer, never a person scorer. It emits:

1. explicit opportunities;
2. 14 atomic textual acts;
3. exact source-span bindings.

Deterministic code compiles five scoring families:

- `stance`;
- `affect`;
- `self_report`;
- `action_guidance`;
- `generativity`.

The primary profile is the mean of two binary observer repetitions. Atomic
codes remain the evidence and explanation layer. An atomic code with
human-gold F1 below 0.65 cannot be used as an independent score.

## Human-Gold Gate

### Sampling

The existing 576 segments are reused without new model calls:

- 48 training items, one per opaque half-profile;
- 336 natural-prevalence items, seven per profile, selected only by a fixed
  hash and used for headline accuracy;
- 192 enriched items, four per profile, selected for disagreements, rare
  acts, and boundary coverage; these may diagnose recall and definitions but
  cannot estimate natural prevalence or headline accuracy.

Two coders work independently. They cannot see author, half, subreddit,
model prediction, GRAIN score, personality labels, or psychological
interpretations. A third adjudicator reviews every coding/evidence
disagreement and a deterministic 10% sample of agreements.

Before evaluation, an expert completes the separate 48-item training key.
Both coders practice on those items and resolve rubric questions against the
expert key. Training items are excluded from every agreement and accuracy
estimate.

The packet is generated by:

```bash
python scripts/build_suica_v8_behavior_v21_human_packet.py \
  --output-dir results/v8_behavior_v21_human_gold_packet/pandora_20260725
```

The frozen packet contains coder sheets, an exact observer rubric, a local
hidden key, manifests, and an inventory. The hidden key is never shared with
coders.

### Human and Observer Gates

All headline accuracy metrics use the 336 natural items:

- each coarse-family human-human Gwet AC1 >= 0.75;
- any coarse-family AC1 < 0.60 causes `HUMAN_ONTOLOGY_STOP`;
- primary observer coarse macro-F1 >= 0.80;
- each coarse family precision >= 0.80, recall >= 0.70, and F1 >= 0.75;
- opportunity macro-F1 >= 0.80 and every opportunity F1 >= 0.75;
- evidence-span F1 >= 0.80;
- audit-model coarse macro-F1 >= 0.75;
- absolute primary/audit macro-F1 gap <= 0.10;
- at least 30 adjudicated positives per coarse family across the complete
  natural plus enriched evaluation set.

Run the evaluator first on completed coder files:

```bash
python scripts/evaluate_suica_v8_behavior_v21_human_gold.py \
  --coder-a PATH/TO/coder_A_completed.csv \
  --coder-b PATH/TO/coder_B_completed.csv \
  --output-dir results/v8_behavior_v21_human_gold_evaluation/pandora_20260725
```

This writes `adjudicator_items.csv` and stops at
`WAITING_FOR_ADJUDICATION`. Rerun with:

```bash
python scripts/evaluate_suica_v8_behavior_v21_human_gold.py \
  --coder-a PATH/TO/coder_A_completed.csv \
  --coder-b PATH/TO/coder_B_completed.csv \
  --adjudicated PATH/TO/adjudicator_completed.csv \
  --output-dir results/v8_behavior_v21_human_gold_evaluation/pandora_20260725
```

Blank or malformed coding files produce only a waiting decision. The
evaluator never substitutes LLM predictions for human labels.

## Fresh-Author Replication

This stage begins only after `V8_BEHAVIOR_V21_HUMAN_GATE_PASS`. Its frozen
machine specification is
`configs/v8_behavior_v21_fresh_protocol.json`.

The no-call preflight has already established sufficient author, text, time,
and thread support: all 300 scanned candidates supported two thread-disjoint
32-comment halves, and the 190-author panel was frozen. It also established
that exact-condition C2 is structurally unavailable in this Reddit sample:
only five conditions passed discovery support, they covered 15.8% of
discovery segments, and exact-condition crossed-cell completeness was 0%.
The fresh run therefore targets the joint/C1 object only. C2 moves to a
separate fixed-condition design unless new shared-condition data are added.

### Panel

- pre-extract at least 190 eligible authors;
- exclude every author used by earlier V7/V8 panels;
- assign 60 discovery, 20 calibration, and 80 confirmation authors;
- require at least 64 comments per author;
- create thread-disjoint, time-even halves with 32 comments each;
- score 12 comments per half as the primary object;
- score 24 comments per half as a preregistered resolution extension;
- run two primary repetitions and an independent audit on 20% of authors;
- after the human gate, run discovery plus calibration first to check event
  support, observer drift, and the frozen score implementation;
- freeze all file hashes after that technical check;
- do not open confirmation AUC unless all 80 confirmation authors are ready;
- keep the 30 reserve authors untouched.

The five families, soft aggregation, cosine distance, and all thresholds are
frozen before the panel is selected. Discovery may fit nuisance/support
objects; calibration may choose registered shrinkage; confirmation cannot fit
or select anything.

### Fresh Gates

- m12 confirmation AUC >= 0.60;
- author-cluster CI lower bound > 0.50;
- pairing-permutation p <= 0.01;
- each repetition AUC >= 0.58 and their gap <= 0.08;
- m24 AUC no more than 0.02 below m12;
- nested log-resolution slope >= 0;
- human drift-audit coarse macro-F1 >= 0.78.

Failure yields `V8_BEHAVIOR_V21_FRESH_STOP`.

Report three distinct profiles: coarse behavior repertoire, C1, and their
joint representation. The joint object may claim incremental behavior
information only when its paired AUC gain over C1 has a confidence-interval
lower bound above zero. Otherwise it merely reproduces C1.

## C1 and C2 Identification

The fresh study reports two separate objects.

### C1: Selected Context and Opportunity

C1 contains condition distribution, opportunity rates, length, and format.
Compare halves with Jensen-Shannon and Hellinger distances. C1 is observable
selected-context behavior. It must not be called nuisance or
condition-invariant personality.

### C2: Response Under Shared Conditions

Fit condition expectations on discovery authors only. An exact subreddit may
be used only with at least 10 discovery authors and 50 discovery segments;
otherwise use a registered coarse/global fallback. Select shrinkage from
8/16/32 on calibration only.

For event family \(k\), author \(u\), and eligible observations \(i\):

\[
R_{u,k}
=
\frac{
  \sum_i O_{i,k}
  \left(Y_{i,k}-\widehat m_k(C_i,X_i)\right)
}{
  \sum_i O_{i,k}+\lambda_k
}.
\]

Here \(O\) is the observable opportunity, \(Y\) the explicit event, \(C\) the
condition support class, and \(X\) registered format/length variables.
Neither the target author nor confirmation outcomes may enter
\(\widehat m\).

For a future fixed-condition test, hash supported conditions into A/B, construct
left-A, left-B, right-A, and right-B profiles, then compare left-A with
right-B and left-B with right-A. Each family/cell needs at least six
opportunities and at least 70% of confirmation authors must be complete.
Otherwise report `C2_NOT_IDENTIFIABLE_IN_REDDIT`, not a null effect.

C2 passes only if ordinary AUC >= 0.60 with CI lower > 0.50 and p <= 0.01,
crossed AUC >= 0.56 with CI lower > 0.50 and p <= 0.05, m24 is non-inferior,
and observer direction is consistent.

The estimator supporting this future design has separately passed a
planted-world technical battery. Its score track must use a fixed observation
quota and must not include author-specific standard errors. Its inference
track must use link-scale Firth estimation with condition-number, coefficient,
and interval-width refusal. Score AUC, operator recovery, and
probability-incidence summaries must remain separate. The planted PASS does
not relax any human gate in this protocol.

Future human analysis must additionally separate all-stranger,
within-group/local-neighborhood, and group-level pairing. A high all-stranger
author AUC cannot support an individual-difference claim when the
within-group result is null. Stable residual structure must survive both
independent text halves and an independent observer; otherwise it is reported
as unstable variation or observer fingerprint. Any individual result below a
registered simulation-derived detection limit is reported as below detection,
not as zero individuality.

The existing 46-person MEPS bundle cannot meet this confirmation gate. It
provides three shared prompts but exactly three direct-answer slots per
condition and no independent repeat; only 2/46 participants have at least six
AI-chat turns in all three prompts. It may be used after the human gate as a
shared-prompt ontology/procedure pilot, never as a C2 confirmation sample.

## Promotion Boundary

Human accuracy plus fresh replication licenses a reproducible explicit
verbal-behavior measurement object. C2 additionally licenses an
opportunity-conditioned response object. Neither licenses a personality
construct, an emotion construct, diagnosis, clinical use, or person-level
interpretation. Those require later external and repeated-measurement data.
