# 相同输出方向下的条件读取与可计算 token 作用

2026-09-10，NEXT39，第28轮。接续[输出方向与上下文传输](GRAIN_READER_OUTPUT_SEED_THEORY_V1.md)。
本轮把标准注意力导数接到了真实作者材料、冻结模型和GRAIN方向，不创造
新的人格构念，也不把原有测量路线改成只有一个模型的解释工具。

## 1. 相同终点不产生相同正文路径

令c为0–9固定候选值去均值、单位化的向量，z为候选logits：

\[
L_q=c^Tz_q,\quad s=W_A^Tc,\quad J_q=K_q^Ts,\quad K_q=D_{H_{16}}x_{final,q}.
\]

c与候选输出权重在全部12作者、N/确认两个查询中完全相同，所以s也相同。
保持作者正文块16状态相同后，新8人J余弦为.657（.519–.761），旧4人.728。
原概率目标的相应值为.649/.704。相同s下同一K必然给出相同J，因此这次
确实测到了条件传输的差异，不再只是上一轮“同算子改变两个夹角”的歧义。

K仍包含查询状态和布局的共同作用。L是为了识别传输而固定的logit函数，
不是原概率评分F，也不直接代表问卷。余弦不是人格相关或共享信息比例。

## 2. 实际模型中每个 token 的两条局部作用

最后attention block的归一化输入记为h_j，最终读取位置为l。h代表head时
写作下标m，避免与隐藏向量h_j混淆；b(m)是共享key/value的组。

\[
\begin{aligned}
q_m&=W_{Q,m}h_l+b_{Q,m},\\
k_{bj}&=W_{K,b}h_j+b_{K,b},\\
v_{bj}&=W_{V,b}h_j+b_{V,b},\\
a_{mj}&=\operatorname{softmax}_j\left((R_lq_m)^TR_jk_{b(m)j}/\sqrt d\right),\\
o_m&=\sum_j a_{mj}v_{b(m)j},\\
g_m&=\nabla_{o_m}L.
\end{aligned}
\]

对不是最终query位置的正文token，有精确局部式：

\[
\nabla_{h_j}L=\sum_m a_{mj}
\left[
\underbrace{W_{V,b(m)}^Tg_m}_{u_m:\text{值传输方向}}
+\underbrace{((v_{b(m)j}-o_m)^Tg_m)}_{\rho_{mj}:\text{相对上下文的值作用}}
\underbrace{W_{K,b(m)}^TR_j^TR_lq_m/\sqrt d}_{t_{mj}:\text{key选择方向}}
\right].
\]

这里的“选择”是模型attention权重如何改变，不是人的自由选择或临床动机。
同组head的key/value梯度必须相加，不能平均；R的转置必须保留。最终位置
还包含query、残差等路径，本式只覆盖声明的非query正文输入，未丢掉后者
再冒充完整的所有位置Jacobian。其它层需要继续链式组合。

推导基于标准[多头注意力](https://arxiv.org/html/1706.03762v7)、
[GQA共享投影](https://arxiv.org/html/2305.13245v3)和
[RoPE位置旋转](https://arxiv.org/html/2104.09864v5)。执行核对了本地Qwen2源码：
12query heads、2KV groups、d=128、block27。不是拿普通无位置单head
代替实际网络。本项目新增的是针对研究问题的接合、实测和可复算接口。

## 3. 实测把哪个机制推到了前台

24/24单元的解析value+key梯度与原生归一化BODY梯度一致：最大相对L2
误差2.03e-6，最大单元绝对误差6.60e-9。这一层的GRAIN有符号作用加和
相对L2误差8.84e-7。因此现在可以分开测量u与rho*t，而非只观察一个黑箱J。

新8人平均逐作者范数比 ||J_key||/||J_value||：N1.826、确认1.887。
若只保留value项，该层相对平方误差平均.731/.743。两场整体余弦接近0，
但沿特定GRAIN方向可能相加或相抵；新8人的64个方向作用中6个反号。
场空间的近正交不等于所有投影上的独立，范数比也不等于人格信息比例。

各head平均仅约13.1%/14.0%注意力质量落在选中的正文token上。其余质量
包括未选正文、边界、模板和查询等，不据此指认是哪一类“噪声”。关键是
o_m来自整个可见上下文，计算rho时不能仅对选中正文重新归一化。

## 4. 如何接回GRAIN与先前的共享方向研究

本轮GRAIN只定义当前层的局部探测方向D_k(j)，并计算：

\[
\tau_k=\sum_jD_k(j)^T J_j
=\tau_{k,value}+\tau_{k,key}.
\]

块16的D_k与最后归一化输入的D_k按各自输入分别构造；二者不是同一数值
干预，不能把两层tau直接相减当信息传输比例。这里没有重新拟合GRAIN。

以前的共享方向V+局部系数a是一种经验压缩。现在得到一个更具体的候选
生成程序：a_mj、rho_mj、u_m、t_mj。共同投影权重可以固定，但查询、位置、
全局汇总和下游读取共同改变方向/系数。这与源方向库能表示新作者、单纯
局部H回归却失配的现象相容，也给出下一步可动手开发的变量，而非事后命名。

## 5. 下一个可独立提取的接口

当前q/k/v仍来自冻结模型前向，g来自当前目标反向。解析分解不是已经脱离
模型的完整人格推论器。下一步[NEXT40](GRAIN_SOURCE_COTANGENT_READER_PLAN_V1.md)
只把g替换为源作者固定方向，其余a/o由当前缓存q/k/v直接计算，再检验新
作者的局部作用。这样无需当前作者的logits、评分或反向目标参与预测。

这先推进一个真实的计算依赖，不重做低秩/alpha网格，也不要求本轮解决
完整encoder替代。保留所有作者与反号分量；作用能被读取后再接完整分数
与已有人的效标通道。系统测量和有来源的辅助解释仍分别记录。
