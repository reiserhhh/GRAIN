# GRAIN 综合使用手册：从一批原文到可解释的个体估计

[English](GRAIN_USER_MANUAL.md) · 简体中文 · [日本語](GRAIN_USER_MANUAL_JA.md)

[当前工具入口、输入协议与离线验收](GRAIN_CURRENT_TOOLCHAIN.md)

要估计一个人在不同情境下的回应，而不是只算发言频率，请看[自然表现、同机会响应与情境反差](GRAIN_RESPONSE_PROFILE.md)，内含可执行算例和真实对话重放。

总池与筛选池重叠、参与者进出或发言时间不规则时，请参阅[开放语流六项工具、适用条件与算例](GRAIN_OPEN_STREAM_OPERATORS_G1_G6.md)。

假设你收到三个月的讨论记录，想知道两件事：有人是否经常提出备选方案？被告知原方案不可行后，他是否改变做法？第一问要看有多少次机会、在哪些情境表达过；第二问需要知道谁在何时对谁说了什么、下一次是谁回应。把三个月的文本合成一个向量，两道题就只剩一个答案。GRAIN 的用途正是让你保留这些区别，再决定哪些区别值得编成量表条目。

本书写给三种读者：带着自己语料的使用者、要制作新工具的研究者、接入服务的工程师。先做第 2 节的小研究；做作者比较接着读 3–7，做会话过程读 8–10，开发新测量与跨领域使用读 11–14。仓库的历史冻结量表、今天从零制作的量具、带特殊模型的研究实验不是同一件成品。

## 1. 先确定你要交付什么

| 你最终要回答的问题 | 需要保留的单位 | 第一份交付物 |
|---|---|---|
| 新作者相对哪群人偏高？ | 每位作者一行；可比的取样机会 | 冻结坐标、每轴百分位和联合距离 |
| 他倾向进入哪里，在那里怎样表达？ | 作者 × 自选情境 × 次数；另有固定条件下的表达 | 选择构成和条件响应两张表 |
| 一部分人不再在这里发言，后来去了哪里？ | 前窗可见名单、来源命名空间、范围覆盖及后窗观测 | 参与迁移、已见去处和群体构成，未知覆盖单列 |
| 换了选项后同一批人怎么选？ | 每人的实际资格、行为结果和可选的独立坐标 | 配对动作变化区间和两端证据覆盖 |
| 同一段文字内部如何变化？ | 独立会话内有序事件；需要秒数时另存时间戳 | 原始路径、简单平滑、变化位置 |
| 是本人改变了说法，还是搭档说了另一件事？ | 说话者、受话者、纠正点、截止点、本人回应 | 带原句地址的证据卡或双人路径 |
| 两种观察是否约束了同一个量？ | 同对象、同坐标的两个视角及独立校准 | 简单比较、可行区间、复杂方法排除了什么 |
| 如何制作一种新场景下的文本测量？ | 一份制作简报、来源队列、独立校准和待测对象 | 可移交的冻结量具、冷计分结果、解释规则 |

所谓 4W 是实际建表的次序：**where** 是可选与实际进入的情境，**what** 是观察到的表达，**who** 是在指定群体里的偏离，**when** 是路径的先后或物理时间。“大家都谈 A，但此人还反复选择 B”首先属于选择记录。把话题当作噪声统一减掉，可能恰好删掉要研究的差异。

下游批量使用时，参考[流水线实测与硬件选择](GRAIN_PIPELINE_PERFORMANCE.md)：给多份独立文档冷计分、减少远端启动、选择 CPU 或 GPU，以及核对加速前后的数值。

## 2. 第一次运行：让两个人说相同的话

在仓库根目录使用 Python 3.12。下面用虚构英语短句，不下载语料、不调用模型服务、不需要私人权重。首次安装依赖需要软件源；装好后示例离线运行。

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-lock-main.txt
python -m examples.handbook_study /tmp/grain-first-study
```

输出目录必须是新目录。打开 [示例源码](../examples/handbook_study.py) 的 `corpus`，看两个目标作者：每人在每个场合都说了三句计划、三句探索。甲先连说三句计划，然后转为探索；乙每说一句就换一次。这里的“计划/探索”是写示例时的安排，算法看不到这些标签。

| 本地输出 | 怎么读 |
|---|---|
| `discovery.json` → `native-reference.json` | 12 名来源作者、两种情境、每人 A/B 两组记录。只用这些人的文本学习词表、投影、软节点，再在来源内寻找跨 A/B 可重现的候选轴。 |
| `calibration.json` → `calibration-units.json` → `chart.json` | 另取 10 人，固定两轴：第一节点的平均占比、相邻事件节点向量的平均欧氏步长。先逐会话计算，再等权平均为每人一行；只用这 10 行建立参照。 |
| `target.json` → `target-units.json` → `positions.json` | 两名新作者都用同一个参照，不参与拟合。先看原量，再看百分位；联合距离没有“向上”的含义。 |
| `target-families.json` | 与上述两条预设教学轴**分开**的静态、动态、条件偏移特征和来源发现的因子得分。没有合格载荷时得分是 `null`，特征仍可读。 |

一次实跑的结果：甲、乙在第一轴均为 0.15；在步长轴分别为 0.40、1.00。1.00 表示超过本例十个参照值，不是 100% 的人格概率。节点编号和数值会随依赖及参照改变；可复核的设计关系是**相同句子集合的占比不随排序改变，而相邻步长可以改变**。这条原生路径不需要液态网络。后面若换用学习的时钟，再和这里的直接观测比较。

已有数值的团队可以单独重算最后一步，仍使用同一参考图：

```sh
python -m grain_core.liquid_reference_error locate --chart /tmp/grain-first-study/chart.json --input /tmp/grain-first-study/target-units.json --out /tmp/grain-first-study/recheck.json
```

## 3. 换成自己的文本：一条记录应该是什么

保留内部原文表：匿名作者、会话 ID、原始发言 ID、说话者、可用的搭档/受话者、时间与时区、当时能看到的上下文、主题/条件、自选还是分配、文本版本。脱敏不能破坏轮次或说话者归属。长帖子可以切片，同帖切出来的十片不是十个独立作者。引用别人时把原作者和引用动作分开；编辑过的文本只能用于编辑版本已可见的分析。

无说话者交错的英语输入如下；双人对话另用[对话样本](../examples/liquid_new_dialogue.json)，不要把整场谈话署在一人名下。

```json
{"language":"en","clock":"opportunity","episodes":[
  {"id":"case-01","author":"p17","condition":"detour","carrier":"route-note","view":"A",
   "events":["I checked the route on paper.","I tried another route."]}
]}
```

`condition` 是观察在哪种情形发生，`carrier` 是表达用的媒介或任务格式，`view` 是该人的不同观察材料。机会钟按保留的切片前进，不是秒。这个输入可以交给已拟合的阅读器；一个人一场谈话不足以从零学习跨人因子。未给机会、给了机会但没回答、回答了且有反证须在自己的事件表中区分。原生英语入口遇不到词表内词时输出 `outside_vocabulary`；有一个词命中也不代表整句的语义已被接收。新语言先验证入口，数值已在同坐标时可直接从数值层接入。

**怎样划分。** 先按作者分出发现、校准、应用集，再在作者内按任务或会话形成不重叠的 A/B。若比较跨搭档能力，也隔离搭档；若声明可用于未来数据，按决定截止时间向前划分。将一句话随机分入训练和测试的两半，只验证重复读取。参照框架记录总体、纳入条件、文本量、机会分布、语言、模型与版本。一个人发了一千帖不应自动在作者常模中得到一千票。

**直接换入自己的资料。** 把三个独立队列分别存成 `discovery.json`、`calibration.json`、`target.json`，都用上面的格式，放在同一个本地目录。运行 `python -m examples.handbook_study /tmp/grain-my-study --inputs /path/to/prepared` 即可走完全程。作者 ID 必须跨队列一致编码且不重叠。这份步长配方要求每个会话至少有两个事件、校准人数多于轴数、两轴在校准人群中都有变异；校准或应用文本中整片词表外则停下提示检查覆盖。输出会复制三份输入原文，须存放在私有目录。若研究目标是已有量表轴或真实秒数，分别走数值轴、秒钟接口，不要把教学步长改名充当它们。

在 `calibration.json` 顶层增写 `population`（谁构成常模）与 `namespace`（三份资料共用的作者 ID 体系）。**以后只来一份新文本怎么办？** 只需保留 `native-reference.json` 和 `chart.json` 两份冻结件，用下列命令，不需要交出原始来源文本，也不会重拟词表、因子载荷或常模：

```sh
python -m examples.handbook_study /tmp/grain-placed --frozen-from /tmp/grain-first-study --new /tmp/grain-first-study/target.json
```

## 4. 从切片到节点：从零制作坐标

先保留整条发言作为最简单的观察，再问较细的刀法能增加什么。固定宽度适合比较相近文本量；语义切法尝试跟随来源语料的变化点；按已学习的情境词切适合已有可靠边界的项目。各切法是并行观察：同名的第 3 节点在另一刀法里没有自动对应关系。比较时在**同一批保留原文**上看哪些位置关系延续，再谈运输。

公开英语原生路径从来源切片拟合词项 TF–IDF、截断 SVD 及标准化，再建硬树或软混合。硬树给出一条离散地址；软混合给每个切片一组非负节点权重，适合界面模糊的表达。节点是“文本落在哪里”；因子是“跨多片、多人、观察视角可以重复出现的组合”。一个切片、一个关键词、一个节点都不会自动成为人格因子。为每个候选节点抽高权重片、边界片、同话题反例，保留读者核对它所指的机会。

若要复建发布史中的工具，而非重新发现坐标，按[原始制作记录 S1–S10](WORKED_EXAMPLE_MANUAL.md)顺序做：冻结人员层级、切片计分、用已知真值检查公式、按不同场次重测、比较选择与情境反应、发现候选、盲读题库、最后才对外部量表。该路线所需 PANDORA 等授权文本并未随库分发。历史 19 项构念的操作定义查[构念登记册](CONSTRUCT_REGISTRY.md)，不要把今天新拟合的 `gmm_00` 称作其中第 1 项。

## 5. 静态、动态、条件反应、残差：四种不同的阅读

记某次发言在节点上的权重为向量 $p_t$。静态问题看 $L=\sum_t p_t/T$。静态层另存条件出现比例，例如 8 次改道占 10 次机会。想知道在改道时怎样表达，则看 $R(c)=\bar p_c-L$ 并同时给出该格的样本量；没遇到改道时，这个值未知。条件是被分配的，比例反映设计；是作者自由选择的，比例本身就是观察。

动态层沿真实的会话边界读取波动、惯性、粗糙度、趋势、变化点、多尺度描述。保持每次发言不变而打乱中间顺序，是判断某读数究竟对什么敏感的办法。不要跨会话相减。公开阅读器的 `hybrid` 家族指各条件的节点均值相对个人总体的偏移；历史文献中另有静态/运动两个视角的共享子空间。两者构造不同，报告直接写公式而不只写 hybrid。

因子发现先在来源 A/B 内选能跨视角对齐的方向，然后冻结中心、尺度和载荷，对新作者投影。平行刀法、重抽作者、打乱身份后的方向可以用作对照。未形成可复现方向时，把高维特征、相似结构与各条件覆盖留下；别为填表制造一条轴。残差首先是指定模型没吸收的部分：检验它跟话题、长度、作者习惯还是条件响应走，再决定如何解释。用 Big Five 或 MBTI 做外部联系，应以留出作者为单位；有外部联系时报告对应哪一轴、多大、在哪个总体，不能把作者识别率替代该关系。

## 6. 给新作者打分：位置、距离、误差各说什么

给固定轴的分数 $x$，参照人数 $n$，百分位是 $(\#\{x_i<x\}+0.5\#\{x_i=x\})/n$。两侧都数，是为了让并列落在中间。联合距离先减参照中心再白化，反映整组特征有多不寻常；相距同样远的人可以在相反方向偏离。若要解释“偏向什么”，回到带符号的各轴和贡献段落。批量探索输出 `legacy_batch_relative_node_scores` 的基准会随同批样本改变，不能当作单人固定分。

误差也有不同来源：抽哪几次谈话决定机会覆盖，抽哪些作者决定参照精度，换入口可能改变坐标本身。按作者或完整会话重复抽取，不按相邻 token 当独立重复。置信区间反映重复抽样；未观测机会给出的可行范围反映现有资料兼容哪些答案。两者即便都写成方括号，也不能互换。复评同一人时保留同一参照并报告情境与文量变化；若总体已改变，两版坐标分别报告或用共同锚定材料重新校准。

## 7. 水面下的路径：液态阅读器如何追踪“墨水”

上一节回答“在哪儿”。这一节回答“第 k 个机会的证据在第 t 个机会仍让阅读器偏向哪里”。在获准使用的计算环境中，除核心包外需要 PyTorch 和 ncps（已记录支持版 1.0.1）。生成的教学来源文件也可作为小型输入；它不是训练心理工具的样本。以下额外路线与第 2 节原生示例相互独立：

```sh
python -m grain_core.liquid_instrument fit --input /tmp/grain-first-study/discovery.json --out /tmp/grain-first-study/ltc.json
python -m grain_core.liquid_instrument score --reference /tmp/grain-first-study/ltc.json --input examples/liquid_new_episode.json --out /tmp/grain-first-study/episode-scores.json
python -m grain_core.liquid_dialogue --reference /tmp/grain-first-study/ltc.json --input examples/liquid_new_dialogue.json --out /tmp/grain-first-study/dialogue-scores.json
```

配对比较四条路径：`native` 是当下的节点占比，`fixed_half` 是保留率 0.5 的简单平滑，`liquid` 是学习的下一节点分布，`anchored_signed` 是相对于单次重置的带符号历史修正，最后一条不是概率。先看源句进来时有没有写入，再看还能影响几步；入口把替换的两种说法映成一样时，下游读不出区别要先检查入口，而不是解释为人格扩散太快。

置空第 k 个切片、让钟照走，与原路径相减得 `missing_effect[k][t]`。联合置空与单次置空之和的差是 `joint_minus_sum`，用来找证据间相互增强或抵消的地方。保留两端只交换中段则看 `same_ends_middle_swap_rms`，这回答顺序是否影响终点，而非某个词有没有心理含义。需要从输出逆推来源时，`liquid_inverse` 给兼容的来源权重区间；多个来源有相同读数时，要保留多个解释。模型内部神经元的真实替换属于另一个需授权模型的研究路径，不由上述张量产生。

## 8. 黏度、撤回与时间：同一段话如何读出不同问题

设计两种开放格式：自由说明，或围绕同一具体事件作答。匹配主题、任务、篇幅、可表达的选择，同时改变格式。比较同一来源在两种格式下的**初始写入量**与随后各位置的**保留路径**。一开始就没写入的证据，不能用终点衰减比来解释。刚性模板让所有人写得一样，也可能造成“看起来很稳”；同时检查无关漂移是否减少、来源间可分的差异是否保留。这样的配对描述了给定载体和阅读器下的扩散，不预设每个人有一个固定黏度数。

撤回设计是“基线 → 加信息 → 澄清/撤回”，再与共享真实前缀、却未作同样撤回的分支比较。记录距基线的路径、写入量、恢复比例；初始位移为零时不算恢复率。交换 A、B 顺序的实验回答顺序效应，不能当成撤回。自然对话缺乏匹配分支时，可以报告观察到的转折及时间，不伪造对照。

`liquid_event_time` 另接带秒数的数值路径，区分无事件的间隔和下次到达；`riccati_mobius` 可在冻结输入假设下计算精确连续时间流。词、保留切片、发言轮和秒是四种钟，不能互换。一个月的帖子序列适合研究长期选择，却无法给出句内自我修饰的秒级速度。[各算子、输入形状和可复用代码](GRAIN_LIQUID_TOOL.md) · [连续时间与动态反演](GRAIN_RICCATI_AND_INTERPERSONAL_UPDATE.md)。

## 9. 真对话：区分内容相同而作用不同的行为

“好”可能是在表态、复述对方，也可能只是把话轮交还。先标出目标人、搭档、被回应的事件和命题；展示内容单独、本人连续发言、完整互动三份读法。双人阅读器按发言与切片指纹对齐本人路径和共同路径；共同路径减本人路径既移走搭档文字也移走搭档占用的机会。要问是谁影响了后续，在同一共同钟上分别置空本人和搭档既往输入。

```sh
python -m grain_core.event_response examples/event_response.json
```

例中搭档把 red 纠正为 blue，焦点人下一次说使用 blue，因此在该截止点支持“采用了新前提”。这条证据是本人的那句回应，不是搭档的纠正，更不是以后已经行动。判读时分开支持、反证、回答但不足以判断、尚未轮到回答。若目标情境中实际观测部分权重为 0.75 且全部支持，其余未见，则总体范围为 [0.75,1]。内置显式英语规则只处理其覆盖的事件；自由改写可接独立预编码读者，同样必须绑定到原文和截止点。用真实数据报告关系时标清“谁评谁、谁听懂谁”；同一场对话可有两个不同答案。

```sh
  --queries examples/evidence_stream_queries.json
```

先看 `diagnostics` 的记录数、可计量数和未闭合的采集范围，再读 `forum_flow`、`writing_shift` 和 `paired_choice`。未记录不当作明确拒绝；文本在冻结词表外时保留其参与，但不算坐标。算例中一次动作结局未知，配对变化在 `[0.5, 1.0]`，不是一个强行补齐的点。独立材料默认不凭编号连接同一个人。[输入格式、适配器和内存取舍](GRAIN_EVIDENCE_PANEL.md)。

回答“某种行为在什么机会下出现”，使用 `response_profile`；只有独立标定过读者才启用 `measure_calibrated`。原卡与校准结果并列。回复内的读者误差不能套在没回复者身上；校准值和观测率不相容时，返回状态并保留不确定。[校准、信赖性和可比性说明](GRAIN_PSYCHOMETRIC_OPEN_STREAM_V2.md)。

## 10. 共同结构、双视角与向量证据

两个量表场都响应同一句话，有三种起点：同一个来源、两个特有成分恰好同向、共同的读者或语料偏差。先固定观测对象，再比较保留单视角、交换视角、保持条件而置换作者等结果。`liquid_common_range` 对独立来源校准后的数值视角返回“全由特有成分解释”和“最低特有代价”的重构；显式限制特有分量预算才可能把共享位置收窄。比较两个时点时保留起终点的兼容集合，不从拓扑交点直接命名心理特质。

```sh
python -m grain_core.dual_view_increment examples/dual_view_increment.json
```

工具依次对比当期两视角、只传播公共趋势、各自传播再求交、强制共用同一历史。示例从简单滞后的 [−0.4,2.0] 收窄至 [0.8,1.2]，零由可能变成不可能。这才是复杂分解多提供的信息；区间相同就保留简单法。若要问“某量表词怎样引导模型从文本选取证据”，比较的是**同一读者、同一原文、不同查询/置换**的输出，另存模型、层、源位置、干预与对照。节点层的删除、量表场的共同约束、模型内部的激活替换是三条相关的证据链，不是同一种运行结果。[机制论文](paper/GRAIN_MECHANISM_SUPPLEMENT_ZH_V1.md) · [双视角详细输出](GRAIN_EVENT_AND_VIEW_INCREMENT_ZH.md)。

## 11. 制作自己的文本测量：以“前提改变后重订方案”为例

1. **写制作简报。** 对象是“在明确纠正后，本人按新信息重订方案的比例或条件差”，不是泛称“灵活性”。写清场景、观察窗口、目标人、机会的分母、何为支持与反证。若想问当次状态，就定义这一次或这一短窗的目标。
2. **保留两相材料。** 自由相保留此人选择谈哪些事件；固定相用同一开放提示让每人都有改方案的机会。安排多次独立机会，不把强迫作答的比例当作自发倾向。单次自由会话也能报告其中发生的行为。
3. **制作证据单位。** 一次有地址的纠正和一次本人回应是一项。对照同主题但没纠正、对方重订而本人未答、不同措辞但实际采用等例子。重复转述不算第二项；给独立编码者看来检验含义。
4. **冻结。** 在来源作者上选择切法、节点/查询、条件权重、缺失规则和误差模型；另用校准作者定阈值或参照。若使用 LLM 读者，保存模型版本、正反命题、提示和证据地址；校准后的量和原始判断分栏。可用 LLM 根据已有证据撰写解释，不得让它补造未出现的事件。
5. **冷计分。** 新作者只跑已冻结的步骤。和简单观察率、词频或读者直接判断在相同机会和截止条件下比较。若申请命名心理构念，再用独立观察、自陈或事先指定的外部效标验证；若只交付行为估计，则可保留操作名称。
6. **交付。** 交付参照、原始证据、每人的有效/缺失机会、估计误差、拒答原因与适用范围，并让另一个人只凭简报和冻结件对新文本重做。换场景先复用步骤，重新检查机会、读者与人群。[B1–B7 制作细则和实际字段](GRAIN_CONTEXTUAL_CONSTRUCTION_HANDBOOK_V1.md)；[有校准包时如何离线冷计分](GRAIN_F16_PUBLIC_CALIBRATED_BUNDLE_HANDBOOK_V1.md)。

## 12. 迁移到不同任务：不要沿用错误的样本单位

| 场景 | 可先做的分析 | 关键对照与交付 |
|---|---|---|
| Reddit、多作者随笔 | 论坛保留场所选择及条件内表达；随笔保留篇章位置 | 匹配话题、长度与作者曝光；单篇文章能描述篇内路径，不能凭它估计跨日稳定性。 |
| 心理访谈、互助对话的研究 | 标出叙述、求助、澄清、回应和再次提及 | 本人和搭档分开、保护原文；给研究者带事件地址的估计与其他解释，而非诊断或治疗建议。 |
| 推荐或材料检索 | 用来源群体的表征比较“在哪些情境下、以何种方式”与候选材料接近 | 保留主题相似基线；输出近邻及匹配理由，在新交互中单独检验是否有用。相似不是人际相性标签。 |
| X 市场总池与筛选池 | 决策单位是交易日/标的，先定义截止点、时区、两池筛选规则，再求同坐标的当日轨迹 | 筛选池若包含在总池，二者有重叠，不能当独立复现。先比水平、差、简单滞后，再比较共同历史多排除了什么。次日开盘相对当日收盘的方向是另一个外部结果。 |
| 不同语言、不同站点 | 固定抽样与机会定义；用各入口读同类锚定事件 | 对照同义改写、否定、引用、语域和未知词率。要作跨群体绝对比较，先证明坐标可对齐，不能直接搬用英语常模。 |

## 13. 报告、复核与故障处理

每次运行保留：工具提交、输入/参照摘要、计分对象和截止、单位/语言/分词器、独立划分、保留的切片范围、机会分母、分数与错误/未覆盖原因、用来解释的正反例。对外优先发聚合统计或虚构例，不发布私文、词表中的私有词或可回连身份的逐人参照。

| 看到的现象 | 先查哪里 | 接下来怎么做 |
|---|---|---|
| 新作者加入后旧人分数也变了 | 是否用了同批标准化的旧比较列 | 固定外部参照，单独给同一人重新计分。 |
| 路径全相同；换词没有反应 | 查节点分配、未知词、词典与分词；有词命中并不保证能区分意思 | 在入口做同义/异义替换，先展示哪一步开始相同。 |
| `factor_scores=null` | 来源中有无 A/B 配对作者、跨人变异、保留下的轴和目标条件 | 报原特征与覆盖；不要补零或拿另外一折的轴代替。 |
| 液态比原生好、与固定平滑相当 | 核对目标是顺序、平滑还是学习到的时间响应 | 保留简单平滑作交付，并说明复杂项没有增加哪类信息。 |
| 报告用了另一批人的条件均值或另一语种的同名轴 | 查参照摘要、坐标次序、权重和条件支持 | 重新校准，或分开报告，不默认为同一分数。 |
| 没有历史权重、原始语料或实际秒数 | 区分程序、冻结资产和原始记录三件事 | 走第 2 节重建新参考，或使用授权资产；缺少物理时钟只报告机会时间。 |

报告例：“在自由记录中，甲较常进入改道话题；在分配的改道任务里，有 5 次可见的本人回应，其中 3 次明确重订、1 次明确坚持、1 次未定。对这些机会，支持比例可在 3/5 到 4/5 之间。两处改写位置及一个反例见事件号。”这种写法给下游一条能检查的观察，而不是用一个特质名替代它。

## 从旧研究学会选工具：四个有出处的例子

**原生与分层切片。** 从早期条件化、分层发现到多切法，每一代继承的不是一套永远通用的因子名字，而是“先定义可比较的表达机会，再在多人资料里找结构”。历史登记中，第一人称使用率与指令表达属于文体候选；`novelty_play_v2` 后来被重新归入场所选择主导；负性情感词率 `tension_core_v2` 保留为片段词汇现象。这三者即便出现在同一作者报告，也应放在三个栏目。若用自己的语料制造一项“创新倾向”，首先要让同一题材提供多种不同反应机会，再检验新表现在旧题材偏好之外还留下什么。[原始条目、判读与修订理由](CONSTRUCT_REGISTRY.md)。

**V6–V8 的继承关系。** V6 把个人水准、条件斜率与会话内运动区分开；V7 给不同切法、视角、参照与误差以独立身份；V8 进一步区分个体向量 V、两者关系 R、总体结构 P。比如“甲和乙在谈改道时的表达很接近”是关系；“这一群体出现两种互补回应”是总体结果。要给丙一个个体分，需要丙自己的证据和冻结坐标，不能把群体聚类的编号贴给丙了事。复用已有签名数列时用 `liquid_axis_series`，必须保留轴次序、坐标版本并让应用期晚于校准期。复用已归档 V7 因子则用 `liquid_frozen_bank` 加原冻结资产；没有历史权重，重新建图就是另一套坐标。

**真实自由会话教会我们的两件事。** RealPersonaChat 的“理解度”是填表者报告自己是否听懂搭档，而“主动性”由填表者自评；把它们统称“他人评定的人格”会把对象写错。ESConv 的分析区分了反映感受和复述等策略，却没有得到同样的情绪缓解结果。因此若客户问“帮助者做了什么”和“求助者是否得到了缓解”，应做两张卡，前者用话轮和回应，后者用独立的状态结果。原证据的队列、切分和零结果见[实证出处](paper/GRAIN_LIQUID_RICCATI_EVIDENCE_PROVENANCE.md)。

**故事与非文本任务为何也出现。** 图画故事资料可以按句保留叙事弧，并以打乱句序作对照；隐性任务资料可以用试次的实际时间或次序分析响应。它们给“顺序是否携带额外信息”提供不同检验，却没有共同的人群、钟和量尺。需要的是复用操作，不是把两者合成一份人格常模。若只有已有数值，不要伪造文本再分词：任务路径看 `liquid_task_paths`，不规则间隔看 `liquid_event_time`，原单位有符号面板看 `liquid_axis_series`。
