## Boundaries

- No bridge/MEPS training, no lockbox, no old NEXT91/P1 queue, no auto commit/push.
- Reuse predecessor development material/caches. Do not inspect participant text
  through external APIs or give private material to the public-resource search.
- Local anchor wording is model-authored, not expert eTRS; an increased match
  count is availability, not improved precision or personality validity.
- Expert-review feedback remains a distinct input. Never promote a candidate
  merely because it raises correlation with a held-out personality score.
- Native reference examples precede interpreting our simplified adapters. Pin
  upstream revisions and retain unmodified source under ignored results.
- Bound dependency setup and encoding; preserve errors and resumable outputs.
  Full ctsem/Affective-NLI training is not automatically enabled by code availability.
