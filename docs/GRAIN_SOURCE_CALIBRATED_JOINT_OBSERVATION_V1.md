## 1. Position and co-location are different observation objects

For a qualified author's comment distribution P_u, retain:

\[
\mathcal O_u = \left(m^g_u,m^\psi_u,C^{g\psi}_u\right),\quad
C^{g\psi}_u=E_{P_u}[g\psi^T]-m^g_u(m^\psi_u)^T.
\]

g is the actual frozen four-lexical-coordinate interface, not all of GRAIN.
psi is the old E5 linear query-configuration proxy, not personality ground truth.
The covariance records which behavioral coordinates and query-active readings
co-occur in comments. It is descriptive, not an attention path, chronological
flow, human causal response operator B_u, or a newly named psychological factor.
Do not erase either mean because the covariance uses within-panel centering.

HM63 established finite same-summary witnesses: even preserving the complete
g covariance can leave psi observations different. HM64 adds a different piece:
correctly paired C profiles have weak but recurrent author structure across
technical panels. Neither result implies an exhaustive personality representation.

## 2. Source units remove coordinate arbitrariness, not context

For each held author fold, source means/covariances/RMS are fixed on other authors.
The same old query map is used for every source/held author under that reference.
The comparison metric is

\[
d_C^2(u,v)=\operatorname{tr}\left[
\Sigma_g^{-1}(C_u-C_v)\Sigma_\psi^{-1}(C_u-C_v)^T\right].
\]

For invertible A,B, transport C to ACB^T and the two reference covariances to
A Sigma_g A^T and B Sigma_psi B^T. Cyclic trace cancellation leaves d_C unchanged.
This is standard tensor/Mahalanobis geometry; numerical rotation checks do not
constitute a new uniqueness theorem or psychological invariance result.

Every fold has its own source units. Only comparisons within the same fold and
cohort are made; coordinates from different folds are not a universal norm.
Historical frozen factors/maps are inherited and some source research previously
used external labels. New reference fitting is author-disjoint, but this is not
a fully independent discovery/psychological validation pipeline.

## 4. The next missing mechanism

Repeatable C could reflect author-specific marginal behavioral variation under
one shared relationship, instead of a personal behavior-to-query relationship.
This is now a distinguishable mechanism question, not a fidelity problem.

One source-fixed common-link null can be written, when its source matrix is SPD,

\[
L_0=\left(E_{\rm source}V^g\right)^{-1}E_{\rm source}C,
\qquad C_u=V^g_uL_0+R_u,
\quad V^g_u=E[gg^T]-m^g_u(m^g_u)^T.
\]

This is a planned exact statistical decomposition, NOT an HM64 fitted result.
Check recurrence of the shared-link part and R using source-only units and the
same pairing controls. Preserve marginal shape, mean locations and all failures.
There is no reason to tune L0 to reconstruct a teacher more accurately: its job
is to distinguish two explanations of author recurrence. Even recurrent R would
remain a text relationship until linked to qualified behavior/psychological data.

Separately, HM63's omitted semantic coordinates versus higher dependence remains
open. This C comparison does not decide that issue, estimate real-time state, or
close new-text LLM-free scoring. Original 18/100/44 requirements remain open.
