# M04/M05同事件配对后续检验

2026-09-13。**结果后提出的新机制包**，不是原r1事前计划的一部分。
原r1完整结果保持冻结：NLI两边际通道秩2；GRAIN/查询增至秩3，但第三奇异值
很小，反演将措辞差异大幅放大。增加K有有限改善，并未解决联合矩的弱识别。

唯一新增操作：逐事件 `p(x)=q_worry(x) * q_reassurance(x)`，不是两个作者平均相乘。
不新增NLI/prefix、不拟合神经网络、不改旧K。不增加事件预算或筛种子。
这个操作继承二元联合矩/同事件交互的标准代数，目标是提供缺失观察而非调回归精度。

1. 仅32旧来源标定文本学习新通道单位及协方差；冻结后应用同一批留出记录。
2. 比较NLI+乘积3通道、完整GRAIN/query/NLI+乘积11通道。
3. 一个破坏配对对照：只把乘积的第二项在同作者/条件中循环平移一事件，
   其它10通道保持。两项边际与该人的文本不变，乘积不再表示同一次事件。
4. 同时算完美事件读者的样本均值参照：事件数32下，即使没有文本误读，
   个人条件参数仍有离散事件抽样误差，不误归因于向量模型失败。
5. 原r1原文、观测值、源标定、个人函数和所有失败输出保持不动；后续产物独立目录。

输出：所有三坐标的水平、条件有限差分、+.5未见条件；成对/非成对/完美事件
误差和相关；标定的秩/分辨投影；说明与K作用的区别，不能把两种协方差叫同一个量。
若乘积也失败，按结果结案，不增加更多交互或多项式阶数。
