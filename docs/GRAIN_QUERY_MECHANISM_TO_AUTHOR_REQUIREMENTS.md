## What is now constrained by experiments

Evidence transport, query content, contextualized entity anchors, query target,
answer coding and conditional response are distinct operations. P1M/N show much
less irrelevant influence with an explicit object query and its corresponding
anchor than with person foregrounding; these are different contextualized states,
not an isolated change to the same vector. The selected anchor remains incomplete.
P1K's coding/criterion failure and P1L's tiny-sample functional readout remain valid
within their own prompt families. Later controls narrow interpretation rather than
retroactively discard inconvenient results.

The mathematical objects are finite response operators, not personality axes:

    x -> evidence/role assignment -> n_target(x)
      -> R_(criterion,code,other_states)(n_target) -> native output.

P1N separates additive-state departure from downstream finite nonadditivity on a
fixed reference path. P1O is planned to separate geometric changes from functional
gain. Both require that the relevant representations already exist in the LLM;
neither constitutes an LLM-free personality inference system.

## Requirements before a real-author group comparison

1. Freeze observer identity: model, tokenizer, template, target binding, criterion,
   code, layer, execution shape and intervention/readout definition. Repeated
   numeric scores in one template do not imply code- or criterion-invariance.
2. Qualify material on independent synthetic settings: ownership, relevant versus
   irrelevant evidence, realistic opportunity/qualification, polarity/code and
   length/order controls. One social-initiation cue cannot represent all Big5/MBTI.
3. Define the grouping independently of the measured response. A pre-existing,
   frozen GRAIN reference geometry may supply neighborhoods; never use the same
   response/label to choose groups and then claim a shared mechanism was discovered.
4. Keep author, quoted speaker, assistant and contextual evidence separate. A
   username is a token target, not the latent identity of a real person. Source
   fragments and history must have a permitted, auditable role and provenance.
5. Compare response-profile similarity to group similarity on held authors. Match
   or stratify source/length/context; include unrelated queries, neighborhood-label
   permutation and name/template controls. Preserve complete declared units and
   do not make partial-source results the winner-selection gate.
6. Diagnose psychological meaning only after the functional object is stable.
   Existing scales or behavior can supply external association under a separately
   frozen source/bridge split. Group-level structure, author recognition and true
   personality validity are distinct endpoints, not interchangeable metrics.
7. A faithful causal subspace requires matched interchange predictions on new
   evidence, not just a probe's predictive r or activation cosine. Any alignment
   learning must declare its own train/held-material split and parameter budget.
