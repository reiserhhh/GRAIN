## Scientific Decision

HM34 located a genuine carrier but its source-only linear extension does not
generally transport. Cold P displacement energy87%-92% lies outside the
source span. This alone does not show which component affects the target.
Conditional H/B/Q interaction also acts. We must separate missing directional
support from state-dependent reading, rather than remove residual directions.

At fixed H/B/Q/layout let gamma(t)=P1+t(P0-P1). With alpha=d_H F:

    alpha(P0)-alpha(P1)
      = integral_0^1 (d_P alpha)(gamma(t))[P0-P1] dt.

For each original physical H half-displacement delta_H, observe the scalar
mixed action

    m(t)=<d_P alpha[Delta_P],delta_H>.

It is obtainable with one forward, a create_graph first gradient, and one
second gradient per H direction. Keep parameters frozen; no neural training.
It is a local decoder reference, not a cold compiled predictor.
