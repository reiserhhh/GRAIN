# 查询的作用是一种联合几何，而不是边际强度

2026-09-11，NEXT72 / 第61轮。[实测报告](../reports/grain_vector_mechanisms/QUERY_PARTITION_GEOMETRY_REPORT_V1.md)。

## 1. 同一原文接上两系统的可计算对象

令固定源查询为Qbar，当前材料的key/value为K_i,V_i，GRAIN方向经过已有
运输后对key的作用为delta K_fi。固定下游读向量为g。每个注意力头定义

    l_i = Qbar^T K_i / sqrt(h) + mask_i
    v_i = g^T V_i
    d_fi = Qbar^T delta K_fi / sqrt(h)
    a_i = exp(l_i) / sum_allowed exp(l_j).

GRAIN定义沿哪个表达方向移动；查询规定用什么关系读取同一材料。
在本地key变化、Q/V/g固定的实验条件下，作用精确为

    R_qf = sum_heads [E_a(v*d_f) - E_a(v) E_a(d_f)].

这里没有生成解释性语言，但K/V/dK仍由神经表示提供。它实现的是这段
局部读取的数值接口，不将完整原文编码、人的人格和局部模型作用混同。

## 2. 一个共同势函数，两个不同导数层次

    Psi(s,t) = log mean_allowed exp(l_i + s*v_i + t*d_fi).
    grad Psi(0) = [E_a v, E_a d_f].
    Hessian Psi(0) = [[Var_a v, Cov_a(v,d_f)],
                     [Cov_a(v,d_f), Var_a d_f]].

这是标准有限指数族的对数配分函数恒等式，参见
[Wainwright & Jordan，§3.5.1，Proposition2，式3.41](https://www.cs.princeton.edu/courses/archive/fall11/cos597C/reading/WainwrightJordan2008.pdf)。
Hessian半正定；零方差时相关未定义，协方差仍可为零。我们的组合点是把
同材料GRAIN方向、冻结查询与value放进这个共同函数，实测重建先前作用。
不是把标准恒等式重新命名为原创人格定律。

## 3. 为什么两个边际分布不够

v取{-2,-1,1,2}且均匀，令d=v或d=-v。两种系统的v/d边际分布、均值、方差
完全相同，但协方差分别+2.5/-2.5。这个反例给出的是严格的信息要求：
**只有边际摘要的函数不能普遍识别联合响应的方向**。

真实新8中，交换源查询引子只让value的RMS SD改变约2%，而N与确认查询
作用差对原生目标的相关从+.939变成-.890。反例解释为什么边际相近与方向
反转可以共存；不声称仅凭这张真实表就唯一定位了所有内部原因。

    Cov_a(v,d)=rho_a(v,d) * sd_a(v) * sd_a(d).

此式是逐head/author/factor的恒等式，跨单元的平均数不能随意相乘。
真实own引子绝对对齐的加权比约.088/.070；之后head正负聚合保留.389/.319。
小的总作用可以出自低对齐和跨head抵消，并不等于输入里没有差异。
源4与新8的对齐不同，亦不能把这两个比当作固定的人格信号保留率。

## 4. 中心化的两种完全不同用途

GRAIN历史上反对用统计中心化删除作者的条件选择信息，此结论没有被推翻。
这里不是修改作者文本或剔除topic，而是在固定评分的softmax导数中保留
必要的乘积项B=E(v)E(d)。它可正可负；新8自身查询对比的U/B目标投影
为+.205872/-.068884，R=U-B反而增加到+.274756。

因此“去均值就是删除信号”和“去均值就是降噪”都不是普适结论。必须明确
在哪个对象上、为了哪个函数做操作。这里保留完整联合数据和原文地址。

## 5. 下一开发接口：选择测度与查询方向

现有Q同时控制a(Q)和d(Q)，交换引子会同时改变两者。可以构造

    R(Q_a,Q_d) = Cov_{a(Q_a)}(v, d(Q_d)).
    S_ab(t)=E_{softmax(l(Q_a)+t*d(Q_d))}[v].
    S_ab'(0)=R(Q_a,Q_d).

所有交叉项有同一有限标量路径定义，但非对角项不是把原模型的同一Q
完整替换后的常规导数，只是隔离两种作用的明确计算实验。
NEXT73检验对比反转由哪条关系产生，并将其定义为下一数值operator的
建模目标，不能事后按对新8有利的格子选最终模型。

这把用户的“从同一句话的两个侧面接合”推进为一条具体公式：表达方向的
可测差异，需要通过查询条件下的联合关系获得模型推论意义。心理辅助投映
解释仍需回到原文、关系情节和外部行为；协方差本身不等于潜意识构念。
