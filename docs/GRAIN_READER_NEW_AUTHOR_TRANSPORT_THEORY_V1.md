# 共同方向存在，不代表局部读法自动可迁移

2026-09-10，NEXT37。接续[共享/专用输入方向](GRAIN_QUERY_DIRECTION_TRANSFER_THEORY_V1.md)。
[数据与执行](../reports/grain_vector_mechanisms/READER_NEW_AUTHOR_TRANSPORT_REPORT_V1.md)。

## 1. 在同一token地址接合两个系统

令H_u为作者共同正文的块16状态，G_u为同一token经字符区间对齐得到的GRAIN
分数。D_uk是中心化后的逐位置乘积，按冻结相对RMS单位缩放：

\[
D_{uk}(t,:)=s_{uk}(G_{utk}-\bar G_{uk})(H_{ut:}-\bar H_u),\qquad
\tau_{uqk}=\langle J_{uq},D_{uk}\rangle_F.
\]

这里J_uq是完整查询条件下原生标量输出对正文状态的梯度。GRAIN给出
“哪一类表达差异”，J给出“该差异如何进入当前模型查询”。同一句文字上的
两个侧面因此有明确共同地址，不要求GRAIN轴等于某个人格词。

## 2. 四程序集成必须在共同物理坐标中平均

每个源折s有自己的输入预处理Phi_s、输出行基底V_s和系数W_s。

\[
\widehat J_{uq}=\frac1{4T_u}\sum_{s=1}^4\Phi_s(H_u)W_{qs}V_{qs}.
\]

输入同时传入G作布局/形状核对，但当前content-only系数函数不使用G列；G
参与D的定义。不能将“GRAIN方向上的模型响应读法”写成“系数已由GRAIN预测”。

对任意正交Q_s，V'_s=Q_sV_s、W'_s=W_sQ_s^T，场和最终作用不变。
直接平均不同V坐标里的系数通常不变性失败。此性质有新单元测试。

## 3. 新数据将方向存在与系数可读分开

源四基底联合空间的正交投影记P_V。精确写成

\[
J_{uq}=J_{uq}P_V+J_{uq}(I-P_V).
\]

新作者投影后作用r=.836/.951/.876，证明这些**已选源方向在这批新文本上
仍承载响应信息**。P_V使用源资产，投影系数却用了当前真实J；它是诊断，
不是已经提取出的无LLM程序。联合空间32维也不同于旧单折8维。

对固定预测器，令e_basis=J P_V-J，e_read=Jhat-J P_V。二者在全场中正交，
但经过D测量后通常不正交：

\[
\|\widehat\tau-\tau\|^2
=\|D:e_{basis}\|^2+\|D:e_{read}\|^2
+2\langle D:e_{basis},D:e_{read}\rangle.
\]

因此不能只问“保留多少场能量”。确认查询已出现大幅反向交叉项，降低一个
误差部分可能撤销已有抵消。下一步比较场、实际作用、幅度和符号，而不是
以最高r代替全部测量。

## 4. 系数可能依赖什么

当前a_hat(t)=f_source(H_t,position)是一个有界经验近似。原生J(t)实为完整
H、后续查询、注意力交互、输出状态的函数；同一局部token坐标并不充分描述
整段材料的条件。新作者单维坐标很少越界，却不代表联合分布/条件函数相同。

这里有三种待区分的解释，不能在看到迁移损失后直接宣布其中一个正确：

1. 原方向库有用，但4个作者不足以估计可迁移系数函数。
2. 局部输入缺少整段材料/查询状态的上下文，因此同一局部值需要不同读法。
3. 原生输出概率/候选编码改变梯度的幅度或方向，原回归把它们混在一起学了。

下一步先处理第三项的可直接计算部分，不追加以新8人为调参集的回归。

## 5. 将回答种子与后缀传输分层

对候选logits z、固定值v、p=softmax(z)、F=v^Tp，有

\[
b=\nabla_zF=p\odot(v-F\mathbf1),\quad
s=W_A^Tb,\quad J_H=(D_Hx_{final})^Ts.
\]

W_A是候选LM-head行，x_final为后缀最终归一化状态。分层精确来自链式法则；
并不说明s与H独立，也不把矩阵距离等同于人格关系。N/确认共用数字候选，
可能共享输出种子；query-specific后缀雅可比仍可能不同。

特别地，二分类T/F有J_H=p(1-p)grad_H(z_1-z_0)，只要p不饱和就可以用
当前缓存作**评价端**尺度分离。多候选期望没有一个通用标量能去掉全部b。
同一个已观测J和s也不能识别完整高维后缀雅可比，不能把伪逆解写成唯一机制。

这给出具体下一拼图：确定“共享是输出编码带来的多少、后缀如何把它运输到
正文”，然后研究上下文系数。不是从一轮失配直接跳到人格不可预测，也不是
再复制一个旧线性/非线性准确率网格。
