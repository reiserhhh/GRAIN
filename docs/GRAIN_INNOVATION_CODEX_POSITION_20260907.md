# Codex 独立立场：从坐标改为有条件的证据操作

2026-09-07；写于收到第二次研讨Claude第一轮正式答复之前。以下是候选机制和
有限数学见证，不是新的模型结果或真人发现。主比较、P1和旧缓存保持原定义。

## 最值得保留的三个对象

1. **条件诊断性，而非行为强度。** 同一行动在自由选择、任务要求、机会不足下
   对潜在特征的区分力可能完全不同。候选证据量为
   `L(e,c)=log[p(e|z_high,c)/p(e|z_low,c)]`。不要求LLM真正实现Bayes；它提供
   可被反例推翻的高层计算对象。将where从待删除成分改成证据算子的参数，连接
   旧MCD与新LLM查询。额外的群体先验可改变判断但不改变这个L，必须分开。
2. **带角色的查询响应张量。** 记录 `A[u,context,query,site,intervention]`，不
   强求一个全局人格向量。先从可控的主体互换、行为反转、查询释义中估计交互，
   再用内部patch检验哪一块负责哪种变化。输入因子交互本身不能定位神经机制。
3. **证据互补/协同。** 单片或单维与终点几乎无关联，不等于它是噪声。用配对
   线索有无的四格、真实donor替换和源头条件控制，测联合增量能否迁移到新内容。
   非线性最终读出也可制造交互；不能从一个二阶差值直接宣称组合推理。

局部向量场与可迁移响应算子是后续表示方式，不能仅因术语更复杂就优先；先需要
足够多的语义合格配对与独立文本分组。GRAIN若提供群体先验或材料选择，它有用但
不等于组织内部路径；要另外预测留出作者的干预响应，并对照condition-only邻域。

## P1B不能只是移动一个探针

- 原先最后问题token有强问法成分，但证据末token也可能只是句号/场地信息。
  前移的null不能立刻否定证据；应保留全证据span的donor恢复正控制。
- causal decoder后置问题不改变前缀隐藏状态。query-dependent指后续读取/更新
  操作，不是前缀随未来问题反向变化。
- 将“自己做什么”与“别人的行为归给谁”明确分隔。两个角色动作相反、词袋相同、
  名字及叙述顺序平衡。先测可明确回答的事件归属，再加入倾向归因。
- 不只使用Yes/No：增加无人格词的行为续写候选，观测干预是否保留证据高低间距。
  全体同向平移是控制效应，不自动是更好的区分或更强证据使用。
- 首包不要全交叉所有想法。先把定位、角色、输出语义三个环节拆出结果，再测条件
  诊断性/联合线索；每步保留失败和机会边界，而不是把所有null变成技术否决。

## 定向文献边界

本轮只核对摘要/论文记录，并非再次全文综述：

- [Feng & Steinhardt, 2024](https://arxiv.org/abs/2310.17191)：实体属性绑定
  已有内部干预先例；人格证据在角色和条件中的诊断性不等于已被该工作解决。
- [Geiger et al., 2025](https://www.jmlr.org/papers/v26/23-0058.html)：因果抽象
  为高层运算与内部干预的一致性提供基础；不能只凭可读性或函数拟合认定机制。
- [Bortoletto et al., 2025修订](https://arxiv.org/abs/2406.17513)：心理状态表征
  会对提示敏感，针对激活的修改可改变推断；不是Big5实证，也不是本模型已验证。

不能以这几篇文献证明我们首创或不首创。真正待做的是排除简单竞争模型后，在
指定证据/查询集合上找到可预测干预、可支持更新的小算子。

## 收到第一轮后，Codex补充：编码扰动的作用图

这不是Claude已经提出或同意的结论。将用户的“显影剂”具体化为有限差分系统
辨识：在同一模型坐标、规定证据span位置j，以共享随机方向delta_k写入正负
小剂量epsilon，对各个查询q记录

`A[u,q,j,k] = (s_q(h[u,j]+epsilon*delta_k)-s_q(h[u,j]-epsilon*delta_k))/(2*epsilon)`。

这里s是统一语义方向的候选log-likelihood差，j是明确的干预节点，不是自然
语言概念标签。小剂量平滑条件下A近似查询分数对这个节点的方向导数。若delta
独立、均值0、协方差I/d，则在线性情形

`E_delta[A_i*A_j] = gradient_i^T gradient_j / d`。

这提供固定观察器坐标中的功能相似度，不需要先找到一根可命名的轴，也不需要
第一步全量反向传播。它是标准随机投影/有限差分的应用，不宣称新数学定理。
模型非线性时须做剂量收敛检查；有限方向有抽样误差。一般可逆坐标变化下，若
不同时运输扰动分布，这个欧氏核不具有坐标无关性；只在冻结模型与计量中解释。

已计算的三维线性见证：三查询梯度为(1,2,0)、(1,2,0)、(-2,1,3)，用全部八个
Rademacher符号方向/根号3，响应核重建误差在浮点精度内；相同函数的响应完全
相同，前两查询与第三查询内积为0。这是构造例子，不是已找到真人相似群体。

新候选用途：先画“哪个问题对哪条证据敏感”，再用语义donor交换验证被高亮的
位置是否携带角色/条件相关作用，最后检验GRAIN独立文本邻域能否预测留出作者
的作用配置。随机扰动本身可能只是打亮通用计算，必须有无关问题、错配角色、
非目标证据与等范数对照，不能把每条非零通路都叫人格机制。全attention质量图
不是这一作用图，残差span干预也不等于已隔离某条query-key边。
