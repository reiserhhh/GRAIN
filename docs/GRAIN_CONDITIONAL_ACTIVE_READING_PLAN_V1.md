# HM37: Source-Only Conditional Active Reading Law

Status: planned after verified HM36, not executed. No new model calls, no

## One Scientific Decision

HM36 finds source-active carriers transferable to cold actions, while HM35
finds state-dependent reading. Can an explicit source-only reading law carry
the coefficients, rather than requiring the cold decoder's derivatives?
This is a finite conditional-transport question. It is not an absolute
personality-score model or a theorem that masks represent human conditions.

weighting is fixed before application and source wordings remain separately

Use the complete eight characters chi_S(c)=(-1)^(sum_{j in S}c_j). Store the

quadratic Lagrange rule; evaluation initially uses only those same nodes.

Freeze five predeclared reading laws for each query/arm:

1. global source mean, constant in c and t;
2. node-conditioned source mean, retaining t but marginalizing c;
3. fiber-conditioned source mean, retaining c but averaging t;
4. full c/t law, retaining every design character and every node;
5. the full law evaluated at c XOR(0,1,1), a fixed mismatched-fiber control.

Each law is a closed arithmetic source average/character transform, not a
trained neural model. Max30 source coefficient-law constructions (3queries
x2arms x5laws),0 new neural calls,300CPU seconds total including verification.

Freeze code/spec/source coefficients and hashes before reading numerical
application v or gradient targets. Cold action prediction is

    a_hat(c,t)=||deltaH_application||*a_source_law(c,t),
    prediction=<a_hat,U_V^T DeltaP_application>.

No actual cold v enters prediction. The known c/t address and upstream states
are supplied by this controlled experiment; this is not a natural-text

## Evaluation and Decomposition

Report all source/application node and half-integral actions, signs, raw RMS,
relative error and both quadrature rules for all five laws. Compare with the
frozen HM34 extension, the actual HM36 supported action and full HM35 action
without making different estimands compete as if identical predictions.

For each node and integral preserve the exact identity

    actual_full - predicted
      = actual_missing + (actual_supported - predicted).

The first term is carrier truncation; the second is reading-law transfer
error. Retain their covariance and any cancellation. Report covector-space
coefficient errors separately from scalar action errors: a small dot-product
error alone cannot prove a faithful reading law. Independent lexical-pair
replication remains a later scope, not fabricated by counting nodes.

Synthetic tests: all8character inversion, conditional-only/no-conditional
worlds, per-unit covector scaling, source isolation, fixed fiber permutation,

## Branch After Observation

Full conditioning better than its fixed marginal controls locates reusable
conditional reading, then extract which supplied c/t contrasts carry it.
If source carrier covers cold action but none of these laws transports,
the missing object is the law connecting upstream states to coefficients;
plan a specific finite state-response mechanism, not a regularization grid.
If scalar prediction is good but coefficient error remains large, preserve
that distinction and locate the action-relevant quotient rather than claim
complete covector reconstruction.
