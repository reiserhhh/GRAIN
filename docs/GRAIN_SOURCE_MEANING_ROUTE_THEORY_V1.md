This extends a declared GRAIN measuring interface; it is not a new theorem

## 1. Three objects must not be conflated

Let E_u be a qualified author event, C_theta(E_u) its frozen numeric memory,
and S_up an independently source-calibrated author-relative criterion field.
An observation contract specifies target description q, actual next text b,
serialization, comparison author, and computation graph O. Then

    T_uq(O) = Delta_context Delta_pole log p_theta(b|C_theta(E),q,O).

Memory change, output action T, and SOURCE meaning are different objects.
The same stored memory can be read in several ways; large ||T|| does not
imply a positive or transportable relation to S. Conversely, a negative
relation is not automatically noise to erase. Choice and within-condition
fields both belong to the measured SOURCE object.

The neural probability law is explicit but is NOT the human author language
law or posterior personality probability. Actual archived target text is
observed, not generated to please a persona judge. The encoder/reader remain
neural even though the exported signed numerical account is independently
executable without a neural runtime.

## 2. A meaning functional rather than a bigger norm

For a fixed source reference, define

    M_p[y] = (1/U) sum_u (S_up-meanS_p)(y_u-meany).

M is a linear functional on observations of these U authors. It is a
covariance-like SOURCE contact, not r, a psychological fraction, or a causal
effect of changing a person's personality. It can be negative, and its
units change if the SOURCE field or observation units are rescaled.

If an action has M_p[y]=0 for every supplied p, it is orthogonal to these
finite SOURCE directions, not necessarily devoid of author/personality
information. If M_p[y]!=0, the finite relation exists, but the source field's
definition and sampling opportunity still determine its interpretation.
These are elementary linear-functional statements, not new psychometric laws.

Unlike an output RMS, M lets a mechanism experiment ask whether a route
changes a SPECIFIED relation to source meaning. All cross-target M_p[T_q]
are retained: a same-name diagonal is not the only useful connection.

## 3. Full autoregressive route support

The fixed prefix contains a generic header followed by the entire prior
comment. A later suffix contains the target description and chat closing.
At all decoder layers, r enables prefix-body access by suffix query rows
before the LAST suffix row. d enables prefix-body access by that last row
and every teacher-forced continuation input row. The last suffix row predicts
the FIRST target token. Subsequent actual target embeddings/positions are
unchanged across all arms; their recursive processing is retained.

These two families are computational interfaces, not clean semantic units:
relay includes description and generic closing tokens; direct includes
recursive continuation effects. Intervening on the additive mask changes
attention normalization and downstream states, not merely a displayed
attention heatmap. No subset of heads/layers is selected for a stronger score.

O_rd changes only those prefix-body edges. Texts, query tokens, positions,
prefix cache, source fields and output-token covectors are identical. Thus
the comparison is not the earlier HM257/HM258 prompt-order comparison, nor
the old HM222 single digit description-discrimination task.

## 4. Signed source-meaning interaction

On the finite two-route support, at every actual token and target,

    T_rd = T00 + d*D + r*R + r*d*J,
    D=T01-T00; R=T10-T00; J=T11-T10-T01+T00.

By linearity of M,

    M_p[T11] = M_p[T00] + M_p[D] + M_p[R] + M_p[J].

This supplies a source-meaning account of computational interactions. If
M_p[J] is nonzero, adding two separately measured source-linked route
effects fails to recover the native SOURCE correspondence on this support.
It does not locate a unique multiplication neuron or imply a causal
psychological interaction. Conditional effects are D+J and R+J, not D/R.
No absolute values or equal splitting of J gives an information fraction.

Selected-token contraction and vocabulary competition also remain separate:

    T_q = sum_t W_bt^T Delta_context Delta_pole h_t
          - sum_t Delta_context Delta_pole log Z_t.

The actual output covector W_bt varies with each target token. A source
contact could change through h, through the denominator, or through both.
Discarding the denominator changes the observation contract, not its noise.

## 5. Opportunity is not erased by a content-blind reference

At equal context length and unchanged generic header, suffix and target,
O00 makes suffix/continuation states independent of source BODY identities.
Proof is causal-layer induction: all entries from the body are forbidden;
earlier header states cannot read future body, and row-local MLP/residual
updates cannot reintroduce missing input. This follows from architecture.

Own/foreign prefixes have different lengths. Position/opportunity effects
and properties of the actual target text can therefore remain in T00 and
its SOURCE contact. T00 is measured and kept, not assumed zero. Calling it
psychological noise would require an additional model not supplied here.
Same-length body-token-shift controls test only the declared architectural
invariance, not the absence of all condition confounds.

## 8. Construction decision rather than another instrument sweep

The local theoretical change is that a source-linked observation must carry
its JOINT computation contract. Its source calibration cannot be reconstructed
by separately favorable route contacts, nor promoted by maximizing action RMS.
This adds a complete-text source-meaning interface to HM222's existing route
interaction result; it does not discover general neural nonadditivity anew.

The next mainline object is a constructible measuring function with declared
event, reference, target, opportunity and joint-evidence support. Its proposed
rule must say which source relation it preserves on a new evidence use and
how it differs from ordinary language-context prediction. A finite contact
matrix alone does not identify that function: components orthogonal to the
supplied SOURCE fields remain uncharacterized. No unique psychological circuit
or LLM-free text encoder follows from the current account.

Do not automatically add heads, layers, route cuts, prompts, floating-point
precision or predictor grids. First inventory existing source-supported
construction/transport interfaces. Any next experiment must discriminate
competing explanations and enable a NEW measurement construction, rather than
re-report nonadditivity or select the largest positive contact. Choice, state,
relational and dynamic information remain part of the full objective.
