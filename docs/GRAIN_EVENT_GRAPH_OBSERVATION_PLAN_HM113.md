# HM113: qualified event relations, packaging and author identification

2026-10-10. Bounded CPU construction, not a new precision search. The original
18 protocols /100 cards /44 computational questions remain open.

## Inventory and new scientific decision

M02 already versions, corrects and deduplicates event reports; M04 already binds
propositions and responses. `math_evidence.replay_qualified` retains unknown
conditions rather than inventing zeros. `math_event_relation_renaming` already
preserves event equality under code renaming. HM62/HM78 already give sharp
finite moment bounds. HM102 separates local readings from author aggregation.
HM112 supplies an actual compiled joint observer. None of these generic facts
is this packet's novelty claim.

New operation: apply the HM112 observer to supplied qualified episode edges,
not report batches. Measure how much arbitrary loss of those edges can change
the author observation, and what relation information closes that ambiguity.
This decides whether to collect joint episode relations or refine unary scores.
It does not infer episode identity or psychological meaning from raw language.

## Fixed materials and protocol

Use only sealed HM112 compiled `layered` scores, with actual reference scores
as a separately reported numerical check. Both were already inspected. No new
full model calls or pretrained parameter loads. All six queries, two banks,
four triples, two laws and five packaging rules are retained without selection.

For each bank/triple, expand P+/minus=(1+/- .4*x1*x2*x3)/8 into40 episodes.
Each episode supplies all six declared slots (three other slots are neutral).
Atoms have supplied atom ID, actor, qualification, episode ID, condition, state
and slot. The two laws share the exact atomic-value/ID multiset, unary moments
and all value-pair moments; the episode assignment differs. Individual atom-pair
identities need not match: do NOT claim their actual pair-edge graphs coincide.
These are16 designed graph laws, not16 humans or640 new independent texts.

Five deliveries preserve the same graph: episode order, reverse order,
independently shuffled slot streams, arbitrary13-record packets, and duplicate
reports. A relation-aware scorer deduplicates exact atom reports, then joins on
supplied episode identity before invoking the fixed joint kernel. A comparator
keeps the same atom marginals/condition/qualification but zips slot encounter
orders without episode identity. It is explicitly an invalid coupling baseline,
not a recommended text model. Score all five versions, not only the worst.

An edge-erasure arm removes episode IDs. It returns unavailable direct joint
readouts plus identification sets, never a silently invented episode or0 score.
Unknown actor, other-actor episodes, conflicting aliases and incomplete episodes
are separate routing checks. This finite kernel needs complete six-slot units;
that restriction is not a general rule to discard partial natural evidence.
Keep the condition-specific readings and empirical condition choice. A fixed
1:3 versus3:1 two-bank construction verifies choice is not normalized away.
Current state is supplied/fixed, not estimated as emotion or trait dynamics.

## Identified sets and complementary observations

For the three active binary slots, let A have constant/unary/pair character
rows and b=(1,0,...,0). Rank(A)=7, and

    P = {p >= 0: A p=b} = {(1+t*x1*x2*x3)/8: -1<=t<=1}.
    I_q = [min_{p in P} p'K_q, max_{p in P} p'K_q].

Solve both finite LPs, save feasible extremal laws and dual witnesses, and check
the alternate explicit formula mean(K_q)+/-abs(mean(x1*x2*x3*K_q)).
This is an identification interval, NOT a sampling CI. Exact unary/pair inputs
do not shrink it with greater sample size. Adding the aggregate third relation
moment t=+/-.4 collapses it in THIS eight-cell support. One observation, one
event or one prompt does not identify a human personality.

Compare unary-only, unary+pair, and third-moment-completed observations for
all48 query/bank/triple cells. Use a third-character-removed kernel as a negative
control: pair constraints should then suffice. Do not tune a precision threshold,
select a query, or use the LP to fit a predictor. Existing HM78 bounds are not
rediscovered; this packet connects them to missing supplied event edges and the
new executable joint instrument.
