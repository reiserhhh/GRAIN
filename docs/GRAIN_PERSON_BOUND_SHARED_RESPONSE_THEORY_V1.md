## 1. Three objects that must not be identified with one another

An evidence ledger binds each comment event to a true writer and an observation
window. The reader experiment assigns display labels R/S to two complete comment
pairs. These experimental labels do not rewrite ledger identities. A SOURCE model
also supplies a reading of each pair relative to a fixed reference population.

1. Event identity:who actually wrote the comment.
2. Experimental incidence:which displayed actor the reader is asked to assess.
3. SOURCE criterion:what a declared reference model reads from the numerical pair.

A model may correctly follow displayed incidence while having no connection to the
SOURCE criterion. Conversely,a sample-wide criterion association may exist without
the reader attaching it to the intended person. The construction separates both.
Existing synthetic role-binding and natural author-comparison interfaces supply
machinery;their different observations cannot be stitched into a new causal proof.

## 2. SOURCE levels and model contrasts

For source writer i,pair x=(x1,x2),and a fixed kernel k,define author masses

\[
 A_i^F(x)=\frac1{m_i}\sum_b k(x_1,z_{ib1})k(x_2,z_{ib2}),\qquad

          \left(\frac1{m_i}\sum_b k(x_2,z_{ib2})\right).
\]

Normalize each law over the same permitted SOURCE authors,then average the two
declared pair orders. The kernel/projection/source support are historical and
unchanged. No reader outputs or evaluated-author labels enter these weights.

\[
 W_i^L(x)=\frac{A_i^L(x)}{\sum_a A_a^L(x)},\quad L\in\{F,J\},
 \qquad D_i(x)=W_i^F(x)-W_i^J(x).
\]

F is an observed-pair MODEL and J a within-author product MODEL. A difference
between their normalized readings is not an absolute author trait,an intervention
adding a comment,or a causal psychological interaction. Both levels and their
model contrast survive into every downstream contact.

For target q the old SOURCE conditional design fixes

\[
 m_{iq}=E_{\mathrm{SOURCE}}[Y_q\mid Y_{-q},\mathrm{bank}],\qquad
 e_{iq}=Y_{iq}-m_{iq}.
\]

Thus the total reading has composition and within-configuration components
\(W^L Y_q=W^L m_q+W^L e_q\). This is a decomposition of the SOURCE criterion,
not deletion of choice,context or state information from the text.

For writer u and fixed partner v(u),define relative LEVELS

\[

## 3. The complete observation cube

specify ownership labels,queried actor and display order. At fixed item and t,

Let \(\ell_{uj}(o,t,d)\) denote native log-odds for the complete behavioral item j.

\[
 \beta_{uj,S}=\frac18\sum_{o,t,d}
       \left(\prod_{r\in S}r\right)\ell_{uj}(o,t,d),\qquad
 \ell_{uj}(o,t,d)=\sum_{S\subseteq\{o,t,d\}}
       \beta_{uj,S}\prod_{r\in S}r.

character o*t;mask7 retains display-dependent person binding. Mask0 is the common

\[
 \ell(o,t,d)=\frac{r_u+r_v}{2}+ot\frac{r_u-r_v}{2},\qquad
