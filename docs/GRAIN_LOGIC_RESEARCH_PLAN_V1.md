## 3. LOG01 数学与统计协议

对平衡的 n×3 观察，采用有限经验概率（所有协方差 ddof=0）：

\[
C_T=\operatorname{Cov}_{u,v}(G_{uv},f_{uv})
=\underbrace{\operatorname{Cov}_u(\bar G_u,\bar f_u)}_{C_B}
+\underbrace{E_u\operatorname{Cov}_v(G_{uv},f_{uv})}_{C_W}.
\]

作者标准化偏移、相邻差分不是同一统计对象。分别报告 r_B、r_W、r_delta。
r_delta 复用旧实验的共同转移位置中心化定义；不将三者平均。
同理分别报告 r(平均 G,Y)、r(平均 f,Y)。由于 Y_u 不随视图变化，
Cov(G-平均G,Y) 在此数据上恒为0；不能据此宣布动态没有人格信息。

作者 bootstrap 1999；作者标签/轨迹整体 permutation 3999；随机种子20260910。
每类关联独立构成306格 BH 家族。置信区间按重采样重新计算中心，不当作独立
新样本验证。尺度共变可有正负抵消；贡献率不是人格成分比例。

LOG02 首轮仅使用12个冻结坐标：8个固定随机正交旋转 + 1个预定可逆缩放。
坐标变换是代数比较而非新增样本；不以这些结果选择因子数或推论坐标因果性。

## 5. 后续主动寻找的逻辑连接

1. **同级机制三角**：同统计量的 GRAIN、f/F、Y，在相同作者/材料上是否同向；
   优先解决 level/dispersion 的跨级混淆，然后再决定是否原生干预。
2. **语义与行为通道**：自评、对话行为、未来行为是不同响应；现有数据能描述
   哪些桥，缺哪些观测，不再用模型复杂度填补未观测通道。
3. **共同坐标对象**：发现支持共享作用的子空间后，再研究源拟合方向的搬运，
   不要求每一轴在任意旋转后仍有同名解释。
4. **构造链与执行链**：B0/B4/f 的真实依赖逐项登记；“省去生成”与“省去全部
   神经网络”分开，继续研究有用投影而不是先重构整模型。
5. **反馈与选择**：where 的选择携带 who，LLM 对话又会改变可表达机会；
   后续优先用已有角色顺序/固定条件材料研究可见的反馈，不偷换成人脑机制。

每个问题完成后由结果决定下一卡。需要新增人类观测的项保留 pending，
可以用真实缓存/有针对性的模拟解决的项继续执行。此 goal 不宣称逻辑宇宙可穷尽。

## 6. LOG01 后的第二轮卡（分析前追加）

LOG01/02 已产生完整数值缓存；不改变其计划、样本或重采样数。理论协作者建议
用既有正负向量干预的偶项寻找非线性。主 agent 发现另一条需要先接好的逻辑：
**概率输出的 sigmoid 本身就能产生偶项和作者间响应幅度差异**，这不一定是
新的内部非线性门控。

LOG05 因而固定为无新模型调用的匹配终点审查：现有12作者、real/null两个
方向，同时计算 probability 与 log-odds 的奇项、偶项、共同响应和异质响应。
保留未裁剪 (0,1) 检查。只作12作者既有干预的描述，不做效标训练或猜测个人特质。
对照一个已知恒定 logit 平移的有限例子，判断哪类表象无需内部非线性即可产生。
输出 `native_endpoint_accounting.csv`、合成反例与残差保留的作用公式。

LOG04 同时加入 source-fit D 与真实 Jacobian 不是一回事的有限反例。
若 H 不能由 G 唯一决定，不允许直接写无余项的 G 空间积分。保留两个作用
通道才能继续发现现有因子没有覆盖但会被查询读取的部分。

第二轮解释复核又追加第五个有限例子：完全共同的单位干预响应与完美的
作者间测量轴可以同时成立。共享梯度不是失败，也不是效度证明。后续比较
共享算子下的不同作者位置/自然行程，再判断是否需要个体化算子。
