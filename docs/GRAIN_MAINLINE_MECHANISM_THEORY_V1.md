# GRAIN：真实文本到人格判断的向量响应理论 V1

日期：2026-09-08。这是 D1–D4 主线机制研究的整合档案，不替代 GRAIN 已发布的
确定性计分方法。D1–D4 和 D3B 全部完成；本轮有限机制研究目标闭环。

## 1. 本轮回答的问题

用户的核心猜想是：LLM 从一个人的多段文本推断人格时，证据与判断之间存在
可追踪的向量关系；不必先把模型的全部运算翻译成自然语言，才能研究这种关系。

本轮把这个猜想落为三个可直接观察的对象：

1. **判断对象**：真实作者文本上的固定人格查询分数，与已有量表标签发生关联。
2. **干预对象**：改变文本证据或一个中间向量，观察同一个判断怎样改变。
3. **数学对象**：从中间向量的位移近似预测这种改变，并用未参与拟合的作者检验。

由此得到的主张是局部、可计算的机制：**查询组织证据；上下文化向量传递一部分
证据效应；共享的低维响应公式能够预测新作者上的部分判断变化。** GRAIN 的
群体参照坐标补充说明哪些人在哪类响应上接近，而不是先假设存在一条通用人格轴。

## 2. 从输入到输出

```text
同一作者的多条真实评论 x
    -> 固定 trait 查询 q + 固定输入模板
    -> 冻结 Qwen 的上下文化状态 H(x,q)
    -> block16 最后查询位置 h (1536维)
    -> 后续网络 + 最终词表读出
    -> 固定候选答案上的连续判断 s

并行观察：评论的冻结 E5 向量 -> trait 两极描述 -> 选择4条相关评论
并行参照：作者的冻结 GRAIN 坐标 z -> 比较群体邻域与具体响应类型

机制实验：改变评论 -> 得到 d = h_changed - h_original
    -> 在原输入中只注入 alpha*d -> 观测判断变化 M(alpha)
    -> 训练作者拟合8维响应公式 -> 预测新作者的干预变化
```

D2 材料是 40 位 MBTI-only 作者与 24 位 Big5-only 作者，各两组 12 条评论。
这些人与 D1 作者和冻结参照总体分开。实验使用既有 cue-mask 文本，不读取该批
作者的心理量表标签。GRAIN 群体通道是冻结的 48 维 whitened profile 及 16 个
参照点距离；它代表这里使用的一条 GRAIN 几何通道，不等于全部历史版本的功能。

T/F 输出是候选 F 相对于 T 的条件概率。神经质输出是 0–9 候选数字的期望除以9。
所有机制 r 都是这些分数或其变化之间的相关，不与量表预测 r 混写。
对应 cue-mask 条件下，D1 的 TF 标签 AUC=.6591、N 标签 r=.1765，表明本轮
追踪的输入条件仍连接到原有真实人格指标；它与原始文本的结果分别记录。

## 3. 公式链与每一环的地位

### 3.1 查询引导的证据坐标：操作性定义

对评论向量 e(x_k) 和查询两极描述 a_q^+, a_q^-：

\[
v_q=\frac{e(a_q^+)}{\|e(a_q^+)\|}-\frac{e(a_q^-)}{\|e(a_q^-)\|},\qquad
r_{qk}=\left\langle\frac{e(x_k)}{\|e(x_k)\|},v_q\right\rangle.
\]

选取 |r| 最大的4条，保留正、负两种倾向的证据。这是实用的查询坐标，不要求
人格信息天然只存在于两个人格词之间。对照是另外4条、尽量匹配总 token 数的评论。

### 3.2 最终评分：固定候选集上的精确读出

记最终归一化隐状态为 v，候选词表行为 w_c，logit 为
\(\ell_c=w_c^Tv+b_c\)。在固定候选集 A_q 内：

\[
p_c=\frac{\exp\ell_c}{\sum_{j\in A_q}\exp\ell_j},\qquad
s=\sum_{c\in A_q}a_c p_c.
\]

T/F 的 a=(0,1)，故 s 是 sigmoid(ell_F-ell_T)；神经质的 a_c=c/9。
其精确梯度为：

\[
\nabla_v s=\sum_{c\in A_q}p_c(a_c-s)w_c.
\]

因此“离人格词近”不是输出规则的完整表达。查询、上下文先改变 v，再由答案
读出方向与条件概率归一化产生分数。候选概率不是校准过的真人患病或人格概率。
代码对应 `grain_research/vector_mechanisms/direct_traits.py`。

### 3.3 中间向量的作用：可执行干预与精确分解

记完整模型为 F_q，原输入的 block16 查询末端向量为 h，证据变换 E_j 产生
d=H_q(E_jx)-H_q(x)。g_iq 是保留原输入和其余状态、仅允许替换这个站点的后续计算。

\[
M_{iqj}(\alpha)=g_{iq}(h+\alpha d)-g_{iq}(h),\qquad
\Delta s_{iqj}=M_{iqj}(1)+R_{iqj}.
\]

其中 \(R_{iqj}=F_q(E_jx)-g_{iq}(h+d)\)。这条分解是精确的加减恒等式，
R 含其他路径、上下文差异及交互，不被定义成应删除的噪声。M 是本次替换规则
测出的功能效应，也不等于独立心理成分的百分比。

在这条路径可微时：

\[
M(\alpha)=\int_0^\alpha\nabla g(h+\lambda d)^Td\,d\lambda.
\]

这用“位移 × 响应场”替代“一个位置直接等于某人格”的假设。模型可以在不同
作者与查询上用不同增益解释相似位移。向量路径是可测对象，心理意义需依靠
查询功能和外部标签连接解释。

### 3.4 紧凑响应公式：由新作者检验的近似

从开发作者的 d 得到正交 SVD 基 U，拟合：

\[
\widehat M=\alpha b_q^T U_q^T d.
\]

8维是本轮响应近似的坐标数，不是八个新的人格构念。D4 的两个固定候选为
rank2/rank8；后续 D3B 对训练投影做 RMS 尺度化，仍可吸收到 b 中，保留零位移
对应零响应。得到向量后计算该式无需继续调用后续 LLM，但本实验的 h、d 仍由
冻结 LLM 提取，不能把整条处理链描述成已摆脱 LLM 的编码器。

在 Hessian 范数上界为 L 时，误差可以拆成三种具体来源：

\[
|M-\widehat M|\le
\alpha\|(I-UU^T)\nabla g(h)\|\|(I-UU^T)d\|
+\alpha\|U^T\nabla g(h)-b_q\|\|U^Td\|
+\tfrac12L\alpha^2\|d\|^2.
\]

依次是遗漏方向、作者/语境增益差、曲率。这是条件性的数学界，不把实测误差
人为分摊为三个非负“人格信息比例”。两剂量只测有限曲率对比 M(1)-2M(.5)，
没有据此估计全路径的 L。详见 `GRAIN_QUERY_PATH_MATHEMATICS_V1.md`。

### 3.5 群体连接：响应特定的邻域与候选增益

令 z_i 为独立 GRAIN 分数，R_i 为多种证据/向量干预响应。D3 检验邻居是否在
同一类响应上相近；D3B 进一步检验：

\[
\widehat M=[b_q+W_q\phi(z_i)]^TU_q^T(\alpha d).
\]

phi 是训练作者内拟合的4维 GRAIN 投影，W 是双线性增益项。不是把 z 相近
预先等同于所有心理反应相同，而是让实测响应决定群体参照在哪一环有用。

## 4. 已完成的证据链

| 环节 | 结果 | 对理论的贡献 |
|---|---|---|
| D1 真实人格标签连接 | 原始文本：213人 Big5 native mean r=.1993；2328人 TF AUC=.6600 | 建立确实有标签关联、值得追踪的判断对象 |
| D1 与向量头的联系 | TF native/E5 score r=.5127；N native r=.2244 vs E5 .0417 | 既有共同部分，也有查询读出与聚合读出的不同部分 |
| D2 查询证据组织 | 4条选中文本与12条完整文本的作者均分 r：TF .6104，N .8193 | 短证据集能保留相当部分作者排序 |
| D2 定向向量作用 | 选中文本移除产生的自然变化与 block16 替换变化 r：TF .3108，N .4592 | 找到真实文本到判断之间一条有功能效应的向量路径 |
| D2 有限曲率 | 两剂量偏离线性幅度约占 patch RMS 的6.5%–9.3% | 为局部线性近似提供实测根据 |
| D4 新作者响应预测 | rank8 r：TF .5314，N .5584；MSE较零响应下降26%/20% | 公式能跨作者预测已定义的向量干预响应 |
| D3 群体线索 | 特定响应的邻域预测 r：TF .4549，N .5838 | 群体连接可以按响应类型定位 |

完整报告保留了方向相反的条件：选中评论的绝对移除效应没有统一优于对照；
邻域对全部7项响应合并后的 MSE 也没有统一优势。相应设计结论是：保留
“查询导向组织”与“响应特定群体关系”，不采用“选中部分独占人格信息”或
“一个邻域包办全部反应”。这是公式结构的选择依据，不是重启防御支线的理由。

## 6. 与 GRAIN 既有理论的连接

- **who**：作者在固定群体参照中的位置；既体现在输入路径 d，也可能体现在响应增益。
- **what**：多段评论提供的具体证据；查询先组织证据，而不是只平均全体向量。
- **where**：条件、主题、角色和机会结构保留在上下文及其他路径 R 中；不先整块删除。
- **when**：本轮 alpha 是人为干预剂量，不是心理时间；真实时间动力学继承旧版本，
  不用本轮两点干预曲线冒充人格变化或临床恢复过程。

旧版本的作者分布、条件分层、静态/动态结构与残差研究仍是参照层。本轮新增
的是从分布几何进入**查询相关的功能响应**：知道两个人距离近还不够，还要明确
对哪个查询、哪种证据变化、哪一个读出而言接近。

P1H/P1I 的合成结果曾显示查询内容和主体归属会影响内部作用位置。这为寻找
上下文化的查询路径提供工具依据；D1–D4 则把研究对象带回真实作者。保留两者
的材料层级，不把合成角色事实等同于真人量表标签。
