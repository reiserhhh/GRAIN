## 2. Absolute fidelity is not the author-comparison estimand

Let phi_q be a declared observable with events, ownership, condition and unit
rules; P_u is an author's evidence distribution, not the reader or personal
response operator. Let tilde-phi_q be a mathematical substitute and r_q its error.

    Theta_u,q = integral phi_q(t) dP_u(t)
    relative error(u,v,q) = integral r_q(t) d(P_u-P_v)(t)

Because (P_u-P_v)(1)=0, a constant error cancels. Consequently:

    r_q(t)=constant+epsilon_q(t)
    relative error = integral epsilon_q(t) d(P_u-P_v)(t)

This identity holds for errors of the FINAL observable, even when the underlying
reader is nonlinear. HM77 tests phi=the query hidden-state vector only; it does
not evaluate final nonlinear trait scores or natural human personality accuracy.
For a fixed linear readout ell, ell can be applied to the tested vector contrast.
For a nonlinear reader, its own observable error must be measured, not inferred
from the vector RMSE. Do not exchange these two claims.

Shared TOOL ERROR can cancel; this is not permission to remove common text,
topics or situations. A conditional error c(condition) does not cancel when
authors choose conditions at different rates. Such choices remain part of P_u.

## 3. Measurement-relative seminorm and the older mathematical basis

For a declared set C of admissible author signed contrasts nu=P_u-P_v, define

    ||r_q||_C = sup_{nu in C} |integral r_q dnu|

(use a specified vector norm for a vector observable). This is a seminorm;
its null space consists of errors invisible to the DECLARED comparison family.
Constants always lie in it. More contrasts or additional objectives shrink the
null space. No declaration that an error is universally harmless is permitted.
For normalized scalar probabilities and bounded r:

    |integral r d(P-Q)| <= oscillation(r) * TV(P,Q)

where TV=sup_A|P(A)-Q(A)|. The bound follows by subtracting the midpoint of
sup/inf and using the signed measure's total mass norm 2TV. This is standard
measure duality, not a new psychological error-zero theorem.

Gretton et al. (2012), Section2.1, define integral probability metrics by
expectation contrasts across specified function classes. That is a primary
mathematical precedent for making the observable/comparison class explicit:
https://jmlr.org/papers/volume13/gretton12a/gretton12a.pdf
Our seminorm fixes an error function and varies author contrasts; it is not
automatically MMD, no RKHS metric/characteristicness theorem is assumed, and
no MMD test has been run in HM77. We read Section2.1, not all51 pages.
