# M03/M04/M10：选择、共同条件响应与来源学习观察设计

2026-09-13。执行前机制规格；继承现有NLI及条件证据包，不再调短句分类器。
本包交付有限条件下的计分/制作规则，不把合成参数称为真人心理量表。

## 问题与方法

1. 两层选择树：根与两个条件尾部各有个人偏好gamma。已知可用机会时，
   `logit P(choice+) = opportunity_log_odds + gamma`；未知时只能测观察选择。
   自由48次、固定48次、自由24+固定24次，三者等总事件预算。
2. 同一人的两条件反应期望为 `a+b*z`。输出共同参照水平a和两条件对比b，
   而不是把斜率当清洗后人格；数式中的a不是未观测中间情境的实测值。
   比较自由/固定/两相，以及两相中合并全部反应或仅用固定相。
3. 世界：选择和响应独立、共享、机会混杂、当次状态影响选择与响应。
   最后一个是选择可忽略假设的反例，不期待所有世界同一种程序最优。
4. 从来源作者的固定条件事件读数估计两条件均值、作者协方差与事件方差。
   由目标方差下降选择下一条独立观察，不读取新作者真参数或未来结果。
   比较来源学习、已知分布moment oracle、覆盖均衡、随机、重复报告策略。
   目标分别是共同水平、条件对比、指定条件响应；固定16条报告预算。
5. 条件矩阵来自实验安排；事件读数来自上一包固定文本/NLI缓存。
   来源参数只用source措辞生成的来源作者估计。验证新作者，另报新措辞与
   作者响应分布变化。源语义校准/条件读取不重训；MEPS、真人量表完全不读。

## 数学来源与新增接点

- 选择似然与响应似然分账；状态同时影响选择和结果时，简单条件回归不再给出
  被分配条件下的反应。继承[Rubin,1976](https://doi.org/10.1093/biomet/63.3.581)
  的可忽略性原则；这里是局部选择模型的推导，不宣称重现该论文实验。
- 来源事件内方差校正样本均值的测量误差，再做线性最小均方预测。
  设计采用[Chaloner与Verdinelli,1995](https://www.stat.cmu.edu/tr/tr599/tr599.html)
  的目标/效用导向思想；Gaussian工作公式也可按二阶矩线性预测理解，
  不是把二值事件假定为真实高斯人格。
- 本包发展点：用文本事件读数估计设计所需量，显式保存选择、响应、借力、
  未知机会及重复证据，而不是仅演示已知生成参数的最优设计。

## 冻结范围与验收

配置 `configs/grain_choice_design.json` 固定5seed、每世界128新作者；
每seed/查询256来源作者、每条件16独立事件；不续扫预算或先验。
词句仅是既有128条有限材料的重组，模拟作者数不增加语言样本量。
采集前记录本包代码/配置/银行hash，运行失败可修软件但记录版本，不改成功标准。

输出：逐作者参数与事件抽样地址、来源moment、设计分配、逐seed及汇总指标、
配对模拟作者bootstrap、精确反例和制作决策表。分别报告模拟潜在参数和固定读者
所定义的条件期望；置信度是工作模型/固定语言银行内的，不是总体人格区间。
所有世界保留，反例同样验收。不承诺两相设计每一分数都最精确；
它的价值是同时识别自由选择与分配条件响应，固定预算必有取舍。

范围外：开放文本自动发现可选机会、真实未记录事件补全、任意多层偏好树、
所有任务的个体动态模型、独立心理含义与量表效度。
