## Two sampling levels and source target law

Author u contributes a distribution P_u over eight observed cells a=(c,s).
The condition c is the frozen TOP20-venue bit; s has the unchanged coordinate0/5
source-cut bits. Each of two windows contains17 distinct current events. Events
are not independent questionnaires; the source observation is author-balanced.
Existing Big5-only OOF author identities and outcomes exactly match the624
material authors. Source403 calibrates; validation101/held120 never calibrate.

For each trait q, let Y_uq be the binary above-SOURCE-median label and U the
number of source authors. Define the finite joint observation law:

    R(a) = mean_u P_u(a)
    pi_q = mean_u Y_uq
    J_q(a) = mean_u P_u(a)Y_uq
    psi_q(a) = J_q(a)/R(a)
    rho1_q(a) = J_q(a)/pi_q
    rho0_q(a) = [R(a)-J_q(a)]/[1-pi_q]
    w_q(a) = psi_q(a)-pi_q
           = pi_q(1-pi_q)[rho1_q(a)-rho0_q(a)]/R(a).

This standard density-contrast identity explains how external source outcome
meaning enters an anonymous vector observation rule. The reference has positive
support in all8 cells. Missing support is unobserved, never silently zero.

The empirical author measurement is:

    theta_uq = sum_a [P_u(a)-R(a)]psi_q(a)
             = sum_a P_u(a)w_q(a).

It has source event-law probability-difference units. It is NOT the posterior
probability that an author has a high trait after all comments, a percentile,
a clinical score or the author's response to a causal intervention. No
independence product of repeated author labels is used.

## Source positivity is constructed, not validation

Taking the source conditional author means gives the exact standard identity:

    E_source[theta_q|Y_q=1]-E_source[theta_q|Y_q=0]
      = pi_q(1-pi_q) sum_a [rho1_q(a)-rho0_q(a)]^2/R(a) >= 0.

The same identity holds when source profiles are permuted and used to calibrate
a new reader. Thus a positive source binary-group gap is BUILT INTO this
estimator. It cannot be reported as independent psychological evidence.
Raw continuous-label correlations are different statistics; their sign is not
fixed by this binary identity. Held-author/validation associations and source
half-direction agreement provide additional empirical observations.

Actual five-target source gaps are .010425/.002343/.007948/.002386/.009880;
the fixed permuted-source gaps are also all positive. A separately labeled
post-outcome direct-count check agrees with the identity to6.1e-17. This is a
measurement interpretation correction, not a new theorem or a new fit.

## Components, shared fields and reproducibility

Using source conditional mu_q(c)=sum_s R(s|c)psi_q(c,s), retain:

    choice_uq = sum_c [P_u(c)-R(c)]mu_q(c)
    within_uq = sum_cs P_u(c,s)[psi_q(c,s)-mu_q(c)]
    theta_uq = choice_uq + within_uq.

Within is conditional composition, not a nuisance-free innate trait. Choice
does not become noise merely because it overlaps venue context. Signed
covariances with the target add; correlations and standard deviations do not.

The weighted target Gram describes overlap of the source reader fields, not
