# HM96: same-text GRAIN observation and directed target action

Frozen before scoring, 2026-10-10 JST. Original scope remains OPEN.

## Scientific decision

Does the *actual inherited lexical GRAIN instrument* retain the directed
differences already visible in the frozen HM93 target-vector kernel? This is
not another same-text concatenation, teacher fit, or personality prediction.
M04/HM81 already implemented joint scores; HM66 examined cached score fibers.
Here the raw-to-observation pipeline, exchange symmetry, and author integration
are tested together, without fitting a map from GRAIN to target scores.

Competing explanations:

1. Whole-text observation loses the exchange-odd information upstream. No
   downstream accuracy improvement on that observation can recover it.
2. Ordered observations retain it, but first-order differences cancel under
   matched closed author paths. A pair-dependent observation is required.
3. Even pair-dependent GRAIN observations fail on these materials. Preserve
   the negative result; do not tune windows, factor counts, or targets.

## Inputs and fixed instruments

All 288 public HM93 designed bodies, the sealed target kernel, and the 36
already frozen numerical author ledgers. Reuse is not a new replication.
The inherited SU7 whole bundle and TF-IDF/SVD runtime are frozen, label-free
at scoring. Their historical reference weights remain local; this is not
the entire current GRAIN framework or a neural embedding comparison.
No private source text, questionnaires, API, model forwards, fitting, Git,
lockbox, or old queues. The target kernel still depends on the old Qwen
encoder, source query seeds and behavior-calibrated directions.

Input-only inspection: lexical body counts 42--60; four-slice support 152/288
(116 pair, 36 reset). Every event has 14--23 lexical tokens, above the inherited
minimum 12. The three existing newline-separated events are therefore a
fixed full-coverage alternative, not an outcome-selected cut.

## Fixed observations

- Whole body: sparse TF-IDF, 24 SVD values, four anonymous factor z-scores.
- Event boundary: score each of the three original event sentences with the
  SAME frozen instrument. Retain mean, current-minus-previous, and six signed
  triangular areas in the four-coordinate plane pairs.
- Historical four equal lexical slices: use the unchanged min-48 rule and
  original dynamic descriptors. Keep missing rows explicitly. Integrate an
  arm only for context/family groups with all nine pair cells supported.

Let X,Y,Z be the three event coordinates. Area is
`A_ab = ((X-Z)_a (Y-Z)_b - (X-Z)_b (Y-Z)_a)/2`.
It is a known polygon/signature-area construction, not a new theorem.
The exchange is previous/current action swapping in the fixed template, not
reversal of a real person's time series. Check actual raw-to-score symmetry;
do not assume the two event vectors exchange exactly.

## Tests and author application

For every one of 24 lexicon/frame/family groups, split each kernel into
exchange-even and exchange-odd components. Keep all six target directions
and all three target readout fields, without selecting a winning diagonal.
Use source HM93 actual ledgers, not labels, to integrate each supported
observer. Compare positive/negative ledger scores only in final evaluation.
Report exact cycle contrast, including zero and reversed results.

First-order edge difference `Y-X` telescopes on a closed path if the point
map is common across events. A nonzero odd component alone therefore does
not imply retention of divergence-free author circulation. Verify the point
map assumption and the actual cancellation numerically, rather than importing
a general claim about all text.

Whole TF-IDF equality is the strongest obstruction: if two bodies have the
same input feature vector but different target action, no function of that
feature vector can distinguish them on this finite support. Approximate
factor equality alone supports only a numerical obstruction, not an exact
impossibility theorem. Do not equate feature/target scales or report accuracy.
