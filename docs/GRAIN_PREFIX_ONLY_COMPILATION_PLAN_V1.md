# HM11: Source-Compiled Reading of Query-Independent Prefix States

2026-10-08. Next finite mechanism follow-up, not executed or independently
replicated. HM10B3 primary stays frozen. This plan reuses its existing numeric
captures after local action verification; it never opens private data or an
old experimental queue. The goal is to determine which part of a conditional
reader can be compiled into an explicit source-learned function.

## Decision Changed

Local causality and standalone reading are different questions. A fixed
source frame may carry owner action, yet the suffix map can still require
other states and nonlinear context. This packet asks whether query-independent
prefix coordinates support cold target-specific numeric reading, and whether
the coordinates preserve owner-dependent contrasts rather than only levels.
It is not another search for personality-prediction accuracy.

## Input and Role Boundary

- Use the 224 HM10B3 documents and its source/validation/application split
  (8/4/4 lexical families, 14 documents per family).
- Use only canonical body states and the frozen source frame at block output
  16. This was the original no-op anchor, not a best-layer selection.
- For each document and each captured A/T property/actor/neutral span, compute
  the token mean and project onto the frozen two-column U16. Twelve numbers
  result. Do not use question endpoints, logits or target answers as inputs.
- Absolute token positions may define which declared relation comes first.
  Never use material family IDs, truth polarity, supplied owner label or a
  receiver/donor relation as predictive inputs.
- Three output targets are the three already fixed native conditional digit
  observations. They are reader functions, not new human personality labels.
- Source-only means/scales are frozen. Application authors are never used to
  redefine reference coordinates or select hyperparameters.

## Four Fixed Arms

1. Source target mean as a non-discriminating reference.
2. Four property coordinates, linear readout.
3. All twelve span coordinates, linear readout: tests local role/context
   information omitted by property-only reading.
4. Four property coordinates plus the declared relation-order bit and their
   complete degree-two polynomial, with a target-specific numeric readout.
   This tests a conditional joint law, not a discovered intrinsic manifold.

Ridge alpha=1 is fixed for each fitted arm; one source-fitted model per output
law. No layer/rank/alpha/prompt grid or validation-selected winner. Standardize
nonconstant predictor columns with source statistics only, leaving a separate
intercept. All arms and coefficients remain in the report, including failures.

## Primary Readouts

- Cold family-level owner-by-polarity contrasts for both A/T relations and
  both orders, at every fixed target. Contrast mismatch matters even if mean
  level prediction is good.
- Level RMSE, signed mean bias and ordinal-score correlation as secondary
  observation-law diagnostics. They are not author psychological validity.
- Fixed-frame empirical family intervals, with uncertainty scope explicit.
  Do not pretend these refit the original source activation frame.
- Show the compiled coefficient/function units and the contribution of
  property, context and joint terms; don't name an anonymous coefficient as
  a trait or allocate a percentage of psychological information.

## Verification and Deliverables

Verify every consumed capture/hash and canonical query-prefix invariants.
Keep an output manifest and separate source/validation/application tables.
Test source-only preprocessing, exact coefficient replay, missing/constant

Deliver a new runner, focused tests, frozen source functions, cold outputs,

## Interpretation and Next Branch

- If linear property reading works: an explicit numeric prefix-to-target map
  can replace part of the original target-conditioned suffix on this domain.
- If the twelve-span or joint arm preserves extra action: the needed object
  is relational/conditional, not a single keyword or universal linear axis.
- If levels replay but owner contrasts fail: the compiled function mimics
  surface output without preserving the localized mechanism; report that
  difference and investigate distributed context, not more alpha values.
- If all compact arms fail: positive local intervention is still retained;
  preserve the signal and expand the observation unit only through a new
  finite scientific design.

Cached prefix states still come from the frozen transformer. This is suffix
compilation, not full transformer-free text scoring or psychological truth.
Fresh natural-material, event eligibility, author aggregation, dynamics and
the original full-scope requirements remain separate next stages.
