2026-10-09. This is a finite new-material mechanism experiment, not a predictor

## Competing explanations

Each account contains Person A and Person B, one high and one low behavioural
clause inherited verbatim from HM46. In the appraisal-present condition a separate
observer calls one person's action admirable and the other's objectionable.
Both words are always present. Independently swap behavioural ownership (b),
appraisal ownership (e), and the order of complete person records (o). Query each
person (r), using all six fixed targets. No-appraisal accounts are separate controls.

The system instruction is deliberately person-neutral: HM46/HM47's writer-only
instruction cannot legitimately be reused for a colleague query. This is a new
frozen protocol, not an outcome-guided prompt fix or a direct score replication.
Keep both behavioural clauses and all outside-appraisal information. No assertion
that an observer's appraisal has no psychological relevance.

Two behavioural example families x six contents x two b x three appraisals
(absent/A-positive/B-positive) x two o =144 accounts. Twelve person/target queries
per account give1728 fresh actual local forwards. First family:864 source scores,
sealed before second family's864 application scores. There is no parameter fit,
source-selected direction, human truth label or sampled-author significance test.

## Mathematical objects and decisions

For appraisal-present cells let Y[b,e,o,r] be the native digit expectation. All
sixteen signed characters of (C2)^4 are retained:

    beta_S = mean_g Y(g) product_{j in S} sign(g_j).

Use 2 beta_{b*r} for target-bound behavioural high-low contrast; 2 beta_{e*r}
for target-bound appraisal contrast; beta_{b*o} and beta_{e*o} for shared record-order
channels. All other interactions remain available, not relabeled noise. Absent
appraisal uses the complete three-bit b/o/r cube, not a padded fourth bit.

Simultaneous A/B renaming flips b,e,o,r. Its even/odd projection separates
rename-invariant from name-asymmetric response components. This is a standard
finite-group calculation on design labels, not an assumption that Transformer
hidden states carry a linear group action or an imported Specht-density theorem.
Names and order may change actual responses; report them rather than impose
invariance by altering the model or deleting observations.

Prepare must prove identical actual input token multisets within each fixed
family/content/query-person/query-target/appraisal-presence class. Each class
has4 absent or8 present scores. A token-bag-only function has one value per class.
Its best possible squared error on these observations is their within-class
variance. This result-after lower bound is not a trained cold predictor, human
error floor, or a claim that contextual embedding means cannot preserve binding.

Actual block16 property/end/query states are captured. The first action precedes
all appraisals: check its shared causal prefix and report its numerical change
without a microscopic floating-point stop gate. No hidden-state intervention is
in this packet: behavioural binding is not proof of a particular Binding ID circuit.

Decisions: a retained b*r channel establishes target-qualified reading beyond
the common token bag; e*r establishes person-bound external evaluation; e*o with
weak e*r points instead to shared order-dependent evaluation. Simultaneous
channels require a joint observation law. No universally tuned pass threshold.
Do not equate these reader channels with latent human traits or delete appraisal.
