    K1: Person A focal action
    K2: Person A companion action

and two action families. Keep the full action block exactly unchanged across

    focus_alias:
      Occasion K3 is the same event as occasion K1.
      Occasion K4 is a different event from occasion K2.

      Occasion K3 is a different event from occasion K1.
      Occasion K4 is the same event as occasion K2.

by actor, not global string coincidence. This is a binding/control comparison;

    K3 and K1 refer to separate events. K4 and K2 refer to one event.

Declarations follow the unchanged action block, preceded by the sentence:
"The following event identity statements apply only to Person A's occasions."

Narrative reversal is not a reversal of event time. The explicit event graph
