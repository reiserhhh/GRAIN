## 3. Operation-indexed coefficients

For an event set E, define its condition proportion p_E and
a_E=(1-2p_E)p_E(1-p_E). For i!=j the ordered-pair coefficient B_Eij is
1/[n_c(n_c-1)] inside condition c and -1/(n0*n1) across conditions; diagonal0.
U_E=sum B_Eij z_i z_j^T, M_E=delta_E delta_E^T, V_E=M_E-U_E. Then

    F_U(E)=a_E<W_q,U_E>=sum a_E B_Eij k_qij,
    k_qij=z_i^T W_q z_j.

The kernel W_q remains frozen. Deletion does NOT change the scorer parameters;
the SAME functional recomputes empirical coefficients for the remaining set.
This is not evidence that the LLM internally uses these B coefficients.

Let I=E\D and retain original event addresses. Exactly:

    F_U(I)-F_U(E)=choice_change+survivor_normalization+removed_pairs
    choice_change=sum_(i,j in I) Deltaa*(B_Iij+B_Eij)/2*k_qij
    survivor_normalization=sum_(i,j in I) (a_I+a_E)/2*(B_Iij-B_Eij)*k_qij
    removed_pairs=-sum_(i in D or j in D) a_E B_Eij*k_qij.

This follows from the finite midpoint product identity. It is not a new
theorem, Shapley allocation or a causal mediation decomposition of the LLM.
Balanced p can set a=0 even with nonzero U; those cases stay in the panel.
