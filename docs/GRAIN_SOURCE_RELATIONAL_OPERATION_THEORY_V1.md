# Source-qualified operation and contextual reading

HM51 finite result, 2026-10-09. This is an observation-operation construction,
not a human personality score or a newly proved universal binding mechanism.

Let C_j,r(x) be the complete query suffix state after the model has read x at
the fixed block16 cut. The unchanged decoder above the cut is D(B,C), where B
keeps every unpatched body/prefix state. Source ownership0-to1 changes are d_j,A
and d_j,B. Define d_j,+=(d_j,A+d_j,B)/2 and d_j,-=(d_j,A-d_j,B)/2.

The operation is C'=C+sigma*(d_j,+ + s_r*d_j,-), with sigma=1-2*direction,
s_A=+1, s_B=-1. This is target-specific, with exact relative suffix-token
matching for each actor. Cross-actor slots intentionally differ at one name.
No neural permutation-equivariance theorem is assumed.

On the known second behaviour example, full source action RMS .698999 versus
natural exchange .761301, wrong-person .096492 and random .036770. Full and
actor-oriented actions both have24/24 matching signs. Source-only transport
is useful, while separate shared action is small. No target refit, gradients,
layer search or output rescaling was used.

State additivity leaves output interaction:
I=D(B,C+d_+ + s_r*d_-)-D(B,C+d_+)-D(B,C+s_r*d_-)+D(B,C).
