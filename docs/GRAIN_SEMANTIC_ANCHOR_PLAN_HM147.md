## Fixed mathematical constructor

For slice v, learn mu_v and ONE scalar RMS norm s_v from all discovery vectors.
Define z_v=(g_v-mu_v)/s_v. This changes the reference origin and units; it does
not delete topic or condition variation, which remains in z. No per-task
centering, optimized bandwidth, regularization, axis orientation or model grid.

    Phi(z) = tensor_(v=1..4) (1,z_v), 625 coordinates.
    w_k = mean_source_high(Phi) - mean_source_low(Phi).
    f_k(z) = <w_k,Phi(z)> / ||w_k||.

Here k names the *generator prompt assignment* E or N, not a measured human
trait. Source high/low metadata anchor the sign; no application labels or model
scores construct w. Each source class contains 27 texts, balanced in task,
phrasing and seed. The finite polynomial kernel is NOT characteristic over
arbitrary distributions and f is NOT a probability/Bayes posterior.

All 16 constant/single/pair/triple/four-slice tensor sectors stay explicit.
Their signed cold contributions sum exactly to f. Higher-order sectors can
contain products of means, content and context; they are not automatically
irreducible synergy, dynamic motion or pure personality. No winning sector is
selected from application performance.
