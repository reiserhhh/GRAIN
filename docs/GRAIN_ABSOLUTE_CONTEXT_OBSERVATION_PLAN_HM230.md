## Competing mechanisms

1. Comparative wording/alphabet/readout, not background alone, accounts for
   the earlier target-geometry collapse: absolute other background need not
   reproduce it. Failure to reproduce does not uniquely identify those parts.
2. Adding/repeating context is sufficient: duplicate and other backgrounds both
   change geometry. Duplication also changes target-token positions/opportunity.
3. Other content has an additional effect beyond duplicate background: the
   other-minus-duplicate contrast changes target organization. This contrast
   still includes background length/content; it is NOT a pure semantic effect.
