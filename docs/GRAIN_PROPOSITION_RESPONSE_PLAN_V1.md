# M01/M09：具体命题绑定与条件回应 r1

本轮新增机制是将已学得的依存边变为可计分的具体命题/回答关系，不再增加抽象
证据身份NLI元描述。保留旧失败；冻结后不重写规则以适配结果。

## 输入到输出

原文话轮 → 固定Stanza UD解析 → 主语/控制/来源/模态/条件从句 → 具体目标事件 →
唯一前问与裸Yes/No的绑定 → 分身份/条件的个人表达函数。
不把回应的Yes字面意思当个人trait，不把报告过去行动当实际行为证据。
存在多命题、引语来源或否定问题时保留未解析；显式回复保留自己的命题及候选前文。

使用旧事件图，意愿等词典是声明的有限适配器，非完整事实性系统；新parser不
接收刺激身份/条件真值。条件保留自动抽取的原文字串，不把所有advcl解释为同类情境。
条件坐标以来源措辞的抽取片段TF-IDF均值学习；新措辞不拟合。未取到条件保持缺失。

## 有界实验

32公开对话：2条件（deadline/instructions）×2身份（意愿/过去报告）×2主体
（本人/同事）×2回应（Yes/No）×2措辞。8挑战为多问、负问、他人引语、显式修正、
请求与未观察前文，全部保留。既有hash选择12条PANDORA原句只重跑接口，禁用标签
拟合或声称自然语义准确率；不读MEPS、不外发任何私人文本。

三层：正确条件/身份的设计参照；原文解析及来源学习条件；仅内容NLI相近程度。
内容参照为一个固定查询，不根据本轮结果更改。192模拟个人每条件/身份24机会，
从实际句型/读数采样；分别报告条件错配、未解析覆盖、身份目标MSE和采样参照损失。
研究目标是证明保留绑定能改变可测对象，不将模拟参数相关当真人人格效度。

内容NLI只在来源16对设计目标上用固定Ridge alpha=.001换算单位，并给正确条件
作为较强参照；不拿未校准概率直接对有符号目标比误差，未见措辞不拟合。

目标是同一机会分母下，本人报告行动与意愿的有符号差：
\[
 f_u(c)=E[1_{actor=u}s(1_{mode=report}-1_{mode=intent})\mid c].
\]
正确条件、估计条件、内容边际使用同一事件样本，避免把更多文本当方法优势。
移除绑定可保留同一句Yes/No但丢掉目标方向。未解析不编码为反对/零人格；
另报完整设计目标与选择后观察平均的区别。

## 理论继承与验收

[UD xcomp](https://universaldependencies.org/u/dep/xcomp.html)要求受外部论元控制的主语，
但对象/主语控制有例外；旧图的ambiguous_controller继续保持不确定。
[UD advcl](https://universaldependencies.org/u/dep/advcl.html)包含时间、条件、目的等，
不是统一心理情境。[Sauri/Pustejovsky](https://aclanthology.org/J12-2002/)的来源事实性
与已有ISO对话依赖作为接口依据，不宣称复现全部语义解析器。

验收：可冷运行的原文接口、原文条件地址、具体绑定作用对照、个人计分损失，
以及自然文本可用/未解析清单。成功、有限失败均写回父项；不能把一个有限语法适配器
声称为开放自然语言全部解决。预算300秒，最多104解析文本/96NLI对；不训练LLM。
