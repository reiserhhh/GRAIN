## 1. 本轮建立了什么

主线从“文本向量里有没有人格方向”发展为三个可以分开研究的对象：

1. **查询条件下的功能响应**：哪种向量变化会改变某项判断，能否跨作者复用。
2. **文本证据的组织方式**：共同、专属以及组合贡献分别在哪一层出现。
3. **轻量计算保留的作者关联**：哪些判断可以用固定编码器和统计函数复现。

现在已有真实文本上的正例：只用教师评分训练的 T/F 学生，在作者外验证中
达到 AUC=.7173，教师为 .6591。也有明确的相反实例：神经质教师 r=.1765，
同类学生 r=.0673。共同公式不意味着每个特质可以共享同一套充分特征。

这些是两个既有 PANDORA source-only 子集的探索性结果，不替换官方 benchmark
或发布版 GRAIN scorer。因子名称、心理意义和机制压缩不是同一个检验。

## 2. 向量变化与判断变化：精确式与近似式

文本 x、查询 q、固定模型、固定 block16 查询末位置 h，令 s_xq(h) 表示其余
状态保持原输入时的下游读出。自然编辑 E 引起 d=h(Ex,q)-h(x,q)。

\[
\Delta_q(E,x)=s_q(Ex)-s_q(x),\qquad
M_q(E,x)=s_{xq}(h+d)-s_{xq}(h).
\]

在路径可微条件下，微积分基本定理给出

\[
M_q=\int_0^1 \nabla s_{xq}(h+td)^T d\,dt,
\qquad \Delta_q=g_{xq}^T d+T_q+R_q.
\]

这里 g=grad s_xq(h)，T=M-g^Td，R=Delta-M，后式是精确记账。
T 是单位置路径的一阶余项；R 是未由该单位置替换重现的自然编辑作用。
文本删除改变长度、其它位置和关系，R 不预先命名为纯噪声。

S1 的三个查询中，g^Td 对实际 M 的 r=.9936–.9956，而 M 对完整 Delta 的
r=.2360–.3934。结论是**该测点附近近似线性，而完整文本作用分布在更多位置和关系中**，
不是“LLM 整体是线性的”。

进一步写 g_xq=bar(g_q)+delta(g_xq)，可得

\[
\Delta_q=\bar g_q^T d+\delta g_{xq}^T d+T_q+R_q.
\]

这是共同读出、输入条件敏感度、局部高阶项和其它通路四部分的工作分解。
共同项已有跨作者经验支持；各部分不是天然正交，不将其平方直接叫独立方差贡献。

## 3. 为什么功能方向优于“大方差方向”

功能投影研究的是

\[
L(P)=E[(g^T(I-P)d)^2],\qquad P^2=P,
\]

而不只是 E[||(I-P)d||²]。两个目标不同：巨大但对读出不敏感的位移，可以压过
很小却能改变判断的位移。S0 的监督 PLS 对位移 SVD 的误差下降约 55%；冻结后
在 24 名新作者、另一公共编辑规则上仍有 r=.8420/.8715（TF/N）。

S1 作者外的 rank8 CoBRAS 式投影保留的局部作用 r=.982/.985/.982；它用到了
测试输入的实测梯度，因此回答**功能是否可压缩**，不是无 LLM 推理性能。
真正不需要新输入反传的 S0 冻结算子另报，不把两者混同。

CoBRAS 的状态/梯度边际平衡是候选构造；最终以同一输入上配对的 g,d 作用误差
检验。既有线性代数、降阶方法支持这种构造，本项目的贡献是对象、实验连接与证据，
不宣称发明了 PLS 或平衡截断。

## 4. 共享路径是分层关系，不是一根万能人格轴

同 24 作者、同 48 视图、同 E1/E2 编辑下，N 与寻求确认查询表现为：

- 同评论的每 token 敏感度剖面平均 r=.6090。
- 去除编辑/视图共同均值后，内部响应 r=.7033，自然编辑响应 r=.2567。
- T/F 与这两者的总体自然响应接近零相关，提示保留专属分支的价值。

8 作者的同数字格式、不同内容查询进一步给出：N/确认内部响应 r=.6303，
N/数量内容 r=-.0280。共享不只是“都输出 0–9”；这里发现的是查询相关计算结构，
并未把它直接等同于问卷间相关或完整依恋特质。

另一个重要结果：三查询的共同作者空间没有一致的低秩结论，最清楚的共享是
N/确认的配对响应。故先采用**按查询对、按证据单元定义的共享关系**，不强制
所有人和所有特质服从同一组少数潜因子。

## 5. 组合项必须保留，但不乱命名

两个不重叠删除包定义四格函数，精确的有限差分为

\[
I_{12,q}=s_q(E_1E_2x)-s_q(E_1x)-s_q(E_2x)+s_q(x).
\]

在该二编辑布尔格上，“基线 + 两个主效应 + 交互”精确重建四个分数。
推广到 m 个编辑就是 Möbius/Walsh 类型有限展开；低阶是否足够由数据决定。
删除不可逆，I12 也不是 Lie 交换子。

联合子面板的交互 RMS 为联合自然响应 RMS 的 56%–88%。状态本身已经非加性，
g 投影的状态混合差分与分数交互 r=.840（TF）、.817（N）、.420（确认）。
这支持继续研究证据组合、归一化与条件重组织，而非只给每条评论一个固定分值。
比值不是解释率；其中也可能包括长度、位置和读出效应。

## 6. 轻量化为什么可能胜过教师，也可能丢掉关键关联

令 S 为教师判断、Z 为固定编码器保存的信息、Y 为外部作者指标，S和Y平方可积。
平方损失下的理想学生 m(Z)=E[S|Z] 满足

\[
S=m(Z)+\epsilon,\quad E[\epsilon\mid Z]=0,
\]

\[
\operatorname{Cov}(Y,S)=\operatorname{Cov}(Y,m(Z))
+E[\operatorname{Cov}(Y,S\mid Z)].
\]

这来自条件期望和全协方差公式。若剩余项与 Y 不相关，学生保留协方差而减少
不相关波动，Pearson 相关可以高于教师。如果剩余项仍携带 Y 的关联，压缩就会
损失它。它不保证 AUC 的单调性；本轮 AUC 增益另由实测给出。

对于实际估计学生 f，始终有精确的可核算式

\[
\operatorname{Cov}(Y,S)=\operatorname{Cov}(Y,f)+\operatorname{Cov}(Y,S-f).
\]

更细地，后项同时包含 E[Cov(Y,S|Z)] 与 Cov(E[Y|Z],m-f)：可能是表示未保留
的关系，也可能是有限样本/函数估计误差。一次有限学生失败不能唯一分辨这两者。

本轮 S4 均值学生（全部训练作者、嵌套作者 CV）：

| 项 | T/F（2328 作者） | N（213 作者） |
|---|---:|---:|
| Cov(Y,S) | .015187 | .002663 |
| Cov(Y,f) | .014291 | .000693 |
| Cov(Y,S-f) | .000896 | .001969 |
| 学生保留的协方差比例 | 约 94% | 约 26% |
| 教师 / 学生标准差 | .1187 / .0817 | .0479 / .0327 |
| 教师 / 学生 Pearson r | .2656 / .3632 | .1765 / .0673 |

这些比例依赖声明的原始评分尺度，是协方差的代数分账，不是人格成分的因果比例。
T/F 的残差几乎不保留标签关联（r=.021）；N 残差仍有 r=.143。它们给出不同的
开发方向：T/F 可压缩的路已经存在；N 应定位仍在教师剩余响应中的特质相关证据。

## 7. 对八个工作假说的本轮裁决

| 假说 | 裁决与下一含义 |
|---|---|
| H1 低复杂度功能规则可跨作者复用 | 支持；S0 新作者与 S1 梯度测量一致推进 |
| H2 查询组织证据而不只换答案 | 支持继续发展；内容对照可区分，固定锚点加权不是充分实现 |
| H3 大小特质有共享及专属作用 | 支持 N/确认的配对作用；不强制统一潜轴 |
| H4 证据组合可以有非加性贡献 | 支持；四格效应和状态混合差分均已观测 |
| H5 persona 写入/读出功能对偶 | 本包未执行，不冒称已闭环 |
| H6 分布/条件信息一定改善当前学生 | 当前分布与简单乘积实现无一致增益；保留问题，停止堆该实现 |
| H7 固定编码器可复现教师 | T/F 分数复现正例；自然编辑响应只部分成立，N 的简单实现不足 |
| H8 轻量化保留真实作者关联 | T/F 得到正例；N 不支持跨特质“一套特征足够”的强版本 |

数学恒等式、经验支持和特定实现的失败分别记录。当前完成的是这一批有限命题，
不是把未来所有特质、语言、观察器的机制一次宣布证明完毕。

## 8. 下一次主线应研究什么

优先对象是 N 的 **S-f(Z)**，而不是再拟合一次完整教师分数。沿同一作者/同一
文本编辑，比较多位置状态及查询条件化的证据关系，找到简单 E5 聚合未保留的
响应成分，再决定需要跨评论交互、角色关系、顺序，还是更合适的固定表示。

先用教师响应定义目标、做作者外差值复现，再在冻结后接作者指标。不从已经看过
的 D1 问卷分数反向选择“最好看的神经元”。新材料按源数据权限组织，MEPS、bridge
和旧 lockbox 仍不开放。T/F 保留为已成功的轻量对照，不因 N 较难而推翻旧成功。

没有理由恢复大规模 prompt 网格或旧128分片队列；本次使用旧缓存扩大学生样本，
只花了数秒。下一神经采样包应围绕上述剩余作用设计，而不是填满既定计算额度。
