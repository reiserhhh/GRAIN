# Event Aggregation and Contextual Interpretation

2026-10-09. HM56 mathematical construction; numerical findings are recorded
in its report after collection. This is not a new scale or a global theorem
about human personality.

## One evidence object, multiple observation coordinates

An author history H has current own events, historical claims, other-person
context, choice/framing and presentation order. An isolated event e has an
observer vector a(e)=(F_1(e),...,F_6(e)). Its components are target-conditioned
observations, not six verified human traits. An event measure can be constructed
without requiring the whole-account reader to be a sum of isolated scores.

The empirical event profile is a conventional distributional observation:

    mu_H = sum_e w_e delta_e, w_e >= 0, sum_e w_e = 1,
    B_q(H) = integral a_q(e) d mu_H(e).

This preserves common event identities across queries. A mention profile is a
different measure. Counting one corrected event twice is not the same as
repeated expression being psychologically meaningless; preserve both objects.

## A falsifiable score-level composition claim

For two behavior contents with observer vectors x and y, all common positive
normalized mixtures form C=conv{x,y}. Native whole-account observation z can
be represented in this model only when z belongs to C. This remains a claim
even if each account is allowed its own unknown mixture weight.

Project z onto C to obtain p, then set w=z-p. The projection optimality
condition gives w dot (v-p) <= 0 for all v in C. Therefore

    w dot z - sup_(v in C) w dot v = ||w||^2.

This is an explicit certificate covering every shared positive weight. It
uses standard convex projection/separation, not a new theorem. Query-specific
positive weights have a larger feasible coordinate box; shared signed
normalized weights have an affine line. Separating these sets avoids treating
every mismatch as the same kind of contextual effect.

## Unit transport is not an automatic escape

Let every observation use the same invertible affine calibration z'=D*z+b,
x'=D*x+b, y'=D*y+b. Membership in the transformed segment is equivalent to
original membership. The witness transports contravariantly:

    w'=inverse(transpose(D))*w,
    w' dot z' - max(w' dot x',w' dot y')
      = w dot z - max(w dot x,w dot y).

Euclidean distances generally change under D; do not claim their numerical
size is an invariant psychological quantity. The separating statement survives.
Likewise, strictly increasing or decreasing per-query recoding preserves
whether a coordinate lies outside its two isolated endpoint values. A
non-injective constant scorer can erase this distinction but erases information.

## Preserve the distinction between aggregation and interpretation

There are two compatible constructions:

1. Aggregate events, then evaluate their distribution with declared observations.
2. Build a context/relationship/history state, then apply a target-specific
   interpretation operator to that state.

They need not commute. A nonlinear operator after aggregation can leave the
score-level convex hull without violating kernel mean embedding or Deep Sets
theory. This does not prove that the LLM has discovered a person's latent trait.
Conversely, forcing native scores back into the hull could discard contextual
signal while merely making the tool easier to summarize.

For GRAIN, keep the event distribution and the interpretation operator as
different interfaces. Choice, condition and narrative response may carry author
information themselves. The next mechanism must identify a reproducible
contextual composition law, not rename z-B(H) as a discovered personality factor
or fit an arbitrary residual until teacher error vanishes. Source-only laws
must make a prediction on different event combinations before being promoted.

## Mathematical ancestry

- Convex projection and separating/supporting hyperplanes: Boyd/Vandenberghe,
  Convex Optimization, sections 2.5 and 8.1.
  https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf
- Common finite measures and linear expectations: Muandet et al., Kernel Mean
  Embedding of Distributions, section 3.1, equations 3.8-3.11, Lemma 3.1.2.
  https://arxiv.org/html/1605.09522v4
- A nonlinear rho after sum(phi) is a standard permitted set construction:
  Zaheer et al., Deep Sets, section 2.2 Theorem 2. The current ordered history
  is not assumed to be an unordered set function.
  https://arxiv.org/html/1703.06114v3
- OpenAI/math finite computations: deterministic episode updates and final
  output tests are conceptually distinct. This inspires the interface; neither
  finite monoid assumptions nor the manuscript's star-height bound are imported
  into neural or psychological measurement.

Natural author differences, B_u, psychological/behavioral interpretation,
independent mathematical operation and original18/100/44 remain open. This
construction states a testable composition model, not their completion.
