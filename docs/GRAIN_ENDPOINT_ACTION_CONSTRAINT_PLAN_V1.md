# M21：端点约束与作用场可识别性

2026-09-08。M20结果后声明的零神经对照；不改M20冻结计划，不追加积分节点。

## 问题与决定

M20只有3/16奇作用积分达到数值容差。现在要区分“有误差的积分监督”和
“固定位置/状态函数缺少可运输结构”，而不是再找一个更高的源标签r。
已有端点给出精确奇作用，但它不能唯一决定逐token梯度。把这一自由度写清楚。

令d为评论内中心化状态、g为M20偶敏感度，目标o为已缓存双向端点差的一半：

```
delta = o - <d,g>
g_star = g + delta*d/||d||_F^2
<d,g_star> = o
```

这是欧氏/Frobenius范数下满足一个作用约束的最小改变量，由Cauchy-Schwarz
直接得到。所有其它解为g_star+v，其中<d,v>=0。因此它是一个选定的作用场
代表，不是恢复了真实积分梯度。反射时d和o都换号、g为偶函数，修正仍为偶。
不得把约束后的训练端点精确重建当成新发现。

完整复用M20的16梯度单元、每query4reference/4check、48作者×3视图。
只对reference监督作上述修正，原固定64投影、32位置函数、三个函数族和
两类损失完全不变。无新超参、无新特征、无模型/前缀/后缀/梯度调用。

读数是跨材料描述，不冒充训练拟合误差。先冻结全部预测，再连接同一旧源标签。

输出端点约束误差、修正范数、token/作者作用误差、奇性重放、六种函数的
运输与源协方差余项。六种全报，不按Y挑选。最多120秒CPU；不再加alpha/rank。
若修正后仍弱，结论限于当前函数族/参照，不把方向通路删除或称为噪声。

## 理论位置

这是对可操作函数与不可唯一识别内部场的区分。有限积分依循
[Integrated Gradients](https://proceedings.mlr.press/v70/sundararajan17a.html)
的路径完整性思想；最小范数约束为本实验的代数选择，不声称原论文给出它。
奇偶分解是二元反射群投影的直接应用，不主张群论或正交投影为GRAIN原创。
