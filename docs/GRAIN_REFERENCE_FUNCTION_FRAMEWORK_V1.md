# GRAIN：参照功能读出的理论框架 V1

2026-09-08。**方法框架v1交付稿，M8-M21完成，整链数学接口已重放。**
本文件整合既有GRAIN/4W与新查询矩阵机制，不取代历史方法与发布计分器。
当前执行和完成条件见[闭环计划](GRAIN_FRAMEWORK_CLOSURE_PLAN_V1.md)。

## 1. 问题与对象

研究目标是从作者文本形成可比较、可解释的个体特征，而非仅复现某个LLM分数。
LLM已有作者关联提示了一个可研究的机制：查询如何组织真实文本的证据，哪些
向量运算把它变成特质判断；哪些步骤可冻结成数学函数而不再生成推理文字。

给定作者u、材料/条件c、查询q及固定观察器theta：

```
H_uq = Encoder_theta(text_u, q, c)
(E_uq, Z_uq, h_uq) = Partition(H_uq)
s_uq = F_theta,q(E_uq, Z_uq, h_uq; layout_uq)
```

H为block16输出。E包含查询区域之前的证据、模板及历史；Z为固定查询P区的
token×hidden矩阵；h为最后token Q。F是原生剩余网络及冻结候选答案期望值。
P文字在作者间完全一致，但它的上下文化向量不同。相同词不是相同证据状态。

所有分数都属于声明的观察器/材料/查询，不把LLM给出的心理名称当作真人真值。
外部量表只在构造冻结后连接，不用来定义每一条中间路径。

## 2. 精确的锚定分解

把P/Q堆叠为x=(vec(Z),h)，参照总体R给出固定xbar。对每人保留E与布局，定义：

```
b_q(E_u) = F_q(E_u, xbar)
s_uq = b_q(E_u) + integral_0^1 J_q(E_u,xbar+t*d_u) dot d_u dt
d_u = x_u - xbar
```

F沿线可微且积分存在时，这是微积分基本定理。它不要求人与人相同，不要求
输入坐标独立，也不要求非线性消失。锚定状态是计算干预，可不是自然人文本。

测得的一条编辑路径导数不能唯一确定作者水平的基线。若J不随E改变，b(E)
仍可改变；这解释了“能读变化，不一定能读水平”的可能性，而非矛盾。

固定矩阵候选使用参照作者的函数J_ref：

```
s_hat_uq = b_ref,q + J_ref,q dot d_u
r_uq = [b_q(E_u)-b_ref,q]
       + integral_0^1 [J_q(E_u,xbar+t*d_u)-J_ref,q] dot d_u dt
```

这精确区分**条件基线偏移**与**函数运输误差**。现有算法中J_ref由P积分矩阵
和Q完整上下文梯度拼接，属于经验候选，并未假定它就是任一全局势的真梯度。

设路径邻域内J关于x有L-Lipschitz界，且在xbar与参考函数差不超过eta(E)，则：

```
abs(r_uq - [b_q(E_u)-b_ref,q])
  <= eta_q(E_u)*||d_u|| + (L_q/2)*||d_u||^2.
```

证明是对梯度差作三角不等式、Cauchy-Schwarz后积分。这里L/eta是条件性的
理论量，不假称我们已对整个神经网络估出有效常数。它指引误差应如何分类，
不是给未观测作者的自动认证界。

## 3. 已实现的构造

参照作者各有一条固定E1编辑。P积分对两个E背景平均，Q保持旧状态：

```
G_uq = (1/2) sum_e integral_0^1 dF_q(E_e, Z0+t*(Z1-Z0), h0)/dZ dt
G_ref,q = mean_reference(G_uq)
g_ref,q = mean_reference(dF_q(E_u,Z_u,h_u)/dh)
s_hat_q(x) = b_ref,q + <G_ref,q,Z-Zbar,q>_F + g_ref,q dot (h-hbar,q)
```

Simpson三节点实现积分；P token坐标只在同一个查询内对齐。b/Zbar/hbar来自
参照完整原生状态，不来自删文后的状态。评估人不给梯度、不改变参照、不调权重。
自然变化预测就是同一函数在编辑前后的差，不另拟合一条变化回归。

两参照并非通用最小样本数，只是本次有限见证。未来参照总体应该由预期应用域
决定；换模板、模型或层通常需要重新构造，不可把本轮系数当跨模型常数。

四参照局部图册是后备：按原坐标最近参照选一张局部仿射图。它不天然优于
单一共享函数，切图可能引入响应不连续；本轮全部结果保留，不择优藏负项。

## 4. 自然文本变化的完整账本

删除评论改变内容、长度、布局、状态历史与重分词，不能把删文效果当成只改Z。
原状态映射到编辑布局，未匹配边界保留编辑状态，得到Q0下E/P四格f00/f10/
f01/f11，随后换成Q1取得原生编辑分数。精确分账为：

```
Delta = (f00-s_full) + (f10-f00) + (f01-f00)
        + (f11-f10-f01+f00) + (s_edit-f11)
      = Gamma + E_main + P_main + EP + Q_conditional.
```

Gamma不是纯粹长度因果效应；Q_conditional也不是三玩家Shapley值。若EP平分
到E/P，两者已含交互，不再次相加。由此保留支持/抵消结构，而不是删除残差。

这一思路与[多变量函数的锚定分解](https://web.maths.unsw.edu.au/~fkuo/pubs/preprint/ksww09-decomp.pdf)
相通：固定一部分坐标来定义条件效应。锚定分解与统计正交ANOVA不同，条件间
相关和非零协方差应保留。不是把该数学方法包装成GRAIN首创。

## 5. 作者配置和共享函数空间

作者在某材料域的配置由多个查询的水平和声明编辑响应共同构成：

```
R_u(c) = [s_hat_q(text_u,c),
          s_hat_q(edit_j(text_u,c))-s_hat_q(text_u,c)]_(q,j)
rho_u(c) = D_ref^(-1) * (R_u(c)-mean_ref(R(c))).
```

作者身份不是拟合残差，也不要求J_u-J_ref很大。同一共同函数下，不同输入
状态可以产生稳定作者差异。D_ref须由参照材料指定；当前两人标准差只是研究
坐标，不是人口常模。要区分同批作者位置、跨文本复现和跨场景人格三个问题。

共享/专属关系定义在功能而非字面名词上。给共同材料变化分布pi，
`K(q,q')=Cov_pi(f_q(event), f_q'(event))`。这里每个q处理自己的token矩阵，
不能直接跨查询拼对不同token。隐子空间角度是另一种几何，不等于这个功能K。

与GRAIN的关系：Where保留选择分布/条件，What保留内容组织和KV/矩阵配置，
Who是显式参照中的位置与响应配置，When是顺序、状态变化和路径操作。没有
证据要求这四层压成少数统一人格轴。群体几何是组织与解释通路，不强行充当
所有查询的乘法增益；D3B已经说明后者不总改善误差。

## 6. 可用证据、心理解释与LLM依赖

三种关系必须各有对象：

1. 数学读出与原生模型判断的关系：检验构造复现了什么计算。
2. 构造跨文本/作者的关系：检验在何种材料条件下形成可比较配置。
3. 与既有心理指标/行为的关系：检验这部分计算具体涉及什么人的属性。

本轮无需模型生成思维链。构造阶段用冻结模型求参照梯度；使用阶段计算固定
前缀，再用矩阵点乘得到分数。**没有语言化推理，不等于没有预训练神经知识**。
局部影响也不是唯一的内部推理链，向量干预定位的是声明测点上的功能作用。

源连接应使用`Cov(Y,s)=Cov(Y,s_hat)+Cov(Y,s-s_hat)`，追踪遗漏关联在哪里。
协方差份额可正负、可大于1，绝不能称为独立心理方差解释率。老师的评分高
保真也不自动保证更多心理关联，S4/S26对此已有正反实例。

### 7.1 配置与查询的交互，不是两个独立读数相加

令C(E)保留每条评论均值但抹平其内部token偏移，固定同一作者布局：
`f11=F(E,x), f01=F(C(E),x), f10=F(E,xbar), f00=F(C(E),xbar)`。
则`E_main=f10-f00, X_main=f01-f00, I=f11-f10-f01+f00`，
`s=f00+E_main+X_main+I`。旧S9配置项=E_main+I，查询位移=X_main+I。

在F二阶连续可微的固定布局矩形上，设dE=E-C(E)、dx=x-xbar：

```
I = integral_0^1 integral_0^1
    dE' Hessian_(E,x) F(C(E)+a*dE, xbar+b*dx) dx da db.
```

证明为两次微积分基本定理。这与
[Janizek等(2021)的交互归因工作](https://jmlr.org/papers/v22/20-1223.html)
相关，但这里是两组变量的矩形锚定差分，不冒称实现了该文的Integrated Hessians
分配规则。M15计算的是四个端点，尚未直接估出高维混合Hessian矩阵。

### 7.2 为什么均值保持时仍有有用作用

固定xbar，令各评论G内d_t=h_t-m_G，定义沿C(E)到E的积分梯度g_t，则
`E_main=sum_t d_t'g_t=sum_G |G| trace(Cov_G(h,g))`。
每组sum d_t=0，所以任何组内常数敏感度都会抵消；真正作用来自token状态
偏移与敏感度偏移的联合配置。它不是普通token均值，也不必等于一个attention
head的权重。该敏感度是对整个固定后缀的导数，包含后续层的直接/间接作用。

M16已保存完整条件场。每query4参考作者的固定64秩场在20非参考作者上，对
N实际配置效应r=.534，但幅度和源协方差保留较弱。16单元积分有8项达到
三/五节点数值容差，失败项保留。符号恒等式与数值/运输误差各有账本。
见[M16报告](../reports/grain_vector_mechanisms/CENTERED_ADJOINT_FIELD_REPORT.md)。

### 7.3 作用商空间、二次方向和目标范数

令Gamma=T*center_G(g)。对当前d，`Gamma_parallel=d*(d'Gamma)/||d||^2`，
其余部分Gamma_perp满足d'Gamma_perp=0。这是相对于当前路径的零作用，不是
全局无心理信息。共同二次场的矩阵A只有对称部分B进入d'Ad；反对称部分
不影响该标量。M17对B完整非零特征方向重新拟合，不增加方向数。

在相同方向上，参考token作用损失`(d'Gamma-d'Gamma_hat)^2`与整梯度损失
`||Gamma-Gamma_hat||^2`是不同范数/半范数。前者对应实际输出函数，不需要
复制沿当前方向无作用的分量。两者都由模型导数监督，不用人体量表训练。
M17作用损失使TF/N作者外配置r=.689/.574，零作用MSE比=.394/.653；但源N
关联仍主要在余项。这保留了功能构造成功，也指明不能用它替代整链结论。

逐token误差e的作者聚合误差有精确式：
`mean(e)^2 = mean(e^2)/T + sum_(t!=s)e_t e_s/T^2`。
有符号抵消与共变决定作者读数，单token误差降低不必然意味着作者作用更好。
这与[Sobolev导数监督](https://papers.neurips.cc/paper_files/paper/2017/hash/758a06618c69880a6cee5314ee42d52f-Abstract.html)
及[面向输出降阶](https://onlinelibrary.wiley.com/doi/10.1002/nme.3074)的动机相通；
这里使用有限基函数解析回归，不冒称复现其神经或结构力学算法。

### 7.4 条件化、方向性与不应混同的两个目标

M18把上述系数写成c+Lz，z是评论背景和布局条件。它回到MCD“条件如何调节
表达”的原则，不先删条件。源作者关联出现新例：TF位置条件场r=.521，
N联合场r=.240（各20人发现样本），但原E效应运输变差。故作者关联与实际
干预保真是两个对象，必须分别保留；不能宣称已完整找回E的心理相关通路。

所有当前二次场都满足h(d;z)=h(-d;z)，因为评论均值和位置在符号反射时不变。
一般实际函数没有这个假设。M19以反射群的两个投影定义：

```
e_plus = F(C+d,xbar)-F(C,xbar)
e_minus = F(C-d,xbar)-F(C,xbar)
e_odd = (e_plus-e_minus)/2; e_even = (e_plus+e_minus)/2
e_plus = e_odd+e_even
```

对任一偶读出h，成对均方误差`[(e_plus-h)^2+(e_minus-h)^2]/2`
等于`(e_even-h)^2+e_odd^2`。因此非零奇作用是偶函数族的结构缺项，而不是
调参不足；此下界针对声明的成对方向分布，不直接当原生作者总体误差。
奇/偶都可包含高阶非线性，不能把奇叫纯一阶、偶叫纯方差。镜像是内部
功能试验，不假装是自然语言的反面。

M19完成148后缀/93秒，24人/query。N全部样本odd/even源r=.407/.514，
20非参考作者为.451/.453，标签协方差约各半；TF非参考组两部分协方差
反向抵消。原点一阶L与odd在各8缓存单元上相关-.436/-.157，不能直接
把方向项当一阶导数。见[M19报告](../reports/grain_vector_mechanisms/CONFIGURATION_PARITY_REPORT.md)。

因而共同公式需要同时保留方向、对称配置、查询与交互。下一步不是多加几项
经验因子，而是用`g_plus/minus=int grad F(C +/- a*d) da`构造
`odd=.5*d'(g_plus+g_minus)`和`even=.5*d'(g_plus-g_minus)`。
函数的奇/偶性由反射关系确定，其跨作者可运输性仍须实际构造。
[M20](../reports/grain_vector_mechanisms/ODD_ACTION_CONSTRUCTION_REPORT.md)已执行：
70新前反传对/139秒；奇/偶积分分别3/16、5/16达到数值容差。位置/状态场得到
部分源关联，但实际奇作用运输较弱，不把积分失败冒称成公式失败。

### 7.5 可识别的是作用，不一定是唯一敏感度场

对于一个非零路径d与端点作用o，约束是一个标量：`<d,g>=o`。若g0为近似场，
在声明的Frobenius度量中，最近的可行场为：

```
g_star = g0 + (o-<d,g0>)*d/||d||^2
all_solutions = g_star + {v : <d,v>=0}.
```

令改变量u，Cauchy-Schwarz给出`||u|| >= abs(o-<d,g0>)/||d||`，等号由上式
达到。该式只选择一个代表；它不识别真正积分场，也不让任意新d自动有正确
作用。多个已知路径提供多个线性约束，只有在它们张成的子空间上才增加识别。
路径不满秩时，核空间仍存在。可复用标量函数与唯一内部神经链是不同对象。

M21使用精确端点约束，仅修正4参考作者/query的监督，六个函数族/损失不变。
约束误差1.73e-18、奇性误差0；运输r最大变化约.0034。故该最小范数约束不
解决当前有限场的跨作者缺口。N联合作用函数的源r=.4063保留为研究坐标，
实际奇作用r=.1159，不能混称同一成功。详见[M21](../reports/grain_vector_mechanisms/ENDPOINT_ACTION_CONSTRAINT_REPORT.md)。

这给v1一个必要修订：共同的是**条件化构造程序**，不是已经证明所有查询都
可由同一个均值、二次式或小型固定场无误读取。以积分、双向端点和误差账本
定义可研究对象，以成功的冻结P/Q或配对函数给出可用实例，二者不互相冒充。

### 7.6 当前可以合在一起的总式

同一作者、布局、查询、参照下：

```
s = f00 + odd_E + even_E + X_main + I
s_hat_PQ = b_ref + <G_ref,Z-Zbar> + g_ref'*(h-hbar)
s - s_hat_PQ = baseline_shift + transport_remainder.
```

第一行是M15+M19的精确内部干预账本；第二行是已运输的近似使用函数；第三行
说明它们如何接合。**不是**把第二行再与第一行的E/X/I相加。旧S20配对读出
也应放在其声明目标下，除非先算重叠，不叠成一个假装更全面的总分。

自然文本变化另用第4节的布局账本；跨查询共享另用第5节功能协方差；作者
位置另用固定参照归一。这是分层方法体系，不必压成一个可以随意代入的r公式。
任何余项都保留其符号、幅度、条件和外部联系，不预先定义为可删除噪声。

## 8. 从零构造与重放入口
