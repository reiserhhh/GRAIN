## 2. Observation purpose is part of the mathematical function

Let h be the qualified history, c the evidence opportunity, q the endpoint and
iota the observation/response instruction. The action is

\[
\mathcal A_{q,\iota,c}(h;\delta)
=f_{q,\iota,c}(h\oplus\delta)-f_{q,\iota,c}(h).
\]

One delta need not define one scalar effect independent of q/iota/c. Here a
diagnostic question, a prospective choice and a request to output Yes/No are
different functions of the same evidence. The forced-answer arms are *requested*
policies, not physically imposed responses. Forced Yes was not obeyed uniformly,
so it is not a valid constant-output negative control. This remains in the report.

Selected logits give two different kinds of observations:

\[
D=l_Y-l_N,\quad p_{Y\mid Y,N}=\sigma(D),\quad
m=e^{l_Y-Z}+e^{l_N-Z},\quad p_Y=m\sigma(D).
\]

Even if log-odds action remains, saturated binary probabilities can change very
little. Suppressed probability response is not evidence that information was
removed from the cache. Full answer mass was near1 in these actual observations,
so the principal results are not manufactured by low Yes/No format probability.

HM160's observed-author endpoint psi=P(Y|H,A) remains a separate object. A model
choice probability does not become a human future-action probability merely
because it has the same numerical form. A source bridge must link the actual
endpoint events/measurement target, rather than equate those functions by name.

## 3. A partial relation edit is not a natural actor update

For any readout f on the registered natural records let
g_e(e,n,p)=(-e,n,p), and D_e f=f(g_e x)-f(x). Then exactly

\[
(D_e f)(g_e x)=-(D_e f)(x).
\]

Thus every finite-character coefficient of D_e f that is *even* in e is zero.
For the n exchange, all n-even coefficients vanish. This holds for arbitrary
nonlinear f and is a standard Z2 identity, not a new theorem or a linear-model
assumption. Natural full-record exchanges satisfy it: maximum even coefficient
over every measured endpoint/condition/order was2.78e-17.

The frozen source *partial-cache* edits do not generally satisfy this whole-record
exchange identity. In target-matched restricted-choice action energy:

| Source edit / endpoint | Exchange-even fraction |
| --- | ---: |
| e / diagnostic | .297565 |
| e / prospective choice | .321138 |
| n / diagnostic | .145119 |
| n / prospective choice | .051204 |

These are finite mathematical action components, not percentages of psychological
information/noise. Their presence does not invalidate the measured intervention;
it prevents calling that intervention a faithful *whole actor exchange*.
This description was added after observing the primary results, with no new
forwards or changes to the original experiment; it is not a new blind test.

The source four-corner representation has the form

\[
M(e,n)=M_0+eM_E+nM_N+enM_{EN}.
\]

Flipping only the en term while holding both marginal terms fixed leaves the
natural four-corner support unless a relevant marginal term is zero. The exact
algebraic witness f(e,n,r,p)=rep with r=en gives f=np; flipping only r changes
that n-person response, whereas a complete natural e exchange leaves it unchanged.
This explains why effective relation steering and a semantically coherent author
update are not interchangeable concepts. It is a compatibility constraint from
the registered design, not proof of a global neural manifold or a human trait law.

## 4. Implication for GRAIN construction

Keep three distinct contracts:

1. Evidence/event qualification: who did what, under which opportunity, with
   event identity/history and source population retained.
2. Vector intervention: actual support and conditional relation/marginal
   components; mark whether it is a partial carrier edit or a supported natural
   evidence update. Multiple carriers do not become independent events.
3. Endpoint observation: q/iota/c and readout units; diagnostic, model choice
   and empirically observed author outcome are not merged automatically.

The new result advances contract2-to3 without closing contract3-to-human-meaning.
It is not necessary to maximize Euclidean reconstruction or reader accuracy to
investigate these contracts. The next finite discriminator should compare a
source-complete natural-update operator with the existing relation-only operator
on these SAME frozen endpoints, including whole-exchange parity and effective
support. No teacher-answer fitting, head/rank/dose grid or output projection
that removes inconvenient coefficients to manufacture compatibility.
