# M19：配置的方向性与分散幅度不是同一种信息

2026-09-08，预执行冻结。M18完成后唯一新包。不是换参数，而是检验M16-M18
共同具有的d->-d不变性是否适合实际函数。

## 精确分解

在同一布局与固定查询xbar下，C为每评论均值状态，d=E-C：

```
plus = F(C+d,xbar)-F(C,xbar)
minus = F(C-d,xbar)-F(C,xbar)
odd = (plus-minus)/2
even = (plus+minus)/2
plus = odd+even
```

这是二元素反射群的对称/反对称投影。偶部分可以包含四次及更高阶项，不能
直接叫Hessian/方差；奇部分也可含三次及更高阶，不等于裸线性项。
任何偶估计器h对成对方向的均方误差为`(h-even)^2+odd^2`。这是同一对端点
等权测度下的精确下界，不是未经测量的原生作者分布误差下界。

M16-M18的二次场，包括给均值和位置条件化的版本，在这两个方向上读数相同。
若odd携带明显作用，继续优化这些偶函数不可能完整表达该方向效应。
这定位表示缺项，不将odd自动称人格、不将even当噪声。

## 最小实际干预

复用M15/M16的48人×3视图，各测一个镜像端点；原F(C+d)/F(C)均已缓存。
镜像只作用body mask，P/Q固定原参照，其它模板/位置/顺序不变。
每查询第一个作者/view0重放两个旧端点，总148后缀前向，0prefix/0梯度/0训练，
600秒上限，按作者完整单元保存恢复。镜像可能不在自然语言编码流形上，
本包只识别这个固定内部函数如何利用方向，不解释为现实人的反向人格。

预测/三格冻结后才接同一已暴露源Y。报告24全部和4参考/20评估子组，
odd/even作用RMS、互协方差、与旧配置和冻结M17/M18读数的关系、源r和有符号
Cov(Y,plus)=Cov(Y,odd)+Cov(Y,even)。不按数据改镜像幅度/挑方向/挑作者。

另用16个已存a=0梯度，列出一阶`L=<d,gradient F(C)>`和`plus-L`，只作
Taylor余项诊断，不增加Hessian或积分节点。比较奇项和线性项，检验高阶
方向依赖是否重要。数值恒等式、偶读数不变性与有限多项式写单测。

如果方向是主要缺项，下一构造应包含条件依赖的一阶/奇作用，而不是再扩大
二次秩；如果不是，则定位跨token关系或参考覆盖。目标都是完整向量推论
函数及其作者关系，不重启局部r的无边界优化。
