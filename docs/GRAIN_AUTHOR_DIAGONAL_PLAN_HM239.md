## Exact accounts

For a source library, n_g authors per profile and chi_S(g) its32 characters,
let m_v(g) be its view mean and B_vS=sum_g chi_S(g)m_v(g)/32. Write K_ij as
the view-A/view-B inner product in each fixed space.

The original V_ST=<B_AS,B_BT> has a same-author diagonal

    D_ST = sum_g chi_S(g)chi_T(g) sum_(i:g) K_ii / (32^2 n_g^2).

In particular D_SS is IDENTICAL for all characters under this fixed profile
partition, including the common one. It is not invariant under arbitrary
profile reallocations. Preserve R=V-D, which includes all distinct-author
pairs with the original weights; R is NOT by itself an unbiased statistic.

For n_g>=2 replace the within-profile diagonal block m_A(g).m_B(g) by

    U_g = sum_(i!=j:g) K_ij / [n_g(n_g-1)].
    U_ST = V_ST + sum_g chi_S(g)chi_T(g)
                         [U_g-m_A(g).m_B(g)]/32^2.

This is the established distinct-index estimator. Unbiasedness for a population
moment additionally requires independently sampled authors inside each profile;
natural comments inside an author may remain dependent. The pooled library is
expected to have all n_g>=2; if not, the full U moment stays undefined. Fold
singletons are recorded, NOT imputed or deleted to manufacture a full moment.
The diagonal U_SS-V_SS correction is also character-neutral for this fixed
partition. Preserve off-diagonal character relations; a common correction is
not a claim that one specific target character is an author fingerprint.
