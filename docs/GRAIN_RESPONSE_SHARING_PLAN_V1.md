# M04：从条件距离到同人响应协方差

2026-09-13，执行前固定。新增机制是**学出可共享的响应结构，保留个人系数**，
不是再次调GP带宽、聚类数或个人预测头。M02批量/平方根与既有结果均保持冻结。

## 问题与已有证据

旧自然条件GP的GRAIN24条件均值几何未胜截距；NAV06旧水平分组未支持路径共享。
这些结果不表示个人条件函数不存在，而表示描述/水平相近未识别出响应共享关系。
新输入为来源人的跨条件配对观察，不能由两个语料的独立平均值替代。

继承Yao/Müller/Wang(2005)的总体函数均值/协方差与个人条件预测思想、
多输出核和GPML条件矩。本包五离散条件，没有采用稀疏随机时间的平滑FPCA或
宣称复现其置信带。CAPS的平均水平及if-then轮廓区分用于对象定义，不当作真人效度。

## 固定实验

1. 60新公开文本：五个记录到的时间预算条件×正负体验×六措辞，沿用已有公开段落。
   固定NLI共120对，40来源原文先运行并按条件校准，再冷运行20留出措辞；不改提示。
2. 3种子×3世界，来源384、新应用256参数组；每条件32事件，来源两独立半组。
   世界分别为平滑共享、条件响应交叉、条件特有响应。相同条件几何，允许响应协方差
   不同甚至负相关。生成真值与拟合/应用分离，不把模拟人称真人。
3. 来源两半`Y_A/Y_B`的同人交叉协方差估计函数K；半差估计观察误差R。
   K固定PSD投影，不扫截断秩；噪声按32事件均值的单位。来源不用隐参数。
4. 五参照：来源均值、只估计个人平均并广播、J/RBF/I几何核、来源响应协方差、
   打乱来源两半作者配对的协方差。几何核NNLS三个方差分量，带宽为条件中位距离。
5. 个人先有中心条件，再有两端响应，再补一个隐藏条件；臂内相同文本预算。
   应用每阶段只读取该阶段公开的数值文件，不读被隐藏条件或真值。
6. 同一函数输出五条件、整体平均、两隐藏条件差及一个未观察条件；报告个人平均/
   个人响应/来源先验分账、工作协方差、MSE/r/覆盖，不以MSE压低作为人格成功。
7. 固定响应阶段：最近来源人分别按共同中心条件水平与三条件去水平响应匹配，对比其隐藏响应
   差异；随机来源人为参照。只一个最近邻定义，不调k、不成为新回归器。
8. 数学见证：同平均而反应相反、平均不同而反应相同；响应核可负相关且仍PSD；
   没有跨条件共享时个人补充观察能修复哪一部分，而不是要求所有世界正结果。

## 验收与边界

实现来源学习K/个人条件函数/三目标及分账、整条件隐藏、响应距离和以上正反对照。
共同核是响应模式的统计参照，不是把某位来源作者的全部反应贴给新人。
仅五个已由来源覆盖的条件；全新语义条件归M01，交互因果含义归M09。
无MEPS读取/拟合，无新心理标签、原神经模型训练、发布或原队列启动。
如果本文条件响应模型失败，报告来源矩/支持或观察缺口，不增加精度救援网格。
