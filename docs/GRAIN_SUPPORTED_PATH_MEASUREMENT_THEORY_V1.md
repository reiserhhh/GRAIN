## 2. Zero-mass coordinates are not observed coordinates

At each layer an attention context has keys k_i, values v_i, positions p_i,
and availability a_i. Its conditional attention uses

    p_i(q) = a_i exp(q dot k_i) / sum_j a_j exp(q dot k_j).

Two cache representatives X and X' are equivalent when their availabilities
coincide and their K/V coincide wherever a_i>0. K/V at a_i=0 can differ without
changing any current-token attention; recursion preserves this equivalence.
This is a property of the explicitly defined constructor, not of real people.

However, straight coordinate interpolation can activate a formerly masked
slot while interpolating its arbitrary stored K/V:

    X_t=(1-t)X_low+tX_high.

Changing the invisible endpoint representative changes this interior path,
even though both measured endpoints are equivalent. This is a mathematical
source of path ambiguity distinct from numerical quadrature error.

## 4. Consequence for a GRAIN interface

A positional response measure can be defined as

    mu_q = sum_i A_qi delta_(g_i),
    mass = sum_i A_qi,
    first = sum_i A_qi g_i,
    connected = sum_i A_qi (g_i - mean_body(g)).

Keep its K/V/availability parts and untagged prompt mass. A connected moment
does not remove a condition mean from author scoring. Under affine mark change
g'=Lg+b, mass is unchanged, first'=L first+b mass and connected'=L connected.
Cosine itself is not invariant under arbitrary L; retain the frozen metric.

But A must first be defined on meaningful observed support, rather than on
arbitrary masked representatives. Accurate integration of an arbitrarily
chosen cache path would still not make it a uniquely identified text-to-trait
path. Thus the next task is a supported path definition, not a precision grid.

One candidate uses positive position-marked attention measures

    nu_l = sum_i a_i delta_(p_i,k_li,v_li,g_i),
    nu_l,t = (1-t)nu_l,low + t nu_l,high.

This mixture ignores zero-mass endpoint values and preserves rotary positions
and causal current support. It is an unexecuted proposed path, not a proven
natural psychological trajectory. A future constructor must allow two atoms
at one old position without incorrectly doubling rotary position indices.
Other supported paths remain possible; no uniqueness theorem is claimed.

Do not delete genuine topic, choice, condition or state contributions. The
equivalence above concerns ONLY zero-mass numerical cache positions. It is not
an argument that uncommon text or a residual author difference is noise.
