# Codex 独立立场：研究可压缩的计算，而不只寻找一根方向

2026-09-07，研讨第一轮期间形成，尚未吸收 Claude 的第一轮结论。

## 1. 我对用户命题的操作化

用户不是要求立刻准确诊断，而是把已观察到的文本与心理指标关联当作一个可研究的
自然现象。底层向量实现本身并非未知；未知的是有没有一个比完整 Transformer 更
简洁、跨新证据仍有效、能够解释观测变化的中间运算。

三个层次必须分别推进：

1. 不生成语言化解释：仍使用原 LLM 内部计算，直接读取规定输出/隐藏状态。
2. 不运行完整 LLM：从某些已冻结表征建立紧凑运算，检验能否保持原生函数的行为。
3. 不依赖原生分数：同一紧凑运算能否保留对真实外部指标的关联。

第二层的 teacher fidelity 与第三层的 criterion validity 不是同一个目标。
embedding 自身也可能携带预训练语义；不能把“无语言输出”写成“没有语言知识”。

## 2. 数学上的中间机制应满足什么

令 \(h_{t+1}=F(h_t,e_t)\)、\(s=G(h_T,q)\) 表示一个指定模型的状态更新与查询输出。
我们寻找压缩 \(z=\phi(h)\)、更新 \(\widetilde F\) 与读出 \(\widetilde G\)，使

\[
\phi(F(h,e))\approx\widetilde F(\phi(h),e),\qquad
G(h,q)\approx\widetilde G(\phi(h),q).
\]

只拟合最后一个分数不够：第二个等式可在一个问题上近乎完美，却完全不满足第一个
等式，或者遇到新问题就失效。这里的时间是模型计算或证据输入步，不是人的心理时间。
闭合要求必须限定证据/查询支持，不能用有限 panel 宣称全局充分。

我偏好的机制候选是：角色/事件绑定的低秩交互、依赖历史的证据更新，以及任务条件化
的函数度量。它们不是互斥算法；需要分层决定哪些可以用小运算替代、哪些仍依赖
上游语义表征。简单堆叠所有候选只会重复过去大网格而不能定位机制。

## 3. 最小思想反例：当前读得准不代表状态已抽取完整

设二维状态 \(h=(a,b)^T\)，更新矩阵交换两个分量，当前读出只看第一分量：

\[
A=\begin{pmatrix}0&1\\1&0\end{pmatrix},\qquad C=(1,0).
\]

\(\phi(h)=Ch=a\) 完美重现当前输出，但 \((a,1)\) 与 \((a,-1)\) 在下一步输出不同。
一步观察矩阵 \(C\) 的秩为 1；两步 \([C;CA]\) 的秩为 2。需要的可能是对多种
受控查询/更新的响应组合，不是当前最强相关轴。这是线性系统可观测性的标准反例，
不是 Transformer 或人格遵循线性状态方程的证据。

同样，若两个历史在平均 embedding 下完全相同，但主体关系不同，任何仅依赖这个
平均向量的复杂函数都不能把它们区分开。要么保留关系结构，要么承认这种压缩不足。

## 4. 文献更新与本地证据的对应

- Yang 与 Oshio 的 738 人研究报告历史推论与自评正相关，同时存在整体高估和关系
  调节；支持研究能力与线索来源，不提供内部计算路径。此轮核对大学正式摘要，
  不把摘要外的精确相关或路径分析结果补写出来。
  [2026 论文记录](https://waseda.elsevierpure.com/en/publications/attachment-towards-generative-ai-influences-self-ai-agreement-in-/)
- Härtel 的 406 个 LinkedIn 档案研究已经把 lens model 用到 LLM 判断；因此“使用
  lens model 分析 LLM 人格线索”不能作为本项目首创。GRAIN 新问题应落在内部向量
  运算、证据绑定和可替代机制，而非重新命名经典分解。
  [2026 原文](https://link.springer.com/article/10.1007/s10869-025-10087-8)
- Coconut 用连续隐藏状态继续计算而不把每一步解码为单词；支持无语言化中间推理
  的可行性，但仍依赖 LLM 和专门训练，也不是人格推论研究。
  [Hao et al., COLM 2025; arXiv v4 2026](https://arxiv.org/abs/2412.06769)

本地最接近用户命题的证据不是更高的总相关，而是 VM03：加性表示漏掉关系，
联合表示与显式乘积核恢复关系；多 token 的早层状态替换影响输出，晚层强 probe
却不一定有同样干预效应。这已经把“数值可读”和“计算功能”分开。

## 5. 我希望在第二轮澄清的分歧

Lens 四项分解是诊断账目，PSR 是候选对象定义，两者都不能单独算发现了机制。
我倾向先研究一个受控的关系/更新微系统，比较终点拟合与响应闭合，再回到人格
外部关联。问题是：这种微系统会不会与 GRAIN 的自然作者证据脱节？我们需要 Claude
给出能够连接回真实历史、但不提前打开新标签或追加大训练的具体桥梁。
