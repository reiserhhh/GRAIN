## 2. Exact source operation

assigned social and worry behaviors. The complete source K/V cube has the exact
standard character expansion

    M_s(e,n) = M_0 + e M_E + n M_N + en M_EN.

Every four-corner array permits this expansion; its existence is not evidence

An E assignment edit has source increment

    D_E^rel(e,n)  = D_E^full-D_E^marg = -2en M_EN.

interventions, not interchangeable natural texts or a proved global group action.

replaced by a single context-free trait direction simply because the marginal

## 4. Why a relation can become a person-qualified observation

Characters multiply by sign products. A constructive example is

    (en) * (np) = ep,

where p specifies the queried person. A relation between two attributions can be
converted into a qualified response by conditional person selection. Averaging
the en component to0 before selection destroys this possibility. This is a
standard algebraic mechanism, NOT a localization of an actual multiplication
inside Qwen. The actual experiment establishes the intervention's effect, while
K-versus-V-versus-recursive-reader routing remains a separate question.

HM106 already showed selection/value character convolution in a declared reader;
HM133 showed a common role key can suffice at an explicit declaration. HM157 adds
source transport and a relation-only causal arm on effective content-dependent
carriers, with native target readout. It does not rediscover those identities as
new mathematics or assume that their different carrier findings are inconsistent.
