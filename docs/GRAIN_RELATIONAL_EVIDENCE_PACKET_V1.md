# M01/M04：关系式证据，而非另一轮分类器调参

2026-09-13。承接[互动响应实测](../reports/grain_measurement_foundation/INTERACTION_RESPONSE_REPORT.md)。
本文件为下一包规格，尚未执行；不把公式或计划计作新实证。

## 1. 要改变的主线决策

同一句“Yes”既可能接受建议，也可能确认拒绝建议。当前失败不是只有语义模型小，
而是“文本亲近度 -> 单分数”的接口未强制保留对哪个命题的哪一种响应。
比较内容边际与关系联合信息，判断个人条件函数的输入需要保留哪些相互依赖。
这是计分结构研究，不追求把Qwen七字母提示改到高准确率。

## 2. 继承及新接口

- [Roelofsen与Farkas2015](https://escholarship.org/uc/item/99k892mp)，
  [作者2014稿](https://people.ucsc.edu/~farkas/papers/polarity_particles_in_Language.pdf)：
  本轮读第1–7页的经验现象/设计要求；回复需前件、极性和话语承诺。
  真正的否定疑问句中，bare yes/no存在歧义，不能用通用负号规则冒充理解。
- [Smolensky1990](https://doi.org/10.1016/0004-3702(90)90007-M)：角色与值的张量绑定。
  本轮核查出版社检索摘要，全文打开失败；不声称复现其认知模型。
- [Coecke等2010](https://arxiv.org/abs/1003.4394)：语法类型约束组合向量语义；
  本轮读摘要，不把下面的有限张量接口称为完整范畴语义模型。

保留完整原文及事件地址，观察器输出联合候选权重，而非只输出一个类别：

\[
J_e(o,c,p,s,z)=P(o,c,p,s,z\mid x_{\leq e},\mathcal O),
\quad E_q(e)=\sum_{o,c,p,s,z}J_e(o,c,p,s,z)A_q(o,c,p,s,z).
\]

o=行为主体/归属，c=当前话语行为、过去报告、未来计划等证据通道，
p=所回应命题，s=对该命题态度，z=条件，O=固定观察器。
若观察器只给分数而非校准概率，应明确称候选权重，不能冒充后验概率。
不把未来计划当已实现行动，也不从单次响应自动推出习惯。

有限二值命题世界可用p,s在{-1,+1}且目标A=ps；这是声明的语义约定，
不是直接对自然语言Yes/No贴正负。需要的是E[ps]，一般不等于E[p]E[s]。
两个联合表可有完全相同边际而E[ps]相反，说明边际读者的缺口是信息结构，
不一定能靠提高回归阶数弥补。

## 3. 一次性执行包

1. 实现有限关系张量、查询收缩、支持区间与未知关系标记。单元测试覆盖共同
   基变换、角色交换、边际相同而联合相反、歧义不变成0分、不输入隐藏真标签。
2. 固定最多3种公开构造世界：关系绑定完整、丢前件、主体/时态绑定错位。
   比较已知关系上界、固定文本工具估计关系、仅内容边际；同一文本预算。
   工具不能读生成器标签。已知关系上界只验证计算，不作为文本识别成绩。
3. 各证据通道分别接既有`profile_fit`，报告个人水平/条件响应及新条件有限作用，
   不先混成“人格总分”。记录语义读取损失与累积损失，包含无可识别分数的实例。
4. 只复用既有PANDORA事件/查询缓存，保留原文地址作关系接口示范；没有人工
   标签时只给覆盖/未解析/路由差异，不给自然行为正确率。不新开MEPS神经实验。

预算：一个新版本目录，CPU数学分钟级；最多256个新增公开NLI对、零新训练、
零Qwen救援调用、零私有数据上传。若现工具不提供所需关系，交付缺失观察与
计算反例，停止该支路并推进M05有限作用/M14制作整合，不再次扩充模板刷分。

## 5. 执行前实例化（未看本包NLI输出）

配置`configs/grain_relational_evidence.json`：3固定种子，每种子128模拟作者。
32条公开对话跨2条件、本人/同事、过去报告/未来意图、接受/拒绝命题、Yes/No。
固定8个联合语义查询，合计256个NLI对；另有只接受声明语法的字面参照。
后者直接从原文字段解析，是计算接口上界，不是开放自然语言识别成绩。
NLI支持分归一化为候选权重，未做概率校准，不把区间称为真实后验置信区间。

三种是信息消融，不是三个新增人群：完整关系、前件缺失、关系边际化。
缺前件时关系接口不运行NLI补猜，返回未解析；有完整信息的已知关系臂保持上界。
边际化臂保留每个轴的分布、删除轴之间的绑定。另有只看回复极性的参照。
每作者8个条件块，每块32个独立模拟事件，共98304事件；三个信息臂复用它们，
不能把复用次数计作新增样本。估计本人过去/未来两个分开的条件函数，
z=.5只验证声明线性条件函数的数值插值，没有编造新情境的真实文本验证。

自然连接复用PANDORA现成query_event_r2的273个查询-事件候选及source_event_r4，
不重跑模型，不把句法时态自动当真实事件时间。未知事实性、语义主体、
目标方向继续为空；该部分验收是关系/原文地址接口，不是自然个人读数。
