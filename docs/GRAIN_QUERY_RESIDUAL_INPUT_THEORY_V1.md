# 查询定向输入、局部系数与 GRAIN 测量方向

2026-09-10，NEXT35结果后的机制整理。不是新增心理构念或完整人格预测器。
前序：[源特征空间](GRAIN_CONTENT_COEFFICIENT_THEORY_V1.md)；
证据：[匹配残差方向实验](../reports/grain_vector_mechanisms/QUERY_RESIDUAL_INPUT_REPORT_V1.md)。

## 1. 三种方向属于不同空间

正文状态 H_u 是 T_u×d 矩阵，d=1536。对于查询q，J_uq是标量原生输出相对
同一正文状态的梯度。V_q是由三名源作者构造的8×d正交行基底。系数密度为

    A_uq = T_u J_uq V_q^T,       Jhat_uq = Ahat_uq V_q / T_u.

V是输出梯度的近似方向；输入PCA32行基底P和本轮新输入基底U是另一对象。
GRAIN方向D_uk=Gc_uk * Hc_u又属于整张token×隐藏维度张量。不能因为它们
都叫“方向”就当作同一种轴。测量作用是

    tau_uqk = <J_uq, D_uk>_F,
    tauhat_uqk = sum_t Ahat_uq(t,:) [V_q D_uk(t,:)^T] / T_u.

后式是可运行的同token加权接点：一边给表达方向，一边给查询条件化读取。
本轮不任意拆句、重新选择token或更新GRAIN参照；新作者的梯度不进入预测。

## 2. 从遗漏的输入方向读取系数

原固定设计Phi0有36列（截距、三项位置和32个源标准化内容分量），旧参数W0。
将源中心化正文投到旧PCA补空间：

    R_u = (H_u - hbar)(I - P^T P).
    E_uq = A_uq - Phi0_u W0_q.
    C_q = sum_u R_u^T E_uq / (3 T_u).

取C_q的左奇异向量U_q（d×8），重新投影/正交化以消除数值误差。对照U_var
来自加权R的8个最大方差方向。两种设计完全等宽：

    Phi_u = [Phi0_u, source_standardize(R_u U)].
    W_q = argmin_W sum_u ||A_uq - Phi_u W||_F^2/(3 T_u)
                      + .01 ||W_nonintercept||_F^2.

这是源目标引导的输入压缩。当前材料只提供H、顺序及GRAIN模式，读取Phi W
不再调用后缀或梯度；但H来自模型前缀，源导数仍是构造阶段的教师信息。
它不是“无监督发现人格轴”，也不是查询词本身就等于真人量表得分。

数学先例是[多输出降秩/岭回归](https://pmc.ncbi.nlm.nih.gov/articles/PMC3444519/)
对响应共享结构与高维输入的共同处理。本实现未求解该文完整的rank约束
回归问题，也未做迭代PLS；这里先隔离一个最小可计算机制。

## 3. 低能量不等于低读取价值

source residual energy retained: variance8为7.071%，query8为2.985–3.192%。
同44列下，query8的留出作用r为T/F .863、N .473、confirmation .576；
variance8为.684/.114/.149。源系数误差也一致下降，而非只有留出相关变高。
因此当前被一般PCA低估的输入子空间中，确实存在可利用的查询读取联系。

它未说明“能量越低越好”，没有搜索最小方差，也未说明所有残差都是信号。
4作者LOO仍是小型机制面板。方向选择的监督标签是模型导数，不是真人Y。
下一步尤其要区分：U_q是否真的查询专属，或只是一般反向读取结构的投影。

## 4. 完整场误差与测量误差可以反向变化

令e=vec(Jhat-J)，把vec(D_k)^T堆成M，则

    complete field loss = e^T e,
    measured action loss = e^T M^T M e.

M^T M半正定且秩不超过4，通常不是单位矩阵。无需新定理即可理解：减少
第一种距离不保证减少第二种距离；第二种距离减少也不证明所有梯度更准确。
本轮三个query8方案完整场误差更大，作用误差却更小，是这个区别的实际例子。
所谓测量核空间仅是对本次D不可见，不是“心理上没有用”。

基底余项与系数误差在完整场中正交；经过M后仍必须保留有符号交叉项。
N query8的作用误差相对零为.319+2.134-1.579=.874。不能由小总误差反推
各分量独立正确，不能靠丢掉交叉项把不同路径相加。幅度和相关分开报告。
