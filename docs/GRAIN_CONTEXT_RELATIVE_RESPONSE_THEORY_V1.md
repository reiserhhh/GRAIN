## 1. The interface that changed

imitating an LLM answer. HM148 asks why that fixed joint function changes its

- The vector displacement induced by a controlled generator assignment.
- The background location at which the frozen function reads that displacement.

Neither is automatically noise. In particular, the induced displacement need
not be one fixed personality direction shared by every task.

## 3. Exact location-by-change response

For an observed high/low vector pair in the unchanged source units, define

\[
m=(z_++z_-)/2,\quad d=z_+-z_-,\quad
R_k(m,d)=f_k(m+d/2)-f_k(m-d/2).
\]

Cross source and application pairs:

\[
R_{00}=R(m_s,d_s),\quad R_{01}=R(m_s,d_a),\quad
R_{10}=R(m_a,d_s),\quad R_{11}=R(m_a,d_a).
\]

Only 00 and 11 reproduce observed text endpoints. The others locate dependence
inside the specified numerical function. The source pooled diagonal is positive
by the HM147 witness construction, not an independent validation endpoint.

## 4. High-order coefficients are not high-order finite actions

The HM147 function is multilinear in four affine slice vectors:

\[
f_k(z)=c_k^\top\bigotimes_{v=1}^4(1,z_v).
\]

For a changed-slice subset S, central subtraction cancels even |S|. Hence

\[
R_k(m,d)=\sum_{|S|\text{ odd}}2^{1-|S|}c_k^\top
\bigotimes_{v\in S}(0,d_v)\otimes\bigotimes_{v\notin S}(1,m_v),
\]

where the factors retain their original slice order. Equivalently,

\[
R_k(m,d)=Df_k(m)[d]+\frac1{24}D^3f_k(m)[d,d,d].
\]

This identity is exact for this degree-at-most-four function, not a
small-displacement Taylor approximation. A pair-sector coefficient contributes
a first-order action depending on m. A fourth-order coefficient contributes
both first- and third-order actions. Calling every high-order source sector
"motion", "synergy" or "personality" is therefore unjustified.

Here d is a paired generation contrast, not a time derivative or a newly
measured human dynamic. This interface can inform subsequent dynamic work
without relabeling the current contrast as a trajectory.

## 5. Accounting without deleting context

Use symmetric two-factor allocations:

\[
L=\tfrac12[(R_{10}-R_{00})+(R_{11}-R_{01})],\quad
D=\tfrac12[(R_{01}-R_{00})+(R_{11}-R_{10})],
\]
\[
I=R_{11}-R_{10}-R_{01}+R_{00},\qquad L+D=R_{11}-R_{00}.
\]

I is already half allocated to each symmetric term. It must not be added again.
These signed allocations are not independent variance shares or psychological
causal percentages. The large source contrast includes self-supported source
separation; its decline cannot be called lost personality information.

Moving m at fixed c is different from changing coordinates. For z'=z-b, define
T(b)=tensor_v A_v(b), A_v(b)=[[1,0],[b_v,I]]. Then c'=T(b)^T c and
f'(z')=f(z). Do not renormalize c'. The translation group action preserves the
same function; input-only re-centering generally does not.
