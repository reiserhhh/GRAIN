## One observation construction

Capture native tail V and full final-row probabilities at all28 layers once.
For a fixed unit x, query q, suffix offset r and layer l, define

    common_V[l,r] = mean_q native_V[l,q,r],
    specific_V[l,q,r] = native_V[l,q,r] - common_V[l,r].

This is finite arithmetic projection, NOT a posterior sufficient statistic or
a trait/noise split. Preserve both arrays. Each new recipient runs its original
prefix. Only the final-row attention output changes:

    fixed_output = sum_i native_p[l,q,i] * current_V[l,q,i],
    installed_output = fixed_output
      + sum_(r in suffix) native_p[l,q,r] * (donor_V[l,q,r]-current_V[l,q,r]).

Use native_p for ALL final-row positions, including the current self position.
Every other output row remains native. Final residual/MLP/self-value recurrence
can respond; no linear final-score assumption. This frozen instrument is a
counterfactual, not the natural decoder or a unique mediation percentage.

Modes: native; common (same five-query mean V for every recipient); foreign
(E<-O,N<-A,A<-N,C<-C,O<-E). Capture includes native outputs; do not repeat them
as a new prediction discovery. Two identity replays on first two units verify
the fixed instrument. Foreign C is a self-control; common C is not.

96*3+2=290 five-query batches/1450 inquiries, cap2200 model seconds including
