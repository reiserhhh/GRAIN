# GRAIN：共享路径与特质专属路径

2026-09-08。根据用户对主线目标的补充建立。本文件是理论扩展及一个已执行的
缓存几何分析，不把拟人化、依恋等尚未运行的查询写成已完成实验。

## 1. 研究对象不由 Big Five / MBTI 限定

Big Five、MBTI 是当前可用的两类入口。拟人化倾向、依恋相关倾向，以及更窄的
行为倾向都可以有自己的“文本证据 -> 向量关系 -> 特质判断”路径。
主目标是共同数学形式与可发展的特质专属算法，而不是每个量表都获得相同的
预测精度。某个特质在当前材料上关联较弱，不使整个机制研究失去价值。

量表之间的相关给出了共享路径的一个候选解释；实验应进一步分开三件事：

- 证据来源共享：不同判断使用同一批经历、表述或行为信息。
- 向量空间共享：证据变化经过的位移子空间部分重叠。
- 功能方向共享：同一个位移会让两个判断以相同或相反方向改变。

相近的量表分数还可能来自输入条件之间的相关。故“量表相关”和“内部路径重叠”
分别测量，再分析它们之间的联系；不需要先把两者视为同一个量。

## 2. 可复用形式与可替换部分

以人格相关查询 q 为索引，当前可执行的局部形式是：

\[
\widehat M_{iq}(d)=a_q^T d,
\qquad a_q=U_qD_q^{-1}b_q.
\]

U_q 是训练得到的位移子空间，D_q 是训练投影的尺度，b_q 是响应读出。
共同的是构造和计算程序；不同的是证据查询、子空间、方向、尺度及可能的
非线性响应。不是所有特质共用一套固定系数。

共享/专属的后续模型族可以写成：

\[
\widehat M_{iq}
=b_{s,q}^T\psi_s(x_i,d,q)
+b_{p,q}^T\psi_{p,q}(x_i,d).
\]

psi_s 是跨查询可复用的响应特征，psi_p,q 是特质专属特征。两者先从多查询数据中
学习，再检验各自的功能作用；名字本身不制造可识别的心理成分。当前8维线性
读出是这个模型族的简单实例，不把现在的8维固定为未来所有特质的最优容量。

## 3. 已执行：T/F 与神经质的路径几何比较

复用 D3B 开发阶段已经冻结的两个 shared 算子。它们使用同一模型、同一个
1536维 block16 站点，但来自不同源作者群。没有新增 forward、人格标签或调参。

对子空间 U_T、U_N，以主角及投影重叠衡量空间共享：

\[
\sigma_k=\operatorname{svd}(U_T^TU_N)_k,\quad
\theta_k=\arccos\sigma_k,\quad
O=\frac{\|U_T^TU_N\|_F^2}{8}.
\]

以最终功能向量 a_T、a_N 的余弦衡量方向相似：

\[
C=\frac{a_T^Ta_N}{\|a_T\|\|a_N\|}.
\]

| 数量 | 本轮结果 |
|---|---:|
| 两个 rank8 空间的投影重叠 O |0.272375|
| 最接近/最远主角 |39.14 /80.97 度|
| 功能向量余弦 C |0.089451|
| T/F 功能向量在 N 空间内的平方投影比例 |0.262506|
| N 功能向量在 T/F 空间内的平方投影比例 |0.204244|
| 归一化两个功能向量用单方向表示的能量比例 |0.544726|

**具体发现：空间部分相近，读取方向却明显不同。** 这使“共同构造程序 + 专属
功能读出”成为有数据支持的设计，而不是把相近的空间强行压为同一特质轴。
O=.272 不是“27.2% 的人格信息共享”；C 也不是 T/F 与神经质问卷的相关。

同维独立各向同性随机子空间的 O 期望为8/1536=.005208，仅作为几何量级参照。
真实模型空间有结构和各向异性，这不是本次的统计零分布或显著性检验。
不同查询目前也对应不同作者群；下一次用同人同材料多查询直接研究功能共享。

脚本：`scripts/analyze_grain_cross_query_geometry.py`。
结果：`results/grain_vector_mechanisms/d3b_conditional_operator_r1/cross_query_geometry.json`。
两个单元测试展示：同一子空间可以有正交读出；基旋转不改变重叠。

## 4. 共享路径怎样连接量表相关

若在一个指定参照总体上，两项分数可近似为共同输入特征 z 的线性函数：

\[
s_q=\beta_q^Tz+\epsilon_q,\qquad
s_r=\beta_r^Tz+\epsilon_r,
\]

则完整协方差是：

\[
\operatorname{Cov}(s_q,s_r)
=\beta_q^T\Sigma_z\beta_r
+\operatorname{Cov}(\beta_q^Tz,\epsilon_r)
+\operatorname{Cov}(\epsilon_q,\beta_r^Tz)
+\operatorname{Cov}(\epsilon_q,\epsilon_r).
\]

这条式子明确了用户猜想的数学位置：在可建模部分，相关由**功能方向与群体
输入协方差共同决定**。若拟合残差对 z 正交，中间两项才消失。即使方向在
普通欧氏空间正交，输入相关仍可使分数相关；反过来，共用空间也可以产生
低相关的输出。这里的心理学问题因此是功能共享，不只是找几何交集。

同人同材料多查询可形成响应矩阵 M_{i,j,q}：作者 i、统一证据变换 j、查询 q。
比较不同 q 对同一次证据变换的响应，再用共享/专属的低秩分解研究路径关系。
这比先分别追求每个问卷的最高预测分数更贴近当前主线。

## 5. 如何逐步省略 LLM 的推导计算

目标架构分为开发时和使用时：

```text
开发时：文本 + 查询 -> 冻结LLM观察器 -> 位移、响应、共享/专属路径
                           -> 学习可复用数学算子与轻量查询条件化表示

使用时目标：多段文本 -> 固定编码器 -> 查询条件化证据聚合
                           -> 共享数学基 + 特质专属读出 -> 连续分数
```

当前成果已实现“内部向量 -> 无后续 LLM 的局部响应近似”。下一座桥是从固定
编码器的文本向量直接得到那些有功能意义的响应坐标。必须给这座桥单独定义
拟合目标：预测既有路径坐标/干预响应，而不是只优化一个问卷分数。

保留已有真人标签作为后续的独立心理连接。新的窄特质先操作化行为证据和查询，
可以先研究路径；其量表或行为指标随后给出该路径测量什么的证据。大量文本
提供的是覆盖更多场景和积累证据的机会，不预设任意文本都对任意特质同样有信息。

关联分别有自己的指标；先发展真实出现的关系，再集中补强解释。
