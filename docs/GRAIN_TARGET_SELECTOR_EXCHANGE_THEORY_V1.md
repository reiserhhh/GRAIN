## 2. Disintegrate allocation and selection

For layer l, head h and query q, let p_qi be its final-token attention row and
B the registered physical body support. Define

    m_q = sum_(i in B) p_qi > 0,
    s_qi = p_qi/m_q,                 i in B.

The native body contribution is m_q sum_B s_qi V_i. A query may change total
allocation m, conditional selection s, or downstream interpretation of the
weighted values. These are different objects; none is defined as noise.

Capture s_q from an untouched five-query pass on identical physical body
prefixes. During a new recipient pass, install

    p'_qi = m_q,current s_sigma(q),i,native    i in B,
    p'_qi = p_qi,current                     i outside B.

The fixed sigma swaps E/O and N/A and leaves C unchanged. The current body
mass and outside weights are preserved at each call. This does NOT preserve
the original native trajectory: earlier interventions can change later query
states, allocations, outside values, MLP activity and response interpretation.

The decoder is causal and all changes are at the final physical query token.
Earlier body rows are unedited. The shared body K/V are checked on all calls;
the native text and question are never replaced by donor text or answers.

## 3. Weighted-value action, not a unique token path

For a single declared call, the exact finite head action is

    delta_o = m_q,current sum_B (s_sigma(q),native - s_q,current) V_i.

This is a weighted-value identity, not a softmax linearization. The correction
is inserted before o_proj and the rest of the frozen decoder is executed.
All heads and blocks act together; the final response is not the sum of
independent per-head effects.

If all body values equal a constant vector, the action is zero because the
selection difference sums to zero. More generally, with a body value matrix V,

    s ~_V t iff (s-t) V = 0,

on the probability simplex. Consequently two different selections can have
the same head action. After output projection, further kernel directions may
become unobservable. No singular-vector/rank search is required to acknowledge
this equivalence; the experiment tests one actual finite action instead.

Different contextual token vectors can already contain mixtures of earlier
text. Token addresses are physical intervention locations, not uniquely
identified psychological evidence atoms. Query wording/length/position are
also part of this fixed intervention, not independently controlled semantics.

## 4. Source-anchored response criterion

For author u/view v, freeze the existing selected/control deletions g_S/g_C
and the SOURCE field d_br. Define the same source action

    X_uvbr = d_br^T [mean_embedding(g_S X_uv)-mean_embedding(g_C X_uv)].

For native and foreign-selector readers F_q and F_q^sigma, retain

    D_uvq = F_q(g_S X_uv)-F_q(g_C X_uv),
    D_uvq^sigma = F_q^sigma(g_S X_uv)-F_q^sigma(g_C X_uv),
    delta_M_brq = Cov_u(mean_v X_uvbr, mean_v(D_uvq^sigma-D_uvq)).

The covariance change is signed and uses identical author/evidence addresses.
Pearson contacts are descriptive companion units, not additive accounts or
personality prediction accuracy. Conditional bootstrap resamples authors,
holding SOURCE fields and this historical N-enriched panel fixed. Keep every
target, space, component, text view and historical split, including negatives.

A change in this contact would demonstrate that the declared selection
intervention participates in the SOURCE-related reader action. Persistence
would motivate value/other-context/response routes, not increasingly fine
attention searches. Neither outcome alone identifies the unique circuit,

## 5. Prior art and applicability

- [Vaswani et al. 2017, Section 3.2](https://arxiv.org/html/1706.03762v7):
  scaled query-key probabilities and weighted values; the primary formulas.
- [Geiger et al. 2021, Sections 1-3](https://papers.nips.cc/paper_files/paper/2021/file/4f5c422f4d49a5a807eda27434231040-Paper.pdf):
  probing and interchange-based causal hypotheses. HM200 is one declared
  intervention, not an exhaustive causal-abstraction proof.
- [Brunner et al. 2020, Section 3](https://arxiv.org/html/1908.04211v2):
  attention null spaces and effective attention. The local kernel argument
  above is an application of established linear algebra, not our invention.
- [Kobayashi et al. 2020, Sections 2-3](https://aclanthology.org/2020.emnlp-main.574.pdf):
  weights must be considered with transformed values. This motivates measuring
  actual response action rather than attention distance alone.
- [Wiegreffe and Pinter 2019, Sections 1-2](https://aclanthology.org/D19-1002.pdf):
  nonunique attention does not by itself negate every explanatory use; foreign
  distributions are interventions, not necessarily natural model behavior.
- [OpenAI/math, pinned three-state foundations, lines 217-232](https://raw.githubusercontent.com/openai/math/adc7f1241b42e322a6451854ab7e4b4c146bf78a/preprints/The-exact-reconstruction-threshold-for-the-three-state-symmetric-channel-September-25-2026/build/sections/02-foundations.tex):
  observation degradation requires an input-independent kernel. The present
  query/evidence-dependent exchange is not established as such a degradation;
  its Jensen result cannot declare personality information lost or noise removed.
