## Objects and Construction

The tested interface is four frozen lexical coordinates g per comment, averaged
from four slices. This is not every GRAIN representation. Match each comment to
its cached E5 vector h; the previous author-OOF map gives psi_q=h*w_q. This is a
lightweight query-configuration proxy, not a native history reader or human truth.

For one author's n-comment support, A contains the retained moment rows and view
mass rows. Finite interior target identification is exactly the row-space test:

    r_q = (I - P_row(A)) psi_q.
    p_q_plus/minus = 1/n +/- r_q/(2*n*max_abs(r_q)).
    gap_q = ||r_q||^2/(n*max_abs(r_q)).

For nonzero r, each probability stays between .5/n and1.5/n, A p_plus=A p_minus,
and the fixed observation changes. This elementary null-space witness is not
noise removal, a fitted predictor, a sharp bound or a confidence interval.
Each query has its own probability pair; they are not one joint new author.

## Mainline Decision and Boundaries

GRAIN summaries and target-vector observations should be parallel joint channels,
not forced into a single four-axis sufficient statistic. Retain their matched
comment identities. Examine author distributions, selection, conditional response
and dynamics of these channels rather than indefinitely tuning a summary reader.

An unexplained residual may reflect missing semantic variables, higher-order
dependence, or both; this packet does not distinguish them. Do not assert that
adding moments necessarily recovers it. Existing Cov(G,H) work is prior local
work, not rediscovered novelty. A new measurement law must specify observation
units and a reference population before author scores or psychological naming.
