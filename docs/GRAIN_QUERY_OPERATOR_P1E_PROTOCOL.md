# P1E: remove the endpoint-gap oracle from the conditional response model

2026-09-07. Zero-forward exploratory analysis chosen after complete P1D.

P1D four-bin additive response shape has held-setting relative error energy.1916
for facts and.07313 for trait attribution, but its inputs include the true neural
donor-gap. This is not an autonomous predictor. Test that missing component now.

Use the SAME deterministic first3/last3 setting split as P1D. Atblock16, compare
three independently reported feature representations: mean evidence-state donor
difference, mean query-state donor difference, decision-state donor difference.
Each is a1536-vector already computed by the LLM; no new inference or human data.

fit_intercept=False) on6 signed pair rows. No tuning, no per-feature selection.
Predict held-out donor-gap from held-out donor/current activations, not endpoints.
Combine that prediction with the P1D degree1 response-shape coefficients fitted
on training settings only. Report gap error and all16-mask effect error versus
oracle-gap shape and no change. Keep all three locations, not only the winner.

An apparent success would mean conditional vector-readout compression in this
small synthetic material family. It still uses donor/current LLM activations,
known question/task and a supplied baseline when reconstructing absolute scores;
it is not LLM-free personality inference, external validity or a causal circuit.
The reused setting family is already exposed; no fresh-confirmatory claim.

Also independently audit P1D complete16-cell/source/output identities, verify the
operator coefficients using sklearn instead of collector lstsq, report the planned
