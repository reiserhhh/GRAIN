# 最后一轮短核对：保留真正新增的机制

请只回应下面几点，不再读文件，不展开新候选，500-800 字以内。模型和 effort 不变。

第二轮你接受了协方差、编码和有限证据范围的修正。Codex 认为你新补的非证据槽
（prompt / sink）竞争是本次最值得保留的机制候选，而不只是一项限制。

1. 我的旧反例明确是没有 sink 的纯内容平均，数学上仍正确。你新增的是另一个模型：
   m(k)=(a0*v0+k*A*vbar)/(a0+k*A)。两者不是矛盾，而是嵌套模型。它给出一个新解释：
   重复可能改变“先验/提示与证据的相对质量”，而非增加独立证据。
   取 a0=A=1,v0=0,vbar=1，k=1,2,4,8，m=.5,.667,.8,.889。
   形状随证据相对基线的方向变化，不必都是凹增；位置权重模型更无普遍凹性保证。
   可以把它作为我们共同优先的新增假说，但曲线只能在指定候选族内判别，不能证明
   内部实现唯一。顺序效应也不只来自rho，语义覆盖、状态转移和非交换更新均可产生。

2. 归一化前范数是有价值的新观测，但不能单凭它唯一识别内部算法。简单 h_k=(1,k)
   经L2归一化后读第二坐标，也得到 k/sqrt(1+k²) 的饱和曲线。不同内部机制可在有限
   k 上近似同一输出。需要相同模型/位置协议、配对干预与跨条件预测，不只看曲线。

3. 四端点响应矩阵的低秩，只说明对所观测扰动的有限低维响应，不足以证明状态更新
   闭合；一次响应矩阵不是已观测的 [C;CA]。BF16 也没有对全部 margin 通用的 .125
   噪声阈值，不能据此做秩门槛。应先核实真实author_effects字段和配对粒度，再看
   作者留出重建与变化范围，不能直接用报告想象数据布局。

4. 你的第二轮把 KL 的 d_M 与 RKHS 距离混同，请修正。MMD是核均值的Hilbert距离，
   KL通常不对称，二者不是同一度量；只有特定局部或约束条件下才可能建立联系。
   作者侧未来行为 Ψ 与模型侧未来输出预测状态继续严格分开。
