## 2. Exact finite construction

Let b=(b1,b2,b3), bi in{-1,+1}, t=+1 for H and -1 for L, and c in{-1,+1}.
Define chi(b)=b1*b2*b3 and

    p(b|t,c)=(1+.6*t*c*chi(b))/8,   p(t)=1/2.

All probabilities are positive. Each category has100 observations; eight cell
counts are20 or5. Marginalizing any unobserved coordinate sums its sign to zero:

    p(b_I|t,c)=2^(-|I|), for |I|<3.

Consequently every class-conditional single and pair law agrees for both t and
c. Each individual event and pair has likelihood ratio1. Yet the complete
configuration has likelihood ratio4 or1/4:

    log p(b|H,c)/p(b|L,c) = c*chi(b)*log4,
    p(H|b,c) = .5+.3*c*chi(b).

Replacing the joint likelihood by a product of one-event likelihoods loses this
operation completely. This is a classical positive parity construction. It is
not evidence that human traits use parity or that all text dependence is useful.
It shows precisely what observation an additive independent-event assumption
would erase; more precise marginal estimates cannot restore that observation.

## 3. Observe every native operation, not only a desired posterior

Let Y_q(b,c) be the actual native reading for query q. On the full four-bit grid
its exact classical character expansion is

    Y_q(b,c)=sum_{S subset {1,2,3,4}} a_(q,S) product_{j in S} x_j,
    a_(q,S)=1/16 sum_x Y_q(x) product_{j in S} x_j,
    x=(b1,b2,b3,c).

There are16 coefficients, all retained. Ideal supplied-table probability has
only a_empty=.5 and a_{1,2,3,4}=.3. Actual expected digit, high/low digit odds,
digit mass and entropy are different observable units. Their coefficients must
not be called psychological information percentages or population correlations.

The coefficient a_{1,2,3,4} is a direct dual test for joint/reference interaction.
It can be nonzero for generic numerical lookup, nonlinear cue response or other
reference contamination. Therefore its existence alone does not identify the
algorithm as Bayesian or the channel as personality-specific. Preserve anonymous
H, unacting B and unchanged-action facts, plus every other coefficient.
No native partial-history experiment is run in HM145. The lower-marginal result
above is population mathematics, not an empirical native partial-history finding.

There is a further alternative: in this three-binary-choice design, chi(b) is
determined by the total number of R/S choices. Matching all single/pair population
marginals does not preserve each individual record's complete token bag across
different b. Only reference reversal c preserves that bag. A native high-order
term can therefore use count parity or table lookup rather than bind the three
occasions to a specific person. This limit is identified during collection,
before native outputs are analyzed; it is not repaired by changing sealed input.
The discriminating follow-up would hold whole-record counts constant with two

no unobserved-B prior can be inherited after giving B actual observations.

## 4. Relating configuration to author measurement

For any supplied positive author account P_u(b), define a conditional reading

    S_q(P_u,c)=sum_b P_u(b) Y_q(b,c).

This is linear in the account, although Y itself may be a nonlinear operation on
the complete evidence. Do not confuse event additivity with account integration.
For P_+=(1+eta*chi)/8 and P_-=(1-eta*chi)/8, 0<eta<1, all first/pair moments
are equal, but exactly

    S_q(P_+,c)-S_q(P_-,c)
       =2*eta*(a_(q,{1,2,3})+c*a_(q,{1,2,3,4})).

The reference-independent joint response and reference-conditioned diagnostic
response are separately measurable. The ideal table yields .6*eta*c. This is
an analytic identity, not another sample of simulated authors or a new empirical
success metric. Repeating the same event bundle is not independent new evidence.

For continuous anonymous GRAIN configurations, the analogous target map needs
a source-defined diagnostic functional on the joint observation space. A source
dependence tensor alone supplies no orientation toward extraversion, attachment
or state. A native diagnostic experiment supplies an operational bridge but not
that unknown natural likelihood. The latter must connect qualified observations,
author/condition/occasion structure and an interpretable behavioral target.
