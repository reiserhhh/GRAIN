# GRAIN V8 Hierarchical Evidence Stack

Status: `DEVELOPMENT_THEORY__EXTERNAL_CONSTRUCT_NAMING_CLOSED`

## 1. Core decision

V8 is not one universal person vector. It is a hierarchy of frozen evidence
objects connected by registered, lossy maps and task-specific read routes.
Different tasks may require different resolutions. No route output becomes a
new GRAIN score merely because it predicts an external anchor.

The hierarchy separates:

1. author-level coarse-graining;
2. population-level relational lifting;
3. independent external instruments;
4. human-readable explanation.

These operations have different estimands and may not be collapsed into one
linear pipeline.

## 2. Author-level hierarchy

Let \(u\) index an author. The maximum-resolution observation is

\[
L_{u,0}
=
X_u
=
\{(x_{uit},b_{uit},c_{uit},o_{uit},t)\}_{i,t},
\]

where \(x\) is token or embedding position, \(b\) records observation
boundaries, \(c\) records condition or situation, \(o\) records expression
opportunity, and \(t\) records order or time.

Local eventization is

\[
L_{u,1}
=
\mathcal C_{01}(L_{u,0})
=
E_u
=
\{e_{uij}\}_{j=1}^{J_u},
\]

with

\[
e_{uij}
=
(z_{uij},\Delta z_{uij},c_{uij},o_{uij},\tau_{uij},q_{uij}).
\]

Here \(z\) is local position, \(\Delta z\) is change, \(\tau\) is duration or
transition evidence, and \(q\) records support and observation quality.

Author-level assembly is

\[
L_{u,2}
=
\mathcal C_{12}(E_u)
=
\left(a_u,\pi_u,B_u,K_u,C_u,U_u\right),
\]

where:

- \(a_u\) is stable relative position;
- \(\pi_u(c,o)\) is selected expression opportunity;
- \(B_u\) is a conditional response operator;
- \(K_u\) is path inertia, transition, and recovery structure;
- \(C_u\) is static-dynamic coupling;
- \(U_u\) is uncertainty, support, and refusal state.

The current frozen V7 48-coordinate representation is an information-rich
proxy for part of \(L_{u,2}\). The V8 canonical object is a further
reference-relative contraction:

\[
L_{u,2c}
=
\mathcal C_{2c}(L_{u,2};\mathcal P_{\mathrm{ref}}).
\]

It preserves canonical landmark-distance shape while deliberately discarding
some row-wide location and scale information.

## 3. Irreversibility and information loss

For the author-level chain, let

\[
\mathcal F_0\supseteq\mathcal F_1\supseteq\mathcal F_2
\supseteq\mathcal F_{2c}
\]

be the information sigma-fields generated by each layer. A noninvertible
coarse-graining leaves unresolved microstate information:

\[
H(L_{u,k}\mid L_{u,k+1},C,O)>0.
\]

For an external target \(Y_q\), if the transformation is frozen, label-free,
and satisfies the corresponding Markov condition, the data-processing
inequality gives

\[
I(Y_q;L_{u,k+1}\mid C,O)
\le
I(Y_q;L_{u,k}\mid C,O).
\]

The task-specific information loss is

\[
\Lambda_{q,k}
=
I(Y_q;L_{u,k}\mid C,O)
-
I(Y_q;L_{u,k+1}\mid C,O)
\ge 0.
\]

This does not imply that a higher-resolution representation must have lower
test error in finite samples. A contraction can reduce estimator variance
while increasing information bias. Prediction compares finite-sample
generalization; the inequality concerns available information.

The word "entropy increase" therefore refers here to increasing uncertainty
about the unresolved lower-level state after coarse-graining, not to a claim
that every deterministic output has larger marginal Shannon entropy.

## 4. Population relational lift

The population object is not another per-author vector. Given a declared
reference population \(P\),

\[
G_P
=
\Gamma_P\left(\{L_{u,2}:u\in P\}\right)
\]

may contain:

- author distance and neighborhood structure;
- covariance and relation matrices;
- population topology;
- group and subgroup differences;
- support and refusal distributions.

The Big5-to-MBTI bridge is one population functional:

\[
R^{BM}_{P,\mathrm{pred}}
=
\operatorname{Corr}_{u\in P}
\left(\widehat Y^{B}_u,\widehat Y^{M}_u\right).
\]

It does not assign a better personality score to an individual. Consequently,
individual Pearson \(r\), axis AUC, and relation-matrix element \(r\) are
different estimands and must not be ranked as though they shared one scale.

## 5. External anchors are not the top of the text chain

Questionnaire and behavioral anchors are independent measurements:

\[
Y^B_u,\;Y^M_u,\;Y^{\mathrm{behavior}}_u
\sim
\text{external instruments}.
\]

A task head reads one or more declared text evidence layers:

\[
\widehat Y_{u,q}
=
h_{q,\rho_q}\left(L_{u,k_1},\ldots,L_{u,k_m}\right),
\]

where \(\rho_q\) is a source-selected route. This is an external calibration
map, not a natural coarse-graining step. A successful map does not rename the
underlying GRAIN coordinates.

## 6. Task routes

A route is

\[
\mathcal R(q,D_{\mathrm{source}},m)
\longrightarrow
(\rho_q,h_q,\theta_q,\delta_q),
\]

where:

- \(q\) declares the task and estimand;
- \(D_{\mathrm{source}}\) is the permitted source dataset;
- \(m\) contains support, stability, and refusal diagnostics;
- \(\rho_q\) lists the layers read by the task;
- \(h_q,\theta_q\) define the head and its source-selected parameters;
- \(\delta_q\) defines refusal and applicability rules.

Task-local concatenation is permitted only as an ephemeral design matrix
inside \(h_q\). It must retain layer namespaces, route provenance, reference
population, and selection scope. It is never exported as a universal person
coordinate.

For the current PANDORA experiment:

| Object | Level | Role |
|---|---|---|
| V7 upstream 48D | information-rich author layer | individual prediction candidate |
| V8 canonical 16D | invariant relational geometry | compressed structure candidate |
| opportunity/format surface | condition and observation layer | explicit conditional evidence |
| Big5-to-MBTI matrix | population relational lift | group-structure endpoint |
| Big5/MBTI labels | external anchors | calibration and evaluation only |

## 7. Evidence contracts

Every layer artifact must record:

- layer ID and object type;
- observation operator and tokenizer;
- source and input hashes;
- reference population;
- support and refusal status;
- uncertainty scope;
- whether labels were available during construction.

Every edge artifact must record:

- source and destination layer;
- deterministic or fitted map;
- fitting cohort and split;
- invariance and information-loss diagnostics;
- failure and refusal conditions.

Every route artifact must record:

- task and estimand;
- layer list;
- head family and parameters;
- source-only selection folds;
- frozen route hash;
- destination labels unavailable during selection.

An LLM may render these artifacts, but it may not change scores, routes,
relation matrices, uncertainty, or refusal states.

## 8. Falsification gates

| Edge or object | Required test | Failure interpretation |
|---|---|---|
| \(L_0\to L_1\) | replay hash, boundary/tokenizer perturbation, label permutation | eventization is not reproducible |
| \(L_1\to L_2\) | grouped split-half, matched-condition strangers, support curve | author object is opportunity or format dominated |
| \(L_2\to L_{2c}\) | retained-information and task-specific loss profile | canonical contraction removes required evidence |
| \(L_2\to G_P\) | fixed reference, author bootstrap, subgroup/support sensitivity | population object is sample-specific |
| author layer to anchor | source-only nested CV and paired bootstrap | no individual external connection |
| population lift to relation anchor | route frozen before bridge, permutation, author and head-refit bootstrap | relation structure is unstable |
| evidence to LLM | replay consistency and evidence traceability | renderer contaminates measurement |

## 9. Current falsifiable hypotheses

### H-LAYER

Different external tasks select different evidence routes under source-only
nested validation.

### H-ROUTE-DIRECT

A source-selected router is not materially worse than the information-rich
upstream representation for individual prediction.

### H-ROUTE-STRUCTURE

Source-selected heads retain nonzero held-out Big5-to-MBTI relation structure
without bridge-assisted route selection.

### H-UNIVERSAL-VECTOR

One fixed vector is optimal for individual prediction, population structure,
and explanation.

The current architecture treats H-UNIVERSAL-VECTOR as rejected. H-LAYER,
H-ROUTE-DIRECT, and H-ROUTE-STRUCTURE require executable evaluation.

## 10. Claim boundary

This hierarchy is a technical measurement theory. It does not establish that
any layer is a personality trait, that Big Five or MBTI is the final ontology,
or that GRAIN is clinically valid. A positive route result licenses a
task-specific external connection only. Psychological naming requires
independent evidence designed for that purpose.
