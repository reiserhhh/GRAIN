  from frozen original source scores, leave-own-source-out where appropriate;
  it is a baseline only, not a recalibration of candidate outputs.

  not only correlation. Preserve all source4 negatives and denominator sizes.
- Composition checks: reverse/JVP/FD agreement; exact input/map hashes; numerical

pass one and not the other. These are exploratory utility rules on reused people,
not human-effect significance tests; do not treat4 directions as4 independent authors.
