## Question that changes the construction decision

Can frozen GRAIN vectors define an executable relative-author likelihood whose
common menu bias cancels, rather than a function interpolating native LLM scores?
Which author differences remain unidentifiable even with exact observations?

HM139's conditional linear target extension is stopped. M03/F03 already model
choice/opportunity and HM135 already implements logit likelihoods. This packet

The statistical laws below are established conditional-likelihood tools.

## Declared world, not an inferred psychological law

For author u and known two-option menu j, let d_j be the difference of the two
frozen GRAIN text coordinates, with one source-only scalar normalization.

    logit p_uj = kappa_j + d_j^T theta_u.

kappa is shared across authors, arbitrarily different across menus. Independent
binomial trials, fixed known exposures, a known chosen option and a common logit
scale are assumptions. They are not properties proved for natural text.
No latent parameter is trained from Big5/MBTI or copied from a native reader.
The score estimates a relative expressive-choice parameter under this law.

Given author's successes x/n and a fixed reference's y/r, condition on K=x+y:

    p(x | K, delta) proportional to C(n,x) C(r,K-x) exp(x d_j^T delta),
    delta = theta_u - theta_reference.

The shared kappa and reference level cancel. This is not subtracting a context
mean from the embedding. Context exposure/selection counts remain in the output.
Forced acts have no choice trials in this model; their language is NOT declared
uninformative to every other GRAIN channel. Unknown offers/qualification are
not repaired into observed choices.

## Finite execution, no accuracy search

1. Freeze code/config/input hashes and all12 source/new menu differences.
2. Calculate the full15-dimensional observable quotient, source null witness,
   new-menu action on source-unidentified directions and common-shift gauge.
3. Independently enumerate joint binomial probabilities at multiple common biases
   and reference levels. Verify that conditioning yields the same declared law.
4. Execute3seeds x36 paired author parameter configurations x3 worlds: shared
   context, unequal exposures, personal-context alias. Retain all counts/profile
   values; no Pearson/AUC/leaderboard or selecting a best world/parameter.
5. Source-only2D basis and fixed121-point prior grid yield likelihood/posterior
   mean/covariance and per-menu expected contrast. This grid is finite posterior
   integration, not hyperparameter/model search. Application truth is not a
   scoring input. Reused reference counts induce dependence across comparisons.
6. Test forced-only, no common support, missing/unknown menu qualification,
   private truth/ID fields, zero-information margins and duplicate menu addresses.
7. Construct an exact personal-context alias: theta=0, eta_uj=d_j^T h_u versus
   theta=h_u, eta=0. Same probabilities, different asserted source of difference.
   Also keep the common utility/temperature scale ambiguity explicit.

## Decision rules

A usable finite constructor requires the conditional law, hashes, numerical
scorer and invariances to agree. Failure is retained, not rescued by a new prior,
reader, axis or parameter grid. No claim of human accuracy/psychological validity.

If it works, retain relative conditional-choice evidence as ONE author channel,
not the whole personality instrument. If the personal-context alias persists,
record it as an observation-design/structural-identification boundary. Full goal
is not completed by this packet. Next experiments must address whether actual
text supplies the qualifying events/offers and calibrated response law, not
whether this toy model can be made to predict its own simulated labels better.
