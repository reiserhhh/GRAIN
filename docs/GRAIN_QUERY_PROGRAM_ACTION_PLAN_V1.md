## 问题与固定比较

M06定位了上层问题区作用，但它不推出浅层问题区也占同样比例。
使用已冻结NAV10的R_real读者与来源算子：A重建上层P/Q，B直接读出目标投影；
B的token-only和4层版本均保留。唯一新机制变量是查询条件化状态是否参与运算。

对于4层B，按已有两来源chart把当前变化分为共同文本C、问题P、末端Q。
比较全部、仅C、仅P/Q；不重新拟合系数或幅度。A同时实际重建状态与运行既有编译
仿射函数，核查同一程序的两种表达一致。token-only比较既有uniform与semantic_order：
词袋不变的角色互换是否仍被区分，不把静态词汇差异当作绑定。

材料为M06的16段公开编写文本，加3目标领域×本人/同事高低互换×前后顺序的12段
公开材料，共28文本×既有3查询=84输入。M06低落16行原生值只供最终比较，可复用；
新材料与其余查询重新执行固定教师，绝不供独立程序读取。既有材料是已暴露诊断集，
新增材料在调用前冻结，不声称新真人或大样本泛化。实际token词袋是否相等单独核查。

## 数学与依赖

线性读者与状态仿射估计可精确交换复合次序；这是标准线性代数，不是新定理。

学生/教师输出分工参考[知识蒸馏](https://arxiv.org/abs/1503.02531)；
本轮仅核读两文摘要，没有复现其训练目标或引入新蒸馏训练。
