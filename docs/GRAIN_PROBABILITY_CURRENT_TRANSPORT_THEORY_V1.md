# GRAIN: probability-current transport and the conditional observer field

2026-10-10 JST. HM98 theoretical companion. This is standard finite algebra
and Markov Hilbert geometry applied to an actual measurement interface, not
an original interpolation, exterior-algebra or personality theorem.

## 1. Three objects must travel separately

An event point x is not an author law P, and neither is a target observation
kernel F_q. Source event coordinates can be turned into a fixed positive
partition T(x), but accurate addresses alone do not determine the relation
between events in a new context. Preserve the following levels:

    event representation -> probability coordinates T_c
    author evidence law P_u,c -> transported law T_c^T P_u,c T_c
    conditional target relation F_q,c -> score <P_u,c,F_q,c>.

The cochain F here is a declared frozen vector observer on local event pairs,
not the author's human trait or a full native LLM answer. A context includes
wording, occasion and observation protocol; not every such change is nuisance.

## 2. Positive transport, duality and endpoints

Let T have m application rows and n source columns, T_ij>=0 and T1=1. Define

    P_s = T^T P_a T,
    F_a,transport = T F_s T^T.

For every pair array, <P_a,F_a,transport>=<P_s,F_s>. Positive unit mass remains
positive unit mass. If P_a is stationary, P_s is stationary. If two laws have
the same occupancy and symmetric traffic, their transported laws do too.
For a closed signed current D=-D^T with D1=0, T^T D T remains a closed current.
This is the relevant finite chain/cochain compatibility, not a full claim
about all simplicial degrees or a FEEC PDE convergence theorem.

Changing the source cochain by an exact gradient g_i-g_j gives an application
gradient (Tg)_a-(Tg)_b. Its closed-current integral is zero. Endpoint effects
cannot masquerade as a new cycle merely because the source coordinates moved.
For open trajectories the gradient remains meaningful and is NOT discarded.

## 3. Bounded interpolation is not a target observation law

For distinct source points x_i, one fixed Shepard-type coordinate map is

    T_i(x) = ||x-x_i||^(-2) / sum_j ||x-x_j||^(-2),
    T(x_i) = e_i.

It is source-interpolatory, positive and bounded, with no target scores needed
for its construction. It is a nonlinear function of point coordinates. Even
four-dimensional points can give a centered probability matrix of rank17
on18 points; HM97's six-area rank6 is not a universal bound on all functions
of those points. Source cardinality is an algebraic property, not evidence
that the interpolation preserves an unseen target relation.

## 4. Rank and observable amplitude are different

A row-stochastic map need not be a Euclidean contraction. Use an explicit
reference p on application nodes and r=T^T p on source nodes. For r>0 set

    A = diag(sqrt(p)) T diag(1/sqrt(r)),
    C = A-sqrt(p)sqrt(r)^T.

Jensen gives ||Tf||^2_p <= ||f||^2_r. The weighted constant direction is
transported exactly, and C acts on the orthogonal zero-mean subspaces. Let
s_i be its singular values. The induced skew-current operator has singular
values s_i*s_j, i<j. In particular its norm is s_1*s_2, possibly small even
when the node map and the exterior map have full numerical rank.

For D1=0, define D_bar=diag(1/sqrt(p)) D diag(1/sqrt(p)). Then

    D_s,bar = A^T D_bar A = C^T D_bar C.

No author choice is removed here: p and r describe the diagnostic metric,
while actual occupancy/traffic/law arrays remain stored separately. Uniform
mapping annihilates cycles, while an identity map preserves their amplitude.
This is observation dilution, not proof that the original text lacks signal.

## 5. The conditional observation defect is a separate mechanism

On application pairs define

    R_q,c = F_q,c(actual) - T_c F_q,source T_c^T,
    r_q,c = cycle(R_q,c).

For a closed author difference D,

    actual author contrast
      = <T_c^T D T_c,F_q,source> + <D,r_q,c>.

The second term is not sampling error. More observations reduce sampling
variation but need not eliminate it. If all fundamental cycle contrasts
agree, r_q,c=0; otherwise the reusable observation law itself is incomplete
on the declared support. This criterion keeps individual and group contrasts
central instead of optimizing a global vector reconstruction metric.

A known event-correspondence diagnostic removes geometric addressing error
only for the DESIGNED correspondence. It does not assert that different acts
in different situations are psychologically identical. If a defect remains,
one cannot fix that particular source kernel merely by assigning its nodes
more accurately. Nor does this prove that every other source-derived law is
impossible. It motivates a family of conditional relationship operators.

Even the best result-after scalar rescaling of one source cycle kernel retains
only cos(F_source_cycle,F_actual_cycle)^2 of the actual norm squared. This is
a geometric upper bound on an amplitude-only explanation, NOT an accuracy
estimate, independent prediction or a fitted model to deploy.

## 6. Consequence for the GRAIN/personality mainline

The base formula should not identify event coordinates with a universal
personality map. A target observer is a conditional field whose common and
specific parts must be constructed from source observations:

    F_q,c = transported shared relation + condition-specific relation,
    score_u,q = sum_c <P_u,c,F_q,c>.

Keep condition choice, within-condition response, endpoint and current terms.
Do not explain a transport failure away as small random error, and do not
call every conditional remainder noise. HM98's positive common orientation
and large conditional defect are both evidence about this frozen observer.
They do not yet label either part as a human personality factor.

Next development should distinguish event representation transport from
relationship-operator transport using the same evidence units. It should seek
shared/specific operators with declared conditions, not improve the already
source-exact lookup or repeat interpolation/teacher/head/rank grids.
