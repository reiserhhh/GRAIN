# M06：共享内容、查询条件化与末端作用的有限交换

2026-09-13，采集前冻结。决策问题：不同目标共享的究竟是题目前的共同证据，
还是题目/答案通道中的通用倾向？不再以相关表或34×34网格代替机制检验。

## 继承与新增

[Geiger等，2021](https://arxiv.org/abs/2106.02997)用表示交换与高层反事实对应检验
因果抽象；本地对应是固定block输出中有明确角色的状态交换。
[Goldowsky-Dill等，2023](https://arxiv.org/html/2304.05969)区分节点定位和路径定位，
并用指定材料分布上的未解释作用检验局部解释。本包是**节点组交换**，不冒称
完成了论文的逐边path patching、全网络因果抽象或人类心理因果发现。

新增为同一原文四查询的共同输入/不同读法操作图，连接GRAIN的有地址输入和
查询路径。冻结旧M30B向量函数仅做参照；不拟合、不按新结果重新定方向。

## 材料与干预

4个既有查询：负性唤起、低落、两者复合、AI意图归因（固定独立反证作为远端对照）。
2种新事件/措辞×唤起高低×低落高低×本人/他人体验包装=16文本；共64模型输入。
两句话的高低版本已在模型调用前核对token长度一致。四状态在同框架/同归属/同查询
下须同长度、同问题token和同分区；不使用padding来改变材料、不选最好结果。
归属对比含其自然包装变化，不将它当作纯字符级单token干预。

在既有block16输出分C/P/Q：C为问题前所有状态（文本及共同提示），P为非末端问题区，
Q为最后答案位置。C在自回归模型中不依赖后面问了哪道题；实际数值同一性另核对。
对每个因素的一次低→高变化，保持另一因素固定，交换三组状态的全部2^3组合。
64条有向证据边×6个非平凡交换=384suffix，加64完整前向及64原值重放=512调用。
另将三个情绪查询的同证据变化delta-Q加到不相关查询的基底Q，保持其C/P与文字不变，
48次作用检验末端方向的跨任务可运输性；总560调用。若不相关目标也动，说明该末端
方向不是查询专属机制；不能仅凭Q有作用就宣称是纯答案偏置或心理构念共通。
端点000/111用已重放一致的两自然输入值；全状态交换为供体值因为形状/位置一致。
900秒采集上限，状态原子保存，可按同一冻结包继续；不重启完整包、不扫层号。

定义F_q(S)为S中分组来自供体、其余来自基底的输出。有限Möbius交互：
I_q(S)=sum_{T subset S}(-1)^(|S|-|T|)F_q(T)。
总变化=sum_{S nonempty}I_q(S)；三组Shapley分账为phi_j=sum_{S contains j}I_q(S)/|S|。
这是标准有限差分/组合分配恒等式，不以分账值冒充唯一生物路径比例。
冻结仿射函数不直接用C，故在该边界C交换效应为0、P/Q无交互；原生偏离这一结构
能指出轻量程序缺少什么上下文运算，而不是再拟合权重来隐藏差异。

## 输出与结束

完整原生/仿射水平、两类内容对每查询的作用、主体包装差、C/P/Q及交互分账，
共同C数值同一性、独立logit/数组/组合公式审计。按两个措辞分别报告，再汇总。
对照不是心理构念完全无关的公理；若广泛串入，应记作共同证据或通用评价混合的
候选，而非删掉跨载荷。2种材料不做人群p值。0.01只是事前分辨率，不是显著性阈值。
不读取真人/MEPS/问卷；不新增persona训练、不改问题或数值单位。
