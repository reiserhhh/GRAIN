# GRAIN：条件、时钟、参照与目标如何同时成立

2026-09-10。NEXT12 理论接口。连接4W、choice/路径、群体参照、查询读出与
第六至八轮逻辑实验；不是新计分器或新量表。现有发布规范和锁箱不变。

## 1. 系统不能只保留一条“文本 -> 分数”的线

同一材料至少支持三个不同对象：

| 对象 | 输入和条件 | 比较单位 | 要保留什么 |
|---|---|---|---|
| 作者参照位置 | 声明机会/材料采样下的表达与选择 | 作者相对固定总体 | 群体偏移、条件选择、表达配置 |
| 表达路径与响应 | 带事件/互动顺序的多段表达 | 路径、变化、条件响应 | 改变、维持、转移及先后联系 |
| 模型查询读取 | 指定排列、查询、模型、运行精度 | 同材料模型输出/干预差 | 模型如何把可见证据用于该问题 |

三者可以共用向量和函数，不能只因共用代码就共用测量解释。
输出时须带对象地址，而不是把每一种变化都汇成同一个“人格分数”。

## 2. 四个时钟不能互相偷换

记作者记录为`D_u = {(x_i,c_i,tau_i,role_i,id_i)}`。本文id仅为事件配对键，
不是评分特征。明确四类索引：

- `tau`：实际事件/互动时间。支持响应、先后和恢复类问题。
- `j`：文本内部token/slice序号。支持文内路径；没有时长就不称现实速度。
- `v`：人为抽样视图。重抽三份评论不是同一作者在三个真实时点的状态。
- `pi`：给模型或界面展示的排列。它可以不同于真实事件发生顺序。

模型层深又是计算索引，不是第五种人的时间。动态研究必须说明沿哪一个索引
运动；同一份问卷Y在重抽视图内为常量，是设计属性，不排除真实状态变化。

## 3. 显示不变性与真实动态可以兼容

若每个事件保留可靠时间，令kappa按时间及预先规定的并列规则恢复自然顺序。
对只改变展示排列、但完整保留事件元数据的pi，有：

`kappa(pi D) = kappa(D)`。

因此`g_event(D)=h(kappa(D))`对任意展示排列不变，但h仍然可以强烈依赖
自然事件顺序。**稳定位置与动态响应并不要求删除顺序，而要求正确区分操作。**

有限例子：真实事件`(时间,数值)=[(0,0),(1,1),(2,3)]`，末减初为+3。
六种展示排列恢复时间顺序后都得到+3；若真正换成`[(0,3),(1,1),(2,0)]`，
则得到-3。两组均值相同。若去掉时间，两种不同历史都可能显示为`[3,1,0]`，
仅凭这个输入不能判断究竟是界面反转还是表达过程相反。
这些命题由`tests/test_grain_clock_contract.py`的有限反例检验，不冒充真人实证。

现有PANDORA人工反转实验改变的是展示。12人干预证明固定LLM对它敏感；
不代表那些评论本来就是一次连续会话。时间缺失或并列无法解开时，应保留
集合/文内路径对象，或声明规范展示规则，不能伪造一个自然事件时钟。

## 4. where的选择与where条件下的表达同时保留

沿用[线索利用与条件推论文档](GRAIN_CUE_UTILIZATION_AND_CONTEXTUAL_INFERENCE_V1.md)
中的完整历史条件化结构，而不是新发明一个独立句子假设：

\[
p(D_u\mid\theta_u,\mathcal F)
=\prod_i p(c_i\mid\Omega_i,H_i,\theta_u,\mathcal F)
         p(x_i\mid c_i,\Omega_i,H_i,\theta_u,\mathcal F).
\]

`Omega_i`为当时可用机会，`H_i`包含此前历史，`F`为采样/交互设计。
第一个通道关注选择，第二个关注条件下的表达。若机会本身被作者影响，
还要建模机会形成，不能把它当外生噪声条件化掉。若只有选择记录而没有
机会分母，只能先测“已观察选择组成”，不把它直接解释成自由偏好概率。

GRAIN的实际工作对象可保存为向量包而非被迫合成一个总分：

`M_u = (observed_choice, conditional_expression, event_path, query_links; R0,F)`。

R0是源固定参照总体。条件固定使表达更可比，但也减少选择的观察范围。
这保留了旧rind/C1/C2设计原则；不是回到“删掉topic或situation”的降噪思路。

## 5. 哪些不变性有数学依据，哪些须由测量目的选择

| 变换 | 合理要求 | 不能从中推出的结论 |
|---|---|---|
| 带完整事件键的展示置换 | 规范事件评分不变；模型读取可另有展示响应 | 文本所有顺序都无用 |
| 向量坐标旋转 | 评分函数和参照同时搬运，结果协变/保持 | 任意不搬运参数的旋转结果都可比 |
| 作者真实选择或表达转移 | 应允许变化，并声明机会条件 | 因为会变就应被删除 |
| 更换总体、编码器、精度或查询 | 新的对象地址，需要分别核对 | 同一名称就是同一测量函数 |
| C2两方向等权平均 | 得到该展示群的不变量 | 原始自然方向的奇项不含作者关联 |

[Deep Sets](https://papers.nips.cc/paper/6931-deep-sets.pdf)与
[Janossy pooling](https://arxiv.org/abs/1811.01900)给集合函数与排列平均提供
构造依据，但不替研究者决定什么应该是集合、什么应该是一段有序过程。
前一轮原生平均没有自动提高自评关联，正说明目标选择需要独立于模仿指标。

## 6. 与本轮目标遗漏的连接

设F为原生查询、f为固定公式、p为轻量读出。三种任务要分别验算：

1. `F-f`：公式构造保留了什么；先剥离运行条件差。
2. `f-p`：给定输入与训练支持，哪些计算可提取。
3. `Assoc(F,Y), Assoc(f,Y), Assoc(p,Y)`：各程序连接到作者哪一种效标。

这里“剥离运行条件差”是对照记账，不是把个体分数里的差异全部消掉。
新实账发现T/F运行条件与公式遗漏会抵消。单看端点相关，既可能误判没有
缺口，也可能在错误目标上持续优化。下一步应逐查询确定目标与输入，再考虑
GRAIN提供的条件、群体参照、路径如何帮助构造，而不是强行共享一个最佳头。

## 7. 本轮闭合的接口与下一机制

已闭合的是逻辑接口：展示稳定性可以与真实动态共存；choice不是无条件偏好；
source视图不是现实重测；模型保真度不是效标保留；运行条件是评分函数的一部分。
它们各有定义、数学例子或实际缓存依据，不要求现在采集新的临床样本。

仍可继续研究的具体分岔：固定标量的非线性链接，还是新增条件向量，能解释
原生至f的非仿射余项？先用旧构造与缓存区别这两种机制，再决定补哪个函数。
暂不为缺失真实事件时钟发明参数，也不要求GRAIN仅剩模型查询这一条观察路线。
