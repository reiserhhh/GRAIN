# M01/M09 → M02：话语/命题双账与原文版本关系 r1

本轮在运行前冻结。目标是将上轮尚未接入的当前请求、省略与显式纠正变成
不同的证据操作，不继续提高抽象身份NLI精度。

## 双账与操作

话语事件保存发话者、受话者、直接请求候选及其原文地址；命题账保存句内行为者、
查询、意愿/过去报告、条件、相对时间线索和源问题。请求别人帮助不记录为本人帮助。
省略只在唯一前问或显式“previous answer”引用下替换局部人称/极性，不复制人格标签。
当前适配器接受明确裸Yes/No和I do/did/not辅助词结构；其他省略继续保持缺失。

`new/repeat/alias/revise/retract`接已有M02 `active_records`。
明确更正替换同主张版本，显式同内容复述为alias；撤回不等于负向回答。
不同问题产生问题局部事件参照，**不是物理事件唯一ID的自动识别**。
比较新时点和纠正旧主张，分清作者变化与证据认知变化。

## 实验和预算

8条公开主对话：两来源支持条件×意愿/过去报告×两措辞。每条依次包含前问、
回答、复述、纠正、新时点问题/回答、撤回、直接请求和他人引语。
6挑战检查裸回答负问、缺前文纠正、复述内容冲突、当次请求、引语、歧义省略。
实际使用旧冻结Stanza，最多100种文本、300秒；不训练、不NLI、不读取MEPS。
条件采用上一包来源片段TF-IDF参照，新文本只transform，不新增人口常模。

三个计分参照：无版本的所有报告均值、最后一个句子极性、M02版本/事件账。
主指标是操作是否更新正确目标、复述是否改变有效证据、纠正/新时点是否被混同；
不以大样本相关或分类近100%作为目标。刺激预期只用于运行后的对照，不进入解析。
评分为每身份/条件下活跃主张的有限均值，不与旧NLI来源模型的单位硬接。

## 继承范围

[ISO对话标注](https://aclanthology.org/2020.lrec-1.69/)提供功能依赖与被纠正片段的
区分，本轮复读§2.1–2.2。[Dalrymple/Shieber/Pereira](https://arxiv.org/abs/cmp-lg/9503008)
将省略作为受约束的语义解析问题；这里只继承保留源语义/局部替换的动机，不宣称
实现高阶合一、量词作用域或完整英语省略消解。

验收交付原文到双账、每前缀数字、替换/复述/撤回作用对照以及未解析挑战。
有用有限机制可进入M01/M09，但剩余开放自然语义与独立行为含义必须保留。
