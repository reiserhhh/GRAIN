## Exact toy law and selection, not inferred human personality

Each person has t=+1(H) or -1(L), balanced prior, and choices b in{-1,+1}^3:

    p(b|t,c)=(1+.6*t*c*chi(b))/8, chi(b)=b1*b2*b3.

Draw A and B independently, then retain only b_B=-b_A. The selection probability
is1/8; marginal class priors remain1/2 but paired classes become correlated:

    p(t_A,t_B | retained)=(1-.36*t_A*t_B)/4.

gives P(H_A|record,c)=.5+.3*c*chi(b) and P(H_B|record,c)=.5-.3*c*chi(b).
No unobserved-B prior is inherited. The correlation from selection is not a
discovered interpersonal/psychological relationship. Verify via independent
enumeration of all original256 class/path cells for each c.
