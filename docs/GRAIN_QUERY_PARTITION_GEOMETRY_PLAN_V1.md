# NEXT72: source-query evidence as a common log-partition potential

2026-09-11. PLANNED after NEXT71; generic normalized-Gaussian development stops.
Develop a mathematical interface to the real query-directed selection program,
not another attention22 accuracy/anchor search or another capacity account.

## Mainline question

Mass sensitivity and relative-value response differed in NEXT70/71. Can the
existing source-compiled query program expose them as first/mixed derivatives
of one potential, and identify whether a GRAIN effect is small because evidence
has little value contrast, little directional sensitivity, or poor alignment?
The deliverable is a query-directed moment representation for subsequent numeric
function construction, not a new questionnaire predictor or refitted attention.

## Data and frozen boundaries

Reuse audited `logic_source_query_selection_v1`: source4LOO/new8all4, bothqueries,
all4GRAINdirections, bothfixed readout modes and the same own/other/shared Qbar.
Use original pure K,V,dK/mask/RoPE/readout inputs and source bank; no current Q,
new native calls, fits, Y, MEPS, source changes or feature rankings. Preserve its
original code/manifest and NEXT49 reporting amendment. No new layer/head search.

Freeze new code/tests/plan before numeric application. Each query has a frozen
local neural query anchor, not the P/Q token-index sets or a psychological intention.
Current K/V may themselves contain query context; keep that dependency explicit.

## Compile, not refit

For each permitted head, render original logits l, readout values v=g^T V and
key-direction logits d_f=Qbar^T dK_f/sqrt(h). All masks/RoPE/grouped KV rules
must match the existing program. Define the finite, masked partition:

    Psi(s,t)=log mean_allowed exp(l+s*v+t*d_f).

At zero compute:
- mean v and mean d (first derivatives);
- variance v, variance d, covariance(v,d) (Hessian entries);
- uncentered U=E[v*d], centering B=E[v]*E[d], response R=U-B;
- rho=R/sqrt(Var(v)*Var(d)), undefined when variance iszero, never imputezero.

Sum head R must reproduce all frozen NEXT50 key actions. Do not compare mean d
and R with SSE as if their units matched; U/B/R do share units. Keep head signs
and cancellation rather than selecting beneficial heads. Build public aggregates
over authors, query, anchor, mode and factor; author/head/token rows stay private.

Synthetic tests: mixed derivatives by finite differences; covariance PSD; constant
value or direction giveszero R; logit common-shift invariance; masked tokens;
actual scalar first derivative reproduces the old key-action formula. Do not use
finite differences at unstable arbitrary scales to manufacture a numerical effect.

## Read the empirical geometry and stop

Report first/second-moment magnitude, signed U/B/R, head cancellation, and
value-spread x directional-spread x alignment. Relate these to already-existing
own/other/shared fidelity with no new arm selection or recalibration. Different
authors/queries are descriptive configurations, not psychological variances.

Decision: specify which **joint moments** a source-trained numeric reader must
preserve, versus which marginals alone are insufficient. If the centered response
is small due cancellation, preserve both terms in future scalar construction;
do not tune away a bad-looking derivative. If geometry is degenerate, keep that
record and return to the missing input relation, not a new Gaussian/alpha sweep.

0newneural/fits/Y. One application+replay and account, max90CPU seconds. Freeze
numeric outputs before comparing cached native targets; public report/theory,
hashes and dependency map updated. Finish the card without a broader statistics
search. This develops a reusable local mechanism while the full goal stays ACTIVE.
