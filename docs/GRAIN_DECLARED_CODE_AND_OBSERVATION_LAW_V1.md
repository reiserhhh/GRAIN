# Declared Code and Actual Observation Law

2026-10-09. Theory companion to finite HM53; not a completed personality model.

## Actual finding

Changing only the two low/high digit cues did not reverse the native ordering
of any of the twelve own-behaviour contrasts in either source or application.
Both source-code operators continued to have strong raw-digit effects. The
observer changes amplitude without implementing the declared inversion.
This identifies a separation between declared code and actual observation
law. It does not identify the operation uniquely as a numerical bias or a
conceptual representation, because the native recoding premise failed.

## Units

Let E denote actor-bound event evidence and Q the requested target. Let C be
the query-conditioned hidden state, D the continuation/readout operation and
kappa the declared code. An observed score is

    y_raw = D_kappa(C(E,Q))
    y_declared = (1-kappa)/2 + kappa*y_raw.

The second equation is an exact coordinate rule. It does not assert that
D_minus implements a semantic reversal of D_plus. Code compliance is a
separate empirical property, not a guarantee supplied by the prompt.

Likewise, an intervention action

    A(E,d) = L(C(E,Q)+d) - L(C(E,Q))

may come from a readout offset, an injected judgement/evidence payload, a
changed observation operation, or their context-dependent mixture. Strong
action and correct actor orientation alone do not separate these objects.
Do not put d directly into an author's stable parameter merely because it
steers an answer. Qualification and author aggregation remain separate.

## Exact finite contrasts

For source code s and receiver code kappa in {-1,+1},

    R(s,kappa) = a0 + a_s*s + a_k*kappa + a_sk*s*kappa
    a_ij = sum(s**i * kappa**j * R(s,kappa))/4.

This is the standard Fourier expansion on C2 x C2. It identifies signed
output contrasts without assuming hidden-state equivariance. A large a0
under failed native inversion is not a proof that semantic information is
absent. Characters are not psychological factors or information shares.

Source deltas under the two codes have cosine .9853--.9938 in the same model's
ordered suffix-slot coordinates. Geometry is descriptive here: no canonical
cross-model alignment, concept group action or universal metric is claimed.

## Next discriminating operation

Use the same d, with fixed sign, on both receiver evidence variants E0 and E1:

    M_sigma = [L(C(E1)+sigma*d)-L(C(E0)+sigma*d)]
              - [L(C(E1))-L(C(E0))].

An output-only constant log-odds addition has M_sigma=0 exactly. A nonzero
value rules out that simple null but is also compatible with nonlinear
payload injection. Additional behavioural structure is needed to identify a
reusable reading program. Do not rename this mixed difference a commutator:
the two finite-difference operations commute algebraically.

## Research discipline

Teacher fidelity and numerical accuracy are tools, not the main theoretical
claim. Improve them only when a specified mechanism cannot otherwise be
distinguished. Retain useful finite effects without erasing them because the
full theory remains open; do not substitute fitted teacher agreement for
independent evidence of human personality or for an LLM-free scoring rule.
