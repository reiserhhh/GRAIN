# GRAIN M3 Cross-Family Confirmation Protocol

Status: draft only; not sealed and not executable as confirmation.

## Purpose

The next run must test whether the M3 two-phase micro-to-meso objects survive
outside the Gaussian RFF/RBF near-family used in V2 discovery. It must not
reuse discovery seeds or tune gates after oracle results are opened.

## Generator families

The confirmation matrix must contain at least:

1. smooth spline/GAM response fields with local knots;
2. piecewise or Voronoi response fields with discontinuous boundaries;
3. random non-kernel tanh/softplus MLP response fields;
4. state-dependent joint \((S_t,C_t)\) transition worlds;
5. a null-author world for response identity and personal transition;
6. an exact stable-position/state observational alias.

The estimator must not receive generator family, knots, partitions, hidden
width, latent states, prototypes, or planted rank.

## Actual perturbation worlds

Protocol metadata and data-generating perturbations must be separated.

| World | Required data perturbation | Licensed check |
| --- | --- | --- |
| MNAR | response-dependent missing fixed cells | sensitivity/refusal |
| technical dependence | shared noise or duplicated technical streams | reliability refusal |
| mixed coarsening | blocks containing distinct conditions | coarsening refusal |
| reference drift | shifted reference-population response law | version/refusal |
| representation drift | held-out non-orthogonal map | transport refusal |
| non-random fixed phase | assignment depends on author/state | associative-only license |

Passing a metadata guard proves contract enforcement only. Statistical
detection requires a separate registered diagnostic.

## Primary confirmation gates

Across predeclared positive worlds:

1. occupancy truth correlation: bootstrap 95% CI lower bound \(>0.80\);
2. personal transition log-skill versus pooled transition: lower bound \(>0\);
3. shared transition skill versus pooled occupancy: lower bound \(>0\);
4. null personal transition: CI contains zero and absolute mean \(<0.003\);
5. public response-projection correlation: lower bound \(>0.50\);
6. unseen-condition response \(R^2\): lower bound \(>0\);
7. nonlinear incremental held-out \(R^2\): lower bound \(>0\) and at least
   75% positive seeds in each nonlinear world;
8. relative occasion-state correlation: lower bound \(>0.60\);
9. null-author response reidentification AUC: CI contains 0.50;
10. all exact aliases and registered protocol refusals pass.

The conjunction fails if any required world fails. Correlation with planted
\(h_u\) cannot substitute for incremental held-out prediction.

## Freeze procedure

1. Freeze code, config, thresholds, world counts, and seed derivation.
2. Save SHA-256 hashes before generating oracle truth.
3. Generate observations and truth into separate paths.
4. Fit and hash predictions while truth is inaccessible to the runner.
5. Open truth once, compute the registered decision, and prohibit retuning.
6. Obtain an independent mathematical/code audit.

Until these steps occur, V2 remains
`M3_TWO_PHASE_MICROKERNEL_DISCOVERY_PARTIAL`.

## Mechanism-atlas confirmation additions

The later mechanism-atlas discovery adds five candidate intermediate objects.
A confirmation run must not merely repeat the matched dictionaries used during
discovery. It must include:

1. equal-low-order distribution worlds generated by non-atomic mixtures,
   skew families, and copula changes while the estimator dictionary is frozen;
2. nonlinear condition and partner response generated by splines,
   discontinuities, and non-polynomial neural maps rather than Hermite terms;
3. hidden-state or switching dynamics with unknown order and matched observed
   lag-one/lag-two summaries;
4. exact first-order edge-multiset path aliases with higher-order motif changes;
5. independently parameterized pairwise and three-way mixtures with
   target-specific knockout;
6. actual actor, partner, dyad, opportunity, and occasion components.

The confirmation gate must score held-out predictive increment, own-truth
partial geometry, cross-talk, and knockout specificity. Same-author AUC alone
is insufficient because any surviving channel can identify an author.

## Claim boundary

Even a complete synthetic pass would establish estimator existence and
refusal behavior only. Human-text persistence, psychological interpretation,
macro construct discovery, personality validity, and clinical use require
later data stages and remain closed.
