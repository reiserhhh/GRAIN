# Persona 表达、作者推断与 GRAIN 群体通路

日期：2026-09-07。状态：证据综合与拟议协议，尚无本轮新模型实验结果。

## 1. 研究判断

用户提出两条可连接的路径：人格提示如何影响模型表达，以及人的表达如何使模型
形成关于作者的人格判断。可检验的连接是**共享概念表征与可迁移的计算操作**，
不是预设两个任务互为逆函数，也不是预设某个人格词对应唯一固定向量。

```text
persona 条件 -> 角色绑定 / 概念状态 / 任务操作 -> 表达
作者文本    -> 来源绑定 / 证据状态 / 查询操作 -> 关于作者的判断
                                      ^
GRAIN：在独立文本上定义作者位置，检验哪些内部操作在邻近作者间可迁移
```

需要分别识别：模型怎样模仿某类人、模型怎样理解某类人的文字、这种理解与真实
心理差异有什么联系。前两者可先做机制实验，第三者不能由合成闭环自动推出。

## 2. 定向研读的证据链

这是原始论文、作者项目和代码的定向核对，不是系统综述或逐篇复现。2026 年两项
Anthropic 工作按技术报告／预印本引用，不视作已经独立复现的学界共识。

| 研究 | 已有证据 | 对本项目的作用与边界 |
| --- | --- | --- |
| [Persona Vectors, Chen et al., 2025](https://www.anthropic.com/research/persona-vectors) | 对比不同特质条件下的模型激活，可提取影响模型行为的方向。 | 支持“特质指令到内部表征再到表达”的生成端；对象是模型行为，不是真人 Big Five。 |
| [TalkTuner, Chen et al., 2024](https://arxiv.org/html/2406.07882v3)；[作者页面](https://yc015.github.io/TalkTuner-a-dashboard-ui-for-chatbot-llm/) | 从对话中的隐藏状态读取模型对用户属性的表征，干预后回应改变；最好的读取探针并非最好的控制探针。 | 将自我 persona 与用户模型连接起来。研究属性含年龄、教育等，数据大量为合成，不能外推为 Big Five 有效测量。 |
| [Emotion Concepts, Sofroniew et al., 2026](https://arxiv.org/abs/2604.07729)；[作者技术说明](https://www.anthropic.com/research/emotion-concepts-function) | 情绪概念表征随当前文本相关性变化，并能因果影响模型输出；不是持续不变的全局情绪分数。 | 支持跨情境概念与行为之间的内部中介；必须追踪“当前是谁的状态”，不能把出现的情绪概念都归给作者。 |
| [Function Vectors, Todd et al., ICLR 2024](https://arxiv.org/html/2310.15213v2) | 跨示例聚合、经因果筛选的注意力头激活可以在新上下文触发相应任务。 | 聚合的可能是“如何运算”，不只是“关于什么”。向量仍依赖接收模型的后续计算，不等于独立算法。 |
| [Sparse Feature Circuits, Marks et al., ICLR 2025](https://arxiv.org/html/2403.19647v3) | 聚类大量上下文的内部状态／效应，再发现共同计算图；一个簇仍可能含多个机制。 | 群体机制搜索已有方法先例。GRAIN 的增量是独立作者结构与条件分层，不应声称首次对多样本聚合电路。 |
| [Jacobian Lens, Gurnee et al., 2026](https://transformer-circuits.pub/2026/workspace/index.html) | 跨上下文平均内部导数，将中间层表示映射到可言说概念，并测试读写、推理和跨情境使用。 | 直接提供跨样本追踪的数学工具；词汇读出不完整，概念列表也不能表示主体／关系绑定，更不是人格通路已被证明。 |

阅读范围：Persona Vectors 为作者说明与仓库；TalkTuner 为论文方法、数据附录和
作者页面；Emotion Concepts 为摘要、作者说明及部分原始技术章节；Function
Vectors 为方法和平均激活相关章节；Sparse Feature Circuits 为聚类／干预章节；
Jacobian Lens 为方法、限制和代码 README。不得把本笔记称为所有全文精读。

## 3. 双向关系怎样数学化

### 3.1 生成与推断不必相同，却可以共享内容

若真实生成过程为 p(X | z,c)，标准贝叶斯关系为：

\[
p(z\mid X,c)\propto p(X\mid z,c)p(z\mid c).
\]

z 是待推断属性，c 是表达条件。这说明生成模型与推断可以关联，但后验还需要
先验和条件信息。LLM 的 p_theta(X | persona 指令,c) 不自动等于真人生成分布。
例如 X=z+c 时，同一句对应的 z 无法在未知 c 下唯一求逆。

因此先比较两种任务是否调用可交换的概念状态，再研究角色／条件造成的变换。
允许生成端和识别端不对称；只成功一个方向也是需要解释的实质结果。

### 3.2 最值得测的是“读写作用”，而不只是向量夹角

在同一模型、同一层／位置的坐标中，令 v_G 为生成端的激活位移，s_R(h) 为识别
端对高／低属性答案的对数概率差。小剂量写入的局部作用为：

\[
\Delta s_R = s_R(h+\epsilon v_G)-s_R(h)
\approx \epsilon\,\nabla_h s_R(h)^\top v_G.
\]

v_G 是写入位移，梯度是读取敏感度，两者不必相同。在线性可逆坐标变换 h'=Th
下，v'=Tv，r'=T^{-T}r，所以 r'^T v'=r^T v；普通余弦则不具有这种一般不变性。
这属于标准微分／线性代数，不是新定理，也不能以一阶近似代替有限剂量干预。

这是 TalkTuner“最优读取不等于最优控制”的一个数学上合理的理解，不声称该
论文已经证明了上述解释。优先比较受控干预的效应，而不是要求两个向量重合。

跨层不能直接比较坐标。Jacobian Lens 的工具原理是：

\[
J_\ell=\mathbb E_{X,t,t'\geq t}
\left[\frac{\partial h_{L,t'}}{\partial h_{\ell,t}}\right],\qquad
\operatorname{lens}(h_\ell)=\operatorname{softmax}
\bigl(W_U\operatorname{norm}(J_\ell h_\ell)\bigr).
\]

这不是把中间向量直接找最近人格词，而是估计后续计算如何使用它。我们的首轮
可只测指定查询分数的梯度／VJP 和有限 patch，不计算全词汇、全位置 Jacobian；
须命名为任务限定的敏感度分析，不能宣称复现了完整 Jacobian Lens。

## 4. GRAIN 怎样进入群体机制分析

### 4.1 Identity 是分层依据，不是喂给模型的答案

先用作者的一组文本 A，在固定参照总体下得到 GRAIN 配置 g_u；再在不重叠文本 B
测机制。不得用姓名、账号或已知人格标签直接做 persona 提示来“证明识别”。
账号也不自动等于唯一自然人。参照系、距离、组数／带宽只在开发作者上确定，
检验作者与开发作者分离。内容去重必须跨 A/B 和作者执行。

当前 VM05 的 g 是 16 维排序 landmark-distance 几何代理，不是完整 GRAIN。
首轮若复用它必须明示限制；不能将代理邻域的结果推广到整个 GRAIN 配置体系。

### 4.2 平均的是受控效应，保留个体差异与异质性

在固定查询 q、条件 c、模型坐标和干预位置 e 下，对作者 u 的片段先求平均效应
a_{u,c,q,e}。再按独立 g_u 到组中心 g 的距离加权：

\[
w_{ug}(c)=\frac{K_\rho(d(g_u,g))I(u\text{ 在 }c\text{ 有可比材料})}
{\sum_v K_\rho(d(g_v,g))I(v\text{ 在 }c\text{ 有可比材料})},\quad
\bar a_{g,c,q,e}=\sum_u w_{ug}(c)a_{u,c,q,e}.
\]

K 可用标准非负核；没有支持样本时不外推、不输出组效应。先按作者聚合，避免
发帖多的人支配机制。报告有效样本量 n_eff=1/sum(w^2)、效应协方差、同号比例，
以及作者级 bootstrap 区间，不只报告平均热图。

须同时保留两个问题：未经条件固定的 choice 总关联，以及在可比 topic、长度、
格式／表达机会下的条件关联。后者不是把前者当作污染全部删除。

**一个容易遗漏的机制：平均向量可能消掉稳定的读写配对。** 同一坐标下：

\[
\mathbb E[r^\top v]=\mathbb E[r]^\top\mathbb E[v]
+\sum_j\operatorname{Cov}(r_j,v_j).
\]

例如一半样本 r=v=+1，另一半 r=v=-1，每个样本的作用都是 1；但两个平均向量
都是 0。因此“平均不出人格轴”并不能排除可重复的作用关系。应直接聚合配对
效应，辅以条件协方差；相反，平均效应非零也不证明每个作者使用同一条路径。
这是数学例子，不是我们数据已经呈现该机制的证据。

### 4.3 什么结果才构成 GRAIN 的增量

在未参与分组或选路径的新作者／新片段上，GRAIN 邻域能否更好地预测或迁移干预
效应？对照为全体平均、条件-only 邻域、相同大小／密度随机组、条件层内打乱的
GRAIN 配置。不能用用于形成组的同一张效应图证明“组内效应相似”。

若成立，支持作者结构能组织 LLM 的证据处理方式；若只有 topic-only 成立，说明
当前通路主要由任务／材料组织。若均值相同而协方差不同，研究“作用配置”而非
强迫所有人共享一个方向。均不能在没有独立心理联系时命名为人格通路。

## 5. 最小实验顺序（拟议，不是已执行）

### P0：限定材料与可读性

复用固定 checkpoint、tokenizer、角色模板与已有 observer。首轮只用一个明确
行为倾向，例如主动发起社交，并保留无特质词的行为定义版本；它不代表完整 E。
材料使用已授权来源或受控合成，不读 MEPS 私人量表，也不拆开 bridge 标签。
测试模型是否理解来源绑定、否定和答案编码；现有 native Big5 的反向答案编码
问题必须纳入，不以模型对任意 A/B 标签的偏好解释人格机制。

### P1：生成／识别 2 x 2 交叉干预

| 提取方向 | 写入表达任务 | 写入作者识别任务 |
| --- | --- | --- |
| persona 高低条件对比 v_G | G->G：表达端正控制 | G->R：关键跨任务检验 |
| 行为证据高低条件对比 v_R | R->G：反向跨任务检验 | R->R：识别端正控制 |

生成任务用相同题目、角色与前缀，在答案生成前采激活；输出用预先定义的行为
候选及其对数概率差评分，不能只找 trait 词是否增多。识别任务使用独立、无 trait
名称的行为材料。正控制也必须在未用于提取方向的题目／模板上测试。

先执行同坐标、小剂量和有限 patch。若需角色变换或低秩 DAS，另立有参数拟合的
分支，限制秩、训练材料和选择预算，不能把反复拟合到成功叫“无训练证明”。

每格记录基线、效应／区间、剂量曲线及语义／格式对照：随机等范数方向、主体
互换、引用者互换、无关特质查询、trait 名改行为释义、答案代码反向、输入长度。
后置查询只影响其后的计算，不应要求已经编码的相同前缀随查询改变。

若只有 G->G，说明能操控表达，尚未找到读写桥。若 G->R 与 R->G 仅在原 trait
词上成立，优先解释为词汇／模板通路。跨词汇、来源、输出编码仍可迁移时，再
将其作为较强的共享计算候选。单次合成生成-识别闭环可能只是模型刻板印象。

### P2：GRAIN 作者条件化效应地图

只在 P1 找到可重复效应后扩大到作者材料；先检查 A/B 可分、条件支持和有效人数，
再定作者规模。按 §4 对照判断作者配置是否提供超出任务／主题的信息，不默认大
样本或 identity 加权一定改善。候选电路须以有限干预复验，梯度排名仅作定位。

### P3：数学替代

冻结可重复的部位后，用低秩映射或小型条件算子预测干预响应／教师判断，并在新
作者与新条件上检验。分别报告行为拟合与干预效应拟合，避免“拟合输出”替代机制。
冻结 LLM encoder 加小算子仍依赖 LLM；真正不依赖 LLM 的版本需另用非 LLM 输入
特征做对照。机制结论冻结后，才安排独立的真人心理联系验证。

## 7. 本轮落点与贡献边界

本轮仅完成证据综合、读写作用形式化、群体效应加权设计。没有新数据性能结果，
没有证明 GRAIN 相近作者共享通路，也没有宣称 Big Five 的唯一神经方向。

潜在贡献不是发明 activation patching、平均 Jacobian 或核加权，而是把已有
机制工具连接到**跨作者、条件化、可检验的心理证据使用过程**，区分公共任务
操作、群体共享作用和个体剩余差异。作者画像是相对于参考群体的结构，不是身份
标签本身；真人心理解释必须有额外证据。

现有长跑继续保持原配置。本笔记不以它们完成为理论工作的前提，但任何新增
GPU forward／反传需要另排资源，不抢占队列。本轮不调用 Claude、不安装依赖、
不读私人文本或外部心理标签、不运行新模型、不 push。
