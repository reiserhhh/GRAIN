# NEXT31: factor the native token reader without confusing energy and action

2026-09-10, planned next after NEXT33. Question: can a small shared hidden-direction
basis plus position-specific coefficients preserve useful GRAIN/query actions?
NEXT33 recovered whole conditional scores but not signed configuration changes.
Do not keep tuning its final score. This experiment selects the next *mechanism*.

## Inputs and scope

- Reuse the12 frozen body-gradient fields from `run_grain_native_material_reader.py`:
  four old authors x three queries (T/F, N, confirmation), common body coordinates,
  four existing GRAIN-modulated directions per author, measured tangent checks.
- Verify the actual cache directory from its manifest and prior report. No raw
  text inspection, new model calls, questionnaire reads, MEPS or lockbox access.
- These are scalar native gradients at natural full states. They are NOT the
  NEXT32 mean-null candidate Jacobians. Do not silently transport between them.
- Varying body lengths require an explicit normalized position grid. Store the
  normalization convention; token index, author ID and human scale are not traits.

## Three distinct comparisons

1. **Within-field compression diagnostic.** At fixed ranks1/2/4/8 compare low-rank
   gradient reconstructions with a uniform reader. Report gradient-energy error
   AND errors in the four already-measured GRAIN directional contractions.
   A factorization using the current field is compression, not unseen-author
   prediction. Use a fixed seeded numerical SVD approximation when needed; never
   call approximate low-rank output the globally optimal psychological solution.
2. **Shared basis across authors.** For each query, leave one of4 authors out.
   Build the hidden-direction basis using only3 source gradient fields, with
   equal author mass, rank at most8. Project the held gradient into that basis
   as an explicitly oracle coefficient diagnostic. Does the direction vocabulary
   transfer, even if individual position coefficients are still unknown?
3. **Small no-held-gradient position reader.** On the same3 sources, fit just
   a source mean reader and fixed degree0-3 polynomial position coefficients.
   Define density K_u(t)=T_u J_u(t), source loss weighted1/T_u per token, and
   predict J_hat=K_hat/T_held. This preserves the declared token-coordinate
   contraction. Compare constant and varying-position versions; no basis/rank
   selection from held effects. Declare numerical estimates, not universal laws.

All arms report contractions before/after approximation, sign, amplitude error,
within-field and source-disjoint results separately. Leave the old reference
and finite-difference measurements untouched. The point is to tell apart:

    shared hidden directions / position coefficient variation / absent support.

## Bound and branch

- Zero neural calls. At most12 source basis fits and24 small position fits;
  within-field factorizations are diagnostics, not additional learned predictors.
- Prefer randomized SVD with fixed seed and maximum rank8, no dense input metric.
  Check resource cost after the first query; preserve partial complete units if
  the predicted total exceeds240 seconds. No accuracy/regularization search.
- If a common basis preserves held actions but fixed position coefficients do not,
  next construct a content-conditioned coefficient reader. If even the shared
  basis loses action, preserve query/author-conditioned bases rather than impose
  one universal axis. If simple position works, test it on a separately declared
  finite native input intervention, not by renaming its axes as personality.
- Do not claim the scalar full-state findings have solved conditional pair
  candidate reading; use them to design the next finite construction in that
  exact input/target regime. Early-encoder transport follows a useful reader.
