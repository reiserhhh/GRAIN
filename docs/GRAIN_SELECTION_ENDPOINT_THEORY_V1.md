# 选择程序与读出程序：从GRAIN方向接到最终模型作用

2026-09-10，NEXT51。[完整实验](../reports/grain_vector_mechanisms/SELECTION_ENDPOINT_REPORT_V1.md)。

## 1. 一个已经实际接起来的组件

在同一作者材料上，已有如下可复算的局部链条：

    原文与GRAIN方向 -> H16与D_f -> 原生上游运输 -> K,V,dK_f
    -> 源固定查询引子Qbar_q -> 完整key增量uhat_q,f
    -> 源固定后续读头rbar_q -> 端点组件kappahat_q,f.

最后两个函数在新8作者上不需要他们自己的query向量或端点梯度；源4构造
后就固定使用。N/确认组件作用r=.973/.978，查询差别r=.963，恢复59.2%
的原生差别RMS。这是可用的**GRAIN方向到指定模型判断作用**的接合，不是
新问卷预测分数。编码与前置运输仍在，下一步移除其中实际可替换的计算。

具体计算为：

    a_q,t = softmax_t(Qbar_q^T K_t/sqrt(h) + mask_t)
    uhat_q,f = W_O concat_heads sum_t a_q,t(V_t-o_q)(Qbar_q^T dK_f,t/sqrt(h))
    kappahat_q,f = rbar_q^T uhat_q,f.

位置旋转、RMSNorm导数、GQA及mask均在真实数据上核验。rbar是相应query的
源作者后续梯度均值；不是用人类Y拟合的因子权重，也不是临床解释器。

## 2. 查询意义不是固定在一枚向量里

同一个增量向量在两个读头下可以符号不同，因为最终测量的是双线性配对
r^T u，而非向量本身的坐标名。NEXT50使用共同局部w*，交换引子导致差别
r=-.890；NEXT51经实际后续读头后为+.868，固定源读头为+.447。

这不是推翻旧结果，而是定位了条件：局部共享读头下的差别不能当作最终
推论差别。当前K/V/dK、查询引子和后续读头三处都可包含查询条件，不能
只找到其中一处就把整个特质命名为那一条轴。它也说明不同量表词可共享
部分选择操作，却通过不同下游配对获得不同的作用。

## 3. 误差可以相互抵消，不能假设一项一项独立累加

固定程序相对实际组件的误差满足：

    e = rbar^T uhat - r^T u
      = r^T(uhat-u) + (rbar-r)^T uhat
      = e_select + e_read
    E[e^2] = E[e_select^2] + E[e_read^2] + 2E[e_select e_read].

新8查询差别：.00772920 + .00077699 - .00412020 = .00438599。
因此固定源读头在这里可以比“实际读头读取近似向量”更接近实际组件；它
部分补偿了选择近似。不能据此说真实梯度不正确，也不能把总误差下降等同
每个内部步骤都更准确。源4的交叉项为正，机制组合必须保留有符号配对。

完整H16导数tau的计算链与旧原生梯度一致到4.777e-6；其中这个组件在新8
查询差别上的投影为+.277。由此可以把组件放回全链分析，但不能把借用了
其余原生项的tau-kappa+kappahat包装成独立预测器。

## 4. 下一步的发展原则：同一个函数产生状态与运动

当前仍借用原生K/V/dK。若要移除这段运行依赖，应构造一个固定函数Psi，
同时产生状态和其运动：

    X22hat = Psi(X16)
    dX22hat_f = D Psi(X16)[D_f].

随后用实际norm/K/V矩阵和冻结Qbar/rbar计算同一组件。不能独立回归X22与
dX22，再把互不兼容的两组输出叫作一个理论函数。NEXT52先检验点式与因果
上下文式的同一小函数族；如果原始状态近似好而运动不好，这个差别本身
会指向需要哪些运输机制，而不是继续改善本轮端点小数。

[FitNets](https://arxiv.org/abs/1412.6550)提供中间表示作源模型知识的先例；
[Sobolev Training](https://arxiv.org/abs/1706.04859)说明可把函数值与导数一起
作为学习对象。NEXT52最初只拟合源状态，导数由同一个函数解析给出并另行
评估，并未预先实现Sobolev导数损失。这里的贡献在GRAIN同材料方向/查询
作用/源固定提取的接合，不是宣称首创中间表示学习或链式法则。
