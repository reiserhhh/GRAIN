# GRAIN：输入等价类、可识别目标与呈现条件

2026-09-10。逻辑图L04/L15/L18/L20/L31的接口说明，不引入新量表或心理因子。
相关实验：[NEXT08b方案](GRAIN_LOGIC_INPUT_ORDER_PLAN_V1.md)。

## 1. “表征丢失了什么”必须相对目标函数来问

令完整材料T经过输入算子phi得到x=phi(T)，目标函数为t(T)。
我们需要一个g满足t(T)=g(phi(T))。在指定材料集合上，存在这样的集合函数g
当且仅当：

    phi(T1)=phi(T2)  =>  t(T1)=t(T2).

证明很简单：必要性由函数单值性直接得到；充分性是在每个phi的原像上取共同
的t值定义g。若进一步要求连续、可测、低复杂度或能从有限训练样本学到g，
还需要额外条件。这是通过等价类分解的标准数学事实，不是新的人格理论定理。

这条逻辑比“线性拟合不好”更强也更具体：两个输入完全相同而目标不同，任何
只看该输入的确定函数都无法同时精确复现它们。换成LightGBM、MLP或更强的
回归器并不能补回已经不被phi区分的输入；但若phi不同，线性失败仍可能只是
读取器不合适。需要用实际材料反例判断，而非根据低r猜测。

当前phi是分别编码评论后再聚合。E5在每条评论内部仍编码词序，所删除的是
评论之间的排列，不是“整个文本没有语义/语序”。这与
[Deep Sets](https://papers.nips.cc/paper/6931-deep-sets.pdf)的集合输入结构相符；
该文的表达能力结果不意味着我们固定1024维均值已经保留全部集合信息。

## 2. 反转群提供一个可以实测的最小等价类

J将完整评论列表反转，J²=I。独立评论均值对J不变。更一般地，任何只依赖
这批评论向量的无序分布的程序，也对J不变。定义：

    t_plus(T)  = [t(T)+t(JT)]/2
    t_minus(T) = [t(T)-t(JT)]/2
    t = t_plus + t_minus.

t_plus反转不变，t_minus在反转时变号。在{T,JT}等权测量设计下，这两个
函数正交。对于任何反转不变预测p，有精确误差式：

    E_pair[(t-p)^2] = (t_plus-p)^2 + t_minus^2.

因此t_minus²是该两元素轨道上的不变读出的误差下界。
它不等于原顺序自然数据上的不可约误差，更不等于某种人格比例。
[Janossy pooling](https://arxiv.org/abs/1811.01900)通过对排列敏感函数求平均构造
排列不变函数；当前只对C2反转群精确平均，不是对12!种排列完成积分。

在同一等权轨道内，若作者标签Y保持不变，则奇项与Y的轨道内协方差为0。
这是设计对称性，不证明原始自然语序中的有序特征不含作者信息。把自然语序
改成随机呈现，与观察作者如何按真实时间表达，是两个不同的测量问题。

## 3. 失配存在以后，有三种不同的发展方向

| 所需对象 | 对呈现顺序的要求 | 合理的发展方向 |
|---|---|---|
| 复现一个固定LLM读取过程 | 可以对顺序敏感 | 输入保留顺序，并学习相应的条件运算 |
| 对一袋既有记录给稳定作者位置 | 不应被任意界面排序主导 | 研究对称平均目标、规范顺序或显式呈现误差，而非盲目复制敏感性 |
| 研究作者的真实表达过程 | 实际时间/互动顺序是观察对象 | 保留有序过程和时钟，在条件匹配下解释其响应 |

三者可以并存。不能因为某个新变量让LLM模仿成绩更好，就把它升级为人格指标；
也不能因为它受呈现顺序影响，就把它从所有动态研究中删去。GRAIN的多观察
平面需要为这些不同对象保留不同的函数与参考，而不是强行共享一个总分。

这直接呼应4W：what的材料内容不变，who的作者不变，改变的是呈现条件；
when必须注明是实际发生时间还是模型读取次序。当前人工反转只检验后者。

## 4. 一个可计算的首阶顺序接口

冻结每条评论的h_j，构造：

    v(T) = (1/n) sum_j s_j h_j,  s_j = -1 + 2j/(n-1), j=0,...,n-1
    p_order(T) = p_mean(T) + a_q' v(T)/s_train.

v(JT)=-v(T)。不加截距、不将v按源均值中心化，保证新增项严格反转奇对称。
a_q只由源作者的模型目标误差学习，s_train是源RMS向量尺度。

这个接口区分两件事：输入开始包含顺序信息，和训练后的系数真的读到目标
顺序响应。第一件事由代数保证，第二件事必须由新材料端点检验。
仅有第一件事，不足以说已经补全了条件推论机制。

## 5. 与旧配置研究的关系

旧S6在block16内部保持评论均值，但改变token配置，已经证实内部函数可变。
本轮则保持独立E5评论向量多重集，改变整段材料呈现。两个phi在不同空间，
不能视为同一实验的重复，也不能把它们的误差百分比直接相加。

当前R=c-m_G中的GRAIN参照项，在改变材料排列后可能也变化。本轮没有给新
排列重算GRAIN分数，所以反转实测只报告c与完整函数f，不能伪造R的变化真值。
下一连接应依据这次结果决定是否值得做GRAIN有序平面或上下文P/Q搬运，
而不是用未测的GRAIN变化去解释已测的配置变化。

## 6. 本轮可闭合与仍开放的边

- 可闭合：实际E5输入的不变性；给定反转端点的精确误差下界；一个新输入
  统计量的变换规则；现有源拟合系数能否迁移到该呈现干预。
- 仍开放：原始63作者T/F读出误差的+.141非仿射效标贡献究竟有多少来自这种
  运算；两种样本/干预地址不同，不用本轮12人响应替代前者的效标记账。
- 下一类机制：有序输入的表示可用性、读取算子的条件适应，以及人格解释
  所需目标应对哪些呈现变换不变。每种机制的成功标准分别定义。

这些区分不是为了否定已有信号，而是避免把补齐“模仿LLM”自动当成补齐
“解释作者”。用明确的输入等价类、目标和干预，将两条主线真正接起来。

## 7. 有序预测器、源训练支持与自然方向

对一般有序预测p也可定义p_plus/p_minus。精确地：

    E_pair[(t-p)^2] = (t_plus-p_plus)^2 + (t_minus-p_minus)^2.

仅观察t(T)-p(T)可能让两种误差抵消；成对目标增加了可区分的约束。
后续[四格实验](../reports/grain_vector_mechanisms/PAIRED_SUPPORT_LOGIC_REPORT_V1.md)
在相同输入与固定惩罚下发现T/F局部响应收益，却没有通用的作者效标收益。
因此“可表示、在源上可学习、可运输、与作者效标相关”必须分别有接口。

还有一个与choice/when紧密相关的区别：同一作者两方向展开时，奇项和固定Y
正交；每位作者只取自然方向时则不必正交。例如令t_minus(T_u)=Y_u、
t_minus(JT_u)=-Y_u，两方向协方差恰为0，原方向相关却为1。
两者不矛盾。对称化是改变观察设计/目标，而非证明奇项“只是噪声”。
本轮源native的原方向奇项与Y确有小幅关联；仍需区分自然表达信息和模型偏置，
不单靠这个相关选不变性规则。此结论也不恢复旧的“所有误差趋零”泛化。
