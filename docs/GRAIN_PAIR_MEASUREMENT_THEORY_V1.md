## 2. Two different decompositions must not be conflated

For route r=(a//4,b//4), let m_X(r)=sum_r p_X and m_rho(r)=sum_r rho.
Define nu_kq(r)=sum_r rho*psi/m_rho(r) on observed reference routes.

    S_route = sum_r [m_X(r)-m_rho(r)] nu_kq(r)
    S_within = sum_(a,b) p_X(a,b)[psi_kq(a,b)-nu_kq(r)]
    S = S_route + S_within.

Proof: expand both terms. sum_r m_rho*nu=sum rho*psi, and
sum p_X*nu=sum_r m_X*nu. Their latter terms cancel exactly.

Both terms remain in the measurement. The conditional reference is an
ACCOUNTING reference, not residualized data with condition information removed.
S_route and S_within have units of averaged binary-target reading differences,
not causal personality fractions or directly comparable scale scores.

## 3. Evidence actions depend on the companion evidence

Write t_ij=psi_kq(a_i,b_j), row_i=mean_j t_ij, column_j=mean_i t_ij,
and T=mean_ij t_ij. Removing an early event and renormalizing gives

    T_(-i)=(n_A*T-row_i)/(n_A-1)
    delta_i=(T-row_i)/(n_A-1).

The late formula is analogous. Removing one in each window has mixed action

    T_(-i,-j)-T_(-i)-T_(-j)+T
      =[t_ij-row_i-column_j+T]/[(n_A-1)(n_B-1)].

This follows by expanding the remaining (n_A-1)*(n_B-1) entries. The fixed
reference cancels from each difference. These equations need no iid assumption.
They give an addressed signed response matrix, not one unconditional importance
number per token/event. Current computation is at comment-vector resolution,
not attention-head or token localization.

The action is removal from a numerical event SET with unchanged cached vectors.
It is not a deletion/reencoding of raw language, an intervention on the person,
or a proven action in the LLM's internal memory. Missing support is unavailable,
not a neutral score. IDs and timestamps verify addresses, not human provenance
or quoted-person ownership; those remain the collector's responsibility.
