This experiment distinguishes these on the existing interface. It does not
identify a unique circuit or equate a model score with human personality.

## Numerical Construction

For author u, view v, target q, the natural deletion response is

    D_uvq = F_q(X without S) - F_q(X without C).

For source field d_(b,r,c,s) from HM184 (two source views, five targets, four
profile components, full/retained/complement spaces), the exact mean-vector action:

    V_uvbrcs = d_(b,r,c,s)^T (sum_C x - sum_S x)/8.

On the isolated S/C arms the same additive source functional gives -2*V. Compare
both actual natural reader operations, rather than assuming they are one linear
operator. All contexts/components/spaces are retained; no denoising or centering
of input vectors or source distributions.

For final-normalized reader states, delta_h_uvq is decomposed descriptively:

    common_uv = mean_q delta_h_uvq;
    specific_uvq = delta_h_uvq - common_uv.

With the SAME digit output head, let w be mean(high5 head rows)-mean(low5 rows).
Then signed geometric-logit contrast has the exact account

    delta_ell_uvq = w^T common_uv + w^T specific_uvq.

This is a post-readout accounting projection, not an independent mediator,
an evidence filter, five independent readers, or personality information shares.
Keep score, high/low log-sum-exp odds, geometric logit contrast and candidate mass.
Do not select whichever unit favors a result.
