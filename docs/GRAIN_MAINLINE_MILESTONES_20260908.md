# GRAIN 主线理论里程碑与剩余距离

2026-09-08，按当前代码与报告回顾。**本页不是将旧成果逐一否定，也不按实验编号
计算完成百分比。主线已到“机制定位完成一批，跨作者构造正在连接”的阶段。**

## 终点究竟是什么

给定真实作者文本、查询和声明的群体参照，形成可重复的向量表示及功能读出，
说明哪些证据共同/专属地改变特质判断，怎样形成作者间的位置与响应差异。
允许使用固定神经编码器；希望省去不必要的生成式分析，而不是证明完全不需
预训练知识。共同的是程序/数学构造，各特质可以有不同参数与作用通路。

理论v1交付的是测量/推论方法基础，不是成品量表或准确率100%的系统。

## 距离理论连接v1还差什么

不是“再提高N的r到某值”。两轮新研讨后，前两接口已得到三查询整链实例，
M10已完成源人格关联的连接，M11将遗漏部分定位到条件基线与函数运输。
剩下的不是再作一个广泛相关检验，而是为这些已定位对象构造可运输估计器。
M12/M13已测试b_q(E)简单读出，M15已将其进一步定位成条件均值基线与配置效应。
下一步M16直接构造`sum token偏移 × 条件敏感度`的完整配置函数，并测试其跨作者
可运输性。保持全值/响应/作者关联同目标；不把实际测得各项等同已完成轻量替代。
全部已启动神经包均完成，无运行中队列或新模型训练。

以下是M7时点的三个接口说明，M8/M9已推进上述连接：

1. **载体→可复用函数**：M7小面板已有正例，下一包冻结全部矩阵，对12位未
   参与本轮构造的作者仅前向运输。若有用便停止此层精度搜索；若某查询失效，
   定位可观测输入如何调节矩阵，不无限加积分节点。
2. **函数→完整推论**：把P作用、其它通路、布局与条件作用连到同一个目标。
   已有精确分账不等于已具备各项的可运输估计器。先做一个明确特质的可运行
   端到端实例，再用第二种查询检验同程序可构造性，不要求同一组参数通用。
3. **作者配置→GRAIN解释接口**：用独立的群体参照组织多查询响应，保留choice/
   context/dynamics的接口，冻结后解释与哪类作者/行为指标相关。不把模型误差
   本身当身份，也不强迫所有特质合为同一低维轴。

因此“机制存在性”已有多组结果，“理论v1整链构造”已进入函数构造与连接，
尚不能给可信完成百分比或保证剩余实验次数。M7已给运输正例，接下来要的是
一次更宽作者检查与同目标整链实例，而不是重新从头寻找有没有人格方向。

persona写入/读出双向性、更多特质、跨观察器及跨语言属于后续扩展；目前不
因“还没做”就把它们全部设成v1入口门槛。真人实验与临床用途另有验证层。
