## 4. Actions cannot be equated by sharing their donor

Let F(E,q) denote the native query readout from supplied text and g_S the
historical actual deletion. The natural action is:

    D_native=F(g_S E,q)-F(g_C E,q).

The query-end block16 action uses a donor state from g_S E or g_C E while
retaining other states of the original E run. At alpha=.5 or1:

    D_patch(alpha)=F(patch_S(alpha);E,q)-F(patch_C(alpha);E,q).

These interventions share event-derived donors, not complete observation
programs. Deletion changes positions, context, evidence count and all affected
representations. A single-position patch does not implement that whole edit.
Consequently D_native=D_patch is not an identity, and a semantic geometry
that corresponds to one need not correspond to the other.

Define the observed action signature by retaining

    A(u,q,operation)=(D_q(u),D_model_operation(u)).

Across-author association, unscaled alignment and absolute sign agreement
are distinct properties of this signature. Do not fit a scale/intercept or
flip q to manufacture a commuting diagram. Future causal abstraction would
need a specified state AND intervention map preserving observed actions.
