## Objects and mathematics

For a declared three-state evidence vocabulary, J_u(i,j) is the empirical
previous/current pair law, not a mental-state transition matrix. F_t(i,j) is
the frozen preanswer observation of the current action after the previous
action. A memory-one observation protocol is explicitly imposed; this does
not assert that real text or the encoder has only one-event memory.

    J = S + A, S=(J+J')/2, A=(J-J')/2
    F = F_even + F_odd
    mu = <S,F_even> + <A,F_odd>
    A = A_gradient + A_cycle
    mu = traffic + endpoint + cycle

The last split is the unweighted complete-graph gradient/divergence-free
projection. Keep all terms; do not remove endpoint changes or conditions as
noise. A gradient reader has zero pairing with stationary circulation. Two
states cannot support a nonzero stationary current; three states can. This
is established graph/Markov algebra, not a new Hodge or personality theorem.
