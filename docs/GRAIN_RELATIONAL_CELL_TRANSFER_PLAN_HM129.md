# HM129: neutral relational cells to qualified behavioural observations

2026-10-10. This is a finite constructive transfer experiment, not a new
binding theorem or a personality-accuracy search. Original18/100/44 stays open.

## Decision and prior inventory

HM04 already implements dependency-parser event qualification. HM05 shares
role maps between two trained semantic targets. HM10 tests joint exposure.
HM100 retains contextual key/value/gate effects; HM111 isolates recursive
collection. None of these is evidence that a neutral factual index reader can
assign unfamiliar behavioural vectors to person/condition cells without
application role labels. HM128's single-block name-slot Hessian intervention
failed factual interchange; its failures remain. This does not rescue it.

The operational question is whether a query-independent structural module
can supply an evidence ledger for a separately frozen target readout. Success
would support a limited modular construction; failure would locate a missing
transport step, not establish that every interpretation must be joint.

## Mathematical interface and acceptance

Let h_e be the candidate state and s_e the frozen six-target value readout.
The source-only program gives b(h_e)=(entity,relation) by nearest legal index.
The cell observation is

    S[u,c,q] = sum_e 1{b(h_e)=(u,c)} s[e,q] / count[u,c].

An empty cell is unobserved (NaN in arrays/null in JSON), never zero.
Mean squared score differences are construction fidelity to gold-addressed
readings on the same vectors, not personality accuracy. All6 targets survive.
The gold-addressed comparator is evaluation-only, not a cold input.

Report entity/relation/joint correct counts and denominators by domain,
wording/header/assignment; source-only/null/position controls. Also preserve
the actor-by-condition routing confusion, coverage and cell score discrepancy.
Matched assignment pairs have identical action multisets; retain all pairs
and the third person's contamination. No success declared from training fit.

A candidate positive modular interface requires both cold domains to exceed
both controls on joint assignment, and behavioural entity decoding to exceed
the nominal1/3 rate separately for all3 people. This finite decision rule is
not a statistical-significance threshold. Report counts without universal or
human-validity claims. Even success is not causal use of the decoded subspace.
The original causal modularity question remains separate.
