# VM04：独立作者的历史访问与跨当前文本确认

日期：2026-09-06。冻结后执行；这是机制程序的确认，不是共享人格方向确认。

## 唯一问题与固定设计

在第一条当前文本上得到的历史状态局部方向，能否作用于同一人的第二条
当前文本？交换回答代码后，是证据方向继续成立，还是仅推高Yes这个词？
仍只用一个既有Qwen观察器，不训练、不读量表、不修改正式GRAIN。

- 全部48 mechanism_holdout作者，首视图12条历史、第三视图前2条当前；
  不按输出、梯度、人格标签、词汇或主题挑人。先前144 discovery和48
  calibration的作者不得重叠。历史/当前ID、thread、时间、重复检查全通过。
- 本包会首次打开这48作者的指定材料。PANDORA母库历史上已被研究，
  不能把它叫全新外部样本。未使用的其他评论也不再代表独立作者保留集。
- Qwen2.5-1.5B-Instruct revision 989aa7980e4cf806f80c7fef2b1adb7bc71aa306；
  Windows .20，BF16 eager，pad1536；只使用block10，epsilon=.002。
- 超长则整作者跳过，不截断、不换评论。少于24可用作者时只报告覆盖，
  不启动确认模型批次。排除表包含所有48作者，不用后验结果删人。

四条件：第一当前的社交主动证据任务（方向来源）；第二当前的同任务；
第二当前同任务但Yes/No代码交换；第二当前的当下建议行为任务。
新公共system不规定Yes极性，答案代码只放在证据后的suffix，避免与system
冲突。此为新读出协议下的迁移确认，不是逐字重播旧system的精确复现。
前三者使用同一证据问题，第四者为已固定的非目标任务。

每作者仅从第一条件的历史位置梯度G0取得D=G0/||G0||_F。
固定预算b=.002*||H_current0||_F。历史的H在四条件必须严格相同、token
位置及IDs相同。对四条件都施加H+bD及H-bD，不再为第二条件优化方向。
每个正/反向另配2个固定种子的全矩阵随机方向，实际BF16后总范数误差
必须<=1%。这是总预算对照，不等于逐token强度或自然流形对照。
自替换与恢复必须为0误差；超限停止并保留失败记录。

所有条件的梯度只用来检查局部预测与方向余弦，不用于再选择或修正D。
保存历史H/G、实际注入范数、完整prompt哈希、输入ID及材料引用供私有重播；
不把正文、行级作者分数、缓存或标签放进公开git。

## 极性能力与分析

先固定8个合成历史（4种主动行为的肯定/否定），同一问题的两套回答代码
共16条件，另重复1次。它们只有文本证据真值，不是人格真值。
两种代码各至少6/8正确、8个配对至少6个方向相反，才允许把自然样本的
代码交换解释成有限的语义控制；这不是充分的通用能力证明。未达标也保留
全套自然结果，但交换端点裁决为instrument_unqualified，不调prompt救援。

主量S=(s_plus-s_minus)/2。方向来源条件按构造可能偏正，不作独立发现。
两条确认端点为第二当前S及代码交换后-S；各减去两个随机方向的平均S。
作者等权bootstrap95%CI、两端点sign-flip p及Holm修正一起报告，不设
心理学相关>.5门槛。代码端点仅在上述能力检查合格时解释。
非目标任务是副作用，不要求绝对0，也不能据不显著认定不存在。

同时报告局部一阶预测MAE、符号可靠条件比例（实际/预测均>=.125 logit）、
源/第二当前历史梯度余弦、源效应至第二当前变化和全部排除。低剂量影响
不证明原文历史必要、人格准确、跨作者共享向量或完整中介。

上限48作者、2048 forward（含最多192 backward）、1800秒。边界/精度/
恢复错误立即停止，不提高容差；预算不足PARTIAL，不挑已完成部分宣布确认。
完整结果只读一次，不按结果重新选层、幅度、作者或问题。

输出results/grain_vector_mechanisms/vm04_independent_access_r1及新的analysis目录：
manifest、eligibility、code_controls、interventions、checks、run_status、私有缓存、
source_snapshot、author_effects、effects、confirmation_endpoints和report。
