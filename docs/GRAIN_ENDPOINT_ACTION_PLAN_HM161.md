## Scientific question and construction increment

HM157/158 already transported a source-only relation operation into new content
and observed its effect on personality *judgments*. That does not automatically
make it an operator on concrete choices. HM160 already constructs an observed
endpoint with a frozen source reference, but only in an exact finite alphabet.
Do not repeat either result or call a new output probability human behavior.

Keep the same16 HM157 fictional records and source0 relation operator. The body
has been observed previously; only the prospective/instruction suffixes are new.
Endpoint meanings, support and signs are fixed before collecting those suffixes.
An endpoint-indexed action interface is the new construction capability: the
same qualified source operation can be evaluated against *different* explicit
observable functions without pretending one target label defines them all.

Competing explanations:

1. The relation operation conveys actor-qualified content beyond the trait
   question. Its prospective-choice action preserves the corresponding natural
   actor-change response, as does its diagnostic action. Explicit output
   instructions may attenuate this effect; that is a separate observation law.
2. The operation primarily accesses a diagnostic readout. Diagnostic action can
   persist while prospective action disappears or changes direction, even if
   the unpatched prospective endpoint distinguishes the natural actor records.

If prospective natural differences themselves vanish, this design cannot
distinguish a diagnostic-only operation from an insensitive endpoint. Preserve
that result rather than optimize the prompt or rescue the action magnitude.

\[
A_q(h;\delta)=f_q(h\oplus\delta)-f_q(h).
