## Mathematical Object and Proof

For a vector-valued table F on {-1,+1}^n, define an evidence edge

    d_j(c) = F(x_j=+1,c) - F(x_j=-1,c).

On every j,k square, at fixed other coordinates:

    K_jk = d_j(x_k=+1)-d_j(x_k=-1)
         = d_k(x_j=+1)-d_k(x_j=-1).

Both expressions equal F++ - F+- - F-+ + F--. This is an exact finite
compatibility identity, not a discovered nonzero circulation. An exact table
has zero boundary circulation by construction; a nonzero K is an interaction,
not curvature, holonomy, causation or a time-order effect.

Suppose d_j=a_j(c)b_j and d_k=a_k(c)b_k with fixed nonzero directions b_j,b_k.
Then K lies in both lines. If the lines differ, K=0. Thus nonzero interactions
between different fixed directions require directional changes for at least
one evidence, or rejection of the fixed-direction model.

Let u_j,u_k be unit directions, and r_j=(I-u_j u_j^T)d_j. On each square:

    SSE_four_edges >= (||P_j K||^2 + ||P_k K||^2)/2
                   >= (1-|u_j^T u_k|)||K||^2/2.

The first inequality follows from ||a||^2+||b||^2 >= ||a-b||^2/2.
The second follows from the two-projector eigenvalues 1 +/- |u_j^T u_k|.
These are standard discrete-differential/projection facts, not new theorems.
Scalar gains may have either sign: this deliberately generous null does not
mistake a pure reversal for evidence requiring a new line. Zero mean directions
are flagged unidentifiable, never supplied an arbitrary axis.
