## 恒等式与可压缩候选

每条评论G的token状态均值为m_G，d_t=h_t-m_G，故sum_G d_t=0。
保持P/Q=xbar，沿`C(E)+a*d`变化：

```
g_t = integral_0^1 gradient_(E_t) F(C(E)+a*d,xbar) da
E_main = sum_t <d_t,g_t>
       = sum_G |G| trace(Cov_G(h,g))
```

任意组内常数敏感度都会相消，因此“一个所有token共用的平均梯度”必然给0。
要找的是敏感度随token状态变化的规则，而非增加普通均值维数。

令T为被干预body token总数，Gamma_t=T*(g_t-mean_G(g))。共同候选为
`Gamma_hat_q(d)=W_q phi(d)`，`E_hat=(1/T)sum_t d_t'Gamma_hat_q(d_t)`。
phi取固定种子正交投影64维，不依据Y选秩。它产生一个可有正负特征值的低秩
二次型，不假设噪声全正或信息只在大方差方向。T乘除是恒等重参数化，不假设
真实神经敏感度一定遵循1/T定律。
