# NEXT61：函数有导数，不等于函数族能表达目标导数

2026-09-11。源目标兼容性分解完成。本文区分同函数兼容性、有限字典表达力、
正则选择与新作者迁移；不把这四件事合并为“数学是否正确”。

## 1. 这一轮对主线的实际修正

NEXT60已经保证分数与路径作用来自同一个可微函数，也恢复了一点token配置
作用。本轮直接发现：主要缺口在可表达的方向形状，不在是否存在兼容标量。

全源4的固定核字典中，梯度目标可表达能量从对照的0.567%/0.397%提升至
候选的3.984%/2.805%，约7.03/7.06倍。非线性前置确实扩展了原来缺失的
方向，而不是毫无效果；但绝大部分目标仍落在这个小字典的列空间之外。
这里的目标是源参考rank8内、按作者均权归一化的梯度密度，不是人格信息量，
不是整个LLM梯度的百分比，也不是预测准确率。

## 2. 从拟合公式分开两类残差

把源评分与密度设计分别记为V、D，目标为ell、k。每作者评分权重
1/(n*sL^2)，其token/坐标权重1/(n*T*rank*sK^2)。系数theta的目标为：

    J(theta)=||V theta-ell||^2 + ||D theta-k||^2 + alpha||P theta||^2
    alpha=.01; P不惩罚截距。

令Pi_D为固定数值截断下col(D)的正交投影，则有精确分账：

    ||D theta-k||^2
      = ||(I-Pi_D)k||^2 + ||D theta-Pi_D k||^2.

第一项不可能靠改变同一字典的系数消除；第二项才可能由另一种拟合/正则
选择改变。对NEXT60候选，全源N两项为.960162+.113344，确认寻求为
.971952+.114956。字典外部分占实际密度误差约89.44%/89.42%。
即便撤掉正则惩罚、任意拟合这些系数，也只会到.960/.972，而非接近0。

这不是噪声检测结论。字典外残差包含真实原生响应，是当前函数族没有容纳
的对象；应保留并发展表达它的函数，而不是把它从文本或教师目标删除。

## 3. 固定评分后，路径是否必然不能改

令N_V为ker(V)的正交基。所有保持源评分V theta0不变的系数都可写成：

    theta=theta0+N_V eta.
    e=k-D theta0
    eta*=(D N_V)^+ e.

其源密度残差是 `||(I-Pi_DNV)e||^2`。本轮20系统中，该残差都达到对应
无评分约束的字典极限，源评分最大变化仅1.37e-13。有限源数据上，评分
不构成额外的代数障碍。不是说目标争夺不存在，而是它不是不可解除的
数学冲突，更不是证明评分与人格推论路径永远必须分离。

原因也可在代码上指认：截距与末token线性项的BODY导数严格为0。其源
评分矩阵A均满行秩（全源rank4、留一rank3），因此可以承接任意这几个源
点的评分残差。锚定后的源评分平方误差最大5.18e-27，但这些校准只识别
3/4个源点，完全不能拿来保证新作者有同样准确率。

## 4. 为什么原来的最优化没有自己走到那个解

同一评分下逼近字典极限，仍需要高幅度系数变化。全源候选所需增量范数
为原系数的62.64倍（N）、19.77倍（确认寻求）；源字段损失分别改善
.113/.115，却使原正则项增加590.022/438.011。原优化器正确地不选择它。

原目标的一阶条件分成三个向量：

    V.T(Vtheta-ell) + D.T(Dtheta-k) + alpha P.T P theta = 0.

实际三项并非都小，评分项与字段项内积为负；正则项参与平衡。相加残差
最大1.75e-13。任何增量delta还满足

    J(theta0+delta)-J(theta0)=delta.T(V.T V+D.T D+alpha P.T P)delta

（theta0为原最优点）。数值相对误差5.92e-14。没有“优化器没收敛”的迹象。
而条件数依赖所选坐标/系数度量，不能当作系统先天绝望的证据。

SVD逆问题理论解释为何小奇异方向需要更大系数并受正则抑制。
[Hansen的原始技术手册](https://www2.compute.dtu.dk/~pcha/Regutools/RTv4manual.pdf)
提供SVD、滤波因子、Picard条件与Tikhonov的标准分析工具。这里使用固定
1e-10数值秩门槛做结构分解，不用它搜索最佳应用参数，也不把工具本身称作
新的心理学定理。撤掉惩罚并不会改变Pi_D，因此不是本轮的优先修复。

## 5. 对下一种函数的具体启发

旧scalar Gaussian center k(v,l)的梯度只提供径向形状，且该center自身在
v=l时的梯度为0。多个center可组合方向，但NEXT61量出了当前有限组合的
不足。下一步发展带center导数的标量基：

    psi_mj(v)=sigma * partial_{l_j} k(v,l_m)
              =(z_j-l_mj)/sigma * k(v,l_m).
    partial_{z_a} psi_mj = k/sigma * [delta_aj-(z_j-l_mj)(z_a-l_ma)/sigma^2].

在center处导数为delta_aj/sigma，因此每个center可提供不同坐标方向，
仍然严格来自一个标量函数。它是标准导数增强/Hermite型核字典，不是任意
向量场，也不需要发明一个与分数不兼容的“路径头”。

[GDML原论文](https://arxiv.org/pdf/1611.04678)用核的导数/Hessian构造兼容
梯度场，与先拟合少量标量核再求导不同。NEXT62借此扩展有限字典，但不
照搬其分子描述符、Matérn核或能量物理解释。是否改善GRAIN路径仍要实算。
[Sobolev Training](https://arxiv.org/abs/1706.04859)支持函数值与导数共同教学，
但不保证选定字典足够。三种文献分别回答表达、兼容、稳定的问题。

下一步保持源数据/归一化/中心/带宽不变，增加可积的局部方向基，进行
一个新候选而非调参网格。若源容量提升却应用无改善，才回头研究token局部
函数缺少全句/末位条件交互的可能。源局部可积不等于已经抽取整个人格机制。
