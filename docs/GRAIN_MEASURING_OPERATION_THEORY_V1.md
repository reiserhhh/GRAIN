## 3. Comparing operations rather than maximizing agreement

Let B_o(X)=.5(mean_H l_oj-mean_L l_oj), with every item and both poles retained.
For two actual distinct events x,z, use the SAME four observed inputs:

    J_o(x,z) = [B_o(xz)+B_o(zx)-B_o(x)-B_o(z)]/2,
    DeltaJ = J_usual-J_sample.

This is departure from a singleton mixture, not factorial synergy. The
discriminating null is specifically

    l_usual,j(X)-l_sample,j(X)=a_j for all four X.

Under that null DeltaJ=0. Nonzero log-odds DeltaJ means the operation distinction
changes how the same pair evidence is used; a context-independent item offset
alone cannot describe it. This does NOT reject arbitrary input-dependent
generic prompt effects or establish human psychological meaning.

Probability scales are also kept, but sigmoid curvature can yield nonzero
probability DeltaJ even when the log-odds null holds. Therefore a probability
difference alone is not used to reject that null. The synthetic focused test
includes precisely this misleading-curvature case. No-sample control responses
describe the model's default behavior; they are not missing people scored0.

## 7. A common-response saturation that keyed scores can conceal

All19300 greedy outputs fall in the requested alphabet, but19287 select digit0
and only13 select digit1. On the19200 sample inquiries, mean conditional yes
probability is .0031906/usual and .0038575/sample. The no-sample balanced
probability keys lie near .5 under both operations. This does not mean a
typical, moderate or neutral human personality has been measured.

The reason is already visible in the standard reverse-key formula:

    B_p=.5+.5(mean_H p-mean_L p).
    All item probabilities p -> 0 implies B_p -> .5.

Thus retaining common endorsement U is essential: a nearly uniform rejection
channel can be hidden by a centered key. The continuous log-odds observations
are NOT constant, and their operational differences remain informative; the
near-constant greedy answer is a separate limitation of this binary judgment
interface. These findings do not establish whether rejection comes from lack
of evidence, task semantics or a model response habit. No prompt tuning to
increase yes frequency or rescue a target contact follows from this result.
