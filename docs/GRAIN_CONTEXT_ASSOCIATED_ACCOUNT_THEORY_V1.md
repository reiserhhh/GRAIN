## 1. An anonymous mean is not the whole account

For fixed event coordinates g(e), observed context C(e), and author-evidence
law P, define the unnormalized joint account

\[
 J_P(k)=\mathbb E_P[\mathbf1\{C=k\}(1,g)],\qquad
 G_P=\sum_k J_P(k)_{g}.
\]

The first coordinate is p_k=P(C=k); the remaining coordinates are
p_k E[g|C=k] when p_k>0. Empty contexts give zero joint mass, not a fictitious
conditional mean. Keep the choice mass and the conditional profile together.
This is not residualization, context removal or recentering a new reference.

Equality of G for two laws only fixes the sum of context contributions.
It does not fix each contribution. There can be cancellations across known
contexts even when no such ambiguity remains inside the declared conditional
variation support. Thus adding arbitrary higher moments is not the only
possible repair: first retain the evidence's existing condition association.

This is established joint/conditional feature-map algebra. The new empirical
question is which account interface actually loses the deployed observations.

## 3. Separate common action from observation-program difference

For two fixed programs H and F on the same evidence, write

\[
 m_q=(y_{H,q}+y_{F,q})/2,\qquad
 r_q=(y_{H,q}-y_{F,q})/2.
\]

For a redistribution v=D alpha, requiring
G^T v=0 and r_q^T v=0 gives equal changes of both programs:

\[
 \Delta S_{H,q}=\Delta S_{F,q}=2\epsilon m_q^TD\alpha.
\]

This is agreement of author-account contrasts, not proof of a shared internal
circuit or human truth. Agreement can hold even when the readers' levels differ.
