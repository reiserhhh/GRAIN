## 公式和比较

M17的V、c固定作为起点。r_t=V'd_t，评论均值m_G保留；令z_t为前置条件：

```
Gamma_hat_t = V diag(c + L z_t) V' d_t
a_hat_t = sum_j (c_j + (L z_t)_j) r_tj^2
E_hat = mean_t a_hat_t
```

共同形式允许条件专属系数。这是有限二次作用字典与条件的一阶张量积，
不是新心理维度，也不保证它是某全局势的梯度。

三个固定候选：background-only、layout-only、background+layout。保留M17
action_refit作同材料对照，不挑一个赢家后隐藏另外两个。

- background：各评论原block16 token均值，投影到M16既有随机正交P前8列。
  投影不读取Y。参考作者等权的均值/标准差决定z，非参考作者不更新尺度。
- layout：log(1+评论token数)、全body序列中的token相对位置、评论内部相对
  位置、评论在整材料中的相对序号。范围按已有body/组布局定义，不读取文字。
- 基础r^2和r^2*z列均按参考token加权RMS标准化；无独立截距。
- 最小化参考token的积分导数作用误差，岭惩罚0.01（每标准化列二阶矩为1）。
  先验为M17 action_refit基础系数，条件系数0；不搜alpha、背景维数或条件。

这样比较条件信息而非新token数量。背景依赖前缀原生状态，不称无LLM知识。
当前四参考仅是有界构造见证；如果条件场不足，不能把这些条件当无用信息。

## 文献与方法边界

[Deep Sets及其表示限制，Wagstaff等(2019)](https://proceedings.mlr.press/v97/wagstaff19a.html)
提醒固定潜在维数的求和并不自动获得任意集合函数的连续通用表示。这里不借
该定理证明“8维背景足够”，只是明确平均和固定方向都有范围限制。
[Sobolev Training](https://papers.neurips.cc/paper_files/paper/2017/hash/758a06618c69880a6cee5314ee42d52f-Abstract.html)
继续提供导数监督构造思路，本实验是有限张量积基函数的解析岭回归。
MCD旧条件化原则在此变成数值背景×token作用的明确函数，而非回归去掉背景。
