## Scientific decision

HM212/214/217 qualified a SOURCE A contact on historical N-selected edits.
They do not establish that this rule can prospectively find evidence used by
a natural reader. The NEW object is an actual, previously unscored-by-HM199
third12-comment window of all24 historical panel authors, and a SOURCE-only
finite evidence selector. These are new native input operations, NOT new
authors, a lockbox, unrestricted human personality identification or accuracy.
Other prior studies may have used these third windows; no claim of globally
untouched material. Source386 and panel24 remain author-disjoint.

Competing mechanisms: (1) actual conditional A assignment supports usable
evidence; (2) old contact required N-guided evidence/the intervened recipient
framework; (3) source selections induce a common narrative/length response,
not an A-specific reader action. Allfive signed outcomes distinguish these
possibilities. Negative results are not followed by kernel/head/r grids.

## Fixed construction

Use HM216's common386 prototypes,32 codes and inherited variance. For each
author i, pool the TWO SOURCE window kernels at a single new point x:

    k_i(x) = (k_i0(x) + k_i1(x))/2
    L_g(x) = mean_(i:g_i=g) k_i(x), pi_g=n_g/386
    Lbar_q,g(x) = mean_(i:c_i=c_g) k_i(x), c=other4bits
    D_q(x) = logodds_q(pi*L) - logodds_q(pi*Lbar_q)

This is a declared single-window mixture, not two independent observations,
not HM217's paired-window likelihood. Finite-group conditional orbit mean
retains other-profile association. The subtraction accounts for it; it does
NOT delete text, context, state or psychological information. The common
x-norm Gaussian term cancels in both odds. No new bandwidth/calibration fit.

Load only SOURCE codes/means and panel IDs; no application questionnaires.
Use frozen cue_mask comment vectors/texts, original ordering and exactly12
distinct event IDs from window2. Source prototypes retain their historical
raw-vector protocol, so this is a declared raw-SOURCE to cue-masked application
operation, as in the inherited contact, not proof of observation-law identity.

Enumerate all495 four-event removals. Each leaves an eight-event mean vector.
Eligible disjoint pairs remove equal counts of the frozen top-venue binary
condition; token lengths differ by <=max(8, .05*larger removal length).
Select the pair with largest |D_A(x_left)-D_A(x_right)|; lexicographic ties.
The lower-D remainder is remove_support, the higher-D remainder remove_counter.
No fallback tolerance, outcome-dependent selection or second selector.
Source positive direction is BY CONSTRUCTION, not scientific validation.
