## 1. Three identities, not one universal context label

For an evidence body x, retain its production regime g, the observation history
z, opportunity o and option-order protocol pi separately. An observation is

    R(x,z,o,pi).

The operation to be compared across evidence units is

    tau = (z0 -> z1, system/style, o, pi),
    A_tau(x) = R(x,z1,o,pi)-R(x,z0,o,pi).

Two observations may end at z1 while applying different tau. A common endpoint
does not establish a common action. Matching tau establishes the specified
message replacement, not invariance of response mechanisms across populations.
The actual text-production conditions g are not overwritten by replacing z.

## 2. An executable vector action witness

Using only source observations and fixed GRAIN article coordinates,

    C_tau = Cov_source(A_tau(X),Phi(X)),
    T_tau(v) = <C_tau,v-mu_source>.

With the same source reference at both endpoints,

    C_tau = C_z1-C_z0.

Using the historical body-production blocks g,

    C_tau = sum_g p_g Cov(A_tau,Phi | g)
            + Cov_g(E[A_tau | g],E[Phi | g]).

Both within and between terms are retained. Neither opposition nor low cosine
licenses deleting a term. This is a signed dependence witness, not a fitted
conditional mean, choice probability or identified latent-person score.

## 3. Why an action is not a state change by definition

An unchanged latent author property theta can still give

    R(x,z,o,pi) = G(theta(x),z,o,pi)

with strongly interacting observation conditions. R changing does not by
itself imply theta changed. Conversely a body-only universal f(Phi(x)) cannot
reproduce all protocol outputs when one body has different R under different z.
The missing argument is not repaired by more precise feature arithmetic.

A useful personal object could ultimately be a conditional response profile
or operator, rather than a context-free scalar. For human measurement this
requires author-linked evidence/behavior and a justified observation model;
the present fictional/model history action cannot supply them by name.

Even for one model history, action matching alone does not identify an unknown
function from42 source bodies. A complete operation address is a design fact;
held-expression action correspondence is a different empirical question.

## 4. Algebraic composition is not empirical transport

For any fixed evidence and observable function,

    A_(z0->z2)(x) = A_(z0->z1)(x)+A_(z1->z2)(x).

Corresponding source covariance witnesses satisfy the same identity when all
three share a reference. This is ordinary subtraction/linearity, not evidence
of a newly identified latent connection, group representation or personality
conservation law. HM163 already tested a different report-edit composition;
do not relabel that result as natural author-time dynamics or repeat its
integrability check as the next discovery.

The actual open construction is whether source-observed action dependence
survives on different text bodies in the fixed observation protocol. A program
can satisfy every algebraic identity and still give the wrong signed action.
