# 自由会话的行为测量：自然表现、同机会响应与情境反差

这个工具回答：“这个人通常怎么回应？让他面对同一组机会时怎么回应？
改变机会类型时，他的回应向哪一边变？”它是可选的行为计分层。
不覆盖原生静态/液态得分，不从未标注原文自动产生心理构念。

从发布库根目录运行，不需要模型、账户或训练数据：

```sh
python -m grain_core.response_profile examples/response_profile_demo.json
```

算例的两个人自然表现均为 0.25，共同机会下都为 0.50。“具体邀请减去开放邀请”
的条件反差分别为 +1 和 −1。两个总分相同，回应模式正好相反。这个小样本只用于核算。

## 输入和输出

1. 固定一个可编码的行为、一条**仅依赖前文**的机会定义、响应窗、读者版本和目标机会权重。命名可观察动作而非直接命名人格；“讲出一个具体例子”优于“有洞察力”。权重不能根据待评者的结果调节。未列入权重的情境只进入自然率，目标权重为零。
2. 每个机会一行，用焦点人、对话、机会地址及实际回应地址去重。两个读者评同一句，应先解决分歧或记为未决，不是两个行为样本。搭档的下一条反馈另记，不能拿来填本人的行为。
3. 有完整的呈现记录时，选 `presented_opportunities`：记录明确表现行为（support）、已答且明确不符合（refute）、已答但不可判（unresolved）、有独立记录确认未作答（no_reply）、确认呈现但回复记录不全（reply_unknown）、连机会也未确认（opportunity_unconfirmed）。最后一类只报告排除数量；这套估计的总体是**已确认的机会**。若只有发言文本，选 `observed_replies`，只接受前三类；所有总分的分母均为已回复，不会估计发言率。
4. `natural` 按本人的实际记录加权；`standardized` 按目标机会分布加权；`response_contrast` 是两个指定情境的行为率之差，每个情境另报发言概率与开口后的行为概率。无人观察的目标情境保留其整份权重作为未识别质量，不在余下部分重新归一化。`mix_gap_natural_minus_standardized` 在两个结果间复用同一个未知行为：若实际与目标权重相同，即使两项都是宽区间，它们的差仍精确为零。
5. `comparisons` 或 Python 的 `compare(left,right,who_left,who_right)` 支持同一参照下两人或同一人两段时间。用平均权重对称分解自然差为「情境比重变化＋给定情境的响应变化」。分母为呈现机会且两端均有可判的发言表现时，第二项再拆成「是否开口＋开口后如何表达」。没有共有条件或行为未决时保留总差的界，不随意分配“原因”。这是描述性恒等式，并未假设能单独操纵其中一项。
6. 可选 `sampling_cluster: "dialogue"` 或 `"partner"`。前者以整场对话、后者以同一搭档的所有对话为单位轮流剔除，给出 jackknife 标准误；后者要求行中提供 `partner`。至少三簇，且每次剔除后该指标仍有点估计，否则为 null。它针对抽样单位近似独立的重复采样；发言条数不能替代搭档数。测量卡中的行为率区间是**已记录材料相容的范围**，不是抽样置信区间。

已有“是否采纳被纠正的前提”输入可直接走原文入口：

```sh
python -m grain_core.event_response correction_input.json --response-profile
```

它绑定前文纠正与同一人的第一条可定位回复；仅到达纠正时间的截断记录计为回复未知。原有 events、cards 和 later_checks 输出不变。从其他语料开始时可使用独立行为标注，也可以使用已冻结的文本读者；后一种的读数描述该读者能识别的行为。词表性能须按情境核对，而非假定各情境误报率相同。

## 实际重放

```sh
python -m examples.response_profile_replay --rpc /path/to/real_persona_chat_v1.0.0.zip --casino /path/to/casino.json --out /tmp/profile-new.json
```

[汇总结果](../reports/response_profile_replay.json)。不发布语料、个人分数或参与者标识。

- [CaSiNo](https://aclanthology.org/2021.naacl-main.254/)：只保留策略标注与原对话逐句、逐序一致的 393 场。4,155 个相邻异人回复中，伙伴被标为询问偏好后，本人陈述自身或他人需要的概率为 212/369；其余为 827/3,786。自然率 25.0%，给两类情境同权为 39.6%。只比较前句有问号的回复，仍为 57.3% 对 21.3%；简单 need/needs 词形只检出约一半被标记的需求表达。此处角色 ID 是局内席位，不拿来做跨局同人判断。
- [RealPersonaChat](https://github.com/nu-dialogue/real-persona-chat)：固定哈希先将焦点人与搭档身份分离，再分成两个不交搭档组；无问卷输入。65 人两组均有覆盖。自然问号率跨组 r=.858；前一条对方消息有无问号对应的本人问号率反差 r=.714；扣除每场对话仅由双方边际频率产生的预期配对后为 .697。前一组中个人的反差用于估计后一组的反差，比只用平时问号率（含平方）与情境比重的对照误差低约 19%，36/65 人改善。读数是标点使用及互动耦合，不把问号直接命名为好奇心。65 人是有足够重复的子集，不是两组总回复的作者总数。
- 两个语料各验证一环：一边有行为编码，一边有持久身份和换搭档重复。它们不验证“补充此前未知的具体信息”这个更强命题，也不拼成同一构念的跨语言效度。
