## 4. Finite Algebra and Its Boundary

Let common Z separate all events. For event a, choose for every b!=a a
coordinate j(b) with Z_j(a)!=Z_j(b). The polynomial

    l_a(e) = product_{b!=a}
        [Z_j(b)(e)-Z_j(b)(b)]/[Z_j(b)(a)-Z_j(b)(b)]

generated by Z identifies every finite probability profile. This is elementary
