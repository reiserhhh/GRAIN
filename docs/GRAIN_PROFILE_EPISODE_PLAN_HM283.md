## Model and competing predictions

Let i index frozen SOURCE path kernels L_i(H), g_i one of32 five-bit SOURCE
anchor profiles, pi_i=1/n, pi_g=n_g/n. Full carry assumes a shared i across
the two windows:

    P_full(A,B)=sum_i pi_i L_i(A)L_i(B).

The new shared-profile law draws one g, then independently draws reference
addresses i_A,i_B within g for the two episodes:

    P_group(A,B)=sum_g pi_g [mean_(i:g) L_i(A)] [mean_(j:g) L_j(B)].

Within EACH complete episode the address stays shared. Do NOT average the
transition matrices then multiply: mean(product) is not product(mean).
State/time/condition/expression information within each episode stays intact.
No cross-window transition. Grouping only uses old SOURCE labels, not held ones.

For the observed early full likelihood, fine weights w_i have group masses W_g.
The new late prior is wtilde_i=W_(g_i)/n_(g_i). Thus its SELECTED assignment's
entire32-profile distribution exactly matches full at the boundary. It does
not generally preserve a different, crossed assignment's readings. Boundary
preservation is known algebra; the scientific result is subsequent transport.

Four fixed models: no early history; same fine address; shared actual SOURCE
profile; shared old-permuted SOURCE profile. Full/fresh observations are reused
byte-for-byte from HM282; only two shared-group laws are newly evaluated.

- If the five-bit anchor organizes portable expression modes, the actual grouping
  should outperform the permuted grouping at the SAME natural late events.
- If arbitrary grouping reduces over-specific catalogue carry, both grouping
  operations may be similarly better than full. This is not psychological success.
- If within-profile source modes carry useful persistent information, either
  resampling can lose it. Keep every negative/zero and target-dependent change.

These are finite SOURCE-law hypotheses, not a claim people have32 personality
types or cannot change. Fixed g is the tested two-occasion model, not ontology.
