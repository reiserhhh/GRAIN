# VM05：同维随机子空间控制

2026-09-06，后续探索计划，记录于本批读出结果产生前。不是新的独立确认集。

## 问题与固定设计

此前raw_ready来源中，TF的垂直33维读出接近完整白化48维，平行15维较弱。
这还不能说明“残差方向特殊”，因为维数、坐标和正则化不同。

- 数据不变：raw_ready的144 Big5-only及1566 MBTI-only作者；bridge不读标签。
- 使用原始raw臂、原official五折和三折inner选择。五任务全部报告，不挑TF。
- 不使用PCA，以免15/33维最后都被压成同样维数；StandardScaler及原L2网格
  仅在训练内fit。不是比较发布版整体GRAIN，也不是寻找更好的参照子空间。
- 在48维冻结白化坐标中，固定20个随机种子94100至94119。
  每个种子生成独立高斯矩阵，QR并规范R对角符号，得到正交分解；前15维和
  余33维成对互补。随机基底不依赖作者数据、标签或先前成绩。
- 共20×2×5=200个新条件。实际parallel15/perpendicular33/full48使用已完成
  的同作者、无PCA来源头作为比较，保存模型与OOF核验后复用，不重复挑参数。
- 每个新条件五折与全来源模型均保存；后者仅为审计，不在bridge挑随机种子。

## 判读

报告实际子空间成绩、同维随机分布的均值/范围/分位数、实际减随机均值的
差值。对随机OOF预测逐作者平均得到的ensemble另列，因为它并不是随机成绩
均值，更不是同维单子空间。维数15和33的成对差异也单列。

若实际垂直方向只落在随机33维常见范围，则优先解释为一般分布式可读信息，
不设“人格残差专属方向”。若超出，仍需来源/线索控制，不能直接心理命名。
20个随机基底的分位位置是方向敏感性诊断，不是标签置换p值或人口学置信区间。
不选择最佳种子、不根据外部结果更换冻结地标、不改scorer、不提高gate。

## 执行边界

只跑CPU小维读出，4线程，条件边界最长1200秒。保留不完整产物；只有验证
manifest/代码/数据SHA与完成模型一致后才允许续跑。Windows已有全量向量
队列及Mac稀疏/置换队列不改变。结果写入新的私有输出目录。
