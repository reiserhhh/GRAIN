## Pre-outcome separation of source discrimination and averaging action

Added while source capture is still running, before any crossed cold reading.
The frozen primary difference D=T-C is retained, but it is not alone a test of
whether the reader distinguishes source criteria. Define, for each edge:

    V_qr = T_qr - mean_r T_qr
    J_q  = mean_r T_qr - C_q
    D_qr = V_qr + J_q = source_r + interaction_qr + J_q

V compares different source criteria at the SAME reader. J compares mean
action with action on a criterion-mean carrier. The latter is an exact
averaging/action commutation gap, not a fitted curvature estimate. Distinct
carriers can have equal individual readings but a different reading of their
mean; then D is nonzero while V=0. Do not report that case as source-criterion
discrimination. No component is erased or automatically named noise.

With the declared equal five-by-five weights, source, interaction and J are
orthogonal in the finite response table:

    mean(D^2) = mean(source^2) + mean(interaction^2) + mean(J^2).

This follows from zero row/column sums, not a new theorem. It distinguishes
three mechanisms rather than optimizing any of their magnitudes. An immutable
companion descriptor will save every edge/reader/source account after original
analysis, and independently recompute row and column differences. The frozen
science code, native observations, primary outcomes and verification remain
unchanged. This supplement does not create extra author observations.
