## 如何续接下一周期

1. **大型多来源合并。** 下一次验收使用远大于当前样本的独立匿名记录流；以准确去重、稳定内存、冷读复算为判据。现有索引随唯一事件数增长；若内存超预算再接磁盘索引，不把逐行读取当常驻内存解决方案。
2. **跨来源事件对应。** 加可显式确认的事件连接清单，区分同一事件的多种读法、同一人在别处的新事件和无法连接的记录。验收用同一输入的去重回执和覆盖差，不按措辞相似自动连人。
3. **多视角分析基准。** 在同观察和时间预算下，把复杂双视角动态分解与直接比较并排。让程序输出哪个观测改变决策、两路各消耗多少，并允许调用方在简单比较已足够时跳过复杂通道。暂不新增实验或神经训练。

本轮入口见 [工具手册](GRAIN_EVIDENCE_PANEL.md)。续接应先确认下游真正碰到的限制；不为填表重复跑已有观察或扩大理论研究。
