## 1. What the new measuring object is

Keep the neutral complete-candidate observation ell_j(X), not a model's answer
to a personality label. For two distinct eligible event positions, define

    R_j(x,z) = ell_j(join(x,z))
    I_j(x,f;z,g) = R_j(x,z)-R_j(x,g)-R_j(f,z)+R_j(f,g).

The first is a joint evidence observation. The second is a dyadic mixed action:
it depends on all FOUR endpoints. It cannot be called the trait of the writer
of x merely because x,z came from that writer. Mixed joins are counterfactual
observations, not testimonies from new actual people.

For ANY additive law R_j(x,z)=a_j(x)+b_j(z)+c_j, I_j=0. This is a standard
finite-difference identity. It allows arbitrary single-event nonlinear functions
a,b, so observing I!=0 is not just rejection of a linear feature regressor.
It still permits formatting, length, positions, coherence, source dependence
and neural interactions as causes. It does not locate a unique causal circuit.

## 3. Dyadic symmetry and reference dependence

Swapping only x/f negates I; swapping only z/g negates I; swapping BOTH leaves
I unchanged. This is an even pair-comparison object, not an oriented ordering
of persons. For hypothetical source coordinates and a bilinear joint rule,

    R_q(a,b)=a^T H_q b + s_q(a)+t_q(b),
    I_q = (a-a')^T H_q (b-b').

This motivates the registered SOURCE second-action contacts. It does not
establish that real R factors through the eight-cell coordinates, nor license
estimating a full H from24 edges (finite full-rank interpolation is vacuous).
No H, kernel bandwidth, rank or source score is fitted in this packet.

To derive an individual measurement from a dyadic observation, one would have
to declare a reference distribution and admissible comparisons, for example

    T_uq = E_(v~P_reference) I_q(e_u0,e_v0;e_u1,e_v1).

The current one-to-one matched graph does NOT observe that entire expectation.
Its24 dependent edges therefore supply interaction evidence, not24 calibrated
individual scores. Existing GRAIN author positions/choice/state are preserved.
This is a constructive boundary on what the new interface can deliver.

## 4. Order is a separate observation action

Reversing the two complete comment blocks creates another actual neural input.
Keep I^0 and I^1, and describe I_even=(I^0+I^1)/2,
I_odd=(I^0-I^1)/2. Even/odd here is the standard two-element decomposition,
not a hidden personality taxonomy. Order-even can still contain generic
coherence; order-odd need not be noise. No order is selected for positivity.
