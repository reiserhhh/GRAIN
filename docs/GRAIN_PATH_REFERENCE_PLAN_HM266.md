## Declared observation law and formula

Let O(X) be unchanged HM265's restricted orbit. Let T(X) contain all distinct
complete words with the same directed counts and fixed first/last edges.
O(X) is a strict subset in general. Its orbits partition T(X). Under the
DECLARED uniform full-family law, for the same frozen SOURCE field psi:

    S=<M_X,psi>; A=<E[M|O(X)],psi>; C=<E[M|T(X)],psi>
    Q=A-C; D=S-A; S=C+Q+D.

C retains state choices, counts and boundary edges. Q retains the extra
excursion configuration relative to that family. D is unchanged conditional
order. None is called pure topic, pure personality or pure noise. Tower and
orthogonality apply to the stipulated reference law, not automatically to
actual people. Natural covariance must keep all nine signed C/Q/D cross terms.

For an unknown homogeneous Markov kernel, complete word probability is
initial(x0)*product P_ij^N_ij. Conditioning cancels unknown P, including a
mixture, but this is NOT proof that natural text follows that null law.

Interior graph N is built from X[1:-1]. Denote its exact distinct-word count
by W(N;s,t). For a marked interior triple (a,b,c), contract it to a marked ac
edge in N'=N-Eab-Ebc+Eac. The full-family summed triple count is

    W(N';s,t)*N'_ac.

Prefix/suffix triples use W after removing the first/last interior edge.
Sequential deletion handles repeated edge types, self-loops and a=c. All
accounts are integer; full mass is (len(X)-2)*W(N;s,t). No MCMC, fitted
transition matrix, smoothing or enumeration of a large primary family.
