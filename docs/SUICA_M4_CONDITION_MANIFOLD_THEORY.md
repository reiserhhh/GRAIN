M4-B demonstrated that opportunity selection, opportunity creation, return,
recovery, and history-conditioned feedback can be separated in finite
synthetic worlds. Its condition categories were nevertheless planted by the
generator. M4-C removes that remaining dependence.

For event \(e=(u,o,t)\), define the pre-response sigma-field

\[

=
\sigma(E_t,\text{current menu descriptors},\text{incoming context},
\text{prompt/provenance},\text{source/time}).

\[

It may not use author identity, current choice, current or future response,

## 2. Object

The object is not a named topic axis. It is a local atlas or an equivalent
condition-relation representation:

\[
\widehat{\mathcal M}
=
\{(\mathcal U_a,\zeta_a),T_{ab}\}.
\]

Coordinate rotations, signs, and individual matrix elements are not formal
outputs. The stable outputs are neighborhood relations, geodesic/landmark
geometry, overlap transport, support coverage, and the action of a frozen
conditional-response operator on held-out conditions.

The V1 implementation registers three response-free candidate families:

1. robust scaling plus linear PCA;
2. robust scaling plus global Isomap;
3. a k-nearest-neighbor geodesic atlas represented by frozen landmarks.

Each source is fitted separately. Corresponding reference landmarks turn
source-specific coordinates into a common radial basis:

\[
\phi_{s\ell}(z)
=
\exp\left[
-\frac{d_s(z,\ell)^2}{2\sigma_s^2}
\right].
\]

This avoids interpreting arbitrary axis alignment as condition recovery.

## 3. Evidence split

The route separates:

- reference calibration: fit scaling, graph, and candidate charts;
- reference selection: choose a chart using pre-response geometry only;
- mechanism calibration: fit the conditional-response head;
- mechanism selection: choose response regularization;
- untouched mechanism evaluation: evaluate once.

The chart-selection objective combines cross-source relation geometry,
cross-author-half stability, trustworthiness, continuity, support coverage,
and a fixed complexity preference. No response metric enters this choice.

## 6. Identification and refusal

Chart recovery requires local injectivity or an explicit quotient claim,
reference support coverage, shared landmarks/overlap across sources,
author-independent inputs, and stable graph geometry. The system refuses when:

- provenance exposes response or author information;
- author fingerprints dominate pre-context;
- cross-source or author-half geometry is underresolved;
- evaluation conditions leave reference support;
- a hidden condition alias preserves chart appearance but destroys response
  retention; or
- topology is forced into an incompatible global chart.

An augmented predictive-state chart that includes past responses is a
different object and must not be silently relabelled as this condition chart.

The V1 observable mechanism-refusal rule is fixed after chart selection:

\[
R^2_{\mathrm{conditional,heldout}}<0.60
\quad\Longrightarrow\quad
\texttt{MECHANISM\_UNDERRESOLVED}.
\]

This rule does not diagnose *why* the response is underresolved. Synthetic
truth is used only afterward to verify that the registered alias world is one
such cause; the operational refusal itself does not read the alias label or
oracle surface.
