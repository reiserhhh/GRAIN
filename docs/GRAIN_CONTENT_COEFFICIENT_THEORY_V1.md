## 2. Two different exact error geometries

With VV^T=I, decompose field error as

    Jhat-J = -J(I-V^T V) + (Ahat-A)V/T = E_basis + E_coefficient.
    <E_basis,E_coefficient>_F = 0.
    ||Jhat-J||_F^2 = ||E_basis||_F^2 + ||E_coefficient||_F^2.

After the GRAIN measurement map L_D(E)=(<E,D_k>)_k, orthogonality is generally
lost. Squared action error equals the two squared component actions plus
2<L_D(E_basis),L_D(E_coefficient)>. Native data reproduce the first identity
within relative1.26e-15 and the second within4.78e-14. N content has relative
action errors .319+2.319-1.655=.983. Cancellation is part of the computation,
not evidence that one component is psychologically pure noise.

A second projection concerns *source input features*, not hidden reader rows.
Stack source designs and targets with equal-author weights w_ut=1/(3T_u):
Xw=diag(sqrt(w))Phi, Yw=diag(sqrt(w))A. Let P_X=Xw Xw^+.

    ||Yw-Xw W_ridge||_F^2
      = ||(I-P_X)Yw||_F^2 + ||P_X Yw-Xw W_ridge||_F^2.

The first term is the empirical source residual unattainable by this linear
design. The second is its Ridge shrinkage cost relative to source least squares.
No OLS model is evaluated on held authors; the projection only diagnoses the
fixed design. This separates mathematical capacity on the source from actual
cross-author prediction and does not give an out-of-sample irreducible-error law.

## 4. Target-aware residual information

Let P be the frozen32-row input PCA and Rc=(H-hbar)(I-P^T P). With source-only
coefficient residual E=A-Phi0 W0, define

    C_q = sum_source w_t Rc_t^T E_t.

The leading left singular directions of C identify linear combinations outside
the retained input space that covary with coefficient residuals on the source.
Compare them with equal-count residual-variance directions before claiming
target-aware compression helps. A source correlation is not already a transport
guarantee. The [fixed NEXT35 plan](GRAIN_QUERY_RESIDUAL_INPUT_PLAN_V1.md) uses
only8 added directions and no regularization/rank grid.

This draws on the distinction between predictor compression and response-linked
low-rank structure in [Mukherjee & Zhu (2011)](https://pmc.ncbi.nlm.nih.gov/articles/PMC3444519/).
Our finite cross-covariance step is not the complete reduced-rank Ridge estimator
or a reproduction of their kernel experiments. PCA uses standard randomized
linear algebra [Halko et al. (2011)](https://arxiv.org/abs/0909.4061); source
projection identities are ordinary orthogonal projection, not new theorems.
