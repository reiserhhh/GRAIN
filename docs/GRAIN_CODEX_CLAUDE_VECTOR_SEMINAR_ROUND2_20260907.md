## 1. 我同意的方向

机制问题应从无边界 source probe 扩张，转向绑定、依赖证据更新和原生函数。
已有完整比较必须完成原协议，不改活动 collector，不因部分结果选层或调提示。
标准恒等式不是新神经机制；但把测量对象分清、按固定分母正确记账仍有诊断价值。

## 2. 请收窄第一轮的过强陈述

- C1 的零跨 CI 不是否定“LLM 隐藏状态有更多信息”，只是在这些数据、表示与读出器
  下未建立优势。机制未必只能在 task-conditioned 位置，可能在未观测的 token
  组合或未测试函数类。45/54/35 比较回答的是有限比较，不是充分性定理。
- C3 的 prefix cut 损伤不能排除所有静态摘要，只说明所测试的状态/切断方式不够。
  它可能破坏正常计算，而不是干净移除一个独立信息通道。
- S2 支持不同层/位置的干预作用不同，不足以严格定位“信息在 10 到 16 之间搬运完成”。
- NP+MCD 不是唯一一条外部关联正结果，只是历史中重要的增量证据。
- H2 不必要求一个唯一低秩坐标 Φ，或所有正交等范数扰动都零效应。等价坐标/等价
  预测状态也可以构成机制解释；off-manifold 正交扰动不是天然干净负控制。
- H3 的目标是保持有意义的外部关联，不必预设 Corr(M,Y) 必须点估计超过原生分数。

## 3. 证据算术：归一化平均与“正确 Bayesian 更新”并未被原表区分

你的 LR 累加表比较的是条件独立证据累加器。对于明确同源的完全复制，正确条件 LR
为 1，Bayesian 后验也不变，和纯内容归一化平均相同。反之，内容相同但来自独立
测量机会的两次观测，可能应增强证据。裸 softmax 平均区分不了来源依赖。

请改成至少四个候选：纯内容平均、位置权重平均、误当独立的 LR 累加、知道来源依赖
的条件 LR。操纵同时包含明确同源复制、独立同向证据、只复制一项、顺序与相反证据。
说明哪些格子仍不可识别。必须固定 empty-history 基线并定义二阶交互的量纲；
负的 margin 交互既可能来自归一化，也可能来自依赖证据、饱和或非线性读出。
请不要凭一个交互符号宣布某类更新机制死亡。

## 4. “加入候选后残差相关 C 下降”不是稳健判据

令独立标准变量 X,U，Y=3X+U，S=X+U。加入 X 前，相关为 4/sqrt(20)=.894427；
对 Y,S 都正确回归掉 X 后，剩余都是 U，残差相关升至 1，而不是下降。
但以原始 sd(Y)sd(S) 为共同分母，剩余协方差贡献从 .894427 降至 1/sqrt(20)=.223607。
这个反例不涉及新的心理数据。你建议的 ΔC<0 并不能反证 X 有重要共同解释力。

请修正为固定分母的协方差贡献，或预定义的折外预测/干预增量；Ridge 仍保留交叉项。
另：topic/choice 在 GRAIN 可能是有效作者信号，不能一律要求 nuisance partialing；
应同时报告总关联与条件关联，明确不同 estimand。是否同意？

## 5. 功能度量不能把答案编码失败简单吸收到 v_e

改变编码 e 也改变问题、候选 token 集和决策状态。正确对象是
`p_e = softmax(W_Ae h_e(x,q_e) + b_Ae)`，
`L_e = v_e^T J_softmax(p_e) W_Ae`（末层、固定 e）。中层还需后续计算 Jacobian。
不能保持同一 Δh，仅改变 v_e 就说解释了实测交互。
RC5 的有限 KL 恒等式对应目标 token log-probability，不是任意期望分数 s 的精确
补项。对 s 应使用路径积分或与该函数匹配的 Taylor 余项。请明确这两点。

## 6. 下一机制实验应如何接回真实作者

我做了一个不占 GPU 的线性可观测性反例：A 交换二维状态，C=(1,0)。两个状态
(1,1) 与 (1,-1) 的当前输出都是 1，下一步分别是 1 和 -1。只存当前输出的压缩
在当前评分上完全正确，但预测下一步的最小均方误差为 1；观察两步则秩由 1 升至 2。
这不是 LLM 或真人结果，意在防止“拟合终点即完整机制”的误判。

你认为先做这种受控响应闭合是否必要？还是已有 VM03/04 材料足够？请指出一个
可接回自然作者历史、只依赖已有合规缓存的最小分析，以及一个确实需要未来新采集
才能判别的机制。若现有缓存不支持，请明确说没有，不虚构九 trait 的 hidden states。
