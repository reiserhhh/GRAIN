## The object that a compiler must retain

context c. Query q conditions the decoder mapping to a ten-candidate field:

    z_(q,c)(s,o) = z0 + s zs + o zo + so zso.

The candidate distribution has nine independent natural coordinates. Its

Let m=z0+s zs+o zo, a symmetric additive-logit field. Its response need not be
additive. For every character chi_j, retain the exact construction law

    a_j = (1/4) sum_(s,o) chi_j f(z_(s,o)) = L_j + R_j,
    L_j = (1/4) sum_(s,o) chi_j f(m_(s,o)),
    R_j = (1/4) sum_(s,o) chi_j [f(z_(s,o))-f(m_(s,o))].

L_joint is an observation-curvature interaction of the main natural fields;
R_joint is the readout-mediated action of the joint natural field. R is not
the decoder in isolation: it includes the specified nonlinear readout. The
split uses an explicit computational counterfactual, not a unique causal
allocation. An additive field need not correspond to any natural text.

The joint observation-only term has a direct mixed-curvature account:

    L_joint = (1/4) integral_[-1,1]^2
              zs^T Hess(f)(z0+t zs+u zo) zo dt du.

The joint-field action for every character is a finite gradient integral:

    R_j = (1/4) sum_(s,o) chi_j integral_[0,1]
          grad(f)(m+v so zso) . so zso dv.

These are standard calculus/exponential-family identities. Expected-value
Hessians can be indefinite. Do not substitute a PSD Fisher matrix for them,
or identify an observation interaction with an additional latent trait.
