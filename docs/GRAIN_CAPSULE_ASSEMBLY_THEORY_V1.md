## 3. Conditional updates and provenance

For a fixed observed joint, an update from A to A+B is J-I_A=I_B+H. It is a
conditional compiler update; it need not be reproducible by a context-free I_B.
The reverse order account is J-I_B. We do not infer natural order invariance:
the actual joint is one frozen order, and reversed raw texts would be new inputs.

A reusable bundle records the exact root event family, partition, compiler
version/coordinates, native/closed controls, I_A,I_B and H. Summing those three
terms reconstructs that root BY DEFINITION. It does not show that H can be
predicted for unseen families, that it is compact, or that it has personality
meaning. Repeating a capsule with a new carrier ID does not add an event.

For an author distribution P_u over eligible event families, a proposed
measurement recipe is E_(E~P_u) Z_q(C_q(E)). Neither Z_q(E C_q(E)) nor a product
of the per-event Z values equals this automatically. The source/event/condition
law and criterion anchor belong to the recipe, not silent attention weights.
This retains author choice, situation, state and temporal dependence rather than
declaring their common components noise. Psychological meaning requires its own
anchor; this experiment studies a model observation, not a questionnaire score.
