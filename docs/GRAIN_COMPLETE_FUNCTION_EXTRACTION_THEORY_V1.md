# 完整评分与GRAIN方向响应：同函数提取的能力与识别范围

2026-09-10，NEXT57/第46轮。实测见
[报告](../reports/grain_vector_mechanisms/COMPLETE_FUNCTION_EXTRACTION_REPORT_V1.md)。
目标是机制提取，不是重新训练Big5/MBTI分类器，也没有改变GRAIN评分规范。

## 1. 同一份文字的两个侧面，已经有具体计算接口

固定作者材料T、查询q和正文地址，X=H16(T,q)。GRAIN提供四个正文方向D_f；
固定模型给L_q(X)及tau_qf=DL_q(X)[D_f]。这是同一材料的测量坐标与查询响应
接合，不是先把两个作者总分无条件相加。本轮用同一个数值函数给出：

    Lhat_q(X)=ellbar_q+sL_q(a_q+w_q^T z(phi(X)))
    tauhat_qf=sL_q w_q^T Dz(phi(X))[D_f].

源数据同时教函数值和方向导数，继承
[Sobolev Training](https://arxiv.org/abs/1706.04859)的原则。应用不再调用suffix，
不读取当前模型答案或梯度，不加回真实端点残差。H16仍来自神经前缀，所以
这是可检验的后半段替代，而非原始文本已经完全脱离神经编码。

## 2. 源响应教学确实改变了函数，但完整评分没有一起迁移

源4联合导数损失降到.001462/.000108；新8的F04响应相关为.639/.610，说明
有具体的方向关系可以在同函数约束下保留。它是事后定位的技术因子响应，
还没有被选作新人格维度或新增预测器。

与此同时，新8评分相关从value的.300/.336变为joint的-.782/-.473。
不能用“局部方向学会了”替代“作者间完整评分学会了”。这一点来自实测，
不只是保守措辞。旧NEXT53局部组件和NEXT56保留的对比机制不因此被推翻。

共同原因尚待下一步分解。当前可以确定的是：

1. 数值程序正确执行了源目标；同函数有限差分及正规方程已核验。
2. 新8响应修正相对旧误差有负内积，但修正能量更大，整体误差仍上升。
3. 新8评分修正与旧误差内积为正，且排序反向；不是只丢了共同截距。
4. 当前目标是固定LLM函数，不是问卷Y，也不是人的认知过程本身。

## 3. 数学上哪里还没有由源观察确定

令v=[a,w]有65个分量。归一化源评分和方向约束组成数据设计A_data。
实测all4的rank(A_data)=20，LOO=15。因此存在分别45/50维的数据核空间。
对任意v0属于该核，v和v+v0在这些有限源观察上的线性预测相同，却可能在
新的输入/方向上不同。Ridge给唯一优化解，不等于源观察给出了唯一机制。

这是已固定设计的线性代数结论，不是证明文本信息不足，更不是证明只有
增加样本或只有非线性才能解决。需要确定新作者用到哪些未约束的输入关系。
同样，源导数训练点少不否定所有导数教学；它限定本次推定的范围。

## 4. 一个明确可检验的接点：正文与条件读取如何共同改变

当前特征z=[z_B,z_Q]，分别为正文均值和最后token。BODY扰动满足Dz_Q=0。
因此对归一化一致的两候选，设delta表示joint-value：

    deltaL = sL(delta_a + delta_wB^T z_B + delta_wQ^T z_Q)
    delta_tau_f = sL delta_wB^T Dz_B[D_f].

这暴露了两个不等价的问题：正文局部运动的斜率，与实际作者差异中正文和
查询状态同时改变时的评分。训练可能用查询项补偿正文斜率变化，使源评分
保持不变；这种补偿是否转移，需要实算，不能从低训练误差推断。

一个纯数学示例L(b,q)=bq说明：同一正文方向的响应是q，既依赖正文又依赖
读取条件。全局加性a+w_B b+w_Q q没有这种条件化斜率。它是可行机制的示例，
不是宣称真实网络就等于双线性式，或本轮失败已经识别出该唯一原因。

[NEXT58](GRAIN_VALUE_TANGENT_COMPENSATION_PLAN_V1.md)只做一次缓存分解，决定
下一次函数/输入设计该保留何种耦合；不在本轮12人上调gain、alpha或PCA。

## 5. 心理辅助解释仍是另一个有来源的连接

GRAIN方向与模型响应相接后，可按相同原文位置生成可核对的候选解释。
精神分析/交流分析中可操作化的关系事件、表达方式编码可作为参照，但不是
把内部斜率直接叫防御机制或自我状态。既有
[同材料解释协议](GRAIN_SAME_MATERIAL_INTERPRETATION_THEORY_V1.md)保留：独立
盲编码与看数字后的解释渲染分开，LLM解释不回写固定分数。本轮没有临床
应用、新受试者读取或新LLM解释实验；其优先级不抢占当前函数机制连接。
