## 2. The new declared generative law

Keep each unchanged HM281 fixed SOURCE kernel, complete episode likelihood L_i,
uniform source-address prior pi_i=1/n, and selected profile g_i. A source address
is an expression-mode prototype, not a literal identification of a new person.
The fine law uses one address for both episodes:

    P_F(A,B)=sum_i pi_i L_i(A)L_i(B).

The profile-shared law uses g across the pair, but resamples the address for
each episode within g:

    pi_g=n_g/n
    P_G(A,B)=sum_g pi_g Lbar_g(A)Lbar_g(B)
    Lbar_g(H)=(1/n_g) sum_(i:g) L_i(H).

The address remains shared WITHIN a complete episode, so its temporal structure
is not replaced by independent per-event mode switching. Averaging transition
matrices first and then multiplying would be a different law. For either law,
the first-episode marginal is the same sum_i pi_i L_i(A).

Early fine posterior w_i gives W_g=sum_(i:g)w_i. At the boundary,

    (R_g w)_i=W_(g_i)/n_(g_i).

This is the original source prior conditional on the current selected profile.
It preserves every function of g, not generally another crossed assignment's
readings. R_g is idempotent; its density-ratio operation is conditional
expectation under the SOURCE reference. It acts on observer belief, NOT on text
vectors or a psychological-noise subspace. The original fine state remains
saved alongside the new state, not silently deleted.

This two-occasion fixed-g model is a hypothesis about observation sharing. It
does not say people have32 true types or cannot change over time. Keeping g
is not proof that a true human trait/state remains constant.
