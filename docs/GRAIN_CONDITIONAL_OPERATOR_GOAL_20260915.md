# Conditional evidence operator: executable research goal

2026-09-15. User authorized execution after the three-round strategic seminar.
Scope: a finite mechanism experiment and construction-rule decision, not universal
human-personality validity. Prior results and lockboxes remain untouched.

## Question and stages

Can a small text-computable evidence change predict a distributed reader action
outside the conditions on which that action was estimated? This is a construction
question, not another personality accuracy contest.

1. Reconcile 270 cached texts and both queries, retaining every refusal. Produce
   108 paired contrasts and 36 cell summaries of GRAIN movement, local and Flash
   readout, and length. Endpoints are separate computations, not independent truth.
2. Source is named/described x diary/opinion/advice, all three seeds, both axes:
   36 pairs. Application is the remaining 72 pairs, tagged task-only, wording-only
   or both-new. All are previously observed exploratory materials. No author data.
3. Use the four existing text-computable GRAIN coordinates. Source-only standard
   scaling of pair differences, no intercept (zero change implies zero action).
   Fixed Ridge alpha=1. Estimate both queries' L12.H0 question-suffix output change
   jointly, then truncate the coefficient matrix to rank 2. No rank/head sweep.
   This is a conditional local action surrogate, not a unique personality basis.
4. On application pairs, add the predicted head change to the low-text reader's
   actual head states. Compare actual score effects with full donor-head change,
   equal-norm random changes and self replacement. Fit direct score-difference
   Ridge on exactly the same source pairs/evidence for a same-budget reference.
   Score predictions use only text features; applying the action still runs the
   frozen reader. Do not call the whole pipeline LLM-free.
5. Report signed effects, RMSE, direction agreement, actual donor action versus
   full text contrast, candidate probability mass, and task/wording strata.
   Paired uncertainty resamples family x task blocks, keeping seeds and both
   axes together. No arbitrary human-prediction success threshold. Report results
   separately for both queries and generator axes.

## Math and decision

Let d_i be a four-coordinate evidence contrast, H_i the concatenated two-query
head-state contrast, and y_i their score contrasts. Fit W and B on source only:

    W = argmin sum ||H_i - standardize(d_i) W||^2 + ||W||_F^2
    B = argmin sum ||y_i - standardize(d_i) B||^2 + ||B||_F^2
    W2 = rank-2 SVD truncation(W)

Applying delta_h = standardize(d) W2 to the low context produces a measured
nonlinear score difference. H and the score are different units; matrix fit is
not an intervention effect. The full-donor control measures the action reachable
at this fixed site, so its unexplained text contrast is retained explicitly.

If donor action transports but compiled action does not, the next question is
evidence sufficiency/learnability, not head search. If the compiled action works
but gives no leverage beyond direct response regression, retain a local model
compression result, not a new measurement theory. If action predictions transport
and explain finite interventions, develop context-specific construction rules;
human interpretation remains a separate link. Null/mixed outcomes close this
finite test with a counterexample, not all theoretical possibilities.
