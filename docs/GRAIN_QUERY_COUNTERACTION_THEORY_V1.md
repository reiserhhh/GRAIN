# 查询差异的回调：已有输入与当前算子分别起什么作用

2026-09-10，第三十五轮 NEXT46。继续同材料、同作者的 GRAIN 方向与查询路径
接合，不把模型内部计算直接命名为人格或临床构念。

## 1. 已找到的机制

NEXT45 发现：同一组正文方向经过上游处理后，两查询的对比先增强、再回调。
本轮把一个明确回调位置 MLP24 拆开。新8作者自身读头模式，已有输入差异项
对最终 T 的有符号投影为 **-.313540**，算子差异项为 **+.067912**，合计
**-.245629**。因此该层主要重新处理已经形成的差异；当前查询造成的局部算子
变化，在总体上反而部分减轻这次回调。

这比“负向层是噪声”更具体，也比“所有层都需要独有的人格专用算子”更简洁。
层号是冻结观察器的零基索引。当前两查询为 neuroticism / confirmation_seeking；
它们还包含不同措辞及渲染，不能只归因于构念词的纯语义。

## 2. 数学对象与精确拆分

在 MLP24 前最后位置，令 x_q 为原生状态，d_qk 为第 k 个 GRAIN 正文方向
传到此处的导数。局部 MLP 增量为 f(x)=W_d[SiLU(W_g n(x))⊙W_u n(x)]，
其中 n(x)=γ⊙x/ρ，ρ²=mean(x²)+ε。

\[
N_x=\operatorname{diag}(\gamma)
\left(\frac{I}{\rho}-\frac{xx^T}{h\rho^3}\right),
\]
\[
B_x=W_d\left[\operatorname{diag}(\operatorname{SiLU}(g))W_u
+\operatorname{diag}(u\odot\operatorname{SiLU}'(g))W_g\right],
\quad J_x=B_xN_x.
\]

这里 J 是 **MLP 增量的导数**，不包含残差连接 I。权重完全相同，算子差异
来自 x 改变了归一化与门控的局部系数，不是模型重新训练。

\[
\Delta u=J_Nd_N-J_Cd_C
=\underbrace{\bar J(d_N-d_C)}_{\text{已有差异的传入项}}
+\underbrace{(J_N-J_C)\bar d}_{\text{局部算子差异项}},
\quad \bar J=(J_N+J_C)/2,\ \bar d=(d_N+d_C)/2.
\]

四格交换 J_Nd_N、J_Nd_C、J_Cd_N、J_Cd_C 可直接算出两项。再用同一
源构造共享 w* 投影，得到它们相对局部对比及最终 T 的有符号贡献。
对称分账平均了两种替换顺序；它是精确代数恒等式，不唯一识别因果中介。

局部对比的投影份额新8为 .918570/.081430，源4为1.080572/-.080572。
不能把这些数当成独立方差或人格信号百分比。局部对比和最终 T 是不同参照
方向，符号与协方差因此必须一起保存。详见[报告](../reports/grain_vector_mechanisms/QUERY_COUNTERACTION_REPORT_V1.md)。

## 3. 真正推进了哪条逻辑

1. **同材料接合可深入到局部计算**：GRAIN 的同一方向，经不同查询形成 d，
   在一个实际神经模块中被不同程度地重新加权；不仅是两个作者总分相关。
2. **语义查询不一定处处需要专用读取**：本位置已有差异项占主导，有理由测试
   共享的源固定算子。当前平均算子仍因作者而异，此结果不直接证明跨作者常数。
3. **符号为负的部分有明确功能**：它调节路径对比，删除它将改变原计算；不因
   与我们想要的增强方向相反就称其噪声。

现有局部结果尚需 H16 输入和原生上游 d。下一步检验固定算子只减去这一处
当前 x 的依赖，不声称一步完成全模型替代。数值重现程度是机制证据，不是
作者问卷相关程度。

## 4. 与先行方法的连接

[Perez et al., FiLM, AAAI 2018](https://arxiv.org/abs/1709.07871)用条件信息调节
特征计算，说明“相同素材、不同查询、不同功能加权”有成熟建模先例。这里不是
把 Qwen 宣称为 FiLM 架构：我们的系数来自实际 RMS/SwiGLU 导数，未增加一个
条件生成模块。可借用的是条件调制视角，而非心理学结论。

[Olivieri与Pérez Rodríguez, 2026预印本](https://arxiv.org/html/2605.25225v2)
将局部干预、响应核与伴随读出组织成统一的响应形式，提供本项目的数学参照。
他们在 GPT-2 类模型检验局部响应，并未证明人格推论或所有模型通用。我们使用
离散有限链式法则，不需要把文本赋予物理场或量子性质。
