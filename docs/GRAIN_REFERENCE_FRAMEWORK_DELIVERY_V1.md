1. **真实文本->查询向量->完整判断/自然变化有可复用函数实例。**两参考矩阵
   在12新作者三查询的完整分数r=.817/.761/.920，自然变化r=.886/.681/.717。

   各样本/目标不同，不能组合成“新版全面优于旧版”。
3. **找到共同程序下不同特质的不同入口。**固定查询的E配置与N链接，TF更多
   经由查询状态。N配置中的方向/偶对称作用分别有r=.451/.453的源关联。
4. **确认有限表示的具体盲点。**均值丢配置、二次偶函数丢方向；原点一阶不足，
   修正积分总作用也不足。我们得到分层功能对象，不将剩余内容一律删成噪声。

## 核心公式与假设账本

| 对象 | 数学性质 | 实验/限制 |
|---|---|---|
| s=b(E)+int J(E,xbar+td)'d dt | 沿路径绝对连续/可积导数下的基本定理 | 内部干预路径，不等于自然语言因果路径 |
| r=基线偏移+函数运输余项 | 同一锚点下精确代数 | M11实测二者都含作者关联；不得独立相加RMS比例 |
| s=f00+E_main+X_main+I | 固定E/x矩形的精确端点账本 | M15实测；I可由混合Hessian二重积分表示，但没估完整Hessian |
| E_main=odd+even | 二元反射群投影 | M19实测；并非一阶/二阶截断，镜像并非相反人格 |
| E_main=sum_G size(G) tr Cov_G(h,g) | 评论中心化与Frobenius内积恒等式 | 均值相同仍能有作用；不删除背景条件 |
| 共同二次场d'Ad | 仅sym(A)影响同一路径标量 | M17有运输正例；M19证明其方向性缺项 |
| 端点约束场g*=g+delta*d/||d||² | 固定度量下最近可行代表；核空间仍自由 | M21有限函数运输几乎不变；不能声称识别唯一神经链 |
| rho=(R_u-mu_ref)/sigma_ref | 固定参考的位置/响应坐标 | API保证批次不改变分数；经验稳定性仍依赖条件与材料量 |
| K_qq'=Cov_material(f_q,f_q') | 同材料功能Gram，半正定 | 各query可有不同token坐标；共同/专属不是词义相似度 |
| Cov(Y,s)=Cov(Y,s_hat)+Cov(Y,remainder) | 同作者有符号协方差恒等式 | 不是独立心理方差解释率，也不是r的加法 |

这些基本数学方法已有来源；本项目的贡献是把查询条件化、作者参照、内部
配置/方向干预、全值/自然响应和源心理关联组织为可执行的同目标证据链。
不主张积分归因、群投影、Ridge或因子分析由我们首创。

## 4W和原系统如何接上

Where：材料来源、topic/situation选择和机会条件；不能把所有选择当混淆删掉。
What：状态配置、证据分配与查询组织；可以用token矩阵和KV关系观测。
Who：同一声明群体中位置、响应和配置的差异，不等于模型拟合误差。
When：自然编辑、时间/顺序、动态响应，测量单位和观察窗口必须明确。

旧MCD/GRAIN是这一方法的条件/作者组织层，不要求每次都对最终读数再乘
“身份权重”。向量相近不是自动人格同类；外部联系给它解释，不能由LLM词名
独自决定。确认倾向等小特质允许先找到功能对象，再寻找适用的行为指标。

## 余下距离如何表述

**方法框架v1有完整输入、构造、使用、解释和错误分类；普适轻量推论未完成。**
现在可以从真实文本提取固定前缀，计算查询特定分数与变化，放到明确参考里，
追踪共享/专属作用和原生模型关联的哪些部分保留、遗漏、抵消。

开放的通用压缩问题是：怎样用更丰富的条件/方向函数和恰当参照覆盖，保留
剩余的心理关联，而不只是更像教师给分。M20/M21没有完成它；这并不要求把
已实现框架继续无限延长成同一个任务。新阶段应有新构造问题，不是重跑旧表。
跨观察器、persona写入/读取互逆、更小心理特质、人体外部验证分别属于扩展，
不作为本次有限构造存在性的否定，也不假称已经证明。
