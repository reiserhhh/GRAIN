## Required mathematical corrections

1. Not all existing alpha gates are constant: token semantic/position matching,
   context chart matching and NAV12 affinity gates already depend on input.
   Only compiled A_linear/A_source has a constant derivative in early query-slot
   coordinates. B4's response attenuation is not proof of cancelled gradients;
   it could involve shrinking, alignment, missing terms or source support.
2. B4 sees all contextual token positions; A packs only query rows and the final
   row. B4's positive signal does not prove A's early P/Q input sufficient. A
   full decoder boundary consists of all sequence positions. Keep sufficiency
   as a competing explanation, not a cleared cause.
3. With the same X, unrestricted output matrix and isotropic Ridge penalty,
   fitting a full vector Y then multiplying by fixed L equals directly fitting
   YL: W=(X'X+alpha I)^(-1)X'Y, so WL is the direct solution. A reader quotient
   alone changes cost/storage, not predictions. A new loss, shared/rank constraint,
   new rows or observable features is needed for a real experimental difference.
4. Pair differences among existing rows do NOT enlarge their linear span or
   supply independent teacher information: Delta Y = D Y. The secant loss
   changes the row metric to I+lambda D'D. New edited endpoint states CAN add
   directions. Describe these separately. Use "有限差分/割线" rather than 秒差.
5. Per-author gamma fitted on the evaluation response is an oracle diagnostic,
   not a deployable correction. Likewise reader-projected inside/outside pieces
   are not necessarily orthogonal; include their cross term. Level-space center
   shifts cancel from differences; do not count recentering as a response gain.
6. Low-rank softmax attention is a reasonable candidate, not a necessary missing
   operation or a novel architecture in itself. We cannot identify alpha as the
   cause from the current correlations. An arbitrary two-target pass requirement
   should not prevent retaining one useful target-specific mechanism.
