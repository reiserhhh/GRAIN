## 1. 唯一终点：可供他人制作文本心理测量的理论基础

**发表一套有数学依据、可复现、可解释且有真实心理/行为证据的构造方法，
使研究者可以依据该方法，为自己的情境制作基于自然语言的测量工具。**

目标包括人格倾向、行为倾向和当次状态。未来的心理咨询、互助团体和人机对话
是应用例子，不是要求现有资料立刻制成临床量表。最终论文的核心应是
“为何可以这样测、如何制作、在什么条件下测到什么”，而不是一个排行榜。

共同基础不等于所有情境共享同一套因子、参数或常模。它应让开发者能够决定：
测量对象与时间范围；必须记录或固定的条件；有用的语言证据；聚合与计分规则；
参照群体；解释方式；新情境需要重新估计什么。资料不足时也应能具体指出缺少
哪种表达机会或外部关联，而非凭空补出人格分数。

**研究方式：发现 -> 构造与使用 -> 针对性核验。** 已有局部关联、数学性质和
有效机制均保留为成果。不再要求先消除所有误差才允许发展方法，也不将做完
工作包、两名agent一致或论文投稿当作理论得到经验支持。

### 1.1 从目标反推机制，不从现有系统反推终点

规划应利用已有知识和证据，但不能把现版GRAIN、向量路径实现或手头数据的
能力当作理论问题的上限。现在不是“成熟GRAIN等待接入另一个系统”，而是
**测量理论、GRAIN方法和向量路径机制仍需共同开发**。历史成果是依据、
候选模块和比较对象，不是必须保留的公理；不足也不能只归因于数据或外部效度。

保持的是目标：为人格倾向、行为倾向和状态的文本测量提供可制作、可解释的
基础方法。允许改变的是证据单位、切片、层级、因子/配置对象、条件模型、
动态算子、参照、计分与解释，以及两系统究竟分工、共用核心还是部分替换。
4W、GLS、固定矩、既有因子和两路线分工都不是理论必须服从的预设答案。

下一阶段按以下方向推进，并允许结果反馈修正上游假设：

```text
测量目标与适用条件
  -> 需要解释的心理/表达/观察机制
  -> 先行理论、竞争解释与现有证据对照
  -> 缺失机制的推导和可区分实验
  -> GRAIN及向量路径的保留、修订、替换或新增
  -> 构造规则与多情境制作示范
```

不能把文献检索变成给现有架构寻找背书。先问同一目标有哪些不同实现，哪些
理论环节现版没有表达，再决定复用什么。现有数据用于发现线索、比较机制与
检验候选方法，不独占理论定义；所需观察不存在时明确缺口，不缩小目标以
适配缓存，也不假设缺失证据已经存在。

### 1.2 两条路线的当前分工，不是固定架构

- GRAIN：组织多人的共同语言证据、条件内差异、选择、路径和群体参照。
- 向量路径：研究目标查询怎样利用同一材料，并提取可重播的证据函数。
- 心理测量：决定这些证据支持什么个体推论、怎样定标、怎样解释。

上述是现有功能清单，不是未来系统的接口约束。向量路径可以改变GRAIN如何
发现和组织证据；GRAIN也可以改变路径研究的测量对象。只要能具体改善测量
构造能力，两者都可以重构，不要求所有新机制嵌入旧特征表。

LLM可以辅助发现、编码与解释；固定数字计分不由临场生成的叙述倒写。
神经前缀仍在运行的方案必须如实称为“无生成式读出”，不是完全脱离LLM。
完全独立于Transformer是保留的技术目标，但不是本阶段基础方法论文的唯一判据。

## 3. 共同数学对象：从测量目标到可实现的证据

### 3.1 先定义要估计什么

用冻结规则从本人文本事件提取证据向量：

\[
E_{u,t}=\phi_q(X_{u,\le t},O_{u,\le t};\eta_0).
\]

其中q是构念问题或匿名探索目标，O是表达机会/条件/角色，eta0是冻结的
编码器、证据函数与版本。phi可以包含GRAIN的分布、条件对比、选择份额、
路径或查询条件化向量。它不必是单一线性轴，也不默认全部成分必须相加。

对条件响应，可用：

\[
m_{u,q}(c,t)=\mathbb E[E_{u,t,q}\mid u,c,t,d],\qquad
T_{u,q}^{\nu_0,h}=\int m_{u,q}(c,t)\,d\nu_0(c)\,dh(t).
\]

nu0规定比较哪些条件，h规定时间窗口，d规定记录/诱发过程。
选择过程另行保留；没有曝光分母时只称“观察到的选择份额”，不称真实选择概率。
被动记录与固定诱发的m不能仅因主题相同就等同。

这先定义一个可估计的语言证据对象。心理解释须由构念论证和独立关联建立，
不因q取名为“外向性”就自动成立。匿名对象可先研究其数学与行为性质再命名。

### 3.2 不再靠稳定性单独决定保留什么

高重复性可能来自目标，也可能来自惯用语或社群。必须区分：证据能否重复、
证据是否对应目标、计分器是否利用证据。模型梯度主要回答最后一项。

一个限制明确、可实现的线性子模型是：

\[
E=L\beta+\epsilon,\quad \mathbb E[\epsilon]=0,\quad
\operatorname{Cov}(\epsilon)=\Sigma,\quad T=b^\top\beta.
\]

若L、Sigma在模拟中给定或在构造侧估计、目标可识别，最小方差无偏线性计分为：

\[
\min_a a^\top\Sigma a\quad\text{s.t. }L^\top a=b,
\qquad
\operatorname{Var}(\widehat T-T)=b^\top(L^\top\Sigma^{-1}L)^{-1}b.
\]

这是标准广义最小二乘，不是GRAIN首创。Sigma允许片段依赖；公式本身不消除
选择偏差或定义心理真值。无标签材料可估计部分协方差和支持度，不能单独认定
哪个方向更具有心理效度。病态或不可识别情形须换可估计目标/设计，不机械求逆。

### 3.3 同一公式为何可以指导不同窗口

一个说明性模型：每人D个独立机会，每次有n个片段，N=Dn固定，
\(E_{u,o,k}=\theta_u+s_{u,o}+\epsilon_{u,o,k}\)。theta在指定窗口固定，
s与epsilon相互独立且均值为零，方差分别为sigma_s^2和sigma_e^2。
对全部片段取均值时：

\[
\operatorname{MSE}_{\theta}=\sigma_s^2/D+\sigma_e^2/N,\qquad
\operatorname{MSE}_{\theta+s_1}=\sigma_s^2(1-1/D)+\sigma_e^2/N.
\]

目标是较长窗口倾向时，多机会平均有益；目标是本次状态时，同样平均会混入
其他机会。这是给定假设下的推导例子，不是“一定多收几天”或“一定只看短文”
的普遍规律。有自相关、异质条件或稀释效应时应重新计算协方差与目标。
当前MEPS资料不允许估计一个完整个人时间核，更不要求真人每天重复同一话题。

### 3.4 用目标信息而非全部模型梯度评价表示

对平方可积目标T、完整可用证据E及其确定压缩Phi(E)，总体最优平方损失满足：

\[
R^*(\Phi(E))-R^*(E)
=\mathbb E\left[(\mathbb E[T\mid E]-\mathbb E[T\mid\Phi(E)])^2\right].
\]

这是条件期望的标准投影性质。它指出条件对比、路径、剩余配置可能保留什么
额外目标信息，不保证某个有限样本模型能学到它。实际实验另计估计误差，
不从一个模型未提升推出信息不存在。若T是教师判断，结论只关于教师；若T是
自评或行为效标，结论针对该效标。二者分别报告，不互相替换。

### 3.5 三种参照与两种关联

| 对象 | 决定什么 | 应怎样检查 |
|---|---|---|
| 读出展开点 | 局部近似在哪些向量附近有效 | 换点后的函数误差和材料支持，不只比较r |
| 目标条件分布nu0与窗口h | 哪些表达条件/时间进入估计量 | 改分布是改变估计目标，不当作任意数据增广 |
| 常模群体P0 | 分数相对谁、原点和单位怎样定 | 冻结群体后单人计分、重建常模、水平/排序/区间变化 |
| 线索有效性 | 某证据与作者的独立心理或行为指标的关系 | 构造侧确定问题，验证侧报告关联与混淆对象 |
| 线索利用 | 固定模型怎样使用证据形成判断 | 数学作用、干预和读出；不当作作者属性的真值 |

Funder的[人格判断模型](https://rap.ucr.edu/FunderPR1995.pdf)为最后两项提供
心理学衔接：相关线索的出现、可获得、被发现和被使用是不同环节。
GRAIN组织证据，向量路径解释使用方式，外部关联赋予心理含义。我们不是首创
这一区分，而是将其变成可执行的文本测量构造流程。

### 3.6 不同局部工具的可比性：本轮新增的必需拼图

“同一算法产生两个分数”不是通用性的充分证据。区分三个层次：

| 层次 | 要保持什么 | 不能据此推出什么 |
|---|---|---|
| 制作规则相同 | 目标定义、证据构造、参数估计、参照与解释步骤 | 两套工具自动测到同一心理属性 |
| 构念可以比较 | 跨语料的构念图/操作性对比、时间含义、锚点及预期关系可对应 | 载荷、均值、方差或全部相关符号都相同 |
| 数字可直接链接 | 共同人/任务/有效锚点、支持范围与计分单位的链接证据 | 不同人群的真实差异可被任意标准化消除 |

Study B必须在构造前给出共同目标定义及各域的映射表。nu0、h和P0变化可能改变
估计对象；不能一边变目标一边要求所有相关都同号同序。只有在链接假设成立的
部分检验同方向/可比较关系，并报告其余条件依赖。出现反转时定位是构念、
语境、效标、计分还是取样差异，不自动全判为模型失败，也不事后改名消解反例。

PANDORA百分位标签与Essays标签的粒度、量尺和时间指向须在F0核实，二值标签
不能直接当成另一组连续百分位常模。缺少等值链接证据时保留局部分数，仍可
检验共同制作方法和构念关系，但不混合排名或宣称已经得到国际统一量表。

### 3.7 实施族与支持规则

三个已有的最小实施例是：带地址证据的线性GLS；加入明确的非线性/路径/交互
坐标后计分；材料支持时的条件化状态估计。它们不是整个研究的候选上限。
先由新增开发阶段比较所需机制，再为每个有界实验固定候选和评价方法；不能
在验证侧看到结果后改公式而仍称原验证成功。第三项须明确实际状态与机会变量，
不能在单次文本中强行估计完整个人动态系统。构造侧选择，验证侧冻结。

缺少共同支持时，先限制目标到有覆盖的条件。若要部分识别区间，必须有评分
定义本身给出的范围或明确外部假设；观察到的最大最小值不自动约束未观察单元。
否则写出需要怎样的诱发/采样，而不是加一个可任意调整的偏差常数。

### 前置开发F-1：由理论缺口决定GRAIN需要长成什么

F-1不是给旧版本补防御，也不是多加一个验收表。它必须产生待推导、待开发的
具体机制与架构选择，必要时改写Study A-C。先从以下问题域建图；这些是规划
问题，不是已经确认的缺陷、穷尽性分类或必须保留的新模块。

| 问题域 | 应由理论和比较解决的设计问题 |
|---|---|
| 属性如何进入表达 | 倾向、当次状态、选择、角色与互动如何共同改变可观察证据？哪种过程模型会导向不同取样/计分？ |
| 不同文本如何成为共同证据 | 共同单位应是token、片段、事件、关系还是路径？切片在哪些目标下有益，何时应替换或省略？ |
| 个体差异怎样组织 | 因子、分布、局部配置、响应算子如何形成群体可比较的测量对象，而非仅能区分作者？ |
| 语义与向量路径如何进入GRAIN | 路径能否改变证据发现、聚合或心理解释，而不只是给既有特征附加标签？两系统需要怎样共同重构？ |
| 目标、条件与时间怎样决定计分 | 哪些差异属于目标、条件或未知成分？何时聚合、何时保留异质性，怎样产生可复算分数？ |
| 从数值到心理解释 | 解释需要哪些可检查的证据关系？何种新观察能区分心理机制与仅有计算相关的竞争解释？ |

每个优先问题交出：测量目标要求、现有/先行方法的覆盖、缺失机制、至少一种
实质替代方案、能区分方案的推导或实验，以及相应的保留/修订/替换/新增决定。
不为了“高级数学”本身增加公式，不以旧代码易于复用作为理论选择理由。

先选最能增加测量构造能力的少数问题开发，其余保留在缺口图中。每个有限
开发批次结束后更新公式、实现规格和验证设计，不把开发者对当前数据的不断
适配冒充一次冻结验证。旧成果保留其原条件下的地位；改架构不等于推翻历史。

首轮交付是**目标要求-机制缺口图、GRAIN架构修订提案及优先实验规格**，
而不是直接冻结旧实施族。方法取得正面能力后再进入相应制作与验证示范。

### Study A：从目标推导表达取样与聚合规则

问题：同样的文本预算，为何自由选择、条件对比、跨机会聚合或当次状态读数
有时更有效？方法能否事先指出何时该换收集设计，而不是只换预测器？

1. 根据F-1确定待比较的机制与表示。3.2至3.4的E、L、Sigma、b模型作为可解释
   特例和基线，不要求新GRAIN的所有证据都能装入这个模型。
2. 构造五类已知机制世界：选择主导、条件响应主导、状态/路径主导、稳定但
   与目标无关的作者习惯、缺少共同支持。每类加入至少一个会改变设计排序的情形。
3. 固定总材料预算，比较朴素合并、条件化、多机会及目标窗口策略。主要评价
   已知目标的MSE、偏差和区间覆盖，不把MSE排序自动当作Pearson排序。
4. GLS作为最小可解释特例。预设一个有实质理由的非线性/交互扩展用于其失配
   情形，不把所有未解释部分塞进自由调整的“bias”以保证成功。
5. 不只解释结果：规则必须在评价之前选择设计。已知L/Sigma的oracle核对
   理论最优；有限样本估计版报告选择准确率、相对最优的regret和区间，允许
   近似并列。不要求每个随机种子都精确选中oracle。

正面验收：给出至少一条在假设范围内可证明、在独立仿真世界可重现的建设性
设计收益，并指出导致排序反转的变量。理论来自一般机制，既有MCD增益是动机
和可选重分析，不要求用衰减公式拟合到`.023608`。
默认对照为同一组证据的等权聚合，不使用故意丢掉全部有效线索的弱对照。

交付：推导、机制-设计图、可重播仿真及一个从输入规格产生设计建议的规则。
仿真不充当真实人格效度，也不以prompt直接写入人格标签来伪造成功。

### Study B：同一规则在自由与固定材料中制作局部工具

问题：不是一个模型能否无调整地跨域，而是同一制作法能否在不同情境下工作。

当前可行的两个候选实例是PANDORA自由文本与Essays固定写作；F-1若指出它们
不能区分关键机制，应补充或更换获准的材料设计，不因此删去该理论问题。
每个语料按作者分开构造和评价，所有特征、常模、参数与表示选择只在构造侧
完成。当前语料已反复
探索，应标记为开发/重分析；不把新切分重新称为首次盲测。

最小共同比较族：

- 朴素合并的文本/向量证据；保留已有强线性基线。
- 固定语义锚点投影，比较整文与预定片段聚合。
- 同材料原生LLM分数及来源冻结读出；优先复用合法缓存。
- 原生/冻结分数与语义投影的非地址组合，控制“混合后只是多了特征”的解释。
- GRAIN条件、选择与路径证据。
- 按Study A规则组成的共同证据，不预设混合一定更优。

主示范同时保留一个有外部锚定的人格目标与一个匿名条件/路径目标。
PANDORA五个Big5与四个MBTI轴均列入结果地图，解释标签方向与任务差异；
不以全维度都提高作为唯一成功条件，也不只展示最优一列。

评价四类输出：目标损失及心理关联；设计预测与观察结果是否相符；固定参照
下的分数水平/不确定性；证据解释。Pearson、AUC、MSE各自保持口径，不统一
成一个“成功r”。构造规则估计时可以用获准的构造侧锚点，不能使用验证效标。
真人潜在T未被直接观察，故效标MSE、重复材料分数差异与理论MSE_T须分列。
3.4的精确Bayes风险差只在已知机制世界计算；真人材料中报告受限估计器的
作者外预测比较，不假装观测到了真实人格条件期望。

正面验收：至少两个局部实例按同一规则产出可复算分数，并在其中建立实际
心理关联；还要展示一种超出朴素评分的实质能力，例如更合理的取样、更有效的
条件对比、水平可重现或有证据支撑的解释。优势不必全部表现为更高r。
如果仅持平，必须说明新增能力是什么并量化；不能把不显著差异称作统计等价。

### Study C：当次状态、行为解释与独立复建

**状态。** 使用来源侧冻结函数，在MEPS本地做评价，不在46人上训练、选择
参数、定标或估计用于后续计分的协方差。可以报告评价侧的描述统计和关联，
不能将它们倒灌为构造参数。既有相谈POST关联和MID对照作为重分析起点。
测量目标是这一会话/时点的状态，不强求跨日常数或完整个人时间核。
从其他来源搬来的协方差或区间也需要评价，不能因“来源冻结”就声称已校准。

**行为。** 先核实已有独立行为效标及其使用权限。优先合法的任务表现/独立
行为编码；明确“在本文里如何表达”与“现实中会如何行动”的区别。
没有效标时，匿名或可观察行为对象可以交付，但跨文本现实行为的验证任务
仍保留为未完成，不能悄悄从终极愿景中删除，也不自动要求新增临床试验。

**解释。** 每个示范提供三层：本人材料地址与相反证据；哪些数值运算使分数
变化；独立内容/心理/行为依据如何支撑该解释。LLM可以起草语言，不能既创造
心理真值又证明自身解释正确。任何私有原文的展示与人工编码需对应权限。

**复建。** 由未参与某一实例设计的执行者，按构造手册重建一个实例并在第二
情境实例上复用规则。记录其不得不询问的理论/方法缺项。允许领域判断和局部
参数估计，不允许作者临时发明关键步骤后把它称为已经通用。
独立执行者与独立语料分开登记。X也影响过GRAIN历史开发，不是未暴露数据；
在X复建可检验手册，但不是新的盲效度验证。若找到许可明确且真正未用于规则
开发的公开语料，再承担独立语料复建；不可把该数据槽写成已经存在。

正面验收：现有状态关联纳入同一证据模型；解释能回指真实计算；独立复建不依赖
口头秘方。任何尚不可取得的行为证据，须列明可执行获取方案和它限制的主张。

## 5. 数据不是理论的定义，而是构造方法的试验场

| 数据 | 本阶段用途 | 固定限制 |
|---|---|---|
| PANDORA official | 自由文本局部构造、外部Big5/MBTI、取样与条件比较 | 作者分开；轴标签/fold协议明确；报告已暴露历史 |
| Essays | 固定情境的独立局部构造 | 不是与PANDORA同一群人的跨情境测量；不强制同系数 |

| X市场文本 | 领域内条件、时序与可观察行为配置 | 没有核实的心理/交易效标就不宣称相应效度；按许可访问 |

人物、角色、观察窗口、语言与AI协助都属于取样定义。文本少并不等于人缺少
某种特征；没有出现目标证据时，记录覆盖不足，不记成极低人格分数。
条件差异可以作为信号，也可以作为待固定条件，取决于目标，不能全局定义成噪声。

实际必须有权限的独立行为效标，是当前最明确的材料缺口。跨语言计量等价、
临床诊断阈值和真实咨询中的行动效度留在未来应用验证，不冒充本阶段已完成。
但对应的取样、构造、链接和解释规则应在本阶段给出。

## 7. 何时算完成，不再用版本号代替成果

| 必需拼图 | 完成证据 |
|---|---|
| GRAIN方法得到发展 | 从目标要求推导出架构选择；必须补足的机制有实现和证据，不能只把旧系统接通或写成手册 |
| 建设性的理论 | 一个具体规则说明如何产生更有信息的测量，而非只说何时不能测 |
| 数学与实现一致 | 计分器确实实现推导中的对象，仿真能恢复目标并呈现预期反转 |
| 方法可以制作东西 | 同一流程在至少两个不同情境产生可解释、可复算的局部实例 |
| 目标可以比较 | 共同构念/操作目标及局部映射明确；数字等值需要的额外证据单列 |
| 心理意义 | 人格与状态的真实独立关联进入统一证据链；行为主张有相应证据或明确未完成项 |
| 可解释性 | 材料、运算、心理含义三层分开且能核对，不只给因子取名 |
| 方法可传递 | 独立执行者能按手册复建；局部重校准不等于临时改写理论 |
| 论文论证 | 继承与新增贡献明确，正面证据与已知边界同表，三语术语一致 |

不使用统一的r>.5门槛。按目标报告效应大小、区间和用途；高相关不是唯一贡献，
小而可信且可解释的关联也有价值。与此同时，无心理意义的高作者识别率不替代
心理测量，模型保真度不替代效度，未完成行为验证不登记为完成。

这定义的是本阶段论文的完整研究论证，不声称穷尽所有未来机制。发现新的必需
前提时修改相应构造规则；普通精度改进与未来应用扩展不再无限延后本阶段完成。

**批次完成与终极目标达成是两件事。** 若设计规则未获支持，或局部工具没有
相应心理关联，该批次仍应完整报告并结束，不无限增加实验直到出现好结果。
可以产出限制性/否定性论文，但不能据此宣布用户的积极目标完成。缺少必需的
行为证据时也一样：材料表完成不等于行为效度完成。只重开被结果指出的具体
机制或证据任务，不重启无边界的精度搜索。

## 8. 先行研究怎样具体改变了计划

| 来源 | 我们继承的东西 | 计划中的具体变化 |
|---|---|---|
| Wilson构造模型、Mislevy等ECD | 构念、任务、证据、计分的设计逻辑；也包括复杂互动任务 | 保留领域判断，不把Build当黑箱，不把ECD贬成只会固定题目 |
| Funder人格判断模型 | 区分相关线索、可获得性、发现与利用 | 外部心理关联与模型作用分列，成为两条路线的接点 |
| Kjell等语义测量、text工具 | 开放回答、向量化、预测与语义投影已有成熟先例 | 加入真正接近的对照，不宣称首创文本心理计分 |
| Luongo等2026预印本 | 构念锚点与句级聚合的直接比较 | 增加整文/片段投影对照；不照搬其衰减修正高r或独立折半假设 |
| G-theory、LST-R、最优设计 | 参照、目标时间、依赖与估计精度 | 从重复性地图改为目标相关风险，不给所有构念统一窗口 |
| Peters等对话、Wright/Ringwald日记 | 任务及取样方式改变可用心理信息；多模型与时点分析已有先例 | 同材料基线与本地状态实例，不以“能读LLM答案”为完整新增贡献 |
| Koutsoumpis等语言线索元分析 | 自评/他评、任务、线索关系不同 | 不将单一问卷相关作为全部解释，也不把评定者印象当作者真值 |

目前的原创候选是**带作者/条件/机会/时间/路径地址的共同证据构造，加上目标相关的
聚合、设计、参照与解释规则**。单个统计恒等式、投影或回归不是原创。
这不是未来GRAIN只能采用的架构。最终新增贡献由方法开发与Study A-C相对
上述方法展现的能力决定，不能靠命名认定，也不能预先保证顶刊发表。

### 来源与阅读深度

- Luongo, Marocco & Milano (2026), [Semantic Projection](https://arxiv.org/abs/2605.04873)：预印本方法及结果表；不是已审定基准；最高相关为部分衰减修正值。
- Mulder & van der Linden (2009), [Multidimensional Adaptive Testing](https://link.springer.com/article/10.1007/s11336-008-9097-5)：正文2-4节，已校准参数、条件独立和目标相关设计准则。

Cronbach等1972原书是否直接处理“自选facet”的具体请求仍未核实；未找到不等于
不存在。此项影响优先权论述，不妨碍先实现已说明假设的构造模型。
