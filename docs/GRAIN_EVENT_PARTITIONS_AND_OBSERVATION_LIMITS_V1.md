# Event Partitions and the Limits of Teacher Fidelity

2026-10-09. Theory interpretation after the frozen HM59 experiment.
The frozen plan/materials/code remain unchanged. The full research goal is open.

## Separate the estimands

A text H supplies mentions, actor-scoped event relations, narrative order,
conditions and content. A reader observation O_q(H) is not the author parameter
theta_u. Accurate emulation of O_q is a tool achievement; it can also emulate
misbinding, positional effects and response bias.

An event reference is a declared measurement operator. Let B be the binary
mention-by-event incidence matrix with one event assigned to each mention.
With D=diag(B^T 1) and k nonempty events:

    S_event(p;B) = (1/k) 1^T D^-1 B^T p
    S_mention(p) = (1/n) 1^T p.

This is standard linear algebra, not a new theorem. Equal event weighting is
an explicit design assumption, not a universal personality posterior. Event
time, narrative position and relation identity must not be silently equated.
Conditions and narrative emphasis remain available alongside the event account.

## What HM59 establishes

384 passive reads and 192 exact full-token-bag contrasts changed only explicit
same/different-event assignments. Native scheme-contrast RMS was .018459 for
the queried actor's declarations and .015709 for other-actor declarations.
Their paired correlation was .943792; actor double-contrast RMS was .006718.

The code-neutral equal-event reference shifted .202222 RMS in the own-actor
arm and exactly zero in the other-actor arm. The reader did not implement that
reference direction consistently (27/96 own-actor contrasts aligned). These
are controlled-material response measurements, not psychological validity.

Thus an explicit partition belongs in the intended measurement interface, but
we cannot substitute arbitrary reader response to partition declarations for
that interface. The difference can concern declaration interpretation as well
as downstream aggregation. It does not establish one unique internal cause.

## Mainline decision

Close this finite template diagnostic branch. Do not repair it by selecting a
successful syntax, tuning injection strength or improving teacher fidelity.
Preserve raw reads/captures as evidence and the relational interface as a
candidate object. The next research decision must return to qualified evidence
composition, shared/target-specific operators and author measurement.

Before tool optimization, state the competing mechanism explanations, the
observational error that prevents distinguishing them, the new discriminating
test and its bounded stopping decision. A lower RMSE alone is not a new law.

Higher-order pooling and relational representations have established ancestry:
[Janossy pooling](https://arxiv.org/html/1811.01900v3) and
[Graph networks](https://arxiv.org/html/1806.01261v3). OpenAI/math conditional
path-flow arguments inspired preserving conditional objects, but their
independent-switch assumptions and mixing bounds were not transferred to LLMs.
Novelty must be assessed at the author-evidence/measurement mechanism, not by
renaming these mathematical tools.
