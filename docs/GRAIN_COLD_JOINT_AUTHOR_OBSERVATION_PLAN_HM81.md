# HM81: Source-Frozen Joint Evidence and Cold Author Observation

## Decision and scope

This is an operational construction packet, not an accuracy search or a new
mathematical theorem. HM78's source score fiber and HM79--80's relationship
effects are retained. We stop actor/count/fidelity controls here.

Question: can a source-frozen observation bundle consume individual new records,
retain same-record structural/query associations, and give an explainable author
profile without an application counterfactual table or fitted inverse?

Use the existing **flat lexical reference** implementation (`WordFactorReference`,
PCA/varimax, four anonymous coordinates, 200 vocabulary cap). Fit it only to
HM79 family-0 public synthetic bodies. This is one existing GRAIN-compatible
structural observer, NOT the historical SU7-FC four-coordinate model, the full
token-slice hierarchy, a new factor discovery claim, or psychological calibration.
The six query observations remain the fixed local Qwen reader, not an LLM-free
text encoder. Aggregation after these observations is purely numeric.

## Frozen construction

- Source: the 480 HM79 family-0 bodies and their 2,880 actual six-query readings.
  Verify the source raw seal and every selected score record; never read family-1
  scores to construct the bundle. Reuse source scores, no source neural rerun.
- Application: 8 synthetic author records, 8 distinct episodes each, 64 new
  two-person accounts. Two recorded conditions (ordinary/deadline), fixed balanced
  schedules, both existing wording families, new context/presentation. Each
  episode has ONE actual body and six readings, not a complete intervention cube.
- 384 new local full-reader calls, block16 capture, max 240 model seconds;
  0 API/generation/new neural training/human labels/private text. No automatic
  retry after uncertain attempts. All primary code/config/materials frozen first.
- Exactly one source lexical fit and one source moment calibration. No teacher
  regression, label model, head/layer/rank/factor-count/regularization sweep.

For source-centered and source-scaled structural/query readings g in R^4 and
q in R^6, retain phi=(g,q,vec(g q^T),{q_j q_k:j<k}), 49 coordinates. Source
feature means/scales are frozen. Marginal, same-unit product and conditional
profiles are distinct output fields. Condition prevalence is retained, not
centered away. Unseen conditions use the same global coordinate calibration and
are flagged, never assigned a fitted source condition mean.

Author output is the event-weighted empirical expectation of phi. Also report
E[g q^T]-E[g]E[q]^T. This covariance is an observable association, NOT an
individual response operator B_u. A fixed finite feature map defines a PSD kernel
and an empirical mean discrepancy, not a characteristic kernel or latent
distribution recovery guarantee. No formal two-sample p-value is claimed.

## Cold contract and checks

The cold CLI accepts only an authenticated source bundle and author JSONL:
author_key and events(event_id, condition, qualification, observer_id, grain,
query). Qualification is explicitly supplied record metadata, NOT a newly
validated automatic actor parser. In this packet Person A is the declared focal
subject. Keep other/unresolved events as counts and emit null if no eligible
events; do not invent a zero/neutral personality score. Deduplicate identities
by rejecting conflicting or repeated events, not by text similarity.

The scoring process has no application body, truth, source score table or
counterfactual support. Produce the same result singly and in a batch; contributions
sum exactly to the author vector. Seal all source/application provenance and
record actual calls. Verify source/readout identities and numeric aggregation by
an alternate formula. Tests cover paired products vs product of means, kernel
identity, cold invariance, qualification, conditions and contribution accounting.

## Acceptance and stop

Accept only the finite cold **interface** if these checks pass and actual new
readings are processed. Report all source and cold distances/couplings without
a winner threshold. Any observational separation is not author identity accuracy,
psychological validity or a new mathematical discovery. Do not promote original
18/100/44 scope or claim universal personality measurement.

Next scientific question after this interface is meaningful author measurement
under known evidence/condition laws, not another covariance/accuracy grid.

## References

space are an established distribution-comparison tool.
Muandet et al., Kernel Mean Embedding of Distributions (2017),
