## Fixed new construction

Six positive evidence recipes use P(f,c,b)=w_f*pi_c*(1+b*t_f(c))/2,
t_f(c)=a_f+B_f*c. Recipes are: flat; level +.4; level -.4; alternating
condition slope .4; mixed alternating level .2/slope .3; the same mixed
conditional behavior with family weights1:2:3:4:5:6 and condition+ share .7.
These are anonymous numeric recipes, not named personality types or truth.

For each slot/recipe/three fixed seeds draw256 atoms and double each count,
giving36 ledgers of512 distinct designed events. An address references an
actual endpoint template; repeated addresses are distinct simulated events,
not permission to count duplicate natural reports as new evidence.

Five fixed routing policies share each ledger's evidence counts:
A only, B only, half each, positive-coupled, negative-coupled. In each of12
family/condition groups, let n+ and n- be even event counts and
k=floor(min(n+,n-)/4). Start with half each, assign k additional positive events
to A and k negative events to B; the opposite policy reverses those assignments.
Thus the last three policies have EXACTLY the same focus counts even within
family/condition. Coupling sees event polarity/counts, never native outputs.
No threshold/policy is picked by a favorable target effect.

## Common reference without deleting author choice

Let J_u(e,r) be the joint event/focus proportions and P_u(e)=sum_r J_u(e,r).
The cold kernel computes

    S_u = sum_e,r J_u(e,r) K(e,r),
    S_star_u = sum_e P_u(e) [K(e,A)+K(e,B)]/2,
    C_u = sum_e,r [J_u(e,r)-P_u(e)/2] K(e,r),
    S_u = S_star_u + C_u.

Both S_u and C_u are retained. If the focus was supplied by the instrument,
C is an instrument-policy contribution. If chosen by the author, it is an
author-choice contribution; do not label it nuisance or remove it by default.
The same numeric ledger is relabeled once as a PROVENANCE INTERFACE TEST,
not an assertion that HM117's experimenter-supplied focus was author-chosen.
Unknown origin is rejected. Raw targets/context/state channels are not centered.

For the coupled-policy pair, an independent per-group formula is

    Delta S = sum_g (2k_g/n_total)
      [K(g,+,A)-K(g,+,B)-K(g,-,A)+K(g,-,B)].

This identifies an evidence-by-instrument pairing term despite equal margins.
The formula is classical finite probability, not a novel theorem, personality
factor, causal human effect or an accurate inverse of an LLM.
