## Fixed observation laws

For window distributions p_u0,p_u1, profile c, n_c, pi_c=n_c/N and means mu_cw:

    J_profile(q,g,a,b)=sum_{c:c_q=g} pi_c mu_c0(a)mu_c1(b)
    J_other(q,g,a,b)=1/N sum_{u:Y_uq=g} p_u0(a)
                        * mean_{v!=u:C_v=C_u}p_v1(b)
    J_same(q,g,a,b)=1/N sum_{u:Y_uq=g} p_u0(a)p_u1(b).

All three are valid nonnegative laws with the SAME full profile prior, early
and late target-conditioned marginals. Other-author uses distinct authors,
not a product reference that accidentally includes self with probability1/n_c.

    J_same,c-J_profile,c=Cov_c(p0,p1)
    J_same,c-J_other,c=n_c/(n_c-1)*Cov_c(p0,p1).

empirically;386*17*17=111554 cross pairs are clustered, not111554 subjects. No
