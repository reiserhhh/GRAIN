## 2. Observation and mechanism transformations

body access to question-prefix tokens. It still has task wording, positions,
length and preamble support. It is not a generic nuisance to subtract.

    whole_foreign:     V'_q = B_pi(q)+I_pi(q)
    increment_foreign: V'_q = B_q+I_pi(q)

B_q-B_pi(q). At fixed native final reading weights p the forcing difference

final readout need not be additive in B/I. Direct final body access, p and all

    T_q(m;y) = d_q(y)^T Cov_u(dx_u, R_m,u,q).

## 3. A paired target-assignment/operation test

Let H contain the SOURCE author vectors. With the matched coefficients c(y)
within other4-label strata, d(y)=H^T c(y). For fixed cached readouts let
a_m=Cov_u(dx_u,R_m,u,q). Then:

    T_q(m;y) = c(y)^T H a_m
    Delta T_q(y) = c(y)^T H(a_m1-a_m0).

Target-assignment exchange changes c, whereas the declared intervention changes
the already observed a. These operations commute in this STATISTICAL account;
this does not assert that two physical neural interventions commute.

Under group G preserving all other4 rows and all32 profile counts, E_G[T]=0.
For any matrix of SOURCE projections t, exact orbit covariance is:

    Cov_G(T) = sum_b omega_b^2*n_b/(n0b*n1b) * SampleCov_b(t).

For a contrast vector l, Var_G(l^T T)=l^T Cov_G(T)l. It is not the sum of two
independent mode variances. The same995 old assignments are shared across
views/modes and no new reference draws are made. Native/whole/zero relations
are not independent studies.

Signed telescoping holds by subtraction:

    native-whole_foreign
      = (native-increment_foreign)+(increment_foreign-whole_foreign).

This is an exact bookkeeping identity, NOT a causal information-fraction
decomposition; nonlinear and redundant routes can coexist.
