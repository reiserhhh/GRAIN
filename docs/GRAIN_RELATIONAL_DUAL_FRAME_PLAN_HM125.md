factorial design identifies twelve action columns, six families x two conditions:

    d_(f,c) = mean_(wording,b,actor) b*actor*h_(f,c,b,actor)
    D = [d_01,...,d_12],  mu = mean_source(h).

No rank, regularization, layer, metric or target-fidelity search. If D lacks

coordinates. Source metadata calibrates D only; it is not an application input.

For any numeric current-state vector h:

    z(h) = B(h-mu),  r(h) = h-mu-D z(h).

Keep z, r and mu together. r is not deleted or called noise. Coordinates are
RD01--RD12, calibrated response directions, NOT twelve discovered personality
factors. B D = I is a calibration identity, not an empirical breakthrough.

For each view compute its own actor-action columns D_v for evaluation ONLY.
The deployed B is never changed. The coordinate transport is M_v=B D_v.
The paired-author score contrast satisfies

    n_cells*(S_theta-S_minus_theta)/2 = M_v theta_visible.

reverse channels. Report full M_v, singular values, diagonal/sign/cross-condition
