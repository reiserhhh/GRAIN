# HM144: source-supported cross-material configuration operator

## Decision and scope fixed before vector-outcome computation

The preceding turn audited accuracy-versus-mechanism work; no new experiment
was run. HM143's next interface is a source-supported soft joint law. Metadata
inventory found 624 authors x36 distinct publication events, but only 12 source
authors support the best exact three-venue tuple (0 validation, 1 held). Do not
fit a three-condition latent-class system to that sparse support. The inventory
used metadata and checked vector shape/hash; no joint outcome was previewed.

This packet asks whether a signed joint observation law learned on one author
cohort has a corresponding action on disjoint author cohorts. It is not a
teacher fit, prediction leaderboard, natural-text latent-class discovery, or
test of psychological meaning. All 18/100/44 parent requirements stay open.

## Frozen mathematical question

For three parcel observations X,Y,Z, construct the signed Lancaster law

    D = P_XYZ - P_XY P_Z - P_XZ P_Y - P_YZ P_X + 2 P_X P_Y P_Z.

Gaussian kernel embeddings give T = E[(phiX-muX) tensor (phiY-muY)
tensor (phiZ-muZ)]. Learn source T_S, preserve its sign, and measure
<T_S,T_A> on each independent cohort. Report its norms and normalized
alignment separately: that alignment is not Pearson personality correlation.
Per-parcel cold witness readings use source means only; cohort alignment uses
the recipient's empirical marginal means to define its law, not to fit a score.

Each of three single-view relinks holds the other pair and all one-view
marginals exactly fixed. Use499 global and499 coarse-stratum relinks, the same
addresses across channels, no favorable seed selection. These relinks do not
hold ALL pair distributions fixed. Report signed statistic, null quantiles,
conditional Monte Carlo tail fractions and max across the three cuts; finite
cohort matching is not guaranteed causal or conditional-independence inference.
Report pair interactions and total dHSIC for diagnostic context, not a new score
selection rule. Lancaster nonzero can arise from ordinary pair-connected or
common-author mechanisms; no claim of irreducible three-way synergy.

1000 whole-author source+recipient bootstrap draws, conditional on frozen
feature/kernel choices. Resampling does not refit the historical directions.
Negative or unstable transport remains a result, without kernel rescue.

## Alternate checks and acceptance

Explicit finite-feature tensors must reproduce the kernel formula; XOR and a
pair-only world distinguish pair, Lancaster and total-dependence readings.
Check fixed source-only cold scoring, source/recipient disjointness, unique
event addresses, complete nonoverlapping parcels, coordinate/metric transport,
joint author renaming, and relink pair/marginal preservation. Independently
recompute actual inner products using Gram matrices and explicit centering
operators; save aggregate checks and local private numerical arrays.

Successful execution means the registered mechanism question has actual
numerical evidence and a consequence for the next packet, not that its result
is positive. No original scope promotion, Git, lockbox, Claude, or automation.
