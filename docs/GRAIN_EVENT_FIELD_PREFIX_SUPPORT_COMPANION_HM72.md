## Question and mathematical consequence

An event-aligned hidden vector of a causal reader is a function of the actual
tokens available up to that event, not all events in the account. Exact event
identity does not imply the same information opportunity after reordering.
For each bank/pair/order/event, derive factor availability from actual token
prefixes under all paired x/y/g flips. Do not infer availability from a high
cosine or from a linguistic explanation of the passages.

Let A(o,e) contain factors whose flip changes the observed prefix. On the
complete independent eight-cell design, let H(o,e;z) be the frozen observation
and chi_J(z) its Boolean character. Causality gives the standard support law:

    J not subset A(o,e) => coefficient_J(H(o,e)) = 0.

Proof: pair cells differing in a missing factor j in J. H is unchanged while
chi_J changes sign, so the coefficient cancels. This is ordinary causal
masking and Boolean orthogonality, not a new theorem. Small finite-execution
discrepancies are reported rather than fitted away or called psychological noise.

Apply all7 characters to all30 pairs/both banks/both orders/all3 events and
all3 event field definitions. Keep coefficients outside/inside the predicted
support. Check whether forward/reverse allowed slots overlap for each character,
and report the actual within-bank direction without choosing favorable terms.

## Scientific decision and stopping

Disjoint allowed event slots can make cross-order interaction directions
orthogonal even when both orders contain a reproducible interaction. Then
order mismatch partly changes what an event observation can possibly contain,
not merely measurement precision or author personality.

This does not explain every order effect, prove semantic binding, or identify
a person's response operator. It changes the observation specification from
H(e) to H(e | available prefix). The next mainline construction must equalize
or explicitly retain information opportunity before comparing author effects;
it must not optimize a regressor to compensate for an impossible early read.

before calculation. Save all support/character/overlap rows and an alternate
coefficient replay; end the packet after theory/report/checkpoint updates.
