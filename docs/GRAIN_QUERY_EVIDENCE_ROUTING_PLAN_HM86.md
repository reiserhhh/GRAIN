## Retained observations and exact composition

For each head, use p=softmax(Kq), retaining full-prefix attention. For each
body event G, m_G=sum_G p, mu_G=mean_G V, and
rho_G=sum_G(p-m_G/|G|)V. Then

    body contribution = sum_G m_G mu_G + sum_G rho_G.

Report both actual body contribution and body-conditional reading (divide
each head by its own body mass), never silently renormalize units. Compare:
native contextual q, source-neutral target q moved to the actual RoPE position,
and uniform-body reading. Keep event-uniform and pairing parts in parallel.

    Delta body = sum_G bar(m_G) Delta mu_G

source direction. Uniform-body selectivity is exactly zero by design.
