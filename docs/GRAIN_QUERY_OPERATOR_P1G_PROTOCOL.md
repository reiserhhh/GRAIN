# P1G: exact error accounting before changing the operator

2026-09-07. Zero-forward exploratory analysis, selected after all P1F outcomes.

Question: when the frozen Q gap readout is better than the oracle gap on a new
query, is that evidence for a better representation, or cancellation of errors?
Use all P1F event/trait forms and all E/Q/D models, no refit or outcome exclusion.

For actual effect y, frozen shape a, actual donor gap d and estimated gap d_hat:

    y_hat-y = (d_hat-d)*a + (d*a-y) = amplitude_error + shape_error
    SSE = SSE_amplitude + SSE_shape + 2*inner(amplitude_error, shape_error)

This is an exact identity, not causal mediation or a unique mechanism split.
It is relative to the chosen frozen shape and shared activation readout. Report
the three terms divided by the SAME observed-effect energy, including negatives
in the cross term. Keep four settings, two directions, five masks per task/form.

Also report every case's four single-bin effect profile and full-Q-minus-sum
additivity defect. Compare canonical/rewrite profile cosine within the same
setting/ownership pair. Token-fraction bins are not semantically aligned; the
cosine diagnoses non-invariance, not changes in personality or a specific circuit.
Do not add a new neural grid, fit a new formula or retrofit P1F as confirmation.
