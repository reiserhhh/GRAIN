# 共同文本如何接上不同的人格查询

2026-09-10，第十六轮逻辑研究。接续
[同材料作者算子](GRAIN_MATERIAL_GEOMETRY_THEORY_V1.md)。研究对象是固定模型
怎样读取 GRAIN 所描述的同一份材料，不是给四个技术坐标直接命名人格。

## 1. 共同材料与条件化读者是两件事

当前原生提示顺序为：共同system指令、作者摘录、人格问题、回答位置。
对于固定参数的因果decoder，前面位置只依赖自身及更早的token。因此在相同
前缀、位置、mask下，后面换问题不会改变先前正文的数学隐藏状态。这个结论
来自逐层因果依赖，不依赖两组人格问题语义是否相近。
[Vaswani等（2017）](https://papers.nips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf)
的decoder遮罩给出标准依据。若问题改放正文之前、system随query变化、使用
双向编码，或先生成解释再读取，这个共同正文前提需要重新判断。

因此当前路线可以写成：

\[
H_{body,u}=E(T_u;\text{prefix,layout}),\quad
(P_{u,q},Q_{u,q})=A(H_{body,u},q),\quad
F_{u,q}=f_q(H_{body,u},P_{u,q},Q_{u,q},R,L).
\]

共同的H不意味着共同的读取函数。查询区和回答区能对同一正文形成不同响应。
这与[Elhage等（2021）](https://transformer-circuits.pub/2021/framework/index.html)
区分注意力的路由和内容变换的思路相符；本轮没有将完整后缀梯度直接等同于
某一个attention head的权重，也没有完成逐头因果归因。

## 2. 把GRAIN切片变成共同的数学方向

在旧四名作者、三个查询的共同材料中，按冻结GRAIN的四个词法切片规则计分。
仅将完整位于合格正文内的模型token按字符重叠分配到切片。设所选token共n行，
H为n×d隐藏状态，G为n×4的切片分数。这里是token权重，不是上一轮每评论等权。

令 Hc、Gc 为逐列中心化矩阵，定义

\[
C_u=G_c^\top H_c/n,\qquad
D_{u,k}[t,d]=G_c[t,k]H_c[t,d].
\]

D_k表达一种可重复的局部干预方向：加强/减弱与第k个GRAIN坐标偏离相配的
隐藏配置。方向由共同材料决定，不按某个query的结果挑选。它不是将作者的
实际人格增加一单位，也不保证存在一段自然语言精确对应这次隐藏状态变化。

实验将每个D归一到所选H的RMS，再施加±0.001的相对幅度。这个单位约定依赖
原生坐标和本材料的尺度，只用于比较局部数值响应；不替换GRAIN的固定群体
常模。原始D、C的中心化恒等式与这种RMS归一的坐标性质应分开描述。

## 3. 原生读取公式比Cw多了一项

固定块16后的query和scaffold状态，记原生分数对每个正文坐标的梯度为J_q。
GRAIN方向的局部作用是链式法则给出的

\[
T_{u,q,k}=\langle J_{u,q},D_{u,k}\rangle
=\sum_t G_c[t,k]\,\langle J_{u,q,t},H_c[t]\rangle.
\]

令 Jbar 为所选token梯度的均值，w_q=n Jbar，精确得到

\[
\boxed{T_{u,q}=C_u w_{u,q}+R_{u,q}},\qquad
R_{u,q,k}=\sum_tG_c[t,k]\langle J_{u,q,t}-\bar J_{u,q},H_c[t]\rangle.
\]

第一项把每个token视为由同一个方向读取；第二项保留不同位置的不同读法。
R不是可以先删掉的噪声，而是可计算的本地读法差异。如果F仅为平均嵌入的
线性函数，J_t=w/n，R严格为零，退化回旧Cw。对于原生非线性读法，不应先
假设它为零。本轮的余项与旧条件作用分解里的R状态区域不同，索引和角色须
明确；此处可在实现中叫`localized`，避免两个R混淆。

更完整的共享对象是带token位置的乘积张量

\[
\mathcal D_u[t,k,d]=G_c[t,k]H_c[t,d],\qquad
T_{u,q,k}=\sum_{t,d}\mathcal D_u[t,k,d]J_{u,q}[t,d].
\]

旧C只是把这个张量沿token压缩。新式不需要造一条心理轴：保留共同材料，
让不同query以不同场来读取它。它也是一般微分映射在GRAIN方向上的限制，
即把完整输出Jacobian乘以这些方向；不是一个首创的数学定理。

## 4. 局部干预、自然文本和人类效标分别连接

本轮有限差分检验的是固定后缀在同一状态附近的导数。查询状态中早已编码的
材料信息保持不变，因此这是**正文到后缀的直接局部作用**，不包含自然文本
改变后从前面各层重新流入P/Q的所有间接作用。

F的零点也不是T或C：导数描述变化，不能从它直接得到绝对分数。要走向完整
独立程序仍需明确原始输入、起点评分、局部/有限响应及它们的组合。NEXT24–26
不被本轮恒等式自动完成。人类自评联系继续使用原有独立账本；这四名作者
的小实验不计算新外部效度。

实现经验上的下一问题可以更具体：token梯度是否有低秩共同方向，GRAIN相关
的作用是否可以在不丢位置的情况下压缩？应优先保留实际作用，而不是只看
梯度矩阵的总能量。先用本轮缓存定量回答，再决定是否需新模型调用。

## 5. 数值前缀与理论前缀

初版缓存门槛发现相同token前缀有微小浮点差异。保留失败记录和原门槛标志，
用同作者的TF前缀作为所有query的明确共同块16前缀。其余query/回答状态不变，
且评分须重放原值至2e-6以内。数学因果性、浮点数组相等、评分函数相等是三项
不同判断，不能用任何一项偷换另一项。
