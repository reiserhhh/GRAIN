## Exact structure, not a prediction-accuracy gate

Let T have nonnegative rows summing to one, each mapping a new event to source
events. Use P_source=T^T P_new T and F_new_transport=T F_source T^T. Check the
duality <P_new,F_transport>=<P_source,F_source>. For skew D with D1=0,
T^T D T remains skew and divergence-free. A source exact gradient pulls back
to another exact gradient and contributes zero to any closed current. Hence
transport preserves the distinction between endpoint and cycle accounts.

On the zero-sum node spaces use H_new T H_source. Its nonzero singular values
s_i induce exterior-square singular values s_i*s_j. Numerical full rank does
not guarantee preserved amplitude. Factor-coordinate dimension4 does NOT
