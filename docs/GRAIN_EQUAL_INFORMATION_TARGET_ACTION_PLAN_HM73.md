## The mainline question

Does ownership-conditioned behavioral evidence have content-matched target
actions, or are we observing generic evaluation/role-marker changes? Where is
query dependence present: the full-body endpoint, the endpoint after the query,
or only the final answer distribution? Keep all three observation objects.
HM72 showed that early event slots have unequal prefix opportunities. Here
every endpoint sees the complete body, with all x/y/g factors available. Body
prefixes must be identical across all six future queries for each document.
This does not make reversed presentations identical neural observations.

## Mathematics and falsifiable alternatives

For each complete table F_q(z), z=(x,y,g) in {-1,+1}^3, retain every character:

    c[q,J] = (1/8) sum_z chi_J(z) F_q(z)
    cbar[J] = (1/6) sum_q c[q,J]
    d[q,J] = c[q,J] - cbar[J]
    F_q(z) = sum_J chi_J(z) (cbar[J] + d[q,J]).

Query centering here is a lossless account: both cbar and d are saved. It is
not a denoiser or removal of a shared psychological signal. Boolean/Fourier
and orthogonal projections are established mathematics, not new theorems.

The companion polarity-by-ownership action at fixed focal polarity x is:

    A_q(x) = [F_q(x,+,+)-F_q(x,-,+)]
             -[F_q(x,+,-)-F_q(x,-,-)]
           = 4 (c[q,yg] + x*c[q,xyg]).

The exact marginal action is4*c[q,yg]; all x-specific deviations are retained.
Companion-matched versus other-query differences test target specificity in
the score/log-odds units. Also retain focal-query actions: context could route
the same ownership edit to another target rather than only its named target.
At vector endpoints, report shared/query-varying action geometry and its
cross-wording/order reproduction; vector norms are not psychological scores.
Do not equate query dependence with semantic target correctness.

Alternatives to distinguish, without adjusting the observer:

1. Generic evaluation: ownership action is approximately the same in all
   queries. It can affect answers but has little matched-query contrast.
2. Target-conditioned action: query-varying changes and content-matched
   contrasts coexist. This supports a qualified observation interface, not
   a causal binding-ID mechanism or human personality validity.
3. Contextual routing: the fixed-x action changes sign or target, so marginal
   averages can hide a real condition-dependent response. Keep those cases.
4. Role-marker/background: neutral companion ownership actions are similar
   to meaningful ones. Neutral controls exist in HM68 only, not HM71; do not
   synthesize a cold neutral observation or silently subtract the reference.
