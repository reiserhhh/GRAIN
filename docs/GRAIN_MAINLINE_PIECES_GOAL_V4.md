## Objective and decisions

Real author text -> conditional vector evidence -> trait judgment -> declared
group-relative author position. Keep Ridge as the readout tool. Nonlinear readers
remain archived alternatives, not a competing optimization queue. A larger
population estimates a reference more precisely; it does not set individual or
systematic errors to zero. Small differences need not block useful construction.

## First packet: M23 cached conditional-coordinate localization

Reuse all M10 authors: neuroticism 213 and T/F 64, each with three cached views.
These are exposed source discovery authors, not a new confirmation set. Frozen
M10 native teacher is the fitting target; existing source human labels join only
after OOF predictions are saved and hashed. Preserve all arms.

For query matrix P (T x d), let m=mean_token(P) and C=P-1*m. Averaging views
commutes with this linear split. Compare exactly these six representations:

1. P mean m.
2. Final query token Q.
3. m concatenated with Q (M22 replay).
4. vec(C), the token configuration without the token mean.
5. vec(P) concatenated with Q.
6. vec(C) concatenated with Q.

Use the same five author folds as M22. Within each fold, reuse that fold's M22
prefix-mean Ridge alpha for ALL six arms; no new parameter search. Fit scales and
PCA64 on training authors only. These are finite representation comparisons,
not equal-capacity causal estimates. Refit ablations and fixed-model accounting
answer different questions and are both retained.

Unroll each fitted affine reader into original-vector coefficients. For full P/Q,
using the outer-training reference, exactly account for:

```
prediction = reference_value + mean_contribution
             + configuration_contribution + Q_contribution
P = 1*m + C
```

Also retain token-level contributions and view-level scores. Covariances can
overlap/cancel; no contribution is automatically independent personality variance.
No tokens are named psychological constructs from their coefficient magnitude.

Outputs: six-arm OOF metrics, paired source associations, signed contribution
ledger, per-token aggregate map, fixed-model artifacts with training membership,
view-response consistency and a short next-location ruling. Neural calls: zero.
CPU bound: two threads, 15 minutes fitting, pause at completed fold boundaries.

Minimum tests: exact P decomposition/reconstruction; affine unrolling; exact
score accounting; author grouping; frozen reference/batch invariance; malformed
states rejected. Check the mean-P/Q arm reproduces M22 within numerical precision.
