# 位置、响应与GRAIN方向：同一文本的两种几何

2026-09-10。NEXT52有限实验后的理论更新；不是新的人格维度，也不改既有评分器。
实测与完整反例表见[报告](../reports/grain_vector_mechanisms/SOURCE_STATE_TRANSPORT_REPORT_V1.md)。

## 1. 这次真正定位到的接点

对相同作者、相同文本token，GRAIN给出相对群体的配置；查询路径回答这个配置
如何改变模型判断。以固定正文方向为例：

    D_f(t) = scale_f * (G_tf-mean_t G_tf) * (H_t-mean_t H_t).

方向先由GRAIN和同材料隐藏状态共同构造，随后走模型路径。它不是把两个模型
各自算出的总分直接相加。四个方向仍使用技术代码F01..F04；查询使用N/确认寻求。
这一接口回答用户提出的“同一片文字可否既用GRAIN分区，又沿查询路径加权”。

设原生blocks17–21的函数为Phi，替代函数为Psi，注意力/固定读头程序为A。
需要保留的对象是：

    X22 = Phi(X16),     d22_f = D Phi(X16)[D_f]
    kappa_hat_f = A_q(Psi(X16), D Psi(X16)[D_f]; Qbar, rbar).

NEXT52只用源作者的X16、X22拟合Psi，再解析求同一Psi的导数。新8状态误差
下降42–47%，方向误差却上升39–50%。这说明本次优化的“位置接近”与需要的
“差异如何传播”不是同一个目标。原生输入组件的成功不因此被推翻。

## 2. 值收敛不自动给出导数收敛

一个标准可检验反例是 g_n(x)=sin(nx)/n。它在实线上一致趋于0，但
g_n'(0)=1，对零函数的导数误差不消失。因此仅观察函数值误差很小，一般
不能推出导数近似良好；额外光滑性/逼近范数等条件会改变这一结论。
本轮并不声称学到的Ridge函数具有这个振荡形式，它只是说明逻辑缺口真实存在。

这个区别对应 [Sobolev Training](https://arxiv.org/abs/1706.04859) 的值与导数联合学习，
以及 [Jacobian Matching](https://proceedings.mlr.press/v80/srinivas18a.html) 对蒸馏目标的研究。
NEXT52实现的是primal-only中间状态匹配，不是已经实现了这些论文的完整训练法。

## 3. 当前近似家族的精确可见范围

冻结源均值mu、基底U和布局s。令p=(X-mu)U，c=Cp，C为下三角累积平均：

    Psi_t(X) = X_t + standardized([p_t,(c_t),1,s_t,s_t^2]) B
    D Psi(X)[D] = D + standardized_d([D U,(C D U),0,0,0]) B.

当前Psi为固定布局下的仿射函数；RMSNorm与注意力在后续仍非线性。
若每个token上D_perp U=0，则严格有D Psi[D_perp]=D_perp：这个方向的增量
根本没有进入可学习分支。新8现有D的源PCA32投影能量约31.94%，其余约68.06%
属于这个不可调分量。分解是线性的，但输出增量仍可指向任意hidden方向。
不能仅凭输入投影比例，宣称遗漏了68%人格信息或确定了68%端点误差来源。

点式图还满足跨token偏导为零；它不可能把BODY-only扰动搬到初始零方向的
query位置。因果累计图允许此事，但实测幅度超出原生且方向总体变差。
由此需要区分：可通信、观测到通信、学习到相应条件下的正确通信。

## 4. 可发展的数学对象：GRAIN加权的响应误差

把整个序列展平，令E=J_Psi-J_Phi，Sigma_G=(1/4)sum_f D_f D_f^T，则：

    (1/4) sum_f ||E D_f||^2 = tr(E Sigma_G E^T).

这是精确恒等式，不需要估计整个巨大Jacobian。GRAIN在这里决定哪些变化方向
需要被保留，相当于定义一个低秩、有来源的扰动分布，而不只是另一组预测输入。
源作者的四个已有JVP即可提供这个目标；当前作者的JVP不参与拟合或预测。
这个度量只覆盖已给定方向，不自动保证其它心理构念或所有输入方向。

下一步使用同一个Psi联合拟合值与方向。先保持U/rank/alpha/布局不变，分离
“训练目标不对齐”与“表示空间不够”两种原因。若加入方向约束有用，就证明
一种实用的GRAIN定向机制传递；若仍弱，检查上述可见范围，而不继续磨相关。
原生全方向范数约为输入1.117倍，而端点误差可达4倍量级，提示最终作用还取决于
方向、归一化和注意力/读头配对，不能把全部缺口塞给一个全局缩放常数。

## 5. 理论与心理解释的连接

这套数学目前解释的是某个文本配置如何在固定模型中参与人格相关查询。
GRAIN群体位置、查询方向响应、作者的心理含义仍是三种相接但不同的对象。
它允许未来把切片贡献回到原文地址，再用有依据的关系事件/交流分析rubric
进行辅助解释；本轮没有新增真人诊断或把线性方向称为无意识冲突。
接口已存在，解释和效标实验可另行发展，不是挡住当前数值机制开发的门槛。

不是宣称所有人格推论线性化、或把组件作用相关当量表预测精度。
