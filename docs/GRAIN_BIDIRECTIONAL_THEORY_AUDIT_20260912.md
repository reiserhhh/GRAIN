# GRAIN 双向理论审查：我们的问题、前人的边界与新的研究问题

日期：2026-09-12。对象是**文本心理测量的构造方法**，不是临床量表验收。
这是对会话主张、当前/历史理论文件和原始文献的定向审查，不是系统综述。
文献编号、原始链接、阅读范围统一见[文献登记簿](GRAIN_LITERATURE_REGISTER.md)。
本轮未训练模型、重启实验队列或读取私人会话；仅对几个数学反例做了数值核对。

## 1. 核心结论

最值得推进的缺口不是“有没有人用文本发现人格”，而是：

> 如何从自选、情境依赖的开放表达中学习心理相关证据，区分关注内容与反应方式，
> 并提前判断什么观察或证据变换能改善测量，而不消掉有意义的个体差异？

本次确认：

- 我们旧4W文档存在两类需要勘误的推断/规则：未复现等于随机误差；外部效标只能最后使用。
- 当前响应分解仍有可识别性问题，但V5已承认它，不能再把它包装成“新发现的实现bug”。
- 一篇已发表文本因子论文对比例变量相关性的说法过强；一个近邻工具把白化与独立混淆。
- 该工具还有固定计分时的批次依赖陷阱。这不等于其默认算法或对应论文结果失效。
- 没有发现并证明所引ICA、条件核或因果抽象定理错误。违反其假设不是反驳它们。

最重要的新增近邻是 **MEM（2008）和BLT（2018）**：它们已经从开放文本形成维度并做心理连接。
因此“脱离既有量表，先从语言发现因子”本身不能作为GRAIN的首创命题。[N09,N10]

## 3. 我们的bug与缺口

### O1：未复现不能推断为随机误差（确认的旧文档逻辑问题）

4W审查前第87、194、365行，将未复现残差归为随机误差或误差/状态。
但同文件第232-233行又正确指出：某种投影不稳定不能证明动态不存在。
这两处逻辑不一致。

设真实过程含有稀有情境响应，某次切半恰好只在一半出现；它未通过切半检验，
仍可能有条件可预测结构。样本量、机会覆盖、时变参数和读取函数都可能解释失败。
条件probing也强调“给定读者能否读到”，不是宣判信息是否存在。[R21-R23]

**修订规则**：未复现项标为“当前设计/读者下尚未解释的残差”。只有在明确模型与
检验能力内才能估计随机成分。这不是保留一切噪声，而是不给未知成分过早定性。
对应 **RQ1、RQ5**。

### O2：必须最后才看外部效标，误把一种发现设计当作普遍原则（确认的旧规则冲突）

4W审查前第45、453-454行要求技术对象先全部冻结，再打开心理标签。这适用于
“盲态发现后验证”的一个分支，不适用于所有构造方法。

监督/半监督学习可以帮助发现心理相关证据；需要隔离的是**构造数据与独立验证**，
不是永久隔离心理学与表示学习。否则系统容易先把作者可识别性优化到极致，最后才发现
与目标心理属性无关。效标也不必只有Big5，可以是行为、状态或另一种观测方法。[R03,R04,P1,P2,N04]

**修订规则**：同时允许匿名发现和目标引导发现；分别声明训练目标与最终效标。
MEPS现有validation-only权限不因此改变。V5已采纳目标引导路线，旧文档必须标记历史状态。
对应 **RQ1、RQ4**。

### O3：响应算子和自由残差之间仍不可唯一分配（已知但未解决的数学缺口）

若只写

\[
m_u(z)=a_u+B_u\phi(z)+h_u(z),
\]

则对任意矩阵D都有

\[
B'_u=B_u+D,\qquad h'_u(z)=h_u(z)-D\phi(z),
\]

完全相同的m。数据再多也不自动区分两组参数。4W“完整但仍可估计”的表述需限定；
V5 §3.2已提醒尺度和等价类，但仅靠中心化不一定解决自由h吸收交互的问题。

**优先解法**：先把m或指定条件对比作为估计对象；若要解释B，冻结基底、参照分布ν，
给h施加相对于该基底的正交约定，并说明这只是一个可识别的投影，不是自然唯一的人格轴。
基底也学习时还存在旋转/尺度自由度。有限支持外的函数恢复仍需要额外假设。[R16,R17,M3,P11]
对应 **RQ2**。

### O4：把已存在的方法结构当创新，竞争对象设得过弱（贡献定位问题）

MEM用词共现构造维度；BLT从未提示的社交文本提取潜在特征；选择IRT已联合处理选择与作答；
LSIRM已允许人-题交互；语义计分工具已实现种子到向量轴。[N09,N10,P8,P9,P11,T01-T03]

因此，新的slice名字、更多因子、把四个过程相加，均不足以构成关键新增。
V5已修正部分定位，本轮补入MEM/BLT作为**因子发现主线的直接对手**，不是只作背景引用。
我们应争取：相同构造规则如何预测新情境中的证据效用，并保留有意义的选择与反应差异。
对应 **RQ1-RQ4**。

### O5：不能从教师一致或路径积分闭合推出人的心理机制（已有边界，继续保留）

教师分数t、外部效标y和抽取函数f是三个对象。令独立标准化变量U,V，
t=U+εV，f=U，y=V，则 corr(f,t)趋1，而corr(f,y)=0。
因而高保真不能单独替代效标连接；反过来效标相关也不证明模型实际用了某个路径。
窄函数报告同时报告两者是正确做法。[R22-R26]

同理，路径积分能重建输出差，属于函数性质；解释路径的心理意义仍需与具体证据和效标相接。
无生成读出、去掉后缀网络、去掉整个编码器必须分别报告。对应 **RQ3、RQ4**。

### O6：不要把已修复的问题再说成当前失败

V5已经明确：选择不等于机会；强制不变性会得到常数表示；一个共同条件不能识别所有响应；
群体关系不能代替个体测量；表示和读者变化不能都归因于人。V8也没有再把残差分型说成
唯一正交分解。以上是下一实验应遵守的已有修正，不值得各自另开长期防御循环。

## 4. 先行研究的问题：按证据等级分别裁决

### L1：已发表BLT论文的比例变量表述过强（可证明的数学表述问题）

Kulkarni等2018，Methods → Factor generation → Alternative methods，将LDA比例
总和为1解释成各分数总是彼此负相关。**一般组成约束不推出任意一对负相关**。[N10]

取非退化T∈(0,1/2)，令p=(T,T,1-2T)。分量均非负、和为1，但corr(p1,p2)=1。
正确一般关系是Σ_j Cov(p_i,p_j)=0，即与其余分量的协方差之和为−Var(p_i)。
固定参数Dirichlet分布确有负的两两协方差；它比“数据是比例”多了一项分布假设。

这不推翻其FA结果，也不消除组成数据的约束。它提示GRAIN应研究共同增长的选择组合，
用合适的组成/对数比表示比较，而非因闭合约束便放弃整个选择通道。对应 **RQ2、RQ5**。

### L2：SPAR白化不保证统计独立（确认的工具文档问题）

固定源码版本：`3924fc4dd2207191b39049ea4d66d81b8d29aad1`。
[README第248行](https://github.com/maifeng/SPAR_measure/blob/3924fc4dd2207191b39049ea4d66d81b8d29aad1/README.MD#L248)
将ZCA与“statistically independent”相连。协方差白化一般只处理二阶关系。[T03]

反例：Z服从标准正态，X=Z，Y=(Z²−1)/√2。二者均值0、方差1、协方差0，
Y却完全由X决定。这是对文档措辞的直接反例，不是对2024年引用论文的实验反驳。
而且心理构念可以真实相关，不应该为了得到漂亮独立轴而全部白化掉。

### L3：SPAR可选白化依赖提交批次（固定测量用途的源码陷阱）

[core.py第343-344行](https://github.com/maifeng/SPAR_measure/blob/3924fc4dd2207191b39049ea4d66d81b8d29aad1/src/spar_measure/core.py#L343)
在当前scores上fit ZCA。[zca.py](https://github.com/maifeng/SPAR_measure/blob/3924fc4dd2207191b39049ea4d66d81b8d29aad1/src/spar_measure/zca.py#L24)
按该批均值与样本协方差变换。[T03]

同一原始分数0.5，在批次[-0.5,0,0.5]中变为1.000；在[-0.5,0.5,0.9]中变为0.27735。
作为批内探索可合理，作为独立个体固定计分则不合适。默认whiten=False不受此问题影响。
GRAIN若复用，应冻结开发集变换与参照；跨环境重新校准须明示版本。对应 **RQ2、RQ4**。

### L4：ChatGPT历史推论有能力证据，但解释链尚未直接观测（不是已证明的论文错误）

Yang与Oshio2026：738人，Big5自评与AI相关约.13-.24；§2.2.3要求一次提示中给出
三次“独立”推断，但这本身不建立独立抽样。§4承认未分析聊天内容，却以披露解释
关系调节。应把该解释作为待检验机制，不能当已观察的中介路径。[R12]

可做的新增是固定同一材料，分开改变可见历史、关系提示和读者，测量线索供给与利用。
“忽略旧分数”的提示也不是可审计的数据删除操作。这是 **RQ3**，不需要先追求临床准确率。

### L5：注意力解释争议不支持两个极端（已有公开争论）

Jain与Wallace2019展示替代注意力可保持输出；Wiegreffe与Pinter2019质疑
把每个样本的权重任意替换视作等价解释，提出训练一致性、简单模型和随机种子对照。[N01,N02]
前者不能被当作“注意力永远无用”定理，后者也不证明所有热图忠实。两者主要实验基于RNN，
不能直接裁决现代LLM的所有头。GRAIN应寻找**固定读者内可检验的作用类**，不要求唯一链。

Tak等2025已经用情绪任务做probe、patching和appraisal干预；其§11还区分了模型操控
与情绪心理理论的因果方向。这是我们可承接的边界，不是论文漏掉所有因果问题。[R13]

### L6：已有高相关结果的目标不同，不应组成一张万能排行榜

Speer等2026摘要的M=.83针对叙事直接评价目标，不能当作自评Big5准确度。
该文已有提示→叙事证据→效标关联的解释，故“好prompt有帮助”也不能作我们的新发现。[P12]

另找到Oltmanns等2026的生活叙事研究：1409人，微调RoBERTa，Big5预测中位r约.41，
并用他评等效标验证。它让“叙事到心理评估”的近邻更具体；其人群、材料与监督方案不同，
不能据此宣布我们输赢，也不能把其关联当作模型内部路径解释。[N04]

### L7：标准数学的适用边界不是“前人bug”

| 方法 | 需要检查的关键条件 | 我们不能声称什么 |
|---|---|---|
| 非线性ICA / 多视图ICA | 混合、条件独立、辅助变化/噪声视图等 | 对同文运行两个LLM就识别出真正人格来源 [R16,M2] |
| 条件核 / 分布回归 | 核、正则、两层抽样、依赖与支持 | 无穷维表示自动保证心理效度 [M3-M5] |
| 潜空间IRT / 选择IRT | 已定义反应与机会、模型及参数约定 | 它们不处理选择或交互，因此GRAIN自然首创 [P8,P9,P11] |
| 因果抽象 | 明确模型、允许干预与抽象映射 | 隐层操作等价于操纵真人心理 [R24,R25] |

数学定理的反例必须满足它的假设；本轮的反例否定的是过宽的推断，不是假装推翻上述定理。

## 5. 更明确的五个research questions

### RQ1：谈论某特质，与以该特质的方式反应，能否被计算地区分？

MEM中语义相反词能同向聚合，提示“某领域被关注”不等于“位于该领域哪一端”。[N09]
这正连接GRAIN的Where/What和查询路径：不是只有相似词，而是谈论对象、立场、主体与反应配置。

比较现版GRAIN、MEM/BLT式因子、双极语义轴和查询条件证据；使用相同材料的主体/极性/情境对照。
成功是得到可定位的关注量与反应方向差异，并解释独立心理/行为关联，而不是仅提高作者识别。
先模拟机制，再在允许开发的真人文本上寻找对应；MEPS只验证冻结方案。

### RQ2：个人条件响应如何获得可比较的定义，而不要求处处相同？

先估计m_u(z)及指定ν下的对比；另保留选择分布，不强行把交互归零。
比较固定参照、当前批次标准化、选择IRT/交互IRT和低秩响应模型。
成功是提前预测更换观察构成后的分数/排序变化，并说明哪些量可以跨条件比较。
只恢复观察到的平均值也应保留为基线；不能把B唯一可识别设成所有路线的前提。

### RQ3：LLM的心理关联来自信息更多，还是利用信息的方式不同？

固定作者材料与读者，比较历史可见性、关系提示、查询和证据替换；继而固定证据换读者。
并行记录模型输出变化、路径作用和独立效标，不把三个指标揉成一个总分。
寻找跨作者可复用的证据作用规律；局部有效也有价值，不要求所有人格词同一条路径。

### RQ4：能否把这种作用规律变成“制作测量”的规则，而不仅是解释一个模型？

在来源域学习证据与计分；冻结后预测新条件中什么证据更有用，保留GRAIN群体参照和路径定位。
比较语义轴、直接回归、叙事评估及当前向量函数；增加新模块必须带来解释或设计决策的新增能力。
测同一目标时看效标连接；换目标时允许重新构造局部测量，不要求通用系数。

### RQ5：共享、独有和残差中，哪些信息必须保留？

比较相关配置、白化配置、非线性依赖与条件/组成表示；用给定读者下的增量预测和
有地址的有限变化判断作用。不能以不相关、不可命名或一次未复现决定丢弃。
只有当该问题改变RQ1-4的证据或设计选择时运行，不重新开启无限“残差洗净”支线。

**执行优先级**：先RQ1的最小可区分机制与RQ2的明确目标量，随后RQ3接现有向量证据，
RQ4检验构造规则；RQ5穿插解决实际障碍。V5 G0/G1据此收窄，不启动另一份无边界终局计划。

## 6. 小型数学核对与复现说明

以下是本轮NumPy核对，不是人格实验或外部库执行：

| 核对 | 结果 | 说明 |
|---|---|---|
| 白化不等于独立 | 三点分布协方差为I，最大数值偏差约2.2e-16，但二次依赖精确存在 | 用Z∈{-1,0,1}等概率，X=√1.5 Z，Y=(3Z²−2)/√2 |
| B与h可互相挪动 | 网格上差异≤2.7e-15 | 2z+z²与9z+(z²−7z)是同一函数 |
| 同原始分数的批次变化 | 1.000 vs 0.277350 | 按所查源码的样本方差/中心化公式独立实现 |
| 保真不等于效标保留 | ε=.01时corr(f,t)=.999950，corr(f,y)=0 | 独立U,V的解析公式，不是模拟证据 |
| 均值误差不等于个体残差 | σ²=1,n=10^6时均值方差10^-6，个体条件方差仍1 | 大样本极限的对象必须指明 |

L1比例反例为代数构造，无需大量模拟。以上均为标准数学的直接应用，不作为原创定理。
