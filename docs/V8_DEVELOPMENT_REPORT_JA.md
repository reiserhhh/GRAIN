## 1. この計画は何をしてきたか(一段落版)

「人の自発的テキストは、話題や状況という『皮』ごと測ってこそ人物シグナルを
運ぶ」という一つの仮説から出発し、その素朴な形を自分の手で反証し
(条件中心化はシグナルを破壊する)、生き残った機構だけを型付きの測定理論に
組み直す——という反証駆動の往復を 8 世代にわたって繰り返してきた。
成果物は「完成した人格尺度」ではなく、(i) どの主張がどの証拠格で立って
いるかを全数管理する台帳、(ii) してはならない比較を例外として送出する
型システムと拒否規則、(iii) 将来の尺度開発が乗れる凍結済み・監査可能な
技術基盤、の 3 点である。

## 2. 世代史 — 何が生き残り、何が死んだか

各世代の「残った貢献」と「殺された普遍主張」(V8 §11 系譜表の叙述版):

- **MCD(条件付き偏差)** — 残: 共有された先行条件の下で著者を比較する
  という発想。死: 条件中心化を万能ノイズ除去として使う考え(3 通りの
  独立な方法で反証。皮モデルの出発点)。
- **H-MCD / V-HMCD** — 残: 再帰的局所構造と著者集約。死: 唯一最良の
  切り方・少数の普遍軸という仮定。
- **V3/V4(19構成概念+選択軸)** — 残: choice / base(style)/ react の
  3 チャネル分離、固定機会設計と自由機会設計の区別。死: tension の
  安定特性扱い、感情語率の人格尺度扱い。
- **V6(運動・経路)** — 残: 経路(motion)は一級市民であり、平均は運動
  情報を捨てるという定理群。死: 「共有された動的軸=既に人格因子」。
- **V7(v0.2.x 封印)** — 残: 複数観測平面、参照集団相対幾何、凍結
  バンドル、事前登録と開封の運用(開封#1 は成功規則 2/7 で不成立を
  そのまま公表)。死: 「スライスは常に非スライスに勝つ」
  「著者識別 AUC =人格妥当性」(T8′: 個人構造ゼロの合成世界で著者
  AUC .864 を実証し、この等式を恒久的に葬った)。
- **V8(型付き統一体系)** — 残: (H,F)→B→X→Z→𝔄→𝔐→Θ→D の型付き連鎖、
  V/R/P の 3 出力型と暗黙変換禁止、M3 のミクロ–メゾ–マクロ機構階層、
  残差の 5 成分分解、LLM の役割制限(レンダラーであって採点者ではない)。
  死: 「一つの普遍スコアが層別対象を代替できる」。
- **M3/M4(機構・条件多様体・合成)** — 残: 5 機構族が異なる著者幾何を
  生成できることの有限合成実証、機会・フィードバック・合成文法、
  応答安全チャート(R2B の条件付き利得)。死: 「原子的回復は複合ループ
  回復を保証する」「サポート量 .80 閾値で適用可否を自動判定できる」
  (Boundary Ecology が反証)。

## 3. M4-D/E/F 線 — 壁の解剖(2026-08-01..03、16実験)

V8 投下が残した最大の未解決は「原子的アクションは移送できる(.77–.98)のに
複合ループは失敗する(.6519)」という 4 連 NO-GO の壁だった。16 本の
登録済み実験(各実験とも lean と pivot 条件を実行前に commit)で、壁は
単一の呪いではなく 4 つの独立成分に分解された:

1. **経路誤同定**(チャート過伸長下のルートフリップ)— 二段構成
   (罰則付き経路選択 → 選択経路での無罰則 D 再適合)で修復。
   フリップ 196→73、プールループ幾何 .6519→.7605。
2. **推定器の自傷** — V2 リッジ罰則の非消失バイアスが「予算不変の床」
   という幻を製造していた(Leg 4b を遡及訂正)。λ~1/n で教科書的
   n^(−1/2) スケーリングが回復(勾配 −.005→−.521)。
3. **対指標の共通モード性** — 真値参照の対診断は共有縮小を褒賞し、
   一方的な脱バイアスを罰し、汚染に**補助**されうる(C.3 レトロフィットで
   清掃がスピアマンを .7264→.6677 に**下げた**)。指標の性質であって
   バグではない、という理解が正しい。
4. **発見目的関数の系統的フレーム変位** — 残差は滑らかな二次盆地の
   方向内容欠損(gap ~ θ^1.8)で、共通オフセットは分散しており
   (最大単一項シェア .38)、方向は世界固有(置換帰無で有意)。
   単一項でも共有方向でも吸収できない——**正式な未解決問題**として
   特徴付け完了(第一容疑者: 凍結白色化の 1/√eig スケール族、
   質量 .39–.48)。

付随成果: 型付き R→V 橋(剛性指数による昇格ゲート)は設計ヌル
(消失個体性世界)で **200/200 拒否**の完全記録を持ち、異分散較正の
運用曲線が文書化された(基準 τ.275 支配、V1 は C2 の 60/60 上限解除、
V2 は深雑音順序 .944→.995 を修復——ただし両修復は反相関し、単一の
万能変種は存在しない)。実テキストへの輸出試験(M4-E1)は自傷教訓が
合成限定であることを原理的理由(射影同値)ごと確定し、代わりに
「飽和した物差し」(実テキスト内部分割半一致が全予算でゼロ)という
より深い制約を表面化させた。これを M4-F1 が定量化し、**D3 パネル設計則**
(イベント軸指数 .153、一致 .5 到達に 10^14 倍——規模でなく構成を
変えよ)として D3 設計への宿題を確定した。

名誉記録: 登録ピボットは Leg 3, 6, 9, 11, 13, 14, E1, E2 で事前約束
どおり発火。計画者(AI)の解釈 2 件が自分の登録した試験で死亡。遡及訂正
1 件(Leg 4b)。登録分岐外の着地 2 件はそのまま記録。F1 はピボット字面が
外れつつ測定された法則が問いを決した。**道具が決め、リーンは決めなかった。**

## 4. ガバナンス史 — 方法としての監査

この計画は「AI が構築し、AI が敵対的に監査し、人間が方向を決める」体制で

- **開封#1(2026-07-07)** — 事前登録の成功規則が不成立(2/7)。結果は
  無修正で公表。H2/H6 の 2 関係のみロックボックス級確認。
- **V7 過程監査(2026-07-17)** — 不変タグ・追記のみの日付付き裁定・
  実行前登録という恒久規則を成文化。
- **V8 投下審査(2026-08-01)** — 実証面 TRUST(見出し 15/15 追跡一致、
  9 件を行データから再計算一致)、ガバナンス面 MAJOR_ISSUES。問題は
  7/28 の PANDORA ラベル作戦 1 点に集中: 登録なしの全量ラベル結合、
  そして**結果依存の演算子切替**(04:29Z の run が bridge r=−.103 の
  ヌル → 演算子組替え → 05:04Z の run が r=+.498 → 後者のみ見出し化、
  時系列非開示)。
- **push 前是正(2026-08-03)** — `docs/V8_PUSH_REMEDIATION_20260803.md`

  R2B カバレッジ値の SESSION_RECOMPUTED_UNPERSISTED 格下げ、プロセス
  恒久規則(登録→実行のコミット粒度、日付型サフィックス禁止、

## 6. 教訓集(次の開発者へ)

1. **リーンを書いてから走れ。** 16 実験で計画者の解釈が 2 回死んだ。
   事前に registered lean がなければ、それらは「発見」として生き延びて
   いただろう。
2. **診断装置自体を疑え。** 壁の半分(自傷・共通モード)は現象ではなく
   計器の性質だった。「床」を見たら、まず罰則と対構造を外して測り直す。
3. **著者 AUC に酔うな。** 個人構造ゼロでも .864 が出る。識別と測定は
   別の問い。
4. **ヌルは成果である。** この計画の最も再利用可能な資産(拒否規則・
   反証済み普遍主張のリスト)は、ほぼすべてヌルと失敗から来ている。
5. **演算子はラベルより先に固定せよ。** 7/28 の教訓。結果を見てから
   演算子を選ぶなら、その数値は探索的としてしか生きられない。
6. **ローカル緑は CI 緑ではない。** 依存 lock と成果物前提はクリーン
   クローンで検証してから push する。
