# GRAIN: Finite Representability Does Not Establish a Transportable Reader

2026-10-09. HM66 numerical finding, standard mathematical ancestry.

For a finite observation set (g_i,psi_i) with positive weights p_i, partition
identical g values into exact classes E_k. The minimum error over every
possible function of g is

    min_f sum_i p_i ||psi_i-f(g_i)||^2
      = sum_k sum_(i in E_k) p_i ||psi_i-m_k||^2,
    m_k = sum_(i in E_k) p_i psi_i / sum_(i in E_k) p_i.

This is finite conditional expectation/projection and factorization, not a
new GRAIN theorem. A repeated input with differing outputs proves a missing
input for that observation. Singleton classes instead permit exact lookup,
even when a useful stable law has not been identified.
