# 同材料的GRAIN方向、查询引子与证据选择

2026-09-10，NEXT50。参见[完整结果](../reports/grain_vector_mechanisms/SOURCE_QUERY_SELECTION_REPORT_V1.md)。

## 1. 两条路线现在在哪里真正接上

同一段作者材料先给出冻结的GRAIN方向D_f，方向经过模型上游后成为各token
的dK_f。某个固定查询引子Q则决定这些变化怎样影响注意力竞争。二者的接口
不是两个量表分数相加，而是同一材料上的条件作用：

    E_q,f(Q;K,V,dK_f,w) = sum_heads,t e_q,f,t
    e_q,f,t = a_Q,t [g_head^T(V_t-o_Q)] [Q^T dK_f,t/sqrt(h)]
    a_Q = softmax(Q^T K/sqrt(h) + mask),  o_Q = sum_t a_Q,t V_t
    g = W_O^T w.

e的各token项相加就是局部key响应。这提供一个可计算的加权接口：GRAIN
方向影响证据的什么部分，查询引子如何选择该变化，读头如何赋予其符号。
此处token是attention22状态的位置，早先正文信号已经传播；不能直接把它
说成原始某个词的唯一心理贡献，也不能用注意力权重本身代替完整e。

## 2. 可共享的引子与必须保留的查询差异

对源作者集合S（源4留一、新8全部4源），构造：

    Qbar_q = mean_(s in S) ProjectQ(Norm(x_s,q,last))
    Qbar_shared = (Qbar_N + Qbar_C)/2.

平均发生在RoPE之前，随后按接收者的真实末端位置旋转。每个引子重新计算
完整softmax及中心化value，不沿用旧注意力权重。没有拟合权重或读新作者Q。

同查询源引子的新8两查询差别r=.939、同号31/32；交换引子为-.890，共享
引子为.477。共同引子仍能读各查询的一部分作用，却只保留8.4%的差别RMS。
因此目前最有用的机制对象是**可复用的选择程序加查询特异的选择方向**，
而非“所有特质只有一个引子”，也不是“每个特质完全独立”。同查询幅度仍
压缩到29.1%，这是本实验的实际近似性质，不把高r当完整精度。

这些是两种已渲染查询下的局部作用差别；当前K/V仍包含查询上下文。交换
引子的反号使局部查询依赖可观测，但不唯一识别心理语义、跨措辞等价性或
临床构念。先保留这个可用数学机制，后续用途在对应层面检验。

## 3. 为什么下一步必须回到后续读出

设局部key增量向量为u，固定源引子给uhat，误差e=uhat-u。NEXT50测的是
w*^T e；最终固定评分L的局部作用误差却是：

    dL_error = r_u,q^T e,  r_u,q = J_suffix(u,q)^T c.

即使w*^T e很小，r_u,q^T e仍可能不小。反过来，向量总误差不小也可能
落在最终读头不敏感的方向。因此不应为局部r继续调参，应直接计算同一
增量到最终读出的贡献，并测试源固定rbar是否能替代当前r。

完整误差可精确分成：

    rbar^T uhat - r^T u = r^T(uhat-u) + (rbar-r)^T uhat.

第一项是选择近似经实际后续通道的误差，第二项是固定读头的运输误差。
无需假设二者独立；平方误差必须保留交叉项。此式指导NEXT51的实验设计，
不是已经完成该实验，也不是自动建立不依赖模型的原文人格预测器。

## 4. 对解释路线的意义

同一材料可以同时报告：群体参照GRAIN位置、查询条件下的向量作用、原文
对应片段。它们能成为人类审核的辅助解释证据，不需要先把每个GRAIN因子
命名为人格。精神分析或交流分析的候选解释另接文献rubric与人工核对；
不能仅凭神经通道位置把它命名为ego-state或诊断。此次没有新增临床结论。

本轮采用的QK双线性交互与OV区分已有
[Transformer Circuits数学框架](https://transformer-circuits.pub/2021/framework/index.html)
和[Kamath等的QK交互追踪](https://transformer-circuits.pub/2025/attention-qk/index.html)
作为方法依据。我们的实证增量是同作者GRAIN方向、两查询源引子及跨作者
应用之间的具体接合，不是把标准softmax微分说成原创心理定律。
