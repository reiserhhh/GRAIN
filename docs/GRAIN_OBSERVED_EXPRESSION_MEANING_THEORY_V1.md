## Source-observed witness construction

Let C be the registered task/style condition and freeze the source event law.
The signed cross-moment functional is

    u_j = Cov_source(Y_j,X),
    s_j(x) = <u_j,phi(x)-mu_source>/||u_j||.

The source has351 actual generated articles. Neither persona assignments nor
model answers enter this construction. The nine Y fields are standardized in
source units, while the feature units are source-only Qwen RMS or old frozen
GRAIN slice units. No application normalization, regression inverse, label fit,
regularization choice or conditional-probability calibration is used.

This provides a vector reading oriented by a defined observable. It does not
estimate E[Y|X] simply because it uses covariance. In source its covariance
with Y_j is positive by construction; that is not validation. Zero source
support yields an unavailable reading, not a fabricated0. The source persona-
word occurrence field is absent, and remains unavailable for all three maps.

The exact account keeps BOTH conditional components:

    u_j = E_source[Cov(Y_j,X|C)]
          + Cov_source(E[Y_j|C],E[X|C]).

Their cold readings use the same total norm and therefore add. The second term
is source condition association, not automatically noise or author choice.
This design assigns task/style; it does not observe human self-selection.
Component norm ratios may exceed1 because signed vector cancellation remains;
they are not fractions of personality information.

## Observation realization differs from a target label

For generator assignment q, writing condition c and field j, the directly
observed response contrast is

    D_qcj = mean[a_j(t_high,c)-a_j(t_low,c)].

It is a finite generated-output contrast, not a human causal effect. In these
actual records, one target label does not fix one universally positive lexical
response. Extraversion social-form rates in diary are +.888293 in neutral,
-.245342 in newsletter and -.395167 in spelling writing. Raw occurrence
differences are respectively +1.444444, -.333333, -.666667 per article pair.
The reversal is present before any vector scorer is applied. It cannot be
repaired by improving vector transport precision alone.

This is not proof that every semantic expression reverses, that social word
frequency exhausts extraversion, or that a person's trait flips with formatting.
It distinguishes two assumptions that the old fixed-arrow narrative conflated:
target assignment, and that target's actually observed realization under C.
Sparse worry-form observations also restrict this particular observation family.
The frozen GRAIN witness retains some cross-task first-person correspondence,
but its evaluation worry contrasts are opposite more often than same, on the11
pairs with a nonzero observed contrast;43/54 have zero observed contrast.
Changing a dictionary would change the object, not merely improve measurement.

## Consequence for the mainline construction

Keep these distinct maps:

    qualified event -> vector observation,
    vector evidence operation -> reader action,
    source event law -> specified observable expression function,
    expression functions -> externally anchored psychological meaning.

HM164 makes the third interface executable for a finite real-output corpus,
without an LLM output supplying the target. The fourth is not inferred from
persona prompts. The necessary next object is a CONDITION-INDEXED observation
family O_c, not a globally fixed trait arrow whose fidelity is driven to100%.
For a future source-supported endpoint a_qc, an author-reference comparison has
the form

    Theta_uq(c)=integral a_qc d(P_u(.|c)-P_ref(.|c)).

An imposed reference mixture over c and naturally selected author conditions are
different measurements; preserve both if observed. Do not silently remove the
condition association in pursuit of stable scores. This expression is a mature
conditional-functional formulation, not identification of unknown a_qc from
the current word list or proof that all psychological targets are measurable.

Stop dictionary/score/precision grids. The next experiment must supply a new
source-observed endpoint or an actual author-linked observation law that can
distinguish target meaning from writer/reader response, using existing licensed
and authorized artifacts before any new collection. Do not glue independent
worlds together by endpoint name, unit, or matching probability type.
