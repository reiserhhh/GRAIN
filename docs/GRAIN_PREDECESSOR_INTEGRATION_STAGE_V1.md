## 1. 阶段目标

**先构成一个有文献依据、可以实际运行的先行方法参照体系，再确定GRAIN需要
新增的机制。** 不再从文献清单直接跳到自研新公式，也不把现版GRAIN设为不可修改的基础。

“追上”不是读完世界上所有论文、重跑所有研究，或在不同数据上追逐论文数字。
它指与本项目目标有关的每个关键功能，都有最接近的方法、明确的假设、可检查的
实现或适用性判断。允许理论继承、直接采用、适配和暂不适用四种不同结论。
“统合”不是把所有算法串成一个模型，而是统一测量对象、公式接口与比较协议，
保留互相竞争或处理不同对象的路线。

当前已有[全体系综述](GRAIN_WHOLE_SYSTEM_LITERATURE_REVIEW_20260912.md)、
[27项机制矩阵](GRAIN_MECHANISM_PREDECESSOR_MATRIX_20260912.md)和
[来源登记簿](GRAIN_LITERATURE_REGISTER.md)。这是检索起点，不是复现完成证书。

## 4. 什么才是可比较的统合

统一记录单位为作者、文档/片段、场合、已知条件、时间索引、评分器及证据来源。
不同方法的单位不得偷换：量表条目文本、作者自然表达、LLM判断和人的效标分别保存。

- 先检查原方法公开示例能否运行；无法获得原数据时称独立重实现/本地适配，
  不称原论文结果复现。
- 同一心理预测任务使用相同作者切分、数据访问和选择预算；特征与计分参数只在
  获准开发侧学习。原生编码器与共同编码器的对比分开，不因强制统一编码器削弱前身。
- 结构发现看计分可用性、维度/配置稳定性和内容；预测看目标关联；动态看过程恢复；
  解释看证据与计算的一致性。不能让全部方法只比一个Big5相关系数。
- 先用来源明确的已知模型检验实现，不在本阶段为证明GRAIN获胜而设计新机制世界。
  理论假设成立与不成立的情况分别标明。
- 整合只发生在对象、样本和监督方式兼容的接口。语义预测与条目匹配可以平行，
  状态模型不必串在静态分数之后；无共同支持时不强行拼接。
- MEPS只做权限允许的验证，不训练、选参或从其结果倒推设计；已经查看过的结果
  保留回顾性标签。不打开封存数据，不为了本阶段恢复旧长跑。

## 5. 第一阶段的完成标准

1. 27项机制都有来源及处理决定；关键链路不存在只写“已有论文”而不知公式和条件的空格。
2. I1三类核心参照均有可运行结果，或明确标注无法复现的依赖和替代实现。
   替代实现不得冒充原方法；重要未覆盖能力仍保持开放。
3. 至少一个获准数据场景能从文本到可追溯计分完整运行，并与现版GRAIN进行
   同问题比较；另有条件/过程接口的实现或已知机制示例，不把模拟通过当真人验证。
4. 结论能逐项回答：继承什么、替换什么、保留什么、哪一个缺口值得新增机制。
   不以文献条数、模型数或必须超过所有论文原始成绩为标准。

某条次要分支资料不足时，可以完成与其无关的主链，但该分支仍标为待解决，
不能据此宣称全体系已追平。若现有组合已经解决某个旧问题，就结束对它的重复发明。

建议交付一个版本化包，包含方法卡、公式/接口图、适配器与运行配置、来源版本、
共同协议结果表、证据示例、贡献与缺口台账。路径在执行前确定，不与历史实验输出混用。
