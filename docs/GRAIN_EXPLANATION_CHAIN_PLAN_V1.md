# M13: 可追溯解释链，有界实验 r1

本计划在运行前连同24段公开输入、配置、实现和冻结计分依赖记录SHA。
目标是完成计算解释链，不用更多分类精度调参替代意义分析。

## 对象和操作

固定匿名 `whole:F03` 与 `confirmation_seeking` 查询矩算子。前者来自发现/校准
作者分离的旧GRAIN模型；后者由四名来源作者上的查询函数编译而来。
不新增训练、不选坐标、不改变阈值、不读取真人标签或MEPS。

交叉3种证据身份（意愿、报告过去实施、当前请求）、2个表达极、2个时间条件
（5/45分钟）、2种措辞，共24段。身份标签不进入数值计分器，只用于公开实验
材料的解释。匿名坐标不预设方向；查询对确认请求的方向仅作描述性对照，不能
由其高分推出真实行动。材料内的当前请求也是作者构造，不是真人行为效标。

每段按现有四等词数slice保留完整原文，使用冻结TF-IDF/SVD/FA评分。
匿名读数是四个slice校准分的均值，不是新作者标准分或百分位。
查询使用同一原文的冻结Qwen前缀状态h，以及按字符重叠分配的token坐标g：

\[
 Q=b+T^{-1}\sum_t p_2(g_t)^T\beta_2h_t
   +T^{-1}\sum_t r_t^TAr_t,\quad
 r_t=(h_t-\bar h_{\operatorname{cell}(g_t)})V.
\]

逐token贡献是精确计算分账，不是词句的独立因果作用。完整原文替换同时改变
token、g、h和单元归属，不冒充固定g的导数实验。比较pole/identity/time的有限变化。
每个刺激配置的条件函数为两端均值和半差，不是实际人的稳定trait。

## 解释与验收

交付原文地址、slice读数、三项查询分解、条件有限变化、候选含义卡和证据级别表。
沿用已有解释schema，固定分数不可由解释器改写。身份意义来自已声明材料设计，
不能宣称系统独立理解了自然文本意愿/行动。精确引用、数值重算和变化分账通过
即可完成M13有限计算解释；若查询不能稳定区分表达极，报告边界，不救援提示。

外部联系仅引用历史聚合结果，区分F03均值与F03/Openness查询协方差两种对象，
不能把后者关联转移给前者或新confirmation函数。真人独立编码/行为证据保留D01。

预算：24次实际前缀调用、CPU两线程、模型载入后300秒；不调用后缀生成/反传。
结果保持不可覆盖。有限实验完成后更新TODO，不将结果解释为新量表完成。
