## Scientific decision and competitors

1. **Linear averaging**: each comment has a fixed target score; averaging it
   determines every subset score. There is an exact size-adjusted identity.
2. **Target-conditioned independent evidence**: given binary target q, all
   distinct comments have a common source conditional law rho_qg. Binary
   posterior log odds add, although probabilities need not add.
3. **Shared source-author evidence**: sample a source author uniformly once;
   conditional on that author's empirical8-cell law P_u, draw distinct events
   independently. The same author index links the five target labels. This
   creates a context-dependent likelihood update without fitting native scores.

All three have EXACTLY the same one-event target probability psi_q(a).
The difference is where conditional independence is imposed, not a better
one-event probe. This is a declared source empirical-resampling observation
model, not a proof that natural comments are conditionally independent.
Chronology, situation and occasion causes are not recovered by a latent source
index. The finite author catalogue is a working distribution, not a list of
psychological types.
