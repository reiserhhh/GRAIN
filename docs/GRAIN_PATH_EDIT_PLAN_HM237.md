## Exact edit calculus, no new general theorem

For an n-record history there are m=n-2 old triples. After deletion there
are m'=n-4-2 new triples. Partition old triples into retained R and destroyed
D; partition edited triples into R and splice-created B, using event identity,
not state equality. Let S=sum_old v_11/m. Then

    S_blind_edit-S = -sum_D v_11/m
                    +sum_B v_11/m'
                    +(1/m'-1/m) sum_R v_11.
    S_gap_edit-S_blind_edit = sum_B (v_d-v_11)/m'.

All four terms are retained. R can be empty; an empty extensive account is0,
NOT an observed trait score. Constant-field toy makes total edit response0,
but individual removal/splice/denominator accounts may cancel. No sign flip,
norm-to-zero optimization, residual deletion or target renaming permitted.
Compare counter-minus-support actions under blind versus known-gap contracts
and record every target/law; missing cells yield incomplete scores with coverage.
