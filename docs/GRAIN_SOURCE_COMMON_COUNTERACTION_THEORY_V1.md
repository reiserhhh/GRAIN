# 从当前算子到源固定读向量：共同计算与条件输入可以分开

2026-09-10，第三十六轮NEXT47。目标是逐段抽取文本到人格查询的计算机制，
不将原模型局部作用相关当作人类人格问卷相关。

## 1. 本轮确实减少了一项依赖

NEXT46的同作者两查询平均J仍需当前状态x。NEXT47仅使用旧4作者的两查询
状态构造读向量，新8作者不再提供此处的x、门控或归一化系数。在同GRAIN
方向上，固定读法与原生局部查询对比r=.955274、SSE/zero=.091333；负向
调整保留。pooled模式重复得到.954853/.092402。

新8全部使用相同的两个1536维向量（每种mode一个，查询间也共享），已实际
逐值核验。这不是每人重新拟合一个线性模型，也没有用新作者人格标签。

## 2. 公式为何可以缩成一个向量

令w*是NEXT44源构造的固定共同读头，J24(x)是实际RMS/SwiGLU局部导数，
S_u是允许使用的源作者集合。构造：

\[
\bar v_{u,m}=\frac{1}{2|S_u|}
\sum_{s\in S_u}\sum_{q\in\{N,C\}} J_{24}(x_{s,q})^T w^*_{u,m}.
\]

预测阶段仅计算：

\[
\widehat a_{u,q,k}=\bar v_{u,m}^{T}d_{u,q,k},\qquad
\widehat c_{u,k}=\bar v_{u,m}^{T}(d_{u,N,k}-d_{u,C,k}).
\]

这是伴随恒等式〈w,Jd〉=〈J^Tw,d〉，并非我们新发明的数学定理。新证据是：
从旧作者编译出来的局部读法能在另一批作者材料上保留该模块的实际响应。
直接算子计算与编译向量误差仅1.222e-15，而跨作者近似误差真实非零；二者
必须分开，不把代数恒等式当成跨作者有效性的证明。

对整个同材料接口，d仍可写为

\[
d_{u,q,k}=\mathcal K_{u,q}D_{u,k},\qquad
\widehat a_{u,q,k}=\bar v^T\mathcal K_{u,q}D_{u,k},
\]

其中D是共同GRAIN正文方向，K是当前query条件下到preMLP24的原生传输。
因此本轮固定的是末端局部读法，并未把K或原始文本编码改成无模型程序。
“共同读向量”与“条件化输入路径”能够同时存在，不互相否定。

## 3. 余项不是一个笼统的误差

定义c为当前作者平均算子作用，o为当前查询算子差异作用，n为原生增量对比。

\[
\widehat c-n=(\widehat c-c)-o+(c+o-n).
\]

三项依次是源替换误差、遗漏的查询算子项、数值实现余项。新8自身模式RMS
为.013454/.024635/1.84e-7，合成误差.028791；不能把RMS直接相加，协方差
也参与误差。源4的替换误差.013857，遗漏项.016109，情况并不完全相同。

这提示共享机制之外还有一个小的query条件项，值得用一次固定源向量检验。
它还不是作者独有的心理机制，也不自动归于“措辞噪声”。只有实际跨查询、
跨作者比较后，才能决定哪些条件参数需要保留。

## 4. 与先行数学方法对齐

[Olivieri与Pérez Rodríguez的响应理论预印本](https://arxiv.org/html/2605.25225v2)
§V使用伴随状态连接前向响应与输出敏感度。这里采取有限维、离散的同一基础
恒等式；不借用其跨模型扩展假说作为我们已经验证的事实，也不要求物理场解释。
我们的附加问题是固定源群体能否提供可复用的伴随读法，以及它与作者的GRAIN
方向怎样组合。这一经验转移由当前缓存实验支持，来自论文的则是数学参照。
