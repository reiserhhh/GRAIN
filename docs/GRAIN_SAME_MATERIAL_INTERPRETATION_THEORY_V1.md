# GRAIN 与查询路径：同材料联合测量及解释接口

2026-09-10。对应 NEXT27–28。目的仍是建立文本人格/状态推论的方法基础，
不是新量表、治疗系统或自动精神分析。实测见
[本轮报告](../reports/grain_vector_mechanisms/SAME_MATERIAL_INTERPRETATION_REPORT_V1.md)。

## 1. 用户补充改变了什么

两套系统最直接的连接点不是最后两个作者总分，而是**同一份局部材料**：
GRAIN 测量该材料的表达配置；查询函数测量同一材料对指定模型读出的作用。
可以先保留两个侧面，再研究它们是否共同变化，而不必假定一方是另一方的误差。

对作者 u 的视图 v、局部单位 j，记 GRAIN 坐标为 g_uvj，查询读数为 psi_quvj。
每个观测具有相同的原文地址、说话者、时钟、条件、版本与参照。
联合经验分布为：

\[
\pi_{uvq}=n_{uv}^{-1}\sum_j\delta_{(g_{uvj},\psi_{quvj})}.
\]

单独汇总两组值只保留边缘分布。打乱它们的配对，两个边缘分布不变，但联合
分布及协方差改变。**因此“如何一起出现”是独立于两套总分的可研究对象**。
这使用标准经验分布与协方差，不宣称创造了新的统计定理。

## 2. 当前可执行公式与新发现

本轮先使用已经抽取的 E5 查询配置函数，精确展开为

\[
\widehat C_q=b_q+\frac1{12}\sum_j w_q^\top h_j,
\qquad \psi_{qj}=w_q^\top h_j.
\]

这是从原有固定模型配置目标学出的线性函数，不是新标签预测器，也不是原生
注意力权重。它的评论局部分解是精确的，模仿原模型仍属于既有近似接口。
GRAIN 的每评论 g_j 是该评论四个冻结词法切片分数的均值。

保留四类统计：

\[
U=\bar g,\quad a_j=|\psi_j-\bar\psi|,\quad
W=\frac{\sum_j a_jg_j}{\sum_j a_j},\quad
D=W-U=\frac{\operatorname{Cov}_j(g,a)}{\bar a},\quad
S=\operatorname{Cov}_j(g,\psi).
\]

协方差采用总体分母 n；当局部信号总量近零，W 回退 U，D=0。
W 对路径读数加常数或翻转符号不变；S 保留符号，因而可以表达相反的共同变化。
这种绝对离差是预定义权重，不是心理重要性、置信度或因果效应。

实测中简单 W 没有普遍增强。开放性查询下 F03 的作者均值与自评相关 .076，
W 为 .052；S 与自评为 -.264，180 项关联 BH 校正 p=.0175。
与此同时，该组合的平均评论内相关只有 -.031。这区分了：

- 群体平均而言，两信号是否同步；
- 不同作者的同步方式/幅度，是否随一个实际效标而变化。

S 仍混合两个边缘的波动幅度与对齐程度，因为每个视图有精确恒等式
\(S=\sigma_g\sigma_\psi\rho_{g,\psi}\)。跨视图平均乘积一般不等于平均量相乘。
下一步应把幅度、配对和方向分别计量，不把 S 一步命名成人格机制。
当前发现提供了具体对象，不要求先把所有临床问题解决才继续开发。

## 3. 用户提出的 token/slice 路径如何接入

第十四轮做到同评论对齐；第十六轮的[原生接口](GRAIN_NATIVE_MATERIAL_READER_THEORY_V1.md)
已加入token地址上的GRAIN方向与原生后缀梯度/有限干预。两个实验分别保留，
不把第十四轮统计改称逐token因果效应。需要三个不同的单位：

| 单位 | 用途 | 必须保存 |
|---|---|---|
| 字符区间/词法 slice | GRAIN 观测与展示地址 | 原文哈希、字符起止、切片版本 |
| tokenizer token/模型状态 | 功能与干预归因 | tokenizer、offset、层、查询、端点、参照 |
| 完整关系叙事/连续对话片段 | 心理解释与盲编码 | 角色、前后轮、被转述者、事件性质 |

它们可以互相映射，但不能拿 token 序号直接当词法切片序号。已实现并测试
`span_allocation`：跨切口 token 按字符重叠比例记账，总贡献不丢失不重复。
这只是记账约定，不能从中识别 token 内各字符的独立因果作用。

未来原生效应应写为带明确基线的片段主作用和交互项，而不是全靠正权加总：

\[
\Delta F_q=\sum_j\phi_{qj}+\sum_{j<k}\phi_{qjk}+R_{q,>2}.
\]

\(\phi\) 的定义必须由具体干预/归因方案给出；交互分配依赖参照与操作顺序。
保留现有评论交互、条件载体、完整输入协议；不能因为图像上路径靠近就省略它们。

## 4. 相关研究提供什么接口

以下为一手论文的定向比较，不是全面系统综述，也不直接移植专有量表条目。

| 先行工作 | 已做的任务/证据 | 对我们的具体启发 |
|---|---|---|
| [Antichi et al., 2026](https://link.springer.com/article/10.1007/s12144-026-09685-3) | 一个案例的前两次会谈，结构化提示编码简化防御机制；模型倾向多标，人与模型一致性低，但部分新增候选获督导认可 | 定位证据、提出候选、独立复核；不把生成标签当患者事实 |
| [Tasca et al., 2023](https://doi.org/10.1080/10503307.2022.2156306) | 158 人、192 次依恋访谈，16,785 个问答对；RoBERTa 防御编码 ROC-AUC .82–.90、PR-AUC .28–.60 | 有定义的观察编码可由向量模型学习；需与人工编码链接，而非从相关自动推导无意识动机 |
| [COMPASS, 2025 / arXiv 2024](https://arxiv.org/html/2402.14701v3) | 对话与36个治疗联盟条目嵌入相似度，汇总 Task/Bond/Goal，另做序列分类及 LLM 解释；缺直接逐轮评分与解释验证 | 很接近“数字测量+解释”模式；相似度、功能响应、真实联盟评分必须分列 |
| [Zamojska et al., PACLIC 2025](https://aclanthology.org/2025.paclic-1.55/) | 控制上下文与 Parent/Adult/Child 状态的代理对话实验 | 支持构造 TA 互动玩具世界，不等于验证真人 CP/NP/A/FC/AC 的逆向测量 |
| [Frontiers 临床案例研究, 2015](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2015.00477/full) | 使用 CCRT 的关系叙事编码，区分愿望、他人的回应、自身的回应 | 心理解释可能以一个关系事件为单位，不能只给孤立词或切片贴标签 |

Tasca 原文四个具体防御为 repression、intellectualization、reaction formation、
undoing；不照抄其他论文转述中出现的 suppression。其
[作者公开稿](https://people.scs.carleton.ca/~matthewholden/assets/Tasca2022a.pdf)
可核对。上述 AUC 是观察标签识别，不与我们的 Big5 r 或评论内相关直接比较。

精神分析不是“只有文字”：叙述中的他人与真实互动中的对方不同，语调、背景、
治疗关系等也不必在文字中完整呈现。我们借用可操作化的**关系/表达模式编码**，
而不是宣称从文本恢复完整临床过程。自然文本也不会因为被解释就自动成为标准
投映测验。旧 TEG 词汇代理 p_fdr=.060 的降级记录保持不变。

## 5. 将第二个想法落实为可测的解释层

本轮交付 JSON schema、本地校验器和渲染提示规范。流程为：

1. 固定原文与相邻轮地址，标记实际发言、转述、假设、引语及角色。
2. GRAIN 与查询程序输出不可回写的数字、参照、查询和算子版本。
3. 解释器仅生成片段级候选，并列替代解释、缺失背景、证据强弱和人工状态。
4. 校验器核对原文哈希/引文区间/数值与引用绑定，拒绝改分或引用不存在的证据。

程序校验不判断自由文本解释是否合理，也不自动核实角色归属或人工审核状态。
当前提示未做 LLM 性能实验；“有 schema”不等于“解释已稳定”。没有临床标签、
严重度或处方字段。样例完全虚构，本轮没有发送任何参与者材料。

若后续做盲编码，编码者只能看到文本、条件和预定 rubric，不能先看问卷、GRAIN
分数或路径权重。冻结标注后再计算局部定位、编码一致性、构念差异和向量作用
关系；看到数字后的渲染不被反用作独立金标准。首选问题是“表达模式与关系事件
怎样对应”，不是“这位作者患有什么问题”。

## 6. 新的接合方式与下一步

接合不再只有作者总分相加，而有四层：同材料双读数、局部配对、响应交互、
带证据的候选解释。NEXT24–26 的条件数学/运行接口继续保留；新的具体候选是
把 S 拆为幅度与对齐，再用同一材料的原生 token/片段效应替代当前编译读数。
不直接扩大临床样本读取、LLM调用或调参网格。
