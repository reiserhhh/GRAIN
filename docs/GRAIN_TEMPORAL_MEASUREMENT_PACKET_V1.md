## 新增机制

个人窗口参数theta=(a,b,c)，此刻状态s(t)，文本观察y(t)：

    y_q(t) = a_q + b_q z_q(t) + c_q u(t) + s_q(t) + e_q(t)
    ds(t) = A s(t) dt + L dW(t)

z为条件，u为前置对方输入；A允许跨通道耦合。
文本读者的误差e与潜在状态s分开。一次联合高斯条件化给出不同目标的
核：共同条件下个人位置、条件差、伙伴响应、此刻状态、窗口内状态平均。
窗口参数不是永恒trait，token顺序不是心理时间。

继承[Driver等2017 ctsem](https://www.jstatsoft.org/article/view/v077i05)的
潜在测量层/不规则时间观念与[Oravecz等2009](https://cidlab.com/prints/oravecz2009hierarchical.pdf)
多元OU条件转移。我们的新接点是从现有文本证据接口到目标特定的时间/条件核。
对方输入分账受[Cook与Kenny2005 APIM](https://journals.sagepub.com/doi/pdf/10.1080/01650250444000405)
启发，但本包不称完整双人潜在APIM估计。

## 固定实验

来源条件读者/证据校准复用condition_accumulation_r1，不重新拟合。
六世界：规则/不规则/集中采样、恒定伙伴、反馈伙伴、共享状态冲击。
3种子×32模拟作者，每人32机会；8/16/32前缀，两个既有事件查询。
Gaussian观察与真实NLI已计分公共句库观察分开。句库每次机会有8个独立事件报告；
生成器真参数仅评价使用，读者只获文本数值、条件估计与指定伙伴输入。
公开模拟的漂移/协方差是声明的构造参数，不能声称来源已学会动力学。

比较joint、把间隔误当均匀的order_clock、忽略伙伴、切断时间/跨通道联系；
另保留原始当次均值/历史均值的端点参照。不给test选参数。
前缀末端是在线读数，前缀内过往状态是回顾平滑，不用未来信息冒充在线。
共同冲击世界故意违反对方输入外生条件；恒定伙伴检验参数可识别性，
Bayes借力不能被误写成从文本单独识别了作者a/c。
