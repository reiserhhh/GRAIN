2026-10-09. Planned, not executed. HM45 remains deferred, not failed or closed.

## Question and competing explanations

HM46 self/actual responses contain a large shared evaluative content projection
and stable non-diagonal effects. These may reflect common behavioural meaning,
the reader's evaluative halo, or a mixture. Cross-trait steering interference
already has precedent (https://arxiv.org/html/2602.15847v1); coupling alone is
not our novelty. Test one specific external-evaluation mechanism instead.

Hold each HM46 behavioural clause, ownership, actuality and target query fixed.
Append either no evaluation, or an evaluation by an explicitly other observer:

    A separate observer, not the writer or the person described, called the
    described behaviour admirable.

    A separate observer, not the writer or the person described, called the
    described behaviour objectionable.

Insert that sentence inside the account before "End of account.", never after
the evidence boundary or in the scoring instruction. No-evaluation inputs keep
the original HM46 bytes and actual template unchanged.

The designed intervention changes outside evaluation, not the recorded action.
It is still new information in the account: do not assert it must have zero
psychological relevance, nor erase all evaluation as noise. Its identity and
the writer's own reactions remain separate observation objects.

## Primary contrasts

For content c and query q, report each high-minus-low behaviour response at
positive, negative and absent external evaluation. Also report the within-action
evaluation contrast positive-minus-negative. Preserve the average and separate
surface forms, source/application and all three account conditions.

The behaviour x evaluation interaction is the difference between high-low
responses under positive and negative evaluation. It measures a conditional
reading relationship, not personality accuracy. Compare response matrices,
diagonals/non-diagonals, the predeclared evaluative content projection, and the
HM46 source-leading mode without using application output to select a direction.
Any projection calculated on the application matrix is labeled diagnostic.
Norm-zero and very small contrasts remain reported, never filled as success.

No p-value treats the216 constructed texts as independent human authors. Do not
manufacture a target trait label for another observer's appraisal. Model scores
are observations to explain, not questionnaire truth or measured author traits.

## Scientific acceptance, not a winning prediction score

Accept the finite question as answered only when the complete contrasts and
arithmetic/provenance checks permit one of these actual decisions:

- Strong shared evaluation shifts: retain an explicit external-evaluation channel
  before attributing the common mode to behaviour or author traits.
- Small evaluation shifts with retained behavioural non-diagonals: this outside
  evaluation explanation is insufficient; preserve shared behavioural meaning
  and test a different causal account, not a broader accuracy grid.
- Target-specific interactions: keep a conditional joint reading operator rather
  than one universal content or eligibility multiplier.
- Form/example dependence: report that dependence; do not cherry-pick a common
  mode or declare all reading mechanisms absent.

Magnitude is judged relative to the observed behavioural contrast and no-eval
reference, not a tuned universal significance gate. A null or mixed result is
useful if it removes one competing explanation. A near-perfect approximation
without a changed mechanism decision is not the purpose of this packet.

Outputs: full native logits/scores/candidate mass and addresses, material/model
manifest, cached-versus-fresh ledger, evaluation and interaction tables, complete
conditional matrices, focused synthetic tests, alternate arithmetic readback and
a report explicitly separating known tools, finite findings and proposed novelty.
