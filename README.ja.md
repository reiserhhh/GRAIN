# GRAIN：個人言語テクスチャ分析法

**Group-Referenced Analysis of Individual Natural-Language Expression**<br>
**参照集団に基づく個人自然言語表現分析法**

[English](README.md) | **日本語** | [简体中文](README.zh.md)

GRAIN はテキストに基づく測定研究のための基盤分析法である。個人の自然言語
イベントを複数の粒度で観測される局所的な「粒」とみなし、明示した参照集団に
対する再現可能な分布、方向、条件応答、経路構造を分析する。それらが組織化
された多尺度パターンを**言語テクスチャ**と呼ぶ。GRAIN 自体は尺度ではなく、
現行コーパスが尺度になることも要求しない。将来のテキスト・アセスメントは、
独自の構成概念・母集団・妥当性・使用目的の証拠を備えた場合にのみ、この基盤
上に構築できる。

旧名称期の西瓜・皮モデルは方法の発展史として残る。話題と状況は単純に除去
すべき包装ではなく、条件選択と条件内応答も個人情報を運びうる。GRAIN はこの
知見を、一つの切片比喩に依存しない一般分析法へ拡張する。詳細は
[名称移行・互換方針](docs/GRAIN_NAMING_MIGRATION.md)を参照。
公開移行の範囲は [v1.1.0 リリースノート](docs/RELEASE_NOTES_V110.md)に記録する。
タグゲートの修正は [v1.1.1](docs/RELEASE_NOTES_V111.md)に記録する。

## 証拠状況の正直な要約

ホールドアウト級(T3)で確認済み: 選択軸の安定性(5/5 軸、縮小 0.027)、
発見された 15/15 構成概念の未見ユーザーでの確認、他人帰無の下での react
シグネチャ 2 構成概念。反証・撤退済み: 条件平均中心化(独立に3通り)、
感情語率の特性/機会状態測定としての使用、アテンション重みの測定証拠と
しての使用。確認的(T4、開封#1、2026-07-07): 事前登録の成功規則は
不合格(2/7)——一人称使用 → 神経症傾向と政治/ニュース選択 → 開放性の
2 関係のみロックボックス級で確認。スコープ: 英語、1プラットフォーム +
学生エッセイ。

V8 時代の追加事実(いずれも台帳が正典):

- 実テキストの直接予測はヌルが正直な結果(V8 不変スコアの Big5 直接予測
  r=−.005、ニュアンス比較対象未満)。強い見かけの数値には必ず格が付く。
- 著者識別 AUC は人格妥当性ではない——個人構造ゼロの合成世界でも著者
  AUC .864 が出ることを実証済み。
- 拒否は機能である: 型システム・比較ライセンス・サポート監査が
  「してはならない比較」を例外として送出する。設計ヌルでの誤受理は
  R→V 橋で 0/200。
