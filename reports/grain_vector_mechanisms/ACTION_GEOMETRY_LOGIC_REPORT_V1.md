# 第十三轮：作用几何、路径适应与完整输入依赖

2026-09-10。NEXT21–23完成；整个逻辑研究goal继续。

## 结论先行

本轮不再用“共享矩阵很相似”代替“能读出每个人的实际作用”，而是实际校准
并分解其作用。**一次参照内校准使T/F作用误差降低4.67%；更关键的是，剩余
作用差异主要来自沿当前R位移的敏感度变化。** N相邻评论的共同方向及个体
幅度已经部分可读，远隔差异则要分开折内与折间来源。

同时完成全链输入审计：数学上的完整条件B并非完整原生F。两者差异已经
逐人复算并文档化，明确下一程序不能跳过的输入，而不是继续仅比较相关。

## 1. 实验范围和代价

- T/F沿用4名源参照作者和20名其余源作者；参考与评估角色不交换。
- N沿用24名源作者、原4折、固定相邻/远隔评论对和所有旧读法。
- 1次预先固定的参照校准，2.22秒；0新神经调用、0新参与者、0新API。
- 所有新预测和几何分解先冻结，之后才连接已暴露的源问卷；未用Y拟合、
  挑参数、改符号或选查询。这是旧材料上的机制开发，不是新增盲检。
- 区间采用1999次整作者重采样，条件于现有拟合结果；不包括重新构造参照
  人群或重新拟合CV模型的不确定性。完整负条件保留在聚合表。

计划`0fb89ff`，实现`b30e767`，无拟合条件诊断`8a45048`。

## 2. T/F：从共同矩阵到作用加权读法

136个保留位置、每位置1536维，总计208896维。以四名参照作者的完整积分
矩阵均值g0为先验，只在四行参照位移D支持内修正：

    g = g0 + D.T @ solve(D@D.T + n*.01*s2*I, phi-D@g0)
    s2 = trace(D@D.T)/n

这正是先验中心化的正则最小二乘，不是新定理。广义representer theorem的
biased regularization讨论给出已有理论依据；本项目贡献在于用它检验实际
条件作用，而非把人格问卷当拟合目标。[Scholkopf等，2001](https://alex.smola.org/papers/2001/SchHerSmo01.pdf)

| 固定臂，20名评估作者 | 作用MSE/零作用MSE | 实测作用相关r |
|---|---:|---:|
| 原完整平均矩阵 | .853553 | .269250 |
| 参照作用均值 | .938863 | 无定义（常数） |
| 新参照支持校准 | **.813729** | **.277043** |
| 零作用 | 1 | 无定义（常数） |

相对原矩阵误差下降4.6657%，配对95%区间[-.0529%,7.5343%]。这是一个
小的实际作用改善，区间仍跨零；不写成人格预测已经显著提升。

四行位移奇异值约104.10、96.66、92.93、2.29e-5。末项来自近零均值参考的
浮点残留；有效自由度2.912。其它作者的**ridge软参照支持平均仅.009129**，
范围.000141–.031249。这是正则投影的位移能量比例，不是被解释人格比例。
仅在这几条原始高维方向内校准，自然留下大量未经校准的输入方向。

作用本身也与矩阵能量不同：四参照的共同作用RMS=.006510，矩阵偏差作用
RMS=.013297，实际积分作用RMS=.009913；交叉能量为负，二者抵消。因此
旧91.18%共有欧氏矩阵能量绝不能解释成91.18%实际个体作用已被捕获。

## 3. 查明是哪一种条件导致作用偏差

不重新跑模型，复用起点梯度J_u，以及固定M0、原正文M_u下的R路径积分
H0u、H1u，精确分成：

    G_u = J_u + (H0u-J_u) + .5*(H1u-H0u)
          布局起点   R路径变化       正文条件交互

在每项中减去四参照的对应均值，再与本人的真实位移相乘，得到下表。
最后一列为与总偏差作用的有符号内积占比，**不是互不重叠的方差比例**。

| 来源 | 矩阵偏差有符号份额 | 偏差作用RMS | 偏差作用有符号份额 |
|---|---:|---:|---:|
| 布局起点 | .4488 | .002606 | -.0810 |
| R路径变化 | .5450 | **.014656** | **1.0899** |
| 正文条件交互 | .0062 | .000223 | -.0088 |

**矩阵偏差中布局占很多，但实际遗漏作用主要来自R路径变化。** 大于1和
负份额是抵消关系，不是异常。分解收支在1e-12以内闭合。
不减参照均值时，R路径项作用RMS=.013807，起点线性项=.006872，正文
交互项=.000531；这些原作用同样相关，不能相加RMS作总量。

该路径项在光滑条件下可以写为：

    (H0u-J_u)^T d_u
      = integral_0^1 (1-t) d_u^T Hessian_R F(M0,R0+t*d_u;L_u) d_u dt.

本轮测的是已存梯度积分及端点，不是已求出208896平方维的Hessian。
这把“神秘个体余项”缩小成了具体的**条件位移曲率**候选；它是模型里的
数值机制，心理命名与作者外部联系另行记账。

四参照位移均值接近0，实际平均作用却为.000931，固定齐次线性读法平均
约为0。一个简单二次函数的合成测试明确展示这种情形：平均输入为0，二次
作用仍为正。真实数据还混有布局与积分近似，不能仅凭平均差就唯一归因；
上面的逐路径分拆提供了更具体的依据。

## 4. N：共同方向、个体幅度与输出曲率

每个训练折只用18人的平均中心化logit交互确定单位方向v。其余6人不参与
定方向。对实际/预测向量都拆成沿v的幅度与正交部分，不再把范数和有符号
输出当成同一个量。

| 几何量 | 相邻 | 远隔 |
|---|---:|---:|
| 不同训练折方向平均cosine | .9824 | .9531 |
| 评估交互能量沿v占比 | .6293 | .4424 |
| bag幅度 pooled r | .4791 | -.4391 |
| bag幅度折内r | **.5014** | -.1139 |
| position幅度 pooled r | .3591 | -.5136 |
| position幅度折内r | **.3629** | -.1611 |

相邻的折内变化已有可读部分；远隔的强负pooled r大部分来自折间均值，而
不是已经证明逐个作者的机制方向相反。常数型训练对均值的所有相关都来自
折间，没有折内辨人信息。这次纠正保留原表，并增加精确协方差分账。

最后softmax映射的局部线性化余项很小：相邻2.41e-6、远隔1.50e-7；
对应实际内部作用RMS分别6.79e-4、1.68e-4。**此处不应继续把主要误差归到
最后一步评分曲率。** 需要理解的是混合向量的方向、幅度和正交能量。

固定Ridge对目标是线性的：(A Y)v=A(Yv)。因此用同一核、同一惩罚另训
一个投影标量目标，必然等于现有向量预测的投影，不会产生新机制。
但条件向量均值的范数与条件范数均值一般不同，这是下一步可测试的新接口。

## 7. 研究决定与复算

下一步不是扩大精度网格，而是：先读取R路径曲率如何随真实位移变化；再
查N的范数/能量是否能构造出与方向读法不同的信息；最后选择一个有明确
输入契约的完整条件接口接回GRAIN。旧正结果保留，缺少新行为数据的心理
命题单独pending，不阻止当前数值机制开发。

理论依据方面，[active subspace研究](https://arxiv.org/abs/1304.2070)强调在指定
分布下研究梯度变化；其梯度二阶矩不是我们这里的位移二阶矩，也不自动给出
四参照人物的心理有效性。本项目将这一差别落实成作用加权损失和实测分账。

83项相关测试通过，包含12项新测试；两个既有SWIG弃用警告。不是全仓库
测试声明。10个预测/模型/依赖文件与5个聚合表字节级重放一致。诊断输出
扩展时修复了输出目录名被输入文件名覆盖的问题，增加回归测试；旧结果
