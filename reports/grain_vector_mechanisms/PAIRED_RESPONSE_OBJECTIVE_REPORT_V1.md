# NEXT66：显式学习配对变化，定位token局部加和的边界

2026-09-11，第55轮。主实现 `3114dca` 在结果前冻结。
源4作者原始/上下文干预视图构造，既有源外8作者应用；两固定查询为
neuroticism、confirmation_seeking，后者不是Big Five尽责性。

## 1. 结果与路线决议

显式变化监督确实略微改善了源响应，但没有把完整读取器提升到旧对照之上。
这一次不继续调权，而是完成了两个数学定位：

1. 576个条件字典方向在当前源数据中，只能覆盖变化目标能量的
   **11.34% / 8.66%**。不是增加变化损失权重就能补出其余方向。
2. 当前公式虽有BODY×查询上下文交互，但固定last时仍是**逐token独立函数相加**。
   不同BODY token间的混合导数严格为零；它缺少“另一段材料改变这段材料读法”的函数形式。

第二项是代码与公式的结构性质，已用合成数值核验；其在原生人格查询上的
大小尚待 NEXT67 测量。源字典容量不足也可能来自其它局部特征选择，不能
把11%这一结果全部归因于未测的跨token机制。

## 2. 唯一主改动

沿用NEXT65完整距离核、BODY U8、64地标/Hermite字典、1169总系数、alpha=.01，
及原始分数/密度尺度。四旧对照不重训、不重应用。只增加：

    J66 = J65 + mean_author mean_elements((dhat-d)^2) / s_delta^2
    d = (k_shifted-k_original)/2
    s_delta^2 = mean_author mean_elements(d^2)

源原始与干预视图各半，作者等权；新增通道零变化预测误差=1，系数固定1。
实际相对原密度尺度的额外半差权重为494.18 / 186.24，不隐藏归一化幅度。
评分和所有导数仍来自同一个标量；没有独立拟合一个不可兼容的响应头。

## 6. 下一步：跨材料读取，而非继续局部字典修饰

当前条件标量可写为 `a(h)+mean_t f(H_t,p_t,h)`。固定h、位置和源归一化时，
对不同token i,j有 `d²L/(dH_i dH_j)=0`。增加局部核中心或变更其权重不能改变此性质。

[NEXT67](../../docs/GRAIN_CROSS_TOKEN_READING_PLAN_V1.md)将固定后半正文及last，
仅在前半正文施加一个预定GRAIN方向，检查原生后缀对**未改后半正文**的梯度
是否改变。17次原生调用上限内完成，不训练、不读新8或问卷；若有作用，
再开发非线性汇总/归一化证据选择，而不是再拟合一组局部相加函数。
