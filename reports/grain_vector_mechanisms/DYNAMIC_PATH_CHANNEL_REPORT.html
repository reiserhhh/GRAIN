GRAIN dynamics, personality-query paths and measurement channels

Date: 2026-09-10. Finite execution complete. Discovery-led mechanism experiment, not a new full-PANDORA benchmark, newly validated psychological scale, or release scoring change. The useful new result is an operational dynamic-factor to model judgment connection, alongside evidence that model-readable and criterion-linked information need not be the same part of a factor.

2. Two time scales, not one ambiguous movement axis

Restored 9,936 exact masked comments and their original timestamps/subreddits. Every author contributes three 12-comment views from 36 distinct discussions. Median author span is 1068.9 days; median within-author comment gap is 12.6 days. These are sampled comments, not adjacent conversational responses.

The sampled-comment branch scores four three-comment blocks per view with the frozen whole/native bundles: 3,312 blocks and eight coordinates. The separate within-comment branch retains 9,165 of 9,936 comments (92.2%), four lossless contiguous lexical-token spans each: 36,660 slices. All 276 authors remain; at least 7 eligible comments per view. These are GRAIN lexical/punctuation tokens, not Transformer tokens. No old factor basis or reference norm is refitted.

Four points support short-path descriptors, not individual AR parameters or a complete flow/gust process decomposition. Moving a frozen whole factor to short spans is an explicitly new observation use; the within-comment CV baseline therefore includes its four new slice means. Neither branch replaces the released GRAIN dynamic measurement system. This is a precisely bounded interface test.

Pooled CV r/AUC can be distorted by fold-specific intercepts; the saved metric files include centered within-fold r, valid-fold AUC and training-mean MSE. For example, sampled-comment SN baseline pooled r=-.234 coexists with within-fold r=-.028 and AUC=.487. Do not reinterpret a negative pooled r as a reversed personality mechanism. Two fixed label permutations per baseline/full arm are sanity checks, not a calibrated significance test. No result is rescued by flipping predicted signs.

The reason the broader "saying versus doing" gap cannot be numerically isolated is identification, not insufficient model complexity. With only observed text T and questionnaire Y, a world with unobserved action B=Y and a world with B independent of both produce the same observed (T,Y) distribution. They imply different text-action relationships. More elaborate functions of (T,Y) do not select between them. Big5/MBTI self-report must not be renamed real action.

7. Updated mathematical interface and next useful experiment

Keep four distinct objects for each factor: level, dispersion, ordered shape, and model sensitivity. Let H denote the concatenated P/Q state and G the frozen factor coordinates. Source fitting provides Delta H = D Delta G + R. For a frozen affine reader f(H)=b+g^T H, the following identity is exact:

Delta f = g^T D Delta G + g^T R.

For the actual nonlinear native reader F, the exact differentiable path identity is Delta F = integral_0^1 grad F(H+t Delta H)^T Delta H dt. Our finite native patch tests a local action along D, not the entire integral or a natural text edit. Separately, D_time(G+c_author)=D_time(G), so dynamic matching alone cannot recover reference-relative author offsets. Preserve the static anchor.

This round's decision is a factor-specific, statistic-specific interface, not universal concatenation. The next sharply defined mechanism question is why F02 level/change is model-readable while its within-text dispersion is more linked to the recorded T/F criterion in this sample. Compare level-aligned and dispersion-aligned state directions on the same material, retaining the current whole:F02 direction as a positive model control. Do not restart a broad accuracy grid or discard GRAIN coordinates simply because a query does not read them. An action-gap experiment requires separately declared same-author action outcomes and opportunity/timing, possibly from independently coded existing MEPS answers; new human recruitment is not automatically required, but outcome definition is.

The method choices are aligned with, rather than inferred as established by:

  • Fleeson (2001): trait-related behavior distributions can have distinct location and variability properties.
  • Campbell and Fiske (1959): different methods and different constructs must be distinguished when interpreting covariance.
  • Jain and Wallace (2019): a displayed attention pattern is not itself evidence of explanatory importance; here the native follow-up tests an actual state intervention instead.

This completes the five bounded computational questions. It does not assert that all latent behavioral mechanisms are identified, or that every historical GRAIN dynamic-factor family was tested. Released scoring, B0/B4, existing lockboxes and parked long-running queues are unchanged.
