## 主要结论

**把参考积分场的总作用修正到端点，并不会自动使既定函数族成功运输。**
这关闭了“只要修正积分误差就能救回当前构造”的捷径，但没有删除方向作用。
N函数源关联依旧最高到.4063，实际奇作用读取仍弱。下一阶段需要新的函数
表示或参照覆盖，而不是把本轮方向结构再次改叫噪声。

## 新增的数学边界

```
g_star = g + [o-<d,g>]*d/||d||^2
<d,g_star> = o
```

8个reference监督的约束误差最大1.73e-18；整个144材料的奇性误差0。
这是最小范数改动，不是找到唯一真实梯度。满足同一约束的所有场为
`g_star+v, <d,v>=0`。单个端点作用只识别一个投影，不能识别整场；必须声明
所用路径、度量与函数族。这也解释了“有共同作用函数”和“唯一共同内部链”
是不同理论主张。增加一条作用约束不是增加全场信息。

成功保持端点恒等式属于代数验证，不算新经验效应。当前读出仍有用作研究
坐标的正例；它不是取代全分数PQ函数的新主预测器，不与PQ重叠相加。
