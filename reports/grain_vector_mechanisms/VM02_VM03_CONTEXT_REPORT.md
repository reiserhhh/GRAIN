# VM02/03：从共享记忆到独立作者对应

日期：2026-09-05。24 作者开发 pilot；探索性模型机制，不是人格效度。所有数据选择与层图分析不使用心理量表值。

## 结论先行

1. 同一份历史反复出现，足以把向量匹配抬到接近 1.00。即使当前文本完全不含作者差异也成立，不能把它当成高可靠人格推断。
2. 换成同一作者的互不重叠历史评论后，仍有较弱的作者对应结构。某些中层 pooled 表示比初始 token embedding 更有区分，但不是所有层、所有读点都变好。
3. 真正值得接回 GRAIN 的是：**上下文条件下的信息保留与使用**，不是共享输入的“伪重测”。本人历史不是噪声；只是必须用独立证据检验其中的可重复对象。
4. 一组非常具体的社交主动性问题在所有真人条件上默认输出 No。模型能识别明确合成正例，但主体归属和答案编码依然脆弱；该读出尚不适合宣布自然人格推断能力。

## 数据与预算

从 official raw PANDORA 按无标签 hash 规则准备原评论，正文未重新摘要。每位作者 3 个较早 history + 2 个较晚 current，线程互不重叠、标准化精确重复排除。尚未完成跨评论语义近重复审计。历史与当前时间差中位数约 17.9 天、最大约 1,272 天，因此不是人格时间稳定性的重测。

8 技术作者中 1 人没有在当前之前的匹配他人历史，明确排除；7 人共 210 条件。独立的 24 开发作者全部可匹配，完成 720 条件：2 真 current + 1 共通 anchor，5 历史 arm（same、other_length、other_condition、none、same_reversed），2 任务。

匹配基于历史 token 数、时间差及 subreddit 交集，不使用标签；中位 token 误差 5.4%，最大 42.7%，21 个唯一 donor，允许重复。不能声称主题、时间和长度已经完全控制。none 同时改变当前绝对位置与语义历史，有固定计算长度并不等于有固定语义位置。

另完成 480 个共同当前片段控制、384 个独立历史条件、48 个合成端点控制。模型与 VM01 相同，固定 BF16 masked execution length=2048；主 pilot 723 forward、213.36 秒，显存峰值 3.73 GB。所有 pre-question task 差异和固定输入 embedding 历史差异均为 0，无 hooks/重播问题。

## 先发现陷阱，再用独立材料补上

表中统计量是：**一个作者的 view A 到自己的 view B 的相似度，超过到其它作者 view B 的概率**，按作者平均。这里叫 matching rank AUC，不是 MBTI/Big5 的预测 AUC，也不是心理量表相关。

| block16 decision，行为任务 | 作者匹配 rank AUC |
|---|---:|
| 两个真人当前片段，不加历史 | .6975 |
| 两个真人当前片段，复用本人历史 | .9293 |
| 两个真人当前片段，复用匹配他人历史 | .9203 |
| 当前换成人人相同的两个中性片段，复用本人历史 | 1.0000 |
| 同样中性片段，复用匹配他人历史 | .9891 |
| 同样中性片段，无历史 | .5000 |

当前片段相同并不意味着历史不含人类信息；它意味着**这个检验不能证明跨独立材料的作者特性**。同一输入造成的高度可识别性与稳定人格是不同的证据对象。anchor 中心化后的相似性也可能保留历史特有响应，不能保证纯作者因素已被隔离。

## 三份互不重叠历史

将每人的 3 条 history 各自作为独立上下文，所有人回答同样的两个中性 current。none 是完全相同输入的负控制。没有共享历史原文，因此不同 history views 的对应不再来自重复喂入同一段话。

以下均为行为任务、相同 anchor 下 3 个 history pair × 2 个 anchor 的描述性平均。范围是这些比较之间的范围，**不是置信区间**。24 人、两次以上层扫描和 donor 依赖的探索结果，不宣称已确认显著优于某 baseline。

| 读点 | rank AUC 平均 | 比较范围 |
|---|---:|---:|
| 初始 embedding，history token mean | .6063 | .5870–.6196 |
| block05，history token mean | .6866 | .6775–.6993 |
| block10，history token mean | .7041 | .6848–.7337 |
| block16，history token mean | .6806 | .6685–.6957 |
| final normalization，history token mean | .6697 | .6540–.6884 |
| block16，decision suffix | .6446 | .5978–.7101 |
| final normalization，decision suffix | .5553 | .4656–.6630 |

换成两个不同 anchor 时 block16 decision=.6332、final decision=.5516。排除唯一包含 MBTI 类型词线索的来源作者，剩余 23 人：block10 history mean=.7022、block16 decision=.6426、final decision=.5623，方向近似保留。这是来源排除敏感性，尚不是同一文本逐 token masking 的因果消融。

这提示两个**候选**机制：中层上下文化可增加某些跨评论作者对应；最终回答 suffix 会突出当前问答需要的信息，未必保留最多的作者几何。后者不能从 history-mean 与 suffix 的不等直接推出，必须在同读点跨层并列、同预算 BGE/GRAIN 对照、独立作者上复测。本表刻意同时报告同池化跨层与同 suffix 跨层，避免把换读点伪称深层机制。

仍可能的来源包括语域、词汇偏好、topic/subreddit、长度、长期经验和其它个体差异。**没有外部链接就不把它们命名为人格方向。**

## 输出问题单独审计

主 pilot 对行为证据与一般倾向的默认支持率均为 0。相比 none，本人历史对行为问题平均 margin 改变 +.6198，对一般倾向 +2.0391；匹配他人历史也改变 +.3828/+1.9297。因此更多“倾向支持”不是本人特异证据，不能仅靠该均值宣称模型了解了这个作者。

用 6 个已知合成正/负材料，另跑两任务、两 system 和两答案编码，共 48 条件：

- context system 的原编码 5/6 正确，两任务都把同事的社交行为错归作者。
- 强调主体、实际行为与愿望区分的 fact system，在这 6 条材料上两任务都是 6/6。
- 明确的两条正例都能输出 Yes，反驳“数值读取只会产生 No”的仪器猜测；但不能证明真实语料确实没有该证据。
- 在 system 层明确反转 Yes/No 编码后，仅 0–1/6 正确；不是用户/系统冲突，但仍显示这套编码反转操作不可靠。不能把不服从反转误解释为稳定语义轴。

所以后续先做主体归属、语义否定、自然肯定/否定问句和中性答案代码的对照，不把 code-switching 本身的能力混入人格判断。不得依据这些小样本去校准出貌似合理的真人分布。

## 给理论增加的明确接口

对某一固定层/读点，记模型响应为 f(C,x,q)，C0 为无历史条件、x0 为固定中性 anchor。可精确写为：

\[
f(C,x,q)=r_q+a_q(x)+b_q(C)+j_q(C,x),
\]

\[
\begin{aligned}
r_q&=f(C_0,x_0,q),\\
a_q(x)&=f(C_0,x,q)-r_q,\\
b_q(C)&=f(C,x_0,q)-r_q,\\
j_q(C,x)&=f(C,x,q)-f(C,x_0,q)-f(C_0,x,q)+r_q.
\end{aligned}
\]

这是**已有锚点分解思想的直接代数实例**，不是新造的正交因子分析，也不使平方范数成为可加的方差贡献。分量依赖 anchor 和观察器，不是本体性的“真实人格/真实噪声”。代码已测试加性例、双线性交互例及精确重建。

该接口的价值在于：保留所有量，分别研究历史主效应 b、当前主效应 a、交互 j。下一步可考察不同独立历史的响应算子 x↦j(C,x)，以及它们与 GRAIN 既有 group-referenced 结构的关系。**稳定输入记忆、稳定作者差异、心理构念三个层级不能跳过。**

实际测量还包含 VM01 已发现的 dtype/shape/backend 误差；上述代数恒等式不是“现实误差等于零”的证明。对于 pre-question 读点，q 尚未进入可见前缀，其任务差为零是因果结构控制，不是“行为与人格等价”的心理结论。

## 下一轮优先级

1. 在互不重叠历史上做同预算 TF-IDF/BGE/E5/GRAIN 对照；先用已保存原文和表示，不重跑整个 pilot。当前中层提升还缺这些 baseline。
2. 将历史长度、topic/subreddit、时间差的影响定位到读点；增加独立作者而不是反复用 24 人选层。
3. 改善主体归属和证据读出；以自然语义改写而不只是任意 Yes/No 反转检验稳定性。
4. 分离独立证据的累积、重复、矛盾和顺序效应，找局部上下文响应的功能作用，再做自然文本干预。
5. 固定观察器后启动允许的 PANDORA 外部连接；MEPS、Essays/X 保持原访问与效度边界。
