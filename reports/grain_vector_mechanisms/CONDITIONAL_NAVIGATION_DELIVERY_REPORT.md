## 本轮真正推进的机制

**固定数学程序可以学会部分条件响应，但条件响应与作者间位置必须分别建模、再连接。**
这不是一次更高 AUC 的搜索。我们保留旧程序的人格/状态关联，同时获得新的
条件响应程序和一个可精确描述的连接缺口。

## 新的数学拼图：响应不能确定作者位置

156个源端点包含60个锚点、96个条件端点。48条互不重叠的成对编辑形成
incidence matrix D，其 rank=48、nullity=108。
如果每个作者所有条件都加同一常数 c_u，那么 D c=0：变化完全不受影响，
但作者在群体中的排序可以完全不同。一个合成反例已经实测：变化精确相同，
作者水平相关可以恰为0。

完整训练仍含 value loss，所以108维不是“整个拟合不可识别”，而是
**响应项单独看不见的方向**。源码中的行度量为
`M = I + lambda * n/m * D.T @ D`，保留均值方向，但大量加强配对差分方向。
T/F和状态线性模型的该方向权重分别约448和385倍；这来自冻结的输入trace规则，
不是事后调参。这提供了水平/响应权衡的数学解释，不声称已唯一定位所有泛化误差。

下一步最有价值的连接因此是：既有、可外部关联的作者参照位置 + 已恢复的条件
响应，怎样成为同一个文本函数，而不是简单把两组指标平均。公式与后续卡片见
[理论交付](../../docs/GRAIN_CONDITIONAL_NAVIGATION_THEORY_V1.md)。
