## 误差分账

逐例计算：

```
native - program = (native - fixed_function) + (fixed_function - program)
MSE_total = MSE_first + MSE_second + 2 mean(error_first * error_second)
```

状态空间中的张成内外正交项，经计分方向投影后存在交叉项。以A_source的
低落状态否认响应为例，读出平方误差约为.000063，由张成外.000066、张成内
.000050和交叉项-.000054共同组成。不能把前两项简单相加，也不能根据单个
占比声称某一种误差占全部人格信息的多少。

逐作者标量增益仅作oracle附表，含评估响应参与拟合；不导出、不晋升。
其解释的是该小面板允许的回顾性拟合空间，不是已获得通用语境门控。
