## 3. 交叉讨论改变了哪些判断

这些修订避免数学名称制造虚假上限，保留已经观察到的作用关系。

| 原推论/提议 | 核对后采用的解释 |
|---|---|
| iVAE的nk+1条件可限制当前因子数量 | 这是指定生成模型下的充分识别条件；不能由6个实验条件推出至多2因子 |
| 用p/n和BBP阈值直接给文本方向分信号/噪声 | 阈值依赖iid各向同性等模型；重复视图不满足，不能推翻已有留作者响应成绩 |
| Schur引理使任何等价变换只能标量缩放 | 复不可约自同态才有该结论；重复分量可混合，实表示亦有额外情形 |
| 归因矩阵rank大于1说明查询换了聚合算法 | 共享向量和不同读出已可产生rank2；需要比较竞争学生或针对性干预 |
| 低平均敏感度保证低阶稀疏机制 | Huang定理针对Boolean最大敏感度；压缩感知另需设计条件，不批准768次子集队列 |
| persona操控成功意味着可以逆向读出真人 | 读写对偶是待测关系；Bayes反向还需人群先验与真实条件似然 |
| 状态混合差分非零就是语义组合 | 先报告表示层非加性；位置、长度、归一化也可产生它，再按结果细分 |
| 没多forward就能免费保存全attention | 后端和O(T^2)内存可能改变；不列强制字段，权重差异本身也不识别算法 |
| D3B条件项无增益等于个人响应不存在 | 只支持当前选择简单共享算子，不排除其它条件参数化 |
| 一种固定编码器学生失败等于必须用LLM | 分别定位表示信息、函数类别和样本范围，不由一次拟合裁决全部可压缩性 |
