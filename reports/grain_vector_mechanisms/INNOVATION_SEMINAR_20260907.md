## 1. 裁决与研究目标

用户的目标不是再拟合一组人格词向量，而是追踪作者文本如何在查询下成为心理
判断的证据，并检验能否用更小的数学操作解释、替代其中一段计算。人格提示到
表达与作者表达到账面判断可能共享组件，但不是预设互逆映射。

本轮最有价值的转向是：**不只问“人格在哪里”，还问“谁的哪项行为，在什么
机会条件下，被哪个问题以什么方式使用”。** GRAIN 的独立作者位置可以用于
研究这种操作在群体中的组织方式，而不只是给预测器再加一组特征。

主对象暂记为 `A[author, condition, role, query, site, intervention]`。它是明确
索引的响应数组，不是已被确认的新心理量表或全局人格轴。下一步先定位功能，
再解释功能；数学上可行、模型中存在、真人心理效度是三个独立结论。

### “显影剂”的可计算形式

在同一冻结模型的节点 `j` 写入共享、等范数的小扰动 `delta_k`，记录统一语义
方向的候选 log-likelihood 差 `s_q`：

```text
A[u,q,j,k] = [s_q(h[u,j] + epsilon*delta_k)
             - s_q(h[u,j] - epsilon*delta_k)] / (2*epsilon)
```

它近似局部方向导数。当 `E[delta delta^T]=I/d` 时，在线性情形：

```text
E_delta[A_i A_j] = gradient_i^T gradient_j / d
```

因而可以先比较“哪些文本被相似地使用”，不必先找到一个能命名的共同向量轴。
之后用有角色/机会含义的 donor 替换定位其语义作用；最后才问独立 GRAIN 邻域
能否预测新作者的作用配置。该随机投影/有限差分恒等式是标准数学，不宣称原创。
原创候选是这种操作性组合及其在作者证据推断中的发现。

这是固定模型坐标中的功能核；任意坐标变换不同时运输扰动分布时，它不保持
不变。有限方向数和非线性都会带来误差，必须报告剂量收敛与抽样不确定性。
本轮仅计算线性三维例子，尚未在神经模型上画出这种图。

## 4. 数学见证与研讨后的修正

已运行 `scripts/check_grain_innovation_witnesses.py`。主要例子：

| 构造 | 实际结果 | 支持的有限判断 |
| --- | --- | --- |
| `m=4+3q+2erq` 完整八格 | e/r 边际均 0，三阶交互 2 | 只找边际方向会漏掉角色绑定关系。 |
| 八个旋转的配对读/写方向 | 平均方向约 0，配对作用 1 | 全局轴消失不排除局部作用稳定。 |
| `y=x1*x2` | 两边际协方差 0，加性 MSE 1，乘积 MSE 0 | 单项无效不能定义为噪声。 |
| 同一行动的条件似然不同 | 平衡先验后验 .8 vs .5；改先验后 .3077 | 机会诊断性与群体先验可以分离。 |
| 线性三维全八符号扰动 | 功能核重建误差为浮点精度级 | 作用相似度不必经单一共同轴表示。 |
| 同基线、不同条件增益 | 两基线均 0，证据敏感性 1 vs 2 | 配平基线不能排除条件对干预效应的影响。 |

另有反例表明：四格不变均值不能唯一识别语义；负语境斜率可由纯注意质量
竞争造成；简单近因和静态非线性也可产生顺序差；联合 patch 减单路 patch
不能直接当作另一条路的间接效应。它们是设计工具，不是真人或 LLM 新发现。

**Claude 明确接受的修正：** 四格分解仅分离规定变换下的响应分量；输出群体
斜率不识别比较机制；顺序环只排除限定加性模型；位置与层不能混为一个对比。

**Codex 在第二轮后仍不采纳的强推断，不能当作共识：**

- P1 无关事实 `+.7006` 尚未经过完整四格，不能直接认定为对所有变换都不变的项。
- “整段 patch 减边 patch = 间接路径”不成立，存在交互时需完整 2×2 干预或另列假设。
- 固定注意质量后负斜率只排除特定正权均值模型；signed OV/多层非线性仍需区分。
- 配平端点不等于配平潜在状态；静态读出不单射时，不能由端点匹配排除静态模型。
- 群体先验/暴露差异可能改变局部增益，不只改变基线；odd 分量也不应全部叫噪声。
- 边 patch 无效、整段有效不唯一指向问句中介，也可能是冗余、错位或干预粒度问题。

这些修正不是取消探索，而是让每一种结果都有明确的后继分支。

## 6. GRAIN 群体路线与创新边界

先用独立文本 A 冻结作者位置/邻域，再在文本 B 测响应，作者等权。在留出作者
上比较 GRAIN 邻域、topic/长度/机会邻域、随机邻域对作用配置的预测；报告
基线水平、条件暴露、方向/交互三层，不用基线匹配宣称已消除全部混淆。
当前 g16 几何代理不等于完整 GRAIN；真实作者文本许可与 A/B 支持审计需先完成。

第一层是模型证据操作，第二层是作者/群体组织，第三层才是 Big5/MBTI 等心理
关联。证明小算子替代指定计算段仍依赖冻结 encoder，不等于完全不依赖 LLM。

本轮只定向核对原始摘要/论文记录，不是系统综述：
[实体属性绑定](https://arxiv.org/abs/2310.17191)、
[因果抽象](https://www.jmlr.org/papers/v26/23-0058.html)、
[提示敏感的信念表征](https://arxiv.org/abs/2406.17513)。它们提供工具和竞争
解释，不替代人格证据研究，也不能证明我们首创。值得争取的贡献是：**从
角色、机会与参照条件中发现可干预、可预测、可在独立作者上组织的证据操作。**
