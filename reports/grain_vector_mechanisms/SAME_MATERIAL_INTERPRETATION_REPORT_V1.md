# 同材料 GRAIN–查询读数接合：NEXT27–28

2026-09-10。第十四轮有限逻辑研究，整体 goal 继续 ACTIVE。

## 结论

**同材料接点已实现；共同变化比简单加权平均更值得发展。** 两套读数不仅能在
作者总分上比较，也能在同一评论上配对。开放性查询/F03 的共同变化统计 S 与
作者自评 r=-.263890，95% CI[-.395409,-.144510]，180项关联 BH p=.017458。
它提供一个可计算的“表达与查询证据如何一起变化”的对象，不给 F03 提前命名。

绝对路径信号加权 W 没有普遍增强关联。本轮不发布新预测器，也不以弱的加权
结果否定同材料接口。第二项交付是文献支持的研究解释协议，而非运行临床分析。

## 1. 材料与算法

| 项目 | 本轮实际值 |
|---|---|
| 旧源作者 | 276，Big5-only 213 / MBTI-only 63 |
| 材料 | 每作者3视图，每视图12评论；原输入9,936评论 |
| 局部可用材料 | 9,165评论，36,660词法切片，每评论4片 |
| 查询与 GRAIN 坐标 | 5个Big5+4个MBTI查询；whole:F01–F04 |
| 拟合 | 复建原5折的45个 E5/岭读数；原固定配置 C 为目标，0个问卷训练 |
| 新神经模型调用/参与者/API | 0 / 0 / 0 |
| 构造计时 | 1.103秒，缓存准备/进程启动/统计分析另计 |

同作者/视图/评论地址与原文哈希核对，四切片均值精确重放已有评论分数。
复建全部3,951个原 OOF 视图预测，最大误差6.11e-16。GRAIN聚合最大误差
3.55e-15；加权协方差恒等式最大误差5.27e-15。

每评论 psi=w_q^T h；原配置预测为截距+12评论均值。新的 g-psi 统计只使用
具有四切片的评论；没有改掉原12评论预测。局部读数是编译配置函数，不是已
测量的原生 attention 或逐 token 因果路径。

U=GRAIN均值；W=按 abs(psi-mean psi) 加权均值；D=W-U；
S=Cov(g,psi)；另有把权重循环移动一条评论的 shifted_W。所有查询、因素和
方向保留，不挑符号、不拟合人类效标。每个作者先在3视图内汇总，999次完整
作者 bootstrap；区间条件于已冻结 OOF 读数，不包括重新训练的不确定性。

## 3. 值得继续的信号在配对变化，而非简单再加权

同一 Openness/F03、同213作者的外部关联：

| 统计 | 与开放性自评 r | 95% CI | BH p（180项） |
|---|---:|---|---:|
| U，未加权均值 | .075592 | [-.052464,.206848] | .881255 |
| W，绝对离差加权 | .051654 | [-.077845,.183054] | .903316 |
| D，加权引起的偏移 | -.037353 | [-.172185,.100426] | .907971 |
| S，有符号共同变化 | -.263890 | [-.395409,-.144510] | .017458 |
| shifted_W，错位权重 | .103771 | [-.024179,.217758] | .761918 |

S 是180个预定义关联中唯一 BH p<.05 的一项。该组合的群体平均局部相关弱，
而作者间 S 与开放性有关，提示**不同作者的表达—查询配对方式可以具有意义，
即使整体平均同步不强**。S 同时含波动幅度和相关方向，尚未分离是哪部分贡献。
这些是重复使用的探索性源材料，并非新的盲验证；S 相比 U/W 的关联强度差异
也不是已检验的预测性能差异。

全部36组的 W-U 有符号相关差平均-.003959，20正16负，无正差逐项区间排除0。
W-shifted_W 平均-.015156，14正22负，仅1个正差逐项区间排除0。
这些是**原始有符号 r 的差**，负向关联不是自动“更差”，不将平均差当统一
预测指标。每视图可用评论约11.05–11.15，加权后有效数量约7.41–7.56。
综合保留全部表后，不支持把这种加权自动替换原 GRAIN 聚合。

## 4. 解释方向的实际交付

文献比较和数学接口见
[同材料与解释理论](../../docs/GRAIN_SAME_MATERIAL_INTERPRETATION_THEORY_V1.md)。
发现直接的防御机制编码、治疗联盟向量映射、关系叙事编码和 TA 代理研究先例。
这支持发展辅助证据解释，不意味着本轮已经完成精神分析/交流分析效度实验。

- `configs/grain/interpretation_evidence.schema.json`：原文地址、角色/事件性质、
  固定测量、候选解释、替代解释和缺失背景。
- `grain_research/vector_mechanisms/interpretation_evidence.py`：本地校验引文、
  不可回写数值及证据引用，不上传文本。
- `configs/grain/interpretation_renderer_prompt.md`：解释渲染与独立盲编码分开；
  没有临床诊断/治疗模式，本轮未调用 LLM。

词法切口与 tokenizer offset 的守恒映射已有数值测试，但本轮没有新算 token
原生归因。关系事件或实际双人交易需要前后轮，不用无关 Reddit 评论伪造对话。
