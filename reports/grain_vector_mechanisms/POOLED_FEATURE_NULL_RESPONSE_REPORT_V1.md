# NEXT59：GRAIN响应主要存在于均值池化看不见的token配置中

2026-09-11。第48轮有限机制实验完成；整体研究goal ACTIVE。
主实现`e9d21c7`在本轮计算前冻结，零新模型调用、零拟合、零问卷标签读取。

## 1. 主要发现

**当前GRAIN方向对原模型的主要作用，不是改变正文平均位置，而是改变不同
token位置上的向量分配。** 在新8作者中，这一项对原始方向响应的有符号投影
为N的0.945894、确认寻求的0.943346；均值/PCA可见项只有0.058362/0.029880。
因此，本轮给出了一个明确输入机制：先做均值、再训练更复杂的读头，会把
我们要研究的主要局部作用压成同一个输入。下一候选应先逐token读取再聚合。

这些比例是同一原模型导数的投影分账，**不是94%的人格信息或预测准确率**。
原生梯度只用于机制观察，本轮尚未得到新的独立评分程序。

## 3. 分解与结果

BODY方向D、源正交基U、token均值barD：

\[
D=D_{vis}+D_{alloc}+D_{out},\quad
(D_{vis})_t=\bar D UU^\top,\quad
(D_{alloc})_t=D_t-\bar D,\quad
(D_{out})_t=\bar D(I-UU^\top).
\]

非BODY位置均为0。三项向量正交；后两项对旧池化特征phi的导数为0。
与同一原生梯度g收缩得到tau_j，三项作用精确相加。

| 新8 / N | 0.765006 | 0.075838 | 0.730286 | 0.045414 | 0.722962 |
| 新8 / 确认寻求 | 0.420743 | 0.040086 | 0.402405 | 0.039433 | 0.409942 |

0.893104/0.949316；不是“丢失89%/95%的文本信息”的估计。

全部96个不可见合计作用均非数值零，最小绝对值0.005527，远大于本轮
1.33e-15的收缩相加误差及4.78e-6的跨缓存全链重建差异。
这是一组局部向量干预见证，不是对自然句子变更的因果量化。

## 4. 不是单一因子或单一查询造成

新8各因子的token分配投影：

| 因子 | N | 确认寻求 |
|---|---:|---:|
| F01 | 0.859524 | 0.857747 |
| F02 | 1.009718 | 1.008775 |
| F03 | 0.663428 | 0.983968 |
| F04 | 1.013513 | 0.905695 |

F03/N的均值作用更大，保留其可见项投影0.222398、PCA外项0.114174。
不能因合并表中token分配占主导就宣布均值无用。
新8两query的差异响应RMS为0.468223，token分配差异为0.460215；不可见
合计差异的平方和比为0.900511。即查询间的区别也主要留在这组池化盲区中。

方向本身约98.91%–99.43%的向量能量属于token分配项，这部分与GRAIN方向
构造有关。真正新增的证据是该部分与原生g有显著数值作用；仅有大向量范数
并不能推出模型会读取它。统一梯度的合成对照即得到零分配响应。

## 5. 理论与开发结论

若L=f(phi(X))，则Dphi[D_null]=0必然推出DL[D_null]=0。此处原生L不是0，
所以即便非线性f，也无法在同一phi上准确恢复这些方向作用。需要改变输入，
而不是只改回归算法。完整函数的有限点分数仍可能相关，二者没有矛盾。

这与旧S6的均值保留干预、NEXT31的局部读法一致，**不把旧结果重新包装成
首次发现**。新增量是：同四个GRAIN方向、两查询、12位作者，追到NEXT57
实际失败的特征契约，并区分token分配与均值PCA盲区。NEXT58的源补偿机制
也保留；源数据不足与输入丢失可以同时存在。

token分配不是词序效应的同义词：非线性内容读取即使对向量集合置换不变，
也可能对零均值变动敏感。当前H16还包含前缀上下文。下一函数应保留声明的
位置/上下文地址，但不能仅凭本实验说某个词或某段临床叙事已获心理解释。
