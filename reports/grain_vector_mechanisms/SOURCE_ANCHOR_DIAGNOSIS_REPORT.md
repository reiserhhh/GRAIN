## 核心发现

**条件基线和函数运输两部分都有真实作者关联，而且不同查询的主要缺口不同。**
不能把条件基线简单当噪声扣掉，也不能把所有查询都缩成一张同精度的全局矩阵。

实际干预：固定两参照的P/Q均值，保留每人E和完整布局，计算`b_u=F(E_u,Pbar,Qbar)`。
于是已有PQ分数的余项精确分成：

```
native-PQ = [b_u-b_ref] + [native-b_u-(PQ-b_ref)]
          = baseline_shift + transport_remainder.
```

三视图先等权汇总，再以作者为单位与已暴露源标签做描述性连接。

|---|---:|---:|---:|---:|---:|

在这个固定小样本中，N余项协方差.002411，基线项约64.5%；TF余项.013112，

两组结果共同指向：旧配置通路没有失效，它在新公式中表现为遗漏的条件化作用。

## 对理论的升级

原固定读出`b_ref + J_ref*d`已经给出跨作者的全值正例，不能因为余项重要就
抛弃它。更完整的构造应写成：

```
s_q(E,x) = b_q(E) + J_ref,q*(x-xbar_q) + c_q(E,x),
```

其中b是实际锚定得到的条件函数，c是剩余函数运输/非线性，不是任意命名的
噪声。它们的数学定义已经清楚；需要分别构造可复用的估计器。今后不允许
测到某项就把它默认为0，也不允许把不可估项藏在“完整理论已证明”后面。

**下一唯一构造问题：由前缀向量估计b_q(E)。** 优先复用本轮144份完整状态，
用固定锚定查询对证据K/V的加权矩构造条件特征；不重取原文，不重新训练LLM。
N是主目标，TF保留作为不同余项结构的对照。目标是实际b(E)，不是人格标签；
先固定作者划分与估计器，再在留出作者上看完整分数和已有源协方差。
