# NEXT63：同一正文的作用，确实随末位读取状态而改变

2026-09-11，第52轮完成，整体goal ACTIVE。主实现`da154ce`在原生实验前冻结。
**正文与GRAIN方向完全不动，只改变末位H16状态，就改变了正文如何影响
特质查询判断。** 这直接定位到上一轮加性读取器无法表示的一条输入交互。

“超过重放误差”是计算分辨率核验，不是32次独立心理显著性检验。

不是把作者实际说的一句话换掉，也不是宣称现实语义变化只有5%。

## 为什么是有效的新机制证据

NEXT60/62的整个加性函数族都满足：改变last可以改变总分，却不能改变
BODY梯度。因此增加同类局部核、提高多项式阶数、改alpha，都无法让它
复现本轮观察到的同正文不同读法。

需要的下一函数不只是`文本分数 + 查询分数`，而是让全局状态进入局部
函数：`Lhat = b + beta*c + mean_t f_q(z_t, position_t, c)`。
这与用户说的“同一段话的两个侧面”相接：GRAIN固定表达变化方向，
查询相关状态决定这一方向在当前推论中被怎样读取。

这里定位的是**混合导数沿固定替换路径的积分效应**。不是已经逐元素
识别了整个混合Hessian，也不说明last是唯一或最大的上下文入口。此前
局部读头、上游选择/运输、token分配机制均保留；新结果补上输入交互。

## 不同投影为什么不能合并

把梯度变化分成旧源rank8与其正交补两部分（每位源作者用排除自身的
NEXT62源基底），rank8仅含约21.20%/25.20%的变化能量。然而在GRAIN
动作的有符号分账里，rank8/正交补贡献为：

| 查询 | rank8有符号投影 | 正交补有符号投影 |
|---|---:|---:|
| 神经质 | 1.386524 | -.386524 |
| 确认寻求 | .898114 | .101886 |

这些是投影系数，和为1，允许负数与大于1，不是心理信息百分比。
神经质两部分发生抵消。不能把正交补叫噪声、删掉后把增大的响应当准确；
也不能因整体能量覆盖低，就否定旧rank8在GRAIN方向上保留的作用。
确认F02主要变化来自正交补（投影.835519），全部因子表保留。

总评分的平均改变仅+.016316/+.025907，却含个体正负改变，范围分别
[-.206776,.332749]/[-.302239,.221025]。低平均分变化不会抵消真实的
读取机制变化；本轮不把它命名为作者的人格变化。
