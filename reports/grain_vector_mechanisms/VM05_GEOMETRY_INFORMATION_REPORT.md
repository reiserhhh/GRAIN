## 1. 修正了一个比较对象问题

VM05最初的grain_intermediate只包含旧词法SVD24维的作者mean/std，共48列。
它不是GRAIN当前4W体系的全部内容，也不是正式地标分数。本轮按现有实现分开：

| 通道 | 实际操作 | 解释边界 |
| --- | --- | --- |
| intermediate | 冻结词法24维的mean/std | 中间向量，不是心理因子分 |
| canonical distances | 冻结白化后，到16个规范定序地标的距离 | 保留跨作者一致的地标身份 |
| sorted distances | 每位作者分别排序16距离 | 既有V7 profile；列不再代表同一地标 |
| canonical shape | 规范距离减行均值、除行标准差 | 既有V8形状通道，去除整体距离与尺度 |

不重新拟合旧参照/白化/地标。所有统计头遵循同作者official五折，inner
三折选Ridge或Logistic正则。PCA与无PCA完整列出，不能选外层最高项当主成绩。

## 4. 地标压缩的精确边界

令q为48维冻结白化向量，l_j为地标，d_j=||q-l_j||，A_j=l_j-l_0：

\[
 A_j^\top(q-l_0)=\frac{d_0^2-d_j^2+\|A_j\|^2}{2}.
\]

当前16地标的仿射秩实际为15。全部带身份距离能确定15维投影，以及剩余
33维垂直分量的范数，但不能一般性确定其方向。非零垂直范数下有32个
角向自由度未识别。这是环境空间的上界，不是测出真人有32个人格因子。

全7,266作者的数值核验：投影重构误差<=2.14e-14，距离平方重构误差
<=4.55e-13。构造相距2的两个合成点，其带身份地标距离最大差1.78e-15。
它证明此几何映射一般非单射；不能独自证明丢失的方向具有心理效度。

更重要的区别：不变表示适合比较某种几何形状，不等于它保存了所有可用于
心理判断的信息。排序/去尺度并非普遍去噪定理。

## 5. 解码后，是信息不在还是读出不合适？

仅使用地标和距离，可恢复parallel15及垂直范数平方，未读取作者原坐标或
标签参与解码；最后才与原坐标投影核验。另保存原向量的perpendicular33。
五通道、五任务、PCA/无PCA共50条件，仍仅用相同raw-ready来源。

| TF通道 | PCA AUC | 无PCA AUC |
| --- | ---: | ---: |
| 完整白化48 | .5859 | .6281 |
| 解码parallel15 | .5609 | .5609 |
| parallel + 垂直范数平方16 | .5605 | .5605 |
| perpendicular33 | .5945 | .6247 |
| 距离平方16 | .5636 | .5636 |

无PCA时，parallel比完整白化低.06724，CI[-.09500,-.03649]；垂直33维比
完整白化低.00338，CI[-.01864,.01417]。不能把区间跨零写成严格等价，
但可把“距离表示不保留的方向仍含TF来源关联”列为后续候选。
该子空间有33维而parallel只有15维；需要同维随机子空间/来源控制，而不是
仅凭强弱顺序把它宣布为人格专属子空间。

parallel+范数平方与带身份的距离平方可仿射互换；不同L2惩罚和坐标缩放仍会
造成读出成绩差异。当前直接解码没有救回TF完整向量成绩，不能把全部损失
解释成简单平方变换未做。与此同时，白化本身可逆，但PCA/正则不对任意
可逆变换不变，所以白化后的分数下降也不能叫信息消失。

这轮得到的是三层区分：**几何映射保留什么、统计读出能利用什么、最后与
哪个外部心理/行为变量相关。**三者不能用一个r/AUC相互替代。
