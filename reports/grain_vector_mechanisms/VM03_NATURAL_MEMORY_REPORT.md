# VM03：自然记忆、事实归属与判断读出

日期：2026-09-06。状态：本轮 bounded 开发实验完成，整体 VM01–07 未完成。
协议：[自然记忆审计](../../docs/GRAIN_VM03_MEMORY_AUDIT_PROTOCOL.md)。

## 结论

本轮没有证明更好的真人格预测，而是把一段具体失败链拆开：

1. 自然历史改变当前文本的上下文化向量；这种变化不等于正确的人格判断。
2. 摘要的格式、引用与语义是三道不同检查。准确引用也能伴随主体归属错误。
3. 已知事实的答案排序优于实际 Yes/No 决策表现。改变问法可以修复某类错误，
   同时引入别类错误；不能只按总体分数宣布 prompt 已修好。
4. 所以下一机制对象应是**证据表示到任务读出的转换**，而不是继续比较哪个
   作者匹配 AUC 高，或给新 hidden-state 方向直接起人格名称。

## 实际材料与执行

6 位 ID-hash 固定的 discovery/comparison 作者，每人 12 条过去评论、
2 条后来评论；未按旧效果或量表挑人。6 人来自上一轮96 comparison，
不是另一个独立确认集。12 current cases 不能当12个独立人。

| 部分 | 条件/调用 | 时间 | 性质 |
|---|---:|---:|---|
| 事实摘要 | 6 次 greedy generation | 106.5 s | 同一小模型；不是独立评审器 |
| 自然记忆 | 312 prompts | 与下一行合计302.5 s | 13 arms ×12 cases ×2 tasks，无 truth |
| 人工事件控制 | 384 prompts | 以上合计697 forward，含1重播 | 单事件族×8变体×12背景×2位置×2极性 |
| 陈述式读出复测 | 384 prompts /385 forward | 167.0 s | 观察首轮错误后追加的诊断，不是确认 |

两次有效采集共1,080 prompts、1,082 forward；419,952 actual input tokens，
固定执行长度共3,323,904 processed tokens。均 Windows隔离目录、Qwen2.5-1.5B、
固定revision、BF16 eager、padding3072，无权重训练/付费API。
实际最大prompt为1346/360 tokens，无截断；GPU peak约4.31GB。
回放、因果前缀、当前初始embedding三项最大误差均为0。

自然Yes/No两候选总概率质量均值 .999815，最小 .979909；人工控制均值 .999965。
因此这不是自由生成 JSON parser 把答案丢掉后的假正确率。
但两候选内归一化值仍不是校准的人格概率。

## 1. 摘要保真

| 检查 | 结果 |
|---|---:|
| 严格 JSON/schema 可用 | 1/6 |
| 只补一个结尾对象括号后可用 | 2/6 |
| 这2份中的事实句 | 12 |
| 满足正确source、精确引文和最短span | 7/12 |
| 一位源文审核者接受的语义 | 4/7 引用有效句 |

5份原始输出格式失败；有限修复后仍有3份超出6条上限、
1份不能被该修复解析。不截取前6条伪装遵从；这些作者摘要arms使用明确的
空摘要fallback，全部作者结果与2作者可用子集分列。
缺失摘要不表示作者没有事实，也不能用于声称摘要效果好坏。

错误类型包括：把个人反应泛化为一般事实、添加源文未出现的项目身份、
把分享已知事实写成新近发现、把“作者鼓励他人”写成“他人支持作者”。
报告不公开原文、作者ID、敏感自述或逐作者心理判断。

这支持把 source citation 与 proposition entailment 分开；不建立此模型以外
的摘要失败率。现象与摘要保真研究一致，不能称首次发现。
见 [Maynez et al.](https://aclanthology.org/2020.acl-main.173/)、
[FRANK](https://aclanthology.org/2021.naacl-main.383/)。

## 2. 自然历史：表示变化和判断变化并不相同

“具体主动社交行为证据”任务在13个arms全部回答 No；完整历史的
“一般倾向证据”也为0/12 Yes。没有独立自然truth，不能据此算准确率、
断言这些作者缺乏社交倾向，或证明模型完全没读到信息。

| 操作，相对 raw_full | behavior margin Δ | disposition margin Δ | 后者翻转 |
|---|---:|---:|---:|
| 历史逆序，同原文同token数 | +.7396 [.1768,1.2083] | +.8229 [.2188,1.3958] | 2/12 |
| 条件匹配他人历史 | −1.0000 [−2.6354,.3125] | −.5000 [−1.3542,.5208] | 0/12 |
| 长度匹配他人历史 | +.0625 [−1.0734,1.1146] | +.4271 [−1.0000,1.8958] | 2/12 |
| E5检索3条 | −.3750 [−1.3125,.4688] | −1.1563 [−2.8750,.5313] | 0/12 |
| 随机3条 | −.7083 [−2.3229,.7083] | −1.8750 [−4.1359,.1042] | 1/12 |

区间为6作者cluster bootstrap，未作多重比较修正，全部探索性。
检索与随机同评论条数，不是精确等token；与full相比也改变了信息量。
“更接近Yes”不是“更正确”，这些差值不可作为prompt leaderboard。

block10当前正文mean相对raw的位移范数/原范数：
none=.2990、条件匹配他人=.1245、历史逆序=.0814；
block16判断位置对应 .1787、.0786、.0545（behavior任务）。
初始token embedding保持完全一致，说明不是换了当前字词；但仍包含上下文
内容和绝对位置效应，不能把位移长度称为人格强度。

同一历史干预在每人两个当前片段上的位移cosine：
block10的none=.8537、他人条件=.5053、逆序=.5366。
两当前共用同一历史和donor，所以不是独立重测信度。

两个互补半历史的有限差分：
disposition margin interaction=−1.8958 [−2.7813,−.8935]，
条件概率尺度=−.0878 [−.2962,.1186]；
behavior两尺度区间均跨0。非加性依赖尺度和输入布局，不作独立协同机制认定。

## 3. 更新事件：聚合分数隐藏了方向性错误

人工Z7有已知最终主体/行动真值，不对应作者真实经历。整体正确率
.8411 [.8099,.8698]、AUC=.9428；正负问句平衡后true prevalence=.5。

| 已知事件变体 | 原问法正确率 | 陈述式正确率 |
|---|---:|---:|
| 作者确实主动组织 | .9792 | .5625 |
| 另一个人组织 | .7708 | 1.0000 |
| 只是设想，并未实施 | .9375 | 1.0000 |
| 明确否认作者行动 | 1.0000 | 1.0000 |
| 肯定后更正为否定 | .8333 | 1.0000 |
| 否定后更正为肯定 | .5000 | .5000 |
| 否定“没有行动” | .7083 | .9375 |
| 引述别人说“我组织了” | 1.0000 | 1.0000 |

陈述式整体正确率 .8750 [.8672,.8828]、AUC=.9579；
配对正确率差 +.03385 [−.00260,.07292]，没有建立总体显著提升。
“否定后更正为肯定”在两种问法都对正/负陈述一律回答Yes，仍只有50%正确。
新问法在若干难例上改善，却破坏简单肯定例，不能挑局部高分宣布修复。

只改问句后，block10 current mean、block10/16 evidence end 对应向量差
均严格为0。效应发生在后续任务读出，**这不额外证明之前的向量已经正确
理解了事实**；它只是定位了问题变化在计算图中的边界。

原问法事件放在背景之后/之前正确率 .8802/.8021；
陈述式变为 .8594/.8906。位置方向随问法改变，不能概括为永久的近因优势。
这与需要单独检查位置利用的研究思路相符，但并非长上下文“中间遗失”
实验的复现：[Liu et al., 2024](https://aclanthology.org/2024.tacl-1.9/)。

## 4. 对理论的实际增补

继续保留两条链：

    作者与条件 -> 真实表达 -> GRAIN参照下的个体结构
    历史材料 -> 选择/压缩 -> 命题归属 -> 任务读出 -> 模型判断

本轮把第二条链里的三类损失分开记录：证据缺失、命题失真、读出/极性失稳。
它们都可能削弱外部量表连接，却不是同一种“向量噪声”，不应通过统一残差
扣除处理。现有choice、动态、残差与作者结构结果不因此被否定。

自然任务还暴露了一个待测的操作定义问题：**文本描述的行动**与**文本正在
实施的行动**不同。鼓励、求助、反驳本身可能是交互行为；当前“具体事件”
问法未单独区分它们。这是下一轮候选解释，不是本轮已经验证的新构念。
