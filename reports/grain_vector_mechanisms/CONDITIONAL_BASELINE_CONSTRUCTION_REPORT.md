# 条件基线的可构造性：第一轮结果

2026-09-08。M12完成；48作者×3视图，四折作者外，144次缓存QKV投影，
6.30秒；新增prefix/suffix/gradient调用均0。全部预测先冻结，再连接已暴露Y。

## 发现

固定查询注意力确实能估计TF条件基线；神经质基线的作者间变化仍只读出很少。
不能把移除截距偏差后的大幅MSE下降，等同于找回了作者差异。

| 查询 | 基线表示 | b的留出r | MSE/训练折均值 |
|---|---|---:|---:|
| TF | E均值 | .382 | .846 |
| TF | native P均值+Q | .778 | .455 |
| TF | 固定查询注意力均值（主） | .583 | .738 |
| TF | 加二阶矩/质量/熵 | .618 | .741 |
| N | E均值 | -.224 | 1.079 |
| N | native P均值+Q | -.352 | 1.219 |
| N | 固定查询注意力均值（主） | .130 | .964 |
| N | 加二阶矩/质量/熵 | .164 | .949 |

N相对于原两参照常数的MSE比例约.066，但相对训练折b均值仅.964。
所以主要修正的是总体截距，而非自动获得新的个体关联。TF的原生P/Q也能
携带关于b的信息；锚定分账不是统计独立分解，条件之间的信息可重叠。

## 接回完整分数

主attention基线 + 原冻结PQ变化项：TF source r从.313到.342；N从-.022到-.019。
这是同一固定24人/查询的诊断子集；不是277人主表的新成绩。TF新增基线的
Y协方差.001260，但仍余.011851；N新增仅.000014，仍余.002397。
原生模型同子集r=.461/.308，不能以高teacher fidelity宣称全源关联已重建。

## 下一机制：聚合次序

当前拟合的是三视图均值之间的函数。下一包只改变一个因素：先在每份材料上
学习b(E)，再平均作者分数，保持相同四折、特征、alpha=1，无rank/grid、无Y调参。
目标是判别“单材料函数弱”与“先聚合改变了可识别关系”，不是再搜一个高r。
