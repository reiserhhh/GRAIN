## 1. N：两评论联合作用的显式数学读法

复用NEXT16的固定32方向、三视图训练几何和原四个作者fold。每折18人训练、
6人评估；view0的相邻(0,1)/远隔(0,11)对各一组，共48对。以评论token份额
加权其傅里叶奇/偶差向量a、b，构造：

    Psi(a,b) = (a tensor b + b tensor a)/2
    k((a,b),(c,d)) = ((a.c)(b.d)+(a.d)(b.c))/2.

核是显式对称张量的Gram核，半正定；交换连同位置元数据的两个参数不变，
任一评论位移为零则输出为零。目标为已测中心化logit混合差，不是问卷Y。
训练折均值对角归一化、mean-loss Ridge惩罚.01、无截距，固定bag/position
两臂，共八个小拟合。三视图只确定训练几何，不把另外视图作为独立作者。

|---|---:|---:|---:|
| 零交互 | 1.000 | 不定义 | 1.000 |
| 训练折内同评论对类型均值 | .726 | .352 | .605 |

    G_u = .5 * sum_{m in {M0,Mu}} integral_0^1

## 3. 新的逻辑发现：矩阵相似不等于个体作用被保留

四位参照作者、两种正文条件的八个矩阵做无拟合欧氏能量分账：

| 矩阵部分 | Frobenius能量份额 |
|---|---:|
| 共同平均矩阵 | 91.175% |
| 作者间平均矩阵差异 | 8.640% |
| 同作者两正文条件差异 | .184% |

三项精确相加，误差<8.1e-19。这里不是人类人格方差；不同作者的布局、R路径
等仍共同变化，不能将8.64%全部命名为作者固有机制，也不能反推正文普遍无效。

它给出一个此前未闭合推论的反例方向：

    G_u = G_ref + DeltaG_u
    Phi_R(u) = <G_ref,d_u> + <DeltaG_u,d_u> + numerical_error.

小的DeltaG是否重要取决于它与真实d_u的对齐，而非只看||DeltaG||。
例如G_ref=(1,0)、DeltaG=(0,epsilon)、d=(0,1/epsilon)，矩阵差可以任意小，
但遗漏作用恒等于1。91%的共同矩阵能量不意味着91%的个体作用恢复。
这一点把“共同规则”与GRAIN关注的“偏离群体的位置”接起来：共同读法值得
保留，个体特异性可能恰在实际行程投影到小差异算子的部分。

另一个精确分账将共享对照m与个体化预测p分开：

    ||y-m||^2 - ||y-p||^2
      = 2<y-m,p-m> - ||p-m||^2.

新增个体变化只有与真实余项对齐才有收益。N远隔臂的第一项已经为负，因而
不是简单幅度不足。此诊断在首轮结果后提出，0新拟合/0神经调用，单独保存。

## 4. 文献如何支撑，哪里是本项目的工作

- [Deep Sets, Zaheer等2017](https://papers.nips.cc/paper/2017/file/f22e4747da1aa27e363d86d40ff442fe-Paper.pdf)：局部Phi、联合rho、最终S分层；不保证固定32维方向足够。
- [Distribution Regression, Szabo等2016](https://www.jmlr.org/papers/v17/14-510.html)：从分布嵌入学习结果的先例；文本token非iid，不直接借用其收敛界。
- [Integrated Gradients, Sundararajan等2017](https://proceedings.mlr.press/v70/sundararajan17a.html)：路径积分的基线相对作用分账；积分恒等式本身不保证跨作者矩阵可搬运。

对称核、微积分与误差恒等式均不是新数学定理。当前组合的研究贡献，是在
相同真实作者材料与冻结模型上，将实际内部效应、共享读法、个体调制、量表
关联和输入依赖逐层连接。数学完整性与实证可迁用性由此分别得到可计算对象。
