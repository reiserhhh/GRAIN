## 3. 为什么还有推进价值

评价时把当前原生梯度投影到固定源rank8子空间，完整作用新8r=.851/.808，
SSE/zero=.376/.420。固定源方向仍保留可用的作用，瓶颈不等于“这8维完全
没有信息”。该投影使用当前原生梯度，仅作容量诊断，不是候选预测或保证
方向误差的最优上界。其查询差值误差也仍大于零基线。

源4内，候选评分标准化MSE=.086/.160，但梯度密度MSE=1.074/1.087；
20模型的该密度指标均超过1。梯度连源内都拟合不足，故优先解剖固定目标
能否在函数导数字典内表达、评分与惩罚是否挤压它，而不是扩大作者量或调核。

与NEXT57的r=.300/.336(value-only)、-.782/-.473(joint)相比，当前完整评分
有发展，但描述基底、梯度教学等都变了。只有本轮两顺序才是匹配因果对照。
完整评分的相近表现也说明：本轮收益不能全部归功于“聚合前非线性”。

## 4. 公式与数据边界

    Lhat = b + a·mean(z) + beta·z_last + mean_t sum_m c_m k([z_t,p_t], l_m)
    Khat_t = T*dLhat/dz_t
    ghat_t = (Khat_t/s_z) @ U.T / T
    tauhat_f = sum_t <ghat_t,D_ft>.

源目标密度为 `T*(g@U)*s_z`。不同作者按总权重相等，token行不是新增独立
被试。学习使用旧源L/梯度，应用进程只能读纯H16/GRAIN/布局和源模型；
所有当前目标拒读探针通过，评价在预测冻结后另进程执行。
H16仍需原神经前缀；本轮移除了当前后缀读取，不声称完全不用神经网络。
