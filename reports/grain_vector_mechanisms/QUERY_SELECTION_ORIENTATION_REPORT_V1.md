## Reusable numerical object

The code now exports the conditional vector operator

    C_(a,h,m,f) = Cov_(attention(Q_a))(v_m, rotated_delta_K_f) / sqrt(hdim).
    R_abmf = sum_head C_(a,h,m,f) dot rotated_Q_b,h.

It is linear in the direction anchor *after* selection has been fixed, but the
operator itself changes nonlinearly with selection Q. This is an exact local
interface, not a fitted personality head or a claim to have removed the encoder.

NEXT74 is actual source-only selector development: learn a differentiable logit
potential from H16, with primal and GRAIN-direction teaching, then form softmax
and the derivative from the same learned function. This targets the dependency
identified here rather than another generic Gaussian or a larger attribution grid.
Native values are retained explicitly to isolate key-selection replacement;
the resulting component must not be advertised as a standalone full predictor.
