# GRAIN 向量机制研讨会：从相关线索到可压缩的推论运算

2026-09-07。状态：三轮研讨完成，有限数学反例已运行；没有新的神经或真人实验。

## 1. 研讨结论

用户的核心想法有明确研究空间：**不要求现在可临床使用，而是解释已有文本与心理
指标关联，寻找不必语言化、但能保留相关推论能力的数学运算。**

双方共同认为，下一突破不应只定义为更高的一个 Pearson r，而应是找到一个较小的
关系/更新算子，解释为什么相同词汇、不同归属，或相同证据、不同历史，会改变判断。
它既要接触模型实际使用的信息，也要与作者的外部指标保持可检验的连接。

研讨没有证明这样的通用算子已经存在。当前最接近的局部实例是 VM03 的归属关系：
加性表示丢失组合关系，联合编码或显式乘积核恢复关系；这个实例不等于真人人格预测。

## 3. 用户命题被拆成三个不同问题

| 问题 | 当前判断 |
|---|---|
| LLM 判断是否由数值运算实现？ | 是实现事实，本身不是新发现。 |
| 能否用较小的数学对象保留指定推论过程？ | 是主要新问题。已有窄机制实例，真实作者/多任务尚未建立充分性。 |
| 能否同时保留与心理量表或行为的关系？ | 必须另外验证，不能用模仿 LLM 的相似度代替。 |

“不语言化”也有三个层次：直接读 LLM 输出而不生成解释、用紧凑算子替代部分 LLM
计算、最终用该算子研究外部指标。冻结 embedding 仍携带预训练知识，并不等于没有
语言知识。现有 BGE/E5 源头关联已证明简单数值通道可以关联外部指标；新增目标是
解释关系与计算如何形成，而不是重复这一存在性结论。

## 5. 三条机制路线，以及真正新增的一点

### A. 归属与关系绑定

把证据中主体槽与事件槽的表示记为 \(h_s,h_a\)，候选交互可写为

\[
B(h_s,h_a)=h_s^T U V^T h_a.
\]

它允许“谁做了什么”改变证据，而不是只累计同一组词。低秩双线性或乘积核都是
标准工具；要验证的是其在指定模型、材料与干预中的解释力。秩不能凭空固定为“人格
需要的维数”，主体识别也不能用作者 ID 特征代替。

Claude 将这条线排第一：已有真实模型上的受控定性证据，且先确认“数的是谁的证据”
再研究“数了多少”，与人格解释最直接相接。Codex 同意它应是后续实证的先行入口。

### B. 证据与非证据通道的权重竞争

Claude 在第二轮补出非证据槽，是本次新增的关键候选。一个简化的有效模型是

\[
m(k)=\frac{a_0m_0+kA\bar m}{a_0+kA}
     =(1-g(k))m_0+g(k)\bar m,\qquad
g(k)=\frac{kA}{a_0+kA}.
\]

\(m_0\) 是非证据部分的读出，\(\bar m\) 是证据读出，\(a_0,A\) 为相应质量参数。
这不是由完整 Transformer 严格导出的输出定律：它假设某个受控范围内内容表示、
评分与非证据贡献近似固定。真实新增 token 还可能改变位置、键值和后续计算。

它提出一种可研究的解释：**多一段记忆可能只是把输出从提示/默认反应拉向证据，
并非增加了一次独立观察。** 这既可能有用，也可能重复强化不恰当判断。这里的
“先验”只是模型非证据通道的简称，不等于已识别 Bayesian 先验或人的心理先验。

取 \(a_0=A=1,m_0=0,\bar m=1\)，复制数 \(k=1,2,4,8\)，得到
\(.5,.667,.8,.889\)。无非证据槽的纯平均是 \(a_0=0\) 的嵌套特例，仍精确不变。

**如何判别：**同源复制与真正独立的同向证据要分开；比较规定数量范围内的整条
响应，并在未来观察归一化前状态与配对干预。不能只看“饱和”或“交互为负”，也不能
用有限数量曲线声称检验了无界增长。近乎平坦可能是已经饱和或统计精度不足。

Codex 认为这条线是本次理论的新收获；Claude 认为其优先级低于绑定，因为若不知道
证据归属，权重竞争还不是人格推论。这是保留的研究排序差异，不伪装成全面一致。

### C. 功能读出与状态更新

在固定答案约定 \(e\) 下，末层概率与分数是

\[
p_e=\operatorname{softmax}(W_{A_e}h_e(x,q_e)+b_{A_e}),\qquad s_e=v_e^Tp_e.
\]

局部响应为 \(L_e=v_e^T(\operatorname{diag}(p_e)-p_ep_e^T)W_{A_e}\)。换问题或
编码时，状态、候选词表与解码向量可能同时变化；不能仅改变 \(v_e\) 就解释实测。
中层还需要后续运算 Jacobian。KL 的精确余项对应 RC5 的目标 log-probability；
期望分数应使用自己的路径积分，不能直接套同一余项。KL 与 RKHS/MMD 不是同一距离。

进一步，以 \(h\) 表示规定协议下足够完整的模型计算状态，紧凑机制需要同时检验：

\[
\phi(F(h,e))\approx\widetilde F(\phi(h),e),\qquad
G(h,q)\approx\widetilde G(\phi(h),q).
\]

即不只拟合终点，还能支持规定证据的更新和新查询。只能在有限支持上检验，坐标允许
可逆重参数化。这里是模型计算过程，不是把模型层深或 token 步数当成人的心理时间。

## 6. 数学质询实际修正了什么

| 原提议/误区 | 数值反例或修正 | 最终处理 |
|---|---|---|
| 加入有用线索后残差相关应下降 | Y=3X+U、S=X+U；去掉 X 后 r 从 .894427 升至 1，但固定分母剩余贡献从 .894427 降至 .223607 | Claude 撤回 ΔC 判据；保留四项与共同分母，不把它们当因果份额 |
| 重复不变可区分平均与 Bayesian 累加 | 已知同源重复时，正确条件 LR 也为零增量 | 比较来源依赖模型，而不是把所有 Bayesian 模型等同独立累加 |
| 负的二阶交互支持归一化 | 重叠同源证据下，纯平均与来源条件 LR 都有交互 -.8 | 一个符号不能定位内部实现 |
| 一个当前读出就代表完整状态 | 交换矩阵 A、C=(1,0)，两状态当前同为 1，下步为 ±1；一步秩 1，两步秩 2 | 当前拟合完全正确仍可丢失未来必需信息；只是一条线性系统反例 |
| 饱和就支持 attention 归一化 | 加性状态 (1,k) 再做 L2 归一化也得到饱和的 k/sqrt(1+k²) | 需要多条件与干预；不能只按曲线命名机制 |
| BF16 有通用 .125 噪声门槛 | 浮点间距依赖数值量级与算子；不存在此通用门槛 | Claude 撤回；数值重播误差与随机方向零假设分开 |

最后一点的主持人补充：随机方向产生的是模型功能的参照分布，不是纯计算误差估计；
自身替换/重复计算可估仪器误差，两者不能混为一个“噪声阈值”。同样，响应矩阵低秩
只描述观测过的有限扰动，不能当作已验证状态更新闭合。

## 8. 文献对这场研讨的实际帮助

- Yang & Oshio（2026）大学正式摘要：738 名日本 ChatGPT 用户中存在自评与历史推论
  的正关联，同时有整体高估。支持研究“能力与线索如何形成”，不识别内部机制。
  [原论文记录](https://waseda.elsevierpure.com/en/publications/attachment-towards-generative-ai-influences-self-ai-agreement-in-/)
- Härtel（2026）已用 lens model 研究 406 个 LinkedIn 档案的 LLM 判断。因此 lens
  用于 LLM 人格线索不是本项目原创；GRAIN 的新增对象应是内部计算与可替代运算。
  [原文](https://link.springer.com/article/10.1007/s10869-025-10087-8)
- Coconut 展示连续隐藏状态不经每步语言解码而继续运算；仍依赖 LLM 和训练，不是
  人格实验。它支持研究路径的可行性，不证明我们的替代机制。
  [Hao et al., COLM 2025; arXiv v4](https://arxiv.org/abs/2412.06769)
- Conditional mean embedding 与 HSE-PSR 为向量化条件分布、预测与更新提供标准
  数学工具；下一步可借鉴，但不能把 RKHS 距离、KL 或潜在人格直接等同。
  [Song et al., 2009](https://icml.cc/2009/papers/538.pdf)，
  [Boots et al., 2013](https://arxiv.org/abs/1309.6819)
