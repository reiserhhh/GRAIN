# 固定方向库与新作者读法：NEXT37 结果

2026-09-10。第二十六轮有限研究。**可迁移的方向信息仍在，但旧局部系数
程序没有完整迁移。** 这把下一步定位到“新文本如何启用共同方向”，而不是
再次给四人小面板增加特征或调参。整体逻辑研究 goal 保持 ACTIVE。

## 1. 实际执行了什么

- 构造作者仍是旧4人。按结果出现前固定的ID哈希，在另外20人中各来源选4人，
  共8人、每人12条原评论；属于读法源外作者，不是全项目从未接触的新人。
- 同一96条评论、348个词法切片、7,156个正文token，冻结 whole:F01..F04
  计分。新作者没有参与因子、方向库、Ridge、权重或校准的拟合。
- 三查询：T/F、neuroticism、confirmation_seeking。分别用自身查询8方向、
  两个其它查询8方向、普通方差8方向。每臂等权复用旧四折程序，保留各自
  输入中心、尺度、基底与输出基底，先还原场再平均。
- 预测96个系数堆栈后才读取新原生梯度。独立预测进程只能打开声明的数值
  输入和模型；3处禁读探针通过。4方向产生96个独特原生作用，不是96个人。
- 24次前缀捕获、24次梯度前向/反向、6次固定有限差分前向，共54次前向、
  24次反向，native工作73.904秒；两次加载合计6.232秒，远低于600秒预算。
  无神经训练、无量表标签、无API、无MEPS材料、无锁箱开启。
- 计划/成员规则先在 `669b8e2` 冻结；运行及分析代码在 `dbca1ae` 提交，
  随后采集。预测冻结文件保留全部资产哈希。

## 2. 固定读法在新8人的表现

格子为 **作用相关r / SSE相对零预测**；每格8人×4方向=32个配对作用。
SSE/零越低越好，1代表全预测0。它不是人格分数预测r。

| 接收查询 | T/F输入方向 | N输入方向 | 确认输入方向 | 普通方差方向 |
|---|---:|---:|---:|---:|
| T/F | .001 / 1.061 | -.004 / 1.074 | .010 / 1.062 | -.002 / 1.029 |
| N | -.002 / 1.314 | .121 / 1.387 | .139 / 1.309 | .101 / 1.125 |
| 寻求确认 | .262 / .957 | .357 / 1.018 | .314 / 1.004 | .423 / .892 |

确认通道仍有可开发的读取关联；方差对照在本面板最好，但不据此选择新生产
模型。T/F旧专用读法的优势没有跨到这些作者，N的作用幅度误差明显。
旧4人LOO与新8人四程序集成不是完全相同评估协议，不把两者差值写成精确
的泛化损失估计。

| 自身查询方向 | r | 作者聚类bootstrap 95%区间 | 因子中心化后的作者r | 预测/真实RMS |
|---|---:|---:|---:|---:|
| T/F | .001 | [-.497, .360] | .058 | .273 |
| N | .121 | [-.129, .319] | .049 | .589 |
| 寻求确认 | .314 | [-.204, .564] | .282 | .317 |

区间按8个作者整组重采样2,000次，保留其4方向；不把token或方向当独立人。
确认的方差臂r=.423、作者中心化r=.395，但区间[-.096,.620]仍宽。
这些关联作为后续机制候选保留，不冠以统计确认。全部逐因子结果在附表。

## 3. 找到了哪一环有问题

使用已经冻结的四个源输出基底构成32维联合空间，**只作评价诊断**：把新
作者真实梯度投影进去，再计算同一GRAIN方向作用。没有拟合新基底。

| 查询 | 源方向联合空间中的oracle作用r | oracle SSE/零 | 当前自身读法SSE/零 |
|---|---:|---:|---:|
| T/F | .836 | .277 | 1.061 |
| N | .951 | .099 | 1.387 |
| 寻求确认 | .876 | .656 | 1.004 |

共同方向库仍容纳可观的响应信息；**从新正文状态预测系数**是当前读法的
主要缺口。oracle使用新作者真实梯度，不是无梯度算法的预测，也不是8维
单基底的上界。确认的oracle相关高但幅度误差大，进一步说明r与作用重建
不是一个指标。

当前结果不要求重做GRAIN，更不推翻“同材料联合接口”。它区分了三个层次：
方向能表示、当前输入能读取、读取后能解释效标。第一层保留，第二层局部
失配，第三层本轮未重测。

额外检查：新坐标越出各旧源单维极值区间的比例平均不到0.026%。因此不是
大规模的单坐标越界；这不等于联合支持集充分，更不等于条件读法不变。
完整梯度场误差与GRAIN作用误差分别保留，避免用投影后一个指标覆盖全部。

作用误差精确分为缺失方向、系数读取与有符号交叉项。确认通道三项为
.656 + 2.372 - 2.024 = 1.004，存在抵消，不能将其中一项直接当“解释比例”。

## 4. 数值验收与已知工程问题

- 同作者共同前缀采用冻结的T/F前缀、保留各查询后缀；原前缀最大浮点差
  5.245e-5，canonicalized原生评分重放最大差9.259e-7，通过原2e-6门槛。
- 固定首作者whole:F01三查询有限差分均同号；最大epsilon尺度误差
  7.912e-7，没有改变epsilon、作者或因子来取得结果。
- 联合空间梯度能量恒等式最大相对差1.49e-15。
- 数值独立重放96个系数数组逐值相同，9张分析CSV逐字节相同；没有重复
  神经调用。43项数值测试、另22项逻辑/解释接口测试通过，Ruff通过；保留
  两个既有SWIG弃用警告。不声明全仓库测试完成。
- 冻结runner的目录计数把macOS AppleDouble `._`旁文件算了进去，状态中
  prefix_units/gradient_units显示48/48。独立审计按确切实验地址核实为
  **24/24**；54实际调用/24反向计数不受影响。冻结数据不回写，后续以
  `audit/summary.json`的显式计数为准，不把元数据当新增实验。
