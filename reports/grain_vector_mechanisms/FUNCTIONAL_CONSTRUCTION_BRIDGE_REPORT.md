# GRAIN 功能构造连接：自然响应由有符号的多通路共同形成

2026-09-08。**COMPLETE**。按研讨后的冻结协议执行；主计算2.88秒，
0次新神经调用、0次新梯度、0次量表连接。代码先于本包结果提交：`cd4ae0d`。
本包连接的是文本编辑与LLM查询判断，不是重新刷人格预测分数。

## 1. 三项发现

1. **共同功能读出可跨作者使用，但局部计算不是完整文本作用。**12位参照作者
   冻结的三个查询读出，在12位留出作者上重建真实局部patch响应r=.878–.942。
   对完整删文响应，N有r=.351，TF/确认则为.049/.143。
2. **查询共享存在于多个通路，而且会部分抵消。**相同编辑/视图条件内，N/确认
   的冻结局部响应相关为.814，实际patch相关为.704，完整自然响应相关为.283。
   自然响应的正协方差由两个正项和两个负交叉项共同形成；不是局部共享不存在。
3. **下一研究对象是上下文与查询读出的组合，不是更精确拟合现有读出。**
   逐项展开发现，N的站点外作用与确认的冻结读出协方差为−.04997，作者bootstrap
   95%CI[−.07382,−.01658]。站点外N/确认彼此又有正协方差+.14904
   [.02718,.23816]。不能把整个剩余项删为噪声。

这里的“抵消”指有符号协方差的统计抵消；是否属于同一输入中的计算抑制，
由下一次实际上下文×查询干预区分。已有S0–S26机制和作者关联继续保留。

## 3. 查询读出与完整自然响应

令d为自然编辑引起的查询状态位移，a=g_ref,q^T d，M为原文中仅替换该状态
得到的实际响应，Delta为完整删文响应。g_ref只由参照作者估计。

| 查询 | a对实际M，r [95%CI] | a对自然Delta，r [95%CI] | 自然响应MSE/零预测 |
|---|---:|---:|---:|
| T/F | .9415 [.8848,.9777] | .0487 [−.2588,.3746] | 1.0837 |
| N | .9176 [.8939,.9532] | .3509 [.1867,.5239] | .9841 |
| 寻求确认 | .8782 [.7828,.9463] | .1430 [−.1834,.4891] | 1.0340 |

相关描述响应排序，MSE同时反映尺度与偏差。N的正向联系已存在，但并不是
自然效应幅度已经完全重建。实际M对Delta的r=.0668/.3326/.2069；继续把a
拟合得更接近M，不能自动解决M与Delta之间的差别。

原始单位下，预定模型的自然响应r / MSE相对零预测：

| 模型 | T/F | N | 确认 |
|---|---:|---:|---:|
| 零响应 | 未定义 / 1 | 未定义 / 1 | 未定义 / 1 |
| 参照query/edit/view均值 | .053 / 1.279 | −.296 / 1.710 | −.110 / 1.200 |
| 共同位移＋专属读出 | .196 / .970 | .280 / .960 | −.007 / 1.108 |
| 专属位移＋共同读出 | −.132 / 1.064 | .296 / .966 | .341 / .877 |
| 专属位移＋专属读出 | .049 / 1.084 | .351 / .984 | .143 / 1.034 |

标准化后，“共同读出”改变了三个读者的相对权重，其r变为−.241/.326/.254，
误差比1.261/.913/.932。其它模型逐查询r/误差比不变。完整两套结果均保留，
不根据有利单位挑“胜者”。这也表明共享构造需要声明输出单位。

## 4. 共享与抵消的精确账本

令epsilon=Delta−a，N与确认的协方差为：

    Cov(Delta_N,Delta_C)
      = Cov(a_N,a_C) + Cov(a_N,epsilon_C)
      + Cov(epsilon_N,a_C) + Cov(epsilon_N,epsilon_C)
      = .06999 − .03391 − .06271 + .15444
      = .12781.

| 项 | 协方差 [95%CI] |
|---|---:|
| 完整自然响应 | .12781 [.01320,.20552] |
| 冻结局部×冻结局部 | .06999 [.02675,.11061] |
| 冻结局部N×剩余确认 | −.03391 [−.10066,.02561] |
| 剩余N×冻结局部确认 | −.06271 [−.09471,−.01923] |
| 剩余×剩余 | .15444 [.03978,.24821] |

两正项合计.22443，经负交叉项−.09662后成为.12781。不能分别平方后称
“解释了多少独立人格方差”，也不能用局部相关.814代替自然相关.283。

进一步按Delta=a+(l−a)+(M−l)+(Delta−M)展开为16个跨查询项。
关键负项为Cov(outside_N,a_C)=−.04997，另向为−.02167
[−.08940,.03804]；outside×outside=+.14904。局部非线性×非线性为+.00064。
完整16项保留于`interpretation/signed_component_covariance.csv`；此展开是在
看到主结果后进行的定位性分析，无拟合、无新增模型选择。

每个分量的参考SD单位RMS如下；它们不是正交能量份额：

## 5. 从局部关系预测整体结构

完整自然响应协方差，与条件于留出位移的冻结函数预测分别为：

    顺序 TF / N / 确认
    自然:   [[ .56098, -.06332,  .07353],
             [-.06332,  .22456,  .12781],
             [ .07353,  .12781,  .90748]]
    函数:   [[ .05366, -.00576, -.00907],
             [-.00576,  .07269,  .06999],
             [-.00907,  .06999,  .10168]]

函数保留N/确认的正向共享，但遗漏较多响应幅度。相对零协方差模型的Frobenius
误差比为.8783；连输入协方差也从参照集冻结后为.8475。共同位移/专属读出
为.9157，专属位移/共同读出为.9501。全部误差区间较宽，不以三条非对角线的
“矩阵相关”宣布整体机制重建。

两个查询的差异可以精确分成对称读出项与证据项。标准化后的RMS：

| 查询对 | 读出项 | 证据项 | 单独记录的交互项 |
|---|---:|---:|---:|
| TF/N | .365 | .312 | .422 |
| TF/确认 | .398 | .268 | .376 |
| N/确认 | .175 | .147 | .125 |

读出项＋证据项已等于模型总差，不能再加交互。TF/N的自然差异与读出项r=.284；
TF/确认的自然差异与证据项r=.320 [.114,.557]。结果支持同时保留两种来源，
而不是强制“查询只改变末端标签”或“全部来自向量位移”。这些是固定坐标内
功能反事实，不是实测跨查询patch的因果份额。
