## 2. 数学链条已经具体化到哪里

```text
真实作者文本 x + 查询 q + 条件/时点 c
  -> 冻结模型前缀
  -> 已吸收上下文的查询区域矩阵 P、末位置向量 Q
  -> f_q(P,Q) = b_q + <G_q,P-P_Rq> + g_q' (Q-Q_Rq)
  -> 作者分数与参照位置
  -> 和真人量表/状态指标进行外部连接。
```

G、g 在独立参照作者上通过导数和路径积分近似构造，不由真人标签拟合。
评分不再调用后半模型或生成解释，但仍需要冻结的神经前缀，不是脱离模型
从原始文字直接做线性回归。P 的行是查询区域 token，不是原始文句逐词向量。

每个函数进一步具有完全可复算的分解：

```text
f_q = b_q + M_q + C_q + Q_q
Cov(Y,f_q) = Cov(Y,M_q) + Cov(Y,C_q) + Cov(Y,Q_q)
Cov(F_q,F_r) = sum_ab Cov(V_qa,V_rb), V=(M,C,Q,F-f)
```

所有相关贡献使用同一个分母，因此相加能还原原始相关。最后一式将原生模型
未被固定函数解释的部分也保留下来；不把它先验当成垃圾。

例如低落感的外部 r=.564 来自均值 .057、配置 .329、末状态 .179；对AI依恋
焦虑 r=.303 则是 .050、.076、.177。**相同公式、不同目标的不同作用分配**
已成为可计算对象。共享部分也可能被反向部分抵消，因此不能只找一个万能
“人格方向”，也不能见到共同成分就称其为噪声。

## 4. 文献如何帮助闭合推导

- [Funder 的现实准确性模型](https://pubmed.ncbi.nlm.nih.gov/7480467/)区分线索的相关性、可获得性、检测和利用。我们的“材料条件 → 状态 → 查询函数 → 外部链接”将这些环节操作化；忠实读模型和准确读人不再混为一谈。
- [PANDORA](https://aclanthology.org/2021.socialnlp-1.12/)与[语言人格评估研究](https://pubmed.ncbi.nlm.nih.gov/25365036/)提供真实作者与外部标签的检验逻辑。本轮继承这一点，但研究对象是冻结模型的向量读出，不把源发现集冒称官方复现。
- [Integrated Gradients](https://proceedings.mlr.press/v70/sundararajan17a.html)提供路径导数的相关方法基础。路径积分等式来自微积分；跨作者平均后得到的固定函数是否可复用，则是本轮实测的问题，不是该定理自动保证的结论。
- [多特质多方法分析](https://pubmed.ncbi.nlm.nih.gov/13634291/)指导完整交叉关联与同人不同材料比较，而非只报每行最大值。当前是描述性矩阵，不是假装已经拟合了可靠的潜变量模型。
- [对话条件与人格推断研究](https://arxiv.org/abs/2405.13052)提示材料的表达机会会改变可用信息；本轮的状态/关系目标差异为我们的条件参数提供了实测内容。

可以据此提出的核心命题是：**在冻结观察器与明确查询条件下，存在一套共同
的可执行向量函数构造，能够跨多个心理目标保留部分模型作用及外部作者关联；
目标差异体现在算子、材料机会和时点上。** 这已经是可供后续推导的基础，
而非“每个因子都必须高相关”或“所有心理推论已被一个公式证明”。
