# VM05：固定当前文本的历史对照，材料与仪器进展

2026-09-06。当前结论：**材料阶段完成；真实神经历史效应与外部预测尚未运行**。
这不是新的 Big5/MBTI 精度报告，也不是整项研究完成。协议见
[历史对照设计](../../docs/GRAIN_VM05_HISTORY_COUNTERFACTUAL_V1.md)。

## 研究对象

同一条当前评论，分别配本人的先前11条评论、固定参照作者的11条评论、
历史不可见遮罩。保留原有三份视图及36条本人评论，不截断或以新文本补位。
在各自固定 token/位置的布局中测量：

```
history_effect = h(current | own_history) - h(current | reference_history)
visibility_effect = h(current | own_history) - h(current | history_masked)
decision_interaction = history_effect(disposition) - history_effect(behavior)
```

本轮总体是既定7,266人 common-material 队列，不是全部官方 PANDORA 用户。
原99名MBTI-only几何参照作者仅作固定、未使用标签的历史字典，排除出本实验
预测/评估对象，余7,167人。没有把bridge作者用作donor或读取其心理值。
字典是297份历史，不是对所有人的完整参照分布积分。

## 实际修复与结果

首轮只有4,551人通过。2,569人因 token 前后缀不一致被排除，但不是原文不足：
历史末尾标点可与后面两个换行合并为 token，造成两种历史的分界归属不同。
192名哈希选取的失败作者，3,456布局诊断中原有1,432次布局失败；将现有两个
换行一起归入历史槽后，全部恢复，原生 token 序列改变次数为0。

完整重跑也恢复了全部2,569人，旧可用作者损失为0。旧、新交集13,653份视图
逐项验证：当前评论、本人历史、donor及匹配代价均未变。剩余47人没有满足
前置时间/来源条件的字典历史，不人为补齐。

## 新发现：软匹配未固定主题

原匹配代价是绝对log长度比、log(1+时间差/天)差和subreddit Jaccard的加权和。
strict材料的长度误差中位数约.032--.037，但三组Jaccard中位数均为0。
因此当前donor应称为**长度/时间优化的参照历史**，不能宣称主题已控制。

随后冻结一个无标签可行性诊断：要求至少共享一个subreddit，再按原代价选
合法donor。保留旧材料不改；新候选尚未经token布局及近重复复审。

| 来源 | 可用视图/原strict视图 | 三视图均有候选的作者 | 新Jaccard中位数 | 新时间误差中位数 |
|---|---:|---:|---:|---:|
| Big5-only |1581/1860|448/620|.0833|1.3549|
| MBTI-only |17475/18717|5253/6239|.0833|.8974|
| Bridge，仅材料 |702/747|209/249|.1000|.9812|

共有5,910人可进入这一备选对照，但时间匹配变差；时间误差是变换后的log差，
不是天数。54个计数/分位数经独立CSV运算重算，误差0。正subreddit重合也不
保证相同语义topic或situation。不能用“匹配成功”替代对各条件的实际检查，
也不能把两种不同保留人群的预测指标直接比较。

理论上的处置是保留两个参照条件，明确其估计对象，而不是把所有条件差异
统计消掉。选择某个语境本身可能承载作者信息；条件限制与自由选择应分别观察。

## 仪器资格与边界

- 新的6名源头技术作者，324布局已按冻结哈希重建，108个三臂布局又作独立
  数组不变量检查。没有加载模型，不能称真实神经资格已通过。
- 合成小型随机Qwen验证了固定当前位置、历史遮罩、更换仅被遮罩的token、
  恢复原历史、与无内部padding的原生forward一致。相关整组122 tests通过，
  两项既有SWIG弃用警告；不是全历史仓库测试。
- 问题位于当前文本之后。当前token状态跨后置问题不变是因果mask的仪器
  约束，不是“任务不起作用”。任务与历史的交互应在后面的decision位置看。
- 真实Qwen资格计划648次forward，等待原72分片采集完成后才执行。小模型
  测试、代码通过、token重播都不能代替真实checkpoint测试。
- 未取得任何新的神经历史预测、人格效度、临床诊断或人类心理因果证据。

旧归档器的窄glob漏收这些新入口。原件保留，已根据原manifest的源码hash从
git blob精确补档，明确标为事后补档。新仪器/比较/可行性入口使用完整历史
源码allowlist并绑定归档SHA，不把补档冒称启动前封存。
