## 剩余误差不是一个黑箱数字

把作者P/Q换成参照均值，但保留作者E与布局，得到b(E_u)。精确分解：

```
真实分数 - 公式分数
 = [b(E_u)-b_ref] - [实际锚定变化 + 公式中心化读数]
 = 条件基线偏移 + 负运输误差。
```

神经质基线偏移均值为-.04104、RMS .04455；负运输误差RMS仅.01402。
总水平误差RMS .04493。因此神经质在本面板上的主要缺口是**条件基线**，
不是简单“向量不含信息”。TF两部分会抵消，不能用各项RMS相除当解释率。

## 作者配置连接

每人三查询×水平/自然变化共6坐标，以两参照的均值和SD固定归一：

- 构造vs原生的同材料作者距离结构r=.6243，作者置换p=.0010。
- 与另一不重叠12评论视图的原生配置r=.0483；原生两视图自己也只有.2052。
- 单独“寻求确认”水平跨视图r=.4266，原生对应.3538；TF/N没有同样现象。
- 既有GRAIN36评论几何与构造配置r=.3490、置换p=.0839；这是材料有重叠的
  对照，不是独立文本验证。两机制视图之间重复文本数为0。

因此本轮得到的是材料/条件相关的作者响应配置。不同文本量与场景下哪些
方向属于更持久的人际差异，保留为后续条件化测量问题，不用它否定本次整链。
