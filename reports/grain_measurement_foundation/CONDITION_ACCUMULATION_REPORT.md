# 从文本条件到个人响应：M01/M02首轮交付

2026-09-13。两个有限实验包完成，总TODO研究goal保持ACTIVE。
本轮不是人格预测排行榜：**条件读取与证据累积共同决定我们把什么算作个人差异。**
已有工具可以接出有效条件响应，但整句条件向量会混入行为；事件重复既会改变信息量，
也可改变所估计的对象。由此得到下一步可用的三条制作规则，而非再做通用分类器。

## 2. 发现一：同一条件下的行为会混进“条件向量”

留出措辞的条件识别率，整句向量为社交78.125%、任务84.375%；事件正反读取
在各自32条留出句上均100%。这是有限设计句的结果，不是开放域准确率。

固定条件前置句，仅换后面的正反行为，整句估计的条件坐标平均绝对改变
社交.350355、任务.107910。因此将该条件坐标再拿来解释行为，存在反应混入条件的通道。
来源词法条件模型几乎完美，并没有阻止这一留出变化。

续包仅改变条件的读取范围：条件估计读前置分句，事件NLI仍读完整原文；
所有内容均保留，没有从个人信息中删除topic/行为。

| 条件识别率 | 整句 | 条件分句 |
|---|---:|---:|
| 社交 | .78125 | 1.00000 |
| 任务 | .84375 | .87500 |

条件分句的行为混入为0是输入隔离的必然结果，不是它理解所有情境的证明。
它是否有用须看个人读数；48独立事件、事件加权方法得到：

| 模拟目标参数 | 整句条件 r / RMSE | 条件分句 r / RMSE |
|---|---:|---:|
| 社交水平 a | .646247 / .240438 | .829038 / .140151 |
| 社交响应 b | .825688 / .279399 | .848517 / .203815 |
| 任务水平 a | .776333 / .167281 | .790512 / .157838 |
| 任务响应 b | .791642 / .197059 | .753370 / .189029 |

社交水平RMSE减少.100287，配对模拟作者bootstrap95%区间[.089037,.111571]；
社交响应减少.075584[.067504,.084192]。四个参数的RMSE均5/5seed改善，
但任务响应r下降，故不是所有指标全面提升。区间条件于固定句库/读者，
不包含语言泛化及来源读者估计的不确定性。

**制作规则1：条件与被测反应应有可区分的读取地址；共享同一原文不代表
必须使用同一池化向量估计二者。** 开放情境可用更一般的条件算子；本分句规则
只是明确语法下的机制见证，不作为开放域通用切法发布。

## 3. 发现二：正确计算重复性，不等于修复重复选择的偏差

12事件各复述4次时，按48报告独立计算的名义95%区间覆盖明显不足。
这里用已知条件臂，隔离条件估计损失：

| 水平参数区间覆盖 | report-IID | 事件聚类 |
|---|---:|---:|
| 社交 | .665625 | .942187 |
| 任务 | .646875 | .932813 |

两者点估计完全相同。正确考虑相关性改变了区间，不会凭空多出36次经历。

另一个世界保持12事件均被记录，但各条件挑一个正反应优先的事件额外复述18次。
仍为48报告，此时改变的是各事件的计分权重。实际学得的整句条件臂：

| 水平参数 | 按报告加权 RMSE / bias | 每事件等权 RMSE / bias |
|---|---:|---:|
| 社交 | .758555 / +.691029 | .379346 / +.027069 |
| 任务 | .646438 / +.585117 | .289202 / -.041366 |

RMSE减少分别.379208[.359186,.401026]、.357236[.333124,.380463]，均5/5seed。
仅换report-cluster稳健误差，点估计偏差保持原样。
完全事件内相关的加权有效事件数从约3.15回到12；它是该假设下的诊断数，
不是所有文本信息量的精确度量。

**重要的混合结果：** 对响应b，学得条件下的事件加权RMSE反而分别增加.126942和
.065103，均0/5seed改善。偏向性复述可能把响应压向0，暂时降低这个低振幅目标的MSE；
同时条件估计误差仍在。正确恢复事件权重不保证每个目标的有限样本MSE最优。
因此不把“去重”宣布为万能提升，也不因某个较小MSE就恢复有偏的事件含义。

重复选择的作用还能直接推导，而不只猜测：若某条件的事件期望为m，6事件中
最正面的一个额外复述18次，则报告均值期望为

\[
H(m)=\frac{6m+18\{1-2[(1-m)/2]^6\}}{24}.
\]

所以H(0)=.7265625，H'(0)=.390625：原本中性的事件过程被读成高度正向，
小的条件差异也被压缩。报告层测到的是H(a±b)，不是原来的a±b。
枚举所有64种事件组合、三个生成概率，公式均与直接加权期望一致。
它解释这个已声明选择机制的偏移/压缩；NLI和条件估计的额外误差仍分开。

**制作规则2：先确定要测报告习惯还是事件反应，再决定权重；估计量的对象、
依赖结构及有限样本收缩是三个不同问题。** 本实验所有事件至少被记录一次。
未报告事件的选择偏差不能靠现有记录去重解决，选择画像另行保留给M03。

已知修订链的有限见证也交付：原记录均值1/3，按事件最新明确修订后的当前均值0；
3条历史全部保留，2个事件参与当前计分。它检验更新规则，不声称能自动判断哪句话为真。

## 4. 发现三：条件坐标换原点，会把响应混进个人水平

即使完全没有随机误差，只要条件估计变成另一坐标：

\[
m_u(z)=a_u+B_u z,\qquad \widetilde z=c+Tz,
\]

就必须同步变换

\[
\widetilde B_u=B_uT^{-1},\qquad
\widetilde a_u=a_u-B_uT^{-1}c.
\]

这是标准仿射重表达，不是新数学定理。它说明：**新坐标里的截距差异可以来自
不同人的响应，而不是他们在同一原条件下的水平改变。** 若连参照条件分布一起运输，
目标积分和完整响应函数不变；只比较截距/斜率数值则可能误读。

主包的留出条件坐标描述性分解，社交约为
z_hat=-.428806+.435802*z+其余项；分句版本为-.027273+.617721*z+其余项。
前者若只有仿射项，会把约.984*b混入截距；后者约.044*b。
这定位了一个实际可见的坐标通道，**不等于解释了本次全部误差或改善的因果份额**：
条件读者还含措辞残差，NLI也有分数尺度误差，真实映射并非精确仿射。

`condition_coordinates.reexpress_response` 已实现共同可逆坐标变化，
100个三维条件×5响应的函数与参照积分不变测试通过；奇异变换明确拒绝。

**制作规则3：个人响应参数必须连同条件坐标、原点、单位和目标参照一起交付。**
条件分类分数也不能未经校准就自动解释为情境强度。下一步应接M03/M04的
选择与共同响应构造，再用M10检验何种观察能补足信息，不继续调此句库的Ridge。
