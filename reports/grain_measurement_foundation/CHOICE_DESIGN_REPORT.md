# 选择、条件响应与来源学习设计：机制交付

2026-09-13。研究goal ACTIVE；M03有限机制验收完成，M04/M10取得可运行子包。
本轮把同一个人拆成**主动选择轮廓、共同条件响应、当次状态的选择效应**，
再从来源文本读数学习下一条观察的价值。不是另一个人格预测排行榜。

## 1. 本轮得到了什么

1. **尾部选择确有条件增量。** 根选择相同仍可有不同尾部偏好；条件树的Fisher
   信息可分解，额外尾部信息不必是噪声。未知机会供给时，偏好与供给不能独立识别。
2. **高相关能掩盖测量对象错误。** 机会与偏好同向时，未校正选择r=.917/.930，
   高于机会校正后的.771/.796，但参数RMSE约1.47/1.53，校正后约.633/.640。
3. **固定/自由两相不是无代价拼接。** 状态驱动选择时，固定相减少响应偏差；
   只用半数固定事件也增加方差。偏差、精度和保留选择信息须分别决策。
4. **非oracle的目标导向设计已可运行。** 指定条件响应可从来源材料选出更有用的
   新事件；整体水平/条件对比未普遍胜过均衡设计。来源先验对新响应分布会失配。

这些是固定文本银行驱动的数值机制结果。作者参数由模拟给定，**不是新增真人人格
相关**。事件方向由既有文本NLI读取；不把模拟人数当独立自然语言样本数。

## 3. 选择与响应的联合对象

在一个根分支及两个条件尾部分支上，令

\[
P(C_{uj}=1\mid O_{uj},u)=\sigma(o_{uj}+\gamma_{uj}),
\qquad E(Y_u\mid z,\operatorname{assigned})=a_u+b_uz.
\]

o为已知机会log odds，gamma为相对于该机会的偏好偏移；不是Big5标签。
反应函数的两个实际端点为m_minus、m_plus，共同参照为

\[
a=(m_-+m_+)/2,\quad b=(m_+-m_-)/2.
\]

a是两条件等权水平，b是半差；不宣称测得未实际观察的中间情境。
只观察一个条件时经验a/b返回缺失，不用零或人口平均冒充个人观测。

若选择与反应在给定条件/个人参数后可分开，联合似然为

\[
\ell=\ell_{choice}(C\mid O,\gamma)+\ell_{response}(Y\mid C,a,b).
\]

分别计分后也可研究共享参数，不需要先把choice从作者表示删除。
对参数独立的两层二叉树，单次自由选择Fisher信息为

\[
I=\operatorname{diag}\{p_0(1-p_0),
 (1-p_0)p_-(1-p_-),p_0p_+(1-p_+)\}.
\]

四叶枚举验算：根信息.221713；两个尾部合计.196844，交叉项数值误差<1e-15。
这些值取决于指定概率，不是人格信息常数。尾部很少被访问时有效信息相应减少。
固定分派条件不由gamma决定，因此对**偏好参数**的信息为0，而非作者无偏好。

独立世界，两相设计的机会校正分数与已知偏好参数相关：

| 目标 | 根r | 负根后的尾部r / 有记录人数 | 正根后的尾部r / 有记录人数 |
|---|---:|---:|---:|
| 社交 | .882677 | .757578 / 634 | .769795 / 634 |
| 任务 | .903330 | .785318 / 632 | .767813 / 630 |

各单元共640作者；没访问某分支者保持该尾部分数缺失。根/尾部偏好在此世界
独立生成，所以不能用“只看根”替代尾部；这是层级选择增量的有限见证。

### 机会未知时改测什么

只观察p，则 `(gamma+d,o-d)` 对任意d产生相同p，偏好与供给不识别。
合法输出是观察选择轮廓 `log((n_plus+.5)/(n_minus+.5))`，
不是声称扣掉了现实平台机会的“纯偏好”。在机会与偏好同向的世界：

| 目标 | 未扣机会 r / RMSE | 已知机会校正 r / RMSE |
|---|---:|---:|
| 社交根选择 | .916693 / 1.471456 | .770769 / .633158 |
| 任务根选择 | .930427 / 1.529419 | .795870 / .639536 |

高r来自供给把个人排序进一步拉开。校正后的低r不等于更差的同一测量：
它更接近声明的参数单位，有限计数和极端分支造成的估计方差仍存在。

## 4. 当次状态为什么要求分开自由与固定

令当次状态s取+/-1，根选择概率为 `sigmoid(o+gamma+2s)`，
事件期望为 `a+b*z+0.3s`。在 `o+gamma=0` 时：

\[
E(s\mid z=+) =\tanh(1),\quad E(s\mid z=-)=-\tanh(1),
\]

故自由文本的条件半差为 `b+0.3*tanh(1)=b+0.228478`。
固定分派z独立于s时该选择偏差为0。这继承选择可忽略性原则，
是[Rubin(1976)](https://doi.org/10.1093/biomet/63.3.581)相关理论在此模型的应用，
不宣称状态分账公式为新发明。

实际固定文本读者与有限观察的b恢复：

| 目标 | 48自由 RMSE / bias | 48固定 RMSE / bias | 两相合并 RMSE / bias | 仅24固定 RMSE / bias |
|---|---:|---:|---:|---:|
| 社交 | .248920 / +.199134 | .141759 / -.017081 | .164055 / +.082266 | .191617 / -.016769 |
| 任务 | .228007 / +.180650 | .136810 / -.020992 | .148289 / +.070854 | .187444 / -.027838 |

自由→固定RMSE减少社交.107161[.093401,.120805]、任务.091196[.079397,.103893]，
均5/5seed正向。区间为固定语言银行内、seed内作者配对bootstrap95%。
但两相中只用固定24条，虽减少偏差，RMSE反而增加.027562/.039155。
不能把“更接近分派条件响应”改写成“相同预算所有指标最优”。

**制作规则：** 同时需要自由选择和分派条件响应时用两相并分账。
若目标是“此人在实际选择语境中的表现”，自由相不是错误数据；
若目标是“共同条件下反应”，不要未经假设把自由相当随机分派来增加样本量。

## 5. 不知道真参数，也能选择下一条观察

从来源作者的事件读数Y估计各条件内方差R，以及作者两条件均值的协方差：

\[
\hat\mu=\overline{\bar Y_u},\quad
\hat T=\operatorname{Cov}(\bar Y_u)-\operatorname{diag}(\hat R/n_0).
\]

代码保留正定特征值下界与触发记录，本轮10份来源拟合均未触发。
新作者独立事件数n、分数和s给出线性预测：

\[
V=(\hat T^{-1}+\operatorname{diag}(n/\hat R))^{-1},\quad
\hat m=V\hat T^{-1}\hat\mu+V(s/\hat R).
\]

分别保存来源均值项与个人证据项，以及数据/先验权重矩阵。
缺少一个条件仍可由来源条件协方差借力，但标明该条件未观察；
它是模型完成，不是独立新证据。来源矩只从来源pilot读数估计，不读潜在a/b。

对于目标 `c.T m`，在条件j补一次独立事件的工作MSE下降为

\[
\Delta_j=\frac{(c^T V e_j)^2}{\hat R_j+e_j^T V e_j}.
\]

完美复述同一事件时独立增量为0。该目标导向思想继承
[Chaloner与Verdinelli(1995)](https://www.stat.cmu.edu/tr/tr599/tr599.html)；
本包新增的是从文本事件pilot到设计规则的可执行连接，不是发明最优设计。
二值事件不服从高斯；这里是固定二阶矩的线性工作预测/不确定性。

### 实际效果与失败边界

16报告、每条件2事件起步，对“指定正条件响应”，来源设计均选2负+14正。
均衡参照8+8。下列目标是真实生成分布经**固定读者**后的条件期望：

| 目标/世界 | 均衡RMSE | 来源设计RMSE | 减少量95%配对CI |
|---|---:|---:|---:|
| 社交/同读者新作者 | .191798 | .183025 | .008773[-.000397,.018556] |
| 任务/同读者新作者 | .198961 | .183119 | .015842[.008286,.023298] |
| 社交/新措辞 | .194092 | .175774 | .018318[.009525,.026515] |
| 任务/新措辞 | .191271 | .187240 | .004032[-.003743,.012483] |

目标导向选择有实际作用，但不是四格都具有明确正区间。
对整体水平、条件对比，来源估计分配会从2/14到12/4漂移，未普遍胜过均衡。
风险排序与实际风险的相关在这两类近似平坦的分配面上很弱；继续扫分配比例
不如保留均衡参照。全部13种分配的风险面**仅评价，不用留出风险反选设计**。

更重要的是响应分布改变：来源b范围为+/- .15，新世界为+/- .40。
仍使用旧来源先验时，b的名义95%工作区间覆盖仅社交.381250、任务.553125；
使用新世界真实二阶矩的oracle覆盖.956250/.962500。
这揭示了**来源协方差过强收缩**，不能靠换最优分配自动消失。
指定条件响应在该世界仍可改善，说明“某目标测得好”不能替代其它目标误差诊断。

同读者新作者，8独立事件各复述2次时，保留事件依赖的水平覆盖.957812/.954688；
误当16独立事件为.898438/.901563。重复校正与来源学习设计是两层不同机制。

## 6. 当前可用制作决策

| 想测什么/观察环境 | 可执行规则 | 不做什么 |
|---|---|---|
| 已知机会的主动选择 | 机会offset + 根/尾部条件计数，未访问分支留空 | 不把固定分派当选择 |
| 自然文本、未知机会分母 | 报观察选择轮廓及条件 | 不伪造机会来命名纯偏好 |
| 两条件共同反应 | 报等权水平、半差、各条件事件数 | 不以频率加权均值代替共同参照 |
| 自由选择和反应都重要 | 两相分账；声明针对实际选择还是分派条件 | 不承诺每个分数精度最大 |
| 指定条件响应优先 | 从来源事件矩选新独立观察，与均衡相比 | 不依据留出误差选分配 |
| 整体水平/响应对比 | 本次保留均衡为默认强参照 | 不为微小增益持续搜索 |
| 新人群响应范围改变 | 新来源pilot重估响应协方差，保留旧参数比较 | 不沿用旧窄先验宣称高置信度 |
| 新措辞/新编码器 | 分开检验读者目标与原生成参数 | 不把reader误差当作者差异 |

新来源pilot重估及来源估计不确定性传播是本包导出的后续规则，**本轮没有
执行新pilot迁移修复**。由M11/M12承接，不把oracle结果标为修复完成。
