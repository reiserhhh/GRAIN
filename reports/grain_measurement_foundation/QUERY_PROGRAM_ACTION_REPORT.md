# M07：独立程序中的查询运算与归属边界

2026-09-13，`query_program_actions_r1`。**两条独立路线的有限运行/机制验收完成。**
28段公开编写文本×3查询=84输入；84次4层前向、84次固定教师前向，无新训练。

## 1. 本轮新增了什么

**查询相关作用可以被编进文本区的投影系数，不一定要在运行时复制整个上层问题区。**
M06在block16发现的P主导，不能直接下推为所有计算层的P主导。本轮既有4层直接
程序的低落证据响应中，98.6%的分账来自C文本区；这与来源查询Jacobian向前投影
的构造相容。注意这里分账的是这个轻量程序的变化，不是它捕获了98.6%的原生作用。

另一条来源状态估计路线，实际重建上层P/Q再计分，与直接编译投影在84输入上
最大分数差`1.55e-15`。因此**不必复制所有状态坐标才能实现同一已构造函数**。
恒等只针对固定状态估计器与线性读者的复合，不等于该估计器恢复了真实全部模型。

本轮还把独立计算的剩余问题具体化：**目标词汇敏感度、顺序敏感度、主体绑定
不是同一种能力。** 同词袋交换本人/同事时，均匀token程序18/18条作用严格为0；
有序程序虽会变化，却随谁先出现而改变方向。这不是继续增加通用回归精度能解释的。

## 5. 数学结论与继承边界

### 状态重建不是必要中间产物

固定A模型：`h_hat = x + mean_r + k_c(x) B`，读者`f(h)=b+v'h`。
因此

\[
f(\hat h(x))=b+v'x+v'\bar r+k_c(x)Bv.
\]

线性核再展开就是一次仿射内积。两条路线的严格数值一致性是这条复合恒等的实例，
不是发现新的测量公理，也不是新证明浅层包含完整人格意义。

### 位置与运算应区别

来源chart梯度可以表示为`J_source' v`，将后续查询读取的局部作用投影到早期状态。
本地B随后还使用冻结soft alignment：

\[
\hat f_q(T)=a_q+\frac12\sum_j\bigl[o_{qj}
+\langle g^C_{qj},A_{qj}(C_4(T))-A_{qj}(C_{4,j})\rangle
+\langle g^P_{qj},P_4(T,q)-P_{4,j}\rangle
+\langle g^Q_{qj},Q_4(T,q)-Q_{4,j}\rangle\bigr].
\]

`A`为原程序语义/相对顺序softmax对齐，参数8和4原样继承；未重新选核。
重基准保证来源点分数一致，**不保证来源点导数也一致**：有效C导数是
`D A(C)' g`，而非自动等于`g`。所以此处是来源导数加启发式对齐的程序，
不是在任意新文本上精确重演教师推论。作用收缩可能来自对齐与来源线性化等环节，
本包不在没有逐环节干预时强行把全部损失归给其中一个。

状态翻译/直接读出的相关先例为[Tuned Lens](https://arxiv.org/abs/2303.08112)；
压缩计算与教师输出分工可参照[Hinton等的知识蒸馏](https://arxiv.org/abs/1503.02531)。
本轮仅补核摘要，继承问题划分，不宣称复现两文训练目标或其完整因果结论。

### 同词袋表示有可计算盲点

若`pi(T0)=pi(T1)`而教师读数分别为`y0,y1`，任何只依赖该表示的确定性读者
都给同一个`c`，该对平均平方误差至少为`(y1-y0)^2/4`。
在本包18对上汇总，教师分数拟合RMSE下界`.030984`；对应目标6对为`.040675`。
这是**当前有限材料上复现教师的下界**，不是人类测量误差下界，也不适用于保留顺序的表示。
它使下一步问题具体化为应增加哪种绑定信息，而不是对同一词袋无限调参。
