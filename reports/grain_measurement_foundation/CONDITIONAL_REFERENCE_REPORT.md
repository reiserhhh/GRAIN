# 固定条件参照：从总体均值到可构造的条件响应对象

2026-09-13，C01/C12/C15/C17续批；交付为`conditional_reference_r2`。
[本批方案及数值修正记录](../../docs/GRAIN_CONDITIONAL_REFERENCE_PLAN_V1.md)。

## 1. 本轮真正补了什么

**过去计划中的“先固定比较条件分布，再评价一个人”现在有了可调用的计分器。**
它不删除条件，也不把缺测补成平均人，而是同时返回：

1. 实际原文的语义画像，以及其来源条件、条件内偏离、新条件表达三个可加回部分。
2. 这个人实际选择的条件比例；相同参照下还没有观察到哪些条件。
3. 固定目标条件的完整得分（材料齐全时），或未观察部分的联合向量范围。

两项实证结果改变制作规则：
- PANDORA的36评论自然采样远不足以让人人覆盖同一个庞大社群分布。共同目标的
  选择本身就是测量设计，不能在计分时悄悄把各人的可用条件当成相同目标。
- 不同语义方向共享向量几何。组合目标的缺测范围应由共同线性映射计算，而不是
  把每一维各自最坏情况任意相加；这里可获得实质更紧的数值范围。

这是条件化测量的**语义证据参照实现**，不是制成了新人格量表。30方向来自固定
IPIP语义锚点，不等于已核实的作者断言或30个心理特质；本批未使用问卷效标。

## 2. 继承的理论与本地改造

后分层提供“各条件的反应×固定条件权重”的制作基础；原文还用层级模型处理稀疏
单元。本批只实现直接汇总，不复制其二项层级模型，也不假定作者未表达的条件
随机缺失。[Gelman与Little，1997，§2.1–2.3](https://sites.stat.columbia.edu/gelman/research/published/poststrat3.pdf)

部分识别将观测材料与额外假设分开，且不把识别范围当作抽样置信区间。本批据此
单独声明未观测单元可取的向量集合，再用Cauchy–Schwarz推导范围。实读的是书的
导论及目录，不冒称读完全文。[Manski，2003，导论](https://www.cemmap.ac.uk/wp-content/legacy/forms/manskipaper.pdf)

GRAIN这里的工作是把这些成熟原则接到**原文单位→冻结向量→作者条件画像→共同
比较目标→应补材料**，而不是将加权平均或凸集合命名为新的数学定理。

## 3. 构造条件与实际覆盖

复用22,464条PANDORA原评论和13,790个Essays原文128word片段，总计3,091作者。
没有新embedding调用或问卷训练。来源侧504/2,213人，开发留出120/254人。
所有来源参数先冻结；每个人单独计分不改变他人的参照。

PANDORA条件是记录的subreddit，不是“心理情境真值”或已固定的刺激；Essays
只记录一个essay_protocol条件，并不证明现实中的任务情境完全同质。

来源分布为每位来源作者条件比例的平均；每个来源条件的语义参照则是该条件中
各作者均值的等权平均。两处都避免让多发言的人支配参照。

| 材料与固定目标 | 目标条件数 | 留出人数 | 覆盖权重中位数 | 完整覆盖人数 | 完全未覆盖目标人数 |
|---|---:|---:|---:|---:|---:|
| PANDORA全部来源社群 | 2,506 | 120 | **4.602%** | 0 | 0 |
| PANDORA来源最常见五社群 | 5 | 120 | **33.550%** | 0 | 39 |
| Essays单一记录条件 | 1 | 254 | **100%** | 254 | 0 |

这里4.602%是**固定来源分布的权重覆盖**，不是丢掉95%文本；所有原评论都进入
实际语义画像。PANDORA留出作者中，来源样本从未覆盖的社群占其评论的中位13.889%，
这些评论仍原样保存在“新条件实际贡献”中，没有判为噪声。

五社群由来源作者人数选出，分别为AskReddit、JordanPeterson、politics、news、
worldnews；它们反映本材料的选择结构，**不是推荐未来心理实验采用这五个主题**。
缩小到这五个社群已经改变测量目标，不是同一量尺的免费精度改进。

Essays的100%只表示覆盖当前定义的单一记录条件，未观测的任务差异不会因为编码
为一个条件就消失。此处确认了公式的单条件退化性质，不作为跨情境效度证据。

## 4. 不删除条件的分解

令pi_uc为作者u在已采样原文中条件c的比例，m_uc为该条件的语义均值，m0_c为
冻结来源参照。K为来源出现过的条件，U为本作者的新条件，则：

\[
\bar e_u=
\underbrace{\sum_{c\in K}\pi_{uc}m_{0c}}_{A^{context}_u}
+\underbrace{\sum_{c\in K}\pi_{uc}(m_{uc}-m_{0c})}_{A^{departure}_u}
+\underbrace{\sum_{c\in U}\pi_{uc}m_{uc}}_{A^{new}_u}.
\]

三项全部保留。条件内偏离只是一个分量，不把它单独升级为“干净人格”；来源条件
参照也混合了作者选择与语料特性，不是因果估计。这与先前时间W/C/U分解的对象
不同：这里比较作者与固定来源画像，不把两套符号当成同一个动态机制。

对PANDORA留出120人，30方向的方差相加后，相对实际画像总方差的比例为：

| 方差或协方差项 | 相对实际总方差 |
|---|---:|
| 条件参照分量方差 | .472428 |
| 条件内偏离分量方差 | .737739 |
| 新条件分量方差 | .107712 |
| 2×条件参照与条件内偏离协方差 | **-.397872** |
| 2×条件参照与新条件协方差 | .001838 |
| 2×条件内偏离与新条件协方差 | .078154 |
| 合计 | 1.000000 |

这不是人格信息占比。负协方差说明不同分量会抵消；把正项各自解释成独立贡献会
重复计数。制作时应保留这种配置，而不是见到“条件相关”就减掉整个通道。

## 5. 固定目标和联合向量范围

目标分布nu在来源阶段固定。S_u为作者实际覆盖的目标条件：

\[
a_u=\sum_{c\in S_u}\nu_c m_{uc},\quad
\kappa_u=\sum_{c\in S_u}\nu_c,\quad\lambda_u=1-\kappa_u.
\]

只有lambda=0时，a_u才是完整目标点分数。a_u/kappa_u是“此人已覆盖部分的目标均值”，
其条件分布因人而异，接口会分开命名。没有支持时返回null，不返回零人格。

以单位向量h为输入，固定方向矩阵D为1024×30，证据e=D' h。把已观测的**有限材料
条件均值**视为固定，未观察条件的均值向量允许在单位球中变化，则目标集合为：

\[
\mathcal T_u=a_u+\lambda_u D^\top\mathbb B_2,
\qquad
\sup_{T\in\mathcal T_u}t^\top(T-a_u)=\lambda_u\|Dt\|_2.
\]

证明：缺失条件均值的加权和落在半径lambda的球内；任意对比t的最大内积由
z=Dt/||Dt||取得。所有缺失条件取同一z即可在所声明的完成类中达到边界。
实际编码器未必能生成球内每个点，所以它是实际文本的外包络，不能把数学可达
误称为真实语言可达。已观察条件的抽样误差尚另列，这里不是95%CI或潜在特质区间。

如果把30个坐标各自的最大范围独立拼接，对比t的半宽为
lambda×sum_j |t_j| ||D_j||。共同向量结构则给lambda×||Dt||，由三角不等式不更宽。

| 组合语义目标 | 联合范围/独立坐标框范围 |
|---|---:|
| 六个A方向的平均 | .448294 |
| 六个C方向的平均 | .631151 |
| 六个E方向的平均 | .700014 |
| 六个N方向的平均 | .801283 |
| 六个O方向的平均 | .664882 |
| E平均减O平均 | **.255365** |

这些结果表明未知量沿共同方向受约束，而非30种任意独立误差；不是“人格误差减少
74.5%”。对比目标、单位和信号幅度都不同，不能仅以范围更窄宣称心理精度更高。

## 6. 可执行的采样需求

若完整观察一个尚缺条件的有限材料均值，各对比范围的宽度精确减少
2×nu_c×||Dt||。按nu_c从大到小安排等成本的缺失条件，是本对象的覆盖优先规则。
它不承诺一个新句子就代表这个人的真实条件响应，也不是人格信息收益最优设计。

以下是现有留出作者的**预算核算**，不是收集了新文本的实验结果：

| 目标 | 当前覆盖中位数 | 再完整观察1个缺失条件 | 再完整观察2个 | 再完整观察5个 |
|---|---:|---:|---:|---:|
| 所有来源社群 | 4.602% | 9.022% | 11.850% | 18.546% |
| 固定五社群目标 | 33.550% | 80.185% | 88.219% | 100% |

这区分了两条制作路线：在指定的小范围条件中设计材料，或在广阔自由文本上显式
引入可检验的条件响应模型。不能在无模型、无补采的情况下输出全社群共同点分数。
本批另外隐藏再恢复已有完整条件，共709项，范围嵌套和宽度减少公式全部成立；
这是可逆材料检验，不是对未观测场景的真实预测成功。
