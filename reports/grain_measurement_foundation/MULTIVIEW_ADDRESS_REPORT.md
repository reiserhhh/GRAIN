## 1. 本轮完成了什么

不是另一次语义预测精度网格：实际调用原V7 E1的完整五视图模型，在现有624名
Big5-only作者的36评论材料上重放。**共同空间能保留跨评论作者关系；重构后剩余
部分也保留作者关系。因此共同空间与剩余配置应同时保留，不把后者直接当噪声。**
同时补上每个观察单位到原文token/字符位置的完整侧栏；这让旧GRAIN构造与新语义
证据可以按同一原文地址连接，而不是凭关键词或相似度猜对应关系。

本批无训练、无标签载入、无神经模型调用、无新作者抽样、无外部数据发送。

## 2. 从原文到输出的构造

```text
原作者36条评论 + 原文字符位置
  -> 原冻结共同预算：32条 / 最多4096项目tokens / 最小单位12tokens
  -> 五种观察：整篇、原评论、句群160、跨评论128、评论内128
  -> 固定 word TF-IDF + SVD24 的单位表示 phi
  -> 每位作者 mean/std，48维
  -> 原发现样本固定的逐视图标准化 X_v
  -> 既有编码器 S_v = E_v(X_v)，23维共同配置
  -> 重构 J_v = S_v D_v，剩余 R_v = X_v - J_v
  -> 数值配置 / 同作者匹配 / 原文证据地址，分别输出
```

这里不是新训练的LLM embedding，也不是新发现23个人格因子。原E1轴命名仍为
`FACTOR_AXES_NOT_IDENTIFIED_SUBSPACE_ONLY`。均值/std之后的动态解释要由时间与
条件模块另行连接；不能把std直接当变化速度。

原预算处理把tokens用空格重接，标点仍保留，但换行/排版不原样保留。
19,968个原评论段中19,956个与原字符子串的格式不同。新侧栏不改变计分输入，
而是保存`source_row, token_start/end, char_start/end, unit_token_start/end`。
重复短语按原token序列游标对齐，不用第一次substring命中；重叠/偏移窗口拒绝套用。

## 6. 数学与制作规则的变化

1. 共同配置、视图特有余项、单句语义证据使用相同来源地址，但不是同一对象。
   距离复现、功能预测、构念效度分别检验；不会由某一个AUC自动互相推出。
2. 本冻结模型`R=X-J`是操作性重构余项；不是[原JIVE](https://doi.org/10.1214/12-AOAS597)
   联合拟合的individual component。它也不与J正交：
   `mean(X^2)=mean(J^2)+mean(R^2)+2mean(JR)`。full native三项为
   `.750067 + .449183 + .047475 = 1.246725`。不能直接把能量各项称独立方差比例。
3. 计分单位与解释证据单位可不同：前者保持可重复的冻结规则，后者回到原文，
   在句/事件范围上检查主体、否定、习惯/单次、引语和上下文。不要改文本去迎合计分。
4. token地址存在只提供溯源条件，不等于解释忠实性。[ERASER §4.2式1–2](https://aclanthology.org/2020.acl-main.408.pdf)
   的删除/仅保留rationale预测比较仍是另一项实验，不能用本批覆盖率代替。
