# 同文本多通道观察与个人条件函数

2026-09-13。M04/M05主实验 `joint_conditional_observation_r1` 及结果后提出的
`paired_followup` 均已完成。结果来自公开编写的机制文本与模拟作者，不是新增真人人格相关。

## 1. 本轮推进了什么

**GRAIN、查询矩及语义读数已在同一原文上进入同一条件函数；真正补回联合个人差异的，
是保存同一事件里的关系，而不是把更多分数拼接后强行反演。**

1. 新查询组内K改善旧二次矩的条件读数，但仍不能稳定反演第三个弱方向。
2. 两个NLI边际读数分别很清楚，却不包含完整的事件联合关系。增加逐事件乘积后，
   留出措辞的联合条件读数相关从近0恢复到 **r=.3578**；解除配对后回到 **r=.0408**。
3. 同一个人函数保留了水平、条件有限差分、整条件隐藏预测，不用人口先验替本人作答。
4. 源计分器与新措辞之间的偏移，可以精确写成个人水平/条件响应的混合映射。
   因而异常不是笼统的“模型不好”，而能定位到观察方向弱、计分单位漂移或有限事件抽样。

M05达到本TODO的有限新增观察/冷计算/作用/条件应用验收。M04的同函数三输出实例已完成，
但“何时能让不同人共享响应结构”及开放语义条件仍保留。未重复旧Big5/MBTI评估。

## 3. 从输入到输出

```text
同一事件原文和条件地址
  -> 冻结四slice GRAIN / 原文向量前缀 / 固定语义读者
  -> 4个GRAIN均值 + 2个旧二次查询值 + 2个纯within-K值 + 2个语义边际
  -> 来源角点标定：各通道偏移、加载、共同措辞误差
  -> 固定多输出解码器与其分辨矩阵
  -> 每事件三个联合矩读数
  -> 每人两个端点的独立事件均值
  -> 一个函数：个人水平、条件有限变化、未见中间条件
```

两个查询沿用 `neuroticism` / `confirmation_seeking` 的旧算子名称；这里的已知目标是
编写文本中的事件极性，不能因查询名字就改称神经质或确认寻求心理量表真值。
NLI为 `cross-encoder/nli-deberta-v3-base`，revision
`6c749ce3425cd33b46d187e45b92bbf96ee12ec7`。
各原始通道都保留原单位；没有把K、logit、NLI边际直接相加。

## 4. 数学对象与制作规则

令同一事件的担忧/平静极性为s，寻求确认/独自行动极性为t，均取-1/+1。
个人条件对象为三个矩：

\[
m_u(z)=(E[s\mid u,z],E[t\mid u,z],E[st\mid u,z])^T=a_u+b_u z.
\]

第三项是**极性联合矩**，既受“担忧且求助”也受“平静且独自行动”影响；不单独等于
正向共同出现概率。若确需该概率，须使用三个矩一起计算：

\[
P(s=+1,t=+1\mid u,z)=(1+m_1+m_2+m_3)/4.
\]

四角点对二元事件给出完整展开。对任意有限维观察o，其角点条件期望可以写为：

\[
E[o\mid u,z]=b_o(z)+L(z)m_u(z).
\]

来源角点拟合b/L；每端点16文本、残差自由度12，R为角点内措辞协方差，固定0.1对角
收缩及相对方差底限。它是标定的工作协方差，**不是全部个人事件抽样误差**。
白化R后SVD求固定解码器W，输出：

\[
\widehat m=W(o-b_o),\qquad \mathcal R=WL,\qquad V_{work}=WRW^T.
\]

`resolution`即分辨矩阵。秩不足时输出的是投影；满秩但最小奇异值很小时，反演会放大
观察变化。这是标准广义最小二乘/线性代数，不是新心理测量公理。

只用z=-1/+1的本人材料构造：

\[
\widehat a=(\bar m_-+\bar m_+)/2,\quad
\widehat b=(\bar m_+-\bar m_-)/2,\quad
\widehat m(.5)=.25\bar m_-+.75\bar m_+.
\]

未见35分钟条件的事件未参与函数拟合。本实验以已声明的线性数值条件为对象；
不把时长插值当成自动理解任意新心理情境。个人参数分别生成在既定范围内，事件分布
由 `(1+s*m1+t*m2+s*t*m3)/4` 给定并检查合法性；估计结果未裁剪来掩盖反演失败。

材料协方差通过W和端点线性对比传播。水平与斜率由同两个均值得到，一般互相关，
新条件方差必须保留交叉项；这里未把有限来源标定不确定性或真实心理误差并入区间。

## 5. 主实验：额外通道有作用，但弱反演并未解决

下表为留出措辞、整条件隐藏z=.5、联合函数、3种子均值。
每格 `MSE / Pearson r`；模拟真值不是模型教师分数，也不是真人量表。

| 来源冻结的输入 | 担忧极性均值 | 确认行为极性均值 | 联合极性矩 |
|---|---:|---:|---:|
| NLI两边际 | .017891 / .6960 | .017709 / .6287 | .002889 / -.0064 |
| GRAIN4 | 15.620492 / .4187 | 331.815218 / .3895 | 29191.574561 / -.0022 |
| GRAIN+旧二次查询 | .212644 / -.1387 | 114.072372 / -.0694 | 15813.963084 / -.0164 |
| 再加within-K | .020229 / .4169 | .133239 / .3707 | 723.492417 / .0731 |
| 全部10通道 | .017726 / .6959 | .017570 / .6287 | 678.537940 / .0724 |
| 全部但忽略通道协方差 | .017754 / .6959 | .017717 / .6287 | 720.085771 / .0502 |

NLI两边际只支持秩2，第三坐标接近0；其第三项MSE小是因为真实第三矩的总体变异小，
不是它成功恢复联合差异。GRAIN/query有秩3但第三方向很弱：例如来源端点-1的
GRAIN最小白化奇异值约.006，全部10通道约.121。数值可逆不能代表可用观察强度。

上述巨大MSE原样保留。源措辞本身的全部10通道第三项MSE也有.9694，留出后678.54，
两部分分别反映弱方向抽样敏感与措辞标定漂移。新K在固定比较中改善旧矩读数，
但不能据此升级为一个普遍可靠的人格测量器。

仅水平/仅斜率/联合也全部保存。例如NLI留出担忧新条件：联合MSE .017891、r .6960；
仅水平MSE .015995、r .6833；仅斜率MSE .022688、r .1574。
有限事件下缩到水平可降低MSE却丢掉条件反应，联合函数也不是每个损失下都最好。

## 6. 结果后检验：增加事件配对观察，而非继续调逆问题

新增一个观察量，来源标定后再应用：

\[
p(x)=q_{worry}(x)q_{reassurance}(x),\quad
E[p(x)]\ne E[q_{worry}(x)]E[q_{reassurance}(x)].
\]

逐事件相乘保存关系；先各自跨事件取平均再相乘会丢掉关系。
这不是给原K换名：K是同token单元内查询对齐协方差，p是同一事件两个语义读数的乘积。
新增三通道NLI+乘积在所有3条件秩3，最小白化奇异值约293–368；该尺度只用于
本包固定单位/工作噪声下诊断，不是可跨系统比较的心理效应量。

同样z=.5，留出措辞，3种子均值：

| 路线 | 担忧MSE/r | 确认MSE/r | 联合MSE/r |
|---|---:|---:|---:|
| NLI+同事件乘积 | .017891 / .6960 | .017709 / .6287 | .017343 / .3580 |
| GRAIN/query/NLI+同事件乘积 | .017835 / .6959 | .017581 / .6287 | .017375 / .3578 |
| 相同模型、乘积第二项错开一个事件 | .017835 / .6959 | .017581 / .6287 | .021972 / .0408 |
| 完美事件极性的样本均值参照 | .018147 / .6956 | .018029 / .6284 | .018475 / .3594 |

**保留两边际与该人的全部材料，仅破坏配对，第三目标就基本消失。** 原始10通道不动，
对照只在同作者/条件内循环错开乘积第二项。它说明关系位于事件内配对，不是增加模型容量。
完美事件读者仍有32事件抽样误差；本包r约.36已经接近同预算简单事件均值参照，
不是Bayes最优上限或任何真实量表效度上限。留出措辞偶尔MSE更小也不表示超过真值读者。

完整配对函数在留出措辞下：

| 输出 | 担忧r | 确认r | 联合r |
|---|---:|---:|---:|
| 个人水平 | .7249 | .6542 | .3744 |
| 有限条件变化 | .4952 | .5499 | .3409 |
| 未见中间条件 | .6959 | .6287 | .3578 |

配对第三矩MSE高于原NLI近零投影的.002889，必须与恢复个人排序的收益一起报告。
三种子是预定模拟重复，未据这些均值宣称显著真人增益。
完整11通道未清楚胜过NLI+乘积三通道；本包支持联合观察接口，不支持为凑两路线
而声明GRAIN总有增益。该后续假设是在看过r1后提出，不能称原计划事前确认。

## 7. 观察漂移怎样变成假的个人变化

在应用措辞中，冻结计分器的期望可写成 `C_z*m_u(z)+d_z`，其中
`C_z=W_source(z)*L_application(z)`，`d_z=W_source(z)*(b_application(z)-b_source(z))`。
应用角点真极性只在评估此诊断映射时使用，没有反馈去修复模型。
记S=(C_-+C_+)/2，D=(C_+-C_-)/2，则：

\[
E[\widehat a]=Sa+Db+(d_-+d_+)/2,\qquad
E[\widehat b]=Da+Sb+(d_+-d_-)/2.
\]

不同条件的单位漂移不仅改变截距，还把水平与响应相互混入。原全部10通道在新措辞
第三矩的水平偏置项约-24.589、斜率偏置项-2.194；完整数值见
`evaluate/meter_drift_function_map.csv`。增加观测方向可解决其中一个弱识别实例，
不是声明所有开放文本计分漂移都被修好。

制作规则因此变成：先明确目标需要边际、联合还是条件变化，再检查对应观察加载；
弱方向缺信息时增加相应事件关系观察，不把大逆系数当“隐含人格发现”。

## 8. 验证、理论出处与边界

- 54项相关测试通过，包括联合矩、合法概率、重复通道、单位变换、秩不足、弱满秩、
  条件函数、关系解除及协方差传播。JUnit存于本包 `evaluate/tests.xml`。
- 2,158项独立公式复算PASS：原文h/g重算观察，独立平衡角点公式，Cholesky/lstsq
  替代生产特征分解，每个函数与MSE复算。最大函数差1.96e-12，最大指标差2.91e-11。
- 可逆单位变换分数差不超过1.48e-12；精确复制通道分数差不超过1.23e-12，信息差
  不超过9.90e-10。共同误差被保留，不把同文多通道当独立复制测量。
- 审计初稿的高级索引轴错误已改为显式事件/通道索引；是审计程序修正，冻结生产
  分数未变。该独立方程重算仍由同一agent完成，不冒充D02独立研究者复建。
- 核心/主runner/审计/测试Ruff检查通过，5文件格式检查通过。冻结后续runner保留
  1项PLC0206字典迭代风格提示，不影响结果；没有为消除提示改写已冻结hash。
- 本包权重含历史私人来源的派生数组以及预训练资产，仅本地使用；公开编写文本
  不代表整个依赖目录可公开。无新神经训练、无MEPS、无commit/push/发布。

继承[Álvarez、Rosasco与Lawrence的多输出函数综述](https://arxiv.org/abs/1106.6251)
第3.3/4节：输入条件与输出间关系应分开建模。本包为有限线性基底，未复现其GP模型。
协方差传播依据[JCGM 102:2011](https://doi.org/10.59161/JCGM102-2011)第6.2.1节；
本包固定线性映射下传播为精确代数，不把该计量指南当心理构念效度证明。
四角点矩展开、配对乘积与线性漂移展开均是标准代数；本地贡献是这些操作对当前
GRAIN/query/语义观察究竟保留或丢失什么的实测及可执行制作规则。
