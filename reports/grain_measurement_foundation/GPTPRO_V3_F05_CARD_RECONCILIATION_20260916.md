## Production Rules

1. Declare the estimand: personal level, conditional slope, current latent state
   and future response are distinct. Good forecasts cannot certify all parameters.
2. Freeze population/noise learning on source; application observations may update
   personal parameters within the permitted prefix. Sequential48+ updates states,
   not parameters, in this protocol. Failed optimization routes to a labelled
   source baseline; preserve availability and all-author losses.
3. State which information is from the observed sequence and which is from the
   source prior. Narrow posterior profiles can be mostly prior-driven. Plug-in
   state intervals omit parameter uncertainty and hand off to F13.
4. Use elapsed time in dynamics. A correct clock does not guarantee a finite-sample
   MAP loss win when source parameters/priors are imperfect. Preserve that reversal
   rather than adopting a knowingly wrong clock as a theoretical fix.
5. Model shared visible inputs when the design supports them. Off-diagonal process
   covariance improves present-state recovery in the common-shock simulation;
   it does not reveal future unobserved innovations. Population uncertainty uses
   independent episodes, not the nominal count of correlated authors.
6. Separate coordinate conventions from observable prediction laws. Free latent
   models allow similarity and noise-allocation equivalences; fixed-C/Q restrictions
   must be analysed separately. Arbitrary state axes are not named psychological
   constructs merely because the model fits.
